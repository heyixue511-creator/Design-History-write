# 《现当代设计史》全书框架

> 状态：初步框架（2026年9月6日）
>
> 依据：`03-教材框架/00_书籍定位.md`、`00-参考原则/00_教材写作修辞方法与原则.md`及现有文献研究。
>
> 本框架用于确定全书分期、章节主线和主要内容。具体人物、事件、对象及历史关系仍须依照`03-教材框架/02_框架确认与完善工作流程.md`继续核验。

## 一、总体结构

全书不设“编”，由导论、七章和结语组成。全书以时间为基本顺序，以设计与现代社会关系的变化确定章界：第一至第三章说明现代设计的形成和制度扩张，第四、五章说明设计在战后社会中的扩展、差异和争议，第六、七章说明产业全球化、数字化和平台化条件下的当代重组。

每章只承担一个主要历史转变，但不预设单一原因。相邻章节可以有时间重叠，不同地区也可以提前、延后或长期并存。中国材料进入各章的具体关系，不另设“中国情况”；全球史和去殖民化通过贸易、劳动、技术、制度、转译和使用关系落实，不以地区数量制造表面均衡。

人物、运动和经典作品只有在能够说明具体历史变化时才进入。各章节数按照实际内容确定，不追求形式整齐。

## 二、导论　如何研究关系中的设计史

导论界定本书的研究对象、历史范围和基本方法：

1. 从具体对象出发，说明材料、制作、流通、使用和制度之间的关系；
2. 辨明design、drawing、pattern、ornament、craft及“图案”“工艺美术”“工业美术”“艺术设计”“设计”等历史词语；
3. 说明从18世纪中后期起笔的理由，以及现代设计与当代设计之间的联系；
4. 说明具有中国视角的全球设计史和去殖民化立场；
5. 区分历史事实、行动者主张、制度规定、实际实施、使用记录和后世解释。

## 三、第一章　跨洲商品扩张与工业化早期（18世纪中后期—19世纪中叶）：构思与制作关系的重组

本章不把现代设计归结为某个单一的诞生时刻，而是考察跨洲商品贸易中已经存在的设计分工，怎样在18世纪后期至19世纪中叶被贸易保护、殖民原料、企业组织、机器生产和印刷技术重新组织。图样、样品、工程图和穿孔卡使技术指令能够离开原有作坊流动，但机器没有普遍取代工匠判断，构思、制作、经营和使用之间形成了新的权力关系。

| 节次 | 时期 | 重点内容 |
| --- | --- | --- |
| 第一节　亚洲商品怎样形成跨洲设计分工 | 18世纪中后期（向前追溯至17世纪） | 英国东印度公司的设计指令和图样与印度装饰棉布；VOC模型、科内利斯·普龙克图样与景德镇外销瓷；地方改绘、定制失败、验收和异地使用 |
| 第二节　图样书、样品与企业组织怎样连接市场和生产 | 1750年代—1810年代 | 齐本德尔《绅士与家具工匠指南》的顾客、工匠和印刷协作；韦奇伍德、托马斯·本特利和约翰·弗拉克斯曼之间的产品开发，以及图样簿、编号、样品、陈列室、模具和分工 |
| 第三节　贸易保护、奴隶制棉花与机器生产怎样重组纺织体系 | 18世纪后期—19世纪中叶 | 印度棉布仿制和进口限制；英国纺纱、织造与印花机械；圣多明各革命、美国轧棉机和奴隶制棉花；工厂中的妇女与童工；英国机制棉布进入印度市场及当地织工处境 |
| 第四节　图纸、穿孔卡与现场安装怎样重新分配技术判断 | 1770年代—1830年代 | 博尔顿—瓦特企业的工程图、专业供应商、分散制造和现场装配；雅卡尔提花装置的累积改进、穿孔卡与织工操作；机床和制造精度作短比较 |
| 第五节　印刷技术怎样扩大设计信息的复制与流通 | 1780年代—19世纪中叶 | 威廉·普莱费尔《商业与政治地图集》的统计图表、阿洛伊斯·塞内费尔德的石版印刷和弗里德里希·柯尼希的蒸汽动力滚筒印刷机；《便士杂志》的制版、发行、读者和教化目标 |

## 四、第二章　公共设计制度扩展时期（19世纪中叶—1914）：标准的建立、传播与争夺

本章考察设计判断怎样进入博览会、博物馆、学校、教材、商业媒介、城市工程和企业组织，成为可以展示、教授、评奖、复制和监督的公共标准。这些制度既服务于工业竞争和殖民分类，也受到工艺改革、民族工业、地方技术和市场使用的改写。

| 节次 | 时期 | 重点内容 |
| --- | --- | --- |
| 第一节　博览会怎样把制造竞争转化为公开评判 | 1851年前后—1860年代 | 1851年伦敦博览会、水晶宫、展品分类、殖民陈列、评奖和观众反应；巴黎博览会作后续比较 |
| 第二节　博物馆、教材与考试怎样固定设计知识 | 1850年代—1890年代 | 亨利·科尔、南肯辛顿制度、设计学校网络、博物馆、《装饰的语法》、课程与考试 |
| 第三节　工艺改革怎样反思劳动、机器与价格 | 1860年代—1890年代 | 罗斯金、莫里斯商号、家具、壁纸、书籍、作坊劳动和销售价格；工艺组织与社会主义活动 |
| 第四节　商业石印怎样形成市场化公共视觉 | 1870年代—1905年 | 欧洲彩色海报与上海点石斋、同文书局、《点石斋画报》；印刷劳动、价格、发行和读者 |
| 第五节　工业教育怎样被国家、殖民政府和民族运动重新解释 | 1870年代—1911年 | 日本维也纳博览会调查与工艺教育、马德拉斯艺术学校和斯瓦德希、晚清实业教育与1910年南洋劝业会 |
| 第六节　城市构件与企业体系怎样推进形式标准化 | 1900—1914年 | 吉玛德巴黎地铁入口；德意志制造联盟、AEG、贝伦斯及1914年类型化争论 |

## 五、第三章　战争、革命与总体动员时期（1914—1945）：设计协调能力的大规模组织化

本章考察设计教育、生产、传播、交通和行政怎样进入战争、革命、企业和国家的大规模组织。设计协调扩大了生产和公共传播能力，也被用于殖民征用、政治宣传、强迫劳动和战争暴力；这不是现代主义风格的单线胜利。

| 第二节　实验学校怎样在财政、课程与生产压力下改组 | 1919—1933年 | 包豪斯与VKhUTEMAS／VKhUTEIN的建校、招生、课程、工作坊、生产合作、治理变化、关闭和人员迁移 |

| 第五节　独裁政权与帝国怎样征用现代专业能力 | 1930—1939年 | 德国人民收音机和宣传展览、苏联工业计划与《建设中的苏联》、日本产业合理化和1935年台湾博览会 |
| 第六节　亚洲战争怎样重组生产迁移、帝国资源与抵抗传播 | 1937—1945年 | 中国工业内迁、战时物资和抗战木刻；日本战争生产、殖民资源及《写真周报》《FRONT》 |

## 六、第四章　战后重建、冷战与去殖民化时期（1945—1968）：设计进入日常生活与国家建设

本章考察战时形成的标准、生产能力和专业知识怎样转入消费品、普通住房、设计教育、国家规划和视觉系统。福利国家、社会主义计划、企业出口、冷战竞争和去殖民化国家形成了不同的战后生活秩序，而不是统一的战后现代主义。

## 七、第五章　社会动员与公共责任争议时期（1960—1979）：设计需求与决策权的公开争夺

本章考察专业人员、国家和企业替“用户”定义需要的权威怎样受到公开争夺。消费与环境批判、黑人自决、中国政治动员、女性主义、工人参与、发展设计和残障权利具有不同的政治基础，不能合并成统一的参与式设计运动。

## 十、结语　关系中的设计与开放的当下

结语回收全书，不增加新的大型案例：

1. 总结现代设计怎样由制造、媒介、专业制度、国家、企业、社会行动、使用和维护关系共同形成；
2. 说明历史不同步是全球设计史需要解释的基本状态；
3. 总结中国材料怎样改变对工业化、现代主义、社会主义设计、全球生产、数字媒介和平台的理解；
4. 说明设计的创造性和社会改善愿望怎样同资本、殖民、战争、不平等和环境后果并存；
5. 区分已经验证的历史变化、合理推断和仍在发生的趋势；
6. 说明AIGC用于史料检索、OCR、图像识别、分类、翻译和辅助写作时的来源追踪与人工核验责任。

本框架中的章题、时段和内容仍是待验证安排。后续研究发现重大遗漏、证据不足、内容重复或章际逻辑不成立时，应依照框架确认与完善工作流程进行调整。
