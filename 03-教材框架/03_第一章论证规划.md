# 第一章论证规划

> 状态：阶段性规划（2026年9月6日）
>
> 对应章节：第一章“跨洲商品扩张与工业化早期（18世纪中后期—19世纪中叶）：构思与制作关系的重组”

## 一、规划性质

本文件不是第一章的人物和对象清单，也不是可以直接扩写的节级目录。它规定本章需要证明什么、五节怎样形成递进关系、核心对象与行动者分别承担什么论证责任，以及哪些结论必须受到证据限制。

本规划以《书籍定位》《全书框架》和第一章第一轮核验结果为边界。进入正文的年代、对象信息、生产关系、影响和因果判断，仍须回到实物记录、企业与贸易档案、同期文献及可靠研究逐项核实。现有分析报告只用于定位材料和发现问题，不能替代原始证据。

## 二、本章需要成立的判断

现代设计不能被归结为某位设计师、某项机器或某家工厂的单一发明。在18世纪中后期以前，印度棉布、景德镇外销瓷等商品已经通过订单、样本、图样、商人网络和地方制作形成跨洲设计分工。18世纪后期至19世纪中叶发生的关键变化，是这些已有关系同贸易保护、殖民原料、奴隶制、企业组织、机器生产和印刷媒介结合，使设计决定能够在更远的距离和更大的生产规模中传递、复制和接受检验。

这种变化不是构思从制作中一次性分离，也不是机器普遍取代手工。图样书、编号、模具、工程图和穿孔卡把一部分判断转化为可以保存和传递的指令，同时又产生新的解释、操作、校正、安装和维修劳动。商人、企业家和工程师扩大了对商品与生产的控制，印度印染工、景德镇画工、欧洲作坊工匠、奴隶、工厂工人、织工、印刷工和现场装配人员仍以不同方式改变最终结果。

本章由此需要证明五项相互衔接的判断：

1. 跨洲设计分工先于英国工业化存在，而且包含双向转译、地方改造和定制失败，不能写成欧洲向亚洲单向输出设计。
2. 图样书、样品和企业记录把市场选择、形式构思与生产控制连接起来，但尚未形成后来边界明确的设计职业。
3. 纺织机械化是由贸易政策、原料供应、奴隶制、工资劳动、技术改造和市场竞争共同组成的全球重组，不能压缩为英国发明史。
4. 工程图和穿孔卡使部分技术判断外化并扩大协调范围，却没有消除默会知识、现场判断和熟练操作。
5. 统计图表、石版印刷、蒸汽动力印刷和铁路时刻信息扩大了设计信息的复制与公共流通，但它们属于不同的技术和使用关系，不能统称为“机械印刷”。

## 三、论证的内在次序

### 第一节　从亚洲商品说明跨洲设计分工

本节先以约1750年前后的印度装饰棉布和按科内利斯·普龙克图样制作的中国外销瓷建立对象问题：商品在亚洲制作、经贸易公司订购并在欧洲使用时，谁决定材料、器形、纹样和质量，图样又怎样在不同语言、作坊和审美习惯之间被理解？为回答这一问题，可向前追溯英国东印度公司1643年的文字指令、1662年起可能为纸本的图样，以及VOC发送模型和图样的实践，但必须说明这些材料是18世纪中后期的必要前史。

印度棉布部分不能只重复“欧洲提供图案”。正文应比较伦敦董事的要求、印度商人与印染工的解释空间、染色技术、实际商品及欧洲用途，辨明哪些特征来自明确指令，哪些属于地方改造，哪些只能确认是多种视觉来源的混合结果。John Styles对“印度棉布创造欧洲时尚”的质疑，与Prasannan Parthasarathi对印度生产者能动性的补充，应作为相互限制的解释，而不是选择其中一方成为定论。

景德镇部分以VOC模型订制的迟延和失败限制成功史，再以1730年代普龙克图样及其中国、日本版本说明同一图样在跨洲转移中怎样发生材料化和改绘。官窑、民窑、贸易公司和地方画工的关系需要分别说明；欧洲公司档案保存较多，不能据此把贸易公司写成唯一的设计主体。

本节结论只到以下范围：工业化以前已经存在跨地点的构思、制作、验收和使用分工，设计控制既不集中也不稳定。它不能提前宣称现代设计职业已经诞生。

### 第二节　由图样书和企业记录说明市场与生产的连接

本节把论证尺度从跨洲订制转向图样和样品怎样在企业内部及市场中工作。齐本德尔1754年《绅士与家具工匠指南》应同时作为设计对象、商业出版物和协作成果分析：齐本德尔绘制和选择方案，专业刻工把图样转为印版，订户和潜在顾客借此选择，其他家具工又可以复制或改造。书中图版提供比例、装饰和部分制作信息，却不是现代意义上的完整工程蓝图。

韦奇伍德案例用于说明另一种连接方式。托马斯·本特利提供市场信息，约翰·弗拉克斯曼等造型者提供模型，工厂通过有限器形、模具、编号和分工维持生产，图样簿、样品、目录和陈列室又把生产记录同订货相连。约1810年的现存图样簿可以证明这一制度已经形成，不能未经档案核查便把其全部内容提前归到韦奇伍德本人在世时期。

两案比较的重点不是谁更接近“现代设计师”，而是公开印刷的图样书与企业内部使用的图样、样品和编号分别怎样移动决定权。齐本德尔和韦奇伍德也不能代表全部家具业和陶瓷业；普通作坊、仿制者、工人和顾客的材料用于限定其代表范围。

本节应得出的判断是：设计决定开始以可复制的视觉和书面媒介连接顾客、经营者与生产者，企业由此获得更强的协调能力，但形式判断和制作知识仍由多人共同完成。

### 第三节　由棉纺织体系说明工业化的全球条件

本节不能按飞梭、珍妮纺纱机、水力纺纱机、骡机和动力织机排列发明。它应先说明印度棉布的技术与市场地位，再追踪英国进口限制、国内仿制和印花生产怎样改变竞争条件。贸易保护为本土制造提供条件，不等于它直接导致工业革命；市场需求、资本、能源、原料和劳动组织仍须分别证明。

机械化部分围绕生产瓶颈和劳动重新分配展开：不同机器首先改变纺纱、织造或印花中的哪一环节，哪些操作被简化或加速，哪些熟练劳动仍然存在，又为何形成集中工厂与外包生产并存的格局。妇女、童工、手织工和技术工人不能只作为机器史的社会后果出现，他们的工资、技能、工作时间和抵抗共同决定机器怎样实际运行。

原料链把英国工厂同加勒比和美洲连接起来。圣多明各棉花生产、1791年革命造成的供应变化、美国轧棉机和奴隶制种植扩张，用于证明机器需求怎样转移到殖民土地与强制劳动，不能把轧棉机写成脱离奴隶制的效率发明。随后追踪英国机制棉布进入印度市场及当地织工的处境，使本节从“印度商品进入欧洲”推进到工业产品反向改变亚洲生产。

本节结论应限定为：纺织品的低价、数量和纹样变化能力来自全球原料、政策、机器与多种劳动制度的结合。它不支持英国技术内生发展、所有印度手工业迅速消失或机器必然带来社会进步等结论。

### 第四节　比较工程图与穿孔卡怎样重新分配技术判断

本节比较两种不同的技术协调方式。博尔顿—瓦特企业的工程图、专门供应商、分散制造和现场装配，用于说明早期蒸汽机并非由一个工厂完整制造后直接交付。现有研究能够支持图纸与现场监督并存，却不足以还原一台特定机器从合同到维修的全部链条。因此正文只讨论企业层面的生产方式，不虚构单项工程的连续过程。图纸使零件要求能够跨地点传递，但制造精度、现场条件、装配、调试、替换和维修仍需要专业判断。

雅卡尔提花装置用于说明另一种“外化”：穿孔卡把纹样选择转化为织机可以逐行读取的控制信息。正文应交代巴西尔·布雄、让·法尔孔和雅克·德·沃康松等人的此前方案，避免把1801年写成单人突然发明；还要说明织工怎样操作设备、制作和校正卡片，以及原有提花劳动怎样变化。穿孔卡可以同后来的信息控制史发生联系，却不能直接称为现代计算机程序。

两案只在“技术指令怎样被保存、传递和执行”这一问题上比较。工程图规定部件关系，穿孔卡控制纹样次序，两者没有需要预设的直接影响关系。机床和可互换性仅在能够说明制造精度与重复生产时作短比较，不另行扩展为机械工程通史。

本节应证明：构思与制作的关系发生了重组，但“外化”不是彻底分离。可见的图纸和编码只有同材料知识、身体技能、现场协作和修理能力结合，才能成为实际产品。

### 第五节　区分印刷方法、动力机器与公共信息

本节从生产指令转向设计信息的公共传播。威廉·普莱费尔1786年《商业与政治地图集》以铜版印刷的统计图表把贸易数据转成可比较的视觉形式，用于说明信息组织上的创新及其高成本和有限早期接受；它不能被当作机械印刷的实例。

塞内费尔德的石版印刷应从在石面制图、油水关系、转印和早期专业操作说明其技术特点。其意义在于改变制版和图像复制的关系，不在于蒸汽动力。柯尼希1814年用于《泰晤士报》的滚筒印刷机则说明动力和机械结构怎样提高印刷速度，但实际效果还取决于排字、供纸、油墨、发行量和出版市场。两种技术必须分别叙述。

《便士杂志》用于说明制版、蒸汽印刷、纸张、发行网络、价格、编辑目标和读者选择怎样共同形成可持续的大众图像传播。它不能证明印刷天然带来文化民主化：刊物的教化目标、具体图文编排和读者能动性必须同时进入分析。铁路时刻表因本地材料不能支持其版面与实际使用细读，不再作为本章核心案例。

本节结论是：到19世纪中叶，设计信息已能面向更大的公众复制、更新和流通，但技术可用性不等于信息已经易懂或得到普遍接受。这个问题为第二章转向博览会、博物馆、学校、教材和公共标准提供接口。

## 四、全章论证链条与章际关系

本章的递进关系是：跨洲商品先形成分散的设计决定和地方转译；图样书与企业记录把部分决定连接到市场和生产；纺织体系把这种组织能力置入殖民原料、机器和劳动制度；工程图与穿孔卡进一步使技术指令能够跨地点重复执行；印刷和铁路信息又把复制与协调推向更广的公共领域。

第一章的终点不是专业设计制度已经建立，而是说明公共制度出现以前，设计对象、生产指令和商业信息已经形成扩大协调的物质条件。第二章随后研究博览会、博物馆、学校、教材和国家制度怎样把这些分散实践转化为可展示、教授、评奖和监督的公共标准。两章可以在19世纪中叶发生时间重叠，但不能重复承担“标准如何制度化”的问题。

## 五、核心对象与行动者的论证责任

| 对象或关系 | 在本章中的作用 | 不得推出的结论 |
| --- | --- | --- |
| 印度装饰棉布与英国东印度公司图样 | 证明跨洲订制、技术差异和地方转译 | 欧洲单独设计、印度只负责复制；印度棉布单独创造欧洲时尚 |
| 普龙克图样及中国、日本瓷器版本 | 证明图样跨地区材料化和改绘 | 一件定制瓷器代表全部景德镇生产 |
| VOC模型订制失败 | 限制贸易公司能够完全控制远程生产的判断 | 一次失败证明跨洲订制整体无效 |
| 齐本德尔《绅士与家具工匠指南》 | 证明图样书同时连接作者、刻工、顾客和制作同行 | 齐本德尔已经等同于现代职业设计师 |
| 韦奇伍德图样簿、样品和陈列室 | 证明企业怎样连接编号、生产一致性和订货 | 韦奇伍德独自发明工厂、市场营销或工业设计 |

| 博尔顿—瓦特图纸与现场装配 | 证明工程图怎样协调分散制造和现场工作 | 图纸能够取代制造、安装和维修知识 |
| 雅卡尔提花装置及穿孔卡 | 证明纹样信息可以转化为机器控制次序 | 1801年出现了现代计算机程序或完全自动化 |
| 普莱费尔统计图表 | 证明信息形式本身能够被重新设计 | 图表因形式新颖便立即获得广泛接受 |
| 石版印刷、蒸汽印刷与铁路时刻表 | 区分制版方法、动力机器和系统信息需求 | 三者属于一种单线发展的“机械印刷革命” |

## 六、本章必须控制的边界

第一，正文可以使用drawing、pattern、design等历史词语，但不能把18世纪的图样师、企业家、工程师和工匠直接套入20世纪设计职业定义。“设计决定”“构思”“图样”和“生产控制”应根据材料选择，不以“设计师”统称所有行动者。

第二，第一节向前追溯至17世纪，只为证明18世纪中后期转变所继承的跨洲关系。前史不能吞没本章时段，也不能把数百年的亚洲生产压缩成工业化的序幕。

第三，中国与印度不是地理补充。景德镇和印度棉布材料必须改变对设计来源、作者身份和远程控制的解释；欧洲公司档案造成的材料优势不能被误写成欧洲行动者拥有全部决定权。

第四，贸易限制、消费需求、机器、奴隶制、煤与蒸汽、企业管理和印刷扩张之间属于多重条件关系。只有存在中间机制和相应材料时才能写成因果，时间先后或共同增长不能代替证明。

第五，代表性企业和经典对象只用于建立具体关系。韦奇伍德、博尔顿—瓦特、齐本德尔和普莱费尔的知名度不能替代普通商品、失败方案、生产者与使用者材料。

第六，本章讨论的是构思、制作和流通关系的重组，不负责完整讲述设计教育、博物馆、博览会和职业制度。这些内容进入第二章；第一章只在结尾说明它们为何成为新的历史问题。

## 七、写作前仍须补证的问题

1. 为第一节确定可以进行实物细读的印度棉布和普龙克瓷器版本，并核对尺寸、材料、制作地、订购地、现藏地和图样来源。
2. 继续核实英国东印度公司1662年图样的载体，补充印度商人、印染工和消费者材料；补查景德镇画工、订单执行和地方档案，降低公司档案的单向偏差。
3. 区分齐本德尔《指南》各版、订户、实际制作与改造证据；核实韦奇伍德现存图样簿、样品、账册和陈列室材料的具体年代及不同参与者责任。
4. 核对英国棉布限制法律的适用对象和实施效果，分别研究纺纱、织造、印花的机械化进度，并补充妇女、童工、手织工和印度织工的工资、工作与抵抗记录。
5. 继续寻找博尔顿—瓦特具体项目的图纸、供应商、合同、现场安装、替换零件和维修材料；在找到连续项目档案以前，只使用已经得到研究支持的企业层面关系。
6. 核对雅卡尔装置此前技术来源、穿孔卡制作流程、织工操作及劳动冲突，不以技术原理说明自动替代实际社会结果。
7. 分别核查普莱费尔图表的版次与早期接受、石版印刷的跨国传播与专业劳动、柯尼希印刷机的生产条件，以及《便士杂志》的制版、发行、编辑目标和读者关系。

这些缺口不会推翻本章当前的基本判断，但会决定正文能否把总体关系落实为可观察对象、具体行动和有边界的历史解释。在相关材料完成核查以前，本规划不能直接转换为正文结论。
