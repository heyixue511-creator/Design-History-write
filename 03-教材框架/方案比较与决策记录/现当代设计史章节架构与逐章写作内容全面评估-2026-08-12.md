# 《现当代设计史》章节架构与逐章写作内容全面评估

> 评估日期：2026年8月12日
> 评估对象：当前本地仓库中的教材总纲、逐章结构文件、写作参考体例、导论正文初稿与章节证据审计
> 评估性质：结构与写作任务评估，不等于史实、引文、图像和版权已经通过出版级核验

## 一、独立结论

现有“导论＋五编十六章＋结语”的宏观架构可以保留。它已经摆脱常见的“欧美运动—大师—名作”单线目录，形成了时间为坐标、历史问题为推进动力、对象为观察入口、制度与生产为解释机制、中国经验与全球关系并行的基本方案。这是一个有明确学科立场的教材架构，不是一般性的设计史知识目录。

但当前总纲还不能直接作为十六章同步开写的最终蓝图。主要原因不是章节不够多，而是部分章节承担了过多互不相同的任务：第8章同时处理冷战、社会主义设计、去殖民化、南亚、非洲、拉丁美洲和国际援助；第9章把家庭消费史、性别史、亚文化史、企业形象、瑞士平面和公共信息设计放在同一章；第14章跨越计算机、软件、HCI、网络、移动、服务和平台；第16章又同时承担算法史、生成式AI、基础设施、中国平台生活和设计职业转型。这四章在1.4—1.8万字和3学时的限制下，很容易成为概念压缩与案例点名，而不是有对象、有机制、有证据的历史叙述。

因此，建议采取“保留宏观模型、重做内部责任”的修订策略：不重新发明整本书的结构，而是先明确每章只能回答什么、不得重复什么、由哪一个历史现场和哪一条对象链贯穿，再决定材料进入。第8章应改造成两个清楚的内部模块或拆为上下章；第9章应合并企业形象与瑞士平面两节，重新建立“消费生活—组织化传播”的桥梁；第14章与第16章必须用时间、对象和责任边界严格分工；第6章标题应与其实际以中国为主体、以东亚为中介的内容一致；结语需要补出核心问题、核心论点与回收机制。

对当前完成状态也要有清楚判断：本地最新汇总显示，121个小节均已有人工语义复核记录，390／589项来源进入复核，形成2388条映射，但核验等级仍全部为V2。这个状态证明章节问题已经获得相当规模的材料路由，不证明各章可以逐字引用，更不证明当前章节论点已成为出版级定论。框架评估与证据成熟度必须分开。

## 二、本书究竟要写成什么

### 1. 核心写作意图

这本书的真正对象不是“现代设计作品有哪些”，而是人工世界如何被生产、流通、使用、维护、解释和治理。全书应让学生看到，一件产品、一幅图像、一项服务或一个平台，并不是某位设计师思想的透明结果，而是材料、劳动、技术、企业、学校、国家、市场、媒介和使用者共同作用的历史产物。

这一意图包含四个相互关联、但不能混为一谈的教学目标：

1. 建立1750年至今的基本时间坐标，使学生知道主要制度、媒介和设计实践在何种历史条件下出现。
2. 训练历史解释能力，使学生能从形式辨认进入生产、制度、流通、使用和后果分析。
3. 建立全球关系与中国经验之间的双向叙述，避免把中国写成欧美设计史之后的接受者附录。
4. 培养证据与责任意识，使学生能区分行动者主张、制度规定、实际生产、使用经验、研究者解释和教材判断。

这四项目标共同决定：本书既不能写成作品图录，也不能写成纯理论读本，更不能把研究工作台账直接搬进正文。它应是一部“以具体对象训练历史判断”的专业教材。

### 2. 当前定位中的内在张力

现有总纲同时追求全球覆盖、中国纵向主线、史学方法、理论批判、教学工具和出版级证据纪律。这些目标都合理，但不能在每一章中平均兑现。若要求每章同时包含经典案例、匿名案例、跨区域案例、反例、中国关联、史料实验室、争议框和多条贯穿线，章节会被栏目挤碎，正文也会失去叙事重心。

解决办法不是删去这些要求，而是允许同一案例承担多个功能，并让不同章节各有教学重点。例如，一件商品既可以是经典对象，也可以追踪匿名劳动和跨境流动；一个失败的公共服务项目既可以承担反例，也可以进入使用与维护史。全书应保证这些视角得到系统覆盖，不必强迫每章机械配齐同一套案例类型。

## 三、阅读对象与接受能力

### 1. 已明确的读者

现有总纲把读者设定为设计学理论、设计史论、艺术设计学专业本科高年级，以及设计学硕士史论基础课程。这个群体能够理解基本概念和史学争议，但不能假定他们已经掌握世界近现代史、殖民史、冷战史、中国工业史、HCI史和AI治理等多套背景知识。

### 2. 当前负荷是否合适

形式上，每章3学时、5—7个正式小节、1.4—1.8万字并不异常；问题在于每个小节内部的概念和地域跨度。以第8章为例，学生需要在一次章节学习中同时理解冷战宣传、社会主义计划生产、住房与短缺、去殖民国家建设、南亚工艺政策、非洲和拉丁美洲发展主义、国际援助与专家网络。即使每项内容都准确，学生也很难形成稳定的问题记忆。

学生最容易接受的不是“少讲理论”，而是让理论有可重复的观察入口。每章应控制为：

- 一个主问题，最多三个子问题；
- 一个贯穿全章的主对象或历史现场；
- 两个补充案例，其中至少一个修正主论点；
- 四至六个需要真正掌握的核心概念；
- 一种可迁移的方法，如对象细读、制度档案分析、跨区域传播链、使用史或平台版本史；
- 一条清楚的章际转折。

### 3. 建议采用分层阅读

为了同时服务本科高年级与硕士基础课，建议把内容分成三层：

1. **核心正文**：完成历史问题、对象链和机制解释，是所有学生必读部分。
2. **案例／史料栏目**：展开图像、档案、争议和反例，本科课堂可选讲，硕士课程要求精读。
3. **研究延伸**：放置史学争论、版本问题、证据缺口和进阶阅读，不进入正文主线。

这种分层不是降低学术要求，而是避免学生在还没有理解历史过程以前，先被来源等级、概念谱系和地区清单压垮。

## 四、应当采用怎样的讲述方式

### 1. 章节的基本叙事动作

每章不应从风格定义、人物名单或文献综述开篇，而应从可定位的现场开始：一件物如何被制造，一次展览如何组织观看，一份课程文件如何分配权力，一个界面如何引导操作，或一个平台规则如何改变参与者的选择。随后才逐步扩大尺度。

适合本书的基本顺序是：

> 历史现场与对象 → 当时发生的冲突 → 参与者及其主张 → 材料、技术与组织机制 → 生产、流通、使用和维护 → 比较对象与反例 → 证据边界 → 有条件的章节结论

这是一组功能，不应变成所有章节都使用相同标题、相同句式的模板。工业史章节可从生产流程展开，展览史章节可沿观看与分类展开，教育史章节可沿课程—工坊—评价—迁徙展开，数字史章节则应沿版本—界面—数据—运营—治理展开。

### 2. 三幕式章节组织

为了增强可读性，可把每章的5—7个小节组织为三幕，而不是七个并列主题：

1. **问题如何出现**：用对象和历史冲突建立学生需要解释的疑问。
2. **机制如何运行**：追踪制度、技术、劳动和媒介怎样把主张变成实践，并说明实践为何偏离主张。
3. **结果如何被使用和争论**：比较地区差异、使用者改写、失败、后果与后来的历史解释。

每章结尾只需要完成四件事：回答了什么；证据允许回答到什么程度；哪个反例限制了结论；下一章为什么必须更换观察尺度。不要用章末再次复述七节目录。

### 3. 现有导论初稿提供的实际检验

当前导论开篇以20世纪70年代中期尼日利亚比达女式裹衣进入问题，让工业纱线、合成染料、手织技术、女性劳动和博物馆分类在同一对象上相遇。这个开篇证明，总纲提出的“场景—对象—机制—边界”方式可以形成可读正文，而不必先讲一套抽象方法。

它也暴露了一个需要持续防范的问题：进入0.1后，布坎南、沃克和阿特菲尔德在较短篇幅内连续出现，正文很容易再次接近学者观点串联。后续章节应让研究者姓名承担明确的争议定位功能，而不是用多位学者的定义代替对象与历史过程。证据等级、来源矩阵和详细核验状态继续留在审校说明、注释和工作文件中是正确的。

## 五、全书章节关系评估

### 1. 总体结构

五编的基本推进成立：

- 第一编回答现代设计的社会与经济条件如何生成；
- 第二编比较先锋实验、教育制度、商业职业与区域转译；
- 第三编讨论战后不同政治经济制度怎样设计现代生活；
- 第四编处理现代主义批判、责任扩展和全球生产重组；
- 第五编解释设计对象怎样从产品扩大到软件、服务、平台和算法系统。

问题不在五编，而在编内章节有时仍以运动、国家或理论名称并列，导致问题链重新退化成主题清单。尤其是第3、7、8、11、12、15章，必须确保小节标题之下写的是机制变化，不是运动或地域的缩略史。

## 六、逐章评估与建议编排

### 导论　设计史的对象、证据、时间与叙事

**本章任务**：不是提供全书知识摘要，而是教会学生如何把人工物转化为历史问题，并理解历史解释为何有证据边界。

**应写内容**：保留对象／活动／话语／制度的区分，保留现代性、现代化、现代主义和当代性的最低限度辨析，重点讲物证、图像、档案、口述与数字痕迹之间的证明责任，再以扩散、转译和纠缠三种模型说明全球关系。

**建议顺序**：裹衣或另一件可核对象开篇 → “设计”四个层次 → 时间概念 → 从英雄史转向关系史 → 物证与其他材料 → 保存偏差和缺席者 → 全球关系模型 → 本书阅读方法。

**主要风险**：八节全部是方法论，概念密度高。0.4—0.6可形成连续的“证据三节”，避免反复定义；0.8应非常短，只交代阅读装置。导论不宜承担所有方法训练，部分方法应在后续“史料实验室”中再次通过对象学习。

### 第一章　工业化、劳动分工与“设计”的生成

**本章任务**：解释专业设计为何逐渐从分布式造物活动中分化出来，同时否定“机器自动发明设计”和“手工被机器完全替代”两种简单叙事。

**应写内容**：作坊与家庭知识、能源与生产尺度、图样和标准、材料供应链、工厂中的分布式作者、专利与职业称谓、不同地区的混合生产。

**建议顺序**：从一件可追踪图样—模具—工序—成品的对象进入 → 回看前工业知识分布 → 机器与材料扩大尺度 → 图样、标准和监督改变权力 → 追踪匿名协作 → 讨论职业名称形成 → 用非英国案例限制英国经验。

**主要风险**：若按棉、陶瓷、铸铁、钢、玻璃逐一介绍，会成为材料小史。应选择一条主生产链，其他材料只承担比较。概念史应在学生已经看到分工变化后出现，不要从“design词义”开篇。

### 第二章　改良、消费、展览与跨国物质流动

**本章任务**：说明工业产品如何同时变成审美改革、社会治理、消费欲望和帝国分类的对象。

**应写内容**：1851年博览会、南肯辛顿体系、拉斯金与莫里斯、百货商店与信用、殖民展陈、跨境材料与图样流动。新艺术不应被写成独立风格巡礼，而应作为“整体生活环境”与消费改革之间的对象案例。

**建议顺序**：水晶宫中的一件展品或一条观看路线 → 展览怎样制造“设计问题” → 博物馆、学校和国家改革 → 工艺美术的劳动批判及其商品矛盾 → 商店和广告怎样生产消费者 → 殖民分类怎样组织异域物 → 沿一件棉布、陶瓷或纹样追踪双向转译。

**主要风险**：本章包含两部历史——国家改革史与市场／帝国史。应明确前半章讲“谁定义好设计”，后半章讲“物和欲望怎样流动”，由展览同时作为两者的接口。否则七节只是并列专题。

### 第三章　战争、革命与先锋派的视觉—物质实验

**本章任务**：解释先锋派为何把形式与媒介当作社会改造工具，以及宣言中的改造愿景为何不能直接等同于生产和社会效果。

**应写内容**：战争与都市感知、排印实验、拼贴和蒙太奇、构成主义与生产主义、抽象形式进入家具与空间、新摄影和展览传播、刊物与迁徙网络。

**建议顺序**：从一张刊物跨页、一幅蒙太奇或一次展览进入 → 战争与大众媒介改变视觉条件 → 未来主义与达达作为两种不同操作 → 构成主义由绘画转向生产的尝试与失败 → 风格派把抽象转入空间和物 → 新摄影／新字体／展览形成公共传播 → 用跨国网络和未实施方案限制“先锋改变社会”的结论。

**主要风险**：现有2—5节仍以运动命名，容易恢复运动史目录。正文小标题应优先写“它做了什么、改变了什么”，运动名称退居副标题。现有材料中行动者宣言较强、接受者和实际效果较弱，必须持续区分主张、实施与后果。

### 第四章　制度化的现代主义：制造联盟、包豪斯与设计教育

**本章任务**：说明现代主义影响力为何来自课程、工坊、企业合作、出版、展览和迁徙，而不是某种固定形式自然胜出。

**应写内容**：制造联盟标准争论、AEG企业系统、魏玛与德绍包豪斯的课程和工坊、性别分流、学校政治、原型与量产之间的距离、迁徙和区域转译。

**建议顺序**：从一份课程表、工坊订单或实验住宅进入 → 改革联盟与企业先例 → 基础课程如何组织身体和材料 → 1923年后原型／生产转向 → 德绍工坊劳动和作者权 → 学校政治与关闭 → 哪些制度被复制、哪些实验被删去 → 中国及其他地区的选择性转译。

**主要风险**：本章容易被包豪斯吸收，制造联盟、企业制度和其他学校成为前奏。应让“制度复制”而非“包豪斯完整史”成为主角；4.7不能只是中国关联附录，应在课程、出版和迁徙的中介链中提前出现。

### 第五章　商业现代性：装饰艺术、流线型与工业设计职业

**本章任务**：说明企业、广告、市场研究和经济危机怎样形成不同于欧洲社会改革传统的商业设计制度。

**应写内容**：装饰艺术的奢侈与殖民资源、美国大众消费、销售工程、流线型的跨物类迁移、咨询设计和企业团队、人体测量与家务效率、计划性更新和消费者能动性。

**建议顺序**：从1930年代一件交通工具或家电的造型与销售进入 → 用1925年巴黎博览会交代装饰艺术前史 → 美国企业和零售体系 → 危机中的销售工程 → 流线型如何跨媒介扩散 → 职业设计师与企业团队的权力分配 → 身体和家庭如何被测量 → 计划报废与实际使用限制商业叙事。

**主要风险**：雷蒙德·罗维等人物容易重新成为英雄主线。人物只应作为合同、团队、媒体作者形象和职业权威的节点。5.7不能仅用后来批评者的道德判断，应加入产品寿命、维修、价格、消费者选择和失败项目。

### 第六章　东亚转译与中国现代设计的形成（1895—1949）

**本章任务**：解释中国现代设计如何在印刷、实业、教育、商业、民族国家和战争条件中形成，并说明日本、欧美与中国之间不是单向输入关系。

**标题判断**：现有内容以中国为主体，东亚主要作为术语、教育和制度中介。“东亚转译”置于标题前部会使读者期待一部覆盖日本、朝鲜半岛、殖民地台湾等区域的东亚设计史，而现有七节并不承担这一范围。建议改为“**中国现代设计的形成与东亚转译（1895—1949）**”；若保留现标题，就必须实质增加东亚多地区材料。

**建议顺序**：从月份牌、书籍装帧、国货包装或课程文件进入 → 由对象中的词语和生产者引出概念前史 → 晚清实业与博览会 → 上海印刷资本和视觉公共领域 → 百货、广告与都市消费 → 教育制度与日本中介 → 民族／现代形式争论 → 战争中的生产、迁徙和传播。

**主要风险**：6.1概念前史不宜成为抽象开篇；应让术语从对象和制度文件中出现。现有内容偏上海、印刷和平面，地方工业、女性设计者、日用品和战时生产不足，不能用少数海报代替中国现代设计史。

### 第七章　重建与“优良设计”：欧美、日本的战后制度

**本章任务**：比较战后不同国家怎样借设计委员会、博物馆、学校、企业和福利政策规定“现代生活”的质量。

**应写内容**：战时技术民用转化、英国设计委员会、美国Good Design、乌尔姆、联邦德国企业设计、北欧制度、日本工业政策与质量体系。

**建议编排**：不要把七个国家／地区写成七篇短史。先建立共同比较指标——谁出资、谁制定标准、通过何种展览或奖项推广、怎样连接工业、面向哪类家庭、谁被排除——再用英国、美国、联邦德国／乌尔姆、北欧、日本回答同一组问题。国家小节可以保留，但每节都必须回到同一张比较表。

**主要风险**：把“优良设计”当成跨国同义词。相同名称背后可能是出口政策、博物馆审美、企业体系或生活教育，传播关系必须有翻译、展览、机构或人员中介。战时技术的民用转化也不能写成自然、无代价的连续过程。

### 第八章　冷战、社会主义设计、去殖民化与国家建设

**本章任务**：比较非单一市场模式中的现代生活方案，并揭示国家建设、资源条件和殖民遗产怎样影响设计制度。

**结构判断**：这是全书负荷最高、最需要重编的一章。东欧与苏联设计已经足以构成一章；印度、南亚、非洲、拉丁美洲、去殖民公共建设和国际援助又足以构成另一章。把这些内容压成七节，会在形式上“全球”，在实质上只能点名。

**首选方案**：拆成“第八章上：冷战与社会主义日常生活”和“第八章下：去殖民化、发展与国家建设”，课程上仍可作为一个单元，书稿上允许两个章节或A／B两部分。

**若必须保持十六章**：内部明确分成两幕。第一幕只写冷战展览、东欧日常生活、苏联公共系统；第二幕从一个可追踪委托—融资—建设—使用—维护的公共项目进入，再比较南亚与一个非洲或拉丁美洲案例，国际援助作为跨案例机制，不再分别概述所有地区。

**主要风险**：以“印度”“非洲”“拉丁美洲”作为同级标签，会掩盖区域内部差异；材料不足时仍追求覆盖，会制造新的中心—边缘结构。宁可深写三个可比案例，也不要用三段概览宣称覆盖三个大区。

### 第九章　消费社会、家庭、性别与企业形象

**本章任务**：解释战后设计如何同时组织家庭生活、身份选择和组织传播，并展示使用者怎样挪用、维修或拒绝设计。

**结构判断**：现有前四节是消费与日常生活史，后三节是组织化视觉传播史，两者缺少中间桥梁。瑞士平面单列一节尤其容易成为风格插章。早期单章审计中该节曾为空，当前聚合索引已补入数项V2支持，但对象档案、学校／机构材料和使用侧证据仍不足，因此结构问题并未因来源条目增加而自动解决。

**建议顺序**：从一件进入家庭的耐用消费品或一套厨房进入 → 丰裕与消费公民 → 家务劳动及效率悖论 → 性别化职业与物品 → 青年文化的使用和商业吸收 → 企业如何把多种接触点组织成一致形象 → 将瑞士网格并入企业／机构视觉系统，不再单列 → 以公共信息设计和使用者实际辨认、绕行、维修、拒绝收束。

**标题建议**：若保留企业形象，可改为“**消费生活、身份与组织化传播**”，使后半章的存在理由更清楚。

**主要风险**：家庭、亚文化、企业形象和信息设计各自都很大。必须用“设计如何组织选择、使用者如何改写组织安排”这一共同问题贯穿，否则本章会成为四个专题拼接。

### 第十章　新中国设计制度的重组（1949—1978）

**本章任务**：以制度和生产过程证明这一时期不是“职业设计空白”，而是形成了不同于市场型工业设计的计划型设计系统。

**应写内容**：院校与行业机构、任务与审批流程、轻工业日用品、公共活动与服务设施、出版与宣传生产链、工艺美术和出口、短缺条件下的材料替代、维修与专业延续。

**建议顺序**：从一件有设计任务、样品、审批、定型、生产和使用记录的日用品进入 → 机构与术语重组 → 设计劳动流程 → 两至三条轻工业生产链 → 公共建设或大型活动的组织机制 → 出版／宣传的委托到发行链 → 工艺美术与地方生产 → 短缺、维修和政治变化怎样改变专业知识。

**主要风险**：本章的核心命题很重要，但当前最缺的恰是10.2和10.3所需的设计室、轻工业部门和产品生产档案。在这些材料补足前，只能把“计划型设计系统”作为待检验的章节假设，不能先写成已经充分证明的事实。对政治图像的全面回避也会限制宣传生产史的完整性；若因出版定位不能使用，应明确这是图像选择边界，而不是历史上不重要。

### 第十一章　从反设计到后现代：意义、差异与媒介转向

**本章任务**：解释现代主义的普遍功能和专业权威为何受到质疑，以及意义、历史记忆、大众文化和低技术媒介怎样重新进入设计。

**应写内容**：城市更新后果、波普商品、意大利激进设计、建筑符号、孟菲斯、朋克自出版、后现代语言的跨区域选择。

**建议顺序**：从一个被拆除、被抗议或被重新使用的现代主义对象进入 → 社会条件与功能主义危机 → 波普和商品复制 → 激进设计对家庭／市场的讽刺 → 建筑符号与历史记忆 → 孟菲斯对象怎样进入市场 → 朋克自出版的生产和传播 → 不同地区为何只选择后现代语言的一部分。

**主要风险**：波普、激进设计、后现代建筑、孟菲斯和朋克容易再次成为风格接力。每节必须回答它挑战了哪一种制度或专业权威、通过什么媒介生产意义、又怎样被市场吸收。第9章已经处理亚文化使用，本章只处理媒介语言与意义政治。

### 第十二章　设计责任的扩展：伦理、生态、参与和包容

**本章任务**：历史化“设计责任”如何从产品性能扩展到生命周期、劳动参与、身体差异、照护、社区持续性和制度后果。

**应写内容**：职业伦理危机、帕帕奈克及其争议、生命周期、北欧参与式设计、通用设计与残障社会模型、女性主义批评、社区设计与正义。

**建议顺序**：从一项声称“为弱势群体解决问题”却产生争议的项目进入 → 市场合法性危机 → 帕帕奈克的主张与家长主义边界 → 材料生命周期把责任推向生产前后 → 工作场所参与重新分配知识 → 残障与女性主义批评改变“使用者”概念 → 社区项目中的代表权、退出和持续性。

**主要风险**：现有顺序看上去像责任意识不断进步的历史。正文应写出失败、冲突和回退，说明参与、包容和共创并不自动转移决策权。当前聚合索引已补入参与式设计和女性主义研究，但项目过程、参与者记录与制度实施P0仍需补强，不能用规范性理论代替实际过程。

### 第十三章　全球生产、品牌系统与中国设计转型（1978—2008）

**本章任务**：说明全球化怎样重新分配设计、制造、品牌、知识产权和废弃，并追踪中国设计教育、产业、职业和文化身份的重新制度化。

**应写内容**：后福特供应链、品牌体验、跨国公司与港台—内地网络、教育与学科恢复、OEM和产业集群、城市消费视觉、大型公共活动、自主品牌话语。

**建议顺序**：从一件产品的拆解、标签、零件来源和品牌归属进入 → 全球供应链如何拆分作者和价值 → 品牌怎样重新统一消费者接触 → 香港、台湾和内地的专业网络 → 1978年后教育／学科／行业制度恢复 → OEM与产业集群中的隐形设计劳动 → 城市消费和公共活动 → “从制造到创造”作为政策与企业话语接受检验。

**主要风险**：前半章是全球生产史，后半章是中国制度史，必须用“设计发生在哪里、价值由谁获得”持续连接。不能把“从制造到创造”写成必然进步线，也不能只凭企业宣传证明自主创新。教育政策、OEM流程、劳动者经验和具体产品档案是核心，而不是补充材料。

### 第十四章　交互、服务与平台：数字设计的制度化

**本章任务**：解释软件、HCI和服务设计怎样形成新的专业对象与组织流程，并交代平台化如何从界面设计扩展为持续运营的规则系统。

**时间边界建议**：本章应以20世纪中期计算研究为前史，主体放在个人计算、GUI、网络、移动和服务设计制度化，原则上收束于2008年前后。平台仅讲形成条件与早期组织逻辑；平台治理、推荐系统和生成式AI留给第16章。

**建议顺序**：从一次具体的人机操作或软件版本变化进入 → 计算工具成为软件媒介 → GUI怎样重组可见操作 → HCI与设计方法汇合 → 网络和移动改变连续连接 → 服务设计把界面接到组织后台 → 设计系统和平台实现规模化 → 以数据化商业模式作为通往第16章的边界问题。

**主要风险**：当前七节几乎是一部数字设计通史。14.4和14.6在当前聚合索引中已有若干V2入口，但多为方法手册、理论或后期实践指南，浏览器／开放标准、平台规则、版本演化和组织档案仍薄。必须选择少数版本明确的对象，不用“从大型机到手机”的产品年表代替制度化解释。软件团队、测试、版本、维护和组织决策应当与界面形式同等重要。

### 第十五章　批判、推测、转型与多元世界设计

**本章任务**：讨论设计从解决既定问题转向揭示问题、组织争议和想象未来时，谁拥有问题定义权与代表权。

**结构建议**：现有七节理论名称过密。可以重组为三次转变：第一，从产品功能到问题揭示；第二，从方案原型到未来叙事和公共争议；第三，从专家定义到共同体自主与多元世界。对推测设计的反批评不必独立成一节，可紧随推测设计案例出现，使批评成为分析的一部分而不是事后纠偏。

**建议顺序**：从一个在展览中提出未来问题的对象进入 → 批判性对象怎样制造陌生化 → 设计虚构和推测原型怎样组织未来叙事，同时检查观众和实际影响 → 对抗性设计怎样保留政治冲突 → 转型设计为何改用长期系统尺度 → 去殖民批评如何追问知识位置 → 多元世界与共同体自主，同时讨论不可代表和不可通约的边界。

**主要风险**：本章最容易写成理论术语解释。每一种“设计”都必须有项目过程、参与者、展示／传播环境、资源来源和结果材料。当前对抗性设计与多元世界两节已有若干理论性V2入口，但项目档案、共同体自述和结果材料仍弱，应在补强前降低结论强度。

### 第十六章　算法、人工智能与中国当代设计转型（2008—至今）

**本章任务**：解释算法和AI被实际部署后，设计责任如何分布到数据、模型、界面、平台规则、基础设施、组织和监管，并以中国平台化生活和设计职业为重要经验场。

**结构判断**：这是时效性最高、证据变化最快的一章。标题中的“算法、人工智能”是一条问题线，“中国当代设计转型”是另一条问题线；若只是前六节讲全球AI、第七节附加中国，就会破坏全书的双向嵌入原则。

**建议顺序**：从一个版本、部署者、任务和时间均可确认的中国或跨国平台案例进入 → 规则系统与机器学习的差别 → 数据集的分类与劳动 → 搜索／推荐怎样分配可见性 → 生成式AI怎样改变作者、版权和专业劳动 → 自动化界面中的解释、纠错、退出和申诉 → 芯片、云、能源、水与隐形劳动 → 回到中国平台和智能硬件组织，比较不同部署制度下的责任分配。

**主要风险**：不能把“至今”写成稳定完成的历史阶段。每个案例都应有材料截止日、系统版本、比较基线和部署范围；把产品演示、企业声明、模型能力测试和实际社会效果分开。第14章讲平台如何成为设计组织，第16章只讲平台和AI部署后的权力与后果。

### 结语　从正典到关系、责任与可能性

**现状判断**：总纲已有五项回收内容和结课任务，但结构化章节文件仍缺核心问题与核心论点。结语目前是价值方向，不是完成的论证设计。

**建议核心问题**：经过十六章以后，学生应当用什么单位解释设计史，又如何把这种历史知识转化为对当代设计选择与后果的判断？

**建议核心论点**：设计史的解释单位应从孤立名作扩展为对象、劳动、制度、流通、使用和环境后果之间的关系；这种扩展不是否定作品与设计者，而是重新说明其行动条件、责任边界和可替代路径。历史不能直接给出未来方案，但能揭示哪些选择曾被制度化、哪些代价被隐藏、哪些行动者被排除，以及其他路径为何可能。

**建议顺序**：回到导论开篇对象 → 对照五编中反复出现的机制，而不是逐章摘要 → 比较至少三个跨时段对象的关系变化 → 回收“事实、解释、反例和证据缺口” → 说明历史判断能为当代实践提供什么、不能提供什么 → 布置综合任务。

**主要风险**：把全书写成从“物”必然进步到“系统、责任和未来”的目的论。结语应强调不同尺度始终并存：数字平台仍依赖物质基础设施，现代产品仍需要使用和维护，经典作品也仍可研究，只是不能孤立研究。

## 七、需要优先修订的结构问题

### 优先级A：动笔前必须完成

1. 为十六章分别写出一句“本章只回答什么”和一句“本章不再回答什么”。
2. 重编第8章，决定拆章、A／B双模块或压缩地域覆盖。
3. 重编第9章，将瑞士平面并入组织化传播，建立家庭／身份与企业／公共系统之间的共同问题。
4. 明确第14章的时间截止与第16章的平台／AI责任边界。
5. 为结语补写核心问题、核心论点和回到导论对象的收束结构。
6. 决定第6章是“中国主体＋东亚中介”还是完整东亚史，并据此调整标题或材料范围。

### 优先级B：形成逐章写作包时完成

1. 每章确定一个贯穿对象、两个补充案例和一个真正限制主论点的反例。
2. 每章把七条贯穿线分为“主线两条＋辅线一至两条”，不要求全部平均出现。
3. 为每章建立相同格式的章际责任卡：前章遗留问题、本章新增尺度、本章回答、不能回答、下章转折。
4. 把国家／运动名称式小节改写为机制式标题，尤其处理第3、7、8、11、12、15章。
5. 把案例的叙事顺序写清：谁委托、谁获得资源、谁生产、怎样流通、谁使用、如何维护、产生何种后果。

### 优先级C：进入成稿前完成

1. 把V2材料进一步升级到版本、页码、图版、引注和P0核验；不以映射数量代替论点可靠性。
2. 对章节标题中承诺的地区范围进行材料审计，范围不足时缩小标题而非用概览填空。
3. 将内部证据表、去重表和审核状态保留在工作文件；正文只在论证需要时简洁交代材料限度。
4. 为本科核心阅读和硕士进阶阅读分别标注必读与扩展内容。

## 八、建议采用的逐章写作卡

在正式撰写下一章以前，每章先完成一页写作卡：

| 项目 | 必须回答的内容 |
|---|---|
| 本章唯一任务 | 本章完成后，学生能解释什么此前不能解释的问题 |
| 开篇现场 | 时间、地点、人物、对象、可观察冲突及材料来源 |
| 贯穿对象 | 对象如何在章节中至少三次返回，而不是只用于开场 |
| 核心机制 | 技术、劳动、制度、市场、国家、媒介或使用中的两至三项 |
| 主要行动者 | 不只列设计师，还列生产者、中介、使用者和维护者 |
| 支持案例 | 哪个案例承担主论点，证据能支持到什么程度 |
| 修正案例 | 哪个案例显示地区异步、实施失败或使用者改写 |
| 不写内容 | 哪些相邻议题明确交给前章、后章或栏目 |
| 学习方法 | 学生从本章获得哪一种可迁移的史学操作 |
| 章末转折 | 已回答、受限、遗留及下章换尺度的理由 |

## 九、最终判断

现有框架的最大价值，是已经找到了这本书不同于一般设计史通史的立场：它要解释人工世界的形成机制，而不是重新排列经典作品。这个方向成立。

当前最大问题也很明确：总纲对“应该看见什么”规定得很充分，对“在有限篇幅里只讲哪一条历史、怎样让学生跟得上”规定得还不够。只要先完成章节减负、任务去重、开篇对象和结语闭合，五编十六章不必推倒重来；如果跳过这一步直接依据材料库逐章扩写，最可能出现的结果是材料丰富、概念正确、证据谨慎，却仍然难以阅读和记忆。

因此，本书下一阶段不应是全面铺开十六章正文，而应先完成“章际责任表＋十六章写作卡＋第8／9／14／16章重编”。这一步完成以后，再用当前证据系统决定哪些判断可以写、哪些需要补证、哪些应降级为争议或暂不进入正文。
