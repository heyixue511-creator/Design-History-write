# NN 专项报告与实体总索引

## 第一部分：专项报告

### 一、语言

1. **语种构成**：全书正文以英语为主；欧陆作者的论文多由译者转译为英语（Juliette Nelles 译 Vitta/Branzi/Moles，L604、L664、L2168；Peter Nelles 译 Burkhardt，L843），保留欧陆理论腔；正文与脚注夹杂德语（gute Form L4812、Warenästhetik L3952、Sachlichkeit L2284、quotidienneté L2013、signaletique L2127）、法语（disegno 意大利语 L3382、design primario L297）、意大利语术语，形成多语混编的学术文体。
2. **术语策略**：关键概念常"原文（译文）"或"译文（原文）"双写（如 "gute Form," the German version of the 'good design' movement, L4811-4812）；专名一律保留原文（Bauhaus、Isotype、Memphis、Ulm）。
3. **脚注语言**：脚注系统与正文同页混排（如 L121-128、L401-414、L4500-4525），承担第二层论证（文献评注、延伸讨论），是本书论证的重要组成。

### 二、文风（按作者群体分型）

| 作者群体 | 文体特征 | 实例（行号） |
|---|---|---|
| 编者（Margolin） | 结构规整、对举句式（"一方面……另一方面"）、转述为主 | L142、L187、L241-247 |
| 理论家（Dilnot） | 长句、插入语、限定从句叠床；反问推进；脚注密集 | L4027-4053、L4107-4115 |
| 设计师（Rams、Branzi） | 格言化短句（Rams）；散文式宣言（Branzi） | L1851、L605-616 |
| 批评家（Butler、Porch） | 第一人称介入、反讽、日常经验叙事 | L1949-1957、L2830-2842 |
| 欧陆理论译文（Moles、Vitta、Selle） | 术语化抽象表达、策展式论证 | L1268、L541-543、L856-861 |
| 学院批评（Lupton、Williamson、Ashwin） | 学术史梳理、案例细读、分类学结构 | L2393-2417、L2884-2888、L3424-3429 |

### 三、修辞方式

1. **对举/二分**：现代主义 vs 后现代（L249-267）；感知 vs 阐释（L2444-2457）；点基 vs 场基网格（L2884-2888）；口述 vs 文字文化（L2659-2690）；use-value vs exchange-value（L4519-4521）；"design and society" vs "design in society"（L4127）。
2. **隐喻**：飞机坠入亚马逊（Branzi，L605-606）；"假肢上帝"（Freud，L570）；"部落手镯"（Porch，L1941）；"透镜"（Baxandall，L4266）；"物之帝国"（L3674）；"游戏规则"（Buckley，L4622-4625）；"黑色机箱"（Kinross，L2348-2350）。
3. **反问推进**：Dilnot 的"为什么要理解设计？"（L4316-4317）；Porch 的"我们真的需要秒级精度吗？"（L1931-1932）；Buchanan 的"物体是否只是其生产条件的符号？"（L1751-1753）。
4. **引文权威化**：以 Pevsner、Banham、Barthes、Clark、Baxandall、Bourdieu、Lukács 等权威引文支撑论点（L3704-3726、L4229-4253、L4262-4267、L900-919）。
5. **元评论**：Margolin 自陈不用"现代主义"而用"现代主义者"（L250-253）；Margolin 自陈文献地图"非常初步"（L4726）；Dilnot 自陈"不确定单一'设计史'是否存在"（L4041）。

### 四、史料使用方式

1. **直接物证**：产品（Krups、Braun、Memphis）、时刻表、海报、手稿（《特雷斯贝勒时祷书》）、网格作品（Mondrian、Rietveld、Tschichold）、Isotype 图表。
2. **档案文献**：Monotype 记录（L2198）、Isotype 档案（L2377-2378）、OTA 报告（L1057-1059）、美国统计局数据（L1062-1063）。
3. **二手文献**：以 Design Issues 前六期为核心的自引网络（L29-71）；Block、Ulm、Casabella、Design Studies 等期刊；各国专著书目（Margolin 结语）。
4. **口述与教学实验**：NSCAD 学生海报实验（L3345-3352）；Csikszentmihalyi & Rochberg-Halton 的 300 人访谈（L223-225）；Luria 的乌兹别克农民访谈（L2726-2731）。

### 五、阐述方法

1. **案例-理论互证**（Buchanan、Kinross、Ehses）；
2. **观念史/谱系学**（Williamson 的网格、Lupton 的实证主义、Dilnot 的设计史三阶段）；
3. **诊断-处方**（Dilnot II：四个问题→可能性）；
4. **文献地图/目录学**（Margolin 结语）；
5. **立场声明**（Buckley 的女性主义、Selle 的民粹主义）；
6. **对比论证**（瑞士 vs 德国排印、Braun vs Memphis、英美 vs 欧陆设计史）。

### 六、推演逻辑

- **全书总逻辑**：设计重要（L72-73）→ 概念化薄弱（L187）→ 现代主义范式失效（L260-266）→ 意义生成需要新理论（L377-378）→ 历史书写需要新方法（L245-246）→ 设计研究作为新学科承载这一切（L98、L535-536）。
- **分章逻辑**：第一部分=设计的处境（后现代）；第二部分=设计的意义（阐释）；第三部分=设计的过去（历史）；三者互为条件（L241-247）。

### 七、文字风格总体评价

全书是 1980 年代"批判转向"设计理论的标本：一方面保留现代主义设计论述的宣言性（Rams），另一方面全面引入人文社会科学话语（符号学、修辞学、女性主义、文化研究），学术化程度高；缺点是部分译文与理论文章行文晦涩（Margolin 在导读中也委婉承认 Baudrillard"术语堆砌" L3965；Moles 的自造词 actomes/proxemes 等）。
