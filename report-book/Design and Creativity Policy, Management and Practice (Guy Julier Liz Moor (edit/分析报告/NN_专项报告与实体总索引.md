# NN 专项报告与实体总索引

## 一、专项报告：全书方法论总评

### 1.1 研究设计评估

本书采用**多案例比较研究**设计，覆盖英国、加拿大、美国、德国、芬兰、新西兰六个国家，涵盖十个设计子领域：

| 子领域 | 对应章节 | 国家/地区 |
|--------|---------|----------|
| 传播设计(governmental campaigns) | Ch1 | 英国 |
| 城市设计 | Ch2, Ch12 | 英国、新西兰 |
| 地方政策咨询 | Ch3 | 英国 |
| 公共艺术 | Ch4 | 英国 |
| 博物馆策展 | Ch5 | 英国 |
| 平面设计 | Ch6 | 加拿大 |
| 广告/传播设计 | Ch7, Ch13 | 英国 |
| 产品设计研究 | Ch8, Ch14, Ch15 | 美国、英国 |
| 服务设计 | Ch9, Ch16 | 英国 |
| 电影制作 | Ch10 | 美国(好莱坞) |
| 编辑设计 | Ch11 | 德国 |
| 展览设计 | Ch18 | 英国 |
| 多学科设计 | Ch17 | 芬兰 |

**方法三角验证**：
- 半结构化访谈：至少30+受访者(包括6位加拿大的平面设计师+6位自由职业者、8位产品设计研究者、8位城市设计师/规划师)
- 参与式观察：Dorland(多伦多工作室)、Hill(Erskine Corporation)、Waisberg(产品设计研究行业)、Owens(德国出版业)
- 政策文本分析：英国政府白皮书、BDI统计、Design Council报告、CABE指南、Big Lottery Fund文件
- 档案研究：Hollywood RKO制片厂的1936年预算账目(Sutton)、V&A博物馆Funding Agreement(Pavitt)

### 1.2 理论贡献评述

**主要贡献**：
1. **为设计管理研究引入批判视角**：挑战设计管理文献中盛行的"最佳实践"规范化取向。
2. **"审计文化"理论在设计领域的创新应用**：将Power/Strathern的审计社会理论与设计实践研究嫁接。
3. **"脚本化即兴"(scripted improvisation)概念的提出**：超越惯性(vs)创新的二元对立。
4. **"STS转向"** 在设计研究中的推动：物件能动性、实践理论、ANT的引入。

**局限性**：
1. **地理覆盖偏重于"全球北方"**：缺乏非西方设计实践的深入考察。
2. **政策焦点集中于英国新工党时代**：对保守党传统或其他政治体制中设计政策的比较有限。
3. **设计学科覆盖不全面**：建筑、时装设计、交互设计、游戏设计等重要领域未涉及。
4. **经验材料的样本代表性**：加拿大部分仅有12位受访者，德国编辑设计部分数据量有限。
5. **对"反例"处理不足**：Higgins(Ch18)和Törmikoski(Ch17)等反形式主义案例未在结论中被充分展开。

  ├→ 设计导向更新(Design-led Regeneration)
  ├→ 编码化(Codification)
  ├→ 城市品牌化(City Boosterism)

  ├→ 出版系统(Publishing Systems)
  └→ 预视化(Previsualization)
