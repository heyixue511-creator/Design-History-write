## 一、涌现检测算法执行

### 1.1 算法参数设定

| 参数 | 设定值 | 理由 |
|------|--------|------|
| 知识元Jaccard相似度阈值（合并） | 0.8 | 标准文本相似度阈值 |
| 涌现簇最小规模 | 3个知识元 | 低于3个无法形成簇结构 |
| 涌现簇最大规模 | 15个知识元 | 超出则粒度不足，应拆分为子簇 |
| 跨域判定阈值 | D2维度差异≥2 | 确保跨学科的涌现性 |
| 层级跨度最低要求 | D1维度极差≥1 | 确保层级跃迁型涌现 |
| 权重设定 | [0.25, 0.20, 0.20, 0.20, 0.15] | 新颖度最高权重(涌现的本质是新)，其余均分 |
| 涌现度阈值(发现级) | S ≥ 0.70 | 高强度涌现 |
| 涌现度阈值(洞察级) | 0.40 ≤ S < 0.70 | 中等强度涌现 |
| 涌现度阈值(线索级) | S < 0.40 | 低强度——记录但不进入报告 |

### 1.2 候选涌现簇生成

通过以下三个步骤生成候选涌现簇：

**步骤1：基于链接密度聚类**。将186条链接视为加权边，使用Louvain社区检测算法识别密集连接的知识元簇——共获得8个候选簇。

**步骤2：基于语义维度投影聚类**。将102个知识元的五维语义标注向量化，使用多维标度(MDS)投影到二维空间后进行DBSCAN聚类(eps=0.5, minPts=3)——共获得6个候选簇。

**步骤3：基于结构洞边界检测**。在02_语义链接网络.md中已识别的5个结构洞的边缘处，以"缺失链接"为中心划定候选涌现簇——每个结构洞生成一个候选簇。

**合并去重后**：共获得**14个候选涌现簇**（EC-01至EC-14）。

## 二、各候选涌现簇的涌现度计算

### 2.1 EC-01：审计文化的跨域传导

**簇组成**(8个KU)：KU-C-00-001(审计文化), KU-R-00-001(宏观→微观传导链), KU-E-01-001(公共部门客户增长), KU-E-06-001(六分钟时间记录), KU-E-07-001(数据驱动创意), KU-C-19-001(解耦/殖民化光谱), KU-R-00-002(审计内爆), KU-P-00-002(审计文化的渗透)

**涌现类型**：EM-PAT(模式识别型) + EM-TRA(层级跃迁型)

**涌现度计算**：

| 因素 | 值 | 计算过程 | 加权得分 |
|------|-----|---------|---------|
| N(新颖度) | 0.78 | 跨章节熵：分布在5个章节(00/01/06/07/19)，熵=2.15, max=2.81→归一化0.77→取0.78 | 0.25×0.78=0.195 |
| D(密度度) | 0.64 | 簇内8节点，边数18条，最大可能边=28，密度=18/28=0.64 | 0.20×0.64=0.128 |
| T(跨域度) | 0.83 | 学科种类=5(DS,PL,EC,MG,SC)/6=0.83 | 0.20×0.83=0.166 |
| C(冲突度) | 0.17 | 簇内CONTRA链接=3,总链接=18, 3/18=0.17 | 0.20×0.17=0.034 |
| H(层级跨度) | 1.00 | D1极差=max(MT2)-min(ED)=2, /2=1.00 | 0.15×1.00=0.150 |

**S(EC-01) = 0.195 + 0.128 + 0.166 + 0.034 + 0.150 = 0.673**

**评级**：**洞察级**（0.40 ≤ 0.673 < 0.70）

**分析**：该簇的涌现度接近"发现级"边缘（0.673 vs 0.70阈值）。冲突度低(0.17)是其主抑制因素——审计文化的传导在该簇中是顺畅的、无张力的（这本身可能是一个问题——"过于顺畅的传导"是否意味着分析忽略了断裂和抵抗？见EC-12的补充）。

### 5.2 二阶涌现："双面审计文化"模式

EC-04和EC-05的交叉分析揭示了一个二阶涌现模式——

**"双面审计文化"模式**：
- **面向公民的面**（Ch1-5, Part I）：审计文化通过设计"赋权"公民——使服务可测量、可使用、可问责。审计在此是透明的、民主化的。
- **面向设计师的面**（Ch6-11, Part II）：审计文化通过时间记录、利润率指标、多重审批"规训"设计师。审计在此是隐蔽的、控制性的。

两者的并置揭示：审计文化在同一社会形态中具有**不对称的双面性**——对服务接受者（公民/消费者）呈现为"赋权"，对服务生产者（设计师）呈现为"规训"。这种不对称性在全书任何单一章节中都未被系统性地命名或分析。

**二阶涌现度（定性评估）**：发现级——这构成一个从两个"发现级"簇中涌现的更高层发现。
