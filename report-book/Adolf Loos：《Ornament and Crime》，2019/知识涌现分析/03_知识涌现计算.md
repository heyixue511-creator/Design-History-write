# 03 知识涌现计算

## 概述

本文档基于00_方法与规则.md定义的六项涌现指标，对路斯《装饰与罪恶》知识元网络进行系统计算，包括：11个L3主题群的聚类系数与内聚度、全局S指数评分、14个涌现命题的S值判定，以及层级图谱深度L的计算。

## 一、网络密度D的计算

### 1.1 全网络密度

**计算基础**：
- N = 101（扣除52个载荷1节点，仅考虑载荷2+载荷3节点）
- E ≈ 485（标注链接数）

**公式**：`D = 2E / [N(N-1)] = 2 × 485 / [101 × 100] = 970 / 10100 = 0.096`

### 1.2 核心子网络密度

**计算基础**：
- N_core = 8（核心节点）
- E_core = 20（核心节点之间的链接数）

**公式**：`D_core = 2 × 20 / [8 × 7] = 40 / 56 = 0.714`

## 六、层级图谱深度L的计算

### 6.1 各层级知识元数量

| 层级 | 描述 | 单元数 |
|------|------|--------|
| L1 | 原文文本（24篇章） | 24 |
| L2 | 章节概要层（论点单元） | 约95 |
| L3 | 跨篇章主题层（主题+子论点） | 约60 |
| L4 | 思想谱系层（学术来源+后继） | 19 |
| L5 | 历史语境层（语境要素） | 约15 |
| L6 | 层间涌现层（涌现命题） | 14 |

### 6.2 L值计算

**公式**：`L = (N_L1 / N_L6) × (1 - σ_layer / μ_layer)`

- N_L1 = 24, N_L6 = 14
- 各层级单元数: [24, 95, 60, 19, 15, 14]
- μ_layer = (24+95+60+19+15+14)/6 = 227/6 ≈ 37.83
- σ_layer的标准差计算：
  - 偏差: [-13.83, 57.17, 22.17, -18.83, -22.83, -23.83]
  - 平方: [191.3, 3267.9, 491.4, 354.7, 521.3, 567.9]
  - 均值: 5394.5/6 ≈ 899.1
  - σ_layer = √899.1 ≈ 29.99

`L = (24/14) × (1 - 29.99/37.83) = 1.714 × 0.207 = 0.355`

### 6.3 L值偏低的原因与解释

L = 0.355 远低于 > 3.0 的"健康抽象阶梯"阈值。原因：

1. **L2层的膨胀**：95个L2单元对24个L1单元，平均每篇章产生约4个L2单元——这是学术分析的特征（细粒度提取），而非知识压缩。
2. **L3-L6的四层压缩比不理想**：从L2(95) → L3(60) → L4(19) → L5(15) → L6(14)，虽然每层都在减少，但L5→L6的减少幅度（15→14）几乎为零——这反映了L5历史语境层与L6涌现层之间的信息压缩不足。
3. **L1→L6的总压缩比仅1.7:1**——理想的涌现性分析应有10:1以上的压缩比。这表明本次分析的涌现命题（14个）相对原始篇章数（24个）来说提炼度不够——部分命题仍可以进一步抽象合并。

**溢出解释**：L值的偏低不否定涌现命题的有效性（S值验证了这一点），但它提示了分析深度的方向——L6命题可以进一步合并为更抽象的"元涌现命题"，将L1→L6的压缩比提升至5:1以上。
