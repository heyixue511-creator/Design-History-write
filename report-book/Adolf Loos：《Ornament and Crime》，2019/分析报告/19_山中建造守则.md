# 19 山中建造守则（1913）

## L1 章节概览

《山中建造守则》（Rules for Those Building in the Mountains）是路斯全集中最短、最精炼的篇章，只有寥寥数段。但它也是最富有诗意的篇章之一。文章以一系列命令式的规则（"不要……"、"要……"）构成了一套关于乡土建筑、自然与人工的伦理契约。其核心理念可以概括为："真——自然只承受真"（Be truthful! Nature can only bear truth.）。此文不仅是路斯建筑哲学的浓缩，也是现代主义与乡土传统对话的经典文本。

## L2 核心论点与主题

### 不要建造如画的

首条规则："不要建造如画的（picturesquely）。把这种效果留给悬崖、山脉和太阳。一个穿得如画的人不是如画的——而是一个小丑。农民不穿得如画。但他是（如画的）。"这段话包含了路斯思想中关于"真实性"的核心悖论："如画"（das Malerische——19世纪美学中的核心范畴）不是通过刻意的布置获得的，而是生活方式的自然副产品。农民的"如画"来自于他不意识到自己是如画的——一旦他意识到，变成表演，就失去了如画性。

### 与农民说话用你的语言

路斯警告不要以居高临下的"亲切"来对待农民："与农民说话用你的语言。那个用土话与农民交谈的维也纳律师必须被根除。"这一规则反对的是将农民客体化为"风景中的配饰"（accessories in the landscape）的文化精英主义。

### 向农民的形式学习，但理解背后的原因

路斯既不是对乡土建筑的无批判浪漫化，也不是对现代技术的无条件崇拜："注意农民建造的形式。因为它们是祖先智慧的凝聚——凝固的物质。但寻找形式背后的原因。如果技术进步使得改进形式成为可能，那么这种改进应该始终被使用。连枷被脱粒机取代。"这一辩证立场——尊重传统但拥抱改进——是路斯思想中少有的平衡表述。

### 最平坦的屋顶

路斯对屋顶的建议——"在山上建造尽可能平坦的屋顶"——似乎反直觉（在雪多的山上不应该用陡坡屋顶吗？），但他的解释揭示了功能主义的深层逻辑："在山上，雪不能想滑下来就滑下来，而是当农民想让它滑下来的时候才滑下来。所以他必须能在不危及生命的情况下爬上屋顶去清除雪。用我们的技术经验，我们也必须建造尽可能平坦的屋顶。"

### 真——自然只承受真

路斯的最后规则："要真实！自然只承受真。它可以轻易应付铁桁架桥，但它憎恶带有桥塔和射击孔的哥特式拱门。"一百年前的真实比我们旁边的假话更贴近我们。这段话是路斯伦理哲学的最精炼表述——真实性不是审美偏好，而是存在论条件。

## L3 文本结构与写作手法

文章采用一种近乎圣经文体的命令式语言——"不要……"、"要……"——赋予文本以道德律令般的权威感。句子的节奏短促有力，每一句都是一个可独立引用的格言。这种极简的表达方式本身就是路斯装饰批判的形式化体现——每一个多余的词都被削减了。

## L4 关键实体与概念解析

| 实体/概念 | 说明 |
|-----------|------|
| 如画（picturesquely / malerisch） | 19世纪美学核心范畴——路斯认为在山上刻意建造"如画的"建筑是荒谬的 |
| 农民的形式 | "祖先智慧的凝聚，凝固的物质"——路斯对乡土建筑的价值认定 |
| 脱粒机（threshing machine） | 技术进步的例子——连枷被机器取代是正确的 |
| 哈布斯堡瞭望塔（Habsburgwarte） | 干扰维也纳森林天际线的建筑——路斯的反面例证 |
| 骠骑兵庙（Hussars' Temple） | 与哈布斯堡瞭望塔对比——"和谐地融入" |
| 哥特式拱门 + 射击孔 | 路斯认为"自然憎恶"的仿古建筑装饰 |
| 铁桁架桥（iron lattice bridges） | 现代工程——"自然可以轻易应付" |
| 最平坦的屋顶 | 农民的逻辑——控制雪的滑落时间，而非让雪随时滑落 |
| 水平vs.垂直 | "平原要求垂直建造；山区要求水平建造" |
| 人的作品不能与神的作品竞争 | 路斯罕见的准宗教表述 |

## L5 历史语境与时代背景

1913年，阿尔卑斯山区的旅游和度假文化正处于爆发性增长期。"避暑"（Sommerfrische）已经成为中产阶级的固定生活方式。山区出现了大量为游客建造的"如画"别墅——仿古农舍、仿城堡旅馆——这些正是路斯所攻击的对象。同时，"乡土建筑保护"（Heimatschutz）运动在德语世界方兴未艾——这一运动试图通过法律手段保护传统建筑形态。路斯的立场处在两者之间：他反对人工"如画"的旅游建筑，也反对将农民冻结在"传统"中以供观赏。

## L6 思想谱系与理论关联

**与海德格尔的平行**：路斯的"筑造"（Bauen）伦理——"在山上建造尽可能平坦的屋顶……那是农民的想法"——与马丁·海德格尔在《筑·居·思》（1951）中对黑森林农舍的分析有惊人的相似性。两者都强调："建造"是对特定场所的响应，不是抽象形式的强加。

**与拉斯金的"真实之灯"**：路斯的"真——自然只承受真"与John Ruskin在《建筑的七盏灯》中的"真实之灯"有家族相似性。但路斯的"真"指向的是构造的真实性和材料的真实性，而非拉斯金式的道德真实。

**与赖特的有机建筑**：弗兰克·劳埃德·赖特在同一时期发展的"有机建筑"——建筑应当从场地中生长出来——与路斯的山中建造哲学有共鸣。

## L7 影响与当代意义

路斯的山中建造守则在当代环境建筑学中具有先见之明。当代"绿色建筑"中关于场地响应、材料地方性、最小化环境干预的原则，都可以在这些1913年的"守则"中找到先声。路斯关于"技术进步可以改进传统形式"的辩证法——既不无条件地浪漫化传统，也不无条件地崇拜现代性——为当代乡土建筑实践提供了一个仍然有效的理论框架。

## L8 批判性评述

**优势**：此文的精炼和诗意是路斯全部著作中独一无二的。每一条规则都是一个可以独立传播的思想原子。对"如画性"的批判——将人客体化为风景中的装饰——具有深刻的伦理力量。

**局限**：(1) 规则的形式（命令式）掩盖了具体情境中的复杂性——在特定地形中，"如画的"建筑可能是对场所更恰当的回应；(2) "人的作品不能与神的作品竞争"这一表述暗示了路斯在此文中使用了一种在其他地方不常见的准宗教语调，其理论位置需要更仔细的辨析；(3) "最平坦的屋顶"的建议对特定气候条件（如极端降雪）可能不适用。
