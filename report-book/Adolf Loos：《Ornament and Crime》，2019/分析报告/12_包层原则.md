# 12 包层原则（1898）

## L1 章节概览

《包层原则》（The Principle of Cladding）是路斯理论体系中最重要的篇章之一，它在路斯全部著作中的地位仅次于"装饰与罪恶"。这篇文章系统地阐述了一套关于建筑材料使用的伦理学——包层原则（Bekleidungsprinzip），其核心律令是："必须排除包层材料与被包层材料之间的混淆可能。"（The possibility of confusing the cladded material and the cladding shall be ruled out in every case.）此文将材料真实性从审美偏好提升为道德律令。

## L2 核心论点与主题

### 建筑起源于包层

路斯以一个类似卢梭"自然状态"的猜想开篇："最初是包层。人类寻求躲避恶劣天气的庇护，寻求睡眠时的庇护和温暖。他寻求覆盖自己。天花板是最古老的建筑细部。"包层（覆盖）先于结构（支撑）。"人类学会建造的顺序"是：首先是覆盖（兽皮或织物），然后才需要支撑结构（墙壁和屋顶），最后发展出空间的概念。

路斯以此区分两种建筑师：(1) "艺术家建筑师"——首先感受空间效果，然后用心灵之眼看到他想创造的空间，最后设计结构来支撑包层；(2) "经验主义的建筑师"——"他们的想象力创造的不是空间而是墙断面。墙断面留下的空隙是空间。然后，被认为适合这些空间的包层类型再被加上去。"

### 包层律令

路斯以法律式的语言宣布："包层原则的法律如下：必须排除包层材料与被包层材料之间的混淆可能。"具体应用包括：

- 木头可以涂任何颜色——除了木色（因为这会使真木头看起来像涂成木色的假木头）
- 灰泥可以有任何装饰——除了裸砖图案（因为这是用灰泥仿造砖）
- 铁可以涂焦油、油漆或电镀——但不能刷成青铜色（金属涂层=仿造金属）
- 壁纸不应模仿大理石、织物或木材
- 预制混凝土不应被用来仿造石材

### 火车车厢的例证

路斯以维也纳的电车为例作出一个惊人的断言：他宁愿看到电车车厢（特别是电车的）涂成纯色，而不是按照展览委员会的"美感原则"被涂成"像桃花心木"。电车的绿色一等座和二等座唤起了比棕色（木质色）的三等座更优雅的感觉——这证明了"优雅的感觉在民族中沉睡，尽管被埋葬和隐藏。"他为此设计了一个社会心理学实验：让人们在不被提示的情况下猜测一栋建筑中哪一侧住着"Blunzengruber先生"（一个土气名字）和哪一侧住着"列支敦士登亲王"——结果一致：木纹涂装的一侧被认为是Blunzengruber的。

### 维也纳的仿造大本营

路斯对维也纳的仿造文化发动了全面攻击：展览委员会决定将老木头涂成"像桃花心木"；在环形大道建筑中，预制混凝土被用来仿造石墙；厨房墙纸模仿石砌块。甚至出现了一栋建筑"其灰泥墙被涂成红色，上面画了白色接缝"——用路斯的原则来衡量，这是终极罪恶。

### 对Semper的致敬

路斯明确地将包层原则归源于Gottfried Semper："包层原则，首先由Semper宣示，也延伸到自然。人披着皮肤，树披着树皮。"但他补充说，包层原则需要被制定为"法律"——因为当偷窃不存在时，没有制定法律禁止偷窃的必要。而仿造已经变得如此普遍，以至于必须明文宣布其非法。

## L3 文本结构与写作手法

文章结构：哲学前提（包层先于结构）→ 原则宣布 → 具体应用举例 → 维也纳案例分析 → 理论归属（Semper）。路斯的写作在此文中达到了高度的系统性和理论性，与Feuilleton（新闻体批评）的松散结构形成了鲜明对比。法律语言的运用（"此条款应理解为……"）赋予论证以权威性。

## L4 关键实体与概念解析

| 实体/概念 | 说明 |
|-----------|------|
| 包层原则（Bekleidungsprinzip） | 路斯的核心理论——覆盖先于结构，覆盖不能仿造被覆盖者 |
| Bekleidung | 德语词，意为"覆盖/包层"，与"衣服"同源 |
| Gottfried Semper | 19世纪德国建筑理论家，包层理论的创始人 |
| Decke | 德语中"天花板"和"毯子"同源——路斯用以论证包层的原始性 |
| 木纹涂装（wood-graining） | 用油漆在软木上仿造硬木纹理——路斯最厌恶的仿造行为 |
| chamotte（耐火黏土）和人造石板 | 19世纪新材料——被用来仿造露台灰泥和波斯地毯 |
| 青铜漆（bronze paint） | 仿造青铜的表面处理——路斯的原则：铁不能以任何金属漆来掩盖 |
| veneer（贴面） | 路斯接受的包层形式——因为贴面与基底"属于同一色族" |
| 彩色涂漆的英国家具 | 来自英国的"诚实"家具——涂成纯色（红、蓝、白、绿），不试图伪装成硬木 |
| 中世纪红、文艺复兴蓝、巴洛克白/绿 | 路斯列出的各时期木材涂色的颜色体系 |

## L5 历史语境与时代背景

19世纪下半叶，随着工业化和城市化，仿造材料成为大众市场的主流。从"仿大理石"的壁纸到"仿木"的门窗，仿造技术以前所未有的规模满足了新兴中产阶级对"贵族品味"的渴望。路斯对仿造的攻击不仅是对审美品味的批判，也是对这一大规模社会经济现象的抵制。

## L6 思想谱系与理论关联

**Semper的面饰理论**：Gottfried Semper在《风格》中提出"面饰原则"（Prinzip der Bekleidung）——建筑的本质在于其表皮，而非其结构。路斯继承了这一观点，但将其从描述性的艺术史理论转换为规范性的道德律令。Semper会说"建筑起源于编织和织物"（描述），路斯会说"壁纸不能假装不是壁纸"（规范）。

**与阿奎那和奥古斯丁**：Masheck在后记中指出，路斯对"多余装饰"的批判与奥古斯丁在《忏悔录》第十卷中对"眼目的贪欲"的批判有深处的基督教神学根源。奥古斯丁写道："为了引诱眼睛，人们在服装、鞋子、器皿和各种工艺制品种类中制作了无数附加物。"这一从早期基督教到现代建筑的"简洁"神学谱系，在Masheck的分析中得到了详细的追溯。

## L7 影响与当代意义

包层原则是20世纪现代建筑中"材料诚实"教条的奠基性文本。从密斯·凡·德·罗的"上帝在细节中"到路易·康的"问砖想成为什么"，现代主义建筑的材料伦理都可以追溯到路斯的包层原则。

在当代，"包层"问题以新的方式出现：GRC（玻璃纤维增强混凝土）板材如何接缝、金属板如何固定、绿色立面上的植物如何管理——这些都可以被理解为路斯包层原则的当代应用。同时，数字制造技术（3D打印、CNC切割）使得材料可以以前所未有的精度模拟其他材料——这使得路斯的律令比以往任何时候都更加相关。

## L8 批判性评述

**优势**：包层原则是路斯最系统化的理论建构，它在描述精确性和规范力度之间取得了罕见的平衡。将Semper的艺术史理论转化为道德实践准则，这一原创性的结合赋予了路斯思想持久的批判力量。

**局限**：(1) "包层材料不能被混淆为被包层材料"的原则在实践中可能过于绝对——建筑史上，许多伟大的建筑（如古罗马的大理石贴面砖墙）正是通过"用更高贵材料覆盖更普通结构"来达到其效果的；(2) 路斯未充分讨论"honest deception"（诚实欺骗）的可能性——如舞台布景、节日装饰等明确知道是暂时的、非欺骗性的仿造；(3) 包层原则以视觉为主导——触觉感知（材料的温度、质地）在路斯的讨论中被忽略了。
