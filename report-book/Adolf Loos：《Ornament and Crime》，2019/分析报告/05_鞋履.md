# 05 鞋履（1898）

## L1 章节概览

《鞋履》（Footwear）是路斯以鞋为切入点探讨人体、文明与技术互构关系的杰出篇章。文章以拉丁格言"Tempora mutantur, nos et mutamur in illis"（时代变迁，我们亦随之而变）开篇，通过一个表面上微小的话题——鞋的式样变迁——展开了跨越中世纪骑士制度、近代宫廷文明、现代体育运动的文化史叙事。路斯论证的核心命题是：鞋的形态反映并塑造了人类在不同文明阶段的运动方式和身体实践。

## L2 核心论点与主题

### 鞋与社会阶层的对应

路斯提出了一个历史形态学模型：鞋的标准鞋型由社会主导阶层的脚型决定。中世纪骑士（以骑马为主）脚小 → 尖头窄鞋流行；城市市民（以步行为主）脚大 → 宽鞋流行；近代宫廷（乘轿为主）脚小 → 高跟鞋流行；现代自由人（骑马）脚小 → 英式马靴成为正装；即将到来的世纪（徒步+自行车） → 系带鞋将主导。这一模型将鞋的形态与社会权力结构直接联系起来，隐含了身体技术（Marcel Mauss意义上的）与社会阶层的关系分析。

### 步行速度与文明程度

路斯提出步行速度是文明的量度："文明更发达的民族走路更快——美国人比意大利人快。"他以军事操典为例：腓特烈大帝的军队每分钟70步，现代军队每分钟120步。"在纽约你总有一种感觉，好像某处发生了事故。"这种将速度与文明挂钩的观点在1909年Filippo Tommaso Marinetti的《未来主义宣言》发表前十年就已被路斯提出。

### 大脚趾的进化

路斯从步行速度推导出一个解剖学命题：快速步行强化了大脚趾（在蹬地时的推力作用），导致脚变长变窄。"靠自己的力量前进是下一个世纪的标语。"马是"从轿子到自我之间的过渡"。这一论述将19世纪定位为"马的时代"（the century of the horse）——"马厩的气味是我们最优雅的香水"——而20世纪将是"步行者的时代"。

### 系带鞋的未来

路斯预测系带鞋（lace-up shoes）将统治下一个世纪，正如马靴统治了19世纪。同时对踝靴（ankle-boots）做了毁灭性的审美攻击——"踝靴死了（ankle boots are dead），就像白天的燕尾服一样死了"。短裤的流行（露出脚踝）使得踝靴的丑陋再也无法被裤脚遮掩。

### 脚的美学转型

路斯引用一段来自美国的描述，其中称一位男性有"一对令人反胃的小脚"（revoltingly small feet），并以此宣告一种新的身体美学的到来：大脚不再是粗俗的标记，小脚在男性身上反而变得可笑。这一转型与体育运动文化的兴起直接相关。

## L3 文本结构与写作手法

文章采用"格言导入→历史综述→当代诊断→未来预测→行业点评"的结构。路斯以拉丁语引语强化了古典修辞的权威感。历史综述部分跨越中世纪到19世纪，使用了丰富的历史细节（腓特烈大帝、Alma-Tadema的希腊人蹲姿图、Rigo的"反胃小脚"）来增强论证的说服力。文章的节奏感极强——从缓慢的历史描述逐渐加速到现代步伐的急促节奏，最后以"Tempora mutantur..."的反复呼应收束。

## L4 关键实体与概念解析

| 实体/概念 | 说明 |
|-----------|------|
| 系带鞋（lace-up shoes） | 路斯预测的下一个世纪的标准鞋型 |
| 踝靴（ankle-boots） | 路斯认为已经死亡的一个过渡形式 |
| 骑士制度 | 中世纪主导阶层，以骑马为主要移动方式 |
| 徒步运动（pedestrianism） | 路斯视为下一个世纪的主导身体实践 |
| 苏格兰高地人 / 阿尔卑斯山民 | 路斯眼中的新型身体典范 |
| 自行车（bicycle） | "平原上的登山者"，统一了登山和日常出行 |
| Lederhosen / kilt | 皮短裤和苏格兰裙——"本质上是同一件东西" |
| 马靴（riding boot） | 19世纪文明的标准正装鞋 |
| 漆皮舞鞋（pumps） | 路斯认为唯一可接受的舞鞋 |
| 系扣鞋（buttoned shoe） | "什么都不做的鞋"，仅限漆皮款在礼服场合穿着 |

## L5 历史语境与时代背景

1898年是自行车热潮的高峰期。自行车在1880年代发明后迅速成为大众交通工具，并引发了深刻的服装变革——女性骑自行车导致了"理性着装"运动（Rational Dress Movement）和灯笼裤的普及。路斯对自行车文化的观察与这一时代背景完全吻合。

同时，登山运动在中欧正在经历从精英活动到大众体育的转型。奥地利阿尔卑斯俱乐部（1862年成立）和德国阿尔卑斯协会的发展，以及"避暑"（Sommerfrische）作为一种中产阶级生活方式的出现，都构成了路斯论述的身体文化背景。

## L6 思想谱系与理论关联

**Marcel Mauss**：虽然Mauss的"身体技术"（techniques du corps）概念要到1934年才明确提出，但路斯此文的论证框架已经包含了身体是社会建构的、不同文化产生不同的身体习惯这一核心洞见。

**未来主义的先行**：路斯对"速度"和"大脚趾"的赞美在某些方面预演了Marinetti的《未来主义宣言》（1909），但路斯的立场更接近一种文化人类学的观察而非未来主义式的暴力颠覆。

**尼采的影响**：路斯对"靠自己的力量前进"的强调——"从轿子到马再到自我"——暗含了尼采式的"自我超越"（self-overcoming）主题。

## L7 影响与当代意义

路斯关于鞋与脚的关系的分析在当代运动鞋文化中具有惊人的预见性。当代运动鞋的设计——从跑鞋的足弓支撑到篮球鞋的脚踝保护——正是路斯所说的"专业化休息"和"专业化运动"的当代体现。他对"脚型随文明变迁"的洞察，在人类学对足部变形（如中国缠足、日本木屐步态）的研究中得到了证实。

## L8 批判性评述

**优势**：此文的跨学科性（从解剖学到历史学到社会学）令人印象深刻。路斯在1898年就已经具备了将鞋视为"文明分析器"的眼光——这在物质文化研究成为独立学科之前是非常超前的。

**局限**：(1) 线性进化叙事过于简化——"从马靴到系带鞋"的一元叙事忽视了历史上多样化的鞋型共存；(2) "美国人比意大利人快"的文化分级反映了当时的文明等级观念；(3) 对"脚小"在女性美中的地位的讨论不足——路斯集中讨论男性，对女性鞋的讨论一带而过。

## L9 扩展思考与延伸阅读

- 鞋的社会史：从古代到现代的功能、符号与身份
- "身体技术"视角下的运动鞋文化研究
- 自行车对19世纪末服装改革的影响
- 延伸阅读：Marcel Mauss, "Techniques of the Body" (1934); Peter McNeil and Giorgio Riello, *Shoes: A History from Sandals to Sneakers* (2006)
