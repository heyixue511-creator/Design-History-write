# 00_方法与规则

## 一、知识涌现分析的总则

### L### 分析定位

知识涌现分析是对已有分析报告（"分析报告"系列，共16章分析+专项报告+实体总索引）进行二次元分析（meta-analysis）。其核心假设是：当知识元（knowledge elements）被系统性地提取、语义标注、链接成网络并加以计算处理后，将涌现出超出单一分析报告所能揭示的新知——包括跨章节的深层模式、隐含的理论结构、未言明的论证预设、以及知识体系中的结构洞和矛盾张力。

### L### 分析对象

本分析的对象为"F:/Design-history-知识元/report/DILLON, ANDREW. Beyond Usability Process, Outcome and Affect in Human Computer Interaction/分析报告/"目录下的全部17个分析报告文件，涵盖：

| 编号 | 文件 | 分析层级 |
|------|------|----------|
| 00 | 00_整体分析报告.md | 全文级（整理论文的结构、逻辑、方法） |
| 01 | 01_前置信息与摘要.md | 入口级（元数据+摘要） |
| 02-14 | 02~14各章分析.md | 章级（逐章九节框架分析） |
| NN | NN_专项报告与实体总索引.md | 跨章级（三项专项报告+六类实体汇总+跨章主题索引） |

### L### 分析目标

1. 从分析报告中系统性提取可独立成义的知识元（语义上自足的最小知识单元）。
2. 对知识元进行多维度语意标注（类型、层级、确定性、新颖性、冲突性）。
3. 构建知识元之间的语义链接网络（因果、对位、支撑、矛盾、层级、时序）。
4. 对语义网络进行涌现计算（中心度、聚类系数、结构洞、模体检测、主题演化）。
5. 生成知识发现报告——报告在单章分析中不可见但在跨章网络中涌现的新知。

## 二、知识元的定义与提取规则

### L### 知识元定义

知识元（Knowledge Element, KE）是语义上自足、认知上独立的最小知识单元。在本分析中，一个知识元满足以下条件：

1. **语义自足性**：脱离上下文仍可被独立理解为一个完整的认知断言（命题、发现、定义或判断）。
2. **认知原子性**：不可进一步分解为更小的独立知识单元（分解后将失去原断言的核心认知内容）。
3. **可链接性**：可以与其他知识元建立语义关系（因果、支撑、矛盾等）。
4. **可溯源**：可以追溯到分析报告中的具体段落和原文位置。

### L### 知识元类型编码

| 编码 | 类型 | 定义 | 示例 |
|------|------|------|------|
| KE-C | 概念型（Concept） | 定义一个术语或概念的内涵 | POA框架的定义 |
| KE-A | 断言型（Assertion） | 提出一个可被评估为真/假的主张 | "用户无法预测自身绩效" |
| KE-F | 发现型（Finding） | 报告一个实证研究发现 | 美学评分与绩效排名无显著相关 |
| KE-R | 关系型（Relation） | 陈述两个或多个概念/现象之间的关系 | "美学感知系统性影响可用性判断" |
| KE-M | 方法型（Method） | 描述一种方法、技术或操作化路径 | 长期纵向实验设计 |
| KE-V | 价值型（Value） | 表达一种规范性判断或价值立场 | "HCI必须超越以绩效为中心的范式" |
| KE-L | 局限型（Limitation） | 识别一个理论、方法或发现的边界或局限 | 经典有效性在非确定性任务中失效 |

### L### 知识元提取规则

1. **自足性检验**：提取后的知识元必须能被独立阅读和理解。若需要上下文补充，则该提取不合格，需扩展或重新措辞。
2. **单义性要求**：每个知识元只承载一个核心认知内容。如果一个句子同时包含两个独立的断言，应拆分为两个知识元。
3. **溯源标注**：每个知识元必须标注其来源（分析报告文件、章节、段落）。
4. **层级标注**：每个知识元标注其所属的分析层级——全文级（TX）、章级（CH）、跨章级（CS）、专项级（SP）。
5. **确定性标注**：五级量表——确定的实证发现（D5）、强有力的理论论证（D4）、有经验支持的主张（D3）、探索性假设（D2）、推测性展望（D1）。

## 三、语意分析的维度与标注规则

### L### 语意分析维度

对每个提取的知识元，从以下六个维度进行语意标注：

| 维度 | 标注内容 | 标注格式 |
|------|----------|----------|
| **语义域** | 该知识元所属的语义场 | POA框架/经典可用性/美学/时间动态性/数字体裁/方法论/认识论 |
| **抽象层级** | 该知识元的抽象程度 | 元理论（MT）/ 理论（TH）/ 实证（EM）/ 操作方法（OP） |
| **认知功能** | 该知识元在论证中的认知角色 | 定义/批判/建构/支撑/限定/展望 |
| **确定性** | 该知识元的认知确定性等级 | D1（推测）/ D2（假设）/ D3（主张）/ D4（强论证）/ D5（确证） |
| **新颖性** | 该知识元相对于时代知识背景的新颖程度 | N1（常识）/ N2（已知但重新强调）/ N3（旧概念新综合）/ N4（领域内新贡献）/ N5（跨领域原创） |
| **冲突性** | 该知识元与既有知识的冲突程度 | C0（无冲突）/ C1（温和修正）/ C2（挑战既有预设）/ C3（颠覆性重述） |

### L### 标注操作细则

1. **语义域标注**：一个知识元可同时属于多个语义域（以"/"分隔）。主要语义域列在首位。
2. **确定性标注**：以该知识元在原文中的论证强度为主要判断依据。原文提供了实验数据→D5；原文提供了有力理论推理→D4；原文陈述了有经验例证的主张→D3；原文使用了推测性语言→D2/D1。
3. **冲突性标注**：对照"2001年HCI领域的主流共识"进行判断。与该共识一致→C0；部分修正→C1；挑战某个既定预设→C2；提出全局替代方案→C3。

## 四、语义链接网络构建规则

### L### 链接类型定义

| 编码 | 链接类型 | 定义 | 方向性 |
|------|----------|------|--------|
| L-CAU | 因果关系（Causation） | A导致/引起/驱动B | A→B |
| L-SUP | 支撑关系（Support） | A为B提供证据/论证支持 | A→B |
| L-EXT | 扩展关系（Extension） | A被B扩展/深化/操作化 | A→B |
| L-OPP | 对位关系（Opposition） | A与B形成概念对位或替代关系 | A↔B |
| L-HIE | 层级关系（Hierarchy） | A是B的上位/下位概念 | A⊃B或A⊂B |
| L-TEM | 时序关系（Temporal） | A在时间上先于B | A→B |
| L-CON | 矛盾关系（Contradiction） | A与B在逻辑上不能同时成立 | A↮B |
| L-ANA | 类比关系（Analogy） | A与B在结构上相似 | A≈B |
| L-PRE | 预设关系（Presupposition） | A是B得以成立的隐含前提 | A→B |

### L### 链接构建规则

1. **链接必须在节点间有明确的语义关系**，不能仅因为两个知识元涉及同一主题就建立链接。
2. **每个链接必须标注其来源依据**——来自哪个分析报告的哪个分析段落。
3. **跨章链接优先**：优先构建连接不同章节知识元的链接（跨章链接比同章链接更具涌现价值）。
4. **避免冗余链接**：如果A→B和B→C已存在，不自动建立A→C（除非存在独立的A→C的直接语义关系）。
5. **负向链接标注**：矛盾关系（L-CON）和对位替代关系（L-OPP）必须明确标注——这些负向链接往往是知识涌现的关键触发点。

### L### 网络密度要求

语义链接网络应满足以下最低密度标准：
- 每个知识元至少与其他3个知识元建立链接（度≥3）。
- 跨章链接占比不低于总链接数的40%。
- 负向链接（L-CON, L-OPP）占比不低于5%。

## 五、知识涌现计算规则

### L### 涌现的操作定义

在本分析框架中，"知识涌现"被操作性地定义为：**在语义链接网络上进行的计算分析所揭示的、在任何单一知识元中不直接包含的、反映知识体系结构性特征的模式、属性或规律。**

### L### 计算维度与方法

| 计算维度 | 计算方法 | 涌现出的知识类型 |
|----------|----------|-----------------|
| **中心性分析** | 度中心性、介数中心性、特征向量中心性 | 识别网络中的"枢纽知识元"——在知识体系中承担最多认知连接的核心概念 |
| **聚类分析** | 模块度检测、社区发现 | 识别知识元的自然聚类——揭示论证的隐含主题结构 |
| **结构洞分析** | Burt结构洞度量 | 识别"认知桥梁"——连接不同知识聚类的关键知识元；同时识别"结构洞"——缺少连接的空白地带 |
| **模体检测** | 三节点/四节点模体频次分析 | 识别反复出现的论证模式（如批判-对位-替代的三元结构） |
| **路径分析** | 最短路径、关键路径 | 识别论证的核心链条——从前提经中间结论到最终结论的最短路径 |
| **内聚与分裂分析** | 模块度Q值、割点检测 | 评估知识体系的内聚力——是否存在分裂的子群？是否存在"一旦移除则网络断裂"的知识元？ |
| **层级分析** | 入度/出度比、层级深度 | 识别知识的"基础层"（被引用最多但引用他人最少）和"衍生层"（引用他人最多但被引用最少） |

### L### 涌现判断标准

一个计算分析结果被视为"涌现知识"当且仅当它满足以下至少两个条件：

1. **不可见性**：该模式/规律在任何单一分析报告中没有被直接陈述。
2. **结构性**：该模式/规律反映了知识元之间的关系结构，而非单个知识元的内容。
3. **解释力**：该模式/规律能解释为什么论证以这样的方式组织、为什么某些论点比其他论点更有说服力、为什么某些主题在文中反复出现。
4. **反常性**：该模式/规律与某些分析报告中的表面陈述形成了有意义的张力（如报告声称某论点重要，但网络分析显示其处于边缘位置）。

## 六、知识发现报告的生成规则

### L### 报告结构

知识发现报告（04_知识发现报告.md）应遵循"从涌现现象到认知论断"的生成逻辑：

1. **涌现现象描述**：陈述计算分析揭示的模式或规律（是什么）。
2. **现象溯源**：追溯该涌现现象在网络中的具体知识元和链接上的来源（从哪来）。
3. **认知含义推断**：从该涌现现象中推断出的认知论断（意味着什么）。
4. **与分析报告的表面陈述对话**：该涌现知识是证实、深化、修正还是挑战了分析报告中的表面陈述？
5. **方法论反思**：该发现对分析方法本身有什么启示？

### L### 发现等级

| 等级 | 定义 | 报告优先级 |
|------|------|-----------|
| **一级发现** | 揭示了在分析报告中完全未被言明的深层结构或隐含模式 | 最高——置于报告首位 |
| **二级发现** | 深化或量化了分析报告中已有暗示但未充分展开的观察 | 中——紧随一级发现 |
| **三级发现** | 以结构化和量化的方式证实了分析报告中已经明确陈述的主张 | 一般——用于确认和巩固 |

### L### 报告输出规范

1. 每个发现以一个L###标题命名（发现的核心论断）。
2. 发现之间以逻辑递进（从结构到内容，从宏观到微观）或重要性递减（等级优先）排序。
3. 每个发现包含至少一个可视化的网络子图描述（以文字描述方式——指出涉及的关键节点和链接类型）。
4. 报告以"方法论反思与局限"部分收尾——坦然陈述本分析方法的假设和边界。

## 八、分析方法论声明

### L### 分析方法的基本预设

本分析方法建立在以下预设之上（这些预设本身是可质疑的）：

1. **知识可原子化预设**：知识可以被分解为不失去认知价值的原子单元（知识元）。这一预设在某些知识传统（如整体论、情境认识论）中是受质疑的——某些知识可能"整体大于部分之和"且不可分解。
2. **关系可穷举预设**：知识元之间的关系可以被有限类型（九类）充分表征。实际上知识元之间的关系可能比这九类更丰富或更模糊。
3. **涌现可计算预设**：知识涌现可以通过网络计算指标加以检测。实际上有些类型的知识涌现（如概念创新、隐喻跳跃）可能超出了当前网络计算方法的检测范围。
4. **中文语意标注的等价性预设**：用中文对英文原文派生的分析报告进行知识元提取和语意标注，不会系统性地丢失或扭曲原知识的认知内容。

### L### 分析方法的边界

1. 本分析不评估知识元本身的"真值"——不判断Dillon的论点是否正确、实验是否有效。它只分析这些知识元在分析报告构成的语料中的结构关系和涌现模式。
2. 本分析的知识元提取仅基于分析报告（二次文献），不直接基于Dillon原文（一次文献）。分析报告的偏见和选择可能已过滤或强调了原文中的某些知识元而忽略了其他。
3. 本分析的语意标注具有不可避免的主观性——不同的标注者可能对同一知识元的类型、层级、确定性和新颖性给出不同判断。本分析通过明确定义标注维度、提供编码手册和示例来降低主观性，但无法消除。

## 九、与"分析报告"系列的关系

### L### 继承关系

本分析是"分析报告"系列的逻辑延长：

- 分析报告系列完成了"从原文到分析"的第一次知识转化（原文 → 结构化分析）。
- 知识涌现分析系列完成"从分析到综合"的第二次知识转化（分散的分析 → 网络化的涌现）。

### L### 超越关系

分析报告系列的每一章聚焦于Dillon论文的一个片段（某一章、某一方面），形成的是"显微镜"式的局部深度分析。知识涌现分析系列则聚焦于分析报告的"整体结构"——通过将分散的分析重新链接为网络，揭示"望远镜"式的全局模式。

**核心认知转换**：从"一篇论文的分析"到"一个知识体系的涌现"。
