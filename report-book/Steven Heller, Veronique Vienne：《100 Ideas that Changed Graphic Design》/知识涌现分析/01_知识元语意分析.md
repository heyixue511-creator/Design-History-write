## 〇、总述：六类实体的五种论证功能

在本书中，六类实体承担五种论证功能（定义见 00）：

| 功能 | 含义 | 典型实体例 |
|---|---|---|
| **因果节点** | 推动观念产生/演变的驱动者（人物、事件、技术） | Rodchenko（L1866）、Kodalith 发明（L3183）、Comics Code（L217） |
| **结构变量** | 决定设计形式/流程的条件（机构、地点、技术） | AIGA（L2494）、Letraset（L119）、网格（L2884） |
| **类型标签** | 标识风格/流派的分类概念 | Sachplakat（L1506）、New Typography（L1883）、psychedelia（L3211） |
| **证据载体** | 支撑论断的作品/实物 | Eye-Bee-M（L2234）、Eros（L332）、London Underground map（L2660） |
| **参照坐标** | 提供历史/地理/理论参照 | Las Vegas（L424）、乌尔姆（L2960）、Derrida（L448） |

## 一、人物（因果节点 + 参照坐标双重功能）

**语义载荷总述**：本书人物均以"谁做了什么、改变了什么、被谁继承"被引用。人物是观念的时间载体：同一观念在不同时代由不同人物接力（如 Lissitzky 红楔 → Beall/Rand/Lustig 转化 → Gerstner 去象征化，L1897-L1916）。

## 七、语义载荷的总体形态

本书知识元的语义载荷呈"**事件化 + 物证化**"双轨：人物与事件解释"观念从哪来"，作品与地点提供"观念长什么样"。概念（Idea）是组织中枢，机构与技术是结构变量，共同支撑引言提出的"观念 = 技术、哲学、形式、美学四重构造"（L13）。
