# 方法与规则：知识元语义分析、知识发现与知识涌现计算

本套报告的**唯一判定标准**是：知识元之间的**实际语义链接**（以文本证据为凭），不以外在学科标签、作者主张或读者预设立场为标准。所有结论均可回溯到分析用 Markdown 的行号（L###）。

---

## 一、层级定义

| 层级 | 定义 | 判定依据 |
|---|---|---|
| **知识元**（Knowledge Element） | 书中最小的、不可再分且有独立语义载荷的单位，即人物、著作、概念、机构、地点、事件六类实体 | 实体在文本中具有独立指称且承载论证功能 |
| **Topic** | 由若干个**相互之间存在直接语义链接**的知识元组成的连通簇 | 簇内知识元两两可达（经由链接），簇间链接密度显著低于簇内 |
| **Theme** | 由若干个 topic 组成的高层语义域 | topic 之间经由共享知识元或强桥接链接而汇聚 |

**涌现**（Emergence）的定义：在单一知识元层面不存在、只在 topic／theme 组合层面出现的新命题、新结构或新属性。涌现计算即度量并解释这种"整体大于部分之和"的现象。

---

## 二、语义链接的判定标准（唯一标准）

两知识元 **A—B 之间存在语义链接**，当且仅当文本中存在以下任一种**可证实的直接语义关系**（证据 = 出现行号）：

| 链接类型 | 记法 | 判据 | 歌德《色彩论》示例 |
|---|---|---|---|
| 因果 | A→B | 文本明示 A 导致/促使/决定 B | 半透明介质→色彩产生；视网膜疲劳→补色残像 |
| 条件 | A⇒B | A 是 B 成立的前提 | 半透明介质⇒色彩产生（无介质则无色） |
| 对比 | A↔B | 文本并置双方作对照 | 黄（加/主动）↔蓝（减/被动）；歌德色彩论↔牛顿光学 |
| 隶属/实例 | A⊂B | A 是 B 的成员/例/部分 | 生理色⊂色彩三模态；黄⊂六色环；残像⊂生理色现象 |
| 时序 | A≻B | 前后相继且后者受前者影响 | 黄≻红黄≻黄红（增强序列）；生理色≻物理色≻化学色（由瞬至久的递进） |
| 空间共现 | A≈B | 同一空间结构内共同作用 | 光≈暗（共构边界条件产生色彩） |
| 归属/属性 | A:B | A 具有属性/由 B 表征 | 黄:温暖、亲近、亲酸性；蓝:寒冷、远离、亲碱性 |
| 论证支撑 | A⇐B | B（权威/实验/现象）为 A 提供证据 | 补色律⇐暗室白光圆斑残像实验；原初现象⇐大气太阳色变 |
| 同域指称 | A∼B | 属于同一体系/进程的两个侧面 | 极性∼增强（同一动力原理的两个维度） |

**判定细则**：
1. 必须以**分析报告中的直接表述**为据，禁止以"读者联想"或外部常识替代；
2. 同一行/相邻行内共同出现的实体仅构成**候选共现**，须进一步确认语义关系类型后才计为链接；
3. 跨章链接须在相关章节均有实体证据（行号）支撑；
4. 对相互矛盾的链接（如歌德的"反牛顿"立场与其实际引用牛顿实验材料之间的张力），如实记录并注明，不强行合并。

## 三、涌现计算指标（语义化计算）

以下指标全部基于第二节规则逐条清点，不作统计假设：

1. **节点度 k(e)**：知识元 e 的直接语义链接数。度越大 = 语义枢纽（hub）。预期歌德文本中"半透明介质"、"补色律"、"极性"等概念的节点度最高。
2. **桥接值 b(e)**：e 的链接中**跨 topic** 的数目。桥接值高 = 中介概念（broker），是把不同 topic 粘连成 theme 的关键。预期"原初现象"（Urphänomen）具有最高桥接值。
3. **簇（topic）识别**：以"强连通"为原则——簇内任意两元经簇内链接可达；簇间只经少数桥接元相连。
4. **内聚度**：簇内链接数 /（簇内节点数）^2 归一化。内聚度高 = topic 论证紧密。
5. **涌现强度 S**：主题级涌现命题的数量 × 支撑该命题的跨 topic 链接数。S 高 = 该 theme 涌现出的新知识越强。
6. **涌现层次**：
   - 一级涌现 = 由知识元链接直接构成的可观察结构（如黄—蓝两极→六色环→红色顶峰的增强序列）；
   - 二级涌现 = 由 topic 间交互生成、不可还原为任一 topic 的整体命题（如"色彩不是光的分解产物，而是光—暗—眼三者交互的事件"）。

## 六、本著作的特殊方法论说明

歌德《色彩论》（Theory of Colours, 1810）与一般科学著作有本质不同，因此本分析需特别处理以下情况：

1. **论战性格与双重语义**：歌德的许多概念同时承载"建设性"（构建自己的色彩理论）和"批判性"（驳斥牛顿）双重语义负荷。如"原初现象"既是正面方法论概念，又是反驳牛顿的武器。分析时需分别标注两种语义链接，不合并。
2. **实体密度的不均匀分布**：Part I（生理色）和 Part II（物理色）的实验与现象实体远多于 Part IV-VI。这是歌德方法论的有意安排（从具体到一般），分析中不因此将实体稀疏的篇章视为"论证薄弱"。
3. **有机论语言的认知负荷**：歌德大量使用有机体隐喻（tone、vital elasticity、recovery、systole/diastole）来描述色彩和视觉过程。这些隐喻不是修辞点缀——它们承载着歌德对自然本质的哲学信念，构成一种特殊的"属性链接"（:）类型。
4. **跨卷关系**：Eastlake 英译本主要翻译教学卷（didactic part），但歌德原书另含论战卷（polemical part）和历史卷（historical part）。本分析以教学卷为主体，论战卷内容通过教学卷中的论战段落间接体现。凡涉及英语译本与德语原本之差异处，已由 Eastlake 译者序（01号报告）覆盖。
