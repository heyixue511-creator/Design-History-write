# Ch04：表面与空间中的定向——图像整体的分节（原书 pp.39-58）

## 一、章节定位与功能

本章从抽象的维度理论转入具体的空间操作。在前章（Ch03）建立了点→线→面→体的生成序列之后，本章的任务是：为这些基本元素在二维平面和三维空间中的位置确定提供一套坐标系。其核心功能是将"上-下、左-右、前-后"的直观定向转化为严格的形式操作工具，从而为"图像整体的分节"（articulation of the pictorial whole）奠定空间句法基础。

## 三、内容分析

### L059 核心论题

**论题一：表面上定位的二维法则**
平面上P点的位置由其在横坐标之上（或之下）和纵坐标之左（或之右）的关系确定。这一简单的数学法则被克利转化为"上/下"与"左/右"的感知性坐标。

**论题二：空间中的三维定位**
在空间中，P还必须考虑"前-后"维度。克利将这三个方向综合为立方体中的三维结合——这是从数学坐标到立体造型的直接平移。

**论题三："I"作为空间定向的原点**
克利将空间定向主体化："'I'根据三个维度在空间中定向自身。"它根据"上→下、左手→右手、前→后"来判断其位置。这不是抽象的笛卡尔坐标，而是以身体为原点的现象学空间。

**论题四：从空间到表面的投射**
当三维空间关系被"移植到表面上"时，克利展示了如何将立体坐标系统映射为平面上的视觉等价物。这是立体主义"多维同时性"背后的操作原理。

## 四、逻辑梳理

```
二维平面坐标（横坐标+纵坐标）
  → 增加前-后维度 → 三维空间坐标
  → 从抽象坐标到具体身体："I"作为原点
  → 主观空间（现象学）与客观身体（几何学）的综合
  → 投射到表面：空间→平面的翻译
  → 为"移动视点"与"主观空间理论"铺垫
```

## 六、论辩与阐述方法

1. **从抽象到具体-身体**：从数学坐标推进到身体经验。
2. **逐步扩展**：每增加一个维度（从二维到三维），论证相应地复杂化。
3. **投射演示**：展示如何将立体空间"翻译"为表面，示范立体主义的操作逻辑。
