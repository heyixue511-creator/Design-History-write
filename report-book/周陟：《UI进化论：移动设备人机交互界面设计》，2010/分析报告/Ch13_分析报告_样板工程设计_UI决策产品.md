# Ch13 分析报告：样板工程设计（UI决策产品）

## 章节定位与功能（含行号范围）

- **章标题**：样板工程设计：UI决策产品
- **所属部分**：PART4 项目实践
- **行号范围**：L1792-L1954（目录预告见 L106；全书结尾）
- **功能**：全书的收束章，也是最雄心勃勃的一章。以"由 UI 设计团队主导一款产品"为命题，完整演示"产品策划→项目会议→概念设计→界面设计→交互实现→音效整合→制作开关机动画"全流程。本章直接回应作者"设计主导产品"的主张（L1793），是全书思想与实践的最终合成。

## 结构分析

本章正文分七节：
1. **13.1 产品策划**（L1795-L1850）：为何旧流程必败（L1795-L1796）、PPT 演示文档的作用（L1798-L1802）、《用户体验浅析》培训课程试卷（L1807-L1810）、部门培训试卷反馈分析（L1832-L1850）。
2. **13.2 项目会议**（L1852-L1869）：产品配置设想（芯片/硬件/功能/形态，L1852-L1859）、交互界面水平（L1861-L1865）、产品应解决的问题（UI 设计数据输入表、功能要求、工厂要求、研发要求，L1867-L1869）。
3. **13.3 概念设计**（L1870-L1893）："影视手机"概念机型定义（功能特色、硬件参数、软件参数、设计方向，L1872-L1884）、测试 LCD（L1886-L1890）、界面概念设计（L1892-L1893）。
4. **13.4 界面设计**（L1895-L1901）：4个关键界面（待机/主菜单/音乐播放器/相册，L1898）；待机界面 Widget 设计（快捷功能、时钟、事件备忘、简易音乐播放器，L1898-L1901）。
5. **13.5 交互实现**（L1903-L1910）：用 Flash 把静态界面转化为可操作的交互界面（补间动画、按钮、音乐控制、进度条、歌词遮罩，L1904-L1910）。
6. **13.6 音效整合**（L1912-L1948）：音源芯片测试（RMAA 软件、频率响应/动态范围/平底噪声/THD/互调失真/声道分离度/IMD 扫描音调，L1914-L1930）、铃音制作示例（nuendo 软件、"黑客之舞"迷幻电子乐铃音，L1935-L1948）。
7. **13.7 制作开关机动画**（L1950-L1954）：设计原则（LOGO、风格统一、区分开关机、长度、兼容风格、简洁，L1951）；Cinema 4D 制作（AI 路径、挤出、三点打光、DanelShader、Shatter 变形、摄影机动画、渲染输出，L1951-L1954）。

## 内容分析

- **设计主导产品**：作者直言"以设计团队出发，无论设计师觉得自己是如何的伟大和高尚，但在大多数中国的企业中，设计师总是和艺术家、技术白痴等词语联系到一起"（L1796），主张通过培训统一项目组价值观（L1850）。
- **培训体系**：PPT 培训文档（渐进结构：UCD价值→关键要素→如何进行→手机产品体验→现状，L1799）；培训试卷（选择题8题+创意题+思考题，L1809-L1816）；答卷反馈分析（15人参与、14份回收、选择题正确率98.52%，L1835-L1838）。
- **"影视手机"概念**：3.2英寸16:9多点触摸 touchlens、重力感应、8GB扩展、320万像素 CMOS、2000mAh 电池、MTK 6238 平台（L1875-L1884）。
- **测试LCD**：直方图、Patone 标准色、黑场/白场测试、GIF 渐变波纹测试、黑白渐变测试（L1886-L1890）。
- **界面设计**：4个关键界面；待机界面含快捷功能 Widget（7±2原则，L1901）、时钟、事件备忘、音乐播放器（L1898-L1901）。
- **交互实现**：Flash 中音乐播放器界面的补间动画、音量按钮 startDrag 代码、播放/暂停代码、进度条、歌词遮罩（L1904-L1910）。
- **音效整合**：RMAA 音源芯片测试报告（L1917-L1930）；"黑客之舞"铃音制作（nuendo、Kompakt 音色、缩混、导出，L1935-L1948）。
- **开关机动画**：Cinema 4D 制作粉碎组合动画（Shatter 变形器）、17张 TIFF 渲染（L1951-L1954）。

## 逻辑梳理

本章逻辑：**立理念（UI 主导产品）→ 建共识（培训）→ 定规格（项目会议/概念定义）→ 验载体（LCD 测试）→ 做界面（关键界面）→ 做交互（Flash）→ 配声音（音效）→ 收尾（开关机动画）**。完整覆盖一款手机 UI 从策划到交付的软硬件全链路。
