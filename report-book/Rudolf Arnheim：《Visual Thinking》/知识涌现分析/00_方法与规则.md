# 00_方法与规则：知识涌现分析规范（《Visual Thinking》）

## 一、层级定义

| 层级 | 名称 | 定义 |
|---|---|---|
| 知识元（Knowledge Element） | 六类实体 | 人物、著作/作品、概念、机构、地点、事件；本分析以"概念"为主要知识元（全书为理论著作，概念是论证主干），其余五类作为概念的功能载体 |
| Topic（主题簇） | 强连通簇 | 由语义链接网络中的强连通子图构成，簇内知识元之间链接密集（相互可达），簇间链接稀疏 |
| Theme（高层语义域） | 主题的聚合 | 多个 Topic 共享桥接知识元或共同语义方向时聚合为高层域，是全书最抽象的思想板块 |

**证据规范**：所有链接与簇均须以 clean 版行号（L###）支撑，行号须真实存在；无证据的主张不得作为知识元或链接列入。

## 二、9 种语义链接判定标准

| 类型 | 记号 | 判据 | 本书实例 |
|---|---|---|---|
| 因果 | → | 一个知识元是另一个的产生原因或结果（含心理因果、历史因果） | 感知歧视（成见）→ 艺术在教育中被边缘化（L43-46） |
| 条件 | ⇒ | 一个知识元的成立以另一个为前提（蕴含/前提关系） | 概括成立 ⇒ 抽象先已发生（L2445-2477） |
| 对比 | ↔ | 两个知识元互为对立面或互补 | 直觉认知 ↔ 理智认知（L3618-3641）；图画 ↔ 记号（L2079-2098） |
| 隶属 | ⊂ | 一个知识元是另一个的子类/成分 | 纯形状 ⊂ 知觉形状（L3213-3218）；类型 ⊂ 概念（L2691） |
| 时序 | ≻ | 一个知识元在时间上先于/后于另一个 | 抽象 ≻ 概括（原初抽象先于归纳，L2857-2858）；感知在先，概念化在后（发展心理学顺序） |
| 空间共现 | ≈ | 两知识元在同一知觉场/空间模式中共现 | 图-底 ≈ 场论（同构的空间组织模式，L4425-4436） |
| 属性 | : | 一个知识元是另一个的属性/特征 | 视觉：选择性（L306）、主动性（L307-309）、概念性（L453-461） |
| 论证支撑 | ⇐ | 一个知识元为另一论点的证据/例证 | Michotte 因果实验 ⇐ "because"的知觉意象（L3764） |
| 同域 | ∼ | 两个知识元属于同一语义领域（如都属"知觉"或"语言"） | Helmholtz 恒常性 ∼ Gibson 恒常性（同属知觉恒常性领域，L645-695） |

## 三、涌现指标

| 指标 | 定义 | 计算方法（人工判定） |
|---|---|---|
| 节点度 k | 知识元在链接网络中的连接数 | 统计与该知识元直接相连的链接数（含双向） |
| 桥接值 b | 知识元连接不同 Topic/Theme 的能力 | 计数其"跨 Topic"或"跨 Theme"链接数；≥2 记为高桥接 |
| 簇识别 | Topic（强连通簇） | 相互可达的知识元子集；每簇给出核心元、簇内链接数与节点数 |
| 内聚度 | 簇内链接密度 | 簇内实际链接数 / 可能最大链接数（n(n-1)/2）的比值（人工估算） |
| 涌现强度 S | 簇/命题的新信息量 | 高（H）：产生原知识元单独不具备的新命题；中（M）：重组已有命题；低（L）：仅为复述 |
| 一级涌现 E | 簇级涌现 | Topic 形成后出现的、不还原为单个知识元的结构性质 |
| 二级涌现 P | Theme 级命题 | 跨 Topic 综合产生的全书层面命题，附生成机制与强度 |

## 四、证据规范与报告清单

1. 所有知识元、链接、Topic、Theme、命题均须附 L### 行号证据；
2. 客观性核对：对每一枢纽与簇，列出反例或边界条件；不掩盖文本内部张力（如作者对"场过程"无神经机制的自承，L1166；对语言作用低估的张力，L3781-3784）；
3. 报告清单：01_知识元语意分析 → 02_语义链接网络 → 03_知识涌现计算 → 04_知识发现报告，逐级递进。

## 五、本书的知识元选择原则

《Visual Thinking》是理论专著，概念知识元远多于人物/著作类实体。本分析按"论证功能"择元：
- **概念知识元**（主）：凡在论证中承担命题功能的术语（视觉思维、视觉概念、纯形状、图画/符号/记号、容器概念/类型、静态/动态概念、恒常性、图-底、模态/非模态补全、原初抽象、语言决定论、场过程等）。
- **人物知识元**（次）：作为"理论位置"参与论证的学者（Plato、Aristotle、Locke、Berkeley、Kant、Wittgenstein、Köhler、Wertheimer、Piaget、Titchener、Whorf、Goldstein、Langer、Worringer 等）。
- **著作/作品知识元**（再次）：作为证据载体（《理想国》《人类理解论》《Abstraction and Empathy》、Rembrandt 画作等）。
- 机构/地点/事件：在语义网络中以"案例节点"出现，主要承担证据载体与参照坐标功能。
