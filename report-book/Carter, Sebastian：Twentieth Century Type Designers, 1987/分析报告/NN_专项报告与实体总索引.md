# NN 专项报告与实体总索引

## 专项报告一：全书叙事结构模型

### 双螺旋叙事

本书采用"技术变革 × 人物传记"的双螺旋结构：

```
技术层: 手工punch → Benton pantograph → 热金属 → 照排 → CRT → 数字
        ↑            ↑                    ↑         ↑       ↑      ↑
人物层: Prologue → Old Types → The designers-1 → New Types → The designers-2 → Epilogue
```

每一周期包含：
- **技术约束**（如：Monotype diecase的width row限制）
- **人物反应**（如：Van Krimpen的反对、Gouldy的抵抗、Gill的讽刺）
- **字体产出**（如：Bembo/Times New Roman/Caledonia）

### 四大贯穿主题的跨章追踪

**主题1：历史复刻的伦理**
- Prologue: Cranach italic事件

- Van Krimpen: 1955年备忘录

## 专项报告四：OCR文本状态与局限说明

本书的数字化文本（F:/Design-history-知识元/00-book/Carter, Sebastian：Twentieth Century Type Designers, 1987.md）存在以下问题：

1. **嵌入的扫描噪声**：文件中包含大量嵌入的电话簿目录页面（Alabama地区的V字头姓氏），这是OCR扫描时从扫描仪或原始来源中意外捕获的非相关材料
2. **OCR误识别**：许多字符存在明显的OCR替换错误（如"thc"/"thc"替换"the"，"whieh"替换"which"，"faees"替换"faces"等），这是英文旧式字体扫描的典型问题
3. **页面顺序混乱**：部分章节的文本似乎与其他章节的文本混杂
4. **字体样张嵌入**：文件包含大量ABCDEFGHIJK等字体展示字符，这些在原始印刷书中作为插图存在，在OCR文本中嵌入为文本
5. **图片引用残留**：所有图片都以`![](images/...)`格式残留，但图片本身不可用

本报告的分析基于对OCR文本的"最佳理解"（best-effort reading），通过上下文推断、命名模式识别（如"Van Krimpen" vs "Van Krimpen"等OCR变体）和结构性线索来还原原始内容。
