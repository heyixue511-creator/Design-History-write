# 00_方法与规则

本文件定义本书（Weiner & Schneider 编《Cloth and Human Experience》）知识涌现分析所采用的完整方法论。全部分析基于父进程清洗文本 `00-book/Weiner, Annette B.; Schneider, Jane：《Cloth and human experience》_clean.md`（7707 行），行号证据统一采用 L###。本套分析为**纯语义分析**：不运行代码、不做统计计算，所有"度值/桥接值/簇"均由对正文逐行语义链接的人工标注生成并据此计数，任何量化数字都可回溯到链接清单中的具体链接条目。

## 一、层级定义

- **知识元（Knowledge Element）**：六类实体——人物（P）、著作/作品（A）、概念（C）、机构（I）、地点（PL）、事件（E）。每个知识元是承载语义载荷的最小分析单元，其身份与证据行号见 `NN_专项报告与实体总索引.md` 与 `01_知识元语意分析.md`。
- **Topic（主题簇）**：由强连通语义链接聚集而成的"簇"。判定：簇内任意两元之间存在 ≥1 条语义链接（不强求每条都双向），簇间以低连接密度为边界；预期 6-15 个。
- **Theme（高层语义域）**：若干 Topic 因共享/桥接知识元而聚合的高层域；预期 3-5 个，与全书三大结构部分（小规模社会/资本主义/大规模社会）及导言的议题映射，但不与之简单等同（见 `03_知识涌现计算.md` 的核对）。

## 二、9 种语义链接判定标准

语义链接是"知识元 A —链接类型— 知识元 B"的有向/无向边，依据**原文语义关系**判定，每条链接必须能在正文找到证据行号。判据与示例：

| 类型 | 符号 | 判据 | 例（本书） |
|---|---|---|---|
| 因果 | → | A 是 B 的原因/条件之因；原文有"because/owing to/导致"语义 | 亚麻原工业→精灵恶魔化（L3548-L3551）；布之持久性→等级深化（L166-L167） |
| 条件 | ⇒ | A 的成立/实现以 B 为前提；"if/only when/除非"语义 | 附体治愈的前提是"使灵言说自报名号"（L1607-L1611）；khadi 生效以"人人纺纱"为条件（L6740-L6741） |
| 对比 | ↔ | A 与 B 构成对立、对照、替代关系 | 布↔金属（L396）；粗布 aratae↔精布 nigitae（L7018）；神圣-生产类比↔生产-再生产对立（L282-L284） |
| 隶属 | ⊂ | A 是 B 的子类/部分/实例；"including/a type of"语义 | tromba⊂萨卡拉瓦祖灵（L1590）；khadi⊂swadeshi 纲领（L6715）；putting-out⊂资本主义制造组织（L258-L260） |
| 时序 | ≻ | A 在 B 之前发生/为其阶段先导 | 甘地服饰实验（伦敦→南非→Kathiawari→缠腰布）≻ 1921 khadi 决议（L6467-L6670）；亚麻漂白诸阶段序列（L3487-L3493） |
| 空间共现 | ≈ | A 与 B 在同一场所/区域中并置出现 | lamba≈王陵/王都（L1460-L1465）；厚布≈Kitō 山地（L7053）；发包制≈San Antonino 与 Ocotlán 区（L4448-L4450） |
| 属性 | : | A 具有属性/特征 B；"X is characterized by Y" | 布之属性：柔软/脆弱/可持久/可割（L103-L121）；khadi 之属性：粗粝/简朴/手纺（L6742-L6746） |
| 论证支撑 | ⇐ | A 作为论证/理论，被 B（证据）支撑；B 是 A 的证据来源 | "保留-给予"理论⇐ Trobriand/Samoa 田野（L609-L610）；"初泵"论⇐ 印加编年史证据（L5027-L5042） |
| 同域 | ∼ | A 与 B 属同一论证域/主题域但无上述强关系；共同出现于某章某主题 | 荷兰纺纱图像∼哈勒姆亚麻业（Ch07 全章）；Sikh 头巾∼英国军队制服（L5661-L5663） |

**判定纪律**：每条链接在报告中标注类型与证据行号；对模糊关系优先选择弱链接（∼）而非强链接（→）；跨章链接须在导言或其他章有明确互文证据（如"this volume"引用、导言综述），禁止凭联想造链。

## 三、涌现指标

| 指标 | 定义 | 本书操作化 |
|---|---|---|
| 节点度 k | 该知识元参与的语义链接总数（去重后） | 人工统计 `02_语义链接网络.md` 链接清单 |
| 桥接值 b | 该知识元连接的不同 Topic 数（跨簇链接数） | 据 `03` 的簇划分回算 |
| 簇识别 | 强连通子图：簇内每节点与其他节点至少有路径相连 | 按"主题区"链接密度人工聚簇 |
| 内聚度 | 簇内实际链接数 / 簇内理论最大链接数（n(n-1)/2） | 人工计算并注明近似 |
| 涌现强度 S | 簇/结构的涌现显著性 = 簇内链接数 ×（簇节点数参与的跨簇链接数 + 1），用于比较不同簇的涌现力 | 相对比较用，不做精确定量 |
| 一级涌现（E） | 由知识元直接链接涌现出的结构（Topic/Theme） | 见 `03` 之 E1…En |
| 二级涌现（P） | 跨簇综合后才能陈述的命题（不属于任一单簇的直接内容） | 见 `03` 之 P1…Pn，附生成机制与强度 |

## 四、证据规范

1. 所有知识元、链接、簇、命题均须带 L### 证据；证据行号必须与 clean 版实际内容对应，不得编造。
2. "点到未论"（`04` 的 C 系列）必须明确标注证据缺口（"原文未直接论述，推断依据为……"）。
3. 客观性核对：对高涌现命题列出反例或边界（如"初泵"论的 Blas Valera 福利论反例 L4989；khadi 运动的 Nehru/Tagore 异议 L6742-L6753）。
4. 本套分析为语义阅读的推演产品，其"定量"均为标注计数，非统计推断。
