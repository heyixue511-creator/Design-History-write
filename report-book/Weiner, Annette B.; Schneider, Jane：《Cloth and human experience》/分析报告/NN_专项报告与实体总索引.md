# NN_专项报告与实体总索引

## 第一部分：专项报告

### 一、语言总体特征

本书为英语学术论文集（anthropology/history/art history 跨学科），语言以规范学术英语为主，但呈现明显的"多声部"特征：

1. **人类学章（Ch02/03/05）**：民族志叙事+理论推演混合体，大量转写受访者引语与原住民术语（如 Kiriwina 的'ie toga、马语的 lamba/tromba、科迪的 moro/hoyo）。术语保留原语并以斜体/引号标注。
2. **历史学章（Ch06/10）**：文献考据文风，直接引语密集（亚麻小册子、英国官员文件、编年史），注释系统庞大（Ch09 注释达 90 余条，L5047-L5293）。
3. **艺术史章（Ch07/12）**：图像/器物清单式叙述（博物馆、年代、图版编号），技术描述精确。
4. **民族志-经济章（Ch08）**：数据表格式（4 张表格、时薪、汇率、净收入）与案例叙事交替。
5. **全书统一性**：两位编者的导言（Ch01）以"布"为贯穿性隐喻，术语（weave/warp/thread/fabric）双关贯穿始终；结论开篇"picking up threads from societies so separated in time and space"（L444）是这一修辞的自我指涉。

### 二、文风特征

- **证据驱动**：几乎每个断言都有田野/文献/图像证据支撑；多数学者使用"it seems""perhaps""I would argue""suggests"等保留性判断（如 Ch02 L617 "establishing a gradient rather than an analytical separation"；Ch09 L5013 "we need not take such decimal accounts literally"）。
- **自反性与谦抑**：Ch01 结论承认"某种傲慢"（L444）；Ch09 承认史料不可靠之处（L4986-L4988）；Ch12 坦陈田野限制。
- **理论显明但非教条**：Weiner 的"保留-给予"、Murra 的"初泵"、Hoskins 的"蓝性"均为鲜明理论旗帜，但各章保持与反例对话（Ch09 并列 Blas Valera 与 Polo；Ch08 呈现发包制的双重效应）。

### 三、修辞方式

1. **隐喻系统**：全书以"织/线/布"为元隐喻（社会如织物 L120；"threads" 连接诸章 L444）；各章自有局部隐喻——染缸=子宫（Ch05）、纺线=命运/美德（Ch07）、头巾=身份（Ch10）、khadi=自由之制服（Ch11）。
2. **对比-反衬**：Trobriand/Samoa（Ch02）、马达加斯加/刚果葬仪（Ch03/04）、原工业/当代发包制（Ch06/08）、印度/冲绳民族布（Ch11/12）。
3. **反事实推理**："would Malinowski have ignored banana-leaf wealth if men had produced it?"（L416）。
4. **以个案切入全局**：Sagar 头巾案（Ch10 开头）、Kijōka 芭蕉布（Ch12 结尾）、Doña Sabina（Ch08）——小事件承载大命题。
5. **引语叙事**：直接引语充当"证据证人"（甘地自传、编年史、受访者、城市颂诗），减少作者代言。

### 五、阐述方法

- **比较法**：社会规模梯度（Ch02）、仪式同构（Ch03 附体=重葬）、制度平行（Ch09-12 贡赋-国库）、图像对举（Ch07）。
- **双层分析**：农民/国家（Ch09）、生产/象征（Ch05, 12）、经济/符号（Ch08, 11）。
- **长时段叙事**：Ch12 从新石器到 1988；Ch09 从 Mochica 到 1781；Ch10 从 1699 到 1959。
- **历史-理论互构**：以理论命题组织史料，以史料检验理论（如"初泵"论对"慷慨论"的检验）。
- **反例呈现**：对矛盾证据并列并给出边界（Ch09 印加福利/强制之争；Ch11 国大党内反对 khadi 的声音）。

### 六、推演逻辑

全书推演遵循"物质属性→文化赋值→社会政治运用→历史转化"的四级逻辑：

1. 布的**物质属性**（软/硬、持久/易朽、可割/不可割、贵/贱）——Ch01 开篇；
2. 文化的**意义赋值**（神圣、祖先、女性、等级、国族）——Ch02-05 与 Ch09-12；
3. 社会政治的**运用机制**（交换、授职、贡赋、规训、动员）——Ch01 四领域 + Ch09-11；
4. 历史**转化**（资本主义去魅、殖民重构、民族复兴）——Ch06-08 与 Ch10-12。

每个章节都在这一逻辑链上占据节点：Ch02 确立"布-等级"原理；Ch03-05 展示"布-祖先/女性/再生产"；Ch06-08 演示"布-资本/商品化"；Ch09-12 收束于"布-国家/殖民/国族"。

### 七、文字风格

- 术语体例：原住民语词斜体（lamba、moro、khadi、dhoti、tafu 等）；英文译名置于引号（"thick cloth""fine mats"）；Ch12 附日文汉字术语表（L7569）。
- 数字与专名：精确到页码/图版/馆藏号；人名官职并列（Guru Gobind Singh；Polo de Ondegardo）。
- 句法：长句为主，复合从句密集（人类学理论句），但叙事段落句长缩短（Ch10 戏剧性段落）。
- 标题趣味：章题多用反讽/双关（"Spun Virtue, the Lacework of Folly, and the World Wound Upside-Down""Why Do Ladies Sing the Blues?""Rumpelstiltskin's Bargain"）。
