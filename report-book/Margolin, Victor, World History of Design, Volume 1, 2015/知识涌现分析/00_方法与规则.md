# 00_方法与规则：知识涌现分析框架

## L001 本分析的总目标

本"知识涌现分析"系列报告，以维克多·马格林《世界设计史》第一卷（以下简称"本书"）及其已完成的全19章分析报告和专项/索引报告为基础，运用知识元（knowledge unit）理论、语义链接网络（semantic linking network）方法和知识涌现计算模型，对本书所承载的设计史知识系统进行结构性挖掘与发现。

本系列报告区别于前述"分析报告"之处在于：
- 分析报告是对原始文本的**解释性还原**——逐章梳理章节结构、核心论点、论证逻辑、材料使用方式、语言风格和实体清单；
- 知识涌现分析则是对分析报告一级数据的**结构性再组织**——从语义层面对知识进行拆解、链接、计算和发现，以揭示在单章视角下不可见的跨章节、跨时代、跨文明的深层知识结构和涌现模式。

## L002 核心概念界定

### L003 知识元（Knowledge Unit）

本分析框架下的"知识元"定义为：在本书设计史叙述中具有独立语义标识性的最小知识单位。知识元以分析报告中已编号的L###实体为基本候选池，按以下六维分类进行标记：

| 维度标签 | 内容定义 | 来源对应 |
|----------|---------|----------|
| K-PERSON | 人物知识元 | 人物实体（设计师、发明家、学者、历史人物） |
| K-ARTIFACT | 物品知识元 | 物品/作品实体（工具、器物、建筑、图像作品） |
| K-TECH | 技术知识元 | 技术/工艺实体（制作方法、材料技术、生产系统） |
| K-EVENT | 事件知识元 | 事件/运动实体（历史事件、社会运动、制度变迁） |
| K-PLACE | 场所知识元 | 机构/场所实体（遗址、城市、工坊、学校、公司） |
| K-CONCEPT | 概念知识元 | 概念/术语实体（理论概念、学术术语、思想范式） |

一个知识元经语意分析后，以三元组形式表达：

```
知识元ID = {名称, 维度标签, 语义描述向量}
```

其中"语义描述向量"为该知识元在原始文本中所有出现的上下文的语义浓缩，用于后续语义链接计算。

### L004 语义链接网络（Semantic Linking Network, SLN）

SLN定义为以知识元为节点、以语义链接为边的有向加权异构图。一条语义链接的形式定义为：

```
链接 = {源知识元, 目标知识元, 关系类型, 链接强度}
```

关系类型包括以下七类：

| 关系类型 | 代码 | 定义 | 示例 |
|---------|------|------|------|
| 因果关系 | CAUSAL | 源导致/促使/造就目标 | 焦炭高炉炼铁(K-TECH) →CAUSAL→ 工业革命(K-EVENT) |
| 时序先后 | TEMPORAL | 源在时间上先于目标 | 奥杜韦砍斫器(K-ARTIFACT) →TEMPORAL→ 阿舍利手斧(K-ARTIFACT) |
| 实例-类型 | INSTANCE_OF | 源是目标的一个实例 | 威治伍德(K-PERSON) →INSTANCE_OF→ 企业家-设计师(K-CONCEPT) |
| 地缘归属 | GEO_IN | 源在地理上属于目标 | 景德镇(K-PLACE) →GEO_IN→ 中国(K-PLACE) |
| 功能相似 | FUNC_SIM | 源与目标在功能上相似 | 苏美尔印章(K-ARTIFACT) →FUNC_SIM→ 品牌标识(K-CONCEPT) |
| 共现关联 | CO_OCCUR | 源与目标在同一语境中频繁共现 | 莫里斯(K-PERSON) →CO_OCCUR→ 工艺美术运动(K-EVENT) |
| 层级包含 | HIERARCHY | 源是目标的上位/下位概念 | 复合工具(K-CONCEPT) →HIERARCHY→ 弓和箭(K-ARTIFACT) |

### L005 知识涌现（Knowledge Emergence）

本框架下"知识涌现"定义为：当知识元之间的语义链接强度和密度超过一定阈值时，从局部知识元集群中涌现出的、无法从单个知识元或简单链接对中直接读取的**高阶知识结构**。涌现形态包括：

1. **知识簇**（Knowledge Cluster）：一组高强度互联的知识元聚集体，通常对应一个主题域或时间/空间维度上的知识密集区；
2. **桥节点**（Bridge Node）：连接两个或多个知识簇的高中介中心度知识元，是知识跨域传播的关键通道；
3. **涌现主题**（Emergent Theme）：由多个知识簇之间的结构性互动揭示的、在原文本中未直接表述的宏观历史主题；
4. **知识断层**（Knowledge Gap）：知识链接网络中显著稀疏或缺失的区域，指向原文本可能的覆盖盲区或学术争议地带。

## L006 分析流程规则

本系列报告的撰写遵循以下五步流程，每一步对应一个独立子报告：

```
[00_方法与规则] → [01_知识元语意分析] → [02_语义链接网络] → [03_知识涌现计算] → [04_知识发现报告]
```

### L007 第一步：方法定义（本文件）

确定知识元的分类维度、语义链接的关系类型体系、涌现判定的阈值标准和计算规则。本文件即为全部分析的方法论纲领。

### L008 第二步：知识元语意分析 —— 输出文件 01

从已完成的19章分析报告及NN_专项报告中提取所有L###编号实体，按六维分类进行知识元化处理，对每个知识元赋语义描述向量。同时识别原报告中未编号的隐含知识元（在逻辑梳理、核心论点中提及但未被纳入实体清单的重要概念或关系），以补充编号形式纳入。

语意分析规则：
- 规则R01：一个L###实体可以有多个维度标签，取其主要维度；
- 规则R02：同名实体在不同章中有不同侧面的描述时，以加权合并方式生成综合语义向量；
- 规则R03：隐含知识元以"IMPL-XXX"形式编号，在发现来源处标注原始文本位置；
- 规则R04：每个知识元的语义向量由以下字段构成——核心定义（50字以内）、时间区间、地理归属、所属主题域、在本卷中的重要性评级（1-5星）。

### L009 第三步：语义链接网络构建 —— 输出文件 02

基于语意分析结果，识别并标注知识元之间的七类语义关系，构建SLN。链接识别规则：

- 规则R05：因果关系（CAUSAL）的识别依据为原始文本中明示或暗示的因果链（"导致""促成""因为""由于""所以"等）；
- 规则R06：时序关系（TEMPORAL）的识别依据为确切的年代先后关系或阶段递进关系；
- 规则R07：功能相似（FUNC_SIM）的识别依据为马格林明确使用的跨时代类比（如"这种做法由……继承下来"）；
- 规则R08：链接强度按1-5标度计分：1=弱关联（顺带提及）、3=明确关联（有阐述）、5=强关联（反复强调且为核心论证）；
- 规则R09：来自不同章节但指向同一对知识元的链接，其强度以累积加权方式计算（加权系数=各章在本卷中的论据权重）。

### L010 第四步：知识涌现计算 —— 输出文件 03

基于SLN进行以下计算分析：

- 规则R10：**度中心度计算**——统计每个知识元节点的入度和出度，识别高中心度节点（前10%）；
- 规则R11：**中介中心度计算**——识别连接不同聚类的高中介性节点（桥知识元）；
- 规则R12：**社区检测**——基于模块度优化算法识别知识元聚类（知识簇），参数设定为分辨率1.0，最小簇大小≥5个节点；
- 规则R13：**时序演化分析**——将知识元按时间轴排列，分析链接密度的代际演变趋势；
- 规则R14：**涌现主题识别**——当一个知识簇的内部链接密度超过全局平均值两个标准差且跨章节覆盖率>30%时，判定为涌现主题；
- 规则R15：**断层识别**——在期望的知识链接密集区出现实际链接密度低于全局平均值一个标准差的情况，标记为知识断层/盲区。

### L011 第五步：知识发现报告 —— 输出文件 04

综合前述分析，撰写知识发现综合报告。报告结构：
1. 涌现主题与跨域连接发现
2. 核心知识枢纽（桥节点）的揭示
3. 本书知识结构的全局特征描述
4. 知识断层与潜在研究方向的提示
5. 与马格林自述方法论之间的对话
