# 00_方法与规则

## K001 知识涌现分析的定位与目标

本系列报告是对《Design: A Very Short Introduction》(Heskett, 2005)已有分析报告（00-NN，共13份）的**二阶知识处理**。分析报告完成了对原著的论证结构拆解、实体提取、逻辑重建和跨章关联标注；知识涌现分析则在此基础上执行以下工作：

1. **知识元提取与语意标注**：从分析报告中识别可独立操作的"知识元"，给出其语意类型、权重和激活条件。
2. **语义链接网络构建**：将离散的知识元编织为多层次的语义网络，度量链接强度、方向和类型。
3. **知识涌现计算**：对语义网络执行涌现计算——识别那些无法归约为其组成部分总和的涌现属性与高阶结构。
4. **知识发现报告**：基于涌现计算结果，生成原始分析报告未曾显式表述的新命题与洞察。

本分析的操作对象是**分析报告文本**（而非原著直接文本），这一选择基于以下理由：分析报告已完成了从英文原文到中文分析话语的转换、实体提取、论证结构重建——知识涌现分析以此为基础，可减少重复劳动，直接进入更高阶的知识整合层次。

## K002 知识元的定义与分类体系

### 知识元的定义

**知识元（Knowledge Unit, KU）** 是在论证系统中具有独立语意功能的最小知识单元。一个合格的知识元须满足以下条件：

- **原子性**：在其上下文中不可再分为更小的独立知识主张而不丧失意义。
- **可操作**：可以被链接、激活、加权、计算。
- **可溯源**：对应一个或若干个具体的分析报告L编号段落。
- **有方向**：在论证系统中承担特定的功能角色（前提/结论/证据/反驳/解释/假设）。

知识元不同于实体（人名、企业、产品）：实体是知识元的**载体或论据材料**，知识元是实体参与论证时产生的**认知操作单元**。例如，"Dieter Rams"是实体，而"Rams以'英式管家'隐喻表达退隐式功能主义"是知识元。

### 知识元分类体系

| 类型代码 | 类型名称 | 定义 | 示例 |
|---------|---------|------|------|
| DEF | 定义型 | 为一个概念提供内涵界定 | "设计是人类塑造环境以满足需求并赋予意义的独特能力" |
| PROP | 命题型 | 提出可验证或可论证的正面主张 | "设计史是层积过程而非线性更替" |
| RELA | 关系型 | 陈述两个或多个概念之间的逻辑关联 | "效用与意义构成分析形式的两个不可互相还原的维度" |
| CRIT | 批判型 | 对既有观点或实践的否定性评价 | "形式追随功能被窄化为纯实用效率" |
| CASE | 案例型 | 以具体实例为论证提供证据支持 | "日本牙签同时承载效用与意义" |
| META | 元方法型 | 关于方法本身的主张或规则 | "以设计者-使用者交互界面为分析框架" |
| DICH | 二分型 | 以对立范畴进行概念操作 | "图像=投射 vs. 身份=现实" |
| INFER | 推论型 | 从前述前提得出的逻辑推演 | "因此需要一种穿透混乱的本质定义" |
| PROP-ETH | 伦理命题型 | 带有规范性判断的主张 | "设计应服务90%世界人口而非仅富裕阶层" |
| STRUC | 结构型 | 关于组织形式、制度安排的描述 | "设计在企业中的位置呈中央化-分散化光谱" |

## K003 知识元的编号与溯源规则

### 编号体系

每个知识元分配唯一标识符：`KU-{类型代码}-{序号}`，例如 `KU-DEF-001`、`KU-PROP-042`。序号按在分析报告中的出现顺序排列。

### 溯源规则

每个知识元附带溯源字段，格式为：`来源: L{编号}@章{数字}`，例如 `来源: L011@章1`。若知识元跨多段落，则以 `+` 连接多个来源，例如 `来源: L012+L013+L015@章1`。

对于从多个章节聚合产生的合成知识元，以 `聚合源: [Lxxx@章x, Lyyy@章y]` 注明。

### 权重赋值规则

每个知识元的初始权重按以下公式计算：
- 出现频次（1-10分）：该知识元在全书中被反复申述的次数
- 跨章跨度（1-5分）：跨越的章节数
- 论证角色（1-5分）：前提(=5)、结论(=4)、反例(=3)、例证(=2)、旁注(=1)
- 概念创新度（1-5分）：是否为原创性概念

初始权重 = 频次 0.3 + 跨度 0.3 + 角色 0.2 + 创新度 0.2，标准化至 [0, 1] 区间。

## K004 语义链接的定义与分类

### 链接定义

语义链接（Semantic Link, SL）是两个知识元之间的有向有型连接。每条链接形式化为：

`SL(KU-a → KU-b, type=T, weight=w, source=Lxxx)`

### 链接类型

| 类型代码 | 名称 | 含义 | 方向 |
|---------|------|------|------|
| SUP | 支持 | KU-a 为 KU-b 提供证据或理由 | a→b |
| OPP | 反对 | KU-a 反对或削弱 KU-b | a→b |
| PRE | 前提 | KU-a 是 KU-b 的逻辑前提 | a→b |
| CONC | 结论 | KU-a 是 KU-b 的逻辑结论 | a→b（等价于 PRE 的逆） |
| ELAB | 细化 | KU-a 是对 KU-b 的细节展开 | a→b |
| INST | 实例化 | KU-a 是 KU-b 的具体例证 | a→b |
| ANA | 类比 | KU-a 与 KU-b 构成类比关系 | a↔b（双向） |
| DICH | 二分共构 | KU-a 与 KU-b 构成对立统一体 | a↔b（双向） |
| REIF | 具体化 | KU-a 在特定领域中具体化为 KU-b | a→b |
| EXT | 扩展 | KU-a 是 KU-b 在更大范围上的推广 | a→b |

### 链接强度

链接强度以 0 到 1 的连续值表示：
- 显式陈述（原文有明确逻辑连接词）：0.9-1.0
- 强暗示（缺少连接词但逻辑关系明确）：0.7-0.89
- 弱关联（需要上下文补充才能建立）：0.4-0.69
- 跨章呼应（不同章节间的主题重奏）：依相似度计算，0.3-0.8

## K005 语义网络的多层次架构

语义网络按三个层次组织：

### L1：章内网络

每章内部的知识元及其链接构成的子图。对应分析报告的各章 L 编号段落。L1 网络的边密度较高，链接主要为 SUP、ELAB、INST 类型。

### L2：跨章网络

跨越章节边界的知识元链接，包括：
- **同主题跨章链接**：同一知识元在不同章被再次引用/发展的实例（如 VW 甲壳虫在第 3 章和第 4 章的两次出现）
- **论证回旋链接**：后续章节对前文的再引用（如第 10 章对第 1 章"类本质能力"的回响）
- **结构对应链接**：不同章中相似论证结构之间的映射（如第 4 章的"设计者-使用者"框架与第 5-8 章的同一框架）

### L3：涌现层

超越单个链接之上的网络结构属性——模块性、中枢节点、桥接边、小世界属性等。L3 是知识涌现计算的直接对象。

## K006 知识涌现的操作定义

**知识涌现**指：在语义网络的特定结构条件下产生的高阶知识属性，这些属性无法通过阅读单个知识元或将其简单相加而获得，必须通过网络的整体结构计算才能显现。

涌现的四种主要形式：

| 涌现类型 | 定义 | 检测方法 |
|---------|------|---------|
| E1: 结构洞桥接 | 两个原本不连通的知识集群之间的意外连接 | 计算介数中心度，识别最高介数的边 |
| E2: 主题凝聚 | 多个分散知识元围绕一个隐式主题形成的无标度聚集 | 社区发现算法识别超越显式章节边界的知识簇 |
| E3: 矛盾张力 | 网络中存在的不可化约的二律背反 | 识别网络中双向OPP边集中区域 |
| E4: 空白推断 | 网络结构暗示应存在但实际缺失的知识元 | 基于图补全算法推断缺失节点 |

## K007 报告体例与L编号延续

本系列报告采用与原始分析报告兼容的 `L###` 编号体系，继续从 `K001` 开始编号，以区别于原报告中的 `L###` 编号段（L001-L104）。体例保持九节结构，但根据各报告的具体需求调整各节内容。

中文行文，章节标题以 `## K###` 标记。所有知识元、链接、涌现属性的标识符确保全文唯一可追溯。

## K008 数据来源与处理边界

### 输入端

- 分析报告 00_整体分析报告.md（L001-L009）
- 分析报告 01-10_各章分析报告.md（L010-L099）
- 分析报告 NN_专项报告与实体总索引.md（L100-L104）

### 不直接使用的数据

- 原著英文文本（除非通过分析报告的原文摘录间接引用）
- 分析报告未覆盖的外部文献

### 处理边界

- 不创造分析报告未包含的新实体
- 可以从分析报告的论证中推演出未显式陈述的隐含命题（E4 类型涌现），但须标注为"推断"并给出依据
- 对分析报告中的评价保持二阶距离——分析赫斯克特的论证方式，而非重复其观点
