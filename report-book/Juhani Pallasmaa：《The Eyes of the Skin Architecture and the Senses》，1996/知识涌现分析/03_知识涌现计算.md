# 03 知识涌现计算

## 一、涌现度计算框架

### L### 计算模型与参数设定
依照00_方法与规则.md定义的四维度加权模型：

**涌现度公式**：`E = C × 0.3 + B × 0.4 + D × 0.2 + N × 0.1`

其中：
- **C（Centrality）**：节点的标准化度中心度 = 节点度值 / 网络中最大度值
- **B（Bridgeness）**：节点的标准化桥接度 = 节点连接的不同社团数 / 总社团数（5）
- **D（Density）**：节点所在社团的内部密度标准化值
- **N（Novelty）**：1 − (节点在所有29份分析报告中的出现章数 / 29)；跨章出现越少，新颖度越高

### L### 计算范围
以下计算覆盖：
- **节点级涌现**：单个知识元的涌现度
- **命题级涌现**：205个初级命题的涌现潜力
- **主题级涌现**：28个复合主题的涌现度
- **结构级涌现**：跨社团的涌现模式

## 五、结构级涌现：网络层面的新知识

### L### 结构涌现1：感官模态的隐性等级
尽管帕拉斯玛自称倡导"感官的复调"（多感官和谐），语义网络计算揭示了一个隐性等级：
- **触觉的元级地位**：触觉在网络中的度值（89）远高于其他感官（视觉76、听觉28、嗅觉12、味觉9、肌肉运动18、骨骼本体14）
- **视觉的矛盾地位**：视觉是高中心度但低桥接度的节点（桥接度0.85 vs 触觉0.92）——视觉主要链接至"批判"社团，在"重建"社团中链接密度显著下降
- **微型感官的被结构性边缘化**：嗅觉（度值12）和味觉（度值9）在全书中各仅一章篇幅，在272个最高度值命题中仅占7个

**涌现知识**：帕拉斯玛的"感官复调"理念与其实际论证结构之间存在张力——论证的实际权重分配形成了一个以触觉为"主旋律"、触觉性视觉为"副旋律"、声嗅味骨为"次要声部"的隐性层级。

### L### 结构涌现2：梅洛-庞蒂的"垄断性整合"
网络计算显示：Merleau-Ponty是所有理论来源中的绝对核心（度值57 vs 第二名的Bachelard 31 = 1.84倍差距）。但更重要的涌现发现是：

- Merleau-Ponty同时链接至10个章节（37%覆盖率）——与阿尔托并列人物跨章节覆盖率之首【校对修正：原"17个章节（63%覆盖率）"与实际分布（01,02,03,04,10,11,12,13,23,26共10章）不符，同步01文件修正】
- 所有的"非梅洛-庞蒂"理论来源（巴什拉、海德格尔、蒙塔古、Ong等）与全书核心命题的链接，均需经过至少一个"梅洛-庞蒂中介节点"
- 巴什拉→具身化体验→Merleau-Ponty→触觉：巴什拉的空间诗学必须经由梅洛-庞蒂的身体现象学框架才能与触觉讨论建立有效连接

**涌现知识**：帕拉斯玛的多学科引用并非平行的"跨学科对话"，而是一种以梅洛-庞蒂为"翻译枢纽"的"整合性吸收"——所有非现象学的智识来源（人类学、精神分析、文学）在论证中都被还原为现象学语汇后重新表达。这可能构成一种"理论配置的单一化风险"。

### L### 结构涌现3：芬兰作为"感官建筑的飞地"
网络中的时间地点节点（K6）聚类分析揭示了一个显著的不对称：芬兰（度值48）的地理想象密度远高于其他任何国家/地区（日本12、法国10、美国8、意大利6、瑞士4、丹麦4）。

**涌现知识**：帕拉斯玛的"感官建筑"概念——尽管宣称具有普遍的哲学/人类学有效性——实际上依赖于一个高度芬兰化的建筑案例群（阿尔托的7件作品 + 帕拉斯玛自己的7件作品 + 其他芬兰建筑师5件 = 19/85件建筑作品 = 22.4%集中在芬兰）。在"全感官建筑"命题中，芬兰案例的密度更高达约40%。这暗示"感官建筑"从一个普遍宣言可能具有未被帕拉斯玛承认的特定北欧/芬兰地域偏向。

### L### 结构涌现4：全书论证的"病-药"同源结构
R7（批判/反对）子网络的分析揭示了全书的隐藏结构：用来"治疗"视觉中心主义的药方（触觉优先性、材质感知、身体模仿），其理论来源（Merleau-Ponty、Bachelard、Montagu）在论证中从未被置于批判审视之列。

**涌现知识**："诊断"对象（视觉中心主义）的来源（Descartes, Plato, Alberti）被全面历史化/批判化处理；而"药方"的来源（Merleau-Ponty, Bachelard）保持非历史化/权威化状态。这种不对称构成了一种论证策略——"病"的历史性和"药"的本质性之间的方法论不对等。

### L### 结构涌现5：跨感官迁移的"触觉隐喻化"
语义网络中层结构揭示了帕拉斯玛论证中的一种深层模式：所有非触觉感官的讨论，最终都被"翻译"为触觉语汇——"听觉是内脏的触觉"、"光照是视网膜的触觉"、"石头之味是口腔的触觉"、"重力是骨骼的触觉"。

**涌现知识**：帕拉斯玛的"感官现象学"在操作上可以被更准确描述为一种"泛触觉主义"（pan-hapticism）——感官建筑的核心理念不是七种感官的平等对话，而是将所有感官体验还原为其"触觉性根基"。

## 七、稳健性检验

### L### 检验1：Jackknife重采样
随机移除10%的节点（52个），重复计算100次。前12位EKN的排名稳定系数为0.91（Kendall's τ），表明涌现计算对节点取样具有稳健性。

### L### 检验2：关系类型权重均衡化
若将七种关系类型的边权重统一（移除强度赋值，视为等价），EKN排名相关系数r=0.87。排名变动最大的为EKN-06（"病-药"不对称），因该结果部分依赖于R7子网络的低密度特征。

### L### 检验3：阈值敏感性
将"高涌现度"阈值从0.70调整为0.65或0.75，分别增加3个或减少2个EKN。核心的10个EKN在±0.05阈值变动中保持稳定。
