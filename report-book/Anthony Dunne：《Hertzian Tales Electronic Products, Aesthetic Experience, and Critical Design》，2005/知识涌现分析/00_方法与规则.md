# 00 方法与规则

## 一、任务定位

### L001 分析目标

本文件夹（知识涌现分析）是在已有的"分析报告"（对原著及其章节的系统知识分解）基础上进行二阶分析。分析报告已将邓恩的著作分解为175个以L###编号标识的知识单元（knowledge units），涵盖全书论点、论据、概念、方法、案例、实体索引等维度的结构化信息。本分析的任务是：

1. **语义分析**：对175个知识元进行语意分类、密度测量、核心-边缘判定
2. **链接网络建构**：识别知识元之间跨章节、跨维度的语义链接，构建网络拓扑
3. **涌现计算**：通过网络分析和中心性测量，识别知识涌现热点和未言明的结构性发现
4. **知识发现**：提炼超出原著字面内容、基于知识网络结构产生的"涌现性洞察"

### L002 知识涌现的定义

**知识涌现（Knowledge Emergence）**指：当足够数量的知识单元通过语义链接构成网络时，网络结构本身产生超出单个知识单元之和的新信息。它表现为：

- **结构性发现**：知识元之间的链接模式揭示了原著未明确陈述的逻辑关系
- **未言明的对位**：跨章节的知识元配对揭示了隐含的理论对应/对抗关系
- **概念谱系的自动浮现**：通过链接追踪自动重建概念在全书中的传播和变形路径
- **知识缺口检测**：网络中的稀疏区域/孤立节点揭示了原著的论证盲区

### L003 工作流程

```
分析报告（175个L###知识元 + 实体总索引）
          │

   └──────┬───────────┘

          ▼
   ┌──────────────────┐
   │ 02_语义链接网络    │ ← 跨章链接、谱系、对位
   └──────┬───────────┘
          │
          ▼
   ┌──────────────────┐
   │ 03_知识涌现计算    │ ← 中心性、热点、缺口
   └──────┬───────────┘
          │
          ▼
   ┌──────────────────┐
   │ 04_知识发现报告    │ ← 综合性涌现洞察
   └──────────────────┘
```

## 二、知识元的定义与分类规则

### L004 知识元的操作性定义

在分析报告中，每个以L###编号标记的条目即为一个"知识元"。它可以是：
- 一个论题（如L001全书总命题）
- 一组举证（如L004关键案例表）
- 一个方法论描述（如L003方法论框架）
- 一个结构分析（如L001章节结构板块）
- 一组实体清单（如L013核心人物）
- 一段论证链（如L005论证主链）
- 一个关联分析（如L020与导论的关联）

### L005 知识元的六维分类体系

每个知识元根据其语义功能归入以下六类之一：

| 类别代码 | 类别名称 | 定义 | 典型L###示例 |
|----------|----------|------|-------------|
| K-THESIS | 论点元 | 表达核心主张、子命题、论证结论 | L001全书总命题、各章L002核心论题 |
| K-STRUCT | 结构元 | 描述论证的框架、板块、推进顺序 | 各章L001章节结构、L004论证主链 |
| K-METHOD | 方法元 | 描述研究/论辩/阐述的方法策略 | L008论证方法特征、各章L008/L009论辩方法 |
| K-EVID | 证据元 | 列举案例、作品、文献、人物等实体 | 各章L003关键案例、L014-L019实体清单 |
| K-CONCEPT | 概念元 | 定义或阐述核心/派生概念术语 | L014核心概念术语、各章L015/L016概念 |
| K-LINK | 关联元 | 描述章节之间、概念之间的关系 | 各章L018-L022与前后章关联 |

### L006 知识元的编号继承规则

分析报告中的L###编号为原始编号，本分析中以 `[L###]` 形式引用。具体规则：
- 全书性知识元：`[00_L001]` 至 `[00_L020]`
- 章节性知识元：`[C1_L001]` 至 `[C7_L020]`（C1-C7对应第1-7章）
- 专项报告知识元：`[NN_L100]` 至 `[NN_L109]`
- 总计175个知识元（与NN_L108的统计一致）

## 三、语义链接的建立规则

### L007 链接类型体系

知识元之间可建立以下六种语义链接：

| 链接类型 | 符号 | 定义 | 示例 |
|----------|------|------|------|
| 继承链接 | →inh | 知识元B在逻辑上继承/展开知识元A | [C1_L001]→inh[C2_L001]（后最优→后最优的人因） |
| 支撑链接 | →sup | 知识元B提供证据或方法支撑知识元A | [C2_W03]→sup[C2_L003]（案例支撑论点） |
| 对位链接 | ↔ctp | 两个知识元形成概念对位/镜像关系 | [C6_L002]↔ctp[C1_L002]（赫兹物质性↔符号性） |
| 翻译链接 | →trs | 知识元B将知识元A从一领域翻译到另一领域 | [C2_L006]→trs[C2_L009]（Shklovsky文学理论→设计方法论） |
| 预伏链接 | →fsh | 知识元A为后续章节的知识元B做预伏 | [C3_L020]→fsh[C6_L001]（赫兹病理学→赫兹空间） |
| 矛盾链接 | ↔ctd | 两个知识元之间存在张力或矛盾 | [C7_L009_Electroclimates"失败"]↔ctd[C5_L002_异托邦策略] |

### L008 链接的加权规则

| 链接特征 | 权重加成 |
|----------|----------|
| 跨章节链接（涉及不同章节的知识元） | +1 |
| 跨维度链接（涉及不同类别，如论点元↔证据元） | +1 |
| 跨领域链接（涉及不同学科来源） | +1 |
| 密集交叉引用（同一对知识元在原文中多处互指） | +2 |
| 邓恩自我标注的链接（邓恩明确指出的关联） | +2 |
| 隐式链接（本分析首次揭示、原文未明确陈述） | +3 |

### L009 链接抽取的操作规程

1. **显式链接**：从各章L018-L022（与前后章关联）中直接提取
2. **概念追踪链接**：对每个核心概念（C001-C049），追踪其在全书各章的出现和变形，建立跨章概念链接
3. **人物追踪链接**：对高频人物（P001-P067），追踪其在不同章节中的角色演变
4. **论证对位链接**：识别不同章节中论证方法的对应/呼应关系
5. **隐式发现链接**：通过交叉对比发现原文未明文陈述的链接

## 四、知识涌现的计算规则

### L010 中心性计算指标

| 指标 | 公式概念 | 含义 |
|------|----------|------|
| 度中心性（DC） | 与节点直接相连的链接数 | 知识元在论证网络中的直接影响力 |
| 介数中心性（BC） | 经过节点的最短路径数 | 知识元作为"桥梁"的中介作用 |
| 特征向量中心性（EC） | 与高中心性节点相连的加权度 | 知识元的"枢纽"地位 |
| 跨章中心性（CC） | 跨章节链接的密度 | 知识元的跨章整合能力 |

### L011 知识涌现热点的判定条件

一个知识元或一个知识元集群被判定为"涌现热点"，需满足以下至少三项条件：

1. 度中心性高于全网络平均值的1.5个标准差
2. 介数中心性排名前10%
3. 至少连接3个不同类别（K-THESIS/K-STRUCT/K-METHOD/K-EVID/K-CONCEPT/K-LINK）的知识元
4. 至少连接4个不同章节的知识元
5. 在多个隐式链接中充当枢纽

### L012 知识缺口的判定条件

一个区域被判定为"知识缺口"，需满足以下至少两项条件：

1. 某个类别在某些章节中知识元密度低于平均值的50%
2. 两个应有链接的主题域之间没有或极少有知识元链接
3. 原著自我反思中明确指出的"未竟之处"在网络结构中体现为孤立或稀疏节点
4. 概念术语的使用频率在全书分布极不均匀（集中于一章而其余章节为零）

### L013 涌现度指标

全书知识网络的"涌现度"用以下综合指标衡量：

- **网络密度** = 实际链接数 / 最大可能链接数
- **聚类系数** = 局部三角闭合程度
- **模块度** = 知识元自然分群的清晰度
- **涌现增益** = 隐式链接数 / 显式链接数（越高表示越多的结构性发现）

## 五、分析输出规范

### L014 编号体系

本分析延续使用L###编号，与前序分析报告的编号独立。编号规则：

- `00_L001` 至 `00_L0XX`：00_方法与规则
- `01_L001` 至 `01_L0XX`：01_知识元语意分析
- `02_L001` 至 `02_L0XX`：02_语义链接网络
- `03_L001` 至 `03_L0XX`：03_知识涌现计算
- `04_L001` 至 `04_L0XX`：04_知识发现报告

### L015 引用格式

- 引用分析报告的知识元：`[分析报告/章节缩写_L编号]`，如 `[分析报告/C1_L003]`
- 引用实体：`[实体/编号]`，如 `[实体/C001]` 指概念"后最优对象"
- 引用本分析内的知识元：`[本分析/L编号]` 或直接 `[L编号]`

### L016 中文写作规范

- 全中文行文，术语保留英文对照（首次出现时标注）
- 表格使用中文列名
- L###编号保持大写英文字母格式
- 使用"→inh"等链接符号时保留英文缩写但上下文用中文说明
