# NN_专项报告与实体总索引

## 专项报告一：跨章节方法论脉络

### L1 方法论总览

本书的核心方法流程（第3-8章）可以用以下公式概括：

```
策略(Strategy) + 研究(Research) + 分析(Analysis) + 构思(Ideation) + 细化(Refinement) + 执行(Execution) = 设计流程
```

### L2 方法论谱系

| 阶段 | 章节 | 核心操作 | 关键产出物 | 不可跳过原因 |
|------|------|----------|-----------|-------------|
| 策略 | Ch3 | 框定问题→差异化→路线图 | 设计简报、竞品分析、产品路线图 | 避免解决错误的问题 |
| 研究 | Ch4 | 观察→访谈→活动→自报告 | 田野笔记、照片、录音录像 | 避免为想象的用户设计 |
| 发现 | Ch5 | 物理化→聚类→分析→模型化 | 概念模型、persona、对齐图表 | 避免数据淹没而无法指导设计 |
| 构思 | Ch6 | 发散→组织→原则筛选 | 概念方案、设计原则 | 避免只产生一个方案 |
| 细化 | Ch7 | 约束面对→法则应用→文档化 | 线框图、服务蓝图、任务流程 | 避免概念无法执行 |
| 执行 | Ch8 | 原型→测试→迭代→开发 | 原型、测试报告 | 避免交付不可用的产品 |

## 专项报告二：跨章节主题演进

### L1 "用户"概念的演进

| 章节 | "用户"的内涵 |
|------|-------------|
| Ch1 | 抽象的用户——交互设计的受益者/受害者 |
| Ch2 | 方法中的用户——UCD的中心/ACD的执行者/系统设计的目标设定者/Genius Design的验证者 |
| Ch3 | 市场中的用户——待细分的目标群体 |
| Ch4 | 可研究的用户——可观察/访谈/与之互动的真实人 |
| Ch5 | 被模型化的用户——persona（行为/动机/期望的合成体） |
| Ch6 | 灵感来源的用户——persona驱动构思 |
| Ch7 | 约束中的用户——用户需求是九类约束之一 |
| Ch8 | 测试中的用户——设计假设的验证者/纠正者 |
| Ch9 | 未来的用户——面临隐私侵蚀/去技能化风险的人 |
| Epilogue | 负有责任的对象——神圣信托的受益者/被迫用户 |

### L2 "行为"概念的演进

| 章节 | "行为"的内涵 |
|------|-------------|
| Ch1 | 交互设计的本质——"interaction design is about behavior" |
| Ch2 | 方法论的焦点——UCD关注用户行为目标，ACD直接关注行为本身 |
| Ch3 | 差异化的载体——Flip Video基于"视频传输行为"而非"拍摄行为"差异化 |
| Ch4 | 研究的目标——"他们说什么"与"他们做什么"的差异 |
| Ch5 | 被模型化的原材料——patterns of behavior |
| Ch7 | 被设计的具体对象——通过affordance/feedback/mapping塑造用户行为 |
| Ch9 | "设计溶解于行为"——Greenfield/Fukasawa的理想状态 |
| Epilogue | 被伦理审视的对象——设计促成的行为是否道德 |

### L3 "约束"概念的演进

| 章节 | "约束"的呈现方式 |
|------|------------------|
| Ch1 | 隐性——"设计需要解决特定问题在特定环境下" |
| Ch2 | 被方法选择所隐含——UCD受限于用户样本，ACD受限于对技能的尊重 |
| Ch3 | 外显的——通过利益相关者访谈主动发现和记录约束 |
| Ch7 | 全面展开——九类约束：时间/资金/技术/商业/用户/情境/工具/团队/自身 |
| Ch8 | 被突破——原型可以在有限范围内"突破规则"，但最终开发必须尊重约束 |

## 编后记

本索引覆盖《Designing for Interaction: Creating Innovative Applications》第二版（2009）全书的引言、九个章节和尾声共11个文本单元的分析报告。

索引编制原则：
- 人物实体：与交互设计学科直接相关的历史人物、学者、从业者（≥3/每类/每章）
- 产品/服务实体：书中作为案例或参照的具体产品与服务（≥3/每类/每章）
- 概念/理论实体：书中定义、引用或展开的理论概念（≥3/每类/每章）
- 方法/工具实体：书中描述的具体设计方法、研究技术、操作工具（≥3/每类/每章）
- 组织/机构实体：书中提及的公司、学校、设计机构（≥3/每类/每章）
- 文献/著作实体：书中引用或推荐的书籍与论文（≥3/每类/每章）

所有实体均标注其出现章节，便于跨章追溯。中文名保留原文英文，以避免翻译歧义。
