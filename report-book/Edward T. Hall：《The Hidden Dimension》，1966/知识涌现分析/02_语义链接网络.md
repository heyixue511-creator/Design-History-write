# 02_语义链接网络

## LK0201 网络构建方法论

### LK0201-01 节点与边的定义
本语义链接网络以95个知识元（详见01文件）为节点，以10类语义链接为有向加权边。每条边携带链接类型标签和强度值（1-5）。

### LK0201-02 构建过程
1. 对95个知识元进行两两关系审查（95×94/2 = 4465对）
2. 对每一对知识元判断是否存在10类语义链接中的至少一类
3. 为每条识别出的链接分配强度值并记录理据
4. 排除自循环（self-loop）和冗余链接
5. 产出链接矩阵和社区结构

### LK0206-02 涌现三角检测
以下三元组在原始分析报告中未被显式陈述，但在语义链接网络中被识别为形成了闭合三角：

**涌现三角1：制度性失败的三位一体**
```
KU-03-T01（建筑制度失败）──ISO── KU-04-T01（制作制度失败）
      │                                    │
      └──────────── ISO ──────────────────┘
                      与

```
原始分析中，03报告讨论了建筑制度批评，04报告讨论了工艺-设计的制度性忽略，NN报告讨论了法律系统的个体化倾向——但三者之间的同构关系未被显式陈述。此三角闭合产生新命题：**建筑、工艺和法律共享一种"结构性缺陷个体化"的制度逻辑**。

**涌现三角2：behavioural sink的跨域映射**
```
KU-03-T02（空间限制→病态行为）──ANA── KU-04-T02（工艺模式二分）
      │                                    │
      └──────────── EXT ──────────────────┘
                      与
              KU-NN-T02（空间是不可化约变量）
```
原始分析中，behavioural sink被作为生物学和建筑学概念讨论，certainty/risk二分法被作为制作哲学概念讨论——但两者在"限制条件导致结果变异"这一结构上的同构未被注意。此三角闭合产生新命题：**"有限空间中的行为变异"与"确定性/风险性工艺中的结果变异"存在深层结构同构——两者均涉及约束条件与结果自由度之间的张力**。

## LK0207 关键链接的强度理据

### LK0207-01 高强度链接的理据示例

**SL-KU-03-T01>KU-04-T01-ISO4**
理据：两者均描述一种权力-知识不对称的结构性失败——在建筑中表现为"出资者不理解人的需求"，在工艺中表现为"设计话语忽视工艺的独立审美价值"。失败的结构逻辑相同（上层决策者系统性忽略下层执行/使用维度的关键因素），施加的领域不同。

**SL-KU-03-T02>KU-NN-T02-CAU4**
理据：Calhoun实验的核心发现（资源充足下空间限制仍导致病态行为）直接蕴含了"空间是不可化约的独立变量"这一结论——后者是前者的概念化表述。

**SL-KU-03-R01>KU-NN-R01-EXT5**
理据：NN报告中的跨学科迁移路径（动物行为学→人类学→设计批评→环境心理学）实际上就是KU-03-R01所描述的Calhoun→Hall迁移的扩展版本——前者是后者的完整展开。

### LK0207-02 低强度链接的理据示例

**SL-KU-02-R02>KU-04-R02-EXT2**
理据：Goldring的计算机视觉论文与Pye的certainty/risk二分法的关联依赖于一个中介推理——计算机生成影片既是"确定性工艺"产品（算法输出），又可能通过随机参数产生"自由"审美效果。这一推理链条较长，强度为2。

**SL-KU-01-M01>KU-03-M01-CON2**
理据：Jopling的"零外部引证"论证模式与Hall的"多外部引证"（Calhoun实验+新闻事件）论证模式形成对比——但这种对比并非原始分析所强调，而是本网络分析的后见之明，强度为2。
