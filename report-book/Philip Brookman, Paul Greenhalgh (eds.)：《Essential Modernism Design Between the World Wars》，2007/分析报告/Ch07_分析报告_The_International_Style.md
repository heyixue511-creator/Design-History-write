# Ch07_分析报告：The International Style（国际风格）

**行号范围**：L172-223
**全书功能**：全书枢纽章。以 1932 年 MOMA 展览与 Hitchcock/Johnson 图录为"命名事件"，界定国际风格的形式特征（简化、体量、空间流动、去装饰），并延伸至"建筑的根本新态度"（Gropius/Le Corbusier 的机器论）与"大众建造"（魏森霍夫、社会住宅、标准化）——是全书的建筑与历史坐标中心。

---

## 一、章节定位与功能

本章完成四项任务：
1. **命名**：1932 年 MOMA 展《国际风格：1922 年以来的建筑》为现代建筑"定名"并介绍给美国公众（L175-179）；
2. **界定**：给出国际风格的四大特征（L188-191）；
3. **深化**："建筑的根本新态度"——Gropius 与 Le Corbusier 的机器/大众命题（L197-204）；
4. **落地**："大众世纪的大规模建造"——魏森霍夫住宅展、标准化住宅、工人住房（L206-223）。

## 三、内容分析

### 1. 命名事件（L175-181）
- 1932 年纽约 MOMA 举办里程碑式展览，详述 1922 年以来国际建筑进展（L175）；
- 由 **Philip Johnson**（MOMA 建筑与设计部创始主任）组织，把现代建筑介绍给美国公众（L176）；
- 展览把 Le Corbusier、Gropius、Rietveld、Mies 等实践者归组，重新定义现代主义（L177）；
- 图录名《国际风格：1922 年以来的建筑》（L178）；Johnson 与合著者 **Henry Russell Hitchcock** 写道："今天一种单一新风格已存在……"（L179-181）。

### 2. 风格特征（L188-193）
- 最共同的特征：**形式的简化、看重体量而非质量（volume rather than mass）、空间流动而非对称**（L188）；
- 关注建筑/物品的内部结构，**拒绝建筑装饰**（L189）；
- **玻璃立面与开放内部空间**创造"既工业又几何的透明性"（L190）；
- 设计常**强调功能胜于形式**，朝向涵盖社会需求与社区发展的美学（L191）；
- Mies 弗里德里希大街摩天楼实例：钢骨架使外墙摆脱承重功能，以全玻璃表面"非物质化"建筑体积、透射与反射光线（L192-193）。

### 3. 悖论（L194-195）
- 这些特征被识别为一种"风格"本身，与典型的现代主义"对规则的怀疑"相矛盾（L194）；
- 但建筑设计关联工业生产与新技术，使领先实践者构建服务于"社会议程"（廉价实用的住宅与工作空间）的方案（L195）。

### 4. 建筑的根本新态度（L197-204）
- **Walter Gropius** 帮助联结视觉艺术、建筑、设计与工艺运动，强调艺术与工业的新关系（L198-199）；
- 1925 年著作《国际建筑》（Internationale Architektur）:"**一种根本性的建筑新态度正在所有文化中同时涌现**"（L200）；
- 1925 年迁德绍后 Gropius 设计不对称的玻璃包裹工业感建筑群（1926 年完成），整合工作室、生产、居住、管理（L200-202）；
- 引文："**包豪斯相信机器是我们现代的设计媒介**，并寻求与之和解"（L203）；
- 同时 Le Corbusier 宣告"住宅是居住的机器"（L204）。

### 5. 大众建造（L206-223）
- 国际风格的社会哲学导向**大批量/大规模工人住房**（L207）；
- 例：Le Corbusier《Citrohan II 住宅》（1922）为标准化、预制住宅设计（L210）；
- **魏森霍夫住宅展**（1927，斯图加特）由多位现代主义建筑先驱设计（Mies、Bruno Taut、Peter Behrens、Le Corbusier、J.J.P. Oud、Gropius）（L211-213）；展出从低收入到中产多种住宅，实验新技术、新材料、开放平面与预制构件（L214）；"乌托邦理想既被赞扬也被批评——这是如此多样的先锋建筑首次公开受审视"（L215）；
- 1920 年代末国际风格成为现代主义建筑的主导路径，影响遍及欧洲（L218），在荷兰、苏联、瑞典、芬兰、意大利留下丰富遗产（L219）；
- 对美国建筑也至关重要：维也纳建筑师 **Rudolf Schindler、Richard Neutra** 移居美国，受 Frank Lloyd Wright 启发发展实验（L220）；
- Aalto《堆叠凳》（1929-30）以"弯曲椅腿同时作垂直与水平支撑"为特色，1930s 可批量生产（L221-223）。

## 六、论辩与阐述方法

1. **命名事件框架**：把"国际风格"当作一个历史命名事件（MOMA 展）而非抽象美学，体现"接受史"意识（L175-181）；
2. **内部悖论揭示**：坦诚指出"风格"标签与反规则姿态的矛盾（L194）；
3. **社会议程论证**：把风格特征（功能/简化）关联到大众住房的社会哲学（L191、L195、L207）；
4. **双人引文对勘**：Gropius 与 Le Corbusier 在同一时期表述同一机器命题（L203-204），证明"根本新态度在所有文化中同时涌现"（L200）。
