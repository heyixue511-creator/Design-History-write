## 二、中介中心性（BC）计算

### L### 2.1 计算方法

BC计算基于SLN中298个节点和约1,250条链接。使用Brandes算法（未归一化值）。所有链接被视为无向以计算最短路径。

```
BC(KE) = Σ(s≠t≠KE) σst(KE) / σst
```

其中σst是节点s和t之间的最短路径总数，σst(KE)是经过KE的最短路径数。

## 三、聚类密度差（CDD）计算

### L### 3.1 计算方法

对五个社区（C1-C5）在七个维度上计算知识元密度：

```
Density(Community, Dimension) = (社区中该维度的知识元数) / (社区总节点数)
CDD(A, B, Dimension) = |Density(A, Dimension) - Density(B, Dimension)|
```

七个分析维度：

| 维度代码 | 维度名称 | 包含的知识元类型 |
|----------|----------|-----------------|
| DIM-ECO | 经济/商业维度 | P-1系列, M-0/1系列中经济机制, C-1系列中经济案例 |
| DIM-POL | 政治/制度维度 | P-2系列, M-0系列中政治机制, C-1系列中政治案例 |
| DIM-SOC | 社会/结构维度 | 社会模仿相关, 阶层分析, 社团组织 |
| DIM-CUL | 文化/心态维度 | P-3系列, M-0系列中心态机制, N-0系列心态概念 |
| DIM-CASE | 案例密度 | C类知识元 |
| DIM-CONC | 概念密度 | N类知识元 |

### L### 3.4 关键空白投影详解

**空白投影1：政治商业化的心态基础（C2 DIM-CUL 密度仅0.05）**

Brewer的政治分析聚焦于制度-组织层面（信用、社团、政治动员），但几乎不讨论心态层面：Wilkes的支持者为什么愿意购买"政治商品"？这是一种什么性质的心态——是意识形态认同、社会归属还是时尚模仿？这一空白因C4中Plumb对"现代性接受"的详细论证而更加显眼——如果"改善"的心态可以从育种扩展到消费，为什么不能从育种扩展到政治？

**空白投影2：儿童消费市场的经济规模（C4 DIM-ECO 密度仅0.15）**

Plumb对儿童世界的分析是丰富的文化和心态史，但缺乏McKendrick式的经济量化。Newbery的Tom Telescope卖了25,000-30,000册——这在18世纪图书市场中意味着什么？儿童书籍市场的总规模、增长率、与成人书籍市场的比例——这些McKendrick在Ch.1中对茶叶和印花布做了但Plumb在Ch.7中没有对儿童商品做的经济分析——构成了一个"应有但无"的空白。

**空白投影3：休闲商业化的政治维度（C3 DIM-POL 密度仅0.03）**

休闲在Plumb的论证中是"去政治化"的——但Brewer在Ch.5中证明俱乐部/社团既是休闲组织也是政治组织。Plumb的流通图书馆、音乐节和Brewer的共济会会所、Wilkes集会之间存在组织的连续性——但休闲消费的政治维度（如流通图书馆中的政治读物、音乐节中的政治宣传）在SLN中几乎没有对应的知识元。

## 四、矛盾张力指数（CTI）计算

### L### 4.1 计算方法

```
CTI(KE₁, KE₂) = Affirmation_Strength(KE₁) × Affirmation_Strength(KE₂) × Logical_Distance(KE₁, KE₂)
```

其中：
- Affirmation_Strength：知识元在分析报告中的确证强度（1-5，1=微弱推测，5=充分确证）
- Logical_Distance：两个命题在逻辑空间中的距离（0=完全同义，1=逻辑矛盾）

### L### 4.3 核心矛盾深度分析

**矛盾1（CTI=14.40）：消费民主化——解放还是新控制？**

```
命题A（McKendrick/P-102）：消费从精英特权转变为大众权利——"前所未有的大量人口进入了体面品乃至奢侈品的消费范围"。
命题B（Plumb/P-309）：童年的"新世界"伴随着规训的强化和性恐怖的兴起——"童年变得更灿烂，但也更黑暗"。

逻辑距离 0.72：两个命题都高度确证（AS=5和4），但它们暗示了对同一过程（消费民主化）的截然相反的道德评价。
A暗示的是解放叙事（从前只有精英能消费→现在大众也能消费=进步），
B暗示的是控制叙事（新的消费伴随着新的规训和恐怖=新的压抑形式取代了旧的物质匮乏）。

这是一个未解决的深层张力：消费社会是使人们"更自由"还是"以新的方式被控制"？
```

**矛盾2（CTI=16.25）：谁在驱动消费革命——商人还是消费者？**

```
命题A（McKendrick/P-003）：商业化——即有意识的营销、广告、时尚操纵和需求创造技术——积极驱动社会与经济转型。
命题B（McKendrick/P-116）：Wedgwood书信中直言"时尚无限优于品质"——消费者不是选择最好的产品，而是追随被赞助和代言的产品。

逻辑距离 0.65：如果需求由供给方"积极创造"，那么消费者"选择"在多大程度上是真正的"选择"？
McKendrick既论证了(1)企业家是消费社会的"助产士"（供给驱动），又承认了(2)社会模仿是消费扩展的"核心动力"（需求驱动）。
但这二者之间的关系——到底是供给在先还是需求在先？是制造了真需求还是制造了虚假需求？——在全书论证中始终模糊。
Plumb的"现代性接受"命题（P-314）为该矛盾提供了一种可能的解决：心态的深层转变是需求侧的基础，
而商业操纵则是供给侧的手段——前者是后者得以生效的"心态土壤"。
```

**矛盾3（CTI=10.40）：阶层接近性的双重性质**

```
命题A（McKendrick/P-105）：英格兰"紧密层叠"的社会结构为消费向下扩散提供了理想条件（正面）。
命题B（Brewer/P-202）：客户经济使中等阶层商人处于对贵族的依赖和脆弱状态（负面）。

逻辑距离 0.52：两个命题指向同一结构特征（阶层接近性）的截然相反的两种效应。
McKendrick看到的：阶层接近→模仿容易→消费快速扩散=经济增长的正反馈。
Brewer看到的：阶层接近→信用依赖→经济脆弱→政治不满=社会矛盾的负反馈。
二者的并存意味着"紧密层叠的社会结构"是一把双刃剑——它同时驱动了消费繁荣和社会矛盾。
而这正是消费社会的"结构性张力"——消费的民主化与权力的贵族化在同一社会结构中共存。
```

## 五、综合涌现指数（CEI）计算

### L### 5.1 CEI公式

为集成四个维度的涌现信号，定义综合涌现指数：

```
CEI(KE) = w₁ × NormC³(KE) + w₂ × NormBC(KE) + w₃ × NormMaxCDD(KE) + w₄ × NormMaxCTI(KE)
```

权重设置：w₁=0.25, w₂=0.35, w₃=0.25, w₄=0.15（BC权重最高，因桥接效应是涌现的最可靠来源）

## 六、涌现发现的优先级排序

### L### 6.1 第一优先级（已确定涌现，证据完整）

1. **"社会模仿"的统摄性与盲区**（CEI 0.854, 0.751）：社会模仿作为全书跨章最广的机制，其仅被用于解释积极消费扩散——作为恐慌、规训和压抑传播机制的"负面模仿"是最大的理论空白。
2. **消费民主化的结构性矛盾**（CEI 0.763, 0.671）：消费的扩展同时带来了解放（更多人能消费）和控制（新的规训体系），这一矛盾在Plumb的"童年双面性"中表现最为尖锐。
3. **商业化技术的跨领域可移植性**（BC高, CDD高）：McKendrick在Ch.2-4中系统归纳的商业化技术工具箱在Plumb的休闲/教育领域几乎未被应用——这究竟是历史事实（休闲领域确实没有类似的商业化技术）还是分析空白？

### L### 6.2 第二优先级（强涌现信号，需更多分析）

4. **政治商业化的心态条件**（CDD 0.37）：Brewer论证政治商业化但未讨论其心态基础——如果消费社会需要"现代性的接受"，那么政治消费主义需要什么样的心态条件？
5. **"改善"意识形态的跨领域贯通**（CEI 0.698）：Plumb的"改善"（improvement）概念是全书最深层的统摄性概念——育种中的改善、消费中的改善、政治中的改善（"改善你的社会地位"）是否拥有共同的日常实践基础？
6. **"支出作为上升和弦"的多维展开**（CEI 0.671）：Plumb将"支出"标记为资本主义的上升和弦——这个命题在McKendrick的经济论证和Brewer的政治论证中是否有对应物？

## 七、计算过程的方法论反思

### L### 7.1 计算的局限性

1. **网络构建的主观性**：SLN中的链接由分析者基于对分析报告的理解手动构建，链接的存在及其强度标注均受分析者判断影响。
2. **C³的粗粒度**：C³以"分析报告"为单位计算跨章次数，忽略了同一章内不同段落之间也可能存在重要关联。
3. **CTI的定性成分**：逻辑距离（LD）的赋值为定性判断，未经验证者间信度检验。
4. **CDD的阈值选择**：0.25的显著密度差阈值是基于分布的经验选择，缺乏理论推导。

### L### 7.2 计算的可靠性

尽管存在上述局限，四个维度的涌现计算产生的结果具有良好的一致性——同一知识元在多个维度上获得高分数（如P-309"童年的黑暗面"在CTI和CDD上同时高排名），增强了涌现发现的可信度。CEI排名前15的知识元与实际撰写02_语义链接网络时已观察到的桥接节点和结构洞高度吻合，表明计算方法具有良好的生态效度。
