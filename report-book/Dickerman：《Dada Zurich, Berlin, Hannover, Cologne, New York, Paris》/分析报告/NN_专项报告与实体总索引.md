# 第一部分：专项报告

## 专项一：全书核心概念的跨章演变

### "Dada"一词的多重定义谱系

| 定义者 | 定义 | 出处章节 | L### |
|--------|------|----------|------|
| Hugo Ball（1916） | 罗马尼亚语"是是"；法语"摇马"；德语"愚蠢的天真" | Zurich | L879 |
| Tristan Tzara（1918） | "Dada不意味任何东西" | 导论 | L538 |
| Richard Huelsenbeck（1920） | 词的"暗示性"——"催眠的能力" | 导论 | L538 |
| 导论 Leah Dickerman | "一个商标"——具有品牌身份的特征 | Zurich | L1071 |

### "蒙太奇/Montage"的跨城演变

| 城市 | 蒙太奇形式 | 核心创新 |
|------|------------|----------|
| Zurich | 同步诗（simultaneous poem）——多声道的声学蒙太奇 | 三个声音以不同语言同时朗诵 |
| Berlin | 摄影蒙太奇（photomontage）——视觉碎片+文字的并置 | 从家庭士兵纪念照→艺术媒介 |
| Hannover | Merz拼贴——物质碎片的层叠堆积 | 所有材料"权利平等" |
| Cologne | 超绘画（over-painting）——在既有图像上叠加颜料 | 科学插图+艺术干预 |
| New York | 现成品——将物体从原语境中"剪切"并重新语境化 | 选择作为创造 |
| Paris | 事件蒙太奇——将诗歌/舞蹈/戏剧/叫卖歌混合在同一演出中 | 公共景观作为碎片组合 |

### "抽象"的跨城演变

| 城市 | 抽象的形式 | 抽象的伦理-政治意涵 |
|------|------------|---------------------|
| Zurich | 声音抽象（Ball）、视觉抽象（Arp/Taeuber）、动觉抽象（Laban） | 逃离被新闻腐蚀的语言 |
| Berlin | 无——柏林达达反对抽象 | "抽象艺术是逃避主义"（Huelsenbeck） |
| Hannover | Merz画中的抽象构成 | "抽象艺术作品"（Schwitters）但以具象碎片构成 |
| Cologne | 几何体块的抽象——但被不规则化/不稳定化 | 抽象秩序的故意崩溃 |
| New York | "审美冷漠"作为抽象——取消审美判断 | 取消趣味/技巧作为伦理 |
| Paris | 数字/目标作为抽象——"统计数字的暴力" | 国家屠杀的抽象化语言 |

## 专项三：全书L###编码总览

L###是贯穿整套分析报告的定位编码系统，用于标记每个关键论点/引文/分析在全书论证链中的位置。

### L1（章节定位）——每章必有的首要定位
| 报告 | L1核心定位 |
|------|-----------|
| 01 Introduction | 全书总论：提出"现代震撼→战术→诊断"三棱镜分析模型 |
| 02 Zurich | 达达发源地：酒馆/抽象/原始主义——作为范式演示的第一章 |
| 03 Berlin | 摄影蒙太奇的发明：政治达达的巅峰——"多声部起源叙事" |
| 04 Hannover | Schwitters的单人达达：被排斥者的Merz世界——"连接一切" |
| 05 Cologne | 前达达到达达的转型：边境城市的怪诞生物学 |
| 06 New York | 现成品与消费批判：跨大西洋的另一条达达路径 |
| 07 Paris | 景观与暴力的终章：达达的自我解体与超现实主义的诞生 |

### L540（核心论证展开位置）——统一编码，贯穿全书
L540标记的是每个章节/报告中"核心论题的直接论证展开位置"——通常是关键引文被分析处或核心命题被浓缩表述处。

| 报告 | L540内容概要 |
|------|-------------|
| 01 Introduction | Dickerman对Tzara宣言的分析——从社会批判到激进主体性的转折 |
| 02 Zurich | Ball的"魔幻主教"表演——抽象声音诗作为对语言的放弃和诗歌的保存 |
| 03 Berlin | Doherty对Scholz画中狗粮广告的道德断言——"人类毕竟在大规模地挨饿" |
| 04 Hannover | "und"作为方法论——Dietrich对Schwitters连词哲学的分析 |
| 05 Cologne | Kriebel对Baargeld ABC攻击诗和评论家冷静引用的分析 |
| 06 New York | Taylor对Stieglitz摄影转化的分析——"闪闪发光的男厕装置"→"拟人化形象" |
| 07 Paris | Mileaf & Witkovsky对Tzara自我拆台、Rachilde军事恐惧、Aragon革命类比引文的分析 |
