## L### NN.1 专项报告一：讽刺理论迁移——从文学讽刺到设计批评

### 1.1 知识迁移路线

```
古典诗学（公元前1-2世纪）
    ├── Horace（贺拉斯）：温和讽刺——识 folly, parody, burlesque
    └── Juvenal（尤维纳利斯）：尖锐讽刺——antithesis, obscenity, violence
        ↓（18世纪文学）
    ├── Alexander Pope, The Rape of the Lock (1714): Horatian 文学典范
    └── Jonathan Swift, A Modest Proposal (1729): Juvenalian 文学典范
        ↓（20世纪末讽刺理论学术化）
    ├── Simpson (2003), On the Discourse of Satire
    └── Connery & Combe (1996), Theorizing Satire
        ↓（2013: 本文的知识迁移操作）
    Malpass (2013): 设计实践中的讽刺分类学
        ├── Associative Design → Horatian satire
        ├── Speculative Design → Horatian→Juvenalian 过渡
        └── Critical Design → Juvenalian satire
```

### 1.2 迁移的创新点

| 创新维度 | 说明 |
|----------|------|
| **对象迁移** | 从文学文本（以语言为媒介）→ 设计对象（以物质形式为媒介） |
| **讽刺主体的变化** | 从作者—读者关系 → 设计师—用户关系 |
| **讽刺媒介的变化** | 从文字修辞 → 物质修辞（material rhetoric） |
| **效果理论化** | 从"娱乐/轻蔑/愤慨"的情感反应 → "批判性反思"的认知效果 |
| **分类学应用** | 将"哪种讽刺"转化为区分不同设计实践的分类标准 |

### 1.3 两种讽刺在设计中的操作差异

| 维度 | Horatian (Associative) | Juvenalian (Speculative/Critical) |
|------|----------------------|----------------------------------|
| 情感调性 | 幽默、干涩的机智（dry wit） | 黑暗、令人不安 |
| 对象关系 | 熟悉→陌生化（subversion of familiar） | 陌生→熟悉化（domestication of unfamiliar） |
| 理性和叙事 | 理性对象 + 嵌入叙事 | 非理性对象 + 外在叙事 |
| 批判焦点 | 学科内部的 folly（愚蠢/荒诞） | 社会/科技中的 errors in logic（逻辑错误） |
| 核心手法 | parody, burlesque, reductio ad absurdum | allegory, exaggeration, antithesis, obscenity, violence |
| 文学同类 | Pope, The Rape of the Lock | Swift, A Modest Proposal |
| 设计案例 | Ball & Naylor, 24-Star Chair | Dunne & Raby, Foragers / Vexed Parka |

### 1.4 迁移的局限

- 讽刺理论源于**语言媒介**，直接迁移到**物质设计**可能存在媒介特定性的损失
- 文学讽刺的效果（阅读体验）与设计讽刺的效果（使用/观看体验）之间的差异未充分理论化
- "constructive social criticism"的限定掩蔽了讽刺可能具有的纯粹娱乐性一面
- 古典讽刺分类（Horatian/Juvenalian）是否穷尽了设计讽刺的类型，值得进一步讨论

## L### NN.2 专项报告二：模糊性作为设计资源——Gaver 三类型的系统应用

### 2.1 理论来源

Gaver, William, Jake Beaver, and Steve Benford. 2003. "Ambiguity as a Resource for Design." In *Conference on Human Factors in Computing Systems (CHI)*, pp. 233-40. New York: ACM Press.

### 2.2 三种模糊性在设计中的映射

| 模糊性类型 | 对应实践 | 定义 | 设计操作 | 用户效果 |
|-----------|----------|------|----------|----------|
| **Ambiguity of context** (语境模糊) | Associative Design | 熟悉的类型学/语境被颠覆 → 语境变得不确定 | 通过 cut-up / context transfer / hybridity 颠覆熟悉对象 | 以开放心态接近设计，质疑关于对象的假设 |
| **Ambiguity of information** (信息模糊) | Speculative Design | 呈现的科技/信息具有不确定性 | 通过 technocratic visualization 和 counterfactual histories 呈现不熟悉的信息 | 感到神秘/印象深刻，被迫参与意义的建构 |
| **Relational ambiguity** (关系模糊) | Critical Design | 人与物之间的关系不明确 → 个人投射空间 | 通过 defamiliarization 和 estrangement 创造"不舒适悬浮" | 对象成为心理镜子，推动质疑自身价值观和态度 |

### 2.3 模糊性—理性—叙事的三角关系

```
           Rationality (理性)
               ↑
              / \
             /   \
            /     \
Ambiguity ←-------→ Narrative
(模糊性)    (叙事)

关联规则：
- 语境模糊 ←→ 理性对象 ←→ 嵌入叙事 → Associative Design
- 信息模糊 ←→ 非理性对象 ←→ 外在叙事 → Speculative Design
- 关系模糊 ←→ 非理性对象 ←→ 外在叙事 → Critical Design
```

### 2.4 模糊性的双重功能

| 功能 | 说明 | 类型体现 |
|------|------|----------|
| **认知功能** | 制造不确定性 → 打破自动化的认知模式 → 开启反思空间 | 三种模糊性共享 |
| **社会功能** | 吸引用户参与意义的共同建构 → 民主化设计讨论 | 尤其在 Speculative 中 |
| **伦理功能** | 不给出确定答案 → 将判断责任归还给用户 → 避免家长式设计 | 尤其在 Critical 中 |

## L### NN.3 专项报告三：方法论专项——Malpass 的研究设计与知识生产

### 3.1 研究方法三角

```
┌──────────────────────────────────┐
│        Malpass 的方法三角          │
├──────────────────────────────────┤
│                                  │
│   专家深度访谈                     │
│   (expert critical designers)    │
│        +                         │
│   项目/文献综述                    │
│   (contextual review)            │
│        ↓                         │
│   显著性识别（salience）           │
│   → satire / rationality /       │
│     narrative                    │
│        ↓                         │
│   分类学建构                      │
│   → 概念驱动的理论分类学           │
│        ↓                         │
│   案例匹配验证                    │
│   → 十余个设计项目               │
│                                  │
└──────────────────────────────────┘
```

### 3.2 方法论评价

| 维度 | 评价 |
|------|------|
| **优势** | 质性方法适合探索性研究；专家访谈获取深层实践知识；案例验证增强可信度 |
| **局限** | 受访专家数量和选择标准未明示；概念驱动的分类学可能过于依赖作者的理论预设；缺乏反向案例（不符合分类学的例外项目）的处理 |
| **可复制性** | 访谈内容未公开（不可验证）；案例选择标准未明述；分类学标准的操作化程度有待提高 |

### 3.3 知识生产类型

本文属于**概念驱动的理论建构**（concept-driven theory building）：
- 不属于实证主义的假设—验证模式
- 采用解释学/建构主义的质性研究范式
- 最终产品是"分类学"（taxonomy）而非"理论"（theory）或"定律"（law）

### 3.4 研究的学科来源

| 学科基础 | 体现 |
|----------|------|
| 设计研究（Design Research） | 核心学科身份 |
| 文学批评（Satire Theory） | 主要理论迁移来源 |
| 科学技术研究（STS） | Speculative Design 的理论背景 |
| 人机交互（HCI） | Critical Design 的理论背景 |
| 社会学（Social Theory） | "建构公众""围绕对象动员辩论"等概念 |
