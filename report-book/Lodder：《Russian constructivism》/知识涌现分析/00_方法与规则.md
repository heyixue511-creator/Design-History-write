# 00 方法与规则

L### 一、知识涌现分析的定位与目标

本分析体系以克里斯蒂娜·洛德《俄国构成主义》（1983）的十份专项分析报告（00整体分析报告、NN专项报告与实体总索引、第一章至第八章逐章报告）为原始数据源，进行**知识元层面的涌现分析**。其目标不是对报告内容进行再次摘要或改写，而是从已有分析结果中提取更高层次的知识结构——即从报告中发现的"分析知识"自身的重组、联结与升华，形成超越原报告离散结论的**集成性知识发现**。

L### 二、核心概念定义

L#### 2.1 知识元（Knowledge Unit, KU）

知识元是知识涌现分析的最小操作单元。在本体系中，一个知识元被定义为：

> 一个在原始分析报告中出现的、具有独立语义完整性的最小判断或实体陈述，能够脱离其原始上下文而被引用、重组和链接。

知识元分为两类：
- **断言型知识元（A-KU）**：表达一个论断、论题、结论或发现。例："塔特林浮雕为构成主义提供了全部形式语言基础。"
- **实体型知识元（E-KU）**：标识一个关键实体的存在、属性或关系。例："塔特林（1885-1953）——构成主义创始人、浮雕与反浮雕创作者。"

L#### 2.2 语义链接（Semantic Link, SL）

语义链接是两个知识元之间的关系断言。一个语义链接必须包含三个要素：源知识元、链接类型、目标知识元。链接类型从原始报告中提取的关系抽象而来。

L#### 2.3 知识涌现（Knowledge Emergence）

知识涌现指当知识元被从原始报告离散位置中提取、依据其内在语义关系重组为网络结构时，新浮现出的、在单一报告中未明确表述或无法直接读出的**结构性知识**。涌现判据为：
- 该知识不存在于任何单一源报告的显式断言中；
- 该知识可从至少两个知识元之间的语义链接结构中推导得出；
- 该知识为对原始领域（俄国构成主义研究）提供新的理解维度。

L### 三、分析流程与方法

分析流程为五阶段递进：

L#### 3.1 知识元抽取（Phase 1）

从十份源报告中提取知识元。提取标准：
1. **语义完整性**：该陈述在脱离上下文后仍可独立理解。
2. **信息密度**：该陈述包含实质性信息（非纯衔接、过渡或修辞）。
3. **可链接性**：该陈述至少与另一个知识元有可辨识的关系。
4. **覆盖完整性**：确保每个源报告的每个核心论题至少贡献一个知识元。

提取后对每个知识元进行编码（格式：A-CD-[序号] 或 E-CD-[序号]），标注来源章节、类型标签、权重等级（核心/支撑/背景）。

L#### 3.2 语义标注（Phase 2）

对每个知识元进行多维语义标注：

| 标注维度 | 说明 |
|----------|------|
| 领域标签 | 该知识元所属的论证领域（形式语言/制度/理论/实践/接受史/方法论） |
| 极性 | 肯定/否定/限定性肯定 |
| 因果角色 | 原因/结果/条件/转折/无关 |
| 层级 | L1（宏观发现）/ L2（中观论题）/ L3（微观案例） |
| 时间锚 | 关联的历史时期标签 |
| 行动者 | 关联的核心人物/机构 |

L#### 3.3 语义链接构建（Phase 3）

构建知识元之间的语义链接网络。链接类型包括：

| 链接类型 | 符号 | 含义 | 示例 |
|----------|------|------|------|
| 因果 | → | A导致/促成B | 革命经验 → 生产艺术理念 |
| 对立 | ⇄ | A与B对立/矛盾 | 加博纯艺术立场 ⇄ 构成主义功利主义 |
| 支撑 | ⤷ | A为B提供证据/基础 | 塔特林浮雕 ⤷ 构成主义形式语言 |
| 并行 | ∥ | A与B平行发展 | VKhUTEMAS ∥ 包豪斯 |
| 转化 | ↦ | A演变为B | 非功利主义构成 ↦ 构成主义 |
| 包含 | ⊃ | A包含B | 构成主义 ⊃ 有机构成主义 |
| 区分 | ↮ | A与B被明确区分 | 构成主义 ↮ 生产主义 |
| 时序 | →ₜ | A先于B发生 | 反浮雕 →ₜ OBMOKhU展览 |

L#### 3.4 涌现计算（Phase 4）

对构建的语义链接网络进行结构分析，识别涌现模式。计算方法包括：
- **结构洞（Structural Hole）识别**：查找网络中本应存在但缺失的链接——指示知识空白。
- **枢纽节点（Hub）识别**：计算节点度中心性，识别起结构性聚合作用的知识元。
- **社区发现**：识别语义链接网络中的凝聚子群——指示知识元的自然聚类。
- **跨社区桥接**：识别连接不同子群的边——指示跨领域知识整合的关键路径。
- **涌现命题生成**：基于网络结构模式推导原始报告中未显式陈述的知识命题。

L#### 3.5 知识发现报告（Phase 5）

将涌现计算结果转化为可读的知识发现报告。报告的结构化输出规则：
- 每个涌现命题标注其来源知识元、推导路径和支持证据。
- 每个发现分为"确认型"（基于多源知识元的一致指向）、"假设型"（基于结构洞或隐含模式）和"问题型"（基于知识元之间的对立或空缺）。
- 每个发现附信度标注（高/中/低），信度取决于支撑知识元的数量、源报告的覆盖面以及推导的直接性。

L#### 4.2 实体索引整合规则

NN专项报告中的六类实体总索引（人物、机构/组织、作品/物品、概念/术语、事件/展览、文献/出版物）作为E-KU提取的基础数据库。每个实体条目的"主要出没章节"字段直接映射为知识元的跨章关联锚点。

L#### 4.3 边界规则

- 不引入洛德原书正文内容（仅以分析报告为其知识表征）。
- 不引入报告未涉及的学术文献。
- 知识涌现的范围限于洛德著作的知识域内，同时允许将开放问题列表（S00第六节）作为涌现输出的合法目标。

L### 五、输出规范

L#### 5.1 格式规范

- 所有文件使用Markdown格式，UTF-8编码。
- 章节标题使用L### 和 L#### 层级（对应Markdown的##和###）。
- 知识元编码使用固定格式：`{类型}-{源编号}-{序号}`，如`A-03-12`表示源报告S03的第12个断言型知识元。
- 语义链接使用固定格式：`[源编码] —[链接类型]→ [目标编码]`。

L#### 5.2 质量控制

- 每个涌现命题必须可追溯到至少两个独立源报告中的知识元。
- 信度标注"低"的知识发现仍需具备陈述价值（指向值得注意的开放问题），但需明确标注其不确定性来源。
- 知识元抽取完成后进行去重审核——同一核心主张在多个报告中以不同表述出现时，合并为单一知识元但保留全部源引用。

L### 六、分析语料的基本统计特征

源报告总计约120,000字（中文），涵盖：
- 62项核心论题（S00的7项 + S01至S08各3-5项 + SNN的4项专项报告）
- 约150个人物实体、45个机构/组织实体、30件关键作品、25个核心概念、20个关键事件、20种关键文献
- 全书八章的完整"发生-发展-转折-收束"叙事弧的结构映射
- 二元对称性结构（几何/有机、理论/制度、三维/二维、俄国起源/西方接受）的显式标注
