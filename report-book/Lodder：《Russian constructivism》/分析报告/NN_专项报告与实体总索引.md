# 专项报告与实体总索引

L### 专项报告一：核心术语的语义学澄清

洛德《俄国构成主义》的一个突出特征是贯穿全书的术语考辨。以下是对全书中最重要的术语区分和概念演变的系统梳理。

#### 1.1 "构成主义"（Constructivism）一词的谱系

- **首次印刷出现：** 1922年1月莫斯科"诗人咖啡馆"展览目录，三位艺术家（梅杜涅茨基、斯滕伯格兄弟）的宣言："所有艺术家现在应'进入工厂，那里制造着生命的真实身体'……这条道路被称为构成主义。"
- **第一构成主义工作组的定义（1921年3月）：** "通过利用材料与预定目的来实现物体的系统。"
- **INkhUK辩论中的一般性定义（1921年春）：** "构成是对材料元素的有效组织。构成的标志：(i)材料的最佳使用 (ii)没有任何多余元素。构成的图式是线条及其定义的平面和形式的组合；它是一个力的系统。"
- **西方的再定义：** 利西茨基1925年："构成主义证明了数学和艺术之间、艺术作品和技术发明之间的界限不是固定的。"加博1948年："构成主义这个词是误用……[构成主义者]要求艺术应该消灭自己。"

#### 1.2 "非功利主义构成"（Non-Utilitarian Construction）vs."实验室工作"（Laboratory Work）

- **非功利主义构成：** 洛德提出的操作性术语。指1913年至1920-21年间创作的、不包含功利目的或社会承诺的抽象三维作品。纳科夫使用的对应术语是"实验室时期"，但洛德认为该术语过于紧密地与特定历史阶段绑定。
- **实验室工作：** 构成主义者自己的术语。指具有最终功利目的指向的形式研究——不是目的本身，而是为未来设计任务做准备的研究。与"非功利主义构成"的关键区别在于意图（是否计划最终走向功利目的）。

#### 1.3 "构成主义"（Constructivism）vs."生产主义"（Productivism）vs."生产艺术"（Production Art）

- **生产艺术（proizvodstvennoe iskusstvo）：** 最广义的术语，泛指艺术家参与工业生产。在使用中含义极度多变——从表面的装饰应用到深层的设计方法整合。
- **构成主义（Constructivism）：** 艺术家从"艺术端"接近"艺术-工业融合"。强调对材料、形式、构成的亲自操作。
- **生产主义（Productivism）：** 理论家从"工业端"接近同一融合。更关注产业组织、工程技术、经济效率。
- **洛德的判断：** 严格地说，唯一真正的"生产主义者"是理论家（阿尔瓦托夫、库什涅尔、早期的布里克）。构成主义者是"先锋"——"他们手中只有一面旗帜，而且那面旗帜……破破烂烂。"

#### 1.4 "建构的"（postroenie/constructive）vs."构成主义的"（konstruktsiya/Constructivist）

- **postroenie（建构）：** 俄语词根stroit'（建造）。加博/佩夫斯纳使用的术语，强调"构建"的过程。在加博看来，这意味著"不是雕刻或模塑一件单一材料的雕塑，而是像工程师建造一个结构那样将它建立到空间中"。
- **konstruktsiya（构成）：** 外来词根。构成主义者使用的术语，强调基于功能和材料逻辑的组织——最终指向有用物品的生产。
- **洛德的论证：** 这一术语差异在西方翻译中不可避免地丢失——两个词都可以被翻译为"construction"——这构成了西方"误解"的语言学根源。

#### 1.5 其他关键术语区分

- **浮雕术语的演变（塔特林）：** "绘画浮雕"（zhivopisnyi rel'ef）→"材料选择"（material'nyi podbor）→"反浮雕"（kontr-rel'ef）→"角隅反浮雕"（uglovoi kontr-rel'ef）。每个术语对应一种空间关系的变化。
- **"未来主义"（Futurism）在革命后俄国的多义性：** 被宽松地用作所有先锋派艺术家和诗人的统称。普宁指出"左翼艺术"同样是模糊的术语。
- **"生活建设"（zhiznestroenie）：** 楚扎克提出的概念，试图将"生产艺术"重新定义为对生活方式的整体重构——不仅是物品的生产。

L### 专项报告二：全书的论辩结构

洛德在全书中有四个主要的论辩靶标，这些论辩贯穿各章：

1. **反"纯艺术"叙事（针对Camilla Gray, George Rickey及西方接受史）：** 持续证明构成主义的社会-政治-工业维度不能被简化为形式-审美维度。最集中的论战出现在导言、第二章（加博/佩夫斯纳节）、第八章。
2. **反"外部镇压"叙事（针对冷战史学传统）：** 在第六章论证构成主义的衰落不是简单的外部政治镇压，而是内部技术审美逻辑的展开。
3. **反"单一化"叙事：** 在第七章通过"有机构成主义"概念挑战"构成主义=机器美学"的等式。
4. **反"加博中心"叙事：** 在第二章和第八章通过术语考辨和接受史批判，将加博从西方构成主义叙事的中心位置移开。

L### 专项报告三：档案使用与未解决问题

洛德的著作是英语世界第一部系统使用苏联原始档案研究构成主义的著作。她在致谢中列出了使用的档案馆：
- 莫斯科中央国立文学艺术档案馆（TsGALI）
- 列宁格勒俄罗斯博物馆手稿部
- 莫斯科列宁图书馆手稿部

主要档案来源包括：
- **TsGALI fond 681（VKhUTEMAS档案）：** 教学大纲、会议记录、学生报告
- **TsGALI fond 2089：** 塔特林相关材料
- **私人档案馆（莫斯科和列宁格勒）：** 包括罗琴科家族档案（含罗琴科未发表手稿和教学文件）

洛德坦诚指出的档案缺口：
- INkhUK档案在写作时"尚未完全开放"
- 塔特林的大量私人文件在他1953年去世后被公寓管理员丢弃
- 许多构成主义三维作品由于艺术家自己销毁或材料不耐久而已失传
- 某些时期的展览目录和期刊不全

L### 四、核心概念与术语

| 术语（原文+中文翻译） | 定义 | 主要出没章节 |
|----------------------|------|-------------|
| non-utilitarian construction（非功利主义构成） | 洛德提出的操作性术语——1913-1921年间无功利目的或社会承诺的抽象三维作品 | Ch.1, 2 |
| construction / konstruktsiya（构成） | INkhUK定义："对材料元素的有效组织……最佳使用材料，没有任何多余元素" | Ch.3 |
| laboratory work（实验室工作） | 指向未来功利任务的形式研究——不是目的本身，而是为设计服务的研究 | Ch.1, 2, 3 |
| production art / proizvodstvennoe iskusstvo（生产艺术） | 艺术家参与工业生产的广义概念。含义极度多变 | Ch.3 |
| Constructivism vs. Productivism（构成主义 vs. 生产主义） | 前者从"艺术端"、后者从"工业端"接近艺术-工业融合 | Ch.3 |
| artist-constructor / khudozhnik-konstruktor（艺术家-构造者） | 既掌握艺术训练又具备技术工程知识的理想设计者。被塔拉布金描述为"几乎超人的" | Ch.3, 4 |
| faktura（肌理/材料纹理） | 俄语术语——材料表面的质感处理、加工状态 | Ch.1, 3, 5 |
| tectonics / tektonika（构造学） | 甘的三个核心原则之一：材料的社会-功能使用方式 | Ch.5 |
| counter-relief / kontr-rel'ef（反浮雕） | 塔特林1914年后使用的术语。前缀"kontr-"指增强的空间张力 | Ch.1 |
| construction vs. composition（构成 vs. 构图） | INkhUK辩论的核心对立——功利性组织 vs. 审美性安排 | Ch.3 |
| prozodezhda（生产服装） | 斯捷潘诺娃的概念——按职业和工业类型区分的功能性工作服 | Ch.5 |
| zhiznestroenie（生活建设） | 楚扎克提出的概念——将构成主义重新定义为对生活方式的全面重构 | Ch.3 |
| photomontage（摄影蒙太奇） | 将摄影图像与图形元素组合为新的合成图像的构成主义技法 | Ch.6 |
| factography（事实性文献/事实学） | 《新LEF》的理念——用摄影和纪实媒介取代传统"虚构"艺术 | Ch.6 |
| Organic Constructivism（有机构成主义） | 洛德提出的分析范畴——基于自然有机形式和动力学的构成主义亚种 | Ch.7 |
| postroenie vs. konstruktsiya（建构 vs. 构成） | 前者（俄语词根stroit'）为加博使用的术语；后者（外来词根）为构成主义者使用。西方翻译中两者合并为"construction" | Ch.2, 8 |
| objet trouvé（现成品） | 取自日常生活或工业的现成物品，不经艺术加工或经最小加工作为艺术元素使用 | Ch.1 |
| Proun | 利西茨基的自创术语："绘画与建筑之间的转换站" | Ch.2, 8 |
| social and technical monism（社会-技术一元论） | 阿尔瓦托夫的理论——所有人类活动（包括艺术）应服从社会和技术功利性这一单一原则 | Ch.3 |
| stylisation（风格化） | 洛德用来描述几何形式在构成主义实践中从功能逻辑脱落为审美风格的过程 | Ch.5 |
