# Ch09 分析报告：The Body-without-a-Name

## 章节定位与功能（含行号范围）

本章行号范围约 L1930-2116（clean 版），以行内标记 `# The Body- without- a- Name`（L1930）与 Luigi Pirandello《已故的 Mattia Pascal》题词开篇（"The only thing I was sure of was my name"，L1931）。内部小节：`## 1.`（L1933）、`## 2.`（L1959）、`## 3.`（L2010）、`## 4.`（L2026）。

**功能**：探讨"无名之身"（body-without-a-name）——身份、命名与"无名性"（nobodiness）政治，从苏联另类艺术的"避名"传统到普京的"无名者当总统"策略。

## 结构分析

1. **西方认知模式批判（L1933-1958）**：1960-80 年代西方对俄罗斯文化的"正统 vs 异议"粗疏二分；foreclosure（弃绝）概念；社会主义现代主义的"被弃绝时间"。
2. **后苏联艺术流通（L1959-2009）**：1988 年苏富比拍卖后的"东西方交流"；"星期五人/鲁滨逊"模式；身体的热月与地缘政治。
3. **女性主义与共同体身体（L2010-2025）**：女性主义被疑为扩张出共同体"无器官身体"；hermaphrodism vs androgyny。
4. **身份/命名政治（L2026-2116）**：对智力主义的攻击；Ulysses/Polyphemus 神话；"无名者"策略；Putin"无名者当总统"。

## 内容分析

**内容一：弃绝与社会主义现代主义（L1933-1958）**
1960-80 年代西方以"正统/异议"二分理解俄罗斯文化过于粗糙（L1933-1935）；苏联另类圈对外国左/右二分持怀疑（L1936）；"被弃绝"（foreclosure）概念——Kandinsky、Larionov、Goncharova、Malevich、Tatlin、Rodchenko、Lissitzky 的遗产被弃（L1938-1943）；社会主义现代主义（1920 年代末-30 年代）与 akhr、早期社会主义现实主义并存（L1944-1945）；Althusser 读《资本论》——经济"我"与心理主体同构（L1948-1954）；Khrushchev 解冻期"基础与上层建筑分离"（L1955-1957）。

**内容二：后苏联艺术流通（L1959-2009）**
1988 年苏富比拍卖后俄罗斯艺术家定期赴西（L1959-1962）；西方对俄罗斯艺术的"捐赠器官"式看待（L1969）；"文化（多元文化）交流与对他者的艺术殖民导致批判视觉的扩散"（L1973）；"反异化药丸"与停滞的悖论（L1974）；"身体的热月"与东欧身体地理（L2004-2008）。

**内容三：女性主义与共同体身体（L2010-2025）**
女性主义被疑为试图扩张出共同体"无器官身体"（L2012）；"批判责任被拖延，让位于肯定性责任与不作判断"（L2013）；"共同体世界中言语不断运动，必须像跳上移动中的电车一样跳进去"（L2017）；"共同体言语的主体是言语本身"（L2020-2022）；hermaphrodism vs androgyny 的区分（L2023）；"雄雌同体者是施虐超我的信徒，而雌雄同体者是受虐话语的代表"（L2023）。

**内容四：身份/命名政治（L2026-2116）**
对身体的热月的攻击常伴随对智力主义的攻击（L2026-2029）；Ulysses 与 Polyphemus 神话：Ulysses 自称"Nobody"使独眼巨人无法求助（L2094-2095）；Sloterdijk 论"无名性的物理生存"（L2095）；"'无名者'是双程票——出去（Ulysses）与进来（Putin）"（L2108）；2000 年"无名者当总统"是普京的制胜策略（L2106-2107）；"后苏维埃时代，'无名性'已不再是可行的生态位"（L2117）。

## 逻辑梳理

本章逻辑：西方认知框架批判（正统/异议二分）→ 弃绝概念解释苏联遗产的消失 → 后苏联艺术流通的殖民结构 → 共同体身体对"命名/判断"的逃避（hermaphrodism）→ Ulysses/Polyphemus 神话与"无名者"政治 → 普京案例。
