# 01 知识元语意分析

本文档给出六类知识元的全文语义载荷——"做什么、指什么、为何存在"——并先总述五种论证功能，再按类分表。所有行号为 clean 版证据。

## 〇、五种论证功能（总述）

知识元在论证中承担五类功能：

1. **因果节点**：直接促成后续观念/作品的知识元（如 Choisy→Le Corbusier，L301-308）。
2. **结构变量**：构成理论体系的结构参数（如"类型/规范"贯穿 Werkbund→Purism→国际式，L813-816，L2371-2373，L3673）。
3. **类型标签**：为运动/风格命名或定性（如"Machine Aesthetic"L2142-2147、"International Style"L3159-3160）。
4. **证据载体**：作为论证的证据（宣言文本、建筑实例、竞赛记录）。
5. **参照坐标**：提供评价基准（如 Philebus 柏拉图主义 L2328-2331、Phidias L2623、Parthenon L2557-2563）。
