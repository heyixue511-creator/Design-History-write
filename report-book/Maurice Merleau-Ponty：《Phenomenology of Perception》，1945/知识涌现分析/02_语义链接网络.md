### 2.1 概念-概念子网（TYPE_C ↔ TYPE_C）

概念之间的语义链接构成了全书知识网络的骨架。以下为核心概念子网的主要拓扑结构：

                      │

- 无标度分布：少数概念（L101、L102、L103、L106、L104）充当超级枢纽，绝大多数概念在这些枢纽周围呈放射状分布

- 高聚类系数（CC=0.46）：概念之间的互链密度高于全局平均，表明概念系统具有高度整合性

## 三、论证拓扑分析

### 3.1 全书的论证拓扑结构

《知觉现象学》的论证不是线性推进的，而是形成一个多中心、多层次、多回路的有向网络。以下为论证拓扑的核心结构：

```
                        前言（方法论框架）
                    ┌───────────────────┐
                    │ L104-意向性       │
                    │ L103-在世存在     │
                    │ L201-描述方法     │
                    └───────┬───────────┘
                            │ [奠定方法]
        ┌───────────────────┼───────────────────┐
        ↓                   ↓                   ↓
  导论(批判传统)        第一部(身体)         第二部(世界)
  ┌─────────────┐   ┌─────────────┐     ┌─────────────┐
  │ L505→[OPP]  │   │ L102-身体   │     │ L101-知觉   │
  │ L511→[OPP]  │   │ L170-图式   │     │ L210-感觉   │
  │ L112-格式塔 │   │ L175-意向性 │     │ L241-他人   │
  └──────┬──────┘   └──────┬──────┘     └──────┬──────┘
         │                 │                   │
         └─────────┬───────┴───────────────────┘
                   ↓
              第三部(自我与自由)
         ┌─────────────────────────┐
         │ L251-沉默的我思         │
         │ L260-时间性             │
         │ L270-处境中的自由       │
         └─────────────────────────┘
```

### 3.2 论证路径分析

**论证主路径（Critical Path）**——从方法到结论的最短语义通道：

```
L104-意向性（前言）
  → [EXTEND] L175-运动意向性（第一部Ch3）
    → [EXTEND] L102-身体-主体（第一部Ch3）
      → [COMPOSE] L177-"我能"（第一部Ch3）
        → [EXTEND] L251-沉默的我思（第三部Ch1）
          → [EXTEND] L260-时间性（第三部Ch2）
            → [EXTEND] L270-处境中的自由（第三部Ch3）
```

论证主路径长度为7步。但这不是唯一的论证路径。实际网络中存在多条并行路径——这是该书"回环递进法"的网络拓扑表达。

**论证回环实例**——L103-在世存在的三次反复：

```
回环1：前言 ──→ L103-在世存在（作为方法论框架）
回环2：第一部Ch3 ──→ L103-在世存在（作为身体的空间性基础）
回环3：第三部Ch2 ──→ L103-在世存在（作为时间性的存在论结构）
```

在语义链接网络中，回环表现为L103节点在不同章节中有不同的入链来源和出链目标——同一个节点在不同网络位置承担不同的论证功能。

### 3.3 "双重失败法"的论证拓扑

"双重失败法"（见00_整体分析报告第六节）在网络中呈现为特定的链接模式：

```
某个知识元 X
    │
    ├──[OPPOSE]──→ 经验主义解释 (L505)
    │                    │
    │                    └──[OPPOSE]──→ 共享"客观世界偏见"
    │
    └──[OPPOSE]──→ 理智主义解释 (L511)
                         │
                         └──[OPPOSE]──→ 共享"客观世界偏见"
                                          │
                                          ↓
                              L102-身体-主体（第三条道路）
```

这种"分叉-汇聚"的拓扑结构在全书网络中反复出现——L402-幻肢、L401-缪勒-莱尔错觉、L428-疾病感缺失等案例均遵循此模式，构成了全书的"论证基因"。
