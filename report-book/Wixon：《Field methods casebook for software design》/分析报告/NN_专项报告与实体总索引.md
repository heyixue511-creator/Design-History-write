# 《Field Methods Casebook for Software Design》专项报告与实体总索引

## 第一部分：专项报告

### 一、语言与文风

1. **专业实践语体**：全书以"学术-实务混合"文体写成。案例章以执行摘要（Executive Summary）开篇（如 L622、L812、L1312），正文使用 HCI/人类学术语（ethnography、tacit knowledge、affinity diagram、work model、Contextual Inquiry），同时穿插大量公司项目语料。
2. **口述语料入文**：高频直引用户/客户原话作为证据。例：Ch4 的客户反馈（L1642-L1651）、Ch4 的"Less is better"（L1547）、Ch6 的"我从不与客户面对面时打字"（L2106）、Ch9 的完整访谈转录（L2694-L2718）。
3. **第一人称经验叙述**：多数案例以"我/我们做了什么、学到了什么"的亲身口吻叙述（Ch6 尤其明显，如 L2033）。
4. **句式特征**：方法论论述多用长复合句（如 L600-L601）；程序性步骤多用列表与短句（如 L1369-L1373 的三条原则）。
5. **隐喻性语言**：
   - "设计是把使能者置于工人与工作之间的空空间"（L430）；
   - Ch9 的"音乐记谱"（staffs and measures，L2806）；
   - Ch17 的"地板平面图"（floor plan，L5036）；
   - "if you want to know about water, don't ask a fish"（L634）。

### 二、修辞方式

1. **引语开篇/点睛**：Preface 以 Will Rogers 名言开篇（L93）；各章常以客户原话收束论证（L1642-L1651、L1601）。
2. **反诘与设问**：Preface 的"How do we know?"（L101）；Ch9 的"What are they really trying to accomplish with all these controls?"（L2618）。
3. **排比/三叠结构**：Ch4 的"Find out…Design…Refine…"（L1369-L1373）；Ch16 的四点差异（L4521-L4527）；Ch17 的三原则（L5060）。
4. **反例论证**：以失败/未预期案例作反论据，如 SAS 专家系统（L4561）、椅子钉地板（L4695）、Joe/Sue 对话（L5028-L5030）、红墨水例子（L3695）。
5. **自谦与自我批判**：Ch2 自陈"并非真正参与式"（L983）；Ch7 自陈"整体影响令人失望"（L2323）；Ch12 坦承管理层要求量化（L3631）。

### 三、史料/材料使用方式

1. **一手田野材料**：录像带、音频、笔记、访谈转录、制品样本、模型图（工作模型、亲和图）、需求文档、客户反馈原话。
2. **量化证据**：数字广泛用于说服——如"2000+ 数据点、200 工作模型、60 天"（L554、L3485）、"542 条需求、411 条均值≥8"（L3817）、"$4500 六天差旅"（L2174）、"300 小时 CI+1300 小时分析"（L3852）。
3. **引用方式**：正文夹注（作者+年份）+ 章末 References；Ch1 用尾注（L778-L798）。引用覆盖人类学、认知科学、HCI、质量管理、软件工程。
4. **交叉引用**：章节间大量互引（如 L558 引用 Wood 章、L568 引 Muller & Carr 章、L590 引 Holtzblatt & Beyer 章），构成内部知识网络。

### 四、阐述方法

1. **案例-框架双层结构**：14 案例在前、3 框架在后，读者可"先见树木后见森林"。
2. **功能化统一框架**：案例统一按 Executive Summary/Background/Planning/Conducting/Analyzing/Impacting/Cost-Benefit/Reflections 编排（Contents，L127-L344），保证跨案例可比。
3. **问题-对策式阐述**：如 Ch7 的 Table 7.2（挑战→对策）、Ch17 的"分离对话"教学案例。
4. **方法-实例对照**：Ch5 的"In Theory / In Real Life"逐活动对照（L1833-L1985）。

### 五、推演逻辑

1. **归纳-涌现逻辑**：从观察数据"涌现"需求与设计（Ch1 的行为流、Ch12 的亲和图"结构从细节中冒出来"L4973）。
2. **假设-证伪逻辑**：田野数据推翻初始假设（Ch4 的四大教训 L1494-L1557；Ch9 的"设计未植根于用户工作"L2879）。
3. **对比-取舍逻辑**：质性 vs 量化（Ch2）、自上而下 vs 自下而上（Ch3）、到现场 vs 带现场（Ch14）、实验室 vs 田野（Ch15）。
4. **组织-方法联动逻辑**：方法成败与组织支持/跨职能结构/变更控制绑定（Ch4、Ch7、Ch17）。

### 六、文字风格总评

平实、克制、实证导向；以"可复制的经验"为写作目标，较少纯理论推演；对方法局限的坦承构成其可信度的重要来源。全书整体是一本"实践者写给实践者"的方法学操作手册。
