# 知识涌现分析 00：方法与规则

## 一、目标与范围

本系列对 Dennis Wixon (ed.)《Field Methods Casebook for Software Design》（1996，源文件行号 L1-L5532）进行**知识涌现分析**，从全书文本中提取知识元（六类实体）、构建语义链接网络，识别强连通簇（Topic）与高层语义域（Theme），并计算涌现指标。全部证据以源文件行号为定位基准。

## 二、层级定义

### 2.1 知识元（Knowledge Atom）
最小语义单元，即六类实体：

| 类型代码 | 类型 | 定义 |
|---|---|---|
| P | Person（人物） | 作者、方法开发者、行业实践者等 |
| A | Artifact（著作/作品） | 产品、方法手册、工具、项目 |
| C | Concept（概念） | 方法、术语、理论概念 |
| I | Institution（机构） | 公司、大学、组织 |
| L | Location（地点） | 城市、国家、场所 |
| E | Event（事件） | 会议、项目、历史节点 |

### 2.2 Topic（强连通簇）
由语义链接（尤其因果→、隶属⊂、同域∼）紧密互连的知识元子集，形成内聚的分析单元。本书预期 6-15 个 Topic。

### 2.3 Theme（高层语义域）
若干 Topic 聚合而成的高层语义域，代表全书的方法论大类与论证轴线。本书预期 3-5 个 Theme。

## 三、9 种语义链接判定标准

| 符号 | 类型 | 判定标准 | 示例（本书） |
|---|---|---|---|
| → | 因果 | A 是 B 的原因/驱动；B 由 A 产生 | 田野数据 → 推翻设计假设（Ch4） |
| ⇒ | 条件 | A 是 B 成立的前提/必要条件 | 跨职能团队 ⇒ 方法制度化成功（Ch7） |
| ↔ | 对比 | A 与 B 构成对照/张力 | 实验室测试 ↔ 田野研究（Ch15） |
| ⊂ | 隶属 | A 是 B 的一部分/成员 | PICTIVE ⊂ 参与式设计工具族 |
| ≻ | 时序 | A 先于 B 发生 | 质性分析 ≻ 量化分析（Ch2） |
| ≈ | 空间共现 | A 与 B 在同一场景/场所出现 | 药企实验室 ≈ 录像受限 |
| : | 属性 | A 具有属性/特征 B | 话务员工作 : 知识工作（Ch2） |
| ⇐ | 论证支撑 | A 作为论据支撑命题 B | 客户原话 ⇐ 支持"mac 本地化"决策 |
| ∼ | 同域 | A 与 B 属于同一领域/主题簇 | Contextual Inquiry ∼ Contextual Design |

## 四、涌现指标

### 4.1 节点度（k）
某知识元在语义链接网络中的链接数。k 高 = 枢纽（hub）。

### 4.2 桥接值（b）
某知识元跨 Topic/Theme 的连接数。b 高 = 中介/桥接节点。

### 4.3 簇识别（强连通）
依据链接密度与方向性聚类。本书链接多为双向语义关联（非严格有向），以无向密度为主要判据，辅以因果/时序方向。

### 4.4 内聚度
簇内链接数 / 簇内节点数；用于比较 Topic 的相对整合程度。

### 4.5 涌现强度（S）
S = 簇内链接数 × log(簇内节点数) 的归一化；用于排序 Topic 的知识涌现贡献。

### 4.6 一级/二级涌现
- **一级涌现结构（E1…En）**：直接由知识元簇化形成的 Topic 结构，即"由数据直接读出的主题"。
- **二级涌现命题（P1…Pn）**：跨 Topic 综合、由分析者从网络结构+文本证据推演出的命题，附生成机制（基于哪些链接/桥接）与强度。

## 五、证据规范

1. 每个知识元、链接、簇、命题均须附源文件行号证据；
2. 链接判定须写明依据（如"L1395：Direct contact with users at early stages ... essential step"支撑"田野研究→设计质量"因果链）；
3. 客观性核对：对"点到未论"（作者未明确论述但网络结构暗示）的链接，明确标注证据缺口；
4. 反例与边界：对可能过强或含糊的涌现结论并列反例。
