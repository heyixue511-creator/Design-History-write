# 02_语义链接网络

## 一、网络的总体构成

### L0201 网络基元

本语义链接网络以58个核心知识元（K001-K058，见01_知识元语意分析.md）为节点，以七类语义链接关系（CAU/OPP/SIM/HIE/SEQ/COM/INS，见00_方法与规则.md）为边。

### L0202 总体网络度统计

| 指标 | 值 |
|------|-----|
| 节点总数 | 58 |
| 链接总数 | 约156条（见以下各表） |
| 链接类型分布 | CAU: ~62条, HIE: ~28条, COM: ~22条, SIM: ~18条, INS: ~12条, OPP: ~8条, SEQ: ~6条 |
| 最高度节点 | K012(殖民总根源归因), K024(资本积累被剥夺), K051(政治自主权), K052(方法论自主) |
| 网络直径 | 约7（从最外层诊断到最深层政治结论） |
| 主要论域间桥接 | D-I→D-II(诊断→归因), D-II→D-III(归因→机制), D-III→D-IV(机制→对策), D-IV→D-V(对策→方法论) |

### L0203 网络的层级结构

知识元网络的语义拓扑呈现清晰的"五层夹心"结构：

```
层级五 (D-V: 方法论/元层) — K053-K058
    ↑ 涵括
层级四 (D-IV: 规范性/对策层) — K042-K052
    ↑ 指向
层级三 (D-III: 机制层) — K028-K041
    ↑ 解释
层级二 (D-II: 归因层) — K012-K027
    ↑ 说明
层级一 (D-I: 诊断层) — K001-K011
```
