## L### 专项报告二：全书跨章主题网络分析

### L#### 主题一："英雄叙事批判"网络

```
Conway (Ch1): 提出"heroic approach"概念
    └→ Kirkham (Ch4): Hepplewhite案例（最彻底的执行）
    └→ Heskett (Ch6): Pevsner/Read/Giedion的"以史为论"
    └→ Miller (Ch2): Laver的"Zeitgeist"理论被批判
    └→ Aynsley (Ch7): Modernism=好的设计的教条被质疑
```

### L#### 主题二：物品意义的非固定性

```
Heskett (Ch6): VW Beetle四次意义转换
    └→ Aynsley (Ch7): Barthes符号学——能指/所指关系的历史变动
    └→ Kirkham (Ch4): Hepplewhite——名望的后世建构而非当代实情
    └→ Woodham (Ch3): bidet——功能不变但文化意义180度转变
```

### L#### 主题三：女性主义设计史

```
Conway (Ch1): 方法论倡议
    └→ Miller (Ch2): 服装史与妇女史不可分割
    └→ Kirkham (Ch4): 术语批判+性别分工分析
    └→ Conway/Roenisch (Ch5): Matrix《Making Space》
    └→ Conway (Ch8): Matrix+住房政策中的女性视角
```

### L#### 主题四：伪造/仿制/误归

```
Woodham (Ch3): 陶瓷伪造→Samson of Paris→"Bernard Leach"狱友案
    └→ Kirkham (Ch4): 家具伪造→Edwards & Roberts→Hepplewhite
    └→ Miller (Ch2): 绘画伪造中的服装错误
```

### L#### 主题五：从客体到语境的方法论转向

```
Conway (Ch1): "以时期语境而非当代审评为标准"
    └→ Woodham (Ch3): 风格分析→社会/经济/技术/考古全维度
    └→ Kirkham (Ch4): 从"鉴赏学"到"历史学"
    └→ Heskett (Ch6): design as object→process→concept
    └→ Aynsley (Ch7): 视觉分析不足以为史→符号学/意识形态补充
    └→ Conway (Ch8): 环境设计的批判性语境分析
```
