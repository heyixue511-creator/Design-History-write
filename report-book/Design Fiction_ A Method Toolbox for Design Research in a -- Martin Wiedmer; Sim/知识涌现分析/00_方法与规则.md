# 00_方法与规则

## L1：分析框架总览

### 1.1 知识涌现分析的定义与目标

本分析系列以"知识涌现"（Knowledge Emergence）为核心视角，对Grand与Wiedmer的论文《Design Fiction: A Method Toolbox for Design Research in a Complex World》及其八份逐章分析报告进行二次知识挖掘。知识涌现分析的目标是：

1. **识别知识元**：从分析报告中提取不可再分的知识要素单元（概念、学者、文献、论证结构、方法、案例、关系），构建知识元词典。
2. **构建语义链接网络**：揭示知识元之间的语义关联模式，识别涌现结构——即不能从单一知识元中推导、只能从多知识元交互中产生的新知识结构。
3. **量化涌现度**：建立多维涌现度计算模型，对知识涌现的强度、新颖度、跨学科度进行量化评估。
4. **生成知识发现**：基于涌现计算结果，识别原始分析中未被显式表述但可从知识元交互中推断的新知识。

### 1.2 分析框架的L层次体系

本分析采用L###层结构，每一层次对应知识涌现分析的一个分析深度：

| 层次 | 代号 | 功能 | 对应文件 |
|------|------|------|----------|
| L1 | 框架层 | 定义分析维度、规则与边界 | 00_方法与规则 |
| L2 | 元识层 | 知识元的抽取、分类与语义标注 | 01_知识元语意分析 |
| L3 | 链网层 | 知识元的语义链接关系建模 | 02_语义链接网络 |
| L4 | 计算层 | 涌现度的量化计算与评估 | 03_知识涌现计算 |
| L5 | 发现层 | 基于涌现计算的知识发现报告 | 04_知识发现报告 |

### 1.3 分析原则

1. **从分析到分析的元分析**：本系列的分析对象不是原始文献本身，而是八份逐章分析报告（00-07 + NN）。所有知识元的抽取均以分析报告中的实体清单和论证分析为数据源。
2. **涌现优先**：重点识别那些"整体大于部分之和"的知识结构——即不能从单一分析报告中得出、只能通过跨章节、跨实体类型、跨学科的交叉关联才能涌现的知识。
3. **量化与定性并行**：既建立形式化的涌现度计算模型，又保留自然语言的知识发现叙述。
4. **中文表述 + L###标注**：所有内容以中文撰写，关键术语保留英文原词，实体引用标注L###行号。

## L2：知识元定义与分类规则

### 2.1 知识元的七类体系

基于对八份分析报告的内容类型分析，知识涌现分析采用七类知识元体系：

| 类别编号 | 类别名称 | 英文 | 定义 | 来源依据 |
|----------|----------|------|------|----------|
| K01 | 核心概念元 | Core Concept Element | 文本中承载理论内涵的关键术语及其定义 | 分析报告中的"概念/术语"实体表 |
| K02 | 学者-思想元 | Scholar-Thought Element | 特定学者的学科归属与核心学术贡献 | 分析报告中的"人物/学者"实体表 |
| K03 | 文献-著作元 | Literature-Work Element | 被引用的学术著作/论文的基本信息与核心论点 | 分析报告中的"著作/文献"实体表 |
| K04 | 论证结构元 | Argument-Structure Element | 文本论证的逻辑骨架（前提、转折、推论、结论） | 各章分析报告中的"逻辑梳理"节 |
| K05 | 方法论元 | Methodology Element | 被描述或使用的研究方法、工具、策略 | 分析报告中的"方法/工具"实体表 |
| K06 | 案例-实践元 | Case-Practice Element | 被引用的设计实践案例、事件、展览 | 分析报告中的"事件/案例"实体表 |
| K07 | 关系元 | Relation Element | 知识元之间显式或隐式的语义关系类型 | 各章分析报告中的"与前后章关联"、"关键概念对偶关系"等 |

### 2.2 知识元的抽取规则

- **完整性规则**：每一知识元必须包含：编号、名称（中/英）、来源章节、L###行号、核心语义属性。
- **不可再分规则**：知识元应抽取至不可再分的语义单元。若一个实体包含两个独立语义（如同一学者的两个独立贡献），应拆分为两个知识元。
- **跨章归并规则**：同一实体在多个章节中出现时，合并为一个知识元，但在"出现章节"属性中标注所有出现位置，在"语义演化"属性中标注各章中该知识元的功能变化。
- **显隐双取规则**：既抽取分析报告中显式列出的实体（如NN_专项报告中的六类总索引），也抽取分析报告叙述中隐含但未被编号的语义实体（如"对称式三段论"这一论证结构特征未在实体表中编号，但应作为论证结构元抽取）。

### 2.3 知识元的语义属性标注

每个知识元需标注以下语义属性：

| 属性 | 说明 |
|------|------|
| 编号 | 七类体系内统一编号 |
| 名称（中/英） | 中文译名 + 英文原名 |
| 类别 | K01-K07之一 |
| 来源章 | 分析报告中的章节位置 |
| L### | 分析报告行号 |
| 核心语义 | 一句话概括的知识贡献 |
| 语义维度标签 | 按L4计算规则中的维度标注（新概念/新论证/跨学科/方法操作/社会语境） |
| 与其他知识元的关联ID | 直接关联的知识元编号列表 |

## L3：语义链接规则

### 3.1 语义链接的类型

知识元之间的语义链接分为七种类型：

| 链接类型 | 英文 | 定义 | 符号 |
|----------|------|------|------|
| 继承-发展 | Inheritance-Development | 知识元B在知识元A的基础上提出、深化或修正 | → |
| 对立-辩证 | Opposition-Dialectic | 知识元A与知识元B构成正反题关系，引出合题C | ⇄ |
| 类比-映射 | Analogy-Mapping | 知识元A与知识元B在结构或功能上平行对应 | ≈ |
| 层级-包含 | Hierarchy-Containment | 知识元A是知识元B的上位范畴或下位实例 | ⊃ |
| 因果-推导 | Cause-Derivation | 知识元A是知识元B的逻辑前提或论证来源 | ⇒ |
| 聚合-涌现 | Aggregation-Emergence | 多个知识元的交互产生新知识结构，不可还原为任一单元素 | ⊕→ |
| 界面-跨界 | Interface-Crossover | 知识元A与B分属不同学科领域，在交叉地带产生新语义 | ⇔ |

### 3.2 语义链接的构建规则

1. **最小语义距离规则**：优先建立直接语义关联；间接关联（通过第三知识元）在链网图中以虚线表示。
2. **显式链接优先**：分析报告中明确描述的关系（如"关键概念对偶关系"表）直接采纳为链接。
3. **隐式链接挖掘**：分析报告中未显式描述但可从语义内容推断的关系，标注为"隐式链接"并以[隐]标记。
4. **涌现链接识别**：当三个及以上知识元之间的多边关系产生新语义时，标注为⊕→链接并命名其涌现产物。

### 3.3 语义链接网络的构建步骤

1. 从七类知识元中识别核心节点（高频出现、多维度连接的枢纽知识元）。
2. 按L3.1中的七种链接类型建立边。
3. 标注每条边的强度（1-5：1=弱关联/仅提及，5=强关联/核心论证依赖）。
4. 识别涌现子图——即封闭三角或多边形中产生的新语义。
5. 以Mermaid图 + 邻接矩阵双重表示。

## L4：涌现计算规则

### 4.1 涌现度的定义

涌现度（Emergence Degree, ED）衡量一个知识结构在多大程度上具备"不可还原性"——即其语义内容不能从组成它的知识元中线性推出，而必须通过知识元之间的特定交互模式才能生成。

### 4.2 五维涌现度计算模型

涌现度从五个维度进行量化计算：

| 维度 | 代码 | 定义 | 权重 |
|------|------|------|------|
| 概念新颖度 | CN (Concept Novelty) | 知识元是否提出新的概念命名或概念重新定义 | 0.25 |
| 论证结构涌现度 | AS (Argument Structure) | 论证逻辑是否包含不可从前提线性推出的转折或综合 | 0.25 |
| 跨学科桥接度 | IB (Interdisciplinary Bridging) | 知识元是否连接了两个及以上不同学科领域的语义资源 | 0.20 |
| 方法操作化度 | MO (Method Operationalization) | 抽象概念是否被转化为可操作的方法标准或工具 | 0.15 |
| 社会语境嵌入度 | SC (Social Context) | 知识元是否将学科内部问题与社会语境（知识社会、集体实验等）关联 | 0.15 |

### 4.3 涌现度计算公式

知识元i的涌现度 ED(i) = CN(i) x 0.25 + AS(i) x 0.25 + IB(i) x 0.20 + MO(i) x 0.15 + SC(i) x 0.15

其中每个子维度的评分范围为0-5（0=无该维度特征，5=最强烈体现该维度特征）。

对于涌现结构（多个知识元的交互产物），涌现度计算公式为：

ED_structure = Σ(ED(i)) / n + IE_factor

其中IE_factor（交互涌现因子）衡量知识元之间交互产生的新语义强度（0-3）。

### 4.4 涌现度等级

| 等级 | ED值范围 | 含义 |
|------|----------|------|
| L5 | 4.0-5.0 | 突破性涌现：提出全新的概念体系或方法论范式 |
| L4 | 3.0-3.9 | 结构性涌现：在现有知识体系中构建了新的组织框架 |
| L3 | 2.0-2.9 | 连接性涌现：在已有知识之间建立了新的语义连接 |
| L2 | 1.0-1.9 | 增量性涌现：对现有知识的局部修正或细化 |
| L1 | 0.0-0.9 | 复述性知识：对已知知识的重新表述，未产生新语义 |

## L5：知识发现规则

### 5.1 知识发现的定义

知识发现（Knowledge Discovery）是指在知识元语意分析和语义链接网络的基础上，识别出原分析报告中未被显式表述、但可从知识元交互和涌现计算中合理推断的新知识命题。

### 5.2 知识发现的四类操作

| 操作 | 定义 | 示例 |
|------|------|------|
| 填补空白 | 识别分析报告中的"缺失"（如对六维标准来源的不完备性），从知识元网络中推断缺失的原因或可能的填补方案 | 从Part 1+Part 2的知识元推导六维标准为何恰好是"这六个" |
| 揭示涌现 | 识别多知识元交互中产生的、超出原始文本表述的新知 | 从"界面""之间""边界模糊"等概念的网络中识别出"界面本体论"的涌现 |
| 批判评估 | 基于涌现计算，对原始论文的论证结构进行知识论层面的评估 | 评估"双重论证"对称结构的知识论强度 |
| 前瞻推演 | 基于涌现网络的未闭合节点，推断可能的研究前沿 | 从"缺失的策略"和"待未来观察"节点推演设计虚构的未来研究方向 |

### 5.3 知识发现的表述规范

每条知识发现应包含：
1. 发现编号（F01, F02...）
2. 发现类型（填补空白/揭示涌现/批判评估/前瞻推演）
3. 发现命题（一句话陈述）
4. 依据的知识元与链接（编号引用）
5. 涌现度评估（ED值）
6. 详细论证（200-500字）

### 5.4 与原始分析报告的关系

知识涌现分析不是对原始分析报告的否定或替代，而是其**元层次的补充**。原始分析报告承担"文本细读与实体识别"功能，知识涌现分析承担"知识结构建模与创新发现"功能。两者构成"分析→涌现"的认知阶梯。
