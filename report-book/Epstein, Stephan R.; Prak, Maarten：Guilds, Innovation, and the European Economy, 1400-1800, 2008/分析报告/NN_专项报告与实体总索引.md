### 专报二：全书方法论工具与论证策略

#### 2.1 核心论证策略

| 策略 | 说明 | 典型章节 |
|------|------|----------|
| 反直觉颠覆 | "众所周知……但事实并非如此"的基本叙事语法 | 全书各章 |
| 稻草人-驳倒-建构 | 先陈述对手最强论点→揭示经验薄弱→建构替代解释 | Ch2,Ch7 |
| 功能性替代解释 | 不问"行会好不好"而问"在给定条件下是否有效率" | Ch1,Ch6 |
| 拆解-分别回应 | 将对手论点拆为认识论和制度部分，分别回应 | Ch2 |
| 规章≠实践 | 区分书面规则与实际执行，关注规则的日常规避 | 导论,Ch2,Ch5 |
| 条件性效率 | 拒绝本质化判断，始终询问"在什么条件下" | Ch1,Ch6 |
| 反事实构建 | 通过比较成功与失败案例来推断关键条件 | Ch6,Ch10 |
| 实践转向 | 关注行会的日常运作而非制度条文 | Ch3,Ch5,Ch8 |
| 概念投射 | 将现代社会科学概念(Marshall/Porter/Polanyi)投射到历史语境 | Ch1,Ch5,Ch7 |
| 历史谱系学 | 追溯"传统叙事"本身的建构过程 | Ch11 |

### 3.2 全书"条件性"命题体系

全书共享一个核心的认识论立场：行会制度的效应取决于具体条件。下表汇总各章识别的关键条件变量：

| 条件变量 | 影响方向 | 来源章节 |
|----------|----------|----------|
| 行会内部结构(分层vs民主) | 精英控制的层次越多→越可能采纳节约劳动力技术 | Ch6 |
| 政治经济地位(帝国城市vs君主国首都) | 独立城市民主行会→更可能抵制技术；首都分层行会→更可能采纳 | Ch6 |
| 市场竞争强度 | 竞争越强→保守行为越难以维持 | Ch2,Ch11 |
| 工匠-企业家政治发言权 | 有市政代表权→转包网络更可能促进创新 | Ch3 |
| 国家监管强度 | 强国家监管→行会创新空间被挤压(威尼斯) | Ch7 |
| 产品质量标准化程度 | 可标准化→全国管辖权可能(伦敦金属行会) | Ch10 |
| 地理距离/运输成本 | 高距离成本→技术采纳压力降低→市场分割 | Ch6 |
| 产业生命周期阶段 | 创建初期→效率导向；晚期→可能退化为寻租 | Ch1 |
