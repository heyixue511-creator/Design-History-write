# NN_专项报告与实体总索引

## 专项报告一：全书Box体系分析

### Box的功能分类

全书11章共有约40+个Box（含正式Box和隐性的exercise comment）。按其功能分为五类：

**1. 案例研究型（Case Study Box）**
L### Box 1.2 "Mobile Life"——四条新闻剪报展示移动社会影响的多面性
L### Box 2.3 "It Doesn't Look Like a Camera"——Ericsson affordance研究
L### Box 3.2 "The Fall and Rise (Perhaps) of WAP"——WAP成败全分析
L### Box 5.2 "Quiet Calls prototype"——从民族志到设计的完整链路
L### Box 7.2 "The Long Way Round"——74次按键用户的启示
L### Box 8.3 "Taking Inspiration from Computer Science"——B+Tree的计算机科学灵感
L### Box 9.1 "Flexible Organic Light Emitting Diode Screens"——未来显示技术
L### Box 9.3 "Using Keyphrases for Small-Screen Skim Reading"——文本挖掘应用
L### Box 10.1 "Treemaps"——可视化技术介绍
L### Box 10.2 "RSVP"——快速序列视觉呈现

**2. 访谈型（Interview Box）**
L### Box 1.3 "Implanting Your Mobile?"——Kevin Warwick教授访谈
L### Box 1.6 "Aromatic Output?"——Jenny Tillotson访谈
L### Box 3.1 "Innovation"（内含Christensen概念但非纯访谈）
L### Box 4.6 "Expert Insights"——Scott Jenson访谈
L### Box 5.3 "Trend-spotting, Trend Forming"——Elise Levanto(Nokia)访谈

**3. 概念框架型（Concept/Theory Box）**
L### Box 2.1 "'Users'?"——对"user"一词的术语批判
L### Box 2.2 "Golden Rules of Design"——Shneiderman八项黄金法则
L### Box 2.4 "Visibility and Mappings: Semi-Transparent Widgets"
L### Box 3.1 "Innovation"——sustaining vs disruptive innovation
L### Box 3.3 "SMS Serendipity"——SMS作为偶然成功
L### Box 4.1 "Interaction Design Defined"——交互设计的历史与定义
L### Box 4.5 "What is Design?"——Fallman的三种设计范式
L### Box 5.1 "The Essence of Ethnographically-Inspired Approaches"——民族志方法论
L### Box 7.1 "Thinking Aloud"——出声思维的困难（开车类比）
L### Box 7.3 "What is Context?"——情境的分类
L### Box 7.5 "Context Awareness"——情境意识批判

**4. 方法/技术型（Method/Technique Box）**
L### Box 6.3 "The Real Reason Why Telephone Trunk Cable is Brightly Colored"（实质上也是社会批判）
L### Box 8.1 "Infinitely Long Menus"——循环菜单的认知陷阱
L### Box 8.2 "Only Two Users"——Cooper的用户迁移理论
L### Box 9.2（无明确标题的技术讨论）

**5. 历史/背景型（History/Context Box）**
L### Box 1.1 "How Times Have Changed"——1954年移动电话的社会史
L### Box 1.4 "Just Another Tool?"——mobiles as pick-up-and-use devices
L### Box 1.5 "The Trouble with Speech"——语音界面问题
L### Box 1.7 "Flowers from Dead Mobiles"——手机环保问题
L### Box 11.1 "The Real Reason Why Telephone Trunk Cable is Brightly Colored"——电话线篮子

### Box体系的分布特征
L### Part I（第1-3章）：Box密度最高，主要用于建立视野和提供多样化视角
L### Part II（第4-7章）：Box以概念框架和专家访谈为主，服务于方法论教学
L### Part III（第8-11章）：Box以案例研究和技术背景为主，补充正文的设计指南
L### 访谈Box集中在第1章（Kevin Warwick, Jenny Tillotson）、第4章（Scott Jenson）和第5章（Elise Levanto）——均位于关键的方法论转折点

### Box的设计功能
L### (a) 提供"另一个声音"——访谈Box引入与作者不同的行业视角
L### (b) 浓缩复杂信息——如Box 3.2（WAP成败）将多年行业教训压缩在一页内
L### (c) 合法化"非常规"讨论——Kevin Warwick的植入式设备通过"访谈"形式进入学术讨论
L### (d) 提供教学锚点——Box 2.2（八项黄金法则）是后续章节反复引用的checklist
L### (e) 嵌入个人反思——Box 7.2（74次按键）将实验中的"坏数据"转化为教学材料

## 专项报告二：全书论证策略类型学

### 七大论证策略

**策略1：二元对立建构→辩证综合**
L### 应用章节：第1章（3组or问题）、第3章（技术中心↔用户中心光谱）、第5章（启发型↔告知型）、第7章（实验室↔情境）
L### 典型表达："communication or information device?" "appliance or Swiss army knife?" "cherished device or commodity tool?"

**策略2：反直觉冲击**
L### 应用章节：第1章（问题不在硬件贫瘠而在设计贫乏）、第3章（SMS不能作为放弃UCD的理由）、第6章（纸板是VR的必需品）、第8章（图标最好情况是无关、最坏情况是干扰）
L### 效果：打破读者常识，建立认知新颖性

**策略3：隐喻体系贯穿**
L### 核心隐喻：建筑/戏剧隐喻（Winograd→全书）、Aladdin精灵（第9章）、拼图游戏（第5章）、巧克力奶泡（第2章）、彩票（第3章Box 3.3）
L### 功能：将抽象概念转化为可感知、可记忆的形象

**策略4：失败叙事作为教学工具**
L### 应用章节：第3章Box 3.2（WAP失败）、第6章（作者"三个月浪费"）、第10章（Java移植失败）、第11章（电话线篮子）
L### 作者自己的失败（第6/10章）建立"共犯"关系，他人的失败（WAP/3G）建立分析距离

**策略5：从个人到全球的尺度跃迁**
L### 轨迹：你的手机菜单（Ch8）→数亿用户的信息访问问题（Ch9）→全球半数人口唯一交互设备即手机（Ch11）
L### 修辞目的：将读者的情感投入和伦理承诺逐步升级

**策略6：实证数据与人文叙事交替**
L### 典型段落结构：定量发现（"36%任务成功"）→用户引语（"it would be cheaper to buy a newspaper"）→设计启示
L### 效果：数据建立可信度，叙事建立共情

**策略7：第一人称的"在场"叙事**
L### 应用章节：第5章Macaulay的田野困惑、第6章作者的"三个月浪费"和婚前课程、第8章"我只有一次成功交换过Bluetooth名片"、第10章"we won't bore you with the details"
L### 功能：降低作者与读者之间的权威距离，将"教科书作者"转化为"有经验的同行"

## 专项报告三：全书跨学科知识网络

### 知识来源地图

```
计算机科学 ─── 认知心理学 ─── 社会学/人类学 ─── 设计学 ─── 商业管理
     │              │              │              │        │
数据结构    短时记忆理论    民族志方法    Norman原则  Christensen颠覆创新
(B+Tree)    (7±2)          (Monk et al)  (四原则)   (维持vs颠覆)
     │       识别vs回忆    参与观察     Fallman范式  TAM模型
算法分析    (Paap)         扎根理论     三种设计     创新策略
(按键次数)  GOMS/KLM      文化维度     affordance   市场分析
     │       出声思维      (Hofstede)   视觉语言     技术接受
API设计     (Ericsson)     社会影响分析  PICTIVE     产品策略
     │              │              │              │        │
     └──────────────┴──────────────┴──────────────┴────────┘
                            │
                    移动交互设计
                 (Mobile Interaction Design)
```

### 关键跨学科融合点
L### **认知心理学 + 数据结构 = 菜单设计**（第8章B+Tree）
L### **民族志 + 照片管理 = 移动图像浏览设计**（第10章）
L### **颠覆性创新理论 + 用户研究 = 创新策略评估**（第3章）
L### **文化维度 + 视觉设计 = 跨文化界面批判**（第11章）
L### **实验心理学 + 界面设计 = 情境评估方法论**（第7章）

### 知识空白
L### **情感计算/Affective Computing**——全书未讨论情绪识别或情感响应设计
L### **神经科学**——只有第10章一句话提及"half the cerebral cortex"，未进入方法层面
L### **行为经济学**——Nudge理论、默认效应等完全未涉及
L### **语言学**——界面术语的语言学分析仅限于Box 2.1的"user"术语批判
L### **性别研究**——仅第4章有一段Sadie Plant的民族志片段（手机与性别），缺乏系统讨论
