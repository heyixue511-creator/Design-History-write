### 专项报告一：全书隐喻体系分析

Holmes在本书中部署了一套严密且贯穿始终的隐喻系统，以**游戏/玩耍**为统摄性隐喻，辅以**建筑/空间**、**语言/词汇**、**牙齿护理**等子隐喻。这套系统不仅是修辞装饰，更是论证的认知基础设施。

#### 1. 统摄隐喻：游戏与玩耍（Play/Game）

| 隐喻元素 | 首次出现 | 关键出现章节 | 功能 |
|---------|---------|------------|------|
| 游乐场（playground） | Ch1 L155-L161 | Ch1, Ch2, Ch4, Ch8 | 包容性社会的微缩模型 |
| 游戏规则（rules of the game） | Ch2 L365-L370 | Ch2, Ch3, Ch6 | 排斥作为"规则设定"的产品 |
| "你不能说'你不能玩'"（Paley规则） | Ch2 L371-L401 | Ch2, Ch3 | 打破排斥循环的社会实验原型 |
| "谁来玩？"（who shows up to play） | Ch1 L345 | Ch1, Ch9 | 包容性设计的最终检验标准 |
| 游戏控制器（game controllers） | Ch4 L642-L716 | Ch4 | 能力偏见在消费产品中的物质化证据 |
| 元游戏（metagame of exclusion） | Ch4 L717-L718 | Ch4 | 被排斥者为适应不匹配设计而必须额外付出的智力/体力劳动 |

**隐喻功能**：游戏隐喻允许Holmes同时讨论童年行为（情感记忆）、社会规则（权力分析）和设计决策（专业实践）——而不需要在三个层面之间切换论述框架。

#### 2. 空间/建筑隐喻

| 隐喻元素 | 功能 |
|---------|------|
| 封闭-排斥圆圈（shut-in-shut-out circle） | Ch2——展示"包容/排斥"的语言学心理模型 |
| 墙（wall）——Porter的"排斥之墙" + 旧金山的"15英尺的墙" | 排斥的物质化身 |
| 后巷入口（back-alley entrances）vs 壮观正面阶梯（grand front staircase） | Ch3——设计选择中的权力与可见性 |
| "塔楼在公园中"（towers in the park）→ 联邦公共住房高层塔楼 | Ch5——美学理想如何成为排斥性政策的技术载体 |

#### 3. 其他关键隐喻

| 隐喻 | 出现章节 | 功能 |
|------|---------|------|

### 专项报告二：全书核心概念的谱系与相互区分

#### 核心概念三角：Inclusive Design / Accessibility / Universal Design

```
                  ┌─────────────────────────┐
                  │   Inclusive Design       │
                  │   (包容性设计)            │
                  │   方法论/过程导向          │
                  │   来源：数字技术           │
                  │   One-size-fits-one      │
                  │   关键：包括排斥社区的参与   │
                  └───────────┬─────────────┘
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
┌───────▼────────┐   ┌────────▼────────┐   ┌───────▼──────────┐
│  Accessibility │   │ Universal Design│   │  "Design For"    │
│  (无障碍)      │   │ (通用设计)       │   │  (排斥性范式)     │
│  属性/学科     │   │ 最终结果导向     │   │  未包含排斥社区   │
│  来源：法律/政策 │   │ 来源：建筑/环境   │   │  基于刻板印象     │
│  Attribute     │   │ One-size-fits-all│   │  Benefactor模型   │
└────────────────┘   └─────────────────┘   └──────────────────┘
```

#### 关键区分（全书跨章提取）

| 对比维度 | 排斥范式 | 包容范式 |
|---------|---------|---------|
| 思考起点 | 包容是什么？（模糊） | 排斥在哪里？（具体可测） |
| 设计对象 | 为平均/正常人类设计 | 为最被排斥的人设计→扩展到多人 |
| 设计者-使用者关系 | 设计者为使用者（for） | 设计者与使用者共同设计（with） |
| 残障的理解 | 个人健康问题（需要修复） | 不匹配的互动（需要重新匹配） |
| 多样性的处理 | 单维度人口统计分类 | 能力光谱（人人皆在变化） |
| 时间的框架 | 项目周期 | 代际循环 |
| 基准 | 平均值 | 个体匹配 |
| 商业定位 | 成本中心/合规负担 | 创新驱动力/增长机遇 |
