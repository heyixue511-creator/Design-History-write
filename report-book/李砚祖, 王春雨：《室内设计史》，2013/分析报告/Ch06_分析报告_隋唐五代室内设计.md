# Ch06 分析报告：隋唐、五代室内设计

## 一、章节定位与功能（行号范围 L383-L448）

本章叙述隋、唐、五代的中国室内设计，是"中国线"的第二个高峰。标题"隋唐、五代室内设计"（L383-L384）。导言断言隋唐建筑"达到中国古代建筑史上的第二个高峰"（L391）。功能上完成：里坊制都城的巅峰（L388）、全木构架的定型与模数化（L395）、起居方式由席坐向垂足坐的过渡（L395）、以及建筑装饰的"大唐之风"（L423）。由 6.1 营造成就概说、6.2 建筑的空间形态与装饰装修、6.3 室内家具陈设构成（L386-L445），末附参考资料（L447-L448）。

## 二、结构分析

- L383-L384：章题与导言（隋唐五代年代、隋统一至五代十国）。
- L386-L398：6.1 隋唐、五代营造成就概说
  - L388：6.1.1 城市规划与城市建设（大兴城/唐长安、洛阳、地方城市）。
  - L391-L395：6.1.2 营造技术与建筑成就（全木构架定型、砖石结构、唐风形式、模数设计）。
  - L397-L398：6.1.3 管理机构与建筑制度（尚书工部、将作监；《唐六典》《营缮令》）。
- L400-L439：6.2 建筑的空间形态与装饰装修
  - L402-L418：6.2.1 建筑结构与空间形态（殿堂型、厅堂型构架；大型官方建筑；住宅）。
  - L421-L433：6.2.2 室内空间界面形式（墙面及门窗、地面、藻井与顶棚、主要建筑构件）。
  - L435-L439：6.2.3 室内空间的组织与分隔（槅扇、帘、帷帐、屏风；织物与陈设）。
- L441-L445：6.3 室内家具陈设（起居方式转变与高型家具、家具类型、织物）。
- L447-L448：主要参考资料（15 种）。

## 三、内容分析

1. **营造成就（L386-L398）**：
   - 城市规划：隋大兴城（唐长安）东西 9721m、南北 8651m、面积 84.1km²，"中国古代规模最大的都城"（L388）；里坊制城市巅峰；洛阳"洛水贯都"（L388）；安史之乱后南方城市繁荣（扬州、益州）与草市、夜市（L388）。
   - 技术：全木构架"基本成熟，进入定型化、设计模数化"（L395）；隋乾阳殿、唐麟德殿、武则天明堂（高 86.4m）为最高大木构建筑（L395）；李春安济桥（敞肩券大石桥）（L395）；"材分"模数体系（L395）。
   - 制度：《唐六典》"凡宫室之制，自天子至于士庶，各有等差"（L398）；《营缮令》详列各品住宅规制（L398）；尚书工部与将作监两系统（L397）。
2. **空间与装饰（L400-L439）**：
   - 殿堂型/厅堂型构架（L407-L408）：殿堂型"柱网+铺作层+屋顶构架"三层、单槽双槽斗底槽柱网；厅堂型内柱自由；"彻上明造"。
   - 墙面门窗（L423-L427）：白垩"缥壁""白壁丹楹"；壁衣、壁画（经变画"世俗化"）；版门、直棂窗（破子棂窗/板棂窗）、格子门前身（五代"格子门"）。
   - 地面（L430）："彤墀""玄墀"；大明宫石铺地与大素面砖；花砖墁地；白居易《红线毯》"地衣"描写。
   - 藻井顶棚（L433）：斗四斗八藻井、平棊、平闇、彻上明造；敦煌藻井彩绘。
   - 构件装饰（L436）：莲花须弥座、覆盆柱础、包镶贴饰（"文柏贴柱"）、外来纹样中国化（卷草纹、连珠纹、宝相花）。
   - 空间分隔（L435）："截间格子"、帘、帷帐、屏风；隋唐"设屏"与"扆"的运用。
3. **家具（L441-L445）**：席坐向垂足坐过渡；高型家具出现（椅、凳、高桌）；月牙凳、圈椅、墩；织物（椅披、桌围）用于家具。

## 四、逻辑梳理

本章逻辑链：**统一帝国的强盛→都城与建筑的规模登峰→模数化技术成熟→装饰的大唐之风→起居方式转变**。与前代不同的是，隋唐将汉以来的"礼制等级"落实为成文的《营缮令》制度（L398），并把"材分"模数推向定型（L395），为宋《营造法式》奠定了基础。

## 五、材料使用方式

- **文献与遗址互证**：唐长安实测、大明宫遗址考古（含元殿、麟德殿、玄武门）与《唐六典》《营缮令》《唐会要》等制度文献（L388、L398、L430）。
- **诗赋引证**：白居易《草堂记》《红线毯》、李思训"江帆楼阁图"（L395、L430、L427）作为住宅与地衣描写的文学证据。
- **图像资料**：敦煌壁画（经变画、花砖地面、帐幕、家具）、墓室壁画（永泰公主墓、懿德太子墓）与建筑明器（王休泰墓、中堡村唐墓）（L423、L427、L430、L433、L418）。
- **转述现代研究**：傅熹年《中国古代建筑史·第二卷》、刘敦桢《中国古代建筑史（第二版）》、李允鉌《华夏意匠》等（L395、L407、L448）。

## 六、论辩与阐述方法

1. **高峰论**：以"第二个高峰""模数设计……一大创造""大唐之风"等判断句定调（L391、L395、L423）。
2. **制度-建筑对应**：将《营缮令》各品规制与住宅明器、遗构比对（L418）。
3. **结构类型学**：殿堂型/厅堂型构架分类，说明柱网与室内空间的关系（L407-L408）。
4. **文-图互证**：诗歌、壁画、明器、遗构四方印证家具与界面（L430、L433、L444）。
