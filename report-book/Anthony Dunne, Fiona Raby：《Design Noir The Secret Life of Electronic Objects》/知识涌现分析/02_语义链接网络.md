## 七、语义链接网络的动态特征

### 7.1 路径依赖：论证的不可逆性

全书论证具有明确的**路径依赖**特征——概念的出现和关系的建立遵循不可逆的顺序：

```
S01（现象·异常）→ S02（本体·空间）→ S03（范式·类型）→ S04（伦理·身份）→ S05（实证·验证）
```

在网络拓扑上，这意味着不存在从S05回到S01的强因果链接——Placebo项目的实证结果没有"反馈修改"病理学方法论的初始假设。这一特征揭示了全书的方法论性质：**验证性**（理论的实证演示）而非**探索性**（从数据中归纳理论）。

### 7.2 网络中的"弱链接"富集区

网络中强度为WEAK_INF的29条链接主要集中在：

| 区域 | WEAK_INF链接数 | 含义 |
|------|---------------|------|
| 问题元与其他知识元之间 | 18 | 问题是开放的，与现有知识的链接本质上是推测性的 |
| 跨社区连接（A↔B, C↔D等） | 7 | 社区之间的连接往往由推论而非显性陈述支撑 |
| 隐喻概念元与其他知识元之间 | 4 | 隐喻类比的跨域性质导致其链接基础较弱 |

### 7.3 网络中的"结构洞"检测

## 八、语义链接网络的可视化描述

### 8.1 网络骨架的三层同心圆结构

```
                     ┌───────────────────────┐
                     │   外层：证据层（E类）    │
                     │  ┌─────────────────┐  │
                     │  │ 中层：命题层（P类）│  │
                     │  │ ┌─────────────┐ │  │
                     │  │ │ 内层：概念层 │ │  │
                     │  │ │  （C类 +    │ │  │
                     │  │ │   R类核心）  │ │  │
                     │  │ └─────────────┘ │  │
                     │  └─────────────────┘  │
                     └───────────────────────┘
                     
                     方法元（M类）贯穿三层
                     断言元（A类）锚定在命题层
                     问题元（Q类）从网络边缘向外指向未知空间
```

### 8.2 论证弧的三段式

网络中的链接密度沿"章序"轴呈现三段式分布：

| 弧段 | 章序 | 内部链接密度 | 跨段链接密度 | 论证特征 |
|------|------|-------------|-------------|----------|
| 弧Ⅰ | Ch01-Ch08 | 高（内部密集） | 中 | 问题空间的开辟与理论基础的建立 |
| 弧Ⅱ | Ch09-Ch14 | 高（内部密集） | 高（与弧Ⅰ和弧Ⅲ均有强链接） | 从经验维度到范式命名——网络的"重心" |
| 弧Ⅲ | Ch15-Ch20 | 中（内部松散但跨域丰富） | 高 | 伦理辩护到实证验证——概念的"落地" |

**涌现特征**：弧Ⅱ是网络的"高密度核心"——它同时与弧Ⅰ（回溯链接到赫兹空间的经验展开）和弧Ⅲ（前瞻链接到批判性设计与实证）保持高强度链接。这一结构表明Design Noir（Ch14）不仅是全书的概念高潮，也在网络拓扑上是全书的知识"重心"：通过它，全书的理论端（弧Ⅰ）和实践端（弧Ⅲ）实现了结构耦合。
