# 00_方法与规则：知识涌现分析框架

## L001 本模块的定位与目标

本模块"知识涌现分析"是对《The Origins of L'Art Nouveau: The Bing Empire》（Weisberg、Becker、Possémé 编，2004）14 份分析报告（00 整体 + Ch01-Ch12 分章 + NN 专项）的二次知识加工。与先行"分析报告"模块（逐章研读、实体提取、论点评判）不同，本模块旨在将分析报告视为一个"知识系统"，运用语义网络分析和涌现计算，揭示各章之间、各实体之间、各论点之间的结构性关联，发现那些在单章分析中不可见、仅在全景观照下才能浮现的"涌现知识"（emergent knowledge）。

核心问题意识：（1）本书作为知识整体，其内部结构是怎样的？（2）哪些实体、概念和论点构成知识网络的"枢纽节点"？（3）各章之间的交叉引用与论点互动形成了怎样的"语义链接"？（4）从这些链接中可以计算出哪些涌现模式——例如"最密集论辩区""最稳固共识区""知识空白区"？（5）最终可产生哪些超越线性阅读的"知识发现"？

## L002 "知识涌现"的操作性定义

**知识元（Knowledge Unit, KU）**：分析报告中可独立识别、具有语义完整性的最小知识片段。包括六类实体（人物、著作/作品、概念、机构、地点、事件）与五类命题（论题、论点、证据、因果链、反事实假设）。

**语义链接（Semantic Link, SL）**：两个知识元之间经由分析报告文本明确建立的关系。本模块遵循方法说明书定义的 9 种标准语义链接类型（详见 L005）。

**知识涌现（Knowledge Emergence）**：当知识元网络中的一个子结构（如三元组 A→B→C，或一个节点簇）产生出不能归约于其构成节点之和的特征或信息时，即发生知识涌现。涌现的判定依据包括：节点度 k、桥接值 b、簇识别（强连通）、内聚度、涌现强度 S、一级/二级涌现。

## L003 方法论步骤

本模块按以下五步展开：
1. **方法与规则（本文件，00 号）**：定义层级（知识元→Topic→Theme）、9 种语义链接判定标准、涌现指标与证据规范。
2. **知识元语意分析（01 号）**：六类实体的全文语义载荷分析，先总述五种论证功能（因果节点/结构变量/类型标签/证据载体/参照坐标），再按类分表，附行号证据。
3. **语义链接网络（02 号）**：核心枢纽识别（k、b 排序）、按主题区组织的链接清单、枢纽与中介分析、网络整体特征。
4. **知识涌现计算（03 号）**：Topic 识别（6-15 个连通簇）、Theme 聚合（3-5 个高层域）、内聚度与涌现强度 S 计算、一级/二级涌现结构、客观性核对。
5. **知识发现报告（04 号）**：结构发现、隐藏枢纽与"点到未论"潜在链接（C1…Cn）、跨主题综合命题、完整层级图谱、总体评价与边界声明。

## L004 层级定义

本模块采用三层知识结构：
- **知识元（Knowledge Unit）**：最底层。六类实体（人物/著作作品/概念/机构/地点/事件）+ 五类命题。
- **Topic（强连通簇）**：中层。由语义链接紧密互连的知识元簇组成，簇内各节点通过因果、隶属、时序、空间共现等链接构成强连通子图。预期识别 6-15 个。
- **Theme（高层语义域）**：顶层。多个 Topic 因共享桥接元（共享人物、共享场所、共享概念）而聚合而成的高层语义域。预期聚合 3-5 个。

## L005 九种语义链接判定标准

| 编号 | 类型 | 符号 | 判据 | 例（本书） |
|------|------|------|------|-----------|
| SL1 | 因果 | → | A 在文本中被明确指认为 B 的原因或前提 | 日本珍品供应枯竭（L661）→ 宾格转向新艺术 |
| SL2 | 条件 | ⇒ | A 是 B 成立的必要/充分条件（"若非/只有/只要"） | 若非法国民族主义批评（L2316）⇒ 宾格未必 1900 年回归传统 |
| SL3 | 对比 | ↔ | 文本明确将 A 与 B 对比/对照 | Gaillard（力量理性）↔ de Feure（优雅） |
| SL4 | 隶属 | ⊂ | A 是 B 的成员/子类/组成部分 | Colonna ⊂ 宾格设计师团队 |
| SL5 | 时序 | ≻ | A 在时间上先于 B（且文本按序叙述） | 1895 画廊开业 ≻ 1897 德累斯顿展 |
| SL6 | 空间共现 | ≈ | A 与 B 在同一场所/地域同时出现或关联 | 宾格画廊 ≈ 22 rue de Provence |
| SL7 | 属性 | : | A 具有属性 B（B 是 A 的特征/状态） | 宾格 : 创意企业家 |
| SL8 | 论证支撑 | ⇐ | A 是支持命题 B 的证据/论据 | Deneken 通信 ⇐ 工坊 1898 年已运转 |
| SL9 | 同域 | ∼ | A 与 B 属于同一领域/主题类别（无因果时） | 宾格帝国 ∼ 新艺术运动 |

### 判定细则
- 每条链接必须能溯源到分析报告的具体章节与行号；禁止凭空构造。
- 当两个节点间的关联在文本中以含糊语言表述（"可能""也许""难以确定"）时，仍按类型记入，但需在链接清单中标注"不确定性"。
- 反例与边界：若文本同时给出相反方向的证据（如商业动机与艺术理想并存），则该链接记为双向/张力链接，并在 02 号文件"客观性核对"中说明。

## L006 涌现指标定义

### 1. 节点度 k
一个知识元与网络中其他知识元直接相连的链接数。k 越高，该节点越是局部枢纽。

### 2. 桥接值 b
一个知识元连接不同 Topic/Theme 的跨簇链接数。b 越高，该节点越是全局桥梁——它使不同语义域相互连通。

### 3. 簇识别（强连通）
以"双向可达"为标准在语义链接图上识别强连通分量；再结合主题一致性（共享核心实体或共享概念）合并为 Topic。每个 Topic 应有明确的语义中心。

### 4. 内聚度 C
簇内实际链接数 L 与最大可能链接数 Lmax 之比：C = L / Lmax（Lmax = n(n-1)/2，n 为簇内节点数）。C 高表示该 Topic 知识高度紧密。

### 5. 涌现强度 S
对每个一级涌现结构（E1…En），S = 簇内聚度 C × 桥接元覆盖度 B（该簇连接到的 Theme 数 / 总 Theme 数）× 关键节点数校正。S 分级：高（0.6-1.0）、中（0.3-0.6）、低（<0.3）。

### 6. 一级/二级涌现
- **一级涌现（E）**：直接由知识元簇的聚集产生的结构特征——如"三个设计师团队"作为枢纽簇。
- **二级涌现（P）**：由多个一级涌现结构交互推衍出的、原书各章未明确表述的综合性命题——即知识发现。

## L007 证据规范

1. **行号证据**：所有知识元、链接与涌现结构必须标注源文件（`00-book/Weisberg：《The origins of lart nouveau the Bing empire》.md`）的实际行号，行号范围以正文 L147-L3038 为主体，辅以 Notes（L3040-L4173）与图录（L4174-L7121）。
2. **可追溯**：每条语义链接标注"所依据的分章报告 + 该报告所述的原书行号"。
3. **客观性核对**：对每个涌现结果提供反例、边界条件与不确定性说明。
4. **中文学术写作**：简体中文撰写，术语首次出现附原文。

## L009 与"分析报告"模块的关系

本模块是"分析报告"模块的元分析（meta-analysis）。其"原材料"不是原书，而是已完成的 14 份分析报告（00 + Ch01-Ch12 + NN）。本模块不重复逐章研读，而是在其基础上进行跨章整合、网络建模与涌现计算。
