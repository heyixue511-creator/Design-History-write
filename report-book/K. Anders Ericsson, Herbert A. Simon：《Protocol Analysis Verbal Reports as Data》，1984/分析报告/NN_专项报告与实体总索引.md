# NN 专项报告与实体总索引

## L### 一、专项报告一：全书的论证逻辑网络

### L### 1.1 全书的核心论证链条

本书的论证可以还原为一条单一的主论证链：

```
P1: 人类认知是信息加工过程，由注意力（STM）、记忆（LTM）和加工器组成。
P2: 口头行为是认知过程的一种输出形式，与其他行为受相同的认知约束。
P3: 只有在STM中被注意的信息才能被口头报告（因为报告需要通达该信息）。
P4: STM中的信息如果已经以口语编码存在，则口头化不需要额外加工资源（Level 1）。
P5: STM中的信息如果以其他编码存在，则口头化需要转码但不改变任务加工结构（Level 2）。
P6: 要求被试解释思维过程会引入额外的推理加工，改变任务加工结构（Level 3）。
C1: (从P3-P6) 在Level 1/2条件下，口头化不改变认知过程。
C2: (从P3) 口头报告的完整性=STM中被注意信息的完整性（自动化过程不可报告是模型的预测）。
C3: (从C1-C2) 口头报告在Level 1/2条件下是有效的认知过程数据。
C4: (从C3) 从口头报告中推论认知过程需要：任务分析+低层编码+弱理论假设。
```

### L### 1.2 全书的论证防御网络

本书不仅有一个"正面论证链"，还有一个针对批评者的"防御论证网"：

| 批评 | 所在章 | 防御策略 |
|---|---|---|
| "口头化改变思维过程" | 第二章 | 区分Level 1/2/3→展示Level 1/2条件下无效应 |
| "很多认知过程是无意识的，因此口头报告不完整" | 第三章 | 再认过程不可报告≠无意识；无意识学习的研究方法有问题 |
| "口头报告是副现象的" | 第三章/四章 | 如能由一个处理模型同时生成任务行为和口头报告，则副现象性不简约 |
| "口头报告不能作为硬数据" | 第一章 | 硬数据=主体间一致性，而非数据形式 |
| "编码口头报告需要理论，这导致循环论证" | 第一章/四章 | 使用"最弱理论"策略，最小化理论负载 |
| "口头报告反映的是个人特异经验，不能概化" | 第四章 | 条件化预测+承认个体差异≠否认规律性 |
| "人们可以给出理由但其理由与实际过程不符" | 第三章/四章 | 这种"理由"来自Level 3的推论过程，不应被当作Level 1/2的报告 |

## L### 二、专项报告二：书中最重要的方法论创新

### L### 2.1 "最弱理论"方法论原则

这是全书最核心的方法论创新——不是关于"口头报告是否有效"的实质性发现，而是关于"如何使用口头报告数据"的操作原则。

**原则表述**：编码口头报告数据时不可避免要使用理论假设，策略不是消除理论预设（不可能），而是使用"尽可能弱、最少争议"的理论假设，以最小化循环论证的风险。

**全书实施路径**：
- 第一章：原则提出——"we want to pick the weakest and most 'neutral' one that can do the job"
- 第二章：实施于经验审查——以"口语编码假说"作为最弱假设推导预测
- 第三章：实施于证据审查——以"STM=注意焦点"作为最弱假设评估完整性
- 第四章：实施于方法论——以"相关性/一致性/记忆"作为非理论性检验标准
- 第六章：实施于编码——以四个"弱假设"作为编码方法的基础

### L### 2.2 Level 1/2/3 三层次区分

这一区分是全书操作化程度最高的方法论创新。它使得"口头化是否改变认知过程"这一模糊问题变得可经验检验。

- **Level 1**：直接发声——对应Table 1-1中的"Talk Aloud"和"Think Aloud"（当信息已以口语编码存在时）
- **Level 2**：外化/描述——对应需要转码的"Think Aloud"（当信息以视觉等其他编码存在时）
- **Level 3**：解释——对应要求被试"给出理由"或"解释思考过程"的指令

这一区分的实践价值在于：当一项研究发现口头化效应时，研究者应首先检查口头化指令是否诱导了Level 3加工。

### L### 2.3 表1-1的口头化程序分类学

```
                直接一对一  多对一  不明确  无关系
信息被注意时        Talk Aloud / Think Aloud
信息仍在STM中        Concurrent Probing      中级推论
信息已从STM消失       Retrospective Probing   回溯推论
```

这一2×4矩阵是全书被引用最多的单张表格，它将口头化程序的操作特征（时间+映射）转化为可被经验检验的理论预测。

## L### 三、专项报告三：书中关键的"未解决问题"

作者在全书中表现出显著的学术诚实性，明示了多个当前模型的局限和开放问题：

1. **个体差异问题**（第四章）：为什么有些被试的口头化流利而有些则是"想-然后-总结"模式？这与编码偏好的个体差异有什么关系？

2. **程序差异vs口头化差异**（第二章）：在许多比较口头化与沉默条件的研究中，两组之间的程序差异是否可以完全与口头化效应分离？

3. **最新研究的混合结果**（第二章，Russo, Johnson & Stephens in preparation）：在心算任务中口头化导致更差的表现，在赌博任务中导致更好的表现——这一不对称性尚未被模型完全解释。

4. **自动化过程的不可报告性边界**（第三章）：自动化过程在什么精确程度上从"可报告"变为"不可报告"？这一转变是渐进的还是突然的？

5. **口头化指令的措辞效应**（第二章、第七章）：TA指令中细微的措辞差异（"keep talking" vs "what are you thinking about?"）产生的影响尚未被系统研究。

6. **"再生记忆"的经验验证**（第三章）：这一概念提供了对许多"口头报告不一致"现象的优雅解释，但尚未被直接的经验研究检验。

7. **认知负荷与口头化暂停**（第二、五章）：在什么认知负荷阈值下口头化会暂停？是与STM容量饱和有关还是与竞争加工有关？
