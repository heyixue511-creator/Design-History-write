## 四、一级涌现结构（E）

E1 **表征悖论结构**：表征（技术层真）→ 失明 → 智能不可编程；同时表征（认知层假）→ 人类智能非表征。两个分支由"表征假说对计算机为真、对人类认知为假"枢纽统一（L1291、L1643–L1644）。

E2 **破裂—设计循环**：破裂 → 对象/属性涌现 → 域生成 → 设计 → 新破裂。该环贯穿第 3、6、12 章（L668–L694、L1355–L1388、L2737–L2759、L2860–L2863）。

E3 **承诺—理解判据**：承诺 → 满足条件 → 理解（=进入承诺）→ 计算机无承诺 ⇒ 不能理解（L1037–L1051、L2057–L2079）。

E4 **对话—组织同构**：言语行为 → 行动对话 → 承诺网络（组织）→ 协调者（L1137–L1174、L2458–L2490、L2629–L2683）。

E5 **结构耦合统一体**：结构耦合 → 一致域 → 语言 → 学习/进化限制 → 设计的耦合基础（L850–L877、L1743–L1747、L3012–L3014）。

## 五、二级涌现命题（P）

P1 **"认知表征假说的领域二值性"**：表征假说不是普遍真/假，而是领域相关的——对计算机系统为真、对人类认知为假，正是这个二值性使本书同时能批判 AI 又能建设系统设计（生成机制：E1 的结构二分；强度：强）。

P2 **"失明不可消除但可显影"**：失明是一切表征/形式化/设计的必然代价，无法消除；但通过"破裂的预判"与"盲区意识的训练"可以将其显影并转化为设计资源（生成机制：E2 循环中"盲区"与"破裂预判"的双向链接，L2760–L2773、L2741–L2759；强度：中强）。

P3 **"语言是不可编程的承诺域"**：语言作为承诺域不可被形式化穷尽，但可被"系统性领域"局部化、工具化（协调者、簿记、字处理），形成"承诺域包裹系统性领域"的嵌套结构（生成机制：E3 + T11 的嵌套；强度：中强）。

P4 **"组织的本质是对话而非决策"**：组织的可设计维度不在决策逻辑而在承诺—对话结构；因此决策支持系统的根本危险（选择取向、权力转移、责任掩盖）是结构性的而非技术性的（生成机制：E4 + T10；强度：中强）。

P5 **"设计即存在之设计"**：设计不是工程方法论问题，而是本体论活动——设计工具即在设计人的存在方式；这一命题把全书的哲学批判与工程建议统一在"本体论设计"概念下（生成机制：E2 循环上升到 Θ04；强度：强）。

## 六、客观性核对与反例

1. **P1 的反例/边界**：作者承认人类也"使用"表征（L1676），因此"对人类认知表征假说为假"须理解为"表征不是认知的基础"，而非"人不使用表征"。原文："Human cognition includes the use of representations, but is not based on representation."（L1676）。
2. **P2 的边界**：作者保留结构耦合机器在原则上获得智能的可能性（L1764–L1766），因此"失明不可消除"的结论限于"由程序员表征的程序"，不覆盖演化型系统。
3. **P3 的反例**：作者明确反对"语言可还原为言语行为表征"（L2681–L2682），提示承诺域不能被工具完全捕获——协调者只处理一个维度。
4. **P5 的文本矛盾**：作者称"我们不能选择是否转化传统、不能选择转化内容、不能完全意识转化"（L3036–L3041），却又倡导"有意识地设计"——两者以"在失明中趋近去蔽"调和（L3042），这是全书最深刻的张力点，予以保留并如实记录。
