## 二、概念型知识元（KE-C）：25项（KE-SEM-01-S2）

### KE-C001：共同基础（Common Ground）
- **定义**：Clark(1996)定义——共享的知识、信念和假设，是所有联合活动得以进行的基础；Norman将其引入人机交互分析
- **跨章频率**：7章（Ch1提及→Ch2建构→Ch3绕过→Ch4默认→Ch5引用→Ch6限定→后记翻转）
- **核心/边缘**：核心枢纽
- **领域标签**：认知语用学 / 人机交互理论
- **源映射**：L000-OV-S3, L000-SR02, L001-CH01-S3, L002-CH02-S3, L003-CH03-S9

### KE-C002：超级鸿沟（Supergulf）
- **定义**：Norman原创概念——覆盖在目标鸿沟、行动鸿沟、感知鸿沟之上的"共同基础缺失"，是人与机器之间最根本的认知隔离
- **跨章频率**：3章（Ch2建构→Ch6诚实限定→后记翻转）
- **核心/边缘**：核心枢纽
- **领域标签**：认知心理学 / 设计理论
- **源映射**：L000-OV-S4, L002-CH02-S3, L006-CH06-S4

### KE-C003：增强vs.自主（Augmentation vs. Autonomy）
- **定义**：全书核心二分法——替人决策（自主）vs. 助人决策（增强）；增强性工具将活动决定权留给人类，自主性系统替人做决定
- **跨章频率**：6章（Ch1种子→Ch3案例→Ch4反面→Ch5立场→Ch6规则→Ch7展望）
- **核心/边缘**：核心枢纽
- **领域标签**：设计哲学 / 技术伦理
- **源映射**：L000-OV-S4, L005-CH05-S1, L005-CH05-S3

### KE-C004：三层脑处理模型（Visceral / Behavioral / Reflective Processing）
- **定义**：Norman基于McLean三位一体脑理论简化的三层次模型——本能层（自动反应）、行为层（习得技能）、反思层（意识自我）——投射于机器设计
- **跨章频率**：3章（Ch2核心→Ch3应用→Ch6隐含）
- **核心/边缘**：核心框架
- **领域标签**：认知心理学 / 情感设计
- **源映射**：L002-CH02-S2, L002-CH02-S3, L003-CH03-S9

### KE-C005：自然交互 / 隐性沟通（Natural Interaction / Implicit Communication）
- **定义**：通过自然信号（声音、振动、光、触觉）而非语言对话实现人机沟通；Castlefranchi的"隐性沟通"——行为的自然副作用可被他人解读而不需要特定的学习或训练
- **跨章频率**：4章（Ch3核心→Ch6规则化→Ch7展望→后记嘲讽）
- **核心/边缘**：核心方案
- **领域标签**：交互设计 / 认知科学
- **源映射**：L003-CH03-S1, L003-CH03-S3, L006-CH06-S2

### KE-C006：三鸿沟模型（Gulfs of Goals, Action, and Perception）
- **定义**：人机之间的三个基本认知鸿沟——目标鸿沟（人想要什么 vs. 机器能提供什么）、行动鸿沟（人如何操作 vs. 机器如何被操作）、感知鸿沟（机器的状态 vs. 人如何感知其状态）
- **跨章频率**：2章（Ch2建构→Ch6隐含引用）
- **核心/边缘**：核心框架
- **领域标签**：人机交互 / 认知工程
- **源映射**：L002-CH02-S3, L002-CH02-S7

### KE-C007：可理解的错误（Understandable Error）
- **定义**：错误模式与用户心理模型一致，使用户能发现错误原因的反馈设计原则；Norman从Newton灾难中提炼出的反直觉命题——可理解性比准确性更重要
- **跨章频率**：2章（Ch6核心→Ch5隐含）
- **核心/边缘**：核心原则
- **领域标签**：交互设计 / 认知心理学
- **源映射**：L006-CH06-S1, L006-CH06-S3, L000-OV-S6

### KE-C008：平静技术（Calm Technology）
- **定义**：Weiser & Brown(1995)——在注意中心与边缘之间移动的交互形式；使用者在"不明确关注的情况下与之协调"（attuned to without attending to explicitly）
- **跨章频率**：2章（Ch3提及→Ch6核心）
- **核心/边缘**：重要概念
- **领域标签**：普适计算 / 交互设计
- **源映射**：L006-CH06-S2, L003-CH03-S2

### KE-C009：H-metaphor / 松紧缰绳控制（Loose-Rein / Tight-Rein Control）
- **定义**：源于马术的人机控制权连续体隐喻——松缰（驾驶者几乎不需操作）到紧缰（轻微推动引导）；由Flemisch团队在NASA Langley和DLR Braunschweig研究
- **跨章频率**：3章（Ch1引入→Ch2展开→Ch3亲验）
- **核心/边缘**：重要概念
- **领域标签**：人机交互 / 车辆自动化
- **源映射**：L001-CH01-S4, L002-CH02-S3, L003-CH03-S3

### KE-C010：风险稳态（Risk Homeostasis）
- **定义**：Wilde的理论——感知安全度不变时，人们会调整行为以维持恒定风险水平；反向运用可使"看起来更危险"提升实际安全
- **跨章频率**：1章（Ch3核心）
- **核心/边缘**：重要概念
- **领域标签**：交通心理学 / 风险理论
- **源映射**：L003-CH03-S3

### KE-C011：符号学工程 / Affordance作为沟通（Semiotic Engineering）
- **定义**：de Souza的理论——affordance不应仅被理解为"对象为行为者提供的活动范围"（Gibson），而应进一步理解为"设计者与使用者之间的沟通"
- **跨章频率**：2章（Ch3核心→Ch6隐含）
- **核心/边缘**：重要概念
- **领域标签**：符号学 / 人机交互
- **源映射**：L003-CH03-S3, L003-CH03-S5

### KE-C012：情境意识（Situation Awareness）
- **定义**：人对情境、当前状态和未来可能性的了解程度；在自动化系统中，人容易被逐出控制环路，导致情境意识丧失
- **跨章频率**：2章（Ch4警示→Ch5隐含）
- **核心/边缘**：重要概念
- **领域标签**：人因工程 / 航空心理学
- **源映射**：L004-CH04-S3, L004-CH04-S8

### KE-C013：过度自动化（Overautomation）
- **定义**：设备自动化程度过高，以至于人不再需要保持警觉——"设备太好以至于人和技能都会衰减"
- **跨章频率**：2章（Ch4警示→Ch5立场）
- **核心/边缘**：重要概念
- **领域标签**：自动化理论 / 人因工程
- **源映射**：L004-CH04-S3, L005-CH05-S1

### KE-C014：信息化赋能（Informate）
- **定义**：Zuboff(1988)术语——自动化不仅取代工人对生产过程的直接经验，还通过计算机赋予工人以前被管理层垄断的全局信息访问权；具有"隔离"与"赋权"的双重效应
- **跨章频率**：2章（Ch4引入→Ch5深化）
- **核心/边缘**：重要概念
- **领域标签**：组织社会学 / 技术社会学
- **源映射**：L005-CH05-S3, L004-CH04-S8

### KE-C015：责备与训练（Blame-and-Train）
- **定义**：将技术失败归咎于用户（"他应该记得关掉"）并试图通过培训解决的工程思维模式；Norman将其列为智能设备设计的系统性缺陷
- **跨章频率**：2章（Ch1引入→Ch4隐含）
- **核心/边缘**：批判概念
- **领域标签**：设计批判 / 工程文化
- **源映射**：L001-CH01-S3, L001-CH01-S4

### KE-C016：智能在设计者脑中（Intelligence in the Designer's Mind）
- **定义**：Norman的核心认识论论断——所谓智能机器的"智能"实为设计者的事先编程和状态预判，而非机器具有真正的理解或推理能力；当意外事件发生时设计者不在场，机器便无所适从
- **跨章频率**：5章（Ch1提出→Ch2深化→Ch3回应→Ch5基础→Ch6规则基础）
- **核心/边缘**：核心枢纽
- **领域标签**：认识论 / 人工智能哲学
- **源映射**：L001-CH01-S3, L002-CH02-S3, L000-OV-S3

### KE-C017：两个独白不成对话（Two Monologues ≠ Dialogue）
- **定义**：全书核心格言——人机各自的单向指令（机器发出警告，人类按下按钮）无法构成真正的交流；对话需要解释、协商和共同理解
- **跨章频率**：7章（作为贯穿全书的"公理"）
- **核心/边缘**：核心公理
- **领域标签**：沟通理论 / 交互设计
- **源映射**：L001-CH01-S1, L001-CH01-S7, L000-OV-S3

### KE-C018：共享空间（Shared Space）
- **定义**：Monderman的交通设计理念——取消交通标志和信号灯，让道路使用者（汽车、自行车、行人）通过眼神接触和行为协商自我调节；Kensington High Street改造后事故下降40%
- **跨章频率**：1章（Ch3核心）
- **核心/边缘**：重要案例
- **领域标签**：交通设计 / 行为心理学
- **源映射**：L003-CH03-S3

### KE-C019：共生关系（Symbiotic Relationship）
- **定义**：Licklider(1960)提出的人机融合理想——人类设定目标、制定假设、确定标准；机器完成可程序化的工作，为人准备洞察和决策所需的技术和科学信息基础
- **跨章频率**：3章（Ch1提出→Ch2发展→Ch7回归）
- **核心/边缘**：重要概念
- **领域标签**：人机交互 / 控制论
- **源映射**：L001-CH01-S3, L002-CH02-S3

### KE-C020：视角翻转（Perspective Reversal）
- **定义**：从非人类视角（机器的视角）重新审视人类的设计原则和假设——通过将人类中心叙事翻转为机器中心叙事，揭示以人为中心的设计中隐藏的假设和盲点
- **跨章频率**：2章（Ch4种子→后记核心）
- **核心/边缘**：核心方法
- **领域标签**：认识论 / 设计哲学
- **源映射**：L008-AFT-S1, L004-CH04-S6, L000-OV-S6

### KE-C021：假开关 / 安慰剂按钮（Fake Switches / Placebo Buttons）
- **定义**：建筑和公共空间中不起作用的交互元素（电梯"关门"按钮、办公室恒温器、过街按钮）——满足人的控制感但不执行任何功能；后记中"机器"坦承安装它们以"让人感觉良好"
- **跨章频率**：1章（后记核心）
- **核心/边缘**：核心隐喻
- **领域标签**：设计伦理 / 建筑心理学
- **源映射**：L008-AFT-S3, L008-AFT-S7

### KE-C022：设计科学（Science of Design）
- **定义**：Norman在Ch7呼吁的新学科——将商业和工程的精确与严谨、对社会互动的理解以及艺术的美学结合起来；是对现有设计教育"学徒制+工作室"模式的超越
- **跨章频率**：1章（Ch7核心呼吁）
- **核心/边缘**：制度方案
- **领域标签**：设计教育 / 学科建设
- **源映射**：L007-CH07-S3, L007-CH07-S7

### KE-C023：神经可塑性（Neuroplasticity）
- **定义**：大脑结构因长期经验而改变的能力——伦敦出租车司机海马体增大、音乐家特定脑区变化、手机拇指打字者脑区重组——Norman以此论证技术不仅改变世界也在改变人类自身
- **跨章频率**：1章（Ch7核心）
- **核心/边缘**：重要概念
- **领域标签**：神经科学 / 技术哲学
- **源映射**：L007-CH07-S3

### KE-C024：蜂群/车队（Swarming / Platooning）
- **定义**：仿生集群行为在交通自动化中的应用——每辆车遵循简单规则（保持距离、匹配方向、避免碰撞），产生复杂协调的涌现行为；理论上可实现无信号灯、无车道线、无碰撞
- **跨章频率**：1章（Ch4核心）
- **核心/边缘**：未来概念
- **领域标签**：交通工程 / 复杂系统
- **源映射**：L004-CH04-S3

### KE-C025：剧本方法（Playbook）
- **定义**：Miller团队的共享任务模型——人与自动化系统通过选择共享"剧本"来传达意图和协调行动，是克服人机共同基础缺失的一种实用方案
- **跨章频率**：1章（Ch3引入）
- **核心/边缘**：重要方法
- **领域标签**：人机交互 / 军事自动化
- **源映射**：L003-CH03-S3

## 三、命题型知识元（KE-P）：25项（KE-SEM-01-S3）

### KE-P001
- **内容**：人与机器之间缺乏共同基础是导致人机沟通失败的根本原因
- **真值条件**：如果未来机器能够发展出与人类共享的知识、信念和假设体系，则该命题为假
- **跨章频率**：7章
- **源映射**：L002-CH02-S3, L006-CH06-S4, L000-OV-S3

### KE-P002
- **内容**：机器的"智能"实际上存在于设计者的头脑中，而非机器本身
- **真值条件**：如果机器展现出设计者未预编的、基于真实理解的创造性行为，则该命题需要修正
- **跨章频率**：5章
- **源映射**：L001-CH01-S3, L002-CH02-S3

### KE-P003
- **内容**：在大多数日常生活场景中，增强性技术优于自主性技术
- **真值条件**：在高风险/高速度场景（如紧急制动）中，"自主"可能优于"增强"——该命题存在场景边界
- **跨章频率**：5章（Ch1种子→Ch5立场→Ch6规则→Ch7展望）
- **源映射**：L005-CH05-S1, L005-CH05-S3, L000-OV-S4

### KE-P004
- **内容**：半自动化（部分自动化）是最危险的状态——既不能让人保持充分的情境意识，又不能完全替代人的判断
- **真值条件**：如果存在一种"中间状态"设计使人保持充分参与同时享受自动化便利，则该命题需要限定
- **跨章频率**：2章（Ch4提出→Ch5深化）
- **源映射**：L004-CH04-S3, L005-CH05-S2

### KE-P005
- **内容**：反馈的可理解性比反馈的准确性更重要——用户可以接受"可理解的错误"但不能接受"不可理解的正确"
- **真值条件**：如果在特定领域（如医疗诊断、航空安全）中准确性压倒性地重要，该命题需要领域限定
- **跨章频率**：1章（Ch6核心命题）
- **源映射**：L006-CH06-S3

### KE-P006
- **内容**：自然信号（声音、振动、光的连续变化）优于人工信号（蜂鸣器、闪烁灯），因为它们信息更丰富、不恼人、可被次意识处理
- **真值条件**：如果人工信号在特定环境（如极嘈杂环境或无障碍需求）中具有不可替代的优势
- **跨章频率**：3章（Ch3提出→Ch6规则化→Ch7重申）
- **源映射**：L003-CH03-S3, L006-CH06-S2

### KE-P007
- **内容**：意外事件总会发生，且发生时总是意外的——设计者无法预判所有可能状态
- **真值条件**：逻辑上为真（意外事件的定义决定了它不能被预知），但可以通过"安全边界设计"降低其后果严重度
- **跨章频率**：3章
- **源映射**：L001-CH01-S3, L001-CH01-S7

### KE-P008
- **内容**：因为机器不能建立共同基础，所以人必须适应机器——但这种适应不应成为劣质设计的借口
- **真值条件**：如果机器在特定领域（如自然语言处理）中开始展现共同基础建立能力，该命题的第一部分需要修正
- **跨章频率**：2章（Ch7核心→后记翻转）
- **源映射**：L007-CH07-S3

### KE-P009
- **内容**：自动化永远有代价——在接管一套任务的过程中，它无可避免地引入一套新问题
- **真值条件**：如果存在"无副作用的自动化"——新问题可以通过更好的自动化完全解决而不引入更新的问题——则该命题需要限定
- **跨章频率**：2章（Ch5提出→Ch4隐含）
- **源映射**：L005-CH05-S3, L005-CH05-S7

### KE-P010
- **内容**：错误归因的方向决定产品的命运——如果用户责备机器则产品失败，如果用户责备自己则产品被接受
