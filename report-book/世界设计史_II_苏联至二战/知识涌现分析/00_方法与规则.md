## 一、层级定义

1. **知识元（Knowledge Atom）**：六类实体（人物、著作/作品、概念、机构、地点、事件）的原子化语义单元。例：知识元"流线型（Streamlining）"。
2. **Topic（强连通簇）**：由语义链接紧密互连的知识元组成的簇，簇内知识元两两或近两两可达（强连通）。例：Topic"美国工业设计职业化"＝{贝尔·盖迪斯，德雷夫斯，罗维，提革，流线型，有计划废止，……}。
3. **Theme（高层语义域）**：多个 Topic 聚合形成的高层语义域，由共享/桥接知识元维系。例：Theme"设计—政治权力"。

## 二、9 种语义链接判定标准

| 符号 | 类型 | 判据 | 例（本书） |
|---|---|---|---|
| → | 因果 | 一知识元的存在/变化直接导致另一知识元 | 甘地主张土布→土布成为民族象征（L5390） |
| ⇒ | 条件 | 一知识元是另一知识元成立的前提条件 | 进口替代工业化⇒拉美本土设计空间（L3238） |
| ↔ | 对比 | 两知识元在同一语境中相互对立/参照 | 鲁尔曼奢侈风格↔勒·柯布西耶机器美学（L853、L861） |
| ⊂ | 隶属 | 一知识元是另一知识元的下位概念/成员 | 摩卡壶⊂意大利消费产品（L2176） |
| ≻ | 时序 | 一知识元在时间上先于另一知识元 | 魏玛包豪斯≻美国新包豪斯（L2650） |
| ≈ | 空间共现 | 两知识元在同一地点/区域语境中共现 | 月份牌≈上海（L5669） |
| : | 属性 | 一知识元是另一知识元的属性/特征 | 奥利维蒂：设计实验室（L2178） |
| ⇐ | 论证支撑 | 一知识元为另一知识元的判断提供证据 | 佩夫斯纳调查报告⇐"90%工业品位异议"（L1040） |
| ∼ | 同域 | 两知识元属于同一主题域但无直接因果 | 民艺∼国货运动（均属"民族认同"域） |

## 三、涌现指标

1. **节点度 k**：某知识元直接连接的链接数（出度+入度）。
2. **桥接值 b**：该知识元作为两个 Topic/Theme 之间唯一或主要连接通道的程度。
3. **簇识别**：对语义链接网络做强连通分量分析，得到 Topic 簇。
4. **内聚度**：簇内实际链接数 / 簇内最大可能链接数。
5. **涌现强度 S**：S = Σ(簇内链接权重 × 簇内节点数)，衡量簇的语义密度；一级涌现（E）为簇级结构，二级涌现（P）为跨簇综合命题。
6. **一级/二级涌现**：一级 = Topic 从知识元网络中的出现；二级 = Theme 从 Topic 聚合中的出现。
