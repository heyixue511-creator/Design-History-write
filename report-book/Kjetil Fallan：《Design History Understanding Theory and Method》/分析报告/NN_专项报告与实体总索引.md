# 第一部分 专项报告

## 一、语言与文字风格

1. **语体**：学术英文（英式拼写为主，如 programme、behaviour；美式拼写偶现于引文），正式书面语，句式以长复合句为主。典型句（L11）单句嵌套七组对照（ideology/practice、mind/matter、culture/commerce、production/consumption、utility/symbol、tradition/innovation、real/ideal），显示作者"以排比对照压缩论证"的句式偏好。
2. **术语密度**：跨学科术语（STS/哲学/史学）密集，凡引入新术语必附定义或词源说明，如 script 的拉丁词源 scriptum（L529）、domestication 的驯养类比（L597）、paradigm 的三分（L868-870）。
3. **OCR 合字说明**：正文中 "fi"/"fl" 合字显示为 "fi"/"fl"（如 "fi eld"、"fl ow"），属字体合字识别现象；"Gropius" 等专名拼写亦偶见 OCR 变体（如 "Gro pius" L981）；"Mácel/Otakar"（L1193 注）、"Fischer, Tom"（索引 L3006，正文为 Tom Fisher L568）等为识别误差，分析时以语义为准。
4. **时态与语气**：陈述多用一般现在时（学科现状）与完成时（学术史）；判断句常带限定语（"can be said to""might be""probably"），体现学术审慎；立场句偶用直陈（"is not shared here" L158）。

## 三、史料使用方式

1. **学术文献为骨**：全书论证几乎全部依托二手文献（专著、期刊论文、文集、书评），直接引语约 200 处以上，均以 `<sup>` 编号对应书末 Notes（L953-2032）。
2. **论战文本全息呈现**：Margolin–Forty 论战以"原论文+回应+再回应"的完整序列呈现（L225-252 + 注 L1239-1287），相当于把一手文献嵌入教材。
3. **实物图像作例证**：21 幅挪威设计图注（L41-939 区间），每幅标注设计者、年份、版权方，属"物证"型材料，服务于论证（如流线型电车论证"意识形态变风格"L793）。
4. **文学文本作论据**：小说段落（Faldbakken L544、Baker L607）被当作"用户端反程序""驯化"的证词使用——作者自认"取自虚构作品"（L539、L546）。
5. **自引与研究史嵌入**：作者本人 7 篇论文（L2257-2269 书目）作为研究路径的自证；注明章节改写自已发论文（L1635、L1803）。
6. **一手文件**：Lelo 公司网站（L965 注）、Ibsen 网站（L973 注）、iPod 专利名单（L37）等零星一手材料。

## 四、阐述方法

1. **引—评—收束三段式**：全书标准单元。例：引 Miller（L271）→ 引 Saumarez Smith 评（L273）→ 作者收束判断（L273）。
2. **概念转译评估法**：把 STS 概念逐一"翻译"进设计史并评估适用性（规则五→设计史行动者平等 L477；黑箱→ism 封闭 L821）。
3. **正反合**：对每个理论资源（艺术史、物质文化研究、ANT、脚本、驯化、范式）都先陈利、再陈弊、后给作者的取用方案。
4. **谱系学清理**：modern→modernity→modernism→isms→paradigm 的词源—语义—使用史逐层清理（L698-884）。
5. **对照表式论证**：ism 与理论、ism 与知识型、物理脚本与社会技术脚本、三种范式等均以"二分/三分+中间态"呈现（L740-762、L732、L868-884）。
6. **案例反证法**：用挪威产品（2CV 案例虽为法国产品）检验理论命题。

## 五、推演逻辑

1. **演绎主线**：设计不是艺术（大前提，L101）→ 艺术史框架不适用（L117）→ 设计更像技术（L396）→ 技术史/STS 理论可用（L660）→ 具体工具（无缝之网→ANT→脚本→驯化）（第2章）→ 上升到认识论：ism 是意识形态/实践的文化模式（L762）→ 范式框架解释其变迁（L889）→ 设计史=设计文化史（L951）。
2. **归纳支线**：从 21 个挪威案例与大量个案研究（2CV、Beetle、Tupperware、Pruitt-Igoe、Pessac）归纳理论命题。
3. **类比推理**：驯化（动物→技术→观念）、无缝之网（技术→设计）、范式（科学→艺术→设计史）——作者对每个类比都标注了适用边界（L509、L831、L925）。
4. **反事实检验**："如果设计史是……那么……"（如 L227 若接受 Margolin 前提则文化史更优）。
