# 《Designing Interactions》专项报告与实体总索引

## 一、专项报告：全书访谈方法论分析

### 1.1 访谈作为知识生产方法

Bill Moggridge在本书中采用的"深度访谈+历史叙事"方法本身即是一项值得分析的交互设计研究实践。全书40余位受访者以第一人称口述历史的形式呈现，构成了一种独特的"人类学式的设计研究"。

**访谈方法论特征：**
- **人物先行于技术**：每位受访者首先以个人传记（照片+职业生涯概述）出现于读者面前，技术发明被呈现为个人生命经历的产物
- **保留口语特征**：访谈以直接引语形式呈现，未经过度编辑——保留了犹豫、幽默、情感和个性
- **交叉印证**：同一历史事件（如鼠标发明、PARC人才外流、桌面隐喻诞生）从多个人物视角反复出现，形成"Rashomon效应"
- **开放性问题导向**：访谈以"What"、"Why"和"How"类问题组织，而非技术规格清单

**访谈方法的贡献：**
1. 使抽象的技术史变得"有人情味"和可记忆
2. 捕捉了正式文献中缺失的"隐性知识"——设计决策背后的直觉、情感和偶然性
3. 创造了一种"导师-学生"式的知识传递体验——读者仿佛在旁听大师之间的对话

### 1.3 知识谱系分析

全书追踪了交互设计知识的三条主要传承路线：

**路线一：Xerox PARC → Apple → 产业扩散**
```
SRI (Engelbart) → Xerox PARC (Engelbart, English, Card, Tesler, Mott, Kay, Liddle)
    → Apple (Tesler, Atkinson, Raskin, Jobs)
    → 全产业 (Windows, 各种GUI产品)
```

**路线二：Stanford → Silicon Valley → IDEO**
```
Stanford University (Winograd, Kelley, various graduates)
    → Silicon Valley startups (GRiD, Palm, Handspring, Google)
    → IDEO (Kelley, Moggridge, Suri, Bray, Boyle, Hunter)
```

**路线三：MIT Media Lab → 全球学术/实践网络**
```
MIT Media Lab (Negroponte, Ishii, Maeda)
    → RCA London (Dunne & Raby, Gaver)
    → Sony CSL Tokyo (Rekimoto)
```
