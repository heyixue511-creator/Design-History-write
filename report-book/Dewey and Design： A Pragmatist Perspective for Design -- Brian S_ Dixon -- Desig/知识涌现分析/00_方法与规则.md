# 00 方法与规则

## 一、知识涌现分析的定位与目标

### Y001 什么是知识涌现分析
知识涌现分析是在既有文本分析报告的基础上，通过对知识元（knowledge elements）的系统提取、语义标注、关系链接和计算评估，识别出在原报告各章中"不可见"但在整体关系网络中"可被检测"的新知识结构、跨域连接和涌现性洞察的分析方法。其核心假设是：**知识元之间的关系网络本身包含的信息量超过了单个知识元的加和**——即涌现性（emergence）存在于关系之中。

### Y002 分析目标
1. 从全部分析报告中提取可操作的"知识元"——即最小有意义知识单元
2. 建立知识元之间的语义链接网络，识别关键枢纽节点和桥接节点
3. 计算涌现性指标，量化跨章知识整合的程度
4. 产出知识发现报告，呈现原分析报告中未被明确表述但可从关系网络中推断的新洞察

### Y003 与"分析报告"的关系
分析报告（00-NN）是对Dixon原著的"第一层解读"——逐章分析内容、论证、逻辑、实体。知识涌现分析是对分析报告的"第二层解读"——在跨章的、关系的、涌现性的维度上进行知识重构。二者是"分析"与"综合"的互补关系。

## 二、知识元的定义与标注规则

### Y004 知识元的操作定义
**知识元**（Knowledge Element, KE）是在文本中可被标注的、具有独立语义完整性的最小知识单元。一个知识元必须满足以下四个条件：

| 条件 | 说明 | 示例 |
|------|------|------|
| 语义完整性 | 能够独立表达一个完整的断言或定义 | "探究是从不确定情境到确定情境的受控转化"是一个完整的定义，构成一个KE |
| 可引用性 | 具有明确的文本锚点（L编号、页号、段号） | 可追溯至特定章节的具体段落 |
| 可链接性 | 能够与其他知识元建立语义关系 | 可与"经验的双重性""有根据的可断定性"建立因果、前提、应用等关系 |
| 不可再分性 | 进一步拆分将失去其核心语义 | "探究"作为单个词不是KE；"探究模式包含五个阶段"是一个KE |

### Y005 知识元的五类
基于对全部分析报告的预处理，知识元分为以下五类：

| 类型编号 | 类型名称 | 说明 | 来源示例 |
|----------|----------|------|----------|
| KE-A | 定义性知识元 | 对概念的精确定义 | "经验的双重性：经验包括'做'和'经受'"（L219a） |
| KE-B | 关系性知识元 | 表述概念之间关系的命题 | "经验为探究提供发生的背景"（L007） |
| KE-C | 论证性知识元 | Dixon的整体论证主张或推论 | "设计实践与涉及实践的设计研究沿同一探究连续体排列"（论题T3.3） |
| KE-D | 案例性知识元 | 来自In Focus Box或Practical Case的具体知识 | "Rosenqvist的印尼卫生治理项目展示了公众概念的设计应用"（IFB 5.1） |
| KE-E | 方法论知识元 | 对研究方法的指导或意涵 | "任何声称的知识必须基于可靠的情境有效证据并可转移到其他情境"（方法论意涵#5） |

### Y006 知识元的标注格式
每个知识元在提取时采用以下统一格式：

```
[KE-ID] | 类型 | 来源L编号 | 核心语义（≤50字）| 关联KE-IDs（初判）| 所属论题
```

其中KE-ID采用三位数字编码（KE001-KE999），类型为A/B/C/D/E，来源L编号追溯至原分析报告的具体标注行。

## 三、语义链接的定义与规则

### Y007 语义链接的六种类型
知识元之间的语义关系分为六种基本类型。每种链接必须是有方向的（A→B），同一对知识元之间可能存在多个不同类型的链接。

| 链接类型 | 符号 | 定义 | 判断标准 |
|----------|------|------|----------|
| 前提关系 | →PREREQ | A是B成立的逻辑前提或理论基础 | "如果没有A，B将不成立" |
| 因果关系 | →CAUSE | A的发生/存在导致B | "A引起/产生/促成B" |
| 应用关系 | →APPLY | A被应用于或被操作化为B | "A在B语境中被具体化为" |
| 对比关系 | ↔CONTRAST | A与B在某一维度上形成对照 | "A与B在X方面不同/对立" |
| 层级关系 | ↑HIER | A是B的上位概念，或B是A的下位概念 | "A包含B"或"B是A的一种" |
| 共振关系 | ↔RESON | A与B在结构上相似但不具有直接因果/层级关系 | "A与B分享相同的逻辑结构" |

### Y008 链接权重的三级赋值
每条链接根据其证据强度赋予三级权重：

| 权重 | 值 | 条件 |
|------|-----|------|
| 强 | 1.0 | 在原报告中由Dixon明确定义或断言的关系 |
| 中 | 0.6 | 在原报告中有充分暗示但未明确断言的、可由多个证据支持的关系 |
| 弱 | 0.3 | 在原报告中仅有微弱线索、需要从跨章比较中推断的关系 |

### Y009 链接的标注格式
```
[LINK-ID] | 源KE-ID → 目标KE-ID | 链接类型 | 权重 | 证据（L编号）| 备注
```

## 四、涌现性的操作定义与计算方法

### Y010 涌现性的操作定义
在本分析框架中，**涌现性**是指在知识元网络中满足以下任一或多个条件的新知识属性：

1. **跨域新连接**：两个或以上原先分属不同章节（因而在原报告中未直接连接）的知识元，在网络分析中被识别出具有强语义关系
2. **结构洞填补**：网络中存在连接不同"知识集群"的桥接节点，这些节点的识别本身构成新知识
3. **模式识别**：在知识元网络中检测到非随机的拓扑模式（如三角形闭合、星形枢纽），这些模式揭示了新的知识组织逻辑
4. **上位概念涌现**：多个知识元的聚合暗示了一个未被原报告命名的上位概念

### Y011 涌现性的四项计算指标

| 指标 | 符号 | 计算方式 | 意义 |
|------|------|----------|------|
| 跨域连接密度 | CDD | 跨章强链接数 / 总跨章可能链接数 | 衡量不同主题域之间的整合程度 |
| 桥接中心性 | BC | 节点的Betweenness Centrality标准化值 | 识别连接不同知识集群的关键节点 |
| 集群模块度 | MQ | Community Detection的Modularity值 | 衡量知识网络自然分群的质量 |
| 涌现增益 | EG | (跨域链接带来的新命题数) / (原报告独立命题总数) | 衡量关系网络相对于独立知识元的"信息增量" |

### Y012 涌现性判断的阈值规则

| 条件 | 阈值 | 判断 |
|------|------|------|
| CDD ≥ 0.5 | 50%跨章连接密度 | 高跨域整合——知识涌现显著 |
| BC ≥ 0.3 | 标准化桥接中心性 | 该节点为关键桥接知识元 |
| MQ ≥ 0.3 | 模块度 | 存在清晰可辨的知识集群 |
| EG ≥ 0.3 | 30%新命题 | 涌现增益显著——关系网络带来了大量新洞察 |

## 五、分析流程与操作步骤

### Y013 五阶段分析流程

```
阶段0：[预处理] 从分析报告中提取全部L编号实体，建立基础知识库
    ↓
阶段1：[知识元提取] 按照KE-A/B/C/D/E五类型标注全部知识元
    ↓
阶段2：[语义链接构建] 建立知识元之间的六类语义链接，赋权重
    ↓
阶段3：[网络分析与涌现计算] 计算网络拓扑指标和涌现性指标
    ↓
阶段4：[知识发现撰写] 基于前三阶段的结果，撰写知识发现报告
```

### Y014 阶段0——预处理的具体操作
1. 遍历00-NN全部分析报告，提取所有L编号标注行
2. 将每个L编号行的核心语义压缩为≤50字的精简表述
3. 建立L编号→知识域（Ch1-Ch7六大论题域）的映射表
4. 识别跨章重复/变体表述的L编号（如L219a"经验的双重性"在Ch2和Ch7中均有出现），做去重合并

### Y015 阶段1——知识元提取的具体操作
1. 对每个L编号行进行"是否满足四条件"的判断
2. 满足条件的标注为知识元，赋予KE-ID
3. 不满足条件的（如纯事实性信息"杜威生于1859年"）标记为辅助实体，不进入网络分析但保留在附属数据库中
4. 知识元的关联KE-IDs初判（基于同一章节内的L编号逻辑关系）

### Y016 阶段2——语义链接构建的具体操作
1. 对每个KE对（KE_i, KE_j, i<j）进行"是否存在六类语义关系"的判断
2. 优先处理原报告中已明确标注的逻辑关系（L007论题间逻辑关系表为关键数据源）
3. 对跨章KE对进行特别关注——这些链接是涌现性的主要来源
4. 赋权重并标注证据

### Y017 阶段3——网络分析与涌现计算的具体操作
1. 构建有向加权网络 G = (V, E, W)，其中V为KE节点集，E为链接集，W为权重集
2. 计算：度分布、Betweenness Centrality、Closeness Centrality、Eigenvector Centrality
3. 执行Community Detection（Louvain算法），识别知识集群
4. 计算CDD、BC、MQ、EG四项涌现性指标
5. 识别跨域桥接节点、结构洞、三角形闭合模式

### Y018 阶段4——知识发现撰写
1. 汇总涌现性指标的计算结果，评估整体涌现水平
2. 列出"涌现性知识发现"——在关系网络中识别但在原报告中未被明确表述的新命题
3. 列出"关键桥接发现"——识别出连接多个知识域的关键枢纽知识元
4. 列出"上位概念发现"——从知识元的聚合模式中推断的新概念
5. 撰写综合知识发现报告（04_知识发现报告.md）

## 六、与Dixon原著的论证结构对应

### Y019 六大论题域（对应L006的T1-T6）
知识涌现分析沿用原分析报告中的六大论题域作为知识元的基本分类框架：

| 论题域编号 | 论题 | 对应章节 | 在本分析中的域标签 |
|------------|------|----------|-------------------|
| T1 | 经验论 | Ch2 | DOM_EXP |
| T2 | 探究论/知识论 | Ch3 | DOM_INQ |
| T3 | 沟通论/意义论 | Ch4 | DOM_COM |
| T4 | 民主-伦理-改良论 | Ch5 | DOM_DEM |
| T5 | 价值-评价论/知识整合论 | Ch6 | DOM_VAL |
| T6 | 方法论框架论 | Ch7 | DOM_MET |

### Y020 跨域链接的价值排序
在涌现性分析中，跨域链接按照其跨越的"域间距"进行价值排序：

| 域间距 | 说明 | 涌现价值 |
|--------|------|----------|
| 1 | 邻接域（如T1→T2, T2→T3） | 低——原报告已充分讨论 |
| 2 | 间隔一域（如T1→T3, T2→T4） | 中——原报告有暗示但未充分展开 |
| 3 | 间隔二域（如T1→T4, T2→T5） | 高——原报告鲜有直接讨论 |
| 4 | 间隔三域（如T1→T5） | 极高——需要在本分析中首次建立 |

## 七、分析规则的局限性声明

### Y021 本分析的认识论定位
1. 知识涌现分析是一种"第二层解读"——它依赖于已完成的"第一层解读"（分析报告）的质量和完整性
2. 语义链接的构建不可避免地包含分析者的判断——虽然通过规则和阈值进行约束，但不能完全消除主观性
3. 涌现性指标是启发式（heuristic）的而非证明式（demonstrative）的——它们标识"可能值得关注"的区域而非"已被证明"的结论
4. 本分析报告不应被视为对Dixon原著的替代或"更高级"解读——而是对分析报告中所含知识的重组和再发现

### Y022 规则适用边界
本方法适用的范围：
- 已完成的、具有充分L编号标注的文本分析报告
- 报告之间的论证具有内在的逻辑连续性
- 知识元的数量规模在50-300之间（过少不足以构成网络，过多超出人工处理能力）

本方法不适用的范围：
- 单一文本（无跨章/跨域维度）
- 纯编年/叙事性文本（缺乏概念性知识元）
- 知识元之间缺乏可识别的语义关系
