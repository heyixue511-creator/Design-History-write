## 四、知识元的层级结构

### Y112 知识元的四层级金字塔

```
       层级4：元知识元（全书级论证命题，5个）
              KE101, KE107, KE042
      ┌─────────────────────────────────┐
      │  层级3：整合性知识元（跨域整合，15个） │
      │    KE038, KE039, KE106, KE105...  │
      │  ┌─────────────────────────────┐  │
      │  │ 层级2：核心概念知识元（35个）  │  │
      │  │ KE001, KE008, KE011, KE016...│  │
      │  │ ┌─────────────────────────┐ │  │
      │  │ │层级1：应用/案例知识元（35个）│ │  │
      │  │ │KE020, KE036, KE045...   │ │  │
      │  │ └─────────────────────────┘ │  │
      │  └─────────────────────────────┘  │
      └─────────────────────────────────┘
```
