# Ch05_分析报告_Fakeshop_The_Diversity_of_New_Media.md

## 章节定位与功能

- **章名**：Chapter 5. Fakeshop: The Diversity of New Media（第 5 章《Fakeshop：新媒体的多样性》，L1061-1231；章题页 L1061-1064，正文 L1065-1231）
- **功能**：全书**"多样性"章**。以 Fakeshop 网络艺术项目为主例，批判"汇聚神话"（myth of convergence），论证数字媒体不是汇聚为单一形态而是"一系列暂定的汇聚"；随后延伸到 Web 的多样性、拼装（bricolage）、普适计算（ubicomp）与可穿戴媒体，最终提出"媒介景观"（mediascape）概念。

## 内容分析

### 1. Fakeshop：新媒体形式的多样性

Fakeshop（Jeff Gomperz、Prema Murthy、Eugene Thacker）是一个结合装置、Web 与表演的艺术家团队（L1067-1069）。其 SIGGRAPH 2000 站点是多窗口拼贴：左上角来自 1978 年科幻电影《Coma》（器官摘除乌托邦）场景的再媒介化，真人演员躺平台上扮演昏迷者，视频流、3D 身体模型（Poser 渲染）、聊天记录文本占据各窗口（L1071-1076）。

- **主题**：人类身体作为物理在场与其在赛博空间中的再现的多样性（L1076）。
- **界面本身就是媒体形式的拼贴**（L1078）。
- TEXT RAIN 与 Nosce 也有拼贴性质；数字艺术"不关心纯粹"，混合虚拟与物理（L1080-1082）。
- **数字世界不汇聚**：恰恰相反，设计者与娱乐公司不断发明旧形式的组合（L1082）。

### 2. 汇聚神话

- **汇聚预测的图景**：交互电视——观众围坐巨幕"与墙上影子互动"（L1086）。
- 但"没有交互电视系统被证明可行或流行"（L1086）。
- **增强电视（enhanced television）意外成功**：观众在电视旁摆电脑或在电脑窗口里看电视，节目前后访问网站（L1088）；它要求观众"分裂注意力"——在电视屏与电脑屏之间振荡（L1088）。
- 增强电视是**反射式设计**，宽容其他形式，因为它不要求用户完全忠诚（L1090）。
- **"我们目睹的是一系列汇聚——技术与形式的暂定组合"**（L1092-1096）：台式机、笔记本电脑、掌上设备、电子书、MP3 设备、带浏览器的手机（L1094-1098）。
- 设备设计的"舞蹈"：技术与形态不断组合、拆解、再组合（L1100）。
- **"汇聚是神话——设计者与数字推广者讲给我们（也讲给自己）的故事"**（L1102）。

### 3. Web 的多样性

- Web 组合了大多数流行媒介与媒介形式（L1108）；Web 本身分化成众多形式，各服务特定受众（L1108）。
- **HCI 专家与设计者都不愿接受多样性的后果**，仍想给出普适设计规则（L1110）。
- Nielsen 的用户是"购物顾客"，追求效率、透明传递信息（L1112-1114）；作者反驳：电视与杂志广告证明"创造体验是商业成功的关键"（L1114-1116）。
- Siegel 的用户也是消费者，但响应视觉设计（L1118）。
- **Web 比广播电视更多样**：Raymond Williams 的"flow"概念（L1120）；没有任何"不可打破的设计规则"——大图、长页、闪烁文本都有合法受众（L1122）。
- **唯一规则**：每个站点的设计应适合其设想的使用者社群，建立对应的节奏，透明或反射皆可（L1128）。
- 未来趋势：更多浏览在更小便携设备上进行（L1130）。

### 4. 拼装（Bricolage）

- **"数字设计是把不同元素以新方式拼合起来的实践"**（L1134）。
- bricolage 源自后现代艺术家/设计师对"用手中材料拼合事物"的描述（L1134）。
- SIGGRAPH 2000 的拼装例证：Elliott Peter Earls 的 EYE SLING SHOT LIONS（"字体、声音、视频碎片、交互数字视频、模拟现场表演、短片与流行乐的大杂烩"，L1136）；Rania Ho 的《Free Range Appliances in a Light Dill Sauce》（解放的厨房电器游荡，L1138）；TEXT RAIN 邀请用户成为拼装者（L1146）。
- **拼装表明汇聚神话是透明神话的另一个版本**（L1148）：汇聚倡导者假设媒介应被自然化并消失（巨幕高保真电视），但 SIGGRAPH 作品"不匹配这种描述"——它们各不相同、引人注目、反射新旧媒体形式的关系（L1148-1150）。
- 数字文化正走向普适计算（L1152）。

### 5. 普适计算与普适媒介

- Mark Weiser 1991 年《Scientific American》文章引入"普适计算"（L1156-1158）：计算散落于环境、隐入背景。
- Weiser 对比 VR 与普适计算：VR 把用户带进图形世界，ubicomp/embodied virtuality 把计算散布到物理世界（L1160-1170）；"ubicomp 承认设计的发散与多样；VR 想成为终极汇聚"（L1170）。
- **但 Weiser 错了一处**：他坚持 ubicomp 也是隐形计算（"最深刻的技术是消失的技术"，L1172）。
- **作者的纠正**："媒介是最深刻的技术之一，而媒介不消失。媒介及其形式在隐形与可见之间振荡——在窗口与镜子之间"（L1174）。
- 我们被普适媒介设备包围：数码相机、MP3、手机（L1176）；媒体处处（家庭、车辆、办公室）（L1178）。
- **注意力是最重要的通货**：Web 电商"买卖眼球"（L1180）；"注意力竞争是再媒介化的终极动机"（L1180）。
- **"普适计算已变成普适媒介"**（L1182）。

### 6. 可穿戴媒体形式

- **可穿戴计算机有 400 多年历史**：第一个可穿戴计算机是手表（L1186）。
- 手表既透明（报时）又反射（时尚宣言、财富标志）（L1188）。
- 瑞士手表业案例：石英表（Bulova Accutron 1960）在精度上击败机械表，但瑞士人靠"卖设计/生活方式"（Swatch、Rolex）挽回（L1190-1194）。
- 数字手表"笨拙无趣只发生在它们追求透明时"；手表业把透明界面卖给极客，把自反设计卖给时尚人群（L1194）。
- 可穿戴媒体（I-O Display 的 I-glasses、Sony Glasstron）承诺透明，但外观醒目（X-Men 的独眼龙造型）（L1198-1200）。
- **可穿戴计算机都交付媒体体验**，是"旧媒介的特定汇聚"，"既被看见也被看穿"（L1206）。

### 7. 从信息家电到媒介形式

- 信息家电包括可穿戴与手持设备（L1210）；谱系从手表、Walkman 到 Palm Pilot（L1210）。
- **Norman 认为信息家电是计算未来**（同 Weiser），电脑将隐入家电（电动马达类比）（L1212）。
- **但未来不只在单一用途家电**：电子书（Rocket Ebook）单一功能 vs 掌上设备的功能膨胀（L1214）。
- **Palm Pilot 的 Graffiti 手写体**：要求用户学习简化字母表，违反透明原则，但用户接受；熟练后透明，但仍"可见"——"把你标为新媒介适应者"（L1216-1220）。
- **信息家电不是隐形电脑**："它们的界面往往高度可见且反射"（L1218）。
- 外形即界面：iMac、G3 的亮色塑料与复古未来设计（L1224）。
- **"所谓信息家电通常就是媒介形式，而'家电'一词对媒介形式并不适用"**——我们不把书、画、照片叫家电（L1226）。

### 8. 媒介景观

- Fakeshop 是对我们生活的媒体景观的戏仿（L1230）。
- 整个 SIGGRAPH 会议是媒介景观的微缩世界（L1230）。
- 信息家电（Norman 以为会让电脑隐形）在四周清晰可见（L1230）。
- **数字设计的目标**：为汇聚与发散中的媒体设备景观增添引人入胜、富有信息的方式（L1230）。

## 逻辑梳理

1. 个案：Fakeshop 的多窗口拼贴展示媒体多样性 →
2. 批判：汇聚是神话，事实是"一系列暂定汇聚"（增强电视为例）→
3. 扩展：Web 的多样性使普适设计规则不可能 →
4. 实践：拼装（bricolage）是数字设计的常态 →
5. 前景：普适计算→普适媒介（Weiser 的错误）→
6. 收束：信息家电实为媒介形式；媒介景观。

## 论辩与阐述方法

- **神话批判法**：把"汇聚"命名为神话，与"透明神话""自然界面神话"并列。
- **案例对照**：交互电视（失败）vs 增强电视（成功）。
- **谱系学**：可穿戴计算机从手表到数字设备的谱系。
- **反例证伪**：用 Web 的多样性证伪"普适设计规则"。
- **概念转移**：把"信息家电"重新定义为"媒介形式"。
