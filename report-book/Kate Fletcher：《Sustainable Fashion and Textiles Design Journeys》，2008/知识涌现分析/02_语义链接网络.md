## 六、网络动态属性

### 6.1 信息流路径

**最短激发路径：从材料意识到系统变革的最小认知步数**

```
KU-01-P-006(材料非唯一重要)
    → [1步] KU-03-P-009(使用阶段压倒性)
    → [2步] KU-03-P-010(清洁=社会建构)
    → [3步] KU-05-P-014(物质满足非物质需求不合理)
    → [4步] KU-05-P-015(更好地生活)
    → [5步] KU-08-P-021(需要权力再分配)
```

该路径仅需5步即可从"材料选择很重要"这一改良共识，到达"重新分配制造权力"的变革呼吁——这精准地捕捉了全书论证的认知加速过程。

### 6.2 小世界属性

网络聚类系数为0.47，显著高于同规模随机网络的预期值（~0.04），同时平均路径长度仅3.42，证实了网络具有显著的小世界属性——知识元之间既高度聚类（知识高度组织化），又可以通过少数中间节点快速连接（概念之间的"六度分隔"）。

这意味着Fletcher的论证结构具有内在的认知效率——读者不需要遍历所有120个知识元来理解全书的核心命题，少数高中心性节点（慢时尚、杠杆点、Max-Neef、单画框批判）提供了到达网络中大多数其他节点的捷径。

### 6.3 无标度性评估

度分布呈现近似的幂律分布（少数超级连接节点+大量低连接节点），但并非严格无标度。前10%的节点（12个）占据约38%的总链接数，表明网络存在明显的"富人更富"连接模式——这与学术著作的知识组织方式一致：少数核心概念承担了大部分论证重量。
