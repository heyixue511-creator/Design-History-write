# 07 纪实摄影与苏联建设

## L01 章节概览

本章涵盖原书中图版240至326号所呈现的罗钦科纪实摄影与苏联建设项目记录，时间跨度1929–1935年。核心内容包括：白海-波罗的海运河建设（1933）、伊兹维斯蒂亚报社印刷厂（1929）、莫斯科-伏尔加运河建设（1930年代）、《苏联在建设中》（SSSR na stroike）杂志的摄影报道、以及莫斯科街头的广告建筑与政治标语景观。本章是罗钦科从实验摄影转向"生产性纪实"的关键过渡期，也是其创作与苏联国家权力关系最复杂的交集点。

## L02 核心主题

1. **摄影作为生产工具**：1930年代罗钦科的纪实转向可视为构成主义"生产艺术"理想在摄影领域的延迟实现——摄影不再是为艺术而艺术，而是服务于社会主义建设。
2. **劳动的美学化**：运河建设、工厂印刷、报纸生产——劳动过程本身成为摄影的核心题材。罗钦科试图在体力劳动与技术劳动中找到形式美的可能。
3. **大规模工程与个体命运**：白海运河由古拉格囚犯修建，罗钦科的照片既记录了工程的宏大，也暗含了个体的消隐。这一张力构成了本章最深刻的伦理与政治问题。
4. **纪实与宣传的模糊边界**：罗钦科为《苏联在建设中》拍摄的照片服务于苏联官方的自我展示，但其中某些作品超越了宣传功能，达到了独立的纪实美学高度。

## L03 关键作品分析

**《印刷机上的纸张》（图版276）与《流水线上的报纸》（图版277–279）**：1929年伊兹维斯蒂亚报社系列。罗钦科将报纸的工业生产过程分解为连续的视觉片段——纸张安装、印刷、计数、堆叠——构成了一部关于现代信息生产的微型视觉史诗。标题"他们这里从不睡觉"（图版270）将新闻业的不间断性转化为现代性的标志。

**《白海运河建设》系列（图版324–326）**：1933年拍摄。图版324显示前小偷斯捷潘·杜德尼克推着手推车——"在运河工作后，他成了一名画家和知名纪念碑艺术家"。图版325《与管弦乐队一起工作》是一幅戏剧性场景——囚犯在下方建造水闸，管弦乐队在上方排练，但"事实上囚犯和乐手都是同一批囚犯"。这张照片的自我指涉揭露让人不安——它既是纪实，也是对纪实的伪装。

**《无线电听众》（图版292–295）**：女儿瓦尔瓦拉在收听自制收音机，1932年作为莫斯科明信片系列出版。这幅照片将技术现代性（无线电）与现代家庭生活（女儿）融合，是1930年代苏联"有文化的日常生活"（kul'turnyi byt）话语的视觉范例。

**《广告建筑景观》（图版211–212, 257）**：罗钦科为莫斯科街头的商业广告（Mosselprom通心粉广告亭、国家出版社教科书广告牌、斯滕伯格兄弟设计的AVTODOR彩票壁画）拍摄的记录。这些照片现在成为1920年代苏联街头商业视觉文化的重要档案。

## L04 技术手法

1. **从Leica到纪实报道**：1930年代罗钦科使用Leica相机（配Elmar f.50mm镜头），小型相机的灵活性使其能够应对运河工地、工厂车间等复杂拍摄环境。
2. **"不再思考形式法则"**：罗钦科在《一个艺术家的转变》（1936）中声称在运河拍摄时放弃了形式主义思考。但检视实际作品——对角线的推车工人、由阴影构成的劳动场景——可以发现构图意识从未真正消失，只是从"显性建构"转为"隐性选择"。
3. **审查制度下的拍摄策略**：白海运河拍摄中，罗钦科必须在现场制作样片并交出全部底片供审查，只有获得许可的材料才能带出。这种"注视的检查"（被观看者反过来检查观看者的观看）构成了摄影史上一个极端的政治案例。
4. **系列报道的叙事结构**：罗钦科的《苏联在建设中》摄影报道采用系列图片的编辑性叙事——单一照片不足以构成报道，照片之间的顺序与对照才生产意义。这是构成主义在出版编辑中的延伸。

## L05 历史语境

- **第一个五年计划（1928–1932）**：苏联进入高速工业化时期，大规模建设工程需要摄影作为"建设成就"的视觉证据。
- **《苏联在建设中》**：1930年创刊的这本大型画报是苏联最重要的宣传性摄影刊物，以多语种向国际社会展示苏联建设成就。罗钦科为其供稿直至1940年代。
- **白海-波罗的海运河**：227公里长的运河于1931–1933年由约10万古拉格囚犯以原始工具挖掘建成，数万人在此过程中死亡。罗钦科和其他苏联作家（如高尔基）被组织前往报道，其作品构成了一份"被组织的见证"。
- **社会主义现实主义的确立**：1934年苏联作家协会第一次代表大会正式确立社会主义现实主义为唯一创作方法，对摄影界也产生了直接压力。

## L06 理论关联

1. **纪实摄影与"事实"概念**：LEF小组的"事实的文学"理论强调对现成材料的记录与组织，罗钦科的纪实摄影可以视为此理论在视觉领域的实践。但"事实"在苏联语境中往往是高度建构的——"白海运河是改造罪犯的伟大工程"这种"事实"本身就是政治建构的产物。
2. **"见证"的政治**：罗钦科的白海运河系列提出了关于艺术见证的伦理问题——在审查制度下拍摄、由政治机构组织、服务于宣传目的的"见证"，其见证价值何在？德里达（Jacques Derrida）关于见证与责任的讨论可为分析此问题提供理论框架。
3. **劳动身体的视觉政治**：罗钦科镜头下的劳动者——无论是前小偷杜德尼克还是演奏管弦乐的囚犯——其身体既是劳动的主体也是政治改造的对象。这与苏联古拉格体系中"劳动改造"（corrective labor）的意识形态直接相关。

## L07 影响与接受

- 白海运河系列在当年曾作为《苏联在建设中》特刊和《白海运河建设》（Belomorstroi）专辑出版，是苏联宣传体系的重要产品。
- 在后斯大林时代，随着古拉格真相的逐步揭露，白海运河系列被重新审视——不是作为"建设成就的记录"，而是作为"宣传机制运作的证据"。
- 拉夫连季耶夫在本书中对这一系列的呈现相对谨慎——既指出审查的存在，又不直接评判罗钦科的共谋程度。这种小心翼翼的平衡体现了后苏联时期对先锋派与斯大林主义关系的复杂态度。
- 罗钦科的工厂与印刷厂系列在1970年代后的西方传播中，常被剥离政治语境，作为"工业现代主义的视觉美学"而被接受。

## L08 批判性解读

1. **共谋还是幸存**：罗钦科参与白海运河拍摄是自愿的、被指派的、还是别无选择的？拉夫连季耶夫暗示是后者，但未提供决定性证据。罗钦科写下的"不再思考形式法则"——是一种解放，还是心灵被体制捕获的证词？
2. **"社会主义劳动"的美学欺骗**：罗钦科的照片赋予古拉格劳动以英雄主义和美学尊严（对角线构图、戏剧性光影），这是否构成一种通过美学手段实施的政治欺骗？或者说，摄影的"美化功能"本身就是其政治同谋性的体现？
3. **看得见和看不见的**：罗钦科的镜头记录了水闸、手推车、管弦乐队，但没有记录死亡、饥饿、看守的暴行。这种"选择性的可见"是审查制度的结果，但也可能是罗钦科自觉的选择——他在拍摄时已经预见了审查的边界。
4. **家族叙事中的沉默**：拉夫连季耶夫在描述祖父的工作时流露出的是同情而非批判。"个人的怨恨平息了"——这究竟是理解，还是一种对更严峻的道德问题的回避？

## L09 延伸研究建议

1. 在俄罗斯联邦安全局（前身为克格勃）档案馆中搜寻罗钦科白海运河拍摄的原始审查记录和出入许可文件。
2. 与同期其他苏联摄影师（如马克斯·阿尔珀特、格奥尔吉·泽尔马）的社会主义建设纪实进行比较研究，辨识罗钦科在苏联纪实摄影系谱中的独特性。
3. 研究《苏联在建设中》杂志的整个出版史——编辑方针、图文关系、国际传播策略——将罗钦科的贡献置于机构逻辑中理解。
4. 以罗钦科白海运河系列为案例，开展关于"艺术与政治暴力"的跨学科研讨，涉及摄影史、苏联史、伦理学与见证理论。
