# 00_方法与规则：知识涌现分析框架

## L001 本模块的定位与目标

本模块"知识涌现分析"是对《Graphic Design and Architecture: A 20th-Century History》（Richard Poulin，Rockport Publishers，2012）12 份分析报告（00 整体 + Ch01-Ch07 + NN 专项）进行的二次知识加工。与先行的"分析报告"模块（逐章研读、实体提取、论点评判）不同，本模块将分析报告视为一个"知识系统"，运用语义网络分析与涌现计算，揭示各章之间、各实体之间、各论点之间的结构性关联，发现仅在整体景观下才能浮现的"涌现知识"（emergent knowledge）。

**核心问题意识**：
1. 本书 12 份分析报告作为知识整体，其内部结构是什么？
2. 哪些实体、概念与主题构成知识网络的"枢纽节点"？
3. 各章之间经由跨章引用形成了怎样的"语义链接"网络？
4. 从这些链接中可以计算出哪些涌现模式——"最密集关联区""最强谱系链""知识薄弱区"？
5. 最终可产生哪些超越线性阅读的"知识发现"？

## L002 "知识涌现"的操作性定义

**知识元（Knowledge Unit, KU）**：分析报告中可独立识别、具有语义完整性的最小知识片段。本书采用六类实体类知识元（人物、著作/作品、概念、机构、地点、事件），与 NN 专项报告的实体总索引一致。

**语义链接（Semantic Link, SL）**：两个知识元之间经由分析报告文本明确建立的关系。本书使用 9 种语义链接类型（见 L005）。

**知识涌现（Knowledge Emergence）**：当知识元网络中的子结构（如三元组 A→B→C、谱系链、主题簇）产生出不能归约于其构成节点之和的特征或信息时，即发生知识涌现。涌现计算依据：节点度 k、桥接值 b、簇识别（强连通）、内聚度、涌现强度 S、一级/二级涌现。

## L003 方法论步骤

1. **第一步（本文件）**：定义层级（知识元 → Topic → Theme）、9 种语义链接判定标准、涌现指标、证据规范与报告清单。
2. **第二步（01 号）**：六类实体知识元的全文语义载荷分析——"做什么、指什么、为何存在"，先总述五种论证功能，再按类分表，附行号证据。
3. **第三步（02 号）**：构建语义链接网络——核心枢纽识别（节点度 k、桥接值 b 排序）、链接清单（按主题区组织）、枢纽与中介分析（含反例与边界）、网络整体特征。
4. **第四步（03 号）**：知识涌现计算——Topic 识别（连通簇）、Theme 聚合、内聚度与涌现强度 S 计算、一级/二级涌现结构、客观性核对与反例。
5. **第五步（04 号）**：知识发现报告——结构发现、隐藏枢纽与"点到未论"潜在链接（C1…Cn）、跨主题综合命题、完整层级图谱、总体评价与边界声明。

## L005 九种语义链接判定标准

| 类型 | 编码 | 判据 | 示例（含证据行号） |
|---|---|---|---|
| 因果 | → | A 是 B 产生的必要条件/直接动因；文本有"由于/因为/导致"式表述 | 白炽灯发明（L317）→ 电光广告（L361-369）→ Great White Way（L405） |
| 条件 | ⇒ | A 是 B 成立的前提条件；B 依赖 A 的存在 | 州际公路体系（L1101-1102）⇒ 路边连锁品牌视觉（L1104-1222） |
| 对比 | ↔ | 文本明确将 A 与 B 对照（风格、立场、成败） | art nouveau ↔ art deco（L801）；现代主义 ↔ 后现代（L1860） |
| 隶属 | ⊂ | A 是 B 的组成部分/实例 | AIGA 象形图 ⊂ 美国交通部导视系统（L1742-1744） |
| 时序 | ≻ | A 在时间上先于 B，且文本强调其先后 | Johnston 字体（1916）≻ Gill Sans（1927）（L583）；Beck 地图（1933）≻ Vignelli 地图（L1541） |
| 空间共现 | ≈ | A 与 B 在同一场所/城市共同出现 | 摩天楼群与 Rockefeller Center 共现于曼哈顿中城（L816-919） |
| 属性 | : | B 是 A 的固有属性/特征描述 | London Underground map : 图式化（diagrammatic）（L588） |
| 论证支撑 | ⇐ | A 为 B 提供论据/权威背书 | Arendt 引语 ⇐ 极权宣传分析（L1008）；Rand 评 Hofmann ⇐ 瑞士风格教育（L1821-1827） |
| 同域 | ∼ | A 与 B 共享主题域/谱系但不构成上述强关系 | Frutiger 字体 ∼ Univers ∼ Gill Sans（人本主义无衬线族，L1731-1738） |

**审慎原则**：当文本使用"似乎/可能/看来"等弱语气时，链接记为弱链接；当存在反例时，在 02/03 号文件中并列边界。

## L006 涌现指标

| 指标 | 符号 | 定义 |
|---|---|---|
| 节点度 | k | 某知识元直接链接的其他知识元数量。k 高者即枢纽。 |
| 桥接值 | b | 节点处于多少对其他节点之间"最短路径"上（中介中心性近似）。b 高者即桥。 |
| 簇识别 | C | 强连通子图：簇内两两可达或通过枢纽高度互达的节点集合。 |
| 内聚度 | coh | 簇内实际链接数 / 簇内最大可能链接数。 |
| 涌现强度 | S | S = 簇内链接密度 × 跨章链接比例 × 类型异质性（链接类型的种类数）。 |
| 一级涌现 | E1 | 直接由链接网络可见的结构性模式（枢纽、簇、谱系链）。 |
| 二级涌现 | E2 | 需跨簇/跨章综合才能得到的命题（与单个知识元不可归约）。 |

## L007 证据规范

1. **每条链接必须标注 clean 版行号证据**（L###），不得凭空构造。
2. **每条涌现命题（P）必须附生成机制（由哪些链接/簇聚合而来）与强度（S 或定性的 k/b/coh 依据）**。
3. **客观性核对**：对"枢纽中心性"等结论列出反例与边界（如作者本所案例的利益相关性、纽约中心叙事造成的度值偏斜）。
4. **知识元编码**：使用 `E{类别}-{序号}`（如 E1-001 指第一个"人物"）；链接编码 `SL{类型}-{序号}`；Topic 编码 `T{序号}`；Theme 编码 `TH{序号}`；涌现命题编码 `P{序号}`；潜在链接编码 `C{序号}`。
