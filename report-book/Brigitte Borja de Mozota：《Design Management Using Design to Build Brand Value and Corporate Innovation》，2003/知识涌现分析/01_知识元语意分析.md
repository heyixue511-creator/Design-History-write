# 01 知识元语意分析：全知识元提取与语义描述

### 一、概述

本章从16份源分析报告（15份章节分析报告 + 1份整体分析报告 + 1份专项报告/实体总索引）中，按照00_方法与规则中定义的六类实体框架，提取135个知识元（Knowledge Units, KU）。每个知识元包含元标识（KU-ID）、类别归属（CAT）、核心命题（PROP）、证据基础（EVID）、关系势能（RPOT）和层次定位（LVL）六个要素。

提取依据：分析报告中的"八、实体清单"和"九、跨章节关联总览"两个关键节段，以及NN_专项报告与实体总索引.m中的六类总索引，确保提取结果具有跨章节覆盖性和深度。
