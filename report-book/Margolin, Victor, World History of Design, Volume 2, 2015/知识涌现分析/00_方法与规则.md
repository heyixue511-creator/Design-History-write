# 00_方法与规则：知识涌现分析的框架与操作规程

## L1 一、分析目标与定位

### L2 1.1 分析目标
L3 本分析旨在从《世界设计史》第二卷的19份分析报告（1份整体报告 + 18份章节报告）中，通过知识元提取、语义链接构建和涌现计算，发现超越单章、超越显性论述的新知识——即那些存在于报告之间、隐含于概念关联之中、尚未被原报告明确表述的"涌现知识"（emergent knowledge）。

### L2 1.2 定位
L3 本分析是"分析报告"的元层面加工——不是再次分析原著，而是分析"分析报告"所形成的知识体系。分析的原材料是19份markdown格式的分析报告，每份报告遵循统一的L###层级结构（L1-L3三级标题），包含实体清单、论点体系、逻辑链条、关联网络等结构化信息。

### L2 1.3 与"分析报告"的关系
L3 ```
分析报告（19份）→ 知识元提取 → 语义网络构建 → 涌现计算 → 知识发现报告
     ↓                    ↓                ↓              ↓
  显性知识层          知识单元层        关系结构层      隐性知识层
```
分析报告呈现的是"显性知识"——对每章内容的归纳、梳理和结构化。本分析要发现的是"隐性知识"——那些因跨章关联、概念共振、结构同构而产生的、单章分析无法独立揭示的知识。

## L1 二、核心概念定义

### L2 2.1 知识元（Knowledge Element, KE）
L3 **定义**：知识元是构成分析报告知识体系的最小独立语义单元。一个知识元是一个不可再分的、具有独立认知意义的陈述或实体。

L3 **类型**：知识元分为六种基本类型：
| 类型代码 | 中文名称 | 定义 | 示例 |
|----------|----------|------|------|
| KE-P | 人物元 | 设计师、艺术家、理论家、政治家等行动者 | Walter Gropius、鲁迅 |
| KE-O | 机构元 | 学校、企业、政府部门、协会、运动 | Bauhaus、Werkbund |
| KE-C | 概念元 | 理论概念、分析范畴、风格标签 | 现代性、流线型、消费工程 |
| KE-E | 事件元 | 历史事件、展览、革命、战争 | 1925巴黎博览会、十月革命 |
| KE-W | 作品元 | 设计作品、出版物、建筑、视觉材料 | 红蓝椅、《新字体排印》 |
| KE-T | 论点元 | 分析报告中提炼的核心论点和判断 | "极权政体没有统一的设计模式" |

L3 **标识规则**：每个知识元赋予唯一编号，格式为`KE-{类型代码}-{来源章号}-{序号}`。例如：`KE-C-21-01`表示第21章的第01号概念元。

### L2 2.2 语义链接（Semantic Link, SL）
L3 **定义**：语义链接是两个知识元之间有意义的、可定义的关系。它不仅是"有关联"，更是一个具有方向性、类型化标签的认知关系。

L3 **链接类型**：
| 类型代码 | 关系名称 | 方向性 | 定义 | 示例 |
|----------|----------|--------|------|------|
| SL-INFLUENCE | 影响关系 | A→B | A对B产生了可辨识的影响 | 包豪斯→美国设计教育 |
| SL-OPPOSE | 对立关系 | A↔B | A与B在理念或实践上对立 | 手工艺理想↔工业标准化 |
| SL-EVOLVE | 演化关系 | A→B | A在时间或逻辑上发展为B | 构成主义→社会主义现实主义 |
| SL-PARALLEL | 平行关系 | A↔B | A与B在不同空间中呈现结构相似性 | 苏联宣传海报↔纳粹宣传海报 |
| SL-CONTAIN | 包含关系 | A⊃B | A在集合或逻辑上包含B | 现代性⊃德国工业标准化 |
| SL-PRECEDE | 前驱关系 | A→B | A是B的历史或逻辑前驱 | 卢布克木刻→ROSTA之窗 |
| SL-EXCHANGE | 交流关系 | A↔B | A与B之间存在双向知识/人员流动 | 苏联构成主义↔德国包豪斯 |
| SL-CAUSE | 因果关系 | A→B | A是B的原因或前提条件 | 1929大萧条→流线型消费策略 |
| SL-COMPARE | 比较关系 | A↔B | A与B可构成有意义的比较 | 美国消费设计↔北欧福利设计 |
| SL-BRIDGE | 桥接关系 | A—B | A与B通过中介C产生间接关联 | 月份牌—华人侨民网络—东南亚设计 |

### L2 2.3 语义链接网络（Semantic Link Network, SLN）
L3 **定义**：语义链接网络是以知识元为节点（node）、以语义链接为边（edge）构成的有向多重图。网络中的每个节点携带类型标签和属性，每条边携带关系类型标签和权重。

L3 **数学表示**：
L3 `SLN = (V, E, T_V, T_E, W)`
L3 其中 V 为知识元节点集，E 为语义链接边集，T_V 为节点类型函数，T_E 为边类型函数，W 为边权重函数。

### L2 2.4 知识涌现（Knowledge Emergence, KE*）
L3 **定义**：知识涌现是指从语义链接网络的整体结构和动态中产生的、不能从单一节点或单一边还原的新知识。涌现知识具有三个基本特征：（1）**新颖性**——在原分析报告中未被明确表述；（2）**结构性**——由网络拓扑而非节点属性产生；（3）**可验证性**——可回溯到具体的链接路径和节点。

L3 **涌现类型**：
| 类型 | 名称 | 定义 |
|------|------|------|
| E-PATTERN | 跨域模式 | 在不同区域/时段中重复出现的结构模式 |
| E-BRIDGE | 隐性桥梁 | 通过网络分析发现的、未被原报告明示的跨章关联 |
| E-CLUSTER | 主题聚类 | 从网络社区检测中涌现的概念群组 |
| E-HOLE | 结构洞 | 网络中理应存在但缺失的链接——指示研究空白 |
| E-HUB | 枢纽涌现 | 在全局网络中具有异常高中心度的节点——揭示"轴心概念" |
| E-TENSION | 矛盾涌现 | 不同论点元之间的结构性矛盾或张力 |
| E-META | 元知识 | 关于知识体系自身的反思性发现——如方法论偏好、叙事偏斜 |

## L1 三、操作规程

### L2 3.1 第一阶段：知识元提取
L3 **输入**：19份分析报告（`分析报告/`目录下所有`.md`文件）
L3 **操作**：
1. 逐章扫描分析报告的"实体清单"（第八节），提取所有六类实体：人物、机构、概念、事件、作品、论点
2. 从"核心论题"（第三节）和"关键论点"中提取论点元
3. 从"逻辑梳理"（第四节）中提取因果关系链中的节点
4. 从"关联"（第九节）中提取跨章引用所涉及的知识元
5. 每个知识元赋予唯一编号、类型标签、来源章号、简短描述

L3 **提取密度规则**：
- 人物元：每章≥5个（按实体清单）
- 机构元：每章≥3个
- 概念元：每章≥4个
- 事件元：每章≥2个
- 作品元：每章≥3个
- 论点元：每章≥3个（从核心论点和关键论点中提取）

L3 **去重规则**：同一实体在多章中出现时，保留首次出现的编号为主编号，后续出现的标记为引用（ref），不创建重复节点。

### L2 3.2 第二阶段：语义链接构建
L3 **操作**：
1. 从分析报告的"关联"（第九节）中提取显性链接
2. 从"逻辑梳理"（第四节）的因果链中提取因果/演化链接
3. 从实体清单的共现关系中推断链接（同一章中频繁共现的实体之间可能存在链接）
4. 从整体分析报告（00_）和专项报告（NN_）的跨国主题中提取跨章链接
5. 为每条链接赋予类型标签、方向性、置信度（1-3，1=原文明示，2=从明示关系推断，3=从网络结构推断）

L3 **链接密度控制**：
- 每章内部至少构建15条链接
- 章间至少构建50条跨章链接
- 全局网络应至少包含300条链接

### L2 3.3 第三阶段：网络分析与涌现计算
L3 **操作**：
1. **中心度计算**：计算每个节点的度中心度（degree）、中介中心度（betweenness）、特征向量中心度（eigenvector），识别高影响力节点
2. **社区检测**：使用模块度优化算法（Louvain）检测网络中的概念社区
3. **结构洞检测**：识别网络中高约束系数的节点和缺失链接
4. **路径分析**：计算任意两节点间的最短语义路径
5. **涌现模式识别**：综合以上计算结果，识别七种涌现知识类型

### L2 3.4 第四阶段：知识发现综合
L3 **操作**：
1. 将涌现计算结果转化为可读的发现陈述
2. 按"主题域"而非"章节"组织发现
3. 每条发现标注其证据链——指向具体的知识元节点和链接路径
4. 区分"强涌现"（多种计算方法交叉验证）和"弱涌现"（单一方法指示）
5. 提出基于涌现发现的研究建议

## L1 四、L###层级标注规则

### L2 4.1 层级定义
L3 本分析沿用分析报告的L###层级体系：
- **L1**：一级标题，标识文档的主要部分（如"一、分析目标与定位"）
- **L2**：二级标题，标识部分的子主题（如"2.1 知识元定义"）
- **L3**：正文段落级，承载实质性分析内容

### L2 4.2 使用规则
L3 (1) 每个标题行必须以L1/L2/L3开头；(2) L3段落是分析的基本载体，每个L3应表达一个完整的语义单元；(3) L1和L2仅作为结构标记，不承载分析内容；(4) 跨文件引用使用`文件名#章节号`格式，如`00_整体分析报告#三`。

## L1 五、质量准则

### L2 5.1 忠实性准则
L3 所有知识元必须可在原分析报告中找到依据。涌现发现必须可回溯到具体的节点和链接路径。不允许凭空构造知识元或链接。

### L2 5.2 系统性准则
L3 覆盖19份报告的全部实体类型和关联类型。不选择性忽略某些章节或区域。全球各区域（欧洲、北美、拉美、亚洲、非洲、大洋洲）均应纳入分析。

### L2 5.3 可验证性准则
L3 每条涌现发现必须标注：(1) 涉及的节点编号；(2) 关键链接路径；(3) 发现类型；(4) 置信度等级。

### L2 5.4 新颖性准则
L3 涌现发现必须超越原分析报告的显性陈述——不能是对已有内容的简单复述。判断标准：如果该陈述在某一分析报告中已经明确出现，则为"复述"而非"涌现"。
