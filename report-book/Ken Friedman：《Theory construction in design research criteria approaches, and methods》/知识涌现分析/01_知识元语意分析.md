## 二、概念型知识元（KU-C）语意分析

### L101 K-C01: Design as Problem-Solving（设计即解决问题）

| 属性 | 内容 |
|------|------|
| 类型 | KU-C（概念型） |
| 层次 | L1 基础层——全文的概念地基 |
| 语义负载量 | 高——全文几乎所有论证均以该概念为前提或参照 |
| 来源L# | L001, L009, L010论1, L024a, L107论2, L207论1-2, L222a, B001 |
| 核心语义 | 设计是"设计行动方案以将现存境况转变为更优境况"的过程（Simon定义）。该概念包含三个共有属性：过程性、目标导向性、问题解决性 |
| 语义边界 | 排除了不以解决问题为首要目的的设计实践（批判性设计、思辨设计、艺术性设计） |
| 语意张力 | "preferred situations"的表述具有极大的语义弹性——可容纳几乎任何设计行为，使得"排他性"与该概念的"包容性"表述之间存在内部张力 |
| 跨域关联 | 源自Simon的人工智能/决策理论传统，被Friedman移植为设计研究的操作性定义 |
| 涌现敏感性 | 是——该概念处于多个论证链的起点，且其语义弹性与Friedman的规范使用之间的张力是涌现的候选条件 |

### L102 K-C02: Theory as Model（理论即模型）

| 属性 | 内容 |
|------|------|
| 类型 | KU-C（概念型） |
| 层次 | L1 基础层——为全文理论讨论提供最基础的定义基点 |
| 语义负载量 | 高——理论的定义是全文的核心议题 |
| 来源L# | L010论2, L022b, L024b, L207论6, L220b, L222c, B002 |
| 核心语义 | 理论的最基本形式是展示元素之间关系的模型。分为静态模型（如分类学，描述关系但不描述过程）和动态模型（描述过程和行动） |
| 语义边界 | 极其宽泛——"模型/图示"的界定使分类学也被纳入理论范畴（K-C10），但这种宽泛性在全文论证中被逐步收紧（通过Whetten和Parsons & Shils的标准） |
| 语意张力 | "most basic form"的措辞为后续复杂化预留了空间——理论从模型到有序断言集合到经验-理论系统，语义在全文各章中发生显著的渐进化"升级" |
| 涌现敏感性 | 是——该概念在§1中极度宽泛，在§2中被逐步收紧，在§3§4中被规范性使用，这一"语义渐变"本身是一个跨章涌现线索 |

### L103 K-C03: Profound Knowledge（渊博知识）

| 属性 | 内容 |
|------|------|
| 类型 | KU-C（概念型） |
| 层次 | L2 中间层——为理论与实践的关系提供规范性框架 |
| 语义负载量 | 高——全文论证的关键"锚点"概念 |
| 来源L# | L010论5, L024c, L208例3, L222f, L507论5, B004 |
| 核心语义 | Deming提出的由四部分组成的知识体系：系统欣赏（appreciation for a system）、变异知识（knowledge of variation）、知识理论（theory of knowledge）、心理学（psychology） |
| 语义边界 | 原始语境为制造业质量管理，被Friedman跨域移植到设计研究——这一移植的语义"保真度"未经验证 |
| 语意张力 | 从制造业专用框架到"使设计成果可预测"的通用知识要求——发生了LND003所述的"含义漂移" |
| 跨域关联 | 跨域链接（SL-TRA）：制造业质量管理→设计研究 |
| 涌现敏感性 | 是——作为全文论证的"锚点"，与多个知识元形成密集链接 |

### L104 K-C04: Disciplined Imagination（有纪律的想象）

| 属性 | 内容 |
|------|------|
| 类型 | KU-C（概念型） |
| 层次 | L2 中间层——为理论建构提供认识论定位 |
| 语义负载量 | 中高——该概念的"矛盾修辞"性质使其在文本中具有特殊的论证凝缩力 |
| 来源L# | L010论1, L024d, L207论8, L220e, L222j, B005 |
| 核心语义 | Weick将理论建构定义为"有纪律的想象的行为"——在系统化学术规训中发挥想象力 |
| 语义边界 | "disciplined"强调约束和规则，"imagination"强调自由和创造——两者之间的张力恰恰是该概念的核心语义 |
| 语意张力 | 矛盾修辞的内在对立——纪律约束想象还是想象被纪律规范？Friedman在全文中倾向于强调"discipline"而淡化"imagination"的维度 |
| 涌现敏感性 | 是——该概念在Friedman的论证中发生了一次微妙的"含义漂移"：从"纪律与想象的平衡"偏向"纪律约束下的想象" |

### L105 K-C05: Tacit Knowledge（默会知识）

| 属性 | 内容 |
|------|------|
| 类型 | KU-C（概念型） |
| 层次 | L1 基础层——理论与实践区分的哲学基础 |
| 语义负载量 | 高——全文最具争议性的概念，出现在几乎所有论证链条中 |
| 来源L# | L010论4, L024e, L207论8, L222h, L406-407, L420a, B006 |

| 语意张力 | 该概念在全文中的语义是分裂的——§1作为中立概念引入，§3作为需要被超越的对象，§4作为知识管理循环的一环（被部分恢复价值） |
| 涌现敏感性 | 极高——该概念在全文中的"语义游移"可能是全文最具涌现潜力的知识元 |

| 层次 | L3 应用层——评判性概念的强形式 |

### L112 K-C12: Explicit Articulation（显性表述）

| 属性 | 内容 |
|------|------|
| 类型 | KU-C（概念型） |
| 层次 | L1 基础层——理论建构的必要条件 |
| 语义负载量 | 高——§3的核心正面主张 |
| 来源L# | L407论7-9, L418f, L420f, B016 |
| 核心语义 | 可以被书写、分享、检验和反思的理论表达形式——是所有理论活动的基础，无论研究范式 |
