# Ch26 分析报告（Creating Economic Value by Design）

## 一、章节定位与功能
阅读材料26，发表于International Journal of Design（台湾，2008年第3卷第1期）。全书最长单篇，是Heskett关于"设计如何创造经济价值"的最全面理论阐述。Part III C组之高潮，也是"Design and the Creation of Value"研讨会（参见Ch03）的部分消化。Dilnot指出此章"将Part I中设计与经济学的关键阅读与Part III中的政策提案联系在一起。"

## 二至三、内容概要
**核心论题**：设计创造经济价值的机制不能在新古典经济学的框架内被理解（其静态假设将设计降为琐碎活动），而需要一种整合了企业层面实践（micro-level）、制度环境（institutional structures）、和技术可能性（technological opportunity）的综合性分析。"The argument here is that profitability cannot be understood without examination of these deeper causes, which inevitably involves a consideration of values in a wider sense than the numerical alone."

**关键论点**：1. "Value vs values"的区分——定量（货币/股价）vs定性（用户满足/文化意义）的根本张力；2. 生产语境（profitability优先）vs使用语境（satisfaction优先）的双重性；3. Tacit vs codified knowledge（默会vs编码知识）——Halberstam的福特案例展示了量化管理对设计创造力的系统性压制；4. Menger的用户中心论——"if value is determined by customers...then not only the context of production needs to be examined, but also the context of use."

**关联**：Ch26是整个Reader的理论制高点。它连接了Ch03（设计-经济学双向对话的理论基础）、Ch19-22（国家设计政策的实践应用）、以及Ch23-25（创造性破坏/产品完整性/文化人因）。与Ch05结论中关于"我们拥有设计史中最令人震惊的丰富遗产"的人文主义展望形成了"硬"经济学分析与"软"人文关切的辩证。
