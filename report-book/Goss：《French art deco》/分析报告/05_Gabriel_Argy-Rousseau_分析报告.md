### L1 章节目录信息
- **设计师**：Gabriel Argy-Rousseau（1885-1953）
- **位置**：Catalogue第一个条目
- **藏品编号**：no.1 — Eurythmics Vase (1932)
- **规模**：传记约3页 + 1件藏品描述

### L2 功能定位
作为Catalogue的开篇条目，Argy-Rousseau同时承担了**技术导引**功能：通过对pâte-de-verre技法及其历史的详细描述，为后续涉及同一技法的条目（Décorchemont的nos. 12-13）建立了技术语境。

### L3 特殊性
Argy-Rousseau并非按字母顺序排列的首位（A开头），但被置于Catalogue之首——这一位置选择暗示了pâte-de-verre作为"古老技术现代复兴"的**象征意义**，呼应导论中"通过历史创新"的核心主题。

## 三、内容分析

### L1 核心论题

**技术革新驱动艺术表达**：
Argy-Rousseau对pâte-de-verre的首要贡献是开发了**可重复使用的模具**，使该技法从单件制作转向批量生产。这种"工程学思维"在Art Deco设计师中具有代表性——技术理性与审美创新的结合。

**艺术家-科学家的双重身份**：
> "he received patents for a number of unusual inventions, including an electric torpedo launcher for automobiles" + "inventing an apparatus for single-exposure color photography"

### L2 关键案例
- **Eurythmics Vase（1932）**：以现代女性韵律体操活动为题材，将古典cameo技法与现代主题结合。Goss特别指出"the women are up-to-date, sporting fashionably bobbed hairstyles"——传统技法承载当代内容。
- **Pliny轶事**：引用古罗马传说——发明pâte-de-verre的陶工被皇帝斩首以保守秘密——将Argy-Rousseau的技术努力置于宏大的历史神秘传统中。

## 四、逻辑梳理

### L1 论证链条
```
pâte-de-verre古老起源（古埃及/罗马）→ 失传达数千年
→ 19世纪末Henri Cros复兴 → Argy-Rousseau在Sèvres学校接触（通过Cros之子）
→ 工程学训练 → 技术改进（可重复使用模具）
→ 1921年商业化生产 → 国际经销 → 风格从新艺术→Art Deco演化
→ 1929年危机 → 公司关闭 → 个人工作室小规模延续
→ 战后遗忘 → 1960年代重新发现
```

### L2 因果转折
- **技术发明→商业扩张**：模具技术是1920年代国际经销的基础
- **1929经济危机→公司关闭（1931）**：奢侈品市场的脆弱性
- **风格简化**：从彩色抽象到"massive and monochromatic"——晚期作品反映了市场萎缩和品味转变

## 八、实体清单

### L1 人名
1. **Gabriel Argy-Rousseau**（Joseph-Gabriel Rousseau, 1885-1953）—— 玻璃艺术家
2. **Henri Cros**（1840-1907）—— pâte-de-verre复兴者
3. **Jean Cros** —— Henri之子，Argy-Rousseau在Sèvres的同学
4. **Maxianne Argyriades** —— 妻子，其姓氏被组合为"Argy-Rousseau"
5. **Gaston Moser-Millot** —— 商业合作伙伴
6. **Émile Jaques-Dalcroze**（1865-1950）—— 瑞士音乐家，发明Eurythmics

### L2 机构与组织
1. **École Nationale de Céramique de Sèvres**
2. **Les Pâtes-de-Verre d'Argy-Rousseau**（1921-1931）
3. **Société des Artistes Français**
4. **Société des Artistes Décorateurs**

### L3 展览与事件
1. **1914年首次Salon展览**
2. **1925年巴黎博览会**（评审+Grand Palais+Ambassade Française）
3. **1934年Musée Galliera玻璃展**

### L4 作品与物件
1. **Eurythmics Vase（1932）** —— MMA藏品，cameo女性韵律操形象
2. **electric torpedo launcher for automobiles** —— 军事发明（专利）

### L5 材料与技术
1. **pâte-de-verre** —— 碎玻璃粉+水+粘合剂+高岭土/金属氧化物/铅→模具→窑烧
2. **pâte-de-cristal** —— 铅晶质变体
3. **reusable molds** —— Argy-Rousseau的核心技术创新
4. **single-exposure color photography apparatus** —— 1925年发明

### L6 学者/批评家
1. **Janine Bloch-Dermant** —— Argy-Rousseau专著作者（1991）
