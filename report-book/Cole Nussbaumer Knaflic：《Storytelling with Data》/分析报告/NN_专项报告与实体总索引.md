| 章节 | 发展状态 | 核心表述 |

### L012.01.03 格式塔原理与预注意属性的协同关系

格式塔原理（Ch.3）解释了受众"如何自然地感知视觉信息"，预注意属性（Ch.4）提供了"如何策略性地利用这一感知机制"的工具。两者的关系为：
- 邻近性（格式塔）→ 直接标注数据（预注意应用）
- 相似性（格式塔）→ 一致颜色编码（预注意应用）
- 包围（格式塔）→ 视觉分区与强调（预注意应用）
- 闭合（格式塔）→ 去除多余视觉元素（杂乱消除）

## L012.04 专项报告四：全书图表类型推荐/禁止清单

### L012.04.01 强烈推荐（Frequently Used）

| 图表类型 | 使用场景 | 关键规则 |
|---------|---------|---------|
| Simple Text（简单文本）| 仅1-2个关键数字 | 数字突出+最少文字 |
| Line Graph（折线图）| 连续数据/时间序列 | x轴间隔一致，可不从零基线 |
| Slopegraph（斜率图）| 两个时间点的多类别对比 | 线条重叠时需谨慎 |
| Horizontal Bar Chart（水平柱状图）| 分类数据（作者首选）| 必须从零基线，类别名长时尤佳 |
| Vertical Bar Chart（垂直柱状图）| 分类数据 | 必须从零基线 |
| Waterfall Chart（瀑布图）| 增量分解/起始→变化→结束 | 使用堆叠柱状图技术实现 |
| Heatmap（热力矩阵）| 表格+颜色饱和度的混合 | 单色饱和度优于彩虹色 |
| Scatterplot（散点图）| 展示两变量关系 | 适合科学/偶尔的商业场景 |

### L012.04.02 谨慎使用（Conditional）

| 图表类型 | 条件/注意事项 |
|---------|-------------|
| Stacked Bar Charts（堆叠柱状图）| 仅底部系列易比较，上方系列无统一基线 |
| 100% Stacked Bar（100%堆叠柱状图）| 需补充绝对数值上下文 |
| Square Area Graph（方形面积图）| 仅当数量级差异巨大时 |
| Secondary Y-axis（次级y轴）| 优先考虑直接标注或垂直分面 |
| Small Multiples（小面板图）| 各面板y轴范围必须一致 |

### L012.04.03 禁止使用（Avoid）

| 图表类型 | 禁止原因 |
|---------|---------|
| Pie Chart（饼图）| 人眼不擅二维角度/面积比较；3D歪曲；相近扇形不可区分 |
| Donut Chart（甜甜圈图）| 比饼图更糟——要求比较弧长 |
| 3D Charts（三维图表）| Excel以不可见切线面作图；永远不应用于单一维度 |
| Spaghetti Graph（意大利面图）| 线条重叠密集，不可读——应用第9章策略解决 |
