### L### 4.2 技术演化谱系分析

#### L### 4.2.1 两大技术谱系
全书呈现一条清晰的技术演化逻辑链：

```
【手工复制谱系】
石印(蜡笔) → 石印(油墨) → 胶版印刷 → 橡胶印章/马铃薯刻印 →
麻胶版刻/木刻 → 水粉着色 → 复写纸 → 手抄本 → 玻璃印刷
                                      ↑
                          Tiflis"办公用品极简主义"
                          
【机械-摄影谱系】                                    
古腾堡活字(参照系) → 工业活字排印 → 照片蒙太奇 → 照相平版印刷
```

#### L### 4.2.2 技术的"回归"模式
- **KE-T01→KE-T09**：石印（1912）→ 玻璃印刷（1928-1933）——Kruchenykh晚年以"玻璃印刷"（steklopechat）回归手工复制，技术形式不同但逻辑同构——"a lithography-like process"
- **KE-T07→KE-T14**：复写纸（1917-1920）→ 手抄本（1928-1933）——Tiflis时期的办公用品挪用，在Stalin时期升格为"档案守护"的伦理实践

#### L### 4.2.3 技术的语义独立性与相互性
- **KE-T01（石印蜡笔）是全书语义密度最高的技术实体（0.90）**——它贯穿Ch01（Wye的"文本视觉化"论述）和Ch04（Janecek的"手稿恢复"论述），是连接书籍本体论与物质技术分析的核心桥梁。
- **KE-T11（照片蒙太奇）的语义密度为0.72**——高度集中在Ch05（Rowell的构成主义分析），几乎不出现在其他章节——反映其作为"1923-1924年转向"的技术锚点，仅在构成主义语境中被深入讨论。
- **KE-T15（古腾堡活字印刷）是全书唯一以"参照系"角色出现的技术实体**——它自身不是研究对象，但作为"被挑战的对象"定义了全书"反古腾堡"叙事的边界条件。

### L### 5.3 团体密度与功能的悖论
- **KE-G05（UNOVIS）语义密度最高（0.42）**——但其所有出版物的版次量仅在数百册，且全部在Vitebsk唯一一台石印机上完成。这一"话语密度/物质产出"的高度不对称，正是UNOVIS"乌托邦愿景vs.物质匮乏"张力的数值化表现。
- **KE-G07（VKhUTEMAS）的语义密度(0.32)低于其实际历史重要性**——因为Rowell明确指出了它的"讽刺性"："常被比作苏联包豪斯"，但其学生的项目"rarely achieved the ultimate phase of industrial production"。语义密度低于预期恰好反映了这种"名不副实"。
