# 00_方法与规则：Penny Sparke《Italian Design 1870 to the Present》（1988）

## 一、本方法文件的定位

本文档规定本书知识涌现分析（01–04）的分析规则与操作约定。其输入是分章分析报告中的六类实体（人物、著作/作品、概念、机构、地点、事件）与行号证据；输出是三层语义结构——知识元（知识元）→ Topic（强连通簇）→ Theme（高层语义域），以及相应的涌现计算与知识发现。全部分析基于 clean 版行号（L###），不引入任何外部统计工具。

## 二、层级定义

### 2.1 知识元（Knowledge Element）

知识元 = 六类实体中的可论证单元。命名采用全书原文名称（英文/意大利语），附中文注释。每个知识元须有至少一处行号证据。

本书知识元类别与示例：
- **人物（P）**：Ettore Sottsass（L2095）、Gio Ponti（L765）、Adriano Olivetti（L453）……
- **著作/作品（W）**："Vespa"（L800）、"Valentine" typewriter（L1644）……
- **概念（C）**：identified design（L62–64）、anti-design（L1528–1530）、flexible specialization（L1587）……
- **机构（I）**：Olivetti（L1328）、Memphis（L2095）、IRI（L547）……
- **地点（Lc）**：米兰（L76）、Brianza（L878）、Third Italy（L1898）……
- **事件（E）**：经济奇迹（L1170–1174）、1968 年抗议（L1556–1563）、Memphis 首展（1981，L2095）……

### 2.2 Topic（强连通簇）

Topic = 由强连通（同一主题区内相互链接）知识元构成的语义簇，规模 3–8 个知识元。识别依据：簇内链接密度显著高于簇间链接密度。全书识别 8 个 Topic（见 03_知识涌现计算.md）。

### 2.3 Theme（高层语义域）

Theme = 2–4 个 Topic 的聚合，由共享/桥接知识元联结，代表全书最高层论证域。全书识别 4 个 Theme。

## 三、9 种语义链接判定标准

链接类型与判据、示例（链接以"源—类型—目标"表示，附证据行号）：

| 类型 | 符号 | 判据 | 示例（本书） |
|---|---|---|---|
| 因果 | → | 事件/政策/行动导致另一实体产生或变化，存在因果动词或明确因果句 | 低工资政策 → 出口竞争力（L1199–1203）；石油危机 1973 → 塑料产业受挫（L1567–1570）；法西斯 → autarchy（L390–391） |
| 条件 | ⇒ | 一实体的存在/性质以另一实体为前提；"如果/只有……才……"句式 | 小型产业规模 ⇒ 设计师直接接触管理层（L95）；出口需求 ⇒ 设计成为市场渗透工具（L1191） |
| 对比 | ↔ | 在同一问题上对立/竞争的双方，作者以对照句式呈现 | Rationalism ↔ Novecento（L596–599）；主流设计 ↔ anti-design（L2235）；美国模式 ↔ 欧洲模式（L829–834） |
| 隶属 | ⊂ | 整体—部分、类—子类关系；"包括/其中/是……之一" | identified design ⊂ 意大利设计概念（L62–64）；submerged economy ⊂ 意大利经济（L1892）；architect-designer ⊂ 建筑师群体（L87–88） |
| 时序 | ≻ | 时间先后、发展次序；年份或"在此之前/之后" | Vespa（1946）≻ Lexicon 80（1948）≻ Cisitalia（1947）等"形式家族"（L800）；proto-design ≻ Ricostruzione ≻ Economic Miracle ≻ New Design（全书分期） |
| 空间共现 | ≈ | 在同一地点/空间中同时出现或共同构成场景 | 米兰 ≈ 三年展 ≈ Domus ≈ 设计师工作室（L76–88, L1130–1135）；Brianza ≈ 家具作坊（L878, L1962） |
| 属性 | : | 一实体具有某特征/属性；"以……著称/特点是……" | "The Italian line" : 有机曲线（L773, L1226）；techno-functionalism : 形式由技术功能决定（L1092）；Third Italy : 灵活专门化（L1898） |
| 论证支撑 | ⇐ | 一实体（理论/证据/引文/图版）支撑另一实体的论点成立 | Eco 三分法 ⇐ identified design 概念（L62–64）；Vespa 图版 ⇐ "意大利线"论证（L800）；MoMA 1972 展 ⇐ 反设计的历史地位（L1823–1828） |
| 同域 | ∼ | 属于同一功能/类型领域但无强因果或对比关系 | Olivetti ∼ Fiat（同为现代大企业，L382–383）；Kartell ∼ Artemide（同为塑料/灯具新公司，L1263–1270）；Domus ∼ Stile Industria（同为设计杂志，L1134–1136） |

**判定纪律**：每条链接必须有行号证据；若证据句仅提及两实体而无语义关系，不建立链接；对比链接需双方均被作者明确并置。

## 四、涌现指标

### 4.1 节点度 k
节点度 k = 与该知识元直接相连的链接数。用于识别核心枢纽（hub）。全书 k≥8 的知识元为核心枢纽（见 02_语义链接网络.md 排序表）。

### 4.2 桥接值 b
桥接值 b = 该知识元连接不同 Topic 的链接数。用于识别跨域中介（bridge），体现知识元在多主题间的枢纽作用。

### 4.3 簇识别（强连通）
以"链接密度大于阈值（簇内链接数 ≥ 节点数）且语义同域"为准则划分 Topic。簇内链接数 L、节点数 N，内聚度公式见 4.4。

### 4.4 内聚度（Cohesion）
内聚度 C = 2L / [N(N−1)]，其中 L 为簇内实际链接数，N 为簇内节点数，分母为完全图最大链接数。C∈[0,1]，C≥0.5 视为高内聚。

### 4.5 涌现强度 S
涌现强度 S = C × N（内聚度×规模），用于度量 Topic/Theme 作为涌现结构的强度。一级涌现取簇级 S，二级涌现取主题域聚合后的合成强度 S' = C' × N'（跨簇链接纳入计算）。

### 4.6 一级/二级涌现
- **一级涌现（E1…En）**：Topic 级——强连通簇形成的整体大于其成员之和，如"米兰设计产业网络"由公司+设计师+展览+杂志+奖项互链而涌现出"设计声誉生产系统"。
- **二级涌现（P1…Pn）**：Theme 级——跨 Topic 聚合产生的整体命题，如"意识形态辩论主旋律"横跨政治、美学、产业三个 Topic 而涌现为全书的解释性主张。

## 五、证据规范

1. 每条链接、每个指标计算均附 clean 版行号（L###）。
2. 实体命名统一使用全书原文（英文/意大利语），首次出现附中文。
3. 对无直接证据的关系标注"证据缺口"，不推测。
4. 客观性核对：在 02、03 报告中设置"反例与边界"小节，并列文本矛盾与例外（如"民主理想"与"消费主义"的背反，L735 vs L1740）。

## 七、本书网络构建约定（沿用 02/03/04）

- 节点集：从六类实体中选取参与论证的主要实体约 40–50 个。
- 链接规则：同一条证据句可派生多条链接；跨章重复出现的实体合并为单一节点（证据取多章行号）。
- 链接清单按主题区组织，每条附类型与证据行号。
- 计算过程为语义人工判定，非程序统计；S 值为相对强度排序依据而非绝对度量。
