# Part II 第14章：The Bauhaus: the Evolution of an Idea 1919-32

## 一至二、定位与结构

### L001 章节定位

包豪斯是现代建筑和设计教育史上最具影响力的机构。本章以包豪斯从魏玛（1919-1925）到德绍（1925-1932）再到柏林（1932-1933）的变迁为线索，展示其理念从表现主义/手工艺到"艺术与技术：新的统一"再到社会功能主义的激进演化。本章以格罗皮乌斯1919年《包豪斯宣言》的"未来大教堂"愿景为起点，以1933年纳粹关闭包豪斯为终点。

### L002 核心功能

1. **现代设计教育的范式建立**：Vorkurs（基础课程）+工作坊的双轨制成为全球设计教育的模板
2. **"艺术与技术"的辩证**：展示包豪斯如何在表现主义的手工艺理想与工业化的技术理性之间寻求平衡
3. **三位校长的对比**：格罗皮乌斯（理想主义）、迈耶（激进功能主义）、密斯（形式主义自律）代表了现代建筑的三种取向

### L003 叙述结构

```
魏玛时期（1919-1925）：
  伊顿的神秘主义→伊顿vs格罗皮乌斯→伊顿辞职（1923）
  凡·杜斯堡的De Stijl影响（1921-22）
  莫霍利-纳吉接替基础课程（1923）→"艺术与技术：新的统一"
  1923年展览→豪斯·阿姆·霍恩（实验住宅）

德绍时期（1925-1932）：
  德绍包豪斯校舍（格罗皮乌斯，1925-26）
  布劳耶的钢管家具（1926-）
  格罗皮乌斯辞职→迈耶任校长（1928）
  迈耶的社会功能主义→建筑系成立
  迈耶被迫辞职（1930）

柏林时期（1932-1933）：
  密斯任校长→去政治化→形式自律
  纳粹关闭包豪斯（1933年7月）
```

## 三至四、内容与逻辑

### L004 核心论题

**论题一：从"大教堂"到"居住机器"**

包豪斯1919年宣言——费宁格的木刻"未来大教堂"——以中世纪石匠行会（Bauhütte）为模型，呼唤所有艺术家和手工艺人联合起来建造"未来的水晶般的新信仰象征"。但在现实的经济和政治压力下，包豪斯从这种手工艺/表现主义理想逐步转向工业化设计。格罗皮乌斯1923年的文章《包豪斯的理论与组织》标志了这一转折——"手工艺的教学是为大规模生产的设计做准备"，这一表述导致伊顿立即辞职。

**论题二：Vorkurs（基础课程）——现代设计教育的发明**

伊顿创建的基础课程（后由莫霍利-纳吉和阿尔伯斯继续）是包豪斯对设计教育最持久的贡献。课程目的是：a）解放个体的创造力，b）使学生了解自己的能力倾向，c）教授基本的形式和材料原理。莫霍利-纳吉引入的构成主义训练——在木材、金属、线、玻璃中的平衡结构练习——将基础课程从伊顿的神秘主义导向技术的客观性。

**论题三：迈耶——社会功能主义的顶峰与危机**

汉内斯·迈耶1928-1930年的短暂任期是包豪斯最激进的时期。他的口号——"Volksbedarf statt Luxusbedarf"（人民的需求而非奢侈的需求）——标志着从形式美学向社会责任的转折。建筑系在他的领导下系统研究日照、通风、热损失和声学等科学问题。但他的左翼政治立场最终导致其被迫辞职，反映了现代建筑在1930年代面临的政治困境。

**论题四：密斯的"去政治化"与终结**

密斯接任后将包豪斯彻底去政治化——禁止一切政治活动，将课程集中于形式自律和工艺质量。这种"退缩到自律"的策略在政治上暂时保全了包豪斯，但无力抵抗纳粹的文化清洗。1933年，包豪斯在柏林的最后据点被盖世太保查封。

**全球影响**：纳粹关闭包豪斯反而加速了其理念的全球传播——格罗皮乌斯→哈佛，密斯→芝加哥，莫霍利-纳吉→芝加哥新包豪斯，阿尔伯斯→黑山学院
