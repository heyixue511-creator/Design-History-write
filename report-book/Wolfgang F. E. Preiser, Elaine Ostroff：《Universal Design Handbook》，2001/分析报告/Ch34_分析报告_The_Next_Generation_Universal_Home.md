# Ch34 分析报告：The Next-Generation Universal Home（下一代通用住宅）

## 章节定位与功能（L13096-13415）
- **作者**：Leslie C. Young, M.Arch.; Rex J. Pace, M.Arch.（Center for Universal Design, North Carolina State University）
- **功能**：开启 Part 5"居住环境"部分。以"下一代通用住宅"概念设计项目（Next-Generation Universal Home）为核心，展示通用住宅从"无障碍合规"向"生活方式整合"的愿景——全屋单层、无障碍厨房浴室、智能技术整合。是 Part 5 的总纲与示范章。

- 34.4 Design Strategies（约 L13302-13380）：设计策略
- 34.5 Conclusions（约 L13382-13415）

## 内容分析
- **设计目标**：可拜访性（visitability：无阶入口、可用卫生间、可进门）、全生命周期、可负担、整合技术（L13108-13180）。
- **项目**：Center for Universal Design 的概念住宅项目——把通用设计原则落到住宅平面、剖面与产品选择（L13182-13300）。
- **设计策略**：无阶入口、加宽门廊、底层生活空间、可调高厨房台面、电梯预留、智能化控制（L13302-13380）。
- **结论**：下一代通用住宅是"每个家庭的默认选项"而非特殊产品（L13382-13415）。
