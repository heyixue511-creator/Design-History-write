# 知识涌现分析 00：方法与规则

本目录对《世界当代艺术史》（王受之，2002，clean 版 L1–L296）进行知识涌现分析。所有实体、链接与簇的判定均基于逐行阅读原文，证据以行号 L### 标注。

## 一、层级定义

- **知识元（Knowledge Element）**：六类实体——人物、著作/作品、概念、机构、地点、事件（与《NN_专项报告与实体总索引》一致）。
- **Topic（主题簇）**：由强连通语义链接聚合的知识元簇，共 6–15 个。
- **Theme（高层语义域）**：由多个 Topic 聚合的高层域，共 3–5 个。

## 二、9 种语义链接判定标准

| 符号 | 名称 | 判据 | 例 |
|---|---|---|---|
| → | 因果 | 甲导致/促成乙，文本含因果表述 | 抽象表现主义垄断 → 波普反叛（L45） |
| ⇒ | 条件 | 甲是乙的前提/必要条件 | 极限艺术退潮 ⇒ 大地艺术产生（L269） |
| ↔ | 对比 | 甲乙对照，文本并列比较 | 美波普 ↔ 英波普（L48） |
| ⊂ | 隶属 | 甲属于乙/乙包含甲 | 观念艺术 ⊂ 当代艺术诸运动（L102） |
| ≻ | 时序 | 甲先于乙，时间先后 | 表现主义 ≻ 抽象表现主义 ≻ 新表现主义（L124） |
| ≈ | 空间共现 | 甲与乙同地/同空间 | 芝加哥、加州、得州 ≈ 纽约以外的美国（L192） |
| : | 属性 | 甲具有属性乙 | 波普 : 绝对客观中立（L48） |
| ⇐ | 论证支撑 | 甲作为证据支撑论点乙 | 大量作品图注 ⇐ 支撑"当代艺术多元"论点 |
| ∼ | 同域 | 甲与乙同属一个语义域 | 女权主义艺术 ∼ 同性恋艺术（身份政治）（L281、L293） |

## 三、涌现指标

1. **节点度 k**：知识元直接相连的链接数。
2. **桥接值 b**：知识元连接不同 Topic 的链接数。
3. **簇识别**：基于强连通（两两可达）或稠密子图。
4. **内聚度**：簇内链接数 / 可能链接数（稠密度）。
5. **涌现强度 S**：S = 簇内链接数 ×（参与知识元数）的归一化（本分析中采用"簇内链接数与跨簇桥接数加权"的定性-半定量复合评估）。
6. **一级/二级涌现**：一级涌现 = 簇（Topic）自身作为整体的属性；二级涌现 = 由多个 Topic 聚合形成的 Theme 及其命题。

## 四、证据规范

- 每条链接/每个簇均标注证据行号；
- 知识元不重复计数；
- 对原文矛盾或证据不足处标注"证据缺口"。
