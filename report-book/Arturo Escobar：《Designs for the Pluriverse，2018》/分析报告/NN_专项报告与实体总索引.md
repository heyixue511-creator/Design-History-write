### 1.2 概念间的派生与转化关系

```
理性主义传统 → 二元论（自然/文化、主体/客体、我们/他们）
    ↓（批判）
关系性（万物皆是其关系）
    ↓（政治化）
政治本体论 → 本体论占领 / OWW批判 → 关系性的政治激活
    ↓（设计化）
本体论设计 → design designs → defuturing → Sustainment
    ↓（实践化）
├─ 转型设计（CMU四维模型 / Manzini社会创新设计 / SLOC）
└─ 自主设计（autopoiesis → ontonomy/autonomy → comunalidad → disoñar）
    ↓（终极目标）
为多元宇宙而设计 / 地球母亲解放
```

## 专项报告四：关键人物思想谱系

### 4.1 马图拉纳与瓦雷拉的影响轨迹

Humberto Maturana和Francisco Varela的思想贯穿全书七章（前言/导论/第2-6章/结论），是全书中被引用次数最多、功能最多元的理论资源：

- **作为认识论批判工具**（第3章）："认知即行动"、"认知不是表象而是执行"——被用来反对理性主义传统的"认知作为表象"模式。
- **作为本体论基础**（第4章）：autopoiesis——被用来重新定义"设计"（设计是通过语言的自创生过程）。
- **作为政治原则**（第6章）：autopoiesis = 自主性的生物学定义——"找到进入下一刻的方式并通过适当行动从其自身的资源中行动"。
- **作为伦理基础**（导论/结论）："爱的生物学"——"我们只有与他人一起带出的世界，唯有爱帮助我们带出它。"

### 4.2 Tony Fry的影响轨迹

Fry是继Maturana & Varela之后第二个贯穿多章的理论人物：

- **作为本体论设计理论家**（第4章）：defuturing/futuring/Sustainment的三一框架——将Heideggerian现象学转化为设计批判。
- **作为文明转型思想家**（第5章）：Sustainment作为"启蒙之后"的文明视域——与Berry的"生态纪"形成呼应。
- **作为去殖民设计批评家**（第6章/结论）："世界的南方在很大程度上是欧洲中心的北方之本体论设计后果"——设计的去殖民化议程。
