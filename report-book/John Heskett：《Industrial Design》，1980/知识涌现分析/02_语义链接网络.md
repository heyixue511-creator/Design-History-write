## 六、矛盾对立网络（SL-COT）

本条追踪知识元之间的逻辑矛盾或张力——这些矛盾往往是Heskett有意保持的"辩证张力"的一部分。

### 6.1 核心矛盾对

**矛盾1：标准化的两种面孔**
```

    张力：同一概念既可通向创造性组合，也可通向去人性化的单调——Heskett保持"双重面孔"不闭合
```

**矛盾2：商业设计的创造力与操纵性**
```
SL-COT-002: KE-ARG-6-01（商业纪律是创造力的条件——Loewy的Coldspot成功）↔ KE-ARG-11-01（消费选择在扩张中趋同——GM的年度车型变更） [★★★]
    张力：同一商业逻辑既可以产生优秀设计，也可导致操纵性消费——Heskett拒绝将商业关系简化为非善即恶
```

**矛盾3：技术进步的曙昧性**
```
SL-COT-003: KE-ARG-结-01（Concorde——"最杰出的美丽形式之一"）↔ KE-ARG-结-01（Concorde——"环境问题不能被忽视"） [★★★]
    张力的浓缩：同一件设计产品同时体现技术卓越和伦理缺陷——全书"条件性价值"的最精炼示范
```

**矛盾4：先锋派的遗产**
```
SL-COT-004: KE-ARG-5-01（先锋派是"没有选民的议会"——脱离工业现实）↔ KE-ENT-5-03（Bauhaus·教育理想对后续设计的深远影响） [★★]
    张力：Heskett同时批评先锋派的"乌托邦脱离"又承认其教育遗产——双重评估不出裁决
```
