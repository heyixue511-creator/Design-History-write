# 02 语义链接网络

## 一、链接类型与记号

| 记号 | 类型 | 含义 |
|---|---|---|
| → | 支持/蕴含 | A 支持或蕴含 B |
| ⇄ | 双向/交互 | A 与 B 互相定义或互相约束 |
| ↑ | 例证/实现 | A 是 B 的例证或实现 |
| ↓ | 具体化/操作化 | A 是 B 的具体化或操作化 |
| ≠ | 反对/张力 | A 与 B 存在文本内部张力 |

## 二、域内链接（T1–T5 内部）

### T1 排印本质与伦理
- T1-4（尊崇内容）→ T1-1（定义）：定义是"为语言服务"，故尊崇内容是定义的自然推论（L76、L103）。
- T1-4 → T1-9（服务读者五项）：五项服务是"尊崇内容"的操作清单（L248–L249）。
- T1-4 → T1-10（伦理次序）：伦理次序把"内容第一"量化成层级（L3187–L3189）。
- T1-6（字母生命）→ T1-8（表演艺术）：字母"活着"才需要排印师如音乐家般诠释（L122、L151）。
- T1-7（风格超越论）⇄ T1-8：风格自由移动能力与"诠释性表演"互证（L148–L151）。

### T2 排印参数与规则
- T2-1（颜色）⇄ T2-2/3/8（em/词距/行距）：颜色=字体+字距+词距+行距四因素（L263–L264）。
- T2-6（大写加空）≠ T2-12（连字）：加空会拆散连字（L814–L815 软化处理）。
- T2-7（字距调整）↓ T2-2（em 度量）：字距表基于 em 单位系统（L406–L408）。
- T2-9（字号音阶）↑ T2-16（黄金分割字级）：黄金分割级数是一种音阶（L2494）。
- T2-19（标点=记法）→ T2-20（en dash 优先）：记法观给出破折号选型标准（L1313、L1394）。

### T3 字体历史与分类
- T3-1（分期轴）→ T3-3/4/11：分期轴统摄各具体史段（L91–L96）。
- T3-2（字母源于手）→ T3-4（阿尔定斜体）：斜体是"手的书写"的技术化（L2325、L2069）。
- T3-5（技术史）→ T3-6（重刻史）：机械排字催生历史重刻（L2301–L2302）。
- T3-8（多元文字史）≠ T3-1（拉丁分期）：拉丁史只是诸史之一（L2329–L2331）。

### T4 技术现实
- T4-2（Unicode）→ T4-4（字形/字符之别）：Unicode 编码字符，字形留待字体（L2936–L2943）。
- T4-3（格式谱系）→ T4-8（无完美字体）：格式之争让位于手艺（L2862–L2863）。
- T4-7（字体=乐器）→ T4-8：乐器需持续调音（L3151–L3195）。

### T5 字体谱系
- T5-7（命名辨伪）⇄ T5-1/4（衬线/希腊谱系）：辨伪是谱系的前提（L3811、L4652）。
- T5-8（数字版缺失诊断）→ T4-8：缺件即"未调好的乐器"（L716–L717、L4345）。

## 四、网络整体形态（供 03、04 详析）

- **中心元**：T1-4（尊崇内容）与 T2-1（颜色）为两大枢纽，分别统摄理念侧与参数侧。
- **桥接密度**：T3 类（历史）承担最多跨域链接（7/12），印证作者"排印有历史意义"的元命题（L42–L43）。
- **张力边**：T2-6≠T2-12、T3-8≠T3-1 两处为结构性张力，是 03 涌现命题的重要素材。
- **孤立倾向**：T5 类条目多为"星型"（中心为各字体名，向 T3-1/T5-8 汇聚），横向链接较少，体现工具书性质。
