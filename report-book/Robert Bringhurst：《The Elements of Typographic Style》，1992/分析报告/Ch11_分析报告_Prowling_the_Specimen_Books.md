# Ch11 分析报告：Prowling the Specimen Books（游猎样本册）

## 一、章节定位与功能（L3385–L4857）

全书最长的实用章，也是作者所称"游猎样本册"：以"字号样本 + 历史评传"的方式，逐条评述他认可的重要字体（衬线文本体、无衬线体、黑体、手写体、希腊体、西里尔体、大写体），并附命名、同名、血缘与"数字版缺失部件"的说明。功能：把前七章的字体史与风格学落到具体字体名录上，是全书的"可执行字典"。

## 二、结构分析

- **章前引言（L3349–L3383）**：选字标准（历史+实用+可读性）；数种"失传佳作"示例（Petrarca Italic、Froben Italic、Colines St Augustin Italic、Firmin Didot Italic）。
- **11.1 命名与同义词（L3385–L3423）**：字体命名原则；版权/商标与改名剽窃史（Palatino、Futura 等）。
- **11.2 衬线文本体（L3435–L2540 附近）**：Albertina、Alcuin、Aldus、Amethyst、Apollo、Arrus、Baskerville、Bell、Bembo、Diotima、Documenta、Electra、Esprit、Fairbank、Fairfield、Figural、Fleischmann、Fournier、Galliard、Garamond (1)/(2)、Palatino、Photina、Plantagenet、Poetica、Poliphilus & Blado、Pontifex、Quadraat、Requiem、Rialto、Romanée、Romulus、Sabon、Swift、Trajanus、Trinité、Van Dijck、Veljović、Walbaum 等。
- **11.3–11.5 无衬线/黑体/手写体（L2530–L2720 附近）**：Futura、Gill Sans、Haarlemmer Sans、Legacy Sans、Lucida Sans、Optima、Quadraat Sans、Romulus Sans、Scala Sans、Seria Sans、Syntax、Univers 等；textura/fraktur/bastarda/rotunda 分类；script 字体（Zapf Chancery 等）。
- **11.6 西里尔体（L2760–L2810 附近）**：Baskerville Cyrillic、Minion、Palatino、Quadraat、Warnock、Lazurski/Pushkin 等。
- **11.7 希腊体（L4591–L4700 附近）**：orthotic/cursive/chancery 三类；Albertina、Antigone、Bodoni、Didot、Diogenes、Gill Sans、Heraklit、New Hellenic、Palatino、Porson、Wilson 等。
- **11.8 附录过渡（L4700–L4857 附近）**：西里尔补充与希腊补充。
- **11.9 碑铭体与书法大写（L4781–L4857）**：Castellar、Charlemagne、Herculanum、Lithos、Mantinia、Michelangelo/Sistina、Monument、Neuland、Requiem Titling、Rialto Titling、Rusticana、Smaragd、Sophia、Trajan 等。

## 三、内容分析

1. **选字标准**：作者明言——"我喜欢的、愿意反复阅读的字体"（L3352–L3353）；兼顾历史与实用重要性，且每个字体都有局限（L3354）。
2. **命名伦理**：字体名是"商业命名与设计者意志的博弈"（L3395–L3423）；类型类别（roman/italic 等）不固定（L3426）。
3. **衬线文本体谱系**：以"历史分期 + 结构特征（轴线/口径/字重/连字/文本数字）"逐条评传。示例：
   - Baskerville=18 世纪新古典主义的代表（L3496–L3502）；
   - Bembo=Monotype 1929 年按 Griffo 1495 罗马体重刻（L3515–L3519）；
   - Garamond (1)/(2)=Garamenti 与 Jannon 的两支（L3795–L3820）；
   - Palatino=Zapf 1949–50 手工钢刻（L2311）；被剽窃史（L3399–L3401）。
4. **无衬线体**：几何无衬线（Futura、Gill Sans）vs 人文主义无衬线（Syntax、Optima、Scala Sans）；"斜体化商数"（italicization quotient）比较表（L4419）。
5. **黑体与手写体**：textura/fraktur/bastarda/rotunda 四类（L4437–L4453）；civilité 与 script 字体（L2700 附近）。
6. **希腊体**：orthotic（正立，类比罗马体）/cursive（草体，类比斜体）/chancery（文书体）三系（L4599–L4607）；新人文主义希腊（Antigone、Heraklit、Minion Greek）"在古典研究式微时出现"的悖论（L4624–L4625）。
7. **西里尔体**：9 世纪由希腊改编（L4719）；Borchtorp 1490 年首套西里尔字（L4719）；现代西里尔文本体（L2790 附近）。
8. **大写体**：碑铭体与书法体的"文前之门"（L4781–L4784）；Trajan、Lithos 等以古碑铭为本（L4814–L4857）。

## 四、逻辑梳理

按"正文常用（衬线→无衬线→黑体→手写）→非拉丁（西里尔→希腊）→装饰大写"的顺序组织，每条目采用固定模板：**样本行 → 出处（设计师/年份/铸字厂）→ 结构评述 → 数字版缺失部件 → 交叉引用**。11.1 的命名史为所有条目提供"名字-血缘"的辨伪框架。

## 五、材料使用方式

- 实物史料：Garamond 冲模（L3797）；Jannon 冲模在 Imprimerie Nationale（L3814）；Van Dijck 矩阵（L5890–L5891）；Warde 图纸在 Newberry 图书馆（L5903）。
- 传记史料：每位设计师的生卒年与工作地（附录 D 亦对应）。
- 数字技术考证：每个字体的数字版"缺文本数字/小型大写/连字"的如实记录（如 Lucida Sans L4345；Méridien L717）。

## 六、论辩与阐述方法

1. 谱系学方法：以"原始雕刻→重刻→数字版"为每一字体的传承链（L2297–L2320）。
2. 价值判断显性化：作者直言"美丑""优雅""笨拙"等主观判断（如 Rialto "prettier still" L4079；Quadraat "not pretty" L4062）。
3. 辨伪考证：Garamond 名下的 Jannon 字体（L3811–L3813）；"Bodoni Greek"实为他人之作（L4652–L4654）。
