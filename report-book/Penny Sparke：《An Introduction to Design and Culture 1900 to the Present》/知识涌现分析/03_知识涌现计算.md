## 三、内聚度与涌现强度 S 计算

**内聚度**：全网络平均内聚度 = (14+12+11+11+10+10+12+10+11+10)/10 = 111/10 = 1.11 基线；T1（1.56）、T4（1.38）、T2（1.33）为高内聚簇——消费、现代主义、材料三簇是全书论证密度最高的区域。

## 四、一级涌现结构（E1…En）

**E1 消费-身份涌现结构**：炫耀性消费 → 百货/广告制度 → 女性/中产主体 → 生活方式 → 身份多元 →（后现代）符号消费 →（当代）可持续消费。涌现命题：**消费制度、消费主体与身份概念三者互相生成，构成现代性的意义循环**（L141-236、L1061-1193、L199-201）。

**E2 现代主义霸权涌现结构**：功能主义理论 → 先锋运动（De Stijl/构成主义/包豪斯）→ 国际风格命名 → 制度霸权（学校/博物馆/出版）→ 内部教条化 → 危机。涌现命题：**现代主义的支配力来自"理论-运动-制度"三重合谋，而其危机源于同一结构的排他性**（L65-81、L721-804、L1592-1651）。

**E3 技术-设计联盟涌现结构**：批量生产 → 新材料 → 战后丰裕材料 → 企业研发（杜邦）→ 数字技术 → 个人化/交互设计。涌现命题：**技术从设计的"外部条件"演变为设计的"内部语法"（联盟），并最终成为生活方式本身**（L31-46、L1194-1394）。

**E4 身份-全球化涌现结构**：国家身份（博览会/民族风格）→ 公司身份（CI）→ 个人身份（生活方式）→ 全球身份（国家品牌/新兴经济体）。涌现命题：**身份的"设计化"从国家下放到个人、再从个人上收到全球品牌，身份始终是设计的核心产品**（L805-968、L1769-1946）。

**E5 设计伦理涌现结构**：消费批判（Packard/Papanek）→ 可持续性 → 社会创新/协同设计 → 设计重定义。涌现命题：**设计的合法性来源从"美学-功能"转向"伦理-社会"，设计从造物术变成治理术**（L118-121、L162-164、L1831-1946）。

## 五、二级涌现命题（P1…Pn，跨 Topic/跨 Theme 综合）

**P1（跨 T1/T4/T9）**：消费文化是现代主义的"隐形共谋"——现代主义以反消费立身，却依赖消费制度（百货、展览、杂志）传播；后现代主义则公开与消费结盟。生成机制：消费文化（T1）与现代主义（T4）共享"品味"知识元（Bourdieu 链接 L173-174、L2820），后现代（T9）把二者张力显性化。强度：高（S≈0.9）。证据：L57-138（Introduction 综述）、L107（好设计运动的中产趣味）、L172-178（后现代与消费合流）。

**P2（跨 T2/T7/T10）**：材料是现代性最忠实的物质编年史——从电木（现代）到尼龙（丰裕）到数字材料（后现代），每次"材料革命"都预告一次设计文化转型。生成机制：新材料在 T2（条件链接）与 T7（因果链接）中均为枢纽，且在 T10 以"可持续材料"重现。强度：高（S≈0.8）。证据：L39-46、L126-129、L139-140、L119-121。

**P3（跨 T4/T5/T8）**：制度（学校、博物馆、协会、公司）是设计话语的"印刷机"——设计史本质上是一部制度选择史（MoMA 选什么、包豪斯教什么、博览会展什么）。生成机制：MoMA（b=7）、包豪斯、Design Council 等高桥接机构在三个 Theme 间反复出现。强度：高（S≈0.85）。证据：L72-81、L142-149、L185-189、L76、L169。

**P4（跨 T1/T6/T10）**：身份的消费化经历了"阶级标示 → 个人表达 → 全球品牌"三级跳，而设计始终是身份的"排版系统"——国家、公司、个人都通过设计排版自己的身份。生成机制：身份知识元（k=13）桥接 T1/T5/T10。强度：中高（S≈0.75）。证据：L17-28、L104-111、L185-201。

**P5（跨 T3/T8/T10）**：设计师的"英雄叙事"被作者批判性祛魅，但祛魅本身又以更多设计师书写完成——设计史学科的结构性悖论：它一边宣称"去英雄化"，一边依赖英雄案例组织教学。生成机制：T3（职业化）与 T8（明星化）的时序链接 + Introduction 的方法论声明（L40-56）之间的张力。强度：中（S≈0.6）。证据：L40-56（去英雄化宣言）vs L57-64、L1395-1591（大量设计师书写）。

## 六、客观性核对与反例

1. **P1 反例**：现代主义内部确有"反消费"支流（乌尔姆的功能主义伦理 L169），且好设计运动（L107）本身试图"教育"消费而非"合谋"——故 P1 表述为"隐形共谋"而非"直接同盟"。
2. **P2 反例**：作者明确反对材料决定论（Ch7 节内对 Postman 的引用 L134、L2716-2718 表明其警惕），P2 是"物质编年史"（弱决定）而非"材料决定史"。
3. **P3 反例**：作者也承认个人能动性（设计师个人叙事贯穿 Ch8），制度选择论不排斥个人作用；且本书对制度"选择机制"内部运作（如何评审、谁掌权）着墨少，属于证据缺口。
4. **P4 反例**：非西方身份的消费化（非洲、拉美）缺乏案例，P4 的适用范围严格限于本书实际覆盖的欧美日体系。
5. **P5 反例**：Introduction 的"去英雄化"主要针对 1986 年前的旧史学（L40-56），作者对当代明星设计师（Starck）的批评是"选择性"的（L159-160 肯定其民主设计），并非一律否定。

**强度自评说明**：S 值为基于簇内链接数、桥接数与文本支撑密度的归一化估计（方法见 00 报告），用于排序而非绝对测量；P1-P5 均已附文本证据与反例。
