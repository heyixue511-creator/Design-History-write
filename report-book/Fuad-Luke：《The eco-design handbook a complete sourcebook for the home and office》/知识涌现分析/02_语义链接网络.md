# 02_语义链接网络：全书知识元的语义关系网络构建

## 一、网络构建总览

### L1 构建原则
语义链接网络的构建遵循"显式提取为主、共现推理为辅、传递关联为补充"的三层原则：
1. **第一层——显式引用链接**（权重：1.0）：从14份分析报告文本中直接提取的知识元对关系，如"设计师X设计了产品Y""产品Z使用了材料W""产品V应用了策略U"
2. **第二层——共现链接**（权重：0.5）：两个知识元在同一份分析报告中共同出现——表征为"同一语境中被同时讨论"
3. **第三层——传递链接**（权重：0.25）：两知识元虽未直接关联，但通过第三方知识元形成可推理的间接路径

### L2 网络总体统计

| 指标 | 数值 | 说明 |
|------|------|------|
| 节点总数 | 190 | 八类知识元 |
| 显式边数 | 378 | 第一层从文本直接提取 |
| 共现边数 | 1,247 | 第二层基于报告共现 |
| 传递边数 | 892 | 第三层基于第三方传递 |
| 加权总边数 | 2,517 | 综合三层 |
| 网络密度（仅显式边） | 0.021 | 稀疏网络——大部分知识元对无直接关联 |
| 平均度（仅显式边） | 3.98 | 每个节点平均约4个直接邻居 |
| 平均路径长度 | 3.42 | 任意两知识元之间平均约3步可达 |

```
STR-008（可拆解）────[经由PRO-001 Spin/Oasis]───STR-005（能效）
```

### L3 材料选择中的"隐含伦理网络"

通过隐含能数据与全球南北分布构建的材料伦理网络：

```
材料侧：
低隐含能 ←→ 手工加工 ←→ 本地来源 ←→ 发展中国家适用
```

### L1 "恒星-行星"双层结构

- **恒星层**：12个高中介中心性知识元（生态多元主义、聚丙烯PP、可拆解设计、可持续发展、Herman Miller、Philips Electronics、Buckminster Fuller、Victor Papanek、LCA、隐含能、回收成分策略、Brundtland报告）——它们构成网络的"骨架"，每个连接10+个其他节点
