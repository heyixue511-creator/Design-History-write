# 00_方法与规则

---

## L001 分析目标与定位

### L001-1 分析对象
本知识涌现分析以Judith Williamson《Decoding Advertisements: Ideology and Meaning in Advertising》（1978/2002）全书的系统分析报告为基础数据源。分析报告包含：整体分析报告（00）、导论至第八章的逐章分析报告（9份）、专项报告与实体总索引（NN），合计11份结构化文档。

### L001-2 分析目标
从已完成的文本分析中提取知识元（Knowledge Units），构建语义链接网络（Semantic Link Network），通过涌现计算（Emergence Computation）识别：跨章知识元的涌现模式、隐性理论结构的显性化、知识元之间非线性的语义关联、以及超越原书明言命题的衍生知识发现。

### L001-3 方法论定位
本分析不重复原书分析报告已完成的工作（文本解读、论点提取、案例分类），而是在其基础之上进行第二阶的知识操作：将分散在各章分析报告中的实体、概念、案例视为一个可计算的语义网络，通过结构分析发现该网络中的涌现属性——即"整体大于部分之和"的知识增量。

## L002 知识元定义与分类体系

### L002-1 知识元的定义
知识元（Knowledge Unit, KU）是语义网络中的最小不可再分节点。在本分析中，一个知识元是原书或其分析报告中出现的一个具有独立语义身份的实体，能够与其他实体建立可定义的关系链接。

### L002-2 知识元的六类别体系
依据NN专项报告的实体分类体系，知识元分为六个一级类别：

| 类别编码 | 类别名称 | 定义 | 全书数量 |
|---------|---------|------|---------|
| KU-P | 人物实体 | 理论家、思想家、公众人物、历史文化/虚构人物 | 约35个 |
| KU-C | 理论概念实体 | 理论术语、分析范畴、原创概念 | 约35个 |
| KU-B | 产品/品牌实体 | 广告中被分析的产品或品牌 | 约80个 |
| KU-A | 广告案例实体 | 具有A编号的具体广告分析单元 | 约116个（核心约60个） |
| KU-T | 文本/作品实体 | 被引用或参照的书籍、文章、艺术作品 | 约25个 |
| KU-O | 组织结构实体 | 全书结构、出版机构、分析框架 | 约20个 |

### L002-3 知识元的属性字段
每个知识元记录以下属性：
- **KU-ID**：唯一标识符（格式：{类别}-{序号}，如 KU-P-001）
- **名称**：中文名 / 英文名
- **类别**：六类别之一
- **来源章节**：主要出现的章节（导论, Ch1-Ch8）
- **频度**：在全书分析报告中出现的次数
- **跨章度**：跨越的章节数
- **功能角色**：在全书论证中的角色（理论基础 / 分析工具 / 论证案例 / 批判对象 / 组织框架）
- **上位概念**：所属的更抽象理论范畴
- **下位实例**：具体化的案例或子概念

## L003 语义链接类型体系

### L003-1 链接的定义
语义链接（Semantic Link, SL）是两个知识元之间有向或无向的、具有明确类型标识的关系连接。每条链接记录源节点、目标节点、链接类型和强度权重。

### L003-2 链接类型定义（11类）

| 链接类型编码 | 链接类型 | 方向 | 定义 | 示例 |
|-------------|---------|------|------|------|
| SL-REF | 理论引用（Reference） | 有向 | A引用B的理论/概念作为分析依据 | Williamson → Marx |
| SL-APP | 应用实例（Application） | 有向 | 概念A被应用于分析案例B | Referent System → A8 |
| SL-OPP | 对立/差异（Opposition） | 无向 | A与B构成差异对立关系 | Chanel No.5 ↔ Babe |
| SL-TRF | 转化/衍生（Transformation） | 有向 | A经过改造/转化后成为B | Saussure差异 → 产品差异 |
| SL-CON | 包含/层级（Containment） | 有向 | A包含B或B是A的子类 | Part I → Ch1 |
| SL-ANA | 类比/隐喻（Analogy） | 无向 | A与B具有结构性相似 | 梦工作 ↔ 广告工作 |
| SL-CAU | 因果/前提（Causality） | 有向 | A是B的前提或原因 | 差异系统 → 意义产生 |
| SL-COO | 共现/协同（Co-occurrence） | 无向 | A与B在同一分析语境中频繁共现 | Marx + Saussure + Lacan |
| SL-REC | 回收/收编（Recuperation） | 有向 | B被A回收为自身材料 | 广告批判 → 广告素材 |
| SL-EXT | 扩展/延伸（Extension） | 有向 | A的理论被B扩展或深化 | Ch1符号货币 → Ch8回收 |
| SL-REV | 反向/倒置（Reversal） | 有向 | A的逻辑在B中被反向应用 | 自然差异→文化差异 → 产品差异→人群差异 |

### L003-3 链接强度的权重赋值
| 强度等级 | 权重值 | 判定标准 |
|---------|--------|---------|
| 强（Strong） | 1.0 | 直接引用、明确定义的关系、全书反复出现的连接 |
| 中（Medium） | 0.7 | 推论性关联、跨章隐含呼应、类比性连接 |
| 弱（Weak） | 0.4 | 语境性共现、可能但非必然的关联 |

## L004 语义网络构建规则

### L004-1 网络层次划分
语义链接网络分为三个层次：

**L1：理论-概念层（KU-P + KU-C + KU-T）**
以理论家、理论概念和被引文本为节点，链接类型以 SL-REF（引用）、SL-TRF（转化）、SL-EXT（扩展）为主。这是网络的"骨架层"。

**L2：概念-案例层（KU-C + KU-A + KU-B）**
以理论概念和广告案例/产品为节点，链接类型以 SL-APP（应用）、SL-OPP（对立）、SL-ANA（类比）为主。这是网络的"肌肉层"。

**L3：案例-结构层（KU-A + KU-O + 跨章关联）**
以广告案例和组织结构为节点，链接类型以 SL-COO（共现）、SL-CON（包含）、SL-REC（回收）为主。这是网络的"皮肤层"——展示知识的实际流通路径。

### L004-2 知识元筛选规则
进入网络的知识元需满足以下条件之一：
1. **跨章实体**：出现于2个及以上章节
2. **核心实体**：在NN索引中被加粗标记
3. **高频实体**：在分析报告中被提及5次及以上
4. **结构性实体**：属于KU-O类别的组织框架实体

### L004-3 链接生成规则
1. **显性链接**：原书或分析报告中明确陈述的关系 → 直接录入，权重1.0
2. **结构性链接**：由章节结构、分类体系隐含的关系 → 推理录入，权重0.7
3. **涌现性链接**：通过网络分析发现的原书中未明言但具有结构合理性的关系 → 标注为[涌现]，权重0.4

## L005 知识涌现计算方法

### L005-1 涌现的定义
知识涌现（Knowledge Emergence）是指在语义网络中，通过节点间的结构性关系而产生的、超出任何单一节点或单一链接之明述内容的新知识命题。涌现不是"被写出的"，而是"被网络结构计算出的"。

### L005-2 涌现计算的四维度

**D1：中心性涌现（Centrality Emergence）**
计算每个知识元在网络中的度中心性（Degree Centrality）、中介中心性（Betweenness Centrality）和特征向量中心性（Eigenvector Centrality）。高中介中心性的节点是"桥接知识元"——它们连接了原本分离的理论域，其桥接功能本身就是一种隐性知识。

**D2：聚类涌现（Clustering Emergence）**
通过社区检测（Community Detection）识别网络中的知识聚类。聚类之间的"边界"和"重叠区"是涌现的高发地带——这些区域往往对应着理论融合的未明言操作。

**D3：路径涌现（Path Emergence）**
计算关键节点之间的最短路径和所有路径。如果两个表面上不相关的知识元之间通过多条间接路径强关联，则说明存在一个原书未明确定义的"隐性的中介概念"。

**D4：结构洞涌现（Structural Hole Emergence）**
识别网络中的结构洞（Structural Holes）——即本应存在链接但实际缺失的位置。结构洞本身可能是"知识盲区"的指示器，也可能指向理论中未解决的张力。

### L005-3 涌现命题的生成规则
满足以下任一条件即生成一个涌现命题：
1. 某个知识元的中介中心性 > 平均值2倍 → "桥接涌现命题"
2. 某个聚类内部链接密度 > 外部链接密度3倍 → "聚类涌现命题"
3. 两个知识元之间存在3条及以上无重复节点的间接路径 → "隐性关联涌现命题"
4. 某个结构洞被识别且该缺失链接具有理论合理性 → "知识盲区涌现命题"

### L005-4 涌现强度的计算
涌现强度（Emergence Strength, ES）由以下因子乘积决定：
```
ES = 路径数因子 × 中介中心性因子 × 跨章度因子 × 类别多样性因子
```
其中：
- 路径数因子 = ln(间接路径数 + 1)
- 中介中心性因子 = 节点的归一化中介中心性
- 跨章度因子 = 跨越章节数 / 全书章节总数
- 类别多样性因子 = 邻居节点的类别数 / 6

ES值越高，涌现命题的"新奇性"和"稳健性"越强。

## L006 分析流程与操作步骤

### L006-1 五阶段流程

```
Phase 1: 知识元提取与编码
    ↓ （从分析报告中提取所有实体，赋予KU-ID和属性）
Phase 2: 语义链接识别与建网
    ↓ （识别所有链接类型，构建三层语义网络）
Phase 3: 知识涌现计算
    ↓ （四维度计算：中心性、聚类、路径、结构洞）
Phase 4: 涌现命题生成与验证
    ↓ （生成涌现命题，回验原书文本）
Phase 5: 知识发现综合报告
    ↓ （整合所有涌现发现，撰写报告）
```

### L006-2 质量控制规则
1. **可回溯性**：每个涌现命题必须能够回溯到至少2个确证的知识元和至少1条显性链接
2. **非冗余性**：涌现命题不能是对原书已明述命题的简单改写——必须有"增量"
3. **可验证性**：涌现命题必须可以通过回查原书分析报告来检验其合理性
4. **等级标注**：每个涌现命题标注置信度（高/中/低），基于ES值和回验结果
