## 二、内容摘要

本书是一部设计哲学与设计政治学著作，核心命题为：**人类已进入一个由自身不可持续性（unsustainability）所导致的"去未来化"（defuturing）危机时刻；唯有通过根本性地重新理解并重定向（redirect）设计实践，使设计成为"重定向实践"（redirective practice），人类才有可能走向作者所命名的"持存时代"（the Sustainment）。**

托尼·弗莱在全书中有三个彼此交织的理论任务：

1. **诊断"去未来化"**：人类以人类中心主义（anthropocentrism）的方式栖居于地球，无节制地攫取资源、制造人工世界，其结果不是简单的环境破坏，而是系统性地"拿走未来"——每一次不可持续的设计行为都在缩减人类及其他物种的有限存在时间。

2. **重新定义设计**：设计不应当被理解为一种职业性的、服务于客户的工具性活动，而应被理解为一种**本体论意义上的世界塑造力量**（ontological designing）。一切被设计之物都在持续地"设计"着世界与人类自身，因此设计是一个攸关存在与未来的政治—伦理行动。

3. **提出"重定向实践"与"持存"方案**：弗莱拒绝"可持续设计""绿色设计"等温和改良话语，认为资本主义逻辑所容纳的"可持续发展"本身即是对不可持续性的维系。他提出以"持存能力"（sustain-ability）取代"sustainability"，以"持存"（the Sustainment）取代"可持续发展"（sustainable development），并建构了一套包含"消除设计"（elimination design）、"重编码"（recoding）、"再物质化"（rematerialization）、"时间中的设计"（designing-in-time）等方法的具体重定向工具箱。

全书不做乌托邦式的"解决方案"许诺，而强调：**持存不是一个终点，而是一个需要永续劳动的过程；设计不是拯救地球，而是拯救人类自身存在的时间。**

## 三、结构分析

全书结构为"前言—导论—三大部分（16章）—注释与索引"，三个部分呈现清晰的"问题—方法—前景"递进逻辑。

### 第一部分：Rethinking the Context and Practice of Design（第1–6章）

**主题：重新审视设计的语境与实践。**

- **第1章 "理解实践的本质"**：借助布尔迪厄"惯习"（habitus）概念，指出实践不是透明的工具性行为，而是构成实践者本体（ontology）的结构性力量。设计实践塑造了设计师的存在方式。
- **第2章 "理解设计的定向性本质"**：提出"本体论设计"（ontological design）概念——一切被设计之物都在持续地设计世界和人类。以汽车为例，绘制其"关系性"后果图，说明线性因果思维的局限性，引入中国"关联性"（correlative）思维作为替代性思维资源。
- **第3章 "命令与重定向"**：批判布伦特兰报告式的"可持续发展"话语，提出"sustain-ability"替代概念，引入"the Sustainment"作为新的历史时刻与过程，并讨论"重定向"与民主政治的张力。
- **第4章 "作为重定向实践的设计"**：正式建构"重定向实践"框架，以"Boonah Two"可持续城市竞赛方案为案例，展示"从未来向当下设计"（designing from the future to the present）的方法论。
- **第5章 "考察两种关键重定向实践"**：详述"消除设计"（designing nothing/elimination design）与"重编码"（recoding），涉及功能替代、去物质化、符号贬值等多种技术路径。
- **第6章 "未来化、重定向实践、发展与文化"**：批判西方"发展"话语的殖民暴力（genocide/ecocide/ethnocide），讨论文化差异与"设计他者"（design otherwise）如何贡献于持存。

### 第二部分：Strategic Design Thinking（第7–11章）

**主题：策略性设计思维与方法论。**

- **第7章 "拆解未来化——自我、社区、文化与伦理"**：将"未来化"置于自我关怀、社区重建与文化再物质化的框架中，讨论设计话语的诸主体（设计师、媒体、教育者）为何集体失语。
- **第8章 "变革方法I——平台化、回馈简报与新团队"**：介绍"平台化"（platforming）策略、"重定向回馈简报"（redirective return brief）和以持存为信念的团队建构方法。
- **第9章 "变革方法II——时间中的设计"**：将时间视为设计的媒介而非尺度，发展"未来化情景建构"（futuring scenario building）方法论，区分"设计情景"（design scenarios）与"设计之情景"（scenarios of design）。
- **第10章 "未来化与向过去学习新事物"**：以北宋《营造法式》和巴西木炭炼铁为案例，展示如何从历史与跨文化的技术传统中提取可应用于当代持存的设计原则。
- **第11章 "设计师作为重定向实践者——超越设计的新角色"**：提出重定向实践者的职业想象与自我再教育路径，强调"自我审查"与"错误教育"（education in error）的辨识。

### 第三部分：Design, Sustainment and Futures（第12–16章）

**主题：通往持存的经济、政治与文化前景。**

- **第12章 "以未来化对抗维系不可持续"**：系统批判五种现行替代路径（技术救赎论、可持续设计、产品转服务、可持续消费、人道主义设计），逐一揭示其与不可持续性的共谋。
- **第13章 "持存与人类新纪元"**：以"启蒙运动"为历史先例，论证"大观念"的历史效力；深化"持存的辩证法"（dialectic of sustainment）：创造与毁灭永恒共生，重定向的关键在于判断"需创造什么"与"需消灭什么"。
- **第14章 "描绘经济与文化的未来"**：提出"从量到质"的经济范式转换——建构以"质量经济"（quality economy）为核心的替代性交换体系，引入巴塔耶"普遍经济"（general economy）概念。
- **第15章 "持存即设计——从脚下开始"**：以瑞典劳工运动口号"Dig where you stand"为方法论起点，提供个人层面的自我审查工具（足迹矩阵、技能矩阵、重定向矩阵）与具体行动情景示例，辅以巴西拾荒者合作社（Coopamare）的案例。
- **第16章 "持存与未来化的挑战——变革力量之检阅"**：以两张系统评估表检阅既有变革力量（政府、国际公约、碳交易、环境运动等）的效能，指出大多数陷入制度惯性，重申"重定向实践"的潜力与"不可能之历史"的乐观主义。

## 四、核心论点与概念

### 4.1 核心论点

1. **不可持续性即"去未来化"（Defuturing）**：不可持续性的本质不是环境"问题"，而是一种"拿走未来"的能动性——每一次不可持续的设计行为都在缩减人类作为物种的有限时间。
2. **设计是一种本体论力量（Ontological Designing）**：设计不仅仅创造物品，而是创造"持续设计着的世界"。被设计之物反过来设计人类的能力、习惯、感知与欲望——人类既在设计世界，也在被世界所设计。
3. **"可持续设计"话语本身就是问题的一部分**：布伦特兰式"可持续发展"将生态系于经济增长，实际上在维系不可持续性。绿色技术、碳交易、可持续消费等"改良方案"回避了根本性的范式转换。
4. **重定向（Redirection）是唯一的出路**：设计必须从根本上被重制为"重定向实践"——一种跨学科的、以"持存"为绝对命令的元实践（meta-discipline），它既不等于革命，也不等于改良，而是比改良更激进、比革命更少破坏。
5. **持存是一个无终点的过程**：The Sustainment 不是一个可到达的终点，而是一个需要永续劳动的"时刻与过程"——它要求持续的辨识（何为不可持续）、持续的创造（何为持存）、持续的毁灭（需要消除什么）。

### 4.2 核心概念术语表

| 原文术语 | 中文翻译 | 含义解释 |
|----------|----------|----------|
| Defuturing | 去未来化 | 不可持续性的本质：以当下的行为系统地消减未来存在的可能性与时间 |
| Sustain-ability | 持存能力 | 区别于"sustainability"，强调一种"确保并维持时间中存在的品质条件"的过程性能力 |
| The Sustainment | 持存时代/持存 | 一个尚未到来但必须被创造的历史时刻与持续过程，以持存能力为主导原则的人类栖居新纪元 |
| Ontological Designing | 本体论设计 | "一切被设计之物持续地设计着"——设计物具有独立于创造者意图的、持续的、塑造世界与人类的能力 |
| Redirective Practice | 重定向实践 | 一种跨学科的元实践，将所有实践导向持存的目标，以"辨识—消除—创造"为基本操作 |

## 五、方法论与材料

### 5.1 方法论特征

1. **关系性分析（Relational Analysis）**：弗莱的核心方法论工具。不同于西方理性主义的"线性因果"思维，关系性分析要求将任何设计对象置于多重生态（生物物理生态、人工物生态、心灵生态、图像生态）的交互网络中考察其后果。第2章"汽车案例"即完整演示了这一方法。
2. **未来化情景建构（Futuring Scenario Building）**：以"从未来向当下设计"为原则，基于审慎研究构建可信的虚构叙事，从中推导设计任务。这既非预测也非幻想，而是"可能的审慎前鉴"。
3. **自我审查/自我审计（Self-auditing）**：第15章提供了一套个人层面的量化与质性相结合的自我评估工具（足迹矩阵、技能矩阵、重定向矩阵），将"重定向"从理论下降到个体实践。
4. **案例分析方法**：全书穿插大量案例（Boonah Two、Lucas Plan、《营造法式》、巴西木炭炼铁、Coopamare等），以具体情境中的"重定向知识"佐证理论。
5. **历史—考古学方法**：弗莱频繁返回历史文本与技术传统（如对启蒙运动的重新解读、对19世纪技术乌托邦的追溯），在"向过去学习新事物"的框架下提取可被转置的持存原则。

### 5.2 核心材料来源

- **哲学**：亚里士多德（praxis/poiesis之分、伦理学）、海德格尔（"物的物化"）、布尔迪厄（habitus）、巴塔耶（普遍经济）、德里达、阿多诺与霍克海默（启蒙辩证法）、阿伦特（行动与制作）、南希（共同体）、梅洛-庞蒂（世界之肉）

## 六、学术谱系

### 6.1 作者定位

Tony Fry（托尼·弗莱）是澳大利亚设计理论家与设计哲学家，曾任教于昆士兰科技大学、格里菲斯大学等多所院校，创办了在线期刊《设计哲学论文》（*Design Philosophy Papers*）和《设计哲学政治》（*Design Philosophy Politics*），并担任Team D/E/S持存咨询公司的联合主任。弗莱是当代设计哲学中"本体论设计"和"重定向实践"话语的主要创建者。他的学术身份横跨设计理论、大陆哲学、环境政治与文化批评，其思想深受海德格尔哲学、法兰克福学派批判理论以及后结构主义的影响。

### 6.2 主要学术对话对象与思想渊源

| 思想来源 | 对话关系 |
|----------|----------|
| **亚里士多德** | 弗莱在praxis（行动）与poiesis（制作）之分的框架中安置其"重定向实践"概念；亚里士多德的"实践哲学"传统为其"伦理的物质化"（ethics materialized）提供了哲学根据 |
| **马丁·海德格尔** | 本体论设计概念深受海德格尔关于"物"（thing）与"栖居"（dwelling）之思的影响；弗莱将海氏的"在世存在"转译为"设计—在世—存在"的框架 |
| **皮埃尔·布尔迪厄** | "惯习"（habitus）概念被弗莱广泛征用以解释"我们如何被世界所预先设计"——habitus被理解为一种"结构之结构的结构化" |
| **汉娜·阿伦特** | 弗莱引用阿伦特对"制作替代行动"的批判，指出当代设计沦为工具性制作而丧失了"开启、引领、完成"的行动品格 |
| **法兰克福学派** | 阿多诺与霍克海默的《启蒙辩证法》为弗莱反思"技术理性"与"启蒙"提供了批判框架 |
| **乔治·巴塔耶** | "普遍经济"（general economy）与"限制性经济"（restricted economy）的区分被弗莱用以建构其"质量经济"替代方案 |
| **让-吕克·南希** | 南希关于共同体之"消解"（dissolution）的论述被弗莱用以论证当代社区重建的必要性 |
| **布鲁诺·拉图尔** | 弗莱借用拉图尔关于"物的议会"与"宪法"的思想来论证"伦理的物质化"与"物的政治能动性" |
| **维克多·帕帕内克** | 弗莱承继帕帕内克"为社会需求而设计"的伦理立场，但批评其仍然陷入技术理性主义和发展主义框架 |
| **埃齐奥·曼齐尼** | 《可持续的日常》被弗莱视为"温和改良主义"的代表，在方法论上予以批判性对照 |
| **李诫/梁思成** | 弗莱将《营造法式》的结构模数化原理（"材份制"）解读为超越当代"可拆解设计"的中国古代设计智慧 |

### 6.3 学术贡献与独创性

1. **"去未来化"（defuturing）概念的创造**：弗莱将不可持续性问题从"资源消耗""环境污染"的物质层面提升到"时间形上学"的哲学层面，赋予设计以存在论意义上的紧迫性。
2. **"本体论设计"（ontological design）的系统化**：弗莱将海德格尔哲学与设计理论进行了当代语境下的深度缝合，使"设计物持续设计着"成为设计伦理学的一个基础命题。
3. **"重定向实践"（redirective practice）的建构**：弗莱不仅提供批判，而且提供了一套可操作的方法论工具箱（消除设计/重编码/再物质化/时间中的设计/平台化等），这在设计哲学著作中较为少见。
4. **对"可持续发展"话语的激进批判**：弗莱直言不讳地拒绝布伦特兰框架，并将其定性为"维系不可持续性的意识形态"，这种彻底性是同时代设计理论中罕见的。

## 八、语言风格

### 8.1 总体特征

弗莱的写作风格呈现为**高度理论化的论辩性哲学散文**。其语言特征可以概括为：

1. **术语创造密集**：全书大量使用作者自创或重新定义的概念（defuturing, sustain-ability, the Sustainment, ontological designing, redirective practice, elimination design, recoding等），这些术语构成了一套闭合的概念体系，要求读者在阅读过程中持续进行"术语习得"。
2. **句法复杂、层层嵌套**：弗莱偏好使用复合从句、插入语、条件限定与否定式递进（"not X but rather Y"），以精确限定命题边界。这种风格在增强理论精准度的同时，对非英语母语读者构成较高的阅读门槛。
3. **语气从激进自信到审慎限定**：在诊断性/批判性段落中，弗莱的语气斩钉截铁（"there is no moderate or balanced position"）；但在建议性/前瞻性段落中，他频繁使用"may""could""potential""tentative"等限定词，以维持其"非乌托邦"的立场。
4. **排印策略**：全书采用三种字体区分文本层次——衬线体为正论、斜体为方法论建议、无衬线体为案例研究，这是弗莱有意为之的"信息设计"策略。

### 8.2 典型修辞模式

- **"It is not X but rather Y"（否定—重新定义）**：弗莱的基本修辞动作是在否定现有理解的充分性后，给出更"根本"的定义。例如："Design practice is not simply the application of a methodology and it is certainly not the same as the design process. Rather, design practice is what brings designers into being as such and thereafter sustains them."
- **"As has been argued / As indicated / As we shall see"（前瞻—回溯）**：全书大量使用此类跨章节的互文标记，以维持长程论证的连贯性。
- **"The question is not X but Y"（问题重设）**：弗莱频繁地拒绝既有问题的设定方式，重新框架化（reframe）问题。
- **警句式收束**：许多段落以高度凝练的格言式语句收尾，具有修辞上的一锤定音效果，例如："The future is now something that we have to make together.""Being unsustainable has to hurt."

## 九、一句话概括

本书以"去未来化"（defuturing）为核心诊断概念，以"本体论设计"（ontological designing）为哲学基础，以"重定向实践"（redirective practice）为行动方案，将设计从一种服务于资本主义市场经济的技术服务行业，激进地重新定义为关乎人类物种存在延续的、根本性的政治—伦理—本体论实践——它不是要拯救地球，而是要在不可持续性的自我毁灭逻辑中，以设计之力为人类"制造时间"。
