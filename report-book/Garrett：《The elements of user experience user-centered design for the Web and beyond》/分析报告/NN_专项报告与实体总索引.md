## L2 专项报告一：Garrett的五层面模型——来源、演变与影响

### L3 一、模型的学术谱系

Jesse James Garrett的"用户体验五层面模型"并非凭空创造，而是以下知识传统的交汇产物：

| L4 知识来源 | L4 具体贡献 | L4 在模型中的体现 |
|------------|------------|------------------|
| 软件工程的分层架构（Layered Architecture） | 将复杂系统分解为层级化的抽象层 | "每个平面依赖于其下方的平面"的依赖关系原则 |
| 图书馆学的分类法与分面理论（Faceted Classification — S.R. Ranganathan） | 信息的多维度分类 | 信息架构中的"分面"（facets）与"组织原则"（organizing principles） |
| 认知心理学的信息加工模型 | 人类如何处理与理解信息 | "概念模型"（conceptual model）与"心智地图"（mental map）的讨论 |
| 人机交互的可用性工程（Usability Engineering — J. Nielsen） | 以用户测试验证设计决策 | 用户研究方法菜单与测试的定位 |
| 建筑学的"形式追随功能" + 反拨 | 建筑隐喻的合法性与局限性 | "自下而上建构"与"地基与屋顶"的隐喻体系 |
| Donald Norman的"以用户为中心的设计"哲学 | 设计应围绕用户而非技术 | "User-Centered Design"的全书核心立场 |

### L3 二、模型的创新点

尽管借鉴了多个传统，Garrett的模型具有若干独特的原创贡献：

1. **五层的命名与序列化**：将Strategy/Scope/Structure/Skeleton/Surface五个"层次"以全"S"头韵命名并序列化为从抽象到具体的单一梯度，这在UX文献中是独一无二的。

2. **功能/信息双轨的全程切割**：不同于多数UX文献将"功能设计"与"内容设计"视为两个独立领域，Garrett将这一区分贯穿五个平面，创造了一个可同时容纳两种视角的统一框架。

3. **"涟漪效应"作为动态机制**：将层级间的依赖关系从静态的"下层决定上层"丰富为双向的"涟漪效应"，赋予了模型以迭代灵活性。

4. **术语映射功能**：将UX领域内混乱的术语群（交互设计、信息设计、信息架构、界面设计、导航设计、视觉设计）系统地映射到模型中确定的位置，解决了长期困扰从业者的概念混乱。

### L3 三、模型的演变（第一版2002→第二版2011）

| L4 维度 | L4 第一版（2002） | L4 第二版（2011） |
|---------|------------------|------------------|
| 适用范围 | 明确限定于Web | "Web and beyond"——所有产品与服务 |
| 学科视野 | Web UX | 扩及移动、物理产品、服务设计 |
| 案例 | 几乎全部为Web案例 | Web案例仍占主导,但增加了非Web的参照 |
| 核心框架 | 五平面+功能/信息双轨 | 不变（"honing and refinement, not radical reinvention"） |
| 视觉呈现 | 黑白印刷 | 全彩印刷——模型图以五色分层呈现 |

### L3 四、模型的影响与衍生

1. **教育领域**：全球大量UX课程和训练营将此模型作为入门框架。
2. **行业实践**：成为跨职能团队的"通用语言"——策略师、设计师、开发者可以在同一张图上定位自己的关注点。
3. **方法论衍生**：敏捷UX（Lean UX）在反对"重文档"的同时继承了分层思考的结构；Design Thinking的"问题定义先于方案探索"原则与Garrett的"战略先于执行"高度吻合。
4. **批评与修正**：批评者指出模型过于线性/瀑布式（尽管Garrett本人做了"finish before next can finish"的防御）；"涟漪效应"在实际项目中很难被如此清晰地追溯；"功能/信息"二分法在混合型产品中日益模糊。

## L2 专项报告二：Garrett的知识生产策略——一个修辞学分析

### L3 一、问题："要素模型"为什么成了？

Garrett的要素模型不是第一份试图整理UX领域概念混乱的尝试，但它可能是最成功的一份。理解"为什么是这一份成了"需要考察其知识生产策略。

### L3 二、"放弃→灵感"叙事的战略功能

Garrett在第一版导言中讲述的"放弃→机场灵感"故事不是随意的轶事——它执行了多重修辞功能：

1. **去意志化**：灵感不是"硬想出来的"而是"自己浮现的"——这降低了模型的"人为建构感"，赋予其"自然发现"的合法性。
2. **可接近性**：如果一个想法是在机场候机厅"突然出现"的，那么它必然是简单的、直觉的——不可能是复杂到需要博士学位才能理解的东西。
3. **超然性**：放弃意味着"放下了自己的预设"，灵感在这种放空中浮现意味着它"超越了个人偏见"。

### L3 三、命名策略分析

| L4 命名 | L4 策略功能 |
|---------|-----------|
| "The Elements of User Experience" | "Elements"（要素）从同义词词典中选出，旨在替代更技术化的"Components"（组件）。"Elements"唤起了"元素周期表"和"Strunk & White的《The Elements of Style》"的联想，赋予模型以"基础性/经典性"的暗示。 |
| 五个平面的"S"头韵 | Strategy-Scope-Structure-Skeleton-Surface —— 五个以S开头的词构成了一种音韵上的"粘合力"，增强了可记忆性。 |
| "涟漪效应"（Ripple Effect） | 比"跨层依赖"或"决策传播"更具意象感——激活了读者对水面涟漪的视觉经验。 |
| "马拉松vs.短跑" | 体育隐喻——通俗、有力、好记。将抽象的项目管理节奏问题具象化。 |

### L3 四、图示优先于文本的知识生产方式

Garrett的知识生产过程中，**视觉图示的建构先于文本的写作**。要素模型最初就是一张图（"a finished diagram that would fit neatly onto a letter-size piece of paper"），书籍是围绕这张图的扩展说明。这暗示了一个有趣的知识生产逻辑：在UX领域，空间-视觉模型可能比线性-文本模型更能有效地组织和传达复杂概念。

### L3 五、"反权威"的权威建构

Garrett通过以下策略建立了一个独特的"反权威的权威"：
- 承认运气的角色（"as much by luck as by intent"）
- 承认失败的尝试（"by the end of January I had given up"）
- 承认命名的偶然性（"chose elements out of a thesaurus"）
- 承认模型的边界（"the lines between these areas are not so clearly drawn"）
- 引用他人的批评（"visual designers complain that wireframes..."）

这种"自我降格"的策略在UX这一"反权威"的实践社群中产生了独特的效果——它使作者不像一个"自上而下颁布真理"的权威，而像一个"分享工具箱的同行"。

## L2 专项报告三：全书隐喻体系全景分析

Garrett在全书中使用了大量的隐喻和类比来降低抽象概念的认知负荷。以下是对全书隐喻体系的全面梳理。

### L3 一、建筑/构造隐喻群

这是全书使用频率最高、最系统的隐喻群。

| L4 隐喻 | L4 源域（Source Domain） | L4 目标域（Target Domain） | L4 出现章节 |
|---------|--------------------------|---------------------------|------------|
| "地基与屋顶"（Foundation and Roof） | 建筑施工 | 战略层（地基）与表现层（屋顶）的先后依赖关系 | 第二章 |
| "骨架"（Skeleton） | 人体/建筑的骨骼框架 | 页面的界面/导航/信息布局 | 第二/六章 |
| "结构"（Structure） | 建筑的承重结构 | 交互序列与信息节点的组织 | 第二/五章 |
| "蓝图"（Blueprint） | 建筑设计图 | 线框图作为页面"蓝图" | 第六章 |
| "建筑的立面"（Facade） | 建筑外观 | 表现层是"用户看到的立面" | 第七/八章 |

### L3 二、运动/身体隐喻群

| L4 隐喻 | L4 源域 | L4 目标域 | L4 出现章节 |
|---------|---------|----------|------------|
| "舞蹈"（Dance） | 双人舞 | 用户与系统的互动——相互适应 | 第五章 |

| "涟漪效应"（Ripple Effect） | 水波传播 | 决策在五平面间的传播 | 第二/八章 |

### L3 三、自然/灾害隐喻群

| L4 隐喻 | L4 源域 | L4 目标域 | L4 出现章节 |
|---------|---------|----------|------------|

### L3 四、容器/空间隐喻群

| L4 隐喻 | L4 源域 | L4 目标域 | L4 出现章节 |
|---------|---------|----------|------------|
| "购物车"（Shopping Cart） | 超市购物车（容器） | 电商的选购组件 | 第五章 |
| "寻路"（Wayfinding） | 物理空间的导航 | 信息空间中的定位 | 第六章 |
| "镜片"（Lens） | 光学镜片 | 导航设计是"用户看穿信息架构的镜片" | 第六章 |

### L3 五、隐喻体系的功能总结

1. **认知降载**：每个隐喻都将一个抽象的UX概念锚定在读者的日常经验中（所有人都见过地基、跳过舞、扔过雪球、玩过传话游戏）。

2. **意象统一**：尽管隐喻来源多样，但全书的主导隐喻（建筑）与五平面的"层"概念形成了意象一致性——"用户体验像盖房子，从地基到屋顶一层层来"。

3. **情感负载**：负面隐喻（雪球、脱轨、传话游戏、无特征大块）承载了"不这样做就会出问题"的紧迫感；正面隐喻（舞蹈、马拉松、蓝图）承载了"这样做就能成功"的希望感。

## L2 专项报告四：本书的版本时间线与知识考古

### L3 时间线

| L4 时间 | L4 事件 | L4 意义 |
|---------|---------|--------|
| 1999年末 | Garrett成为某Web设计咨询公司的首位信息架构师 | 概念混乱的个人遭遇开始 |
| 1999年末-2000年1月 | 尝试建立自洽的术语定义体系→失败→放弃 | "理性建构"的失败 |
| 2000年3月（SXSW后） | 在奥斯汀机场灵感突现；飞机上画出草图 | "直觉浮现"的成功 |
| 2000年3月（感冒中） | 在家中完成终稿——第一张"要素模型图" | 模型的正式诞生 |
| 2000年3月30日 | 在www.jjg.net/ia/elements.pdf首次公开发布 | 公共知识的起点 |
| 2000-2001年 | 下载超20,000次；被全球组织采纳 | 模型的病毒式传播与合法性确立 |
| 2001年3月（又一个SXSW） | 见到Michael Nolan，签下出版合同 | 从"一张图"到"一本书"的决定性时刻 |
| 2002年 | 第一版出版 | 模型的文本化与系统化 |
| 2010年11月 | 第二版导言撰写 | "范式扩展"的宣告 |
| 2011年 | 第二版出版（全彩） | 模型的视觉升级与适用范围扩展 |

### L3 知识考古学观察

1. **从"个人工具"到"公共知识"**：要素模型最初是Garrett用来"教育同事"和"定义自身角色"的个人工具——它是在组织内部的政治性需求中诞生的。它之所以能成为公共知识，恰恰是因为"组织内部政治性需求"（跨职能沟通障碍）具有普遍性。

2. **从"图"到"书"**：知识形式的变化（从一张图到一本书）影响了知识内容的变化——一张图只能呈现结构关系，一本书可以展开案例、方法、论辩和限定。但"图"始终是核心——书是图的扩展注释。

3. **从"Web"到"All Products"**：适用范围的变化不是Garrett主动选择的，而是被用户（实践者）的"意外采纳"所推动的——这是一个"产品被用户重新定义"的有趣案例。
