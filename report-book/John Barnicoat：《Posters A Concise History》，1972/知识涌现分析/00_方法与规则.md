## 二、核心方法论

### 2.1 知识元（Knowledge Unit）定义

知识元是从分析报告中提取的**不可再分的语义单元**，每一个知识元代表一个独立的知识节点。

**知识元属性表**：

| 属性 | 说明 | 数据类型 | 示例 |
|------|------|---------|------|
| 标识符 | 唯一编号，格式：K+三位数字 | string | K001 |
| 类型 | 实体/概念/关系/论题/方法/事件 | enum | 概念—理论概念 |
| 名称 | 自然语言标签 | string | 招贴画与绘画的双向影响论 |
| 来源参考 | 源分析报告中的编号位置 | string | L001, L003-1 |
| 跨章分布 | 该知识元在哪些章节出现 | string[] | [Ch1, Ch3, Ch4] |
| 关联列表 | 与之链接的其他知识元ID | string[] | [K002, K015, K078] |
| 权重 | 基于出现频率、跨章分布、链接密度的综合评分 | 1-10 | 9 |

### 2.2 知识元分类体系

```markdown
知识元体系
│
├── 实体类（Entity）→ 可命名、可指涉的具体存在
│   ├── E-PER（人物）：艺术家、设计师、批评家、作家、政治人物
│   ├── E-INS（机构）：团体、组织、公司、学校、博物馆
│   ├── E-PUB（出版物）：期刊、书籍、展览图录、宣言
│   ├── E-ART（作品）：招贴画、绘画、设计作品、三维展示物
│   └── E-PLA（地点）：国家、城市、展览场域
│
├── 概念类（Concept）→ 抽象的思想单元
│   ├── C-STY（风格/运动）：Art Nouveau, Cubism, Pop Art...
│   ├── C-TEC（技术术语）：石印术、摄影蒙太奇、丝网印刷...
│   ├── C-THE（理论概念）：大众语汇、发布机器、看而不读...
│   └── C-DIC（二分法/框架）：形式vs.装饰、信息vs.喊叫...
│
├── 关系类（Relation）→ 知识元之间的链接本身也是知识
│   ├── R-INFL（影响关系）：A在风格/技术/观念上影响B
│   ├── R-INHR（继承关系）：A继承B的传统/范式
│   ├── R-OPPO（对抗关系）：A与B对立/竞争
│   ├── R-TRAN（翻译关系）：A将B的范式翻译为招贴画语言
│   ├── R-FUSE（融合关系）：A融合了B和C两种来源
│   ├── R-PREC（先导关系）：A是B的前驱/先驱
│   ├── R-PARA（平行关系）：A与B在时空上平行发展
│   ├── R-REPL（回应关系）：A是对B的回应/反叛
│   └── R-CYCL（轮回关系）：A与B构成跨时代的结构性相似
│
├── 论题类（Thesis）→ 有论证结构的命题
│   ├── T-CORE（核心论题）：全书层面的支配性论题
│   ├── T-CHAP（章节论题）：单章层面的论题
│   ├── T-IMPL（隐含论题）：作者未明说但可从论证中推断的论题
│   └── T-EMER（涌现论题）：仅通过网络分析才被发现的论题
│
├── 方法类（Method）→ 学术操作与修辞策略
│   ├── M-ANAL（分析方法）：对比法、谱系追溯法、反事实假设法...
│   ├── M-NARR（叙事策略）：地理迁移叙事、对抗叙事、环形结构...
│   └── M-SOUR（材料使用）：一手文献引证、展览图录引用...
│
└── 事件类（Event）→ 时间轴上的节点
    ├── EV-HIST（历史事件）：战争、革命、政治运动
    ├── EV-EXHB（展览/出版）：展览、书籍出版、宣言发表
    └── EV-TURN（转折点）：风格转折、范式转换、制度变革
```

### 2.3 类型识别规则

知识元类型通过以下规则从分析报告中识别：

| 触发特征 | 分配类型 |
|---------|---------|
| 英文大写首字母人名，伴随生卒年和国籍描述 | E-PER |
| 组织/团体/公司名，通常有成立年份和地点 | E-INS |
| 出版物名（斜体/加粗），伴随出版年份和出版地 | E-PUB |
| 作品名（斜体/加粗），有作者归属和创作年份 | E-ART |
| 以 "-ism" 或特定风格标签结尾的词组 | C-STY |
| 技术过程描述，通常有发明年份和功能说明 | C-TEC |
| Barnicoat自创的分析概念，通常以引号或斜体标出 | C-THE |
| "A vs. B"或"A与B"的句式结构 | C-DIC |
| "X影响了Y"、"Y受惠于X"的因果句式 | R-INFL |
| 跨章重复的论点表述 | T-CORE |
| 在分析报告的"论辩与阐述方法"部分提取 | M-ANAL |
| 明确的历史年份+事件描述 | EV-HIST |

### 2.4 权重计算规则

知识元的权重综合以下三个维度：

```markdown
W(K) = α * F(K) + β * C(K) + γ * L(K)

其中：
  F(K) = 该知识元在全部分析报告中的出现频率（归一化到1-10）
  C(K) = 该知识元分布的章节数（Ch1=1, Ch2=1, Ch3=1, Ch4=1, 专项=1，归一化后×10）
  L(K) = 该知识元被其他知识元链接的入度（归一化后×10）
  α=0.4, β=0.3, γ=0.3

权重等级映射：
  10 ≥ W ≥ 8  → 核心知识元（★★★）
  8  > W ≥ 5  → 重要知识元（★★）
  5  > W ≥ 3  → 一般知识元（★）
  3  > W      → 边缘知识元
```

## 四、涌现计算规则

### 4.1 中心度计算

**度数中心度（Degree Centrality）**：节点拥有的链接总数。

```markdown
C_D(v) = deg(v) / (N-1)

其中：
  deg(v) = 节点v的入度+出度
  N = 网络中的节点总数
  C_D(v) ∈ [0, 1]
```

**介数中心度（Betweenness Centrality）**：节点在最短路径上的频率。

```markdown
C_B(v) = Σ_{s≠v≠t} σ_st(v) / σ_st

其中：
  σ_st = s到t的最短路径数
  σ_st(v) = 经过v的s到t的最短路径数
```

**特征向量中心度（Eigenvector Centrality）**：节点的重要性由链接到它的邻居的重要性决定。

```markdown
C_E(v) = (1/λ) Σ_{u∈neighbors(v)} C_E(u)
```

**高中心度知识元的解释**：
- 度数中心度高 → 该知识元是知识网络的"枢纽"
- 介数中心度高 → 该知识元是知识域的"桥梁"
- 特征向量中心度高 → 该知识元被关键知识元所链接

### 4.2 路径发现规则

**桥接路径**：搜索连接两个不直接相关的知识域之间的最短路径。

```markdown
桥接值 = min(路径长度) × 路径上各链接强度的调和平均值
桥接值越低 → 两个知识域之间的"距离"越近
```

**隐含路径**：分析报告中无直接论述，但网络中两节点之间存在一条所有链接都被分析报告确认的路径。这些路径构成"隐含知识"。

### 4.3 聚类识别

使用Louvain算法识别网络中的群落结构：

```markdown
模块度 Q = (1/2m) Σ_{i,j} [A_ij - k_i*k_j/(2m)] * δ(c_i, c_j)

其中：
  A_ij = 邻接矩阵
  k_i = 节点i的度
  m = 总边数
  c_i = 节点i所属的群落
  δ = Kronecker delta
```

### 4.4 涌现论题识别规则

涌现论题是通过网络拓扑分析发现的、原分析报告中未明确陈述的跨章关联。识别规则：

1. **桥接发现**：在网络中发现介数中心度异常高的节点，分析其"连接了什么和什么"
2. **对称发现**：在原本被视为对称关系的两个节点之间发现不对称的链接模式
3. **路径涌现**：发现长度为≥3的路径，其中每一链接都被确认但完整路径未被论述
4. **群落间关系**：识别被不同群落共享的"边界节点"

## 五、分析流程

```markdown
步骤一：知识元提取
  输入：7份分析报告全文
  操作：逐份扫描分析报告，按知识元分类体系提取
  输出：结构化的知识元集合（约300-400个知识元）

步骤二：语义链接构建
  输入：知识元集合 + 分析报告全文
  操作：识别知识元之间的所有语义链接（类型+强度）
  输出：加权有向语义链接网络（约600-800条链接）

步骤三：语义网络可视化
  输入：知识元集合 + 语义链接网络
  操作：构建网络图、按类型着色、按权重调边粗细
  输出：可视化认知地图

步骤四：涌现计算
  输入：语义链接网络
  操作：中心度计算、路径发现、聚类识别、涌现论题识别
  输出：定量计算报告

步骤五：知识发现
  输入：涌现计算结果 + 原分析报告
  操作：将涌现计算的结果"翻译"为可阅读的知识发现
  输出：知识发现报告（本文集中的04号文件）
```

## 六、与原始分析报告的关系

本知识涌现分析**不重复**分析报告中已有的线性叙事和结论，而是在其基础上进行**结构化重组**，发现因线性叙事结构而被遮蔽的：

1. **跨章联系**：不同章节中讨论了同一主题但未被显式连接的论述
2. **隐含论题**：Barnicoat未明说但在多个章节中反复浮现的模式
3. **涌现知识**：网络拓扑自身揭示的新关系

**分析报告的"纵切"vs.知识涌现分析的"横切"**：

```markdown
分析报告（纵切）：             知识涌现分析（横切）：
══════════════              ══════════════
Ch1 ┃ Ch2 ┃ Ch3 ┃ Ch4      维度A：风格谱系（跨Ch1-Ch4）
────╂─────╂─────╂────       维度B：人物网络（跨Ch1-Ch4）
A   ┃  A  ┃  A  ┃  A       维度C：概念演化（跨Ch1-Ch4）
B   ┃  B  ┃  B  ┃  B       维度D：论题交织（跨Ch1-Ch4）
────╂─────╂─────╂────       维度E：方法谱系（跨Ch1-Ch4）
```

两者互为补充：分析报告保留了Barnicoat原著的叙事结构和论证节奏，知识涌现分析则在语义层面拆解并重组这些叙事材料，发现文本表面之下的深层结构。
