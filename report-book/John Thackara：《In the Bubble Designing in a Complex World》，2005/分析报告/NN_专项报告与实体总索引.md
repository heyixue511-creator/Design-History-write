# 《In the Bubble》专项报告与实体总索引

## N00 专项报告：全书论证网络与核心命题地图

### N001 核心命题的层次结构

```
第一层（元命题）：设计创造了我们的困境 → 设计可以创造我们的出路
    │
    ├─ 第二层（问题诊断）：
    │   ├─ 物质：现代工业的"重量"不可持续（第1章）
    │   ├─ 时间：持续加速是一种文化病态（第2章）
    │   ├─ 空间：过度机动化锁入恶性循环（第3章）
    │   ├─ 认知：信息过载=框架缺失（第8章）
    │   └─ 感知：本体论异化——人在系统空间中失去自我（第5章）
    │
    └─ 第二层（建设方案）：
        ├─ 范式转换：从物到服务、从产品到系统（第1章→第10章）
        ├─ 社会重建：共生化的制度——LETS/时间美元/共基对等生产（第6章）
        ├─ 学习重构：从工厂模式到农场模式——九个生态原则（第7章）
        ├─ 感知重连：多感官/对话性——从"视觉中心主义"到"全身知觉"（第8章）
        ├─ 技术重思：仿生学的优雅vs人造智能的臃肿（第9章）
        └─ 方法重塑：七个"从……到……"的设计框架转换（第10章）
```
