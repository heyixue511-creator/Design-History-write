# 00 方法与规则

## L001 本模块的定位与功能

本模块"知识涌现分析"是对"分析报告"模块所产出的L编号实体网络进行二次加工的知识工程。其基本预设是：当大量精细标注的知识元（L编号实体及其关系）被系统性地组织为一个语义链接网络时，某些在原文本中未被显式陈述、但在实体关系的拓扑结构中隐含存在的知识模式会"涌现"出来。本模块的任务就是定义这一涌现过程的操作规则、计算方法和发现逻辑。

本模块与"分析报告"模块的关系如下：

- **分析报告**：产出原始知识元（L编号实体）及其关系描述——这是知识涌现分析的原料。
- **知识涌现分析**：对上述知识元进行语意聚类、关系建模、网络计算和模式发现——这是知识涌现分析的加工过程。
- **产出**：知识发现报告——指出在原分析中隐含的、经由网络计算而显化的跨章节、跨类别、跨层级的知识模式。

## L002 知识元的定义与分类体系

在本分析框架中，"知识元"（Knowledge Unit）指的是一个具有独立语义、可被引用、可与其它知识元建立关系的分析性陈述。知识元在形式上被编码为L编号（如L045、L078等），在内容上对应"分析报告"中的特定分析点。

### L003 知识元的六类本体类型

延续分析报告中的六类实体分类，知识元按其指称的本体类型分为：

| 类型代码 | 本体类型 | 定义 | 在知识涌现分析中的角色 |
|----------|----------|------|------------------------|
| P | 人物/学者 | 历史或当代的学者、艺术家、建筑师等 | 知识的生产源或传播节点 |
| C | 核心概念/术语 | 具有理论负载的抽象术语 | 知识网络的节点——承担语义枢纽功能 |
| E | 案例/事例 | 具体的经验描述或历史事件 | 知识网络的锚点——连接抽象概念与具体经验 |
| B | 著作/文献 | 已出版的学术著作或论文 | 知识的历史载体与传播路径 |
| M | 隐喻/意象 | 修辞性的意象或类比 | 知识的可感性表达——跨域映射的中介 |
| D | 学科/领域 | 知识生产的制度性场域 | 知识网络的宏观分区 |

### L004 知识元的三级粒度

知识元按其语义粒度分为三个层级：

- **一级知识元（原子级）**：单个L编号实体本身——如L045（"能动性回溯"的定义）、L085（风筝实验案例）。这是最基本的分析单位。
- **二级知识元（关系级）**：两个L编号实体之间的明确关系——如"L051（德勒兹与瓜塔里）→ 提供理论资源 → L067（物质-流概念）"。关系级知识元表达了概念之间的直接连线。
- **三级知识元（模式级）**：三个及以上L编号实体构成的稳定关系构型——如"L065（形质论）+ L066（织理性）+ L077（建筑几何性）构成三元对立语义场"。模式级知识元是知识涌现的主要载体。

### L005 L编号作为知识元的引用体系

所有知识元以L编号作为唯一标识符。L编号体系规则如下：

- L001-L124：来自00_整体分析报告
- 各章分析报告中的L编号通过其所在文件隐式区分（如01章L001指第一章分析报告中的L001）
- NN文件中的索引号（P001-P026, C001-C038, E001-E023, B001-B034, M001-M028, D001-D019）作为L编号的补充定位系统

在知识涌现分析中，引用知识元时采用格式：`[文件前缀]L编号`，如`[00]L045`表示整体分析报告中的第45号分析点。

## L006 语义链接的定义与类型

### L007 语义链接的基本定义

"语义链接"（Semantic Link）是两个知识元之间具有理论意义的、可被命名和类型化的关系。语义链接不是任意的联想，而是基于"分析报告"原文中已明确陈述或强烈暗示的关系。

### L008 语义链接的七种基本类型

| 类型编号 | 链接类型 | 定义 | 示例 |
|----------|----------|------|------|
| SL-1 | 对立/对抗（opposition） | 两个概念在理论上处于对抗或不可兼容的位置 | L065（形质论）←对抗→ L066（织理性） |
| SL-2 | 衍生/来源（derivation） | B概念从A概念中派生或A是B的理论来源 | L051（德勒兹与瓜塔里）→衍生→ L067（物质-流） |
| SL-3 | 例证/具身化（exemplification） | 案例或隐喻将抽象概念具身化 | L085（风筝实验）→例证→ L070（物vs.对象区分） |
| SL-4 | 批判/否定（critique） | 一个学者或概念被另一个学者批判或否定 | L054（吉尔）←批判← 英戈尔德（全文立场） |
| SL-5 | 综合/统一（synthesis） | 多个概念在某一范例或论点中被统一 | L088（素描vs.绘画）→综合→ L066（织理性）+ L074（即兴）+ L076（节奏性） |
| SL-6 | 过渡/枢纽（transition） | 一个论证节点在结构上连接两个论证阶段 | L087（伯杰木工房）→过渡→ 第四章（锯木）+ 第五章（素描） |
| SL-7 | 同构/平行（isomorphism） | 两个不同领域的实体共享相同的结构逻辑 | 劈柴（E001）∥ 石器打制（E002）∥ 锯木板（E014）（三者共享"追随材料纹理"逻辑） |

### L009 语义链接的强度分级

每条语义链接按其论证显性程度分为三级：

- **强度1（显式链接）**：原文中明确陈述的关系。如"英戈尔德批判吉尔的能动性回溯"——原文直接表达了这一批判。
- **强度2（强隐式链接）**：原文未直接陈述但通过论证结构强烈暗示的关系。如L065（形质论）与L073（能动性回溯）之间的"认识论同构"关系——原文未说"形质论与能动性回溯是同构的"，但论证逻辑使这一关系清晰可辨。
- **强度3（弱隐式链接）**：需要跨章节、跨类别联想才能发现的关系。如L103（厨房隐喻）与L108（缝合隐喻）之间的"过程性制作"语义共鸣——两者分属不同章节和论证层，但在意象逻辑上是同源的。

### L010 语义链接的表示格式

在本分析中，语义链接以三元组格式表示：

```
[源知识元] → [链接类型] → [目标知识元]  [强度]
```

例如：

```
[00]L067（物质-流） → SL-2（衍生） → [00]L066（织理性）  [强度1]
[NN]E012（放风筝实验） → SL-3（例证） → [00]L070（物vs.对象）  [强度1]
[00]L073（能动性回溯） → SL-1（对立） → [00]L074（即兴）  [强度1]
```

## L011 知识涌现的操作定义

### L012 知识涌现的界定

在本分析框架中，"知识涌现"（Knowledge Emergence）指满足以下至少一项条件的新知识陈述：

1. **跨章节模式发现**：通过对知识元的语义链接网络进行拓扑分析，发现在原分析的各章分析中未被显式指出的跨章节关系模式——例如，发现隐喻M在第一章和第五章中以不同的形态出现并承担相同的论证功能。

2. **跨类别同构发现**：发现分属不同实体类别（如概念C与隐喻M、案例E与著作B）的知识元之间共享相同的语义结构——例如，发现"劈柴（E001）"与"纺线（C028）"共享"追随纹理"的底层逻辑，尽管一个属于案例类、一个属于概念类。

3. **概念层级跃迁**：从具体的L编号实体中抽象出更高层级的概念范畴——例如，从L065（形质论）、L073（能动性回溯）、L077（建筑几何性）、C002（建筑几何性）等分散在全文各处的概念中，抽象出一个统一的"完成时态本体论"范畴，该范畴在原分析中未被作为独立概念提出。

4. **结构洞发现**：识别语义链接网络中"应该存在但缺失"的链接——即两个在原分析中被分别讨论但未被建立关系的知识元之间的潜在联系。这种"缺失的链接"本身就是一种知识发现。

5. **论证策略揭示**：通过分析知识元的引用网络和链接分布，揭示英戈尔德在论证中使用的、未被原分析充分阐明的深层论证策略（如"通过隐喻序列建构替代性概念词汇表"）。

### L013 知识涌现的非涌现（基线）

以下类型的陈述不属于"知识涌现"，而是对原分析的直接复述：

- 单个L编号实体的内容描述（属于分析报告模块的产出）
- 原分析中已明确陈述的两个实体之间的关系
- 原分析各章已独立完成的章内分析

简言之：**凡是在原分析报告的任何一个文件中可以找到其完整表述的陈述，都不属于本模块的"知识涌现"范畴。**

## L014 分析流程与文件分工

### L015 五文件流程

本模块由五个文件构成，按以下流程运作：

```
00_方法与规则.md（本文件）
    │  定义：知识元、语义链接、知识涌现的操作定义和规则
    │
    ▼
01_知识元语意分析.md
    │  任务：从分析报告中抽取所有L编号实体，按语意进行聚类和标签化
    │  产出：语意聚类图谱、知识元属性标注
    │
    ▼
02_语义链接网络.md
    │  任务：在知识元之间建立类型化的语义链接，构建完整的语义链接网络
    │  产出：链接总表、网络拓扑描述、关键节点识别
    │
    ▼
03_知识涌现计算.md
    │  任务：对语义链接网络进行计算分析——模式识别、同构发现、结构洞检测、概念层级跃迁
    │  产出：涌现知识清单、网络指标、可视化描述
    │
    ▼
04_知识发现报告.md
    │  任务：整合前三步的发现，撰写面向读者的知识发现报告
    │  产出：十大发现、论证策略揭示、研究建议
```

### L016 各文件的独立性声明

每个文件可独立阅读，也可按流程顺序阅读。各文件之间通过L编号和链接类型编号进行交叉引用。

## L017 质量规则

### L018 可追溯性规则

每一知识元必须可追溯到分析报告中的具体L编号。每一条语义链接必须可追溯到分析报告中的具体论证段落（通过引用L编号实现）。每一个涌现发现必须列出其依赖的源知识元和链接。

### L019 非重复性规则

本模块的内容不得重复分析报告中已明确陈述的分析结论。本模块的任务是"从已有分析中发现新知识"，而非"复述已有分析"。

### L020 可证伪性规则

每一个涌现发现必须以"如果……则……"的形式包含一个可被检验的隐含预测。例如："如果'完成时态本体论'这一涌现范畴有效，则应能在L065/L073/L077/C002之外找到其他共享该时间性结构的概念或案例。"

### L021 最低丰度规则

每一个涌现发现至少涉及两个不同章节或两个不同实体类别的知识元。仅涉及单一章节单一类别的陈述不属于知识涌现。
