# 25 Processing... — Ben Fry & Casey Reas | 2007

作者：Ben Fry & Casey Reas (设计师/程序员/Processing创始人) | 出处：Processing: A Programming Handbook for Visual Designers and Artists (MIT Press, 2012) | 文本类型：软件哲学/技术教育文献

## L001 一、章节定位与功能

"Processing..."在Section Three中定位于**开源软件运动的视觉设计宣言**——以Processing编程语言和环境为案例，阐述"软件素养"(software literacy)时代的设计方法论。Fry和Reas作为Maeda在MIT ACG的学生，通过Processing实现了导师"Design by Numbers"的愿景，并将其扩展为全球性社区。其功能为：(1) 定义Processing的三重身份——编程语言、开发环境、教学法；(2) 构建软件的六维哲学框架（Software/Literacy/Open/Education/Network/Context）；(3) 通过Tarbell的Complexification.net和Hodgin的Flight404.com等社区案例展示"开放源码+共享代码"如何加速整个社区的创造性学习。

## L002 二、结构分析

论文按Processing的六个核心哲学维度展开：**Software**（软件=独特媒介/不同语言=不同材料/写生本的比喻）→**Literacy**（软件素养=读写能力/从Nelson到Kay到Maeda的素养谱系）→**Open**（开源=社区共享/与商业软件的对比/Laura Hernandez Andrade通过共享代码构建Talking Colors装置）→**Education**（教育=混合课程/跨学科/短期工作坊）→**Network**（网络=Tarbell和Hodgin的社区案例/Web作为发布和协作平台）→**Context**（语境=与Java和C语言的关系/在设计和艺术语境中的独特定位）。每个部分以宣言式陈述开篇。

## L003 三、内容分析

**核心论题**：编程应被视为一种视觉艺术家的基本素养——不是替代传统媒介，而是扩展表达的可能性范围。

**关键论点**：(1) **软件=媒介(L003-1)**："Software is a unique medium with unique qualities. Concepts and emotions that are not possible to express in other media may be expressed in this medium."——软件不是工具而是媒介。(2) **编程语言=材料(L003-2)**："Every programming language is a distinct material."——如同椅子设计师选择钢材或木材，视觉艺术家选择编程语言作为材料。(3) **写生本(L003-3)**："Sketching is necessary for the development of ideas. It is necessary to sketch in a medium related to the final medium."——电子写生簿的概念是Processing对"艺术家为何需要编程"的核心回答。(4) **素养=L003-4** 引用Kay："The ability to 'read' a medium means you can access materials and tools created by others. The ability to 'write' in a medium means you can generate materials and tools for others. You must have both to be literate."(5) **开源=L003-5**：引用Tarbell："Opening one's code is a beneficial practice for both the programmer and the community. I appreciate modifications and extensions of these algorithms."

**关键案例**：(a) 物体追踪代码的社区改进链——原始代码仅追踪最亮单目标→Karsten Schmidt改写为多色多目标追踪→Laura Hernandez Andrade基于此构建Talking Colors交互装置。(b) Daniel Shiffman的NYU课程网站——全部课程大纲和学生代码公开在线。

## L004 四、逻辑梳理

论证逻辑是"**定义→谱系→方法→证明→展望**"：(1) 定义软件的独特性；(2) 将Processing定位于从Nelson(1974)→Dynabook→Maeda的"素养"思想谱系中；(3) 以开源社区的案例证明"共享代码加速学习"；(4) 以教育实践案例证明"短期工作坊+混合课程"的有效性；(5) 以Web社区（Tarbell, Hodgin）证明网络化协作的自我催化效应。

## L005-L007（合并）

**阐述方法**：将技术文档、教育哲学和社区运营报告融合为一体。"宣言→案例→数据"三明治结构。

> **原文摘录L007-1**："Software is a unique medium with unique qualities. Concepts and emotions that are not possible to express in other media may be expressed in this medium."
> **原文摘录L007-2**："People are encouraged to publish the code for programs they've written in Processing. The same way the 'view source' function in Web browsers encouraged the rapid proliferation of website-creation skills, access to others' Processing code enables members of the community to learn from each other."

## L009 九、与前后章关联

**与前章(Maeda)**：Processing是Design by Numbers的"开源社区化实现"——Maeda提供了哲学框架，Fry和Reas将其扩展为全球运动。

**与后章(Antonelli, Dubberly, Conditional Design, Vinh)**：Processing的开源方法论和"软件素养"理念渗透了Section Three的所有后续文本——Antonelli的"弹性思维"需要跨学科的计算素养、Dubberly的"有机系统"需要模拟和建模工具、Conditional Design的"逻辑作为工具"直接依赖编程式思维、Vinh的"对话框架"需要可迭代的软件方法论。
