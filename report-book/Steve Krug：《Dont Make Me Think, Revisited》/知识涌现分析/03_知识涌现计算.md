## 三、内聚度与涌现强度 S 计算（摘要）

- **高内聚簇**：T4（0.83）、T6（0.83）——"惯例/创新"与"删字"两簇议题集中、反复互证，语义最致密。
- **中内聚簇**：T2（0.70）、T3/T5/T9/T10（0.60）——主论证链所在。
- **涌现强度 S 综合评估**：全书一级涌现密度高（三定律+五要素+两清单构成大量 E 结构），二级涌现（跨簇命题）约 6 条（见下），S 总体评级：**强**（因主干链闭环且枢纽集中）。

## 四、一级涌现结构（E1…En，示例）

- **E1**：别让我思考 → 自明/自解释 → 扫描式首眼判断（T1+T2 复合）。
- **E2**：satisficing ⇒ 无脑选择 ⇒ 信息气味 ⇒ 清晰命名（T1+T5 复合）。
- **E3**：导航五要素 : 页面名+You are here+面包屑 ⇒ trunk test 六问验收（T7 内部涌现）。
- **E4**：大爆炸理论 ⇒ 首页四问 ⇒ 标语/欢迎语 ⇒ 公地悲剧警示（T8 内部涌现）。
- **E5**：宗教辩论 + 平均用户神话 ⇒ 测试为唯一解药（T9+T10 复合）。
- **E6**：善意储备（因情境可降）→ 无障碍（为他人着想）→ 反操纵红线（T12 内部涌现）。

## 五、二级涌现命题（P1…Pn）

| 命题 | 生成机制 | 强度 |
|---|---|---|
| P1：**可用性 = 不思考 + 无脑点击 + 最少文字，三者同一原则的三个切面**（"别让我思考"在页面层/点击层/文字层的递归落地） | 由 T2、T5、T6 的三定律同构性涌现 | 强 |
| P2：**设计的第一职责是"顺应而非对抗"用户行为**（扫描/satisficing/摸索不是缺陷而是默认参数，设计应围绕其展开） | T1 与 T3、T7 的双向支撑 | 强 |
| P3：**验证（测试）是设计争论的终结者**——把"喜好"之争改写为"行不行"之争 | T9 认知论批判 + T10 方法论，经"测试"桥接元 | 强 |
| P4：**一切移动/无障碍新问题都可还原为"权衡中给用户体验的权重不足"** | T11 权衡枢纽向 TH2/TH4 的辐射 | 中 |
| P5：**网站人格即品牌人格**——清晰与体贴（mensch）共同决定用户信任与复访 | T12 善意储备 + 增益清单与消磨清单的对仗 | 中 |
| P6：**可用性职业的伦理底线是"服务用户"而非"取悦客户"**——说服可、操纵不可，测试不可用于判定"可取性" | T12 操纵/说服分界 + P2 的用户中心立场 | 中 |

## 六、客观性核对与反例

1. **"测试是唯一解药"的边界**：作者承认测试无法测"可取性"（L3782-3784），即"解药"不是万灵——此反例已在 P3 命题内嵌。
2. **"惯例"非绝对**：作者同时肯定创新（Harlem.org 案例，L887-896），"创新当你有更好想法"（L883）——T4 的高内聚正源于这种辩证自洽，而非单边断言。
3. **"删字"的边界**：第三定律明确"不是所有正文都该短"（WebMD/NYTimes 例外，L1221），避免对内容型页面的误用。
4. **用户行为三事实的例外**：作者承认用户也会权衡选项（取决于心境/时间/信心，L654-656），行为事实是"主流倾向"而非"铁律"。
5. **善意模型的个体差异**：作者明言池子大小因人而异、看情境（L3392-3398），模型是启发式而非定量理论。
6. **方法的定性定位**：自助测试"不证明任何事"（L2374-2376），作者未夸大其统计效力——涌现命题 P3 的"终结者"表述应读作"辩论层面"而非"证明层面"。

以上反例表明：本书的涌现命题多带"经验概率"色彩而非全称断言，分析时已如实标注。
