# 知识涌现分析 00：方法与规则

## 一、层级定义

本书知识涌现分析采用三级结构：

- **知识元（Knowledge Atom）**：六类实体中最小的语义单元——人物、著作/作品、概念、机构、地点、事件。每个知识元必须附 clean 版行号证据。
- **Topic（主题簇）**：由语义强链接连接成的连通簇（强连通/准连通），即若干知识元因共同论域而内聚成群。
- **Theme（高层语义域）**：多个 Topic 聚合而成的高层论域，通常由共享知识元或桥接知识元维系。

## 二、九种语义链接判定标准

| 类型 | 符号 | 判据 | 例（本书） |
|---|---|---|---|
| 因果 | → | A 导致/产生 B，文本有因果连接词 | 资产阶级去命名（L2071）→ 神话匿名化（L2100） |
| 条件 | ⇒ | A 是 B 的前提/必要条件 | 只有元语言（L2148）⇒ 神话才可能（L2148） |
| 对比 | ↔ | A 与 B 对立/对照 | 摔跤↔拳击（L32-37）；酒↔奶（L602-635） |
| 隶属 | ⊂ | A 是 B 的成员/特例 | vaccine ⊂ 右翼修辞格式（L2204） |
| 时序 | ≻ | A 在 B 之前/之后 | 意义（sens）≻ 形式（forme）（L1826） |
| 空间共现 | ≈ | A 与 B 在文本同一语境共现 | 环法≈旺图山≈jump（L951-963） |
| 属性 | : | A 具有属性 B | 神话:二级符号学系统（L1794） |
| 论证支撑 | ⇐ | B 为 A 提供证据/例证 | 拉丁文句⇐ 神话概念理论（L1804） |
| 同域 | ∼ | A 与 B 同属一个论域 | 疫苗∼同语反复（均属资产阶级修辞） |

## 三、涌现指标

| 指标 | 定义 | 计算依据 |
|---|---|---|
| 节点度 k | 某知识元被链接的数量 | 实体在全书出现并被引用论证的频次 |
| 桥接值 b | 连接不同 Topic 的知识元数量 | 同时支撑两个以上主题簇的知识元 |
| 簇识别 | 强连通子图 | 语义链接网络的连通分量 |
| 内聚度 | 簇内链接数/节点数 | 每簇内部链接密度 |
| 涌现强度 S | 由节点度与桥接值的组合衡量 | S = 高k×高b 的核心枢纽 |
| 一级涌现 | 知识元直接链接形成的结构 | E1…En（可计数的知识元-链接结构） |
| 二级涌现 | 由一级结构推演的新命题 | P1…Pn（全书未明言但可推导的命题） |

## 四、证据规范

- 所有知识元与链接必须引用 clean 版行号（L###）。
- 链接须有文本依据，不得臆造；存在争议时并列反例或标注证据缺口。
- 分析为纯语义阅读，不采用任何统计/编程处理。
