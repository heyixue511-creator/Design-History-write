# Ch30 分析报告：Racine est Racine（拉辛即拉辛）

## 章节定位与功能

第一部分第三十篇，行号 L812-835。以"阿塔莉是拉辛的一出戏"这一批评家声明为对象，分析"同语反复"（tautologie）作为小资产阶级反智批评的修辞：它同时杀死理性与语言，是"以安全的虚无为荣"。

## 结构分析

- L812-821：命题——"口味就是口味（布瓦尔与佩居谢）"（L813）；艺术家声明"阿塔莉是拉辛的戏"（L815）；同语反复是"向语法学家宣战"（L816）；"同语反复总是咄咄逼人的"（L817）；"切断想法的缰绳"（L818）。
- L821-828：反智主义——"对拉辛想太多？"（L819）；"反智主义"（L821）；"智力太多有害、哲学是无用行话"（L822）；"对智力的战争总以常识为名"（L823）；"简单/纯真"的召唤（L826-827）。
- L828-836：结论——"简化"的双重托词（L828）；"找回的批评神话"（L829）；"拉辛总是一个不是拉辛的东西"（L833）；"同语反复使人免于思考，并把懒惰提升为严格"（L835）；"拉辛即拉辛：虚无的令人钦佩的安全"（L836）。

## 内容分析

巴特解剖"拉辛即拉辛"式批评：用同语反复中止意义生产，以"简单/纯真"的名义拒绝智性解释，从而把批评的懒惰神圣化。这是小资产阶级反智主义在文学批评中的典型。

## 逻辑梳理

同语反复的案例 → 反智主义谱系 → "简单"的双重托词 → 同语反复的逻辑死路 → 安全虚无的结论。

## 材料使用方式

引用"阿塔莉是拉辛的戏"（L815）；引用"布瓦尔与佩居谢"（L813）；列举"拉辛-形容词"（L833）；提及 Montherlant、Véra Korène（L833）。

## 论辩与阐述方法

以"同语反复"概念为轴；引用福楼拜《布瓦尔与佩居谢》作为同语反复的原型；结尾格言式收束。
