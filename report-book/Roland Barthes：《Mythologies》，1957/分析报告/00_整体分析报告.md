## 一、著作定位与成书脉络

《神话学》是罗兰·巴特的第一部系统著作，也是法国 1950 年代文化批评与早期结构主义交会点上的标志性文本。本书由两部分构成：前一部分是约五十四篇针对法国当时日常文化现象（报刊、广告、电影、体育、食物、时尚、政治修辞等）的短篇时评，后一部分是《今日神话》（Le mythe, aujourd'hui）这一理论长文，对前文所处理的材料作方法论的系统化。

巴特在前言中自述写作缘起：1954—1956 年间，他每月依据时事写一篇"对法国日常生活某些神话的反思"（L2），材料范围极广——"一篇报刊文章、一张周刊照片、一部电影、一场演出、一次展览"（L3），对象选择"十分随意"（L3）。出发点是"面对报刊、艺术和常识不断地把一种现实裹上'自然'的外衣而感到的不耐烦"（L4）：他"痛苦地看到，在我们时代的叙事里，自然与历史无时无刻不被混为一谈"，因而要"重新抓住……那些不言自明之物（ce-qui-va-de-soi）的装饰性展示中被隐藏的意识形态滥用"（L4）。

巴特明确承认方法论分期：起初"神话"一词取自传统含义（L5），但他早已确信"神话是一种语言（parole）"（L6）；在逐一考察时事之后，他才尝试"系统化地定义当代神话"，并把这篇理论文字放在全书末尾（L8）。这些文章的连接方式是"坚持、重复"（L9），因为"我相信至少它们有所意指（signifient）"（L10）。巴特还坦承自己处于"被神话化的神话学家"的双重处境，拒绝"科学家的客观性与作家的主观性之间的天然分离"，声明"要求完全地活在我这个时代的矛盾之中，这种矛盾可能使讽刺成为真理的条件"（L16-17）。

## 二、全书主旨与核心命题

《神话学》的主旨可概括为一句话：**当代法国资产阶级社会通过"神话"这种言语形式，把历史的、偶然的、人为的东西改造为自然的、永恒的、理所当然的东西，从而完成意识形态的去政治化（dépolitisation）；本书的任务就是对这些神话进行符号学层面的解码与揭露。**

全书核心命题包括：

1. **神话是一种言语（parole）**："神话是一种言说"（L1723）；"神话是一种沟通系统，是一种讯息（message）"（L1727）；"神话不是客体、概念或观念，而是一种意指方式，一种形式（forme）"（L1728）。
2. **神话是二级符号学系统**：神话建立在先于它存在的一级符号链条之上，"是第二级的符号学系统"（L1794）；一级系统中的"符号"（如语言中的词）在神话中降格为"能指"（signifiant）即"形式"，并吸收"概念"（concept），两者结合产生"意指"（signification）。
3. **神话的功能是"把历史变成自然"**："神话的职能是把历史意图建立在自然之上，把偶然性建立在永恒之上"（L2108）；"神话让历史消失，而留存自然"（L2113）。
4. **神话是"被去政治化的言语"**：神话"以对真实做彻底放空（évacuer）为其职能……是一种持续的流失、放血、蒸发，简言之一种可感的缺失"（L2115）；"神话是一种被去政治化的言语"（L2116）。
5. **资产阶级意识形态的匿名化（ex-nomination）**：资产阶级"是拒绝被命名的阶级"（L2071），它"通过把现实改造成世界的形象、把历史改造成自然"来运作（L2100）。
6. **左翼与右翼神话的不对称**："统计上，神话在右翼"（L2180），右翼神话"本质上"存在、丰富、扩散（L2181-2183）；左翼神话则"非本质的、偶然的、贫乏的"（L2162-2167）。
7. **神话学的自反性限度**：神话学家自身处于"被排除"的境遇（L2280），其工作是"元语言"，且"不是摩西式处境"（L2296）；"我还看不到意识形态与诗之间有什么综合"（L2309）。

2. **理论层面（第二部分）**：以索绪尔符号学为起点，建立"语言—对象语言／元语言"、"能指（意义/形式）—所指（概念）—意指"的二级系统，并把这些形式分析接到意识形态分析（马克思、萨特、布莱希特、日丹诺夫主义等）上。

3. **修辞学层面**：第二部分末尾归纳资产阶级神话的"修辞格式"——疫苗（vaccine）、剥夺历史（privation d'Histoire）、认同（identification）、同语反复（tautologie）、"尼尼主义"（ninisme）、质的量化（quantification de la qualité）、断言（constat）等（L2204-2263），并在结尾给出"本质（Essences）与天平（Balances）"两大总纲（L2264-2266）。

| gouvernementalité（政府性） | 巴特在分析"价格下跌"标题时造的新词：作为效率本质的政府 | L1974 |
| sinité（中国性） | 法式小资产阶级想象中的"中国性"混合体 | L1867 |
| basquité（巴斯克性） | "巴斯克小屋"所承载的本质化属性 | L1910 |
| idéologisme（意识形态主义） | 神话学家只谈论意识形态而不谈论物本身的处境 | L2304-2308 |

## 六、材料与方法

**材料类型**：本书第一部分使用当时法国大众传媒与日常生活的具体"文本"作为分析对象，包括：报刊文章与标题（《费加罗报》《巴黎竞赛画报》《她》《快报》《法兰西晚报》《世界报》《队报》等）、广告（Omo、Persil、Astra、Lux 等）、电影（《凯撒大帝》《码头风云》《摩登时代》《瑞典女王》等）、电视电影、戏剧（阿达莫夫《乒乓球》、青年剧团演出）、照片展览（"冲击照片"展、"人类大家庭"展）、宗教活动（比利·格雷厄姆布道会）、体育（环法自行车赛）、司法案件（多米尼西案、杜普里兹案）、政治运动（普雅德主义）、商品（塑料、雪铁龙 DS、洗涤剂）等。

**引用方式**：直接转引报刊语句与广告语（如 L337-340、L1172、L1243、L1255），引用文学作品（如《伊索寓言》"quia ego nominor leo" L1804）、引用名人言论（如科克托 L1384、圣茹斯特 L2298）、转述电影情节与摄影画面（L1811-1814）。

**论证方法**：
1. **符号学还原**：把日常文本拆解为能指/所指/意指，显示其二级系统的运作（L1754-1820）。
2. **意识形态批判**：把符号学分析接到马克思主义阶级分析（资产阶级匿名化）与布莱希特式的"去陌生化"（L555, L561-562, L895）。
3. **对比法**：酒/牛奶（L602-635）、摔跤/拳击（L32-37）、黑色电影中的手势/语言（L585-600）、凡尔纳/兰波（L658-679）、左翼/右翼神话（L2142-2271）。
4. **自反性**：反复强调神话学家自身也被排除、其语言是元语言（L2280-2310）。

**史料意识**：巴特将民间、大众媒介文化视为可作"人类学/民族学"考察的材料（L538, L1721），并援引人类学家（马塞尔·莫斯、列维-斯特劳斯、勒鲁瓦-古尔汉）作为对照（L538）。

## 七、核心论辩

1. **自然化论辩**：神话把"历史"伪装成"自然"，把"制造"伪装为"从来如此"（L2112-2120）。例证：黑人士兵向三色旗敬礼的《巴黎竞赛画报》封面（L1811-1814）。
2. **去政治化论辩**：神话抽空对象的政治性——不是否认帝国主义，而是把殖民主义的"被制造性"抽掉（L2118-2119）。
3. **匿名化论辩**：资产阶级意识形态以"永恒的人"、"普遍人性"为名运作，从而逃过命名与批判（L2071-2100）。
4. **不对称论辩**：右翼神话丰富、本质、蔓延；左翼神话贫乏、偶然、勉强（L2161-2177, L2180-2185）。
5. **反疫苗论辩**：现代资产阶级意识形态善于"接种小恶以免疫大恶"（L2204-2207），用局部自揭掩盖总体维护。
6. **方法论自反论辩**：神话学是必要的（揭穿伪自然即政治行动），但神话学家注定被排除于神话消费之外，也注定无法达到"物本身"（L2277-2310）。

## 九、语言与写作风格总貌

1. **法语文体**：本书为法语学术随笔文体，长句密集、大量使用破折号与分号、插入语与同位语，句子结构复杂，兼有修辞学家的华丽与哲学家的思辨。
2. **格言式断言**：常以斩钉截铁的判断句收束段落，如"Le mythe est une parole dépolitisée"（L2116）、"Tout peut donc être mythe ? Oui, je le crois"（L1732-1733）、"Le mythe est un langage volé"（L1991）。
3. **隐喻与拟物**：以"疫苗"（L2204）、"天平"（L2266）、"水银流动"（L2115）、"被窃的语言"（L1991）等意象作理论工具。
4. **反讽与讥诮**：大量针对资产阶级与小资产阶级的自满话语的反讽（L240-251, L1298-1331）。
5. **术语创造**：新造词（néologismes）频繁——sinité（L1867）、basquité（L1910）、gouvernementalité（L1974）、bobétisme（L1021）、"vaccine""ninisme"（L2204, L2240）等。
6. **第一人称在场**：全篇以"je"组织论证（L2, L4, L10, L1732），承认立场与情感，拒绝客观主义伪装（L16-17）。

## 十、成就与限度

**成就**：
1. 把符号学从语言扩大到整个大众文化领域，成为文化研究、媒介研究、视觉文化研究的奠基文本。
2. 提供了一套可操作的"神话解码"方法（二级系统、能指/所指/意指、阅读三类型）。
3. 对资产阶级意识形态匿名化机制作了深刻的阶级分析。
4. 其"疫苗""去政治化""自然化"等概念至今是批判性文化分析的常用工具。
5. 文本写作兼具理论深度与文学可读性，在法国国内外产生广泛影响。

**限度（含反例与边界）**：
1. 巴特自认神话学家"被排除"（L2280），其分析是一种元语言，无法触及"物本身"（L2303-2308），存在"意识形态主义"危险。
2. 第一部分以时评为体，事实判断随时代流逝部分过时；巴特也承认材料"十分随意"（L3）。
3. 分析方法偏重法国国内语境，对殖民地的分析（L518-542, L1219-1296）带有其时代马克思主义批判的特征，某些判断（如对苏联的立场）后人可有争议。
4. 巴特本人承认"我还看不到意识形态与诗之间的综合"（L2309），全书以悬而未决的"两难"收束，未给出肯定的解决方案。

## 十一、一句话概括

《神话学》以 54 篇时事短评加一篇系统理论长文，完成了对"把历史伪装成自然、把政治去政治化"的当代法国资产阶级神话的一次全面符号学解码，确立了"神话是二级符号学系统的言语"这一经典命题。
