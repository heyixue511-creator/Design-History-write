# Ch56 分析报告：Le mythe est une parole（神话是一种言说）

## 章节定位与功能

第二部分第一节，行号 L1721-1752。这是理论长文《今日神话》的开篇。行 L1721 行尾出现"II. Le mythe, aujourd'hui"的部标题（L1721-1723），正文以 L1723"神话是一种言说"立论。本节为整个神话理论奠基：神话不是对象而是"言语/形式"。

## 结构分析

- L1721-1728：问题与初答——"什么是今日神话？"（L1722）；初答："神话是一种言说（parole）"（L1723）；"神话是一种沟通系统，是一种讯息"（L1727）；"神话不是对象、概念或观念，而是一种意指方式，一种形式"（L1728）。
- L1728-1741：形式与历史的边界——须为形式设定历史条件（L1729）；"既然神话是一种言说，任何可以被言说的东西都可以成为神话"（L1730）；"神话不由其讯息的对象定义，而由它言说的方式定义"（L1731）；"一切都可以成为神话"（L1732）；例：被米努·德鲁埃说出的树不再是树（L1737）；"神话没有永恒的，只有历史的"（L1740-1741）。
- L1741-1752：言语的物质——神话可以是非口头的：照片、电影、报道、体育、演出、广告（L1743）；"不能以对象或材料定义神话"（L1744）；"图像与书写"的差别是构成性的还是偶然的（L1747-1749）；"言语"的广义：一切有意义的单位（L1750）；历史先例：印加奇普、象形文字（L1751）；"神话属于符号学"（L1752）。

## 内容分析

本节确立神话的"形式主义"定义：神话是"意指方式"，由"言说方式"而非"对象"决定；神话的历史性来自其概念（L1740）。巴特明确把神话纳入索绪尔式的符号学（L1752）。

## 逻辑梳理

问题 → 初答（parole）→ 形式 vs 实质的界定 → 一切皆可神话 → 神话的历史性 → 言语物质的泛化 → 符号学归属。

## 材料使用方式

引用伊索寓言式拉丁文例句预告（"quia ego nominor leo"在 L1804）；以"米努·德鲁埃说出的树"（L1737）作例；引用印加奇普与象形文字（L1751）。

## 论辩与阐述方法

定义式论证（先立定义再逐步限定）；"对象/方式"的对立；以"历史性"排除"永恒神话"；结尾归属符号学。
