# Ch39 分析报告：Cuisine ornementale（装饰烹饪）

## 章节定位与功能

第一部分第三十九篇，行号 L1134-1153。分析《她》（Elle）周刊的"装饰烹饪"照片，揭示其"视觉/装裱"的美食神话：以"覆盖（nappé）"和"装饰"把食物变成"海报"，服务"贫穷读者的梦想"。

## 结构分析

- L1134-1141：现象——《她》每周登一幅"摆盘"美食照片（L1135）；主导范畴是"覆盖/装裱"（nappé）（L1136）；"纯粹的视觉烹饪，视觉是高雅感官"（L1137）；其"高雅"诉求服务于大众读者（L1139）；乡村菜只在例外（L1140）。
- L1141-1148：装饰的两条道路——"装裱"支撑"装饰"（L1141-1142）；两条相反道路：逃离自然的巴洛克 vs 重构自然的荒谬（L1143）；"小资产阶级工艺品的同一运动"（L1144）；"有想法的烹饪"（L1146）；"发明只能施加于装饰"（L1147）。
- L1148-1153：结论——"这种装饰烹饪由完全神话的经济支撑"（L1148）；"是梦想的烹饪、海报的烹饪"（L1149-1150）；对比：Elle 给穷人"寓言"，《快报》给富人"真实菜谱"（L1152-1153）。

## 内容分析

巴特解码《她》周刊的"装饰烹饪"：食物被"装裱"、被"视觉化"，成为离身的海报对象；这种"高雅"神话恰恰服务于低收入读者，用梦想替代真实的经济烹饪。阶级差异在烹饪神话中被固化。

## 逻辑梳理

视觉/装裱的主导 → 装饰的两条道路 → "有想法"的烹饪 → 神话经济 → 阶级差异（Elle vs Express）。

## 材料使用方式

引用《她》的具体菜式（松鸡插樱桃、冷鸡、龙虾盏等，L1135）；引用"圣诞树桩"等装饰（L1143）；对比《快报》的"尼斯沙拉"（L1152）。

## 论辩与阐述方法

"视觉 vs 味觉"的感官等级分析；"海报/寓言"的隐喻；结尾以阶级对比点明意识形态。
