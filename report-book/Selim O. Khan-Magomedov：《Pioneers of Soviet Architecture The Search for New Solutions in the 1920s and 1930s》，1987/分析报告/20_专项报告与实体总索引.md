# 20_专项报告与实体总索引

## 一、专项报告

### 专项一：全书"美学—社会"双轴结构专论

- 依据：Introduction（L247–275）明确"两大主要因素"——审美发展（Part I）与社会任务（Part II）。Part III 为"大师与趋势"的文档支撑（L276–282）。
- 美学轴（Part I）：Ch1 传统遗产 → Ch2 左翼绘画来源 → Ch3 早期语言探索 → Ch4 理性主义 → Ch5 构成主义 → Ch6 成熟期创新 → Ch7 民族/国际 → Ch8 1930 年代初转向。
- 社会轴（Part II）：Ch1 聚居/规划 → Ch2 住宅/生活方式 → Ch3 行政/社会建筑 → Ch4 俱乐部 → Ch5 群众剧场 → Ch6 集体服务 → Ch7 教育科学 → Ch8 体育休闲。
- 交会点：Sotsgorod 的"社会凝聚器"理想（L2319、L7757）同时驱动住宅（Ch10）、俱乐部（Ch12）、集体服务（Ch14）各类型；obraz（形象）概念（L295–296）贯穿美学与社会两轴。

### 专项二："转向传统主义"（1932–1934）的原因与边界专论

- 作者立场：转向主要是"审美理想改变"，非创新不足（L3132、L3123）。
- 证据：苏维埃宫竞赛评审"采用最佳古典范例"的指示（L3117）、1934 年 Zholtovsky 的 Mokhovaya 大楼获专业媒体赞誉 vs. Le Corbusier 的 Tsentrosoyuz 被冷落（L3139–3141）。
- 边界：作者同时承认政治/组织因素（Vopra 的 Rapp 式宗派斗争、1932 年党决议，L3109–3113），但坚持美学解释是主因；对"创新派在 1930 年代初专业水平最高"的判断（L3133）为其反证。
