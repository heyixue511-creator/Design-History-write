# Ch25 分析报告：Ecological Design: A New Critique

- 作者：Pauline Madge
- 行号范围：L4935-5148（正文 L4939-5031，Notes L5033-5147）

## 一、章节定位与功能

本书 Part III 第五篇。它梳理生态设计从"绿色设计"到"生态设计"再到"可持续设计"的术语谱系与批评史，论证生态设计蕴含"新设计批评"（Sec3 导言 L4304）。功能：为"评价"部提供环境设计的批评史学。

## 二、结构分析

- 引言（L4941-4947）：生态设计"已成年"；术语变迁作为态度指标。
- 绿色设计（L4949-4979）：1980s 绿色时尚；Design Council《The Green Designer》（L4953）；浅绿/深绿（L4955）；O'Riordan 技术中心/生态中心（L4957）；绿色消费主义与"绿色骗局"（L4961-4967）；Ethical Consumer/New Consumer（L4969）。
- 生态设计（L4981-4993）：EDA（L4983）；EcoDesign Foundation Sydney（L4987）；RMIT 会议（L4987）；Eureka 计划（L4991）；UNEP 五十项倡议（L4991）。
- 可持续设计（L4995-5021 区段）：Brundtland《Our Common Future》（L5113-5117 注）；LCA 与工业生态（L5083-5087 注）；深层生态（L5045 注）；"设计为需要"的回潮（L5021）。
- 结论（L5023-5031）：生态方法之激进性蕴含新设计批评。

## 三、内容分析

核心论点：
1. "绿色→生态→可持续"术语演进代表理论-实践范围的持续拓宽与批评立场加深（L4943-4945）。
2. 生态设计不是统一现象："绿色有多种深浅"、政治分化（L4947）。
3. 绿色设计多为"浅绿、技术中心、浅生态"的改良路线（L4959）；深绿路线（Baubiologie、Green Pages）强调减少消费（L4959）。
4. 绿色消费主义有内在矛盾：广告与扩张经济捆绑（L4961-4963）。
5. 可持续设计回归"设计为需要"主题，要求对消费模式与生活方式的根本质疑（L5021）。
6. 生态设计由定义即反对现状，故蕴含新设计批评（L5025-5031）。
