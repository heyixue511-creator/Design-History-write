## 一、章节定位与功能

本书 Part II 首分节末篇。它以亲历者视角编年记录 1984-1997 年数字排印技术发展（Macintosh 平台为中心）。功能：为"制作"提供数字对象（字型）的技术史，展示多人参与如何塑造数字设计（Part II Sec1 导言 L3133）。

## 二、结构分析

- 引言（L2884-2886）：数字技术如何改变排印；作者作为 Apple 早期 GUI 设计师的观察。
- 早期概念与技术进展（L2888-2915）：Macintosh 1984；WYSIWYG；Xerox Star/ViewPoint（L2892）；LaserWriter 1985（L2911）；PostScript（L2913）；PageMaker 等桌面出版（L2915）。
- 字型的数字构造（L2917-2929）：MIT/Stanford 研究；Knuth METAFONT（L2919）；Lucida（L2919）；CRT 像素；Chicago/Geneva 系统字体（L2921）；NeXT（L2929）。
- 图形设计的对应创新（L2931-2995）：Licko/VanderLans 与 Emigre（L2933-2951）；Greiman（L2953-2959）；抗锯齿（L2961-2972）；Photoshop 与 Illustrator（L2977-2983）；Brody/Makela（L2990）；Carson（L2992）。
- 纸与屏幕（L2997-3014）：CD-ROM 多媒体；Espy 字体；Matthew Carter 与 Bitstream；Adobe Type Manager；TrueType 字体战争（L3012）。
- 排印与万维网（L3016-3026）：浏览器用户控制；@Home；OpenType。
- 赛博空间中的排印与计算（L3028-3034）：MIT Visible Language Workshop（Muriel Cooper）；Maeda；J. Abbott Miller 三维字型。
- 结论（L3039-3049）：文字被并入图像空间；数字技术修订书面语地位。

## 三、内容分析

核心论点：
1. 数字工具"起初因技术限制、后来因技术进展"鼓励了挑战历史先例的表征（L2884）。
2. Macintosh 普及了 WYSIWYG、位图字体、激光打印，民主化排印（L2890-2913）。
3. 屏幕与纸的区分（位图/轮廓双系统）长期支配数字排印（L2927）。
4. Photoshop 把文字降格为图片层，"字母与图像模糊地结盟"成为平面设计新规范（L2983）。
5. 万维网把排印外观控制权交给受众，设计师以"图形文字"抵抗（L3018-3020）。
6. 排印创新延续到赛博空间：编程驱动、算法驱动字型（L3041）。
