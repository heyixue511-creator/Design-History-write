## 二、弱涌现命题（原文分开陈述、闭包路径成立、合并从未出现）

### W1 堆肥伦理 = 存在论 + 死亡论
- 路径：KE-14（我们是堆肥，L828、L1325）→ KE-56（死亡归于堆肥，L2027-2035）
- 计算：两节点均出链至"堆肥"概念簇；闭包成立。
- **涌现命题**：堆肥主义不仅是"活着的主体性"，更是完整的生死循环伦理——"如何死"与"如何活"同属堆肥技艺。
- 应用：把"死亡设计"（end-of-life design、葬仪设计、纪念设计）纳入生态伦理框架。

### W2 响应能力的传播需要元伦理
- 路径：KE-24（相互感染，L465、L1543）→ KE-10（响应能力）→ KE-44（无清白故事，L1531）
- 计算：KE-24 与 KE-44 均指向 KE-10，构成共享后继；路径合并。
- **涌现命题**：既然响应能力"病毒式"传播且"没有清白"，那么传播本身必须接受伦理审查——感染是事实，消毒是责任。
- 应用：设计传播/品牌扩散理论中引入"传播责任审计"。

### W3 部分复原 = 避难所-复苏闭环
- 路径：KE-34（避难所，L1344-1348）→ KE-20（复苏，L2711-2714）→ KE-11（部分复原，L224-225）
- 计算：KE-34→KE-20（避难所是复苏的前提）且 KE-20→KE-11（复苏是复原的一种形态）；传递闭包成立。
- **涌现命题**：部分复原的操作定义 = "保护/创造避难所，使复苏得以发生，并接受复苏形态的不可预期性"。
- 应用：为"再生设计"提供可检验标准：先保避难所，再谈复原。

### W4 命名是记忆装置
- 路径：KE-28（命名即政治，L1338）→ KE-02/03/04/05（命名簇）→ KE-52（纪念是激活，L1802-1810）
- 计算：命名簇与纪念概念共享"过去如何在场"的语义域。
- **涌现命题**：时代命名与纪念仪式是同一种操作（让过去以可行动的方式在场）在不同尺度上的执行。
- 应用：设计史中的"时代命名"与"博物馆纪念"可统一为"记忆工程"。

### W5 触手思维要求语言改造
- 路径：KE-13（触手思维，L503-506）→ KE-26（有界个体主义不可思想，L482-487）→ KE-47/48（词源学：kin 是动词、物质是母亲，L1609-1616）
- 计算：KE-13 反对点状思维，KE-47/48 证明语言本身携带点状/线状假设。
- **涌现命题**：若思想沿线展开，则语言必须被改造为线状语言（动词化、关系化、词根化）——这就是哈拉维造词行为的深层理由。
- 应用：术语工程/概念设计中"造词合法性"的理论依据。

### W6 亲缘设计是人口伦理的正面程序
- 路径：KE-09（制造亲缘，L1367）→ KE-55（三亲制，L1939-1940）→ KE-60（自愿人口下降，L1931-1933）
- 计算：KE-55 与 KE-60 是 KE-09 的两个出链，且互为条件（亲缘创新使人口下降不导致社会解体）。
- **涌现命题**：人口下降只有在"亲缘供给"充足时才公正——制造亲缘是人口伦理的正面程序，而非人口控制的反面禁令。
- 应用：人口政策分析引入"亲缘供给指数"。

### W7 世界游戏 = 原住民认识论 × 数字媒介
- 路径：KE-33（世界游戏，L1175-1195）→ 案例 Never Alone → KE-35（宇宙论表演，L1298-1299）
- 计算：两概念共享"以原住民世界观为操作系统的媒介"语义。
- **涌现命题**：数字游戏可以成为原住民宇宙论的"表演平台"，其关键是世界观即游戏规则，而非题材借用。
- 应用：游戏设计/数字人文的"世界观移植"方法。

### W8 避难所的多尺度性
- 路径：KE-34（避难所）→ KE-19（双重死亡）→ KE-58（水即亲缘，L2090）
- 计算：KE-34 的避难所（生态尺度）经 KE-19（关系尺度）延伸至 KE-58（政治尺度）。
- **涌现命题**：避难所是跨尺度的：生态避难所、关系避难所、政治避难所必须同时存在，缺一则双重死亡加速。
- 应用：生态保护评估增加"关系/政治避难所"维度。

## 三、强涌现命题（含分析者补入概念，标注【补】）

### S1 设计即响应能力的中介【补：中介者（mediator）】
- 路径：KE-10（响应能力，L452）→【补：设计物作为使能装置】→ KE-25（公民科学的人-非人合作，L381）
- **涌现命题**：设计物的本质功能是"使彼此有能力"（rendering capable）；设计 = 响应能力的中介工程。
- 证据支撑：PigeonBlog 背包使鸽子和市民同时有能力（L375-381）；DES 使兽医-狗-主人网络运转（L1408-1418）。
- 应用：设计理论的核心命题候选。

### S2 物种伴侣是"未完成的合约"【补：合约（contract）】
- 路径：KE-24（相互感染）→ KE-44（无清白）→ KE-23（差异中的响应能力，L477）
- **涌现命题**：人-非人共生关系是一种"永续再协商的合约"：感染是缔约，差异是条款，无清白是违约风险条款。
- 应用：人机关系/宠物伦理/农业伦理的合约论框架。

### S3 时代命名 = 集体心理治疗的处方【补：集体心理治疗（collective therapy）】
- 路径：KE-03/04/05（命名簇）→ KE-28（命名即政治）→ KE-01（与麻烦共存）
- **涌现命题**：命名行为的功能之一是给集体创伤（灭绝、殖民、气候）开出"可操作的诊断名"，使哀悼与行动成为可能。
- 应用：灾难研究、公共记忆研究中的"命名疗法"。

### S4 知识元的"词根簇"结构本身可复用【补：词根簇（root-cluster）】
- 路径：KE-47/48（词源学）→ KE-06/07/08（sym- 簇）→ KE-02/03/04/05（-cene 簇）
- **涌现命题**：本书的知识生产方式 = "选定词根 → 派生概念簇 → 用概念簇覆盖问题域"；此方法可独立于内容复用。
- 应用：概念工程方法论（见 04 报告）。

## 四、矛盾检测（张力命题）

### T1 命名多元 vs 命名权威
- KE-40（一个时代需要多个名字，L1350-1352）与 KE-28（命名即政治，命名者担责）之间的张力：多元命名稀释了责任归属，权威命名又垄断了叙事。
- 书中解决：以"集体创生"（Ethnos 对话，L2954-2962）与"自我标注"（拼写自省，L2228-2229）同时保持多元与责任。
- **张力命题**：命名伦理 = 多元命名 + 显式署名 + 集体生成。

### T2 人口下降 vs 生育自由
- KE-60（自愿人口下降）与 KE-39（生育自由）表面冲突；书中以"自愿/非强制 + 三亲制补偿"化解（L1931-1933、L3016-3023）。
- **张力命题**：人口伦理 = 以生育自由为前提的集体自愿约束 + 亲缘供给替代生育供给。

### T3 技术（DES/PigeonBlog）的双重性
- KE-42（药即毒）与 KE-25（技术使能）构成技术双重性：同一技术装置既是响应能力的中介，也是伤害的管道。
- **张力命题**：技术伦理 = 中介审计 + 伤害追溯（pharmakon 立场）。

### T4 故事的普遍主义 vs 语境的特殊性
- KE-54（每个故事都是一次拜访）与 KE-23（差异很重要）的张力：拜访要求进入他者语境，但任何故事都携带讲述者立场。
- **张力命题**：叙事伦理 = 以拜访姿态讲述 + 承认立场不可消除（situated stories）。

## 六、涌现结果的收敛建议

1. **优先级**：S1（设计即响应能力的中介）与 W3（部分复原 = 避难所-复苏闭环）为最高价值涌现，建议进入领域知识库主目录。
2. **验证**：S2（物种伴侣合约论）需在人与 AI 伴侣、宠物伦理文献中做同构性验证。
3. **风险**：W6 涉及人口议题，迁移时须保留"自愿/非强制"边界条件，避免工具化误读。
