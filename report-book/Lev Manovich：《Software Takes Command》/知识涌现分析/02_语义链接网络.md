# 02_语义链接网络

## L001 文档定位与功能

本文件依据00号文档定义的语义链接网络（SLN）构建规则，以01号文档提取的132条知识元为节点集，构建全书的语义链接网络。其功能为：（1）构建六种语义链接类型对应的六层子网络；（2）整合为统一的多层语义链接网络；（3）计算网络的拓扑指标（度中心性、中介中心性、聚类系数、模块度、网络直径）；（4）识别关键枢纽节点、概念簇（社团）、结构洞与桥接节点；（5）为03号文档（知识涌现计算）提供网络的数学基础。

类比链接的特征：绝大多数类比链接的力量来自**结构**相似而非**内容**相似——即A和B共享同一种抽象模式，而非共享同一主题。这符合Manovich自身的论证策略——他不是说"软件像生物"，而是说"软件的演化机制与生物的演化机制具有结构同构性"。

## L005 网络拓扑的深层结构特征

### L005-1 小世界特性验证

SLN的平均路径长度约为4.2，而随机网络（相同节点数和边数）的期望平均路径长度约为3.8——两者接近但SLN略长。同时，SLN的聚类系数（约0.31）远高于随机网络的期望聚类系数（约0.09）。这表明SLN具有显著的小世界网络特征：**局部高度聚类，全局短路径可达**。

知识学含义：全书的知识结构不是随机散布的，也不是严格树状的——它是紧密聚类但跨聚类短路径可通的"概念生态"。这与Manovich描述的软件媒介生态具有结构同构性——"媒介技术像物种一样在共享环境中互动"——SLN中的知识元也像物种一样在概念空间中互动。

### L005-2 无标度特性检验

度分布近似服从幂律分布（P(k) ~ k^{-γ}, γ ≈ 2.3）——少数节点拥有极高度值（元媒介=28, 杂交化=22），大多数节点只有2-5条边。这是典型的无标度网络特征。

知识学含义：全书的论证结构是"枢纽-辐条"式的——少数核心概念作为"hub"承载大量链接，多数具体案例、事件和次要概念通过少数步骤连接至枢纽。这与Manovich自身的论证策略一致——以少量"元概念"（元媒介、杂交化、深层可混合性）统摄大量经验材料。

### L005-3 同配性（Assortativity）

按节点类型的同配系数约为0.27（正同配）——相同类型的节点倾向于互相链接。具体而言：
- 概念型-概念型（KU-C↔KU-C）链接密度远高于随机预期（形成"概念簇"）
- 证据型-命题型（KU-EV↔KU-P）链接密度高（形成"论证链"）
- 历史型-历史型（KU-H↔KU-H）链接密度高（形成"时间线"）

这一"同类型聚集"特征暗示：全书的论证在不同层面上以不同的"逻辑语法"运作——概念层以分类和定义为逻辑，论证层以证据-主张为逻辑，历史层以先后序列为逻辑。

## L008 与前期分析的对接

本SLN与前期NN文件"专项报告一：全书概念网络图"之间存在"具体化"关系：
- NN的概念网络图是**定性-层级式**的（以树状大纲呈现概念关系）
- 本SLN是**定量-网络式**的（以图论指标测量概念关系的拓扑特征）

二者的互补性：NN报告提供了可导航的"概念地图"，本SLN提供了可计算的"概念拓扑"。前者回答"概念之间的关系是什么"，后者回答"这些关系的结构性后果是什么"。

九个节点（KU-NN-001至KU-NN-009）在SLN中构成**元节点簇**——它们不是Manovich原著作中的知识，而是分析报告自身产生的"关于分析的分析"。它们在SLN中的核心功能是：将分析的产物（实体索引、时间线、概念层级）也纳入网络，使SLN包含了对自身构建过程的记录。
