# Part4 Chapter 05：TEXTILES（纺织品）分析报告

## 一、章节定位与功能

**L001** 本章为Part Four专题短章，聚焦20世纪初工艺美术纺织品的演变——从Morris的花卉图案到欧洲大陆的现代主义抽象。

## 二、结构分析

**L002** 三层次：英国传统（Morris→Dearle→Voysey→Morton的Donegal地毯）→欧洲革新（Jugendstil→几何抽象→Wiener Werkstätte纺织品）→美国本土化（Candace Wheeler等）。

## 三、内容分析

**L003** 核心论题：纺织品设计在1900-1920年间经历了从"自然主义花卉"到"几何抽象"的急速转型——这一转变不是英国工艺美术运动内部发生的，而是由欧洲大陆（尤其是维也纳）和美国的新商业需求推动的。
