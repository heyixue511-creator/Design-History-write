# 00 方法与规则

本文档定义《系统之美：决策者的系统思考》（德内拉·梅多斯，中译本2012）知识涌现分析的层级、链接类型、指标与证据规范。

## 一、层级定义

- **知识元（Knowledge Element）**：六类实体（人物、著作/作品、概念、机构、地点、事件）中最小的语义单元。本书以**概念类知识元**为主（系统、存量、流量、反馈回路、适应力、基模、杠杆点等），辅以人物、著作、机构、地点、事件。
- **Topic（强连通簇）**：通过语义链接紧密相连的知识元集合，内部强连通（任意两个知识元之间可经由链接互相到达），构成书中的一个论题单元。
- **Theme（高层语义域）**：多个相关 Topic 聚合而成的高层语义域，对应本书的核心世界观命题。

## 二、9种语义链接判定标准

| 类型 | 符号 | 判据 | 本书实例 |
| --- | --- | --- | --- |
| 因果 | → | A的存在/变化导致B；文本明确"导致""使""因为" | 时间延迟→振荡（L140）；资源耗尽→资本崩溃（L159） |
| 条件 | ⇒ | A是B发生的条件或前提；"如果……就" | 如果流入>流出⇒存量上升（L58） |
| 对比 | ↔ | A与B对立/互补/差异对照 | 调节回路↔增强回路（L84）；系统思考↔还原论（L18） |
| 隶属 | ⊂ | A是B的组成部分/类别/子类 | 调节回路⊂反馈回路（L73）；公地悲剧⊂系统基模（L277） |
| 时序 | ≻ | A先于B发生；历史顺序 | 感知延迟≻反应延迟≻交货延迟（L134） |
| 空间共现 | ≈ | A与B在同一场景/系统中并存 | 石油储量≈石油经济（L159）；鱼群≈渔船资本（L168） |
| 属性 | : | A具有属性B | 增强回路：自我强化（L90）；存量：变化缓慢（L61） |
| 论证支撑 | ⇐ | A是B的论据/例证/支撑 | 荷兰电表⇐信息流杠杆点（L360）；人口模型⇐情景测试法（L120） |
| 同域 | ∼ | A与B属于同一讨论领域但无强因果 | 政策阻力∼公地悲剧（同为系统陷阱） |

## 三、涌现指标

- **节点度 k**：某知识元与其他知识元的直接链接数。高 k 者为网络枢纽（如系统、反馈回路、存量、流量、杠杆点）。
- **桥接值 b**：某知识元连接不同 Topic/Theme 的链接数，衡量跨域中介作用（如"有限理性"连接经济学与系统结构，"范式"连接认识论与变革）。
- **簇识别（强连通）**：基于链接方向形成强连通分量；本书多数链接为双向论证型，可放宽为无向连通簇。
- **内聚度**：簇内链接数 / 簇内节点数。簇内互引越密，内聚度越高。
- **涌现强度 S**：S = 内聚度 × 簇规模（节点数）的归一化值，或按簇内链接密度与跨簇桥接占比综合评定，用于排序 Topic/Theme。
- **一级涌现**：知识元 → Topic 的涌现（若干知识元链接成论题）。
- **二级涌现**：Topic → Theme 的涌现（若干 Topic 聚合为高层语义域，并形成全书性命题）。

## 四、证据规范

- 每条链接、每个簇、每个命题必须附 clean 版行号（L###）证据；
- 行号必须与文本实际内容对应，不得编造；
- 对"点到未论"的潜在链接（书中暗示但未展开）单列并标注证据缺口；
- 客观性核对：对可能的反例、边界情况如实说明。
