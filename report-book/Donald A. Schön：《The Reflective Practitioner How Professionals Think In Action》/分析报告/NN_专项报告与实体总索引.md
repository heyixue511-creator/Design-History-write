## NN-1 专项报告一：全书概念体系的结构分析

### NN-1-1 概念层级

舍恩的概念体系可划分为四个层级：

**层级一：核心概念（全书定义性概念）**
- Reflection-in-Action / Knowing-in-Action
- Reflective Conversation with the Situation
- Problem Setting / Problem Solving
- Back-talk
- Frame Experiment

**层级二：操作性概念（用于分析实践过程的工具概念）**
- Seeing-as / Doing-as
- Generative Metaphor
- Virtual World
- Repertoire / Exemplar
- Double Vision
- Naming and Framing

**层级三：评价性与批判性概念**
- Technical Rationality
- Rigor or Relevance Dilemma
- High Ground / Swampy Lowland
- Mystery and Mastery
- Positivist Epistemology of Practice

**层级四：制度性概念（指向社会推论的规范性概念）**
- Model I / Model II
- Organizational Learning System
- Primary Inhibitory Loop
- Reflective Contract
- Action Science
- Appreciative System
- Overarching Theory

### NN-1-2 概念之间的派生关系

```
Positivism → Technical Rationality → Rigor/Relevance Dilemma
                                         ↓
Polanyi/Ryle → Knowing-in-Action → Surprise → Reflection-in-Action
                                              ↓
Kuhn → Seeing-as / Generative Metaphor → Frame Experiment
                                              ↓
Dewey → Transaction with the Situation → Back-talk → Reflective Conversation
                                              ↓
Vickers → Appreciative System → Evaluation of Frame Experiments
                                              ↓
Argyris → Model I → Limits to Reflection → Model II → Reflective Contract
                    → Organizational Learning System → Action Science
```

## NN-4 专项报告三：全书论证策略与修辞技术

### NN-4-1 主要的论证策略

| 策略 | 操作方式 | 典型案例 |
|------|----------|----------|
| 去自然化（Denaturalization） | 通过历史/制度溯源展示"理所当然"之物的偶然性 | 技术理性→实证主义谱系(Ch2) |
| 极端对比（Maximal Contrast） | 选取两个最不相像的案例来证明底层统一性 | 建筑vs心理治疗(Ch3-5) |
| 案例驱动理论化（Case-Driven Theorizing） | 分析范畴从案例材料的编码中浮现 | 12个设计域从Quist协议中归纳(Ch3) |
| 操作性定义（Operational Definition） | 将抽象概念转化为可观察的行为指标 | "frame experiment"=Quist在描图纸上覆盖并重绘(Ch3) |
| 否定检验（Negative Testing） | 在最不利于理论的案例中寻找理论的运作 | 工程/科学领域中的行动中反映(Ch6) |
| 两难聚焦（Dilemma Focus） | 将抽象认识论问题转化为每个实务者都能感受的生存性困境 | "严谨性vs相关性"的两难(Ch2) |
| 双重批判（Double Critique） | 同时在两条战线上论辩以定位替代方案的独特性 | 技术理性主义+激进批判主义(Ch10) |
| 自我指涉（Self-Reference） | 将自身的理论建构过程也纳入理论的分析范围 | 对积木实验分析的自反性注释(Ch2, Ch5) |
| 权威转借（Authority Transfer） | 借用已有学科的理论权威来支撑新概念 | Kuhn→seeing-as, Ryle→knowing how |

### NN-4-2 关键的修辞技术

| 技术 | 功能 | 经典实例 |
|------|------|----------|
| 核心隐喻 | 使抽象概念可感知 | "高地/沼泽"、"与情境的对话"、"回话" |
| 叙事张力 | 通过将读者置于"卡住"的情境中制造智识焦虑 | Petra的困境→"but the shape doesn't fit" |
| 转录展示 | 通过呈现完整对话（而非摘要）为读者提供自已做出判断的材料 | Quist评审协议全文 |
| 专家vs实用者对照表 | 以视觉对比浓缩论证 | Expert vs Reflective Practitioner三行表(Ch10) |
| 当事人声音 | 以非专业者的朴素语言为理论提供经验锚定 | Aida学生日记、住院医师的回忆 |
| 概念倍增 | 通过创造新的技术术语来重塑专业话语 | 贯穿全书（见概念总索引38个条目） |
