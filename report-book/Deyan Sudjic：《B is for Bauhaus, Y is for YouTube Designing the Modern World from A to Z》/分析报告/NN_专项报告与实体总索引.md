# NN 专项报告与实体总索引

## 专项报告一：全书论证策略与叙事模式分析

### L### 论证结构类型学

Sudjic在本书中使用了六种基本的论证结构：

1. **同心圆式**（A-Authentic）：从个人经验→概念定义→跨域案例→回到概念
2. **对比式**（H-Habitat; X-Xerox）：两个对象平行比较，差异性揭示本质
3. **人物传记式**（K-Kaplický; S-Sottsass; U-Utzon）：个人生平折射时代
4. **自传式**（F-Fashion; N-National Identity; Q-QWERTY）：个人经验作为分析资料
5. **历史谱系式**（B-Bauhaus; P-Postmodern; F-Function）：追踪概念/运动的演变
6. **理论论辩式**（C-Critical Design; I-Imperfect; O-Ornament）：介入学术论争

### L### 叙事模式

- **第一人称入场**：几乎每个章节都以"I..."开始
- **案例密度递增**：前半部分重个人，后半部分重历史/制度
- **开放式结尾**：极少章节有封闭结论，多以反问或展望收束
- **反讽距离**：对自身立场保持一定的审视距离

## 专项报告二：全书跨章主题网络

### L### 五大主题轴

**轴一：本真性（Authenticity）的追问**
核心章：A → 关联章：C-Collecting, C-Critical Design, I-Imperfect, O-Ornament, Z-Zip, D-Design Art

**轴二：现代主义的兴衰**
核心章：B-Bauhaus, F-Function, P-Postmodern → 关联章：M-Manifesto, R-Rams, K-Krier, V-Vienna

**轴三：设计作为个人/集体身份的制造**
核心章：F-Fashion, N-National Identity, T-Taste → 关联章：L-Logo, H-Habitat, K-Kitchen

**轴四：设计的物质基础与数字转型**
核心章：C-Car, C-Chair, Q-QWERTY, Y-YouTube → 关联章：G-Grand Theft Auto, X-Xerox, F-Function

**轴五：设计师的生存策略**
核心章：B-Blueprint, D-Design Art, C-Critical Design → 关联章：K-Kaplický, S-Sottsass, U-Utzon, J-Jim Nature

## 专项报告三：Sudjic的知识网络与立场分析

### L### 知识导师与影响来源
- **Reyner Banham**——设计批评的方法论范式
- **Nikolaus Pevsner**——现代主义史学的标准叙事（被Sudjic部分接受、部分批判）
- **Roland Barthes**——符号学视角（多次引用，尤其在C-Car和J-Jumbo章）
- **Walter Benjamin**——收藏/本真性/机械复制理论（在A/Authentic和C/Collecting中）
- **Jane Jacobs**——城市研究（在S/Slum中）

### L### Sudjic的立场
- **非教条的现代主义者**：承认现代主义的成就但不崇拜
- **经验主义的批评家**：以第一手观察和交往为基础
- **体制内批判者**：在博物馆/媒体体制内运作，但保持批判距离
- **跨大西洋视角**：伦敦-米兰-纽约的三角文化视野
- **巴尔干遗产**：家族移民经历给予他对"身份"问题的特殊敏感性
