# 00_方法与规则：知识涌现分析框架

## L### 一、分析目标与定位

本分析旨在从《Designing for People》（1967）全书的分析报告中提取知识元（Knowledge Units），构建语义链接网络（Semantic Link Network），并通过涌现计算识别跨章节的知识涌现现象——即在单个知识元层面不可见的、仅当多元语义链接交叠互动时才呈现的"新知识模式"。

本分析不是对原书内容的第四次重复叙述（第一次=原书、第二次=分章分析、第三次=整体分析报告），而是在"元层"上对设计知识的底层结构进行建模和计算。

## L### 二、知识元（Knowledge Unit）定义

### L### 2.1 核心定义

知识元是设计知识的最小可独立表达单元。在本分析中，一个知识元 = 一个具有独立语义边界的设计主张、设计原则、设计发现或设计事实，满足以下四个条件：

1. **可独立陈述性**：该知识元可以独立于上下文被陈述为一句有意义的命题。
2. **可引用性**：该知识元可以被其他知识元引用、支撑、反驳或延伸。
3. **元属性完备**：该知识元至少携带"来源章节"、"实体类别"和"语义域"三个元属性。
4. **不可再分性**：若进一步分割则该命题丧失完整意义。

### L### 2.2 知识元五元组模型

每个知识元采用五元组表示法：

```
KU = (id, P, S, C, T)

其中：
id  = 知识元唯一标识符
P   = 命题内容（Proposition）：以中文+关键英文术语表述的设计知识断言
S   = 来源（Source）：原书章节编号 + 分析报告文件路径
C   = 类别（Category）：设计原理 | 方法工具 | 实体事实 | 历史事件 | 批判反思 | 预测洞察
T   = 标签（Tags）：自由标签集，用于跨域聚合
```

### L### 2.3 类别体系（C）详表

| 类别码 | 类别名称 | 定义 | 典型示例 |
|--------|---------|------|---------|
| PRIN | 设计原理 | 普适性的设计主张或价值判断 | "由内而外"原则、"设计应当一目了然" |
| METH | 方法工具 | 可操作的设计方法、工具、流程 | Joe & Josephine人体测量系统、五点评分公式 |
| FACT | 实体事实 | 人、物、组织、地点、事件的具体陈述 | "Bell Labs自1930年起与Dreyfuss合作" |
| HIST | 历史事件 | 有时间锚定的设计史事件 | "1929年Dreyfuss在580 Fifth Avenue开设办公室" |
| CRIT | 批判反思 | 对设计现象的批判性分析 | "流线型风潮是对功能主义的偏离" |
| FORC | 预测洞察 | 面向未来的设计预测或技术预见 | "磁悬浮列车将在未来实现" |

### L### 2.4 语义域体系（D）

每个知识元归属于一个或多个语义域：

| 域码 | 语义域 | 覆盖范围 |
|------|--------|---------|
| D_ANTH | 人类学域 | 人体测量、感知心理、用户行为、文化习俗 |
| D_MECH | 机械工程域 | 结构、材料、生产工艺、力学 |
| D_AEST | 审美域 | 形式、色彩、比例、风格、品味 |
| D_ECON | 经济域 | 成本、市场、定价、收费、商业逻辑 |
| D_SOCI | 社会域 | 民主化、组织关系、阶级品味、公众教育 |
| D_HIST | 历史域 | 设计谱系、先例、传统、时间演化 |
| D_ETHI | 伦理域 | 设计师责任、诚信、价值判断、失败认知 |
| D_COGN | 认知域 | 心理模型、affordance、直觉、学习曲线 |
| D_FUTR | 未来域 | 预测、技术预见、乌托邦/反乌托邦想象 |

## L### 三、语义链接（Semantic Link）定义

### L### 3.1 链接类型体系

语义链接是连接两个知识元的、具有方向性和语义类型的边。本分析定义九种基础链接类型：

| 链接类型 | 符号 | 方向 | 语义定义 | 示例 |
|---------|------|------|---------|------|
| 支撑（Supports） | →sup | A→sup→B | A为B提供经验证据或逻辑支撑 | 熨斗案例 →sup→ "机器应适配人体" |
| 例示（Instantiates） | →ins | A→ins→B | A是B原则的具体案例实现 | 500型电话 →ins→ "由内而外"原则 |
| 延伸（Extends） | →ext | A→ext→B | A将B的原则拓展至新领域 | 假肢触觉迁移 →ext→ "人体对工具的可适应性" |
| 反驳（Contradicts） | →cnt | A→cnt→B | A与B存在逻辑或经验冲突 | Chrysler Airflow →cnt→ "市场决定好设计" |
| 前提（Presupposes） | →pre | A→pre→B | A的逻辑成立依赖于B的先行成立 | "百分位覆盖" →pre→ "极端值而非平均值" |
| 类比（AnalogousTo） | →ana | A→ana→B | A与B在结构或逻辑上相似但属不同域 | "舞台设计开幕夜" →ana→ "产品交付截止日" |
| 转化（Operationalizes） | →opr | A→opr→B | A将B从抽象原则转化为操作工具 | Joe & Josephine图表 →opr→ "人为尺度"理念 |
| 归因（AttributesTo） | →atr | A→atr→B | A将某一现象的原因归于B | "打字机眩光头痛" →atr→ "黑色亮漆反射" |
| 时序（Precedes） | →seq | A→seq→B | A在时间上先于B，且存在因果或演化关系 | "1929年开业" →seq→ "五点评分公式成熟" |

### L### 3.2 链接强度定义

每条语义链接附带一个 [0,1] 区间内的链接强度 s：

- s = 0.9–1.0：显式直接链接（原文明确陈述A与B的关系）
- s = 0.7–0.9：强隐式链接（原文未明说，但单一推理步骤即可导出）
- s = 0.5–0.7：弱隐式链接（需要两步以上推理或跨章节综合）
- s = 0.3–0.5：推测性链接（基于分析者的跨文本解读）
- s < 0.3：不纳入核心网络

## L### 四、知识涌现（Knowledge Emergence）定义与计算规则

### L### 4.1 涌现的操作化定义

知识涌现被操作化定义为：在语义链接网络中存在一个子图模式（emergent subgraph pattern），该模式满足以下三个条件：

1. **新颖性条件（Novelty）**：该子图所表达的命题P_E，不在原书任何单一知识元中显式出现，也不在分章分析报告中独立归纳。
2. **结构性条件（Structurality）**：P_E由至少三个来自不同语义域的知识元经至少两种不同类型的语义链接共同构成。
3. **可验证性条件（Verifiability）**：P_E可以通过引用至少两个独立知识元及其链接来被"证明"——即存在一个可追溯的证据链。

### L### 4.2 涌现强度公式

```
E(KU_group) = N_novelty × D_diversity × L_density × C_coherence

其中：
N_novelty  = 1 − max(KU_i在原书中的自明性)，取 [0,1]
D_diversity = 参与知识元的语义域种类数 / 语义域总数（9），取 (0,1]
L_density   = 实际链接数 / 可能最大链接数（n×(n-1)），取 (0,1]
C_coherence = 1 − (矛盾链接对数 / 总链接对数)，取 [0,1]
```

涌现强度E≥0.5被认定为"显著涌现"，E≥0.3被认定为"弱涌现"。

### L### 4.3 涌现模式分类

| 模式类型 | 定义 | 认知特征 |
|---------|------|---------|
| 桥接涌现（Bridge） | 来自不同域的知识元因共享相同结构而连接 | "A在X域的行为逻辑与B在Y域的行为逻辑同构" |
| 矛盾涌现（Paradox） | 两个或多个知识元共同揭示一个未被表述的矛盾 | "A主张X，B主张Y，且X∧Y蕴含紧张关系" |
| 缺失涌现（Lacuna） | 知识元的分布模式揭示一个系统性空白 | "所有已知X类知识元都涉及A领域，但完全缺失B领域" |
| 递归涌现（Recursion） | 一个知识模式在不同层级上重复出现 | "微观层面的X原则与宏观层面的Y结构递归同构" |
| 逆转涌现（Inversion） | 知识链接网络揭示一个反向因果链 | "通常认为A导致B，但网络揭示B实际上导致了A" |

## L### 五、分析流程规则

### L### 5.1 源材料范围

本分析的知识元提取源材料包括：

1. 分章分析报告（导言+18章，共19个分析文件）
2. 整体分析报告（00_整体分析报告.md）
3. 专项报告与实体总索引（NN_专项报告与实体总索引.md）
4. 原书章节文本（_chapters/目录下的22个txt文件）

共19+2+22=43个源文件。

### L### 5.2 分析步骤

步骤一：知识元提取与归一化
- 从源材料中识别并编码知识元
- 以五元组形式归一化存储
- 去重与合并等价知识元

步骤二：语义域标注与分类
- 为每个知识元标注语义域（可多域）
- 按类别体系分类
- 计算跨域分布统计

步骤三：语义链接识别
- 识别知识元间的九类语义链接
- 评定每条链接的强度 s
- 构建有向加权语义链接网络

步骤四：涌现子图检索
- 应用涌现三条件扫描网络
- 计算涌现强度E
- 识别涌现模式类型

步骤五：知识发现综合
- 将涌现子图"翻译"为自然语言知识发现
- 按涌现强度排序
- 撰写知识发现报告

### L### 5.3 质量保证规则

1. **可追溯性规则**：每一知识发现必须标注其所依赖的知识元ID和语义链接ID。
2. **最小惊奇度规则**：若某发现已在分析报告中显式陈述，则不作为"涌现"报告。
3. **多路径验证规则**：高涌现强度（E≥0.7）的发现应至少有两条独立的证据路径。
4. **反常识优先规则**：与设计常识相悖的发现（矛盾涌现、逆转涌现）具有更高的报告优先级。

## L### 六、输出格式约定

### L### 6.1 知识元编码格式

知识元ID编码：`KU_{章节码}_{序号}`

示例：
- `KU_00_001`：导言中提取的第1个知识元
- `KU_02_015`：第2章中提取的第15个知识元
- `KU_OV_001`：整体分析报告中提取的第1个知识元（OV=Overall）
- `KU_SP_001`：专项报告与实体总索引中提取的第1个知识元（SP=Special）

### L### 6.2 语义链接编码格式

语义链接ID编码：`SL_{源KU_ID}_{目标KU_ID}_{类型码}`

示例：
- `SL_KU02_001_KU01_003_sup`：从KU_02_001到KU_01_003的支撑链接

### L### 6.3 涌现发现编码格式

涌现发现ID编码：`EM_{序号}_{模式类型码}`

示例：
- `EM_001_bridge`：第1号涌现发现，桥接模式
- `EM_007_paradox`：第7号涌现发现，矛盾模式
