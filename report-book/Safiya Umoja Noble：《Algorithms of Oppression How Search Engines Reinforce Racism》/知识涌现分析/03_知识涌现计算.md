## 四、一级涌现结构（E1…En）

**定义**：两个以上知识元直接链接生成的结构性涌现。本书的主要一级涌现结构：

- **E1 商业偏见引擎**：Google + 广告 + PageRank/SEO → "搜索结果=广告利益"（L321、L358）。
- **E2 身份色情化机制**：色情化 + "black girls" + Jezebel 原型 → "身份词被劫持"（L576-582、L645-647）。
- **E3 分类权力机制**：LCSH/DDC + 分类=社会建构 + 搜索引擎 → "分类即权力"（L900-908、L929）。
- **E4 记录-遗忘张力**：被遗忘权 + 记录=权力 + 社会遗忘 → "记忆与遗忘是权利斗争"（L773、L791、L799）。
- **E5 意识形态遮蔽机制**：新自由主义 + 色盲 + 数字鸿沟 → "叙事掩盖结构"（L1013-1019、L1043-1045）。
- **E6 认知-暴力通路**：搜索 + 掩蔽网站 + Roof → "搜索塑造行为"（L731-763，作者已限定因果强度）。
- **E7 数据-劳动复合体**：prosumer + 受众商品 + coltan → "用户即商品、全球劳动被剥削"（L1021、L1029-1031）。
- **E8 理论透镜**：黑人女性主义 + 交叉性 + CRT + BFTS → "批判信息研究"（L1057、L894）。

## 五、二级涌现命题（P1…Pn，附生成机制与强度）

**定义**：多个一级涌现结构复合、跨主题综合生成的命题性涌现。

- **P1 算法压迫总命题**：E1+E2+E5 → "商业算法在新自由主义框架下系统再生产种族与性别压迫"（L151、L1053）。生成机制：概念命名 + 机制链接 + 意识形态背景；强度 5。
- **P2 技术非中立命题**：E1+E3 → "技术（搜索、分类、算法）不是中立的，而是价值与权力负载"（L721、L929、L949）。强度 5。
- **P3 分类即政治的延续命题**：E3+E4 → "从图书馆分类到网络索引，命名与排序始终是权力斗争场域"（L874、L929）。强度 4。
- **P4 信息民主危机命题**：E1+E5+E7 → "信息垄断 + 私有化 + 用户商品化侵蚀民主所需的信息公共性"（L981-999、L1037、L139）。强度 4。
- **P5 制度规制的必要性命题**：E4+E6+E7 → "从被遗忘权到反垄断再到监管，需要以研究为基础的公共政策"（L862、L1003-1009、L1039）。强度 4。
- **P6 抵抗与替代命题**：E8 + 公共搜索设想 → "需要公共非商业搜索、信息学科批判与集体行动"（L977、L1137-1148、L1037）。强度 3。
- **P7 交叉性方法命题**：E8 → "以黑人女性主义视角问出不同的问题，才能看见算法压迫"（L281-285、L1057）。强度 3。

**生成机制总结**：P1 由 E1+E2+E5 复合而成（命名 + 机制 + 背景）；P2-P4 由两个以上机制簇复合；P5-P7 由后果簇与方案簇复合。强度 = 参与的一级结构数量 × 跨 Theme 数量 × 证据密度。

## 六、客观性核对与反例

1. **反例 1（P6 的脆弱性）**：作者承认"在一个公然支持白人至上主义与虚假信息的政府执政期，公共搜索替代方案可能不可行"（L1178）——P6 强度应下调至 3。
2. **反例 2（E6 的因果限定）**：作者明言"不能在搜索结果与谋杀之间画直线"（L763）——E6 的因果方向是作者自述+推断，非确证。
3. **反例 3（P1 的时空限定）**：作者自认"关于算法/谷歌的书出版即过时"（L175），且 2012 年 Panda 更新后"black girls"色情首屏消失（L149、L687）——P1 的普遍性受时间性约束。
4. **反例 4（E5 的过度聚合风险）**：色盲/新自由主义被用于解释过多议题，存在"解释一切则解释不了任何具体问题"的方法论风险；作者用大量具体证据部分缓解了该风险，但网络层面仍显辐合过强。
5. **反例 5（E4 的张力未被解决）**：作者并列"需要记忆责任"与"需要遗忘权利"（L831），但未给出二者边界的明确判据——命题内部存在未解决的规范张力。

**结论**：网络整体涌现强度高（多枢纽、多簇、多 Theme 复合），P1、P2 为最强二级涌现命题；P5、P6 为政策向命题，受现实政治与时间性约束而强度略降。
