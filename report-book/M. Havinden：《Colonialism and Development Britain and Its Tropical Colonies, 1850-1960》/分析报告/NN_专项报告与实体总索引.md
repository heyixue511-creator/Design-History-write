## NN01_概念演变轨迹专项报告

本报告追踪全书六个核心概念在13章中的演变轨迹。

### 概念一："发展"（Development）的定义演变

| 章节 | 阶段 | 定义特征 |
|------|------|----------|
| Ch1 | 概念提出 | 多维定义：人均GNP增长+生活水平+社会文化机会+教育/健康/娱乐获取；警告GNP/GNI测量不适于生存经济 |
| Ch2 | 隐含应用 | 发展还未成为明确的分析概念——基本问题是"是否保留殖民地" |
| Ch3 | 初始理论化 | 曼彻斯特学派"自由贸易即发展"理论：贸易扩展→经济活跃化→分工→税收收入→公共工程 |
| Ch4 | 政策操作化 | Chamberlain模式：国家提供基础设施+私人资本执行=发展 |
| Ch5 | 实证检验 | 量化指标：贸易增长=发展代理指标；"初始基础设施效应"的警告 |
| Ch6-7 | 断裂与反思 | 战争暴露贸易依赖型"发展"的脆弱性；"托管"加入道德维度 |
| Ch8 | 幻灭 | 大萧条的打击→"发展"的失败暴露——几十年殖民发展未减少单一依赖 |
| Ch9 | 范式扩展 | "发展"被配以"福利"（Welfare）→社会服务纳入 |
| Ch10-11 | 制度高峰与危机 | 战后全面制度化→融资困境暴露结构性限制 |
| Ch12 | 实践崩溃 | 国家直接生产的雄心→大型项目失败→"发展"的执行远落后于计划 |
| Ch13 | 最终评估 | 发展遗产：基础设施（有）vs工业化（无）vs社会服务（太晚太少） |

### 概念二：自由贸易意识形态 → 帝国特惠制

Ch3：Palmerston"天意"说（1842）→ Ch4：争夺中帝国主义→ Ch9：自由贸易终结（1932年2月10%进口税）→ Ottawa帝国特惠制→"对殖民地利益微不足道"

### 概念三：Laissez-faire → Constructive imperialism → State as producer

Ch3：曼彻斯特学派自由放任→ Ch4：Chamberlain建设性帝国主义（国家+私人资本）→ Ch10/12：国家直接生产（OFC, CDC）→"Chamberlain观点的胜利"

### 概念四："托管"（Trusteeship/Dual Mandate）

Ch6：委任统治地体系→ Ch7：Lugard《双重托管》（1922）→"托管经济学的微薄性"→ Ch9：从"托管"到"发展/福利"→ Ch11/13：遗产评估

### 概念五：贸易依赖与结构性锁定

Ch2：单一商品依赖起源→ Ch5：依赖在繁荣中固化→ Ch8 Table 8.9：35年趋势——依赖加深→ Ch11：1950年代持续依赖→ Ch13：独立时继承的结构

### 概念六：计划-执行鸿沟（Plan-Performance Gap）

Ch1核心论点提出→ Ch5早期显露→ Ch8大萧条中放大→ Ch11-12战后最戏剧化表现（花生计划）→ Ch13最终确认
