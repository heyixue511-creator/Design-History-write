# 15 章节分析报告：书籍网格（Grids for Books）

## 一、章节定位与功能

本章将网格原理从信纸这一单页媒介**扩展到书籍这一多页序列媒介**。书籍网格的设计需要考虑封面到封底的全程一致性，以及图像与文字的比例协调。

## 三、内容分析

### L1 核心论题

**书籍网格提供从封面到封底的结构与连续性。书籍尺寸应由内容决定——"内容决定容器"。网格应与大多数图像的原始比例相协调，以减少不必要的裁切。当字体和插图遵循同一网格时——即文字的特定行距与插图模块对齐——能产生"巨大的细节优雅"。**

### L2 关键论点

| 论点 | 原文依据 |
|------|---------|
| 内容决定容器——方形图片→方形书籍；矩形图片→矩形或横长形书籍 | "The content determines the container - a basic truth also in book design." |
| 网格比例应与多数图片比例相关以减少裁切 | "It is a good practice to relate the grid to the proportion of the majority of pictures" |
| 文字行距与插图模块一致="细节优雅" | "a specific leading should be determined for the type area of each module with the illustration modules coinciding. This gives great elegance of detail" |
| 列与模块之间的间距宜紧——理想为一行文字的尺寸 | "keep the space between the columns and the modules rather tight - ideally the size of a line of type" |
| 计算机在网格定义上比以往精确得多 | "One of the great advantages of the computer is in the definition of the grid which can be achieved in a very precise way" |

## 七、语言文风
