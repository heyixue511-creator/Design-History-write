# 第一部分 专项报告

## 一、语言特征

1. **体例化、非句法化语言**：全文无完整陈述句，条目一律为"人名 + 任期 + 机构/头衔"的名词性并列短语，如 "Bruce Brown 2006-present"（L1）、"Craig Adcock, Director 2004–2011 University of Iowa"（L5）。语言功能是**指称与登记**，而非叙述或说服。
2. **术语系统二分**：
   - 编辑制度术语（期刊运营）：Editors、Guest Editors、Book Review Editors、Associate Book Review Editors、Associate Editor for Reviews、Associate Editor for Archives、Managing Editors、Editorial Assistants、Editorial Board（L1、L5）；
   - 学术身份术语：Professor Emeritus、Director Emerita、Director（L2、L5）。
3. **时间标记语言**：以年份区间（"2004–2011"，L2）与 "present"（L1、L5、L6、L7）构成任期语义；单年（"2004"，L1、L3）表示仅有该年任期。
4. **专名密集**：人名（约 66 人）、机构名（约 37 个）、地名（约 20 处）密度极高，是全文信息主体；专名均保留原文，无翻译痕迹。

## 二、文风特征

- **公文/档案体**：客观、中性、无评价性形容词；唯一带注释色彩的是 "Paul Stiff (d. February 12, 2011)"（L6 / pL87），以括注方式记录逝者，兼具档案精确性与纪念性。
- **均质化排列**：各条目长度、结构高度一致，形成可扫描的名单节奏；无段落过渡句。
- **符号简约**：仅用连字符（–）、括注（( )）与 "present" 三种标记完成全部语义负载。

## 三、修辞方式

1. **无显性修辞**：无比喻、无排比、无反问；这是名录文体的根本特征。
2. **隐性修辞——名单的象征资本（ethos 式说服）**：通过列举 Arnheim、Maldonado、Bonsiepe、Spiekermann、van Toorn 等权威姓名（L2–L3），以"谁在列"本身向读者传递期刊的学术声望与合法性。
3. **制度修辞——任期连续性**：执行编辑 "2004–2008 / 2008–2011 / 2011–present" 的无缝衔接（L1）以并置结构暗示治理稳定。
4. **记忆修辞**：对逝者 Stiff 的卒日标注（L6）使名录兼有纪念碑功能。

## 四、史料使用方式

1. **文本即史料**：本文不引用任何史料，其自身就是期刊制度史的一手档案（刊头页）。
2. **结构化记录**：以"职务分类表 + 任期 + 机构"的方式保存人事信息，信息粒度达到"人—岗—年—机构"四元，可直接支持历史编纂与网络分析。
3. **时间覆盖策略**：标题 "Editors (2004-2013)"（L2 / pL3）框定十年窗口，同时保留 1984/1993 起始任期（L1），实现"窗口内记录 + 窗口外溯源"的双层时间结构。

## 五、阐述方法

- **列举法**：全文以列举为唯一阐述手段，按职务层级（决策→专项→运营→事务）与任期批次（2004、2011、2013 三个组建时点）组织。
- **对照法（隐含）**：顾问段（2004–2011，L2–L3）与编委会扩容（2011–present，L5）的时间咬合，隐含"制度模式转换"的对照叙事，但文本不作明示。
- **权威宣告法**：以官方刊头格式发布，无需论证即生效。

## 六、推演逻辑

本文无命题推演；若将其视为"制度状态描述"，可还原其信息逻辑：

1. **分类逻辑**：职务类别（Editors → Guest Editors → Book Review → Managing → Assistant）自上而下演绎分工（L1）；
2. **时序逻辑**：任期区间首尾相接（2004–2008 → 2008–2011 → 2011–present，L1），可由之归纳"岗位传承无空窗"；
3. **归属逻辑**：人—机构—地点三元绑定（如 "Gui Bonsiepe / Florianopolis, Brazil"，L2），可由之归纳地域分布与机构集中度。

## 七、文字风格总结

档案式、均质化、零修辞、术语稳定、信息冗余度极低。全文 7 行（clean 版）以最小文字量完成 60+ 人的人事登记，是"去文学化写作"的极端样例；其风格价值在于**可核验性**与**可检索性**。
