# 00 方法与规则（知识涌现分析）

> 适用范围：论文《Editors (2004-2013)》（Design Issues，2014，刊头名录页）。证据基准：`00-paper_clean\Design Issues：Editors (2004-2013), 2014_paged_clean.md` 行号 L1–L7；括注 pL### 为源文件行号。

## 一、层级定义

| 层级 | 定义 | 本文中的实例 |
| --- | --- | --- |
| **知识元（Entity）** | 六类实体：人物、著作/作品、概念、机构、地点、事件 | Victor Margolin（人物，L1）；Carnegie Mellon University（机构，L2、L5）；Editorial Board（概念，L5）；Beijing（地点，L5）；Paul Stiff 逝世（事件，L6） |
| **Topic（主题簇）** | 知识元之间通过强连通语义链接形成的簇（强连通分量），6–15 个 | 如"Carnegie Mellon 机构簇"、"中国设计教育簇"、"主编代际簇" |
| **Theme（高层语义域）** | 3–5 个 Topic 聚合而成的高层语义域，由共享/桥接知识元联结 | 如"编辑治理结构域"、"全球学术网络域" |

## 三、涌现指标

| 指标 | 定义 | 本文取值方式 |
| --- | --- | --- |
| 节点度 k | 知识元直接链接数（人—机构、人—任期、人—角色各计 1） | 对六类实体逐一统计；机构 k = 关联人数，人物 k = 角色数+机构+任期数 |
| 桥接值 b | 知识元连接不同 Topic/簇的链接数；b≥2 视为桥接元 | 如 Richard Buchanan（连接主编簇、客座簇）、Frascara/Grefé（连接顾问簇与编委会簇） |
| 簇识别 | 强连通分量：簇内任意两元经双向/传递可达（本名录中按共享机构/共享角色/共享任期批次聚类） | 机构簇、职务簇、任期批次簇、地域簇 |
| 内聚度 | 簇内链接数 / 簇内节点对总数（完全图=1） | 各簇分别计算并注明近似性 |
| 涌现强度 S | S = 簇内链接数 × 桥接元数 / 节点数（相对值，用于排序比较） | 相对排序，不虚构精确数值 |
| 一级涌现（E） | 直接由知识元链接形成的结构（簇、枢纽） | E1 主编代际结构；E2 Carnegie Mellon 枢纽簇；E3 顾问→编委会承接等 |
| 二级涌现（P） | 由一级结构跨簇综合生成的命题，需明确生成机制 | P1 治理双核（创始核心+新网络）；P2 机构母港效应；P3 国际化批次等 |

## 四、证据规范

1. 每个知识元、每条链接、每个簇、每条命题均须附 clean 版行号（L###）；必要时括注源文件行号（pL###）。
2. 链接类型判定须与第二节标准一一对应；无法判定类型时不强连。
3. 名录型文本无叙事论证，"论证支撑 ⇐"仅用于"条目→制度判断"的推断关系，且标注为推断。
4. 反例与边界：凡出现任期例外（如 Reinfrank 仅 2004 年）、拼写例外（Alto University）、换行拆分（Jason W./Patton）均如实记录。
5. 涌现强度 S 为相对排序指标，报告中给出公式与比较，不伪称精确统计结果（本分析不做代码计算）。
