## 三、概念（Concept）

| 知识元 | 语义载荷（指什么/为何存在） | 行号证据 |
|---|---|---|
| Isotype（Isotype method） | 全文总对象：被反复界定（符号→语法→态度→智识过程）；最终定义为"解释、叙事与再传播的智识过程" | L14-L15, L19, L30-L33, L57-L58, L66, L69-L72 |
| Isotype Institute | 机构概念：从"影子世界"制造者到方法史主体的语义枢纽 | L14-L16, L23, L39, L42, L56, L63, L67 |
| shadow-world | 靶子概念：代表对 Isotype 的窄化认知，全文以"超越它"为起点与终点 | L14, L30 |
| silhouette people and objects | shadow-world 的构成单元：最可辨识产物 | L14, L30 |
| Vienna Method（Wiener Methode） | 早期方法名：连接维也纳时期与牛津时期；被界定为"非普遍程序"的翻译过程 | L22, L25-L26, L57 |
| transformer（Transformator） | 职业概念：数据→视觉信息的中介角色；与 designer 的身份之争 | L24-L25, L34 |
| eye-consciousness | 方法论概念：Otto Neurath 所称视觉成熟感知力，Vienna Method 的灵魂 | L26 |
| pictorial grammar | 核心论题概念：Isotype 的本质被归结于此；四特质+可学习性 | L31-L32, L58, L71 |
| picture education | 目的概念：Isotype 的最终目标，统摄分类与语法教训 | L33 |
| quantified arrangement / removal of perspective / axial organisation / compounding of symbols | 语法四特质：图画语法可学习性的具体证据 | L32 |
| positivist outlook / relativist | 哲学底色对：实证主义（偏好可触可测）与相对主义（信息受限）的张力 | L27, L64 |
| International System of Typographic Picture Education | Isotype 全称：机构更名的名目依据 | L23 |
| visual communication / symbol design / wayfinding / ideograms for public space signing | 归类概念：Isotype 被归入/被排除的领域标签 | L15, L69 |
| essential information / modular symbolic components / flat colour | 起源概念：三个 Isotype 特征被追溯到童年游戏 | L59 |
| attitude towards information | 迁移概念：Isotype 作为"仍可应用的态度"，连接历史与当下 | L30 |
| interpretation, storytelling, and re-transmission | 总结概念：Isotype 本质的三连定义 | L70 |
| preferred forms of composition | 语法同义概念：偏好的构图形式=Isotype 语法 | L71 |
