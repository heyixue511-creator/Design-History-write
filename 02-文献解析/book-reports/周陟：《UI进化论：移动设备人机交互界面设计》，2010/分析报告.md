## 内容摘要

本书是 2010 年国内首部系统面向移动手持设备 UI（用户界面）与交互设计的实用手册型专著。作者周陟以 UCD（以用户为中心的设计）为思想主线，按"设计产品化（第1-3章）→产品化交互设计过程（第4-8章）→GUI视觉设计（第9-11章）→项目实践（第12-13章）"四大部十三章展开，涵盖交互设计与界面设计的基本概念、用户研究方法、原型设计、可用性测试、设计规范、图标与界面视觉设计、项目流程管理，并以两个虚拟项目（配合式与 UI 主导式）串联全书方法。书中附"《设计的小事》"随笔专栏，讨论中国 UI 从业者的职业生态与行业观察。配 DVD 光盘含设计视频教程与素材。

## 核心论点与关键概念

1. **UCD 是全书思想主线**：设计必须从用户的需求和感受出发，而不是让用户适应产品（L190-L191、L419）。
2. **设计不是万能**：交互设计与界面设计不等于产品化设计，不能替代产品策略（L419-L431）。
3. **设计产品化是系统流程**：市场调查→用户研究→概念设计→原型→测试→迭代→产品（L210-L211、L468-L469）。
4. **视觉设计是连接设计师和用户的最后一步**：图标、界面、交互特效是 GUI 三大要素（L1187）。
5. **设计规范与团队管理决定成败**：规范是工具而非制度，本质是"做好人的工作"（L1091-L1098）。
6. **UI 设计团队可以主导产品**：第13章以"样板工程"完整演示设计驱动产品的路径（L1792-L1954）。

关键概念：UCD、交互设计、GUI、可用性、随身性、低保真/高保真原型、Design house、天使/魔鬼客户、卡片分类法、头脑风暴法、任务分析法、情景设定法、启发式评估、设计规范、PI（产品识别）、II（图标识别）、情感化设计、7±2原则。

## 方法论与材料

- **定位**：实际工作案例与经验为主，刻意回避理论综述（L46、L64）。
- **材料类型**：作者亲身项目（CK 系列）、行业产品案例（Apple/Nokia/HTC/三星等）、国际标准（ISO 9241/13407）、国际机构定义（ACM/IEEE）、行业报告（FrogDesign/创新指数）、UCDChina 讨论实录、RMAA 测试数据。
- **方法**：定义-例证-要点三段式、案例教学、流程清单、对比论证、权威引证、实证数据。
- **体例**："【技巧】【要点】【提示】【注意】【故事】《设计的小事》"五类标注贯穿全书（L51-L61）。

## 历史地位与影响

1. 国内移动 UI 领域早期系统专著之一，将 UCD/可用性工程/设计管理引入中文 UI 文献（L7 推荐序、L190-L191）。
2. 第13章"UI 主导产品"（L1792-L1954）是中文设计文献中较早的"设计驱动产品"实践论述，与后来"设计驱动创新"思潮呼应。
3. "《设计的小事》"专栏记录了 2010 年前后中国 UI 从业者的职业生态，具行业史料价值。
4. 时代局限：技术语境（MTK 平台、Flash AS2、240×320）限于 2009 年前后；理论深度有限，属实用手册而非学术专著。

## 成就与限度

**成就**：体系完整（概念-产品化-视觉-项目四阶）、实操性强（两套虚拟项目全程演示）、视野跨界（设计管理/报价/招聘纳入 UI 设计书）、行业观察真实。
**限度**：理论深度有限；技术工具性内容过时；经验主义与主观色彩；个别概念（UCD 定义）多处重复；图片/表格 OCR 损坏影响部分可读性。
