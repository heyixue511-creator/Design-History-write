# 《UI进化论：移动设备人机交互界面设计》周陟 2010

本文件包含两部分：**专项报告**（语言、文风、修辞方式、史料使用方式、阐述方法、推演逻辑、文字风格 + 术语中英对照表）与**实体总索引**（六类实体：人物/著作作品/概念/机构/地点/事件，每项附行号证据）。

所有行号（L###）均以 `00-book\周陟：《UI进化论：移动设备人机交互界面设计》，2010_clean.md`（共1954行）为准。

## 第一部分：专项报告

### 一、语言报告

本书语言以**简体中文职业经验谈**为基调，具有以下特征：

1. **口语化与专业术语并存**：正文大量使用口语（"我估计很多人都经历过""这玩意儿"等），专业术语（UCD、GUI、KISS、ISO、DSP、LCD 等）即时附中文解释（L190-L191、L321、L362-L380）。
2. **第一人称叙事**：全书以"我"（作者周陟）贯穿，个人经验、职场见闻、行业观察均以第一人称讲述（L46、L299-L312、L594、L703、L818-L837）。
3. **对话体**：常以对话再现职场场景（L639 开发/设计/经理三方对话、L1799 培训现场、L1098 UCDChina 邮件讨论）。
4. **中英混排**：书名、品牌、软件、术语保留英文原称（iPhone、Nokia、Photoshop、Design house、KISS），部分英文图注为 OCR 乱码（L17、L1083-L1087）。

### 二、文风报告

1. **随笔专栏化**：全书设有固定的"【故事】《设计的小事》"专栏（L61），讨论职业发展、行业现象、生活观察（如 L448 什么是好的设计、L556 手绘重要吗、L818 饮水思体验、L1130 帮助的乌托邦），形成"正文+随笔"双层文体。
2. **清单式行文**：大量使用"要点清单"（L252、L270、L336、L513 通用设计七原则、L1077），使内容便于速查。
3. **指南手册化**：从第9章起，图标、界面、Flash、音效、动画均以"编号步骤"教程呈现（L1604-L1620、L1712-L1719、L1898-L1954），近似软件教程。
4. **幽默与自嘲**：如"本人乃设计界一介武夫，草莽有余，细腻不足"（L188）、"你才是后现代，你全家都后现代"（L188）、"我甚至怀疑自己是在Adobe面试"（L633）。

### 三、修辞方式

1. **比喻**：设计规范如"种地立规矩"（L1092）；产品是"明灯不是暗礁"（L404）；PM 应"防火不是救火"（L764）；设计师是"股票"（L1683）；规范过度如"尿尿要听'嘘——'声"（L1092）。
2. **反讽**："我们用的画笔是洋人的，用的电脑是洋人的，现在连我们的思想也快洋化了"（L657）；"中国排到37位应该是评审委员会没有考虑到我们'优秀'的山寨产业的创新能力"（L1477）。
3. **设问与反问**："你确定你的产品需要设计吗？"（L744）；"没有哪个客户是不重视自己产品的，切记"（L1474）。
4. **排比**：好图标特点、设计要点等常以排比句列出（L252、L270）。
5. **夸张**："你有机会做这么大的一个项目……"（L1474 报价讽刺语）。
6. **引用**：名人名言置于"【要点】"栏（Victor Papanek L404、唐纳德·诺曼 L1414、亚瑟·普洛斯 L752、Philippe Starck L752、Bob Hayes L685）。

### 四、史料使用方式

1. **技术史编年**：GUI 发展编年（L172-L176）、手机平台芯片演化（L342-L357）、LCD 技术类型（L362-L380）。
2. **国际标准引用**：ISO 9241、ISO 13407（L966-L967）、ISO 组织介绍（L969-L970）。
3. **学术概念溯源**：交互设计提出者比尔·莫格里奇（L114）、头脑风暴法发明者奥斯本（L874-L875）、任务分析法的美国起源（L919-L920）、情景设定的军事起源（L930-L931）、心智模式起源（L923）。
4. **行业数据引用**：2008-2009 全球创新指数（L1477）、Mbricks 分辨率趋势（L1327）、诺基亚三城市用户测试（L784-L788）。
5. **公司史资料**：高通（L345）、ADI（L348）、TI（L351）、MTK（L354）、英飞凌（L354）、展讯（L357）、青蛙设计公司（L1638）。

### 五、阐述方法

1. **定义—例证—要点**三段式：先定义概念，再举产品/案例，最后列设计要点（如 L252 视觉、L252-L268）。
2. **案例教学**：以完整项目（第12-13章）串联全部方法，属"项目教学法"。
3. **对比论证**：合格/优秀/卓越产品（L436-L446）、天使/魔鬼客户（L583-L587）、低保真/高保真（L957）、全能/专业（L382-L395）。
4. **权威引证**：以国际标准（ISO）、学界人物（诺曼、Papanek）、行业领袖（Jobs、Starck）佐证。
5. **实践检验**：以 RMAA 测试数据（L1917-L1930）、培训答卷数据（L1835-L1838）作实证。

### 六、推演逻辑

全书推演主线：**用户中心（UCD）→ 产品化（市场与流程）→ 视觉化（GUI）→ 项目化（实践）**。

- 第1-3章：从概念到产品化（why）。
- 第4-8章：产品化方法（what/how：研究、原型、测试、规范）。
- 第9-11章：GUI 视觉设计的具体执行（do）。
- 第12-13章：项目实践验证（verify）。

章内推演多以"分类→列举→总结"进行，例如用户研究一章（第5章）以九种方法为骨架。

### 七、文字风格

- **行文特征**：短句为主，口语夹杂书面语；标题生动（"产品经理的太极拳""开发人员说：'我讨厌交互设计'"）；数字与表格密集（第12-13章尤甚）。
- **情感基调**：乐观、自省、批判本土弊病（山寨机、伪总监、HR 怪象）而不失建设性。
- **一致性**：全书的"【技巧】【要点】【提示】【注意】【故事】"标注体系贯穿全书（L51-L61），体例统一。
