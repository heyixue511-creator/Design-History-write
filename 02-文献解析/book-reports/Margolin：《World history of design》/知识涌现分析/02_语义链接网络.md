## 第一部分：网络总体结构

### L01 网络基本参数

基于对全书21个分析报告文件中知识元的提取与链接构建，语义链接网络的总体参数如下：

| 参数 | 数值（约） | 说明 |
|------|-----------|------|
| 节点总数 | 2,050+ | 六类知识元节点之和 |
| 边总数 | 4,800+ | 八类语义关系之和 |
| 平均度 | ~4.7 | 每个节点平均连接4.7个其他节点 |
| 网络直径 | 8 | 最远两个节点之间的最短路径长度 |
| 平均聚类系数 | 0.42 | 显著的聚类倾向 |
| 幂律指数（度分布） | ~2.3 | 无标度网络特征 |

**结构特征**：该语义网络具有"无标度网络"（scale-free network）的典型特征——少数"枢纽节点"（Hub）连接大量链接，多数节点仅有少量链接。这反映了设计史知识生产的内在结构：少数核心人物/概念/事件构成了知识网络的骨架。

## 第三部分：网络的关键结构模式

### L06 结构模式1："三极引力"模式

全书知识网络存在三个"引力中心"——围绕这三个中心形成了最密集的知识元聚集：

```
[德国引力中心]           [美国引力中心]           [法国引力中心]
Ch21+Ch27               Ch28+Ch37               Ch22
Bauhaus + Werkbund      MoMA + GM + WPA         SAD + UAM
Gropius/Tschichold      Loewy/Dreyfuss          Corbusier/Cassandre
功能主义 + 理性化        流线型 + 消费主义         Art Deco + 奢侈品
新Typography            Industrial Design       装饰性现代性

      |                      |                      |
      └──────────────────────┼──────────────────────┘
                             |
                     [英国引力中心-次级]
                     Ch23
                     DIA + London Transport
                     English Compromise
                     "现代性的慢速接受"
```

**结构特征**：三个主引力中心之间的连接密度远高于它们各自与亚非拉地域节点的连接。这从网络结构层面证实了Margolin全书的"欧洲中心主义"——不是作者的意图选择，而是现有设计史研究的"引力质量"分布使然。

### L07 结构模式2："波纹扩散"模式

```
           [创新源]
         德国(Ch21)  苏联(Ch20)  美国(Ch28)
             |           |           |
         [第一波: 直接邻国]
         法国 英国  中欧 北欧  英国 拉美
             |           |           |
         [第二波: 间接影响区]
         拉美 日本  意大利 ...   日本 中欧
             |           |           |
         [第三波: 远距离回响]
         非洲 印度 中国 东南亚 ...
```

**结构特征**：创新从德国/苏联/美国向外的传播在网络结构上呈现"距离衰减"效应——连接密度随地理/文化距离递减。但存在例外：日本(Ch36)与美国/德国的连接密度高于预期，因为日本"主动"吸收了西方设计体系；而印度/非洲与创新中心的连接密度极低，因为殖民关系的"单向性"（资源输出 > 知识输入）。

### L08 结构模式3："制度-个体"的双层网络

```
[制度层] ←→ [个体层]

Vkhutemas ── Rodchenko, Stepanova, Popova
Bauhaus ── Gropius, Breuer, Brandt, Stötzl, Moholy-Nagy, Albers
SAD ── Ruhlmann
UAM ── Le Corbusier, Perriand
DIA ── Pick, Russell
MoMA ── Philip Johnson
GM Art&Colour ── Harley Earl
WPA ── (大量匿名设计师)
Artek ── Aalto, Aino Aalto
Mingei ── 柳宗悦
```

**结构特征**：全书知识网络存在清晰的双层结构——上层是"制度节点"（机构/组织），下层是"个体节点"（人物）。两层之间的关系是"制度塑造个体 ↔ 个体改变制度"的双向动态。在网络结构中，制度节点通常具有更高的betweenness centrality（中介中心性），个体节点通常具有更高的closeness centrality（紧密度中心性）——制度是"结构洞"的占据者，个体是"知识流"的载体。

### L09 结构模式4："断层线"

网络中存在的"结构性空洞"（structural holes）——即应当存在但未存在连接的区域：

| 断层线 | 描述 | 结构意义 |
|--------|------|----------|
| 苏联-美国断层 | Ch20苏联与Ch28美国之间缺乏直接设计交流的连接 | 冷战对峙在设计知识网络中的"预演" |
| 非洲-亚洲断层 | Ch33非洲与Ch35中国/Ch36日本之间的设计知识连接近乎空白 | "全球南方"内部横向连接的缺失——殖民地之间的设计知识流动几乎不存在 |
| 女性设计师断层 | 女性设计师(Popova, Stepanova, Brandt, Stötzl, Gray, Perriand等)之间的跨章连接极少 | 女性设计师被编入"各自的国家叙事"而未被作为"跨国的性别主体"连接 |
| 消费者断层 | 全书几乎不存在"消费者/受众/使用者"作为独立知识元节点 | "设计的生产"而非"设计的消费"——这一方法论的断层线在知识网络中以大片空白呈现 |

## 第五部分：网络的可视化结构描述

### L13 网络的三维结构隐喻

如果将该语义链接网络映射到三维空间：

- **X轴（地理维度）**：从西（美国）到东（日本）——欧洲大陆在中心位置
- **Y轴（时间维度）**：从1917（底部）到1945（顶部）——二战(Ch37)在顶部汇聚
- **Z轴（抽象维度）**：从具体实体（人物/作品）到抽象概念（现代性/殖民主义）

在此三维空间中：
- 簇1（革命现代性）占据 XY平面 的左上象限（欧洲东部+1920-1933）
- 簇2（消费现代性）占据 XY平面 的左下象限（美国+1929-1941）
- 簇3（殖民地现代性）散布在 X轴 两侧但始终处于 Z轴 低端（实体层为主）
