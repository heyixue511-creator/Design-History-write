## 五、阐述方法

1. **概念重构**：文化即栽培（Ch01）、信息三义（Ch04）、脚本 vs 意向性（Ch07）、曲线价值逻辑（Ch23）。
2. **模型/图表建构**：Figure 1.1-1.3（Ch01）、3.1-3.10（Ch03）、8.1-8.2（Ch08）、27.1-27.5（Ch26）。
3. **阶段分期**：OSS 三段史（Ch11）、绿色→生态→可持续（Ch25）、乌尔姆三阶段（Ch24）。
4. **术语谱系**：Ch25 的术语学方法、Ch22 的两阶段史。
5. **类比论证**：身体-生物圈-文化（Ch23）、电影史-电脑史（Ch14）。

## 六、推演逻辑（全书论证链）

1. **Ch01 逻辑链**：现代主义解体 → 身份危机 → 两难 → 文化即栽培 → 商议与战略规划 → 为个体设计。
2. **Ch03 逻辑链**：学科缺陷 → 特殊性 → 自创生认识论 → 系统论 → 场景方法论 → 项目研究纲领。
3. **Ch04 逻辑链**：信息三元结构 → 关于/为实在 → 信息论转折 → 数字电子信息 → 作为实在 → 批判 → 平衡处方。
4. **Ch07 逻辑链**：物转向 → 柏拉图主义诊断 → 物作为物 → 脚本之限 → 意向性 → 物质主义设计。
5. **Ch26 逻辑链**：技术伦理问题 → 器物空间模型 → 四界中介 → 技术/伦理决策现象学 → 教育转化。
6. **三部分串联**：构想（理念与价值）→ 制作（物质化与社会化）→ 评价（价值、伦理、批评）。
