# 05 肖像摄影：人物群像

## L01 章节概览

本章涵盖原书中图版58至136号所呈现的罗钦科肖像摄影作品，时间跨度1924–1937年。这是罗钦科摄影创作中数量最多、情感密度最高的部分，拍摄对象包括：其妻瓦尔瓦拉·斯捷潘诺娃、母亲奥尔加·罗钦科、诗人马雅可夫斯基、莉莉·布里克与奥西普·布里克夫妇、作家什克洛夫斯基与特列季亚科夫、电影人库列绍夫与热姆丘日内、构成主义同仁拉文斯基与维斯宁等。肖像是罗钦科进入摄影的入口（"1924年开始拍摄照片——马雅可夫斯基、阿谢耶夫、母亲等肖像"），也是其最具持续性的摄影门类。

## L02 核心主题

1. **亲密性与距离**：罗钦科的肖像在情感温度上呈现两极——对母亲和妻子的温柔凝视与对同仁的冷峻构成主义处理并存。这既反映了拍摄关系的差异，也体现了构成主义肖像的方法论自觉。
2. **构成主义肖像的矛盾**：如何在"建构"视觉形式的同时不丧失人物的个性和生命感？这是贯穿罗钦科肖像创作的核心张力。
3. **先锋派共同体的视觉记忆**：罗钦科的肖像系列无意中记录了1920年代苏联先锋派的核心社交网络——LEF小组、VKHUTEMAS同仁、电影与戏剧界——构成了一份珍贵的视觉档案。
4. **女性肖像的特殊地位**：斯捷潘诺娃是最频繁的拍摄对象（约15幅），母亲和莉莉·布里克也反复出现。罗钦科的女性肖像呈现了比男性同仁肖像更丰富的情感层次。

## L03 关键作品分析

**《母亲肖像》（图版59）**：1924年拍摄，罗钦科的母亲奥尔加·罗钦科是一名洗衣妇。原始负片为全幅拍摄，但在展览和出版时被裁剪为仅留头部与手部。1930年代玻璃负片碎裂，1950年代从复制负片重新制作。这幅作品不仅是一幅肖像，也是一部物质史——负片的物理损坏与修复本身隐喻了苏联历史的断裂。

**《母亲在桌旁》（图版60, 61）**：1927年拍摄，两幅变体。母亲"性格坚强，双手有力，一生勤苦劳作"——拉夫连季耶夫的简短注释揭示了一个工人阶级女性的肖像如何在构成主义的光影处理中获得纪念碑性。

**《马雅可夫斯基系列》（图版71–78）**：1924年春拍摄了六张负片。诗人"愉快的心情"来自一局长时间的中国麻将游戏（mah-jongg），这一细节——在LEF圈内流行但被长期保密的中国游戏——为革命诗人的官方形象增添了一抹日常生活的人性色彩。

**《斯捷潘诺娃系列》（图版44, 46, 56, 63–66）**：从"谨慎的惊讶"表情到手绘上色的变体，斯捷潘诺娃的肖像展示了罗钦科如何在同一个人物上实践多种视觉策略。图版63《画架下的斯捷潘诺娃》以构成主义工作室内景为背景，将人物与空间构成一体化。

**《莉莉·布里克穿金裙》（图版91）**：1924年拍摄。莉莉·布里克是马雅可夫斯基的缪斯、奥西普·布里克的妻子、爱尔莎·特里奥莱的姐妹。这幅金裙肖像融合了时尚摄影的华丽与构成主义的严谨。

## L04 技术手法

1. **设备与规格**：早期肖像使用Iochim 9×12座机配Berthiot f.130mm镜头，玻璃底片；1925年后部分使用Ica 4×6.5和Vest Pocket Kodak。
2. **裁剪策略**：罗钦科对肖像进行后期裁剪（如《母亲肖像》从全幅裁至头部与手部），这是"构成"在暗房中的延续——拍摄是素材的获取，裁剪才是最终构图。
3. **双重曝光**：图版70为画家亚历山大·舍甫琴科的双重曝光肖像——在同一张玻璃底片上两次曝光，创造了一种面部"分裂"与"增殖"的视觉效果。这是对传统肖像"单一人格"假定的技术性质疑。
4. **手工上色**：图版56（斯捷潘诺娃肖像）使用了水彩与蜡笔在相纸上手工着色。这一手法将工业媒介（摄影）与手工技艺（绘画）融合，挑战了摄影"纯粹性"的现代主义教条。
5. **自拍与远程快门**：图版62（自拍像）、图版83（布里克家合影，可能使用线控快门）表明罗钦科对拍摄者-被摄者关系的技术性反思。

## L05 历史语境

- **苏联肖像传统**：1920年代苏联绘画中的"英雄肖像"（领袖、工人、士兵）构成主流肖像范式。罗钦科的肖像选择——母亲、妻子、诗人朋友——可视为对这一宏大叙事的私人化回应。
- **LEF圈子的社交摄影**：LEF小组的工作与生活紧密交织——马雅可夫斯基与布里克夫妇共同居住在根德里科夫巷的公寓，罗钦科一家住在同一栋楼的另一层。肖像摄影在这种语境中既是艺术实践，也是日常社交的记录。
- **摄影肖像与苏联身份政治**：1930年代后，官方肖像的标准趋向于正面、庄严、理想化。罗钦科肖像中的非正式姿态（马雅可夫斯基的嬉笑、斯捷潘诺娃的"惊讶"、母亲的劳作）构成了一种隐性的抵抗。

## L06 理论关联

1. **肖像作为"社会关系"的显影**：罗钦科的肖像不是孤立个体的再现，而是拍摄者与被摄者之间社会关系的视觉显影——母子、夫妻、同志、师生。每一幅肖像都隐含了一个关系网络。
2. **"类型"与"个体"的辩证法**：构成主义倾向于将个体还原为类型（"诗人"、"工人"、"建构者"），但罗钦科最好的肖像在类型框架内保留了个体的不可化约性——尤其是在母亲和妻子的肖像中。
3. **摄影肖像的时间性**：与绘画肖像追求永恒不同，摄影肖像记录了特定的时刻——"马雅可夫斯基因麻将而愉快"——这种瞬时性赋予了肖像以反英雄主义的日常生活质感。

## L07 影响与接受

- 罗钦科的马雅可夫斯基肖像已成为诗人最具辨识度的视觉形象，至今广泛应用于书籍封面、海报和纪念品。
- 其母亲肖像系列被视为20世纪最伟大的摄影肖像之一，可与多萝西娅·兰格的《移民母亲》和爱德华·韦斯顿的《蒂娜》相提并论。
- 1957年罗钦科逝世后的首次遗作展（莫斯科）即大量展出肖像作品；此后科隆（1978）、牛津（1979）等国际展览也将肖像作为核心板块。
- 斯捷潘诺娃肖像在多本罗钦科专著中被用作封面，其"构成主义缪斯"的形象已成为先锋派文化记忆的一部分。

## L08 批判性解读

1. **斯捷潘诺娃的独立性问题**：斯捷潘诺娃本人是重要的构成主义艺术家（纺织品设计、绘画、舞台设计），但在罗钦科的镜头和拉夫连季耶夫的叙述中，她主要呈现为"妻子/模特"。如何在分析中恢复她的主体性？
2. **肖像的选择性沉默**：罗钦科的肖像对象几乎全部来自先锋派圈内——没有工人、农民、士兵等"苏维埃新人"类型的肖像。这一选择本身是否构成一种政治表态？
3. **马雅可夫斯基肖像的偶像化**：马雅可夫斯基1930年自杀后被斯大林追认为"苏维埃时代最优秀的诗人"，罗钦科的肖像在此过程中被政治性地挪用。拉夫连季耶夫对这一问题保持沉默。
4. **"中国麻将"的微政治**：马雅可夫斯基肖像拍摄时的麻将游戏是一个意味深长的细节——LEF圈子所玩的是"中国游戏"，而非任何俄罗斯传统游戏。这一跨文化兴趣暗示先锋派圈子在"无产阶级文化"阵营中的某种异质性。

## L09 延伸研究建议

1. 对罗钦科的斯捷潘诺娃肖像进行完整的图像志研究，追踪同一个人物在不同时期、不同技术处理下的视觉呈现变化。
2. 研究马雅可夫斯基肖像的传播与接受史——从罗钦科的底片到苏联教科书封面，再到全球文化工业中的商品化使用。
3. 比较罗钦科的肖像摄影与同期苏联摄影家（如莫伊谢伊·纳佩尔鲍姆、阿尔卡季·沙伊赫特）的肖像实践，定位其在苏联肖像传统中的独特性。
4. 考察1920年代苏联先锋派社交网络中的摄影实践——摄影如何作为社交媒介、记忆技术与身份建构工具发挥作用。
