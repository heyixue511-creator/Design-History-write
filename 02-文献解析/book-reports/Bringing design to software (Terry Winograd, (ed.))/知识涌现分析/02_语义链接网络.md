#### 2.2 L2：命题网络

**节点**：47个命题性知识元（KU-PROP-01至KU-PROP-47）

命题网络追踪全书的论证链条。47个命题形成了7条可识别的论证路径。

##### L2-1 论证路径1：从宣言到独立专业（Ch.1→多处）

```
KU-PROP-01 (设计应成为独立专业)
    →ᵖ KU-PROP-02 (秘密耻辱)
    →ᵖ KU-PROP-03 (界面≠设计)
    →ᵉ KU-PROP-04 (概念模型是设计核心——Ch.2)
    →ᵉ KU-PROP-16 (内容与形式不可分离——Ch.3)
    →ᵉ KU-PROP-24 (设计师从最早介入——Ch.3)
    →ᶜ KU-PROP-06 (设计是混乱的——Ch.8)
    →ˢ KU-CASE-01 (Star的400页规格+用户测试——Ch.2)
```

此论证链从Kapor的学科宣言出发，经Liddle的方法论精确化（概念模型优先）、Crampton Smith & Tabor的美学论证（形式即内容）和美学与功能的不可分离，得到Kelley的实践确认（设计=混乱、不可方法化），最终由Star案例提供物质证据。共7步，涉及4章。

##### L2-2 论证路径2：设计过程的本体论——非线性与对话性（Ch.9→多处）

```
KU-PROP-09 (无直接路径)
    →ᵖ KU-PROP-10 (惊喜触发反思)
    →ᵉ KU-PROP-11 (任何移动都有副作用→复杂性)
    →ᵉ KU-PROP-12 (品味作为陀螺仪)
    →ᶜ KU-PROP-14 (自上而下→自下而上——Ch.11)
    →ⁱ KU-CASE-11 (Ray的桥——"suddenly popped up")
    →ᶜ KU-PROP-06 (设计是混乱的——Ch.8)
    →ᶜ KU-METH-01 (行动中反思的实操描述)
```

此论证链从Schön的哲学命题出发，经Gal的微观叙事（Ray的桥梁）获得经验证实，再由Kelley的实践语言重述。6步，涉及3章。

##### L2-3 论证路径3：语境决定意义——从在场到社会（Ch.7→多处）

```
KU-PROP-29 (设计的未来在于欠表征)
    →ᵖ KU-PROP-30 (中心与外围共同分担)
    →ᵉ KU-PROP-31 (外围→边界→文类)
    →ᵉ KU-PROP-32 (报纸制造新闻)
    →ᵉ KU-PROP-33 (信息≠从物质中解放)
    →ᶜ KU-PROP-28 (愤慨阈值——Ch.5)
    →ᶜ KU-PROP-26 (友好≠成功——Ch.5)
    →ᶜ KU-PROP-41 (系统定义什么算数——Ch.14)
```

此论证链从Brown & Duguid的理论命题出发，经Saffo的市场验证，最终到达Kuhn的政治论证——语境的力量从认知层面（periphery）经经济层面（threshold）到达权力层面（systems define what counts）。7步，涉及4章。

##### L2-4 论证路径4：组织的双面——阻碍与支持（Ch.12→Ch.13→Ch.14）

```
KU-PROP-34 (问为什么这个问题会出现)
    →ᵖ KU-PROP-35 (文化是最隐蔽的障碍)
    →ᵉ KU-PROP-37 (组织支持的三大支柱——Ch.13)
    →ᵉ KU-PROP-38 (客户聚焦需要结构)
    →ᵉ KU-PROP-39 (以上宾之道待员工)
    →ᶜ KU-PROP-36 (设计=组织干预——Ch.14)
    →ᶜ KU-PROP-40 (显性工作vs.隐性工作)
    →ᶜ KU-PROP-42 (计算机可能是压迫性体验)
```

此论证链从Norman的组织批判出发，经De Young的管理处方，抵达Kuhn的社会政治升华——三章共同构成了"组织-设计"关系的完整辩证。8步，涉及3章。

##### L2-5 论证路径5：个人创造力 vs. 方法化的持续对话

此路径的核心不是线性推进，而是一个张力网络：

```
KU-PROP-06 (设计是混乱的——Kelley)
    ↔⁻ KU-PROP-19 (设计语言可被系统化开发——Rheinfrank & Evenson)
    ↔⁻ KU-PROP-18 (领域本体论的结构化——Denning & Dargan)
    →ᶜ KU-PROP-12 (品味作为陀螺仪——Schön: 可培养但不可完全分析)
    →ᶜ KU-PROP-37 (框架与自由的平衡——De Young)
```

这一张力网络本身就是一个重要的涌现模式：全书不是"选择一方"，而是通过Schön的"品味"概念和De Young的"框架与自由"概念提供了超越"方法vs.直觉"二元对立的中道。详见03_知识涌现计算.md中的EO-2分析。

##### L2-6 论证路径6：建筑类比的全书生长

```
KU-PROP-01 (宣言中的建筑类比——Ch.1)
    →ᵉ KU-PROP-04 (概念模型=建筑蓝图——Ch.2)
    →ᵉ KU-PROP-18 (模式语言=建筑理论——Ch.6)
    →ᶜ KU-PROP-30 (外围/文类=建筑的社会语境——Ch.7)
    →ᶜ KU-PROP-43 (Vitruvius三美德——Ch.1→全书)
    →ⁱ KU-CASE-01 (Star=建筑的落成——Ch.2)
    →ⁱ KU-CASE-12 (电源开关=建筑细节的混乱——Ch.12)
```

##### L2-7 论证路径7：从设计对象到设计伦理——全书的维度扩展

```
KU-PROP-01 (设计独立——专业维度)
    →ᵉ KU-PROP-04 (概念模型——对象维度)
    →ᵉ KU-PROP-16 (形式与内容——美学维度)
    →ᵉ KU-PROP-17 (行动中心——方法维度)
    →ᵉ KU-PROP-28 (愤慨阈值——市场维度)
    →ᵉ KU-PROP-30 (外围/文类——文化维度)
    →ᵉ KU-PROP-36 (组织干预——组织维度)
    →ᶜ KU-PROP-42 (压迫性体验——伦理维度)
```

此链条展示了全书最宏大的论证弧——从Kapor的学科专业合法性到Kuhn的社会伦理责任——7个维度的逐级扩展。
