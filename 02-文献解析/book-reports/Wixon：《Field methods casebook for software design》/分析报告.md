# 《Field Methods Casebook for Software Design》分析报告（综合分析）

- **书名（英文）**：Field Methods Casebook for Software Design

- **出版**：John Wiley & Sons, Inc.（Wiley Computer Publishing），1996 年
- **ISBN**：0-471-14967-5
- **LC 编目**：QA76.76.D47 F54 1996；004.2'1'019—dc20

## 二、内容摘要

本书由 1995 年 CHI 会议田野导向设计工作坊发展而来（L428），为软件设计从业者系统回答"什么是田野研究、为什么/何时用、如何做"（L107-L113）。正文含 14 个真实产品设计案例（覆盖放射医学、电信、办公软件、色谱仪器、家用市场、医疗超声、消费软件、临床工作站、电子表格、字处理、销售自动化等领域）与 3 篇框架综述（民族志、参与式设计、情境设计），共 17 章。全书以"设计始于可能出错的假设，田野研究是设计早期检验假设的前期理解方式"（L93-L103）为哲学起点，以"设计是发现，是把使能者置于工作者与工作之间"（L430）为隐喻核心，最终以 Contextual Design 的端到端流程作为整合性回答（L4785）。

## 三、核心论点与关键概念

**核心论点**：
1. 假设是设计之源且可能出错（L97）；
2. 田野研究最适合设计早期高杠杆阶段（L103）；
3. 用户不善自述，情境观察不可替代（L2410、L4836）；
4. 客户数据是设计的唯一可靠基础（L5060）；
5. 田野研究是组织能力而非个体技术（L1657、L2370）；
6. 三大方法学派（民族志/参与式设计/情境设计）构成方法谱系（L576）。

**关键概念**：Ethnography（L632）、Field research（L103）、Contextual Inquiry（三原则 L4629-L4635）、Contextual Design（L4785）、Participatory Design（L4517）、行为流编年与刺激回忆（L680-L686）、CARD/PICTIVE（L832）、隐性知识（L1086）、知识工作（L899）、亲和图（L4971）、工作模型与合并（L4888、L4979）、用户环境模型（L5036）、Delta 方法（L1729）、可用性圆桌（L3902）、跨职能团队（L1363）、设计室（L4996）。

## 五、方法论与材料

- **体裁**：方法论案例集（案例+框架双层），案例统一采用"Executive Summary—Background—Planning—Conducting—Analyzing—Impacting—Cost/Benefit—Reflections"功能框架（Contents L127-L344）。
- **材料**：一手田野数据（录像、笔记、转录、制品、工作模型、需求文档、客户原话）+ 章末参考文献（人类学、认知科学、HCI、质量管理、软件工程）。
- **论证**：归纳-涌现、假设-证伪、对比-取舍、组织-方法联动四类逻辑；大量量化证据（人时、美元、数据点数、需求条数）。
- **自我批判**：Ch2 自陈"非真正参与式"（L983）、Ch7 自陈"整体影响失望"（L2323）、Ch12 坦承量化压力（L3631），构成可信度来源。

## 六、历史地位与影响

1. 1990 年代中期 HCI 领域**最早的系统性田野方法案例集之一**（封底自称"第一本专注界面设计与 HCI 的田野方法书"，L5516）。
2. 把 Contextual Inquiry/Contextual Design 从 Digital/InContext 的小圈子推向产业界与学界标准，为后续用户中心设计、体验研究、情境研究奠定了方法谱系。
3. 三大框架章（民族志/参与式/情境设计）成为 HCI 课程与工业实践的常用入门文本。
4. "设计植根于用户工作"（L2879、L5060）的命题影响深远，预示了后来"设计思维/用户研究"浪潮的核心信条。

## 七、成就与限度

**成就**：方法地图系统化、细节与多样性平衡、方法论自觉与自我批判、可操作性（步骤/问题/成本清单完备）、组织制度化论题超前。
**限度**：时代性局限（1990s 桌面/局域网技术语境）、样本集中于北美大型科技企业、数据专有性限制核验（Ch8）、缺乏跨案例系统比较、OCR 文本有少量表格损耗（已在分章报告中注明）。

## 九、一句话概括

《Field Methods Casebook for Software Design》通过 14 个真实案例与民族志、参与式设计、情境设计三大框架综述，向软件设计从业者完整演示了"为什么做田野研究、何时做、如何做、如何把用户数据转化为设计并制度化"的方法学路线，是 1990 年代 HCI 田野方法系统化的标志性文献。
