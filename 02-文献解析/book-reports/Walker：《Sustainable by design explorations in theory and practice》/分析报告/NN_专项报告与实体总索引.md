# NN 专项报告与实体总索引：Sustainable by Design: Explorations in Theory and Practice

> 分析基准：`00-book\Walker：《Sustainable by design explorations in theory and practice》.md`，行号 L### 均指该源文件。

---

## 第一部分：专项报告

### 一、语言总貌

- **语种**：英语（学术随笔体）。
- **人称**：以第一人称（作者自述、设计实验叙事）与第三人称（理论综述、历史叙述）交替。第14章刻意从"它"转到"我"以强化设计者与物的直接遭遇（L1344）。
- **术语密度**：高。作者大量自造或重定义术语（visual myth、aesthetic typology、appropriate concern、adequateness、endgame、white canvas、temporary concentration of resources、functional modality、cognitive stock、dominant/subordinate components 等），并常以定义性句式即时解释（如 L756、L1284、L1330、L1418）。
- **句式节奏**：大量单句/双句短段落；长句多由破折号、分号与"hence / it follows that / in other words"衔接，呈现推演感。
- **语域**：学院讲座与个人沉思的混合；避免技术黑话，面向设计学生与从业者（书后推荐语可见，L3088–L3102）。

### 二、文风特征

1. **题记传统**：每章（或章内小节）以引语开篇——Wilde、Thoreau、Bhagavad Gita、Beckett、Polanyi、Maugham、Holloway、Rybczynski、Riis、Stallabrass、Denis 等（L504、L528、L598、L606、L746、L758、L774、L1207、L1211、L1248、L1261）。
2. **类比/隐喻系统**：北极探险（L354–L360）、钻石工业（L238–L240）、长途飞行（L210）、电视晚餐（L510）、棋局两王（L1257）、白桌布/白墙/基座（L1173、L1286）、蛾（L1171）。
3. **排比与铺陈**：念珠的"跨时间、信仰、性别、文化与阶级"（L435）；"industrial diamonds vs gem"对照（L238–L240）。
4. **反问收束**："How would this other half live?"（L548）、"Is it possible to have an object that is more than merely functional ...?"（L488）。
5. **价值宣示式收尾**：多章以"我们必须……"或"唯有……才……"句式作结（L488、L592、L1318、L1549）。
6. **引语转义**：把 Riis 的社会学题名转义为人的内在"另一半"（L536–L538）。

### 四、史料使用方式

1. **实物证据优先**：作者的设计原型（第9、11、13、14章）本身即论证材料，配合图录说明（L104–L185 图表清单）；
2. **经典文献引证**：圣典、哲学、设计史专著逐条注出（Notes L1551–L2260）；
3. **历史事件编年**（第3章）：Carson、布伦特兰、蒙特利尔议定书、地球峰会等，配尾注与网址；
4. **一手来源声明**：视觉神话的图像来源逐一注明并获许（L806、L834、L844、L883、L893、L913、L923）；
5. **数据统计**：电子垃圾、产品寿命、125 种排列组合等（L518、L1250）；
6. **材料局限意识**：作者对单一物件（念珠）能否推出普遍结论持保留（L474），对类型学的非科学性有自觉（L992）。

### 五、阐述方法

1. **现象学自述**：以设计者的亲身经验（尤其第14章）作为知识来源（L216、L1344–L1354）；
2. **类型学归纳**：物品三层分类（L413–L421）、审美七标识（L971–L985）、修辞十二要素（L1452–L1460）；
3. **谱系学追溯**：可持续开发观念史（第3章）、现代性史（L300–L302）；
4. **跨宗教平行对照**（L570–L572）；
5. **"做中学"研究（research through design）**：以命题式设计展开理论（L200、L638）；
6. **多视角审视**：第十二章式的"十二视角凝视"（L1448–L1525）。

### 六、推演逻辑

- **归纳法**：从念珠、甘地兜提、白色画布等具体之物推及一般命题；
- **演绎法**：从"物之意义决定价值"推及"可持续即意义问题"；
- **类比推理**：从北极探险推及设计态度；
- **证伪意识**：作者常自设反例与边界（念珠挑战本地化论 L480；Shakers/Morris 反例 L588；全球化的复杂两面 L1073；类型学允许反例 L992）；
- **循环论证结构**：全书"命题式设计→理论反思→新命题式设计"的递进闭环（第9→10→11→13→14→15章）。

### 七、文字风格

- 简明而富于文学性的英语学术散文；句子长短交错，以陈述与判断句为主；
- 中肯的语气与偶尔的激烈批判并存（对消费主义、血汗工厂、"假生态"企业）；
- 大量使用斜体强调与破折号补注；
- OCR 文本存在若干段落乱码（如 L709、L778、L782、L890 附近），但语义主干可辨。
