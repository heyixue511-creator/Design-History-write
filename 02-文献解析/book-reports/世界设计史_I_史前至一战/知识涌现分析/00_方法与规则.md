# 00_方法与规则（知识涌现分析）

## 0.1 本分析的对象与目的

本分析以《世界设计史》（卷I：史前至一战）为文本对象，从全书 4024 行（L1—L4024）的语义内容中抽取**知识元**（最小语义单位），构建**语义链接网络**，进而识别**涌现结构**（单点知识之外、由节点间关系生成的新知识）。全部工作为纯语义阅读与分析，不依赖统计或编程工具；行号证据以 clean 版为准。

## 0.2 知识元抽取规则

1. **实体性**：知识元必须是可指认的语义单元——人物、著作/作品、概念、机构、地点、事件六类实体中的一类（见《20_专项报告与实体总索引.md》）。
2. **行号锚定**：每个知识元必须能在 clean 版中至少找到一处行号证据；多章复现的实体（如"海报""设计学校""博览会"）以首现行号与关键行号共同锚定。
3. **粒度控制**：知识元为"概念级"节点（如"平版印刷术"），不细分到每次出现；同一实体的不同语义侧面（技术/商业/美学）在《01_知识元语意分析.md》中合并描述。
4. **主题归属**：每个知识元可归属到一个或多个 Topic（中层主题）；Topic 归属到 Theme（高层域）。
5. **排除项**：图注版权信息、参考文献著录条目、OCR 残片内容不单独作为知识元。

## 0.3 链接规则（语义链接）

两个知识元之间存在链接当且仅当文本中存在明确语义关系，链接类型包括：
- **因果链 C**：A 导致/促成 B（如"平版印刷术→海报黄金时代"）。
- **谱系链 G**：A 是 B 的源流/继承/变体（如"腓尼基字母→希腊字母→罗马字母"；"凯尔姆斯哥特→丹弗→罗杰斯"）。
- **制度链 I**：A 与 B 同属一个组织/制度系统（如"设计学校—博物馆—博览会"三位一体）。
- **对照链 D**：A 与 B 构成平行/竞争/对立关系（如"普金 vs 科尔"、"泰勒 vs 拉斯金"）。
- **语境链 X**：A 是 B 的发生条件/背景（如"工业革命→水晶宫博览会→设计改革"）。
- **桥接链 B**：A 连接两个原本分离的 Topic/Theme（如"殖民地印刷"同时连通"文字传播"与"殖民经济"两个域）。

## 0.4 涌现分析规则

1. **一阶涌现（E）**：三个及以上知识元通过链接形成闭合结构（三角/网络），产生任一知识元单独不具备的语义（如"字体—印刷机—报纸—广告"四元网涌现出"工业时代信息基础设施"）。
2. **二阶涌现（P）**：跨 Theme 的命题式综合，须满足：(a) 命题的每个成分都有行号证据；(b) 命题关系在原文中未被作者显式陈述（或仅部分陈述），属于分析性生成；(c) 对每个命题标注生成机制（归纳自何处、桥接哪些节点）与强度（强/中/弱，依据证据密度与跨度）。
3. **内聚度与涌现强度 S**：对每个 Theme，S = 链接密度（该域内有效链接数/知识元数）× 跨域桥接数加权。S 分为三级：高（≥2.0）、中（1.0—2.0）、低（<1.0），为便于核对，本文档给出等级判定与计算依据（链接计数）。
4. **客观性核对**：每个二级涌现命题必须列出反例/边界/证据缺口；禁止将作者未表达的观点强加于文本；对文本内部矛盾（如第12章"统一风格"之辩）如实呈现。

## 0.5 分层结构定义

- **Theme（高层域，5个）**：T1 器物与技术生产；T2 文字与视觉传播；T3 制度与设计教育；T4 工业化与现代性；T5 跨文化传播与殖民。
- **Topic（中层主题，约16个）**：每章核心主题，如"印刷革命"（第6章）、"博览会制度"（第9、11章）、"手工艺批判"（第10章）、"品牌与广告"（第13章）等。
- **知识元（底层，共96个）**：见《01_知识元语意分析.md》清单。
