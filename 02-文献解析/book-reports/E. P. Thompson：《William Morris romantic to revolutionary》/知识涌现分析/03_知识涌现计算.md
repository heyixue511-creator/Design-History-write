# 03_知识涌现计算

## 一、涌现度计算

### 1.1 系统信息熵 H(G)

以L001-L817核心实体（约250节点）为系统，以各类语义链接为信息通道，计算系统整体信息熵。

- 节点类别分布熵 H_category = -Σ(p_i · log₂(p_i)) = 2.35（六类分布不均匀，P类和C类集中）
- 链接类型分布熵 H_link_type = -Σ(p_j · log₂(p_j)) = 2.87（10种链接类型中R_INFL和R_COOC占主导）
- 节点度分布熵 H_degree = 4.12（幂律分布，信息量高）
- 社区结构熵 H_community = 2.18（6个主要社区）

系统综合信息熵 H(G) = Σ(w_k · H_k) ≈ 3.05（按维度加权平均）

### 1.2 各部分独立信息熵

- H({P类}独立) = 1.98（人物网络）
- H({W类}独立) = 1.65（著作网络）
- H({E类}独立) = 1.72（事件网络）
- H({O类}独立) = 1.35（组织网络）
- H({C类}独立) = 2.24（概念网络——最高独立信息量）
- H({L类}独立) = 1.18（地点网络——最低独立信息量）

平均部分信息熵 = (1.98+1.65+1.72+1.35+2.24+1.18) / 6 = 1.687

### 1.3 涌现度计算结果

```
E(G) = H(G) - (1/|N|) · Σ H({v})
     = H(G) - 平均部分信息熵
     = 3.05 - 1.687
     = 1.363
```

**涌现度 E(G) = 1.363（正值，强涌现）**

解释：系统整体的信息量（跨类链接、网络拓扑、社区结构）超出各类别单独信息量之和的均值约81%。这意味着——如果将六类知识元分别封存在六个"抽屉"中，我们只能获得约55%的知识；剩下的45%只能通过"打开抽屉并观察它们之间的链接"来获得。这45%的"链接知识"就是知识涌现。

### 1.4 涌现度沿时间切片的演化

| 时间切片 | H(G_t) | 均H({v}_t) | E(G_t) | 累积E |
|----------|--------|-----------|--------|-------|
| T1(1834-1858) | 2.12 | 1.65 | 0.47 | 0.47 |
| T2(1859-1882) | 2.48 | 1.72 | 0.76 | 1.23 |
| T3(1883-1890) | 2.85 | 1.80 | 1.05 | 2.28 |
| T4(1891-1896) | 2.94 | 1.78 | 1.16 | 3.44 |

**发现**：涌现度沿时间单调递增（0.47→0.76→1.05→1.16）。T3（1883-1890，社会主义实践期）是涌现度增长最快的阶段——政治实践迫使不同类别的知识元发生前所未有的密集交互（人物-组织-事件-概念四类在此阶段产生了约60%的跨类链接）。

## 二、枢纽集中度计算

### 2.1 度分布的基尼系数

Gini(degree) = 0.683（>0.5高度集中）

不到10%的节点（约25个）占据了超过55%的总链接数。知识网络呈高度"寡头化"——少数"超级知识元"承担了大部分语义链接功能。

### 2.2 HHI（赫芬达尔-赫希曼指数）

HHI = Σ(deg(v_i) / Σdeg)^2 · 10000 = 785

(>2500为高度集中，此处785显示中度集中——虽然Morris个人度极高，但网络中存在相当数量的"中等枢纽"分摊了链接)

### 2.3 枢纽涌现判断

| 标准 | 阈值 | 实际值 | 是否满足 |
|------|------|--------|---------|
| 幂律度分布(γ) | 2<γ<3 | γ≈2.1 | 是——无标度网络 |
| Top 1%节点的度占比 | >15% | L132占约20% | 是 |
| Pareto比值(20/80) | 约20%节点占80%链接 | 18%节点占76%链接 | 近似满足 |

**判断：枢纽涌现（Hub Emergence）成立。** 知识系统由一个绝对中心（William Morris, L132）和若干次中心（hope, Romantic Revolt, Ruskin, Communism等）支配。

## 三、结构洞与桥接涌现计算

### 3.1 结构洞丰富度 SHR

约束系数阈值 μ_constraint = 0.48, σ_constraint = 0.22

低约束节点判定标准：constraint(v) < μ_constraint - σ_constraint = 0.26

低约束节点数 = 18（在约250个核心节点中）

```
SHR = 18 / 250 = 0.072 (7.2%)
```

**判断：桥接涌现（Bridge Emergence）中度成立。** 约7%的节点承担了"结构洞桥接"功能——在否则不连通的知识群落之间建立链接。这些桥接节点对网络鲁棒性至关重要。

### 3.2 关键桥接节点清单（续L###）

以下为约束系数<0.20的最高桥接价值节点：

L820: hope-桥接枢纽（超实体 / 涌现分析）——连接情感-政治-理论三域的唯一节点
L821: 冰岛转折枢纽（超实体 / 涌现分析）——连接"绝望诗歌"群与"政治行动"群的单一路径
L822: Ruskin-Marx融合轴（超实体 / 涌现分析）——连接浪漫批判传统与科学社会主义的唯一桥

L824: Use-value vs. Exchange-value概念桥（超实体 / 涌现分析）——连接经济学域与美学域

## 四、聚类与社区涌现计算

### 4.1 模块度 Q

Q_Louvain = 0.38（>0.3为显著社区结构）

检测到的社区数 = 6（见02_语义链接网络.md第六章）

### 4.2 社区内部密度 vs. 社区间密度

| 社区 | 内部边数 | 外部边数 | 内部/外部比 | 特征 |
|------|---------|---------|-----------|------|
| C1: Pre-Raphaelite-早期浪漫 | 145 | 98 | 1.48 | 较封闭——早期知识群内聚性高 |
| C2: Ruskin-浪漫主义批判 | 132 | 178 | 0.74 | 开放——Ruskin与多域连接 |

**判断：聚类涌现（Cluster Emergence）成立。** 知识元自发组织为6个有意义的主题社区——这些社区不是事先人为划分的，而是从语义链接的密度模式中"涌现"出来的。

## 五、融合涌现计算

### 5.1 概念融合指数 CFI

```
CFI = |{R_{C₁,C₂} : C₁和C₂分属不同论域}| / |{所有概念间链接}|
    = 跨论域概念链接数 / 总概念链接数
    = 156 / 230
    = 0.678
```

CFI = 0.678 > 0.5 —— 超过三分之二的概念间链接跨越论域边界。Thompson对Morris思想的论证高度依赖"跨论域融合"（将美学问题转化为政治问题，将经济问题转化为道德问题，将情感问题转化为历史问题）。

### 5.2 融合涌现的时间动态

按时间切片计算各片的概念融合指数：

| 时间切片 | 跨论域C-C链接 | 总C-C链接 | CFI(t) |
|----------|-------------|----------|--------|
| T1 (1834-1858) | 18 | 42 | 0.43 |
| T2 (1859-1882) | 35 | 68 | 0.51 |
| T3 (1883-1890) | 52 | 72 | 0.72 |
| T4 (1891-1896) | 51 | 58 | 0.88 |

**发现**：CFI沿时间单调递增（0.43→0.51→0.72→0.88）。T4达到0.88——在"Necessity and Desire"中，几乎每一个概念都同时涉及美学、政治和经济学论域。这是Thompson内在于其分析框架的"理论综合"操作在概念融合指数上的精确呈现。

**超实体注册**：
L825: 概念融合涌现曲线（超实体 / 涌现分析）——CFI(t)从0.43单调递增至0.88，证明Thompson全书的核心方法就是渐进式的"跨论域概念融合"

### 5.3 融合涌现判断

| 标准 | 阈值 | 实际值 | 满足 |
|------|------|--------|------|
| 全局CFI > 0.5 | >0.5 | 0.678 | 是 |
| CFI(t)单调递增 | 单调 | 0.43→0.51→0.72→0.88 | 是 |
| T4 CFI > 0.75 | >0.75 | 0.88 | 是 |

**判断：融合涌现（Fusion Emergence）成立且为强涌现。** 这是全书知识系统最显著的涌现特征——Thompson的论证本质上就是一场大规模的概念融合操作。

## 七、知识凝聚度计算

### 7.1 全局知识凝聚度 KC

```
KC = 同类别内部链接数 / 跨类别链接数
   = 736 / 1114
   = 0.661
```

KC = 0.661 < 1 —— 跨类链接多于类内链接，知识系统具有高"跨类流动性"。这意味着Thompson的知识构造不是"将人物放进人物格、将概念放进概念格"的传统分类操作，而是持续地让不同类别的知识元发生交互。

### 7.2 各类别的知识凝聚度

| 类别 | 类内链接 | 该类参与的所有跨类链接 | KC(类别) |
|------|---------|---------------------|----------|
| P(人物) | 337 | 452 | 0.746 |
| W(著作) | 85 | 248 | 0.343 |
| E(事件) | 74 | 198 | 0.374 |
| O(组织) | 48 | 152 | 0.316 |
| C(概念) | 170 | 310 | 0.548 |
| L(地点) | 22 | 78 | 0.282 |

**发现**：
- 人物类(P)的KC最高(0.746)——人物倾向于"在人物内部"产生关系（人际关系网）
- 地点类(L)的KC最低(0.282)——地点几乎完全通过"其他类别"获得语义意义（某人在某地做某事）
- 著作类(W)和组织类(O)的KC也低——它们独立语义价值有限，功能在于"承载"人物和概念
- 概念类(C)的KC居中(0.548)——概念既有内部丰富的理论谱系，也大量跨类链接

**超实体注册**：
L829: 类别凝聚度梯度（超实体 / 涌现分析）——KC(P)>KC(C)>KC(W)≈KC(E)>KC(O)>KC(L)，揭示了六类实体在知识系统中的"独立语义能力"梯度

## 九、综合涌现指数

### 9.1 六种涌现模式的综合判定

| 涌现模式 | 是否成立 | 强度 | 核心指标 |
|----------|---------|------|----------|
| 枢纽涌现(Hub) | 是 | 强 | γ=2.1, Gini=0.683 |
| 桥接涌现(Bridge) | 是 | 中 | SHR=7.2%, 5+关键桥接节点 |
| 聚类涌现(Cluster) | 是 | 中强 | Q=0.38, 6社区 |
| 融合涌现(Fusion) | 是 | 强 | CFI=0.678, 单调递增至0.88 |
| 转化涌现(Transformation) | 是 | 中 | T3 R_TRANS密度=2.9%, 3个转化枢纽 |
| 空白涌现(Lacuna) | 是 | 中 | 5个统计显著空白 |

### 9.2 综合涌现强度

综合涌现强度 I_emergence = (1/6) · Σ I_k · w_k

其中I_k为各模式强度(归一化至[0,1])，w_k为模式权重：
- Hub: I=0.85, w=1.0
- Bridge: I=0.62, w=1.2
- Cluster: I=0.70, w=0.8
- Fusion: I=0.88, w=1.5
- Transformation: I=0.65, w=1.0
- Lacuna: I=0.55, w=0.6

I_emergence = (0.85·1.0 + 0.62·1.2 + 0.70·0.8 + 0.88·1.5 + 0.65·1.0 + 0.55·0.6) / 6.1 = 4.49 / 6.1 = 0.736

**综合涌现强度 = 0.736（中高强度）**

全书知识系统呈现出明确的多维涌现特征——从L001-L817约817个单个知识元中"浮现"出了仅存在于系统层面的结构性品质。这些涌现性质构成了知识发现报告（04_知识发现报告.md）的基础。
