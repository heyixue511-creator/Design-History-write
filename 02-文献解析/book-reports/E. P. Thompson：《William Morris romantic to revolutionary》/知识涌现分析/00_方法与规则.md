# 00_方法与规则

## 一、知识涌现分析的定义与目标

知识涌现分析（Knowledge Emergence Analysis）是在已完成的"知识元提取-语义标注-实体索引"基础之上，以系统论和网络科学为方法论框架，对知识元集合进行"二阶计算"，以识别并报告从单个实体层面不可见的、仅在系统层面显现的结构性质、模式与发现。

### 核心操作定义
- **知识元（Knowledge Element）**：全书分析报告中标以L###编号的最小语义单元，包括人物、著作、事件、组织、概念、地点六类实体。
- **语义链接（Semantic Link）**：两个知识元之间在原文叙事或论证中形成的可追溯关系（因果、从属、对照、序列、共现等），构成知识网络的"边"。
- **知识涌现（Knowledge Emergence）**：在知识元集合中，通过计算链接密度、聚类系数、中心性、结构洞、桥接等网络指标，识别出的超实体层面的结构性发现——这些发现不是任何一个L###实体直接"说"出来的，而是在其关系网络中"显现"出来的。

### 本分析的三层递进结构
```
第一层：知识元语义分析（01_知识元语意分析.md）
  → 对L001-L817进行跨类语义维度标注与聚类
第二层：语义链接网络构建（02_语义链接网络.md）
  → 构建六类知识元之间的多维关系网络
第三层：涌现计算与发现（03_知识涌现计算.md + 04_知识发现报告.md）
  → 对网络进行指标计算→识别涌现模式→生成知识发现命题
```

## 三、语义链接类型与编码规则

### 基本链接类型（R集）

| 链接类型 | 编码 | 方向性 | 说明 | 示例 |
|----------|------|--------|------|------|
| 因果链接 | R_CAUS | 有向 | A导致/引发B | L435(东方问题危机) →R_CAUS→ L430("To the Working-men of England") |
| 从属链接 | R_BEL | 有向 | A是B的成员/部分/子类 | L132(Morris) →R_BEL→ L081(DF) |
| 对照链接 | R_OPP | 无向 | A与B构成对立/对照 | L142(Sir Launcelot) ↔R_OPP↔ L141(Mr. Gradgrind) |
| 影响链接 | R_INFL | 有向 | A在思想上影响B | L183(Ruskin) →R_INFL→ L132(Morris) |
| 共现链接 | R_COOC | 无向 | A与B在同一叙事/论证语境中反复共同出现 | L138(Burne-Jones) ↔R_COOC↔ L132(Morris) |
| 序列链接 | R_SEQ | 有向 | A在时间/逻辑上先于B | L152(Morris出生) →R_SEQ→ L266(与Janey结婚) |
| 创造链接 | R_CREA | 有向 | A创作/建立B | L132(Morris) →R_CREA→ L144(The Defence of Guenevere) |
| 转化链接 | R_TRANS | 有向 | A转化为B（概念/状态转换） | L165(Romantic Revolt) →R_TRANS→ L105(Communism) |
| 论辩链接 | R_ARG | 有向 | A是对B的论证/驳斥 | Thompson分析 →R_ARG→ Mackail叙事 |
| 包含链接 | R_CONT | 有向 | A在空间/逻辑上包含B | L117(Kelmscott Manor) →R_CONT→ L791(Kelmscott Manor所在区域) |

### 链接权重规则
- **w=3**: 强链接——原文有明确的因果/影响/从属陈述
- **w=2**: 中链接——原文有反复的共现或隐含的关联
- **w=1**: 弱链接——可推导但未直接陈述的关联

### 边编码格式
```
E{L编号1}_{L编号2}_{链接类型}_{权重}
例: E132_183_INFL_3 （Morris受Ruskin影响，强链接）
```

## 四、知识涌现计算模型

### 4.1 网络构建
将L001-L817知识元作为节点集N，将语义链接作为边集E，构建加权有向多重图G=(N, E)。

### 4.2 基础网络指标
- **度中心性（Degree Centrality）**：C_D(v) = deg(v) / (|N|-1)
- **中介中心性（Betweenness Centrality）**：C_B(v) = Σ(s≠v≠t) σ_st(v) / σ_st
- **接近中心性（Closeness Centrality）**：C_C(v) = (|N|-1) / Σ(u≠v) d(v,u)
- **特征向量中心性（Eigenvector Centrality）**：考虑邻居重要性的加权中心性

### 4.3 涌现指标

**涌现度（Emergence Degree）E(G)**：
```
E(G) = H(G) - (1/|N|) · Σ H({v})  其中H为信息熵
```
当系统整体的信息量大于其组成部分信息量之和的均值时，涌现为正。

**结构洞丰富度（Structural Hole Richness）SHR**：
```
SHR = |{v ∈ N : constraint(v) < μ_constraint - σ_constraint }| / |N|
```
识别网络中占据结构洞位置（即连接否则不连通子网络的桥接节点）的比例。

**知识凝聚度（Knowledge Cohesion）KC**：
```
KC = (同类别内部链接数) / (跨类别链接数)
```
量度知识在类别内部被"封装"的程度 vs. 跨类别"穿透"的程度。

**历时涌现度（Diachronic Emergence）DE**：
```
DE(t₁, t₂) = |N(t₂)| - |N(t₁)| 随时间窗口变动的节点增长率
```
追踪知识元随Morris生命历程的"积累曲线"。

**概念融合度（Concept Fusion Index）CFI**：
```
CFI = |{R_{C₁,C₂} : C₁和C₂分属不同论域} | / |{所有概念间链接}|
```
量度不同论域概念之间的融合程度——CFI越高，跨域理论综合越强。

### 4.4 涌现模式分类

| 模式 | 判定标准 | 含义 |
|------|----------|------|
| 枢纽涌现（Hub Emergence） | 少数节点的度中心性显著高于分布均值（幂律分布） | 存在支配性核心实体 |
| 桥接涌现（Bridge Emergence） | 某节点的移除导致网络断裂为2+个连通分量 | 存在不可替代的"铰链"人物/作品/事件 |
| 聚类涌现（Cluster Emergence） | 模块度Q > 0.3，存在显著社区结构 | 知识元分为若干"主题簇" |
| 融合涌现（Fusion Emergence） | 跨类别链接密度随时间窗口递增 | 晚期出现理论综合 |
| 转化涌现（Transformation Emergence） | 转化链接（R_TRANS）密集于特定时间窗口 | 思想/身份发生质变的节点 |
| 空白涌现（Lacuna Emergence） | 高密度网络中特定区域的边密度显著低于预期 | 存在"未说"的知识空白 |

## 五、分析流程与操作步骤

### Step 1: 知识元语义标注
- 对L001-L817中所有知识元追加"语义维度"标签（详见01_知识元语意分析.md）

### Step 2: 语义链接抽取与编码
- 从20份分析报告中抽取知识元间的语义链接
- 为每条链接标注类型（R集10种之一）、方向、权重
- 交叉验证（多人共现 ↔ 互文验证）

### Step 3: 网络建模与指标计算
- 构建加权有向多重图
- 计算基础网络指标 + 涌现指标
- 时间切片分析（按Morris生命阶段切片）

### Step 4: 涌现模式识别
- 对照"涌现模式分类表"进行模式匹配
- 识别统计显著的涌现模式

### Step 5: 知识发现命题生成
- 将涌现模式翻译为"知识发现命题"
- 以原文证据支撑每个命题
- 区分"确定性发现"与"推测性发现"
