## 专项报告二：全书论证方法汇编

### 论证策略类型 L003

| 策略 | 运用章节 | 特征描述 |
|------|---------|---------|
| 悖论开场 | 导论, Ch5, Ch7 | 以一个看似不合理的设计选择或学科困境开始,制造认知张力 |
| 概念考古学 | Ch5, Ch6 | 追溯一个概念在人类学中的理论史,展示其被解构的过程 |
| 三位一体批判 | Ch2, Ch3 | 以三位思想家的批判构建对既有理论的三角挑战 |
| 漏斗型结构 | 所有主要章节 | 前半=综述与入门,后半=聚焦推进特定论证 |
| 个人叙事论证 | Ch1, Ch3, Ch4, Ch7, Ch8 | 以自身田野经验作为理论建构的基础而非装饰 |
| 类型学建构 | Ch1(三种动机), Ch2(四种进路), Ch4(多种知识工作模式), Ch7(三种未来取向) | 通过分类建立分析框架而非提供单一"正确"答案 |
| 对比性编排 | Ch6, Ch8 | 以对立案例(革命性vs.层叠性)建立"时间策略"等类型学 |
| 知识操作类比 | Ch8 | 在考古学、设计学和人类学之间建立"特征"的跨学科类比 |
| 谱系定位 | Epilogue | 与同代思想家的比较,将本书定位为一个思想立场 |
