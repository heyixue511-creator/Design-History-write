## 三、核心语义链接子网络

### 3.1 招贴画-绘画双向影响网络

```
[绘画->招贴画 正向翻译]
Cubism(K305) --TRAN[强度9]--> Cassandre(K004)
Purism(K307) --TRAN[强度8]--> Cassandre(K004)
Art Nouveau(K301) --INFL[强度8]--> Cheret(K001)

[招贴画->绘画 反向影响]
Cheret(K001) --INFL[强度8]--> Seurat
Lautrec(K002) --INFL[强度9]--> Picasso(K005)
Steinlen(K006) --INFL[强度7]--> Picasso(K005)
美国billboard --INFL[强度9]--> de Kooning(K020) --PROD[强度8]--> Woman系列
消费者广告 --INFL[强度10]--> Pop Art(K318)
```

## 四、关键桥接节点

**Cassandre(K004)** -- 形式与装饰两域"唯一真实桥梁", 介数最高
- 连接群落A(招贴画起源), B(设计方法论), C(再现策略)

**Heartfield(K011)** -- 技术/艺术/政治三角桥
- Dada->Collage->摄影蒙太奇->政治招贴画->战后黑色Surrealism
- 全书唯一同时归类为Dada成员、Surrealism先驱、政治招贴画里程碑的人物

**de Kooning(K020)** -- 招贴画与绘画活体桥
- 美国billboard->Woman系列->Abstract Expressionism/Pop Art先声
- 连接: 大众语汇+高级绘画+Pop Art范式

**Picasso(K005)** -- 跨度最大桥接(四个群落)
- Ch1: 受招贴画影响, Ch2: Cubism+装饰化, Ch3: 拼贴创新, Ch4: Guernica

**Paris** -- 唯一在所有四章所有关键转折点出现的地点【校对修正：原"Paris(K601)"的ID引用有误——K601在01号文件中为"对比法"（M-ANAL）；Paris为地点类知识元，未在01文件编号表中单独列出】
- 1866诞生->1890s画廊->1925装饰展->1968回返

**1917年Holst-Hahn辩论(K364/K392)** -- 介数排名极高(隐桥)
- 连接群落C(再现策略)和群落D(社会功能/政治)
- 审美选择实际上是政治立场

## 六、跨章语义环

**环1: 可收藏性-不可收藏性**
1890s狂热 -> 可收藏艺术品 -> 1968自觉拒绝收藏 -> 反讽:因不可收藏而更有价值 -> CYCLE

**环2: 女性形象百年**
1890s La Cherette(有温度) -> 1910s Christy(爱国性别化) -> 1950s de Kooning Woman(同情式讽刺) -> 1960s Ketchup Queen(消费者情色化)

**环3: Surrealism环形反馈**
流行招贴画(1890s前Surrealism) -> Breton理论化(1924) -> 广告应用Surrealism(1924-70s) -> 被艺术家重新征用(Duchamp, Pop Art) -> 环形闭合

## 七、知识间隙(Gap)识别

1. **技术(群落E)---论题(群落F)**: 缺少直接因果链接 -> 涌现问题: 石印术如何改变招贴画能说什么?
2. **民间艺术(群落A)---古巴革命(群落D)**: 共享"大众语汇自下而上"但无直接链接 -> 涌现问题: 民间艺术纯真与革命政治性是否共享深层结构?
