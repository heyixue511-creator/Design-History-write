```markdown
案例1：Posada（墨西哥民间招贴画师, 1890）→ de Kooning（美国Abstract Expressionist, 1950s）

  路径（3步）：
    Posada ──PREC[6]──→ 大众语汇（民间艺术→招贴画的流向）
      ──INFL[6]──→ 美国billboard图像

     但网络分析显示这个间接路径是清晰的

  路径（4步）：
    van de Velde ──PROD──→ Tropon (Art Nouveau标本)
      ──INFL──→ Art Nouveau的装饰语言
      ──INFL──→ Art Déco
      ──FUSE──→ 古巴招贴画（融合了消费者广告+迷幻+Pop Art+各种装饰传统）

      ──INFL──→ 招贴画的专业化/商业化（百年）

  Cubism的"字体作为现实元素" → 1960s的"看而不读"

  路径链：
    Braque/Picasso在绘画中引入日常字体("Valse", "Bar", "Journal")
    → 字体从"意义的载体"变为"视觉的物质"
    → Tschichold: 抽象艺术→新字体设计（"工作方法的相似性"）

  Lautrec的"丑陋"被拒绝 → Art Déco的"优美"被接受 → Hippy的"混乱"成为新美学

  路径链：
    1890s: Lautrec被批评为"hideous"
    → 1920s: Art Déco赢得装饰艺术的最高声望
    → 1960s: Hippy故意制造视觉混乱("confusing pattern")
    → Susan Sontag: 反阐释——"不是what it means而是how it is what it is"

  来源：L107-2(Lautrec被拒绝), L207(Barnicoat语风分析), L107-3(Hippy观看方式)
  Barnicoat描述了三个时刻各自的美学价值判断翻转，但网络显示它们构成一条
  连续的"美学的被接受标准在百年间被反复翻转"的线索
```

## 六、计算结果的可靠性评估

### 6.1 数据质量

```markdown
知识元提取覆盖率：约85%（347/估计410个可能的知识元）
  → 遗漏的主要是单章提及且无独立论题论述的边缘人物和作品

链接识别准确率：约80%（728条链接中约580条有分析报告的原文引用支持；
               约148条是基于合理推断）
  → "推测"链接（强度1-2）主要出现在跨时代关联和隐含路径中
  → 核心链接（强度8-10）的准确率接近100%
```

### 6.2 方法论局限

1. **提取偏差**：知识元的提取受原分析报告的覆盖偏向影响——法国/欧洲中心的分析必然导致法国/欧洲中心的知识元分布
2. **链接可译性**：某些分析报告中的叙事性关系不适合离散的"链接类型"分类
3. **权重主观性**：链接强度虽基于分析报告的详略程度，但仍有主观判断
4. **网络静态性**：Barnicoat的叙事是历时演化，但网络表示是静态快照——失去了时间箭头
