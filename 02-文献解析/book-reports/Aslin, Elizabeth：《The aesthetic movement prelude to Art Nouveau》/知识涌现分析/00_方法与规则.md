# 00_方法与规则：知识涌现分析框架

## L001 方法论总纲

本知识涌现分析基于对阿斯林（Elizabeth Aslin）《审美运动：新艺术运动的序曲》（The Aesthetic Movement: Prelude to Art Nouveau, 1969）的12份分析报告的系统再分析与计算。分析的总体逻辑遵循"分解-抽取-链接-计算-涌现"五阶段流水线：

```
源文本（12份分析报告）
→ 知识元语义分解（01_知识元语意分析）
→ 多粒度语义链接网络（02_语义链接网络）
→ 涌现计算与模式挖掘（03_知识涌现计算）
→ 知识发现与假设生成（04_知识发现报告）
```

## L002 知识元（Knowledge Unit, KU）定义

**知识元**是本分析的基本操作单元，定义为"一个具有独立语义完整性、可被引用、可被链接的最小知识陈述"。每个知识元具有以下标准字段：

| 字段 | 代号 | 说明 | 示例 |
|------|------|------|------|
| 唯一标识符 | KU-ID | 格式: `KU-{领域}-{序号}` | KU-ARG-001 |
| 语义类别 | S-Cat | 核心论点/案例陈述/因果推理/实体关系/方法断言 | 核心论点 |
| 源文件 | Src | 来源分析报告的编号 | 00_整体分析报告 |
| 知识陈述 | Stmt | ≤150字的精炼陈述 | "审美运动是1870-80年代英国一场覆盖所有装饰艺术门类的现代设计改革" |
| 实体链接 | Ent-L | 关联的人物/机构/出版物/事件/概念实体 | [Morris][Eastlake][Art Furniture] |
| 论证强度 | Arg-Lv | 1(弱/暗示性)~5(强/多重证据支撑) | 5 |
| 跨章出现频次 | Freq | 在12份报告中出现的章次数 | 8 |

## L003 知识元语义分类体系

本分析将知识元分为以下8个语义类别：

### 3.1 核心命题类（KU-ARG）
定义全书/全运动层面的纲领性主张。包括：论题陈述、修正主义判断、历史定位断言。

### 3.2 因果推理类（KU-CAU）
定义两个或更多现象之间的因果/转折/条件关系。包括：起源链条、影响路径、转折点识别。

### 3.3 案例证据类（KU-CAS）
定义具体的、可验证的个案性知识。包括：个人作品分析、企业个案、展览事件、建筑方案。

### 3.4 实体-实体关系类（KU-REL）
定义两个或更多实体之间的社会/经济/影响关系。包括：师徒/合作/竞争关系、商业委托关系、跨大西洋传播链路。

### 3.5 概念定义类（KU-CON）
定义运动专用的术语、分类、概念框架。包括：风格名称的定义、分析范畴的界定、时期分期。

### 3.6 方法论断类（KU-MET）
定义关于研究方法的判断——作者的、或分析报告识别出的。包括：材料使用方式的评价、论证策略的分析、跨学科整合的描述。

### 3.7 结构观察类（KU-STR）
定义关于全书/全章的结构性特征的观察。包括：章节逻辑、论证的起承转合、全书的组织原则。

### 3.8 元认知/局限类（KU-METACOG）
定义关于知识边界的自觉判断。包括：作者承认的局限性、分析报告识别的盲点、证据缺口的标记。

## L004 语义链接的定义与分类

语义链接（Semantic Link, SL）是两个知识元之间的有向、有类型边。定义为：

```
SL = (KU_i, KU_j, LinkType, Weight)
```

链接类型体系：

| 链接类型 | 代号 | 语义 | 示例 |
|---------|------|------|------|
| 因果链 | CAUSAL | KU_i 是 KU_j 的原因/条件 | [反工业情绪]→CAUSAL→[商业"art"标签] |
| 证据支撑 | SUPPORTS | KU_i 为 KU_j 提供经验证据 | [道尔顿签名制度]→SUPPORTS→[个体手工艺可见性] |
| 矛盾/张力 | TENSION | KU_i 与 KU_j 在逻辑/事实上构成矛盾 | [英国创造形式]→TENSION→[英国拒绝新艺术] |
| 类比/同构 | ANALOGY | KU_i 与 KU_j 在不同领域共享同一结构 | [安妮女王建筑红砖诚实]→ANALOGY→[盐釉炻器材料诚实] |
| 序列/阶段 | SEQUENCE | KU_i 与 KU_j 处于同一过程的先后阶段 | [1860s收藏家阶段]→SEQUENCE→[1870s原则吸收阶段] |
| 构成/子类 | PART_OF | KU_i 是 KU_j 的一个组成部分 | [戈德温个案]→PART_OF→[审美室内设计的日本维度] |
| 跨媒介同形 | XMEDIA | KU_i 与 KU_j 在不同媒介中呈现相同原则 | [建筑Picturesque]→XMEDIA→[服装流动轮廓] |
| 双向互动 | INTERACT | KU_i 与 KU_j 互为因果/相互影响 | [讽刺攻击]→INTERACT→[讽刺推广] |
| 盲点/否定 | BLIND | KU_i 的创造者/行动者未能识别或否认 KU_j | [克兰设计]→BLIND→[新艺术形式] |

链接权重分为1-5级，综合考虑：
- 证据直接性（原文是否明确陈述）
- 分析报告的置信度
- 多次出现的累积性

## L005 涌现计算规则

### 5.1 涌现的定义

在本框架中，**涌现**（Emergence）定义为："在源文本的单独段落中不可见，仅在跨章、跨维度、跨实体类别的系统链接后显现的知识模式或洞察"。涌现不同于汇总——汇总将已知信息并置，而涌现产生新的命题或假设。

### 5.2 涌现判别标准

一个知识模式被判定为"涌现"需满足至少两项条件：

| 标准代号 | 标准描述 |
|---------|---------|
| E1: 跨维度 | 模式跨越至少3个分析报告的维度（如建筑+服装+童书） |
| E2: 非显性 | 模式在源文本中未被任何单一作者明确陈述 |
| E3: 结构性 | 模式揭示的不是内容相似性，而是结构/逻辑上的同构或模式 |
| E4: 解释力 | 模式能够解释一个此前未被解释的历史困惑 |
| E5: 可验证 | 模式可以通过回溯源文本的证据进行验证（不被源文本证伪） |

### 5.3 计算流程

```
步骤1：知识元抽取 → 生成KU池（约200-300个KU）
步骤2：语义链接生成 → 生成SL集（约400-600条边）
步骤3：中心性计算 → 识别高联通度KU（度中心性+中介中心性）
步骤4：社群发现 → 识别紧密关联的KU簇 → 即为"知识模因"（KMEME）
步骤5：跨社群桥接识别 → 在不同KMEME之间寻找跨类型、跨维度的桥接KU
步骤6：涌现模式发现 → 对桥接结构进行E1-E5标准检验
步骤7：新假设生成 → 对通过检验的涌现模式进行命题化表述
```

## L006 知识模因（KMEME）定义

**知识模因**（Knowledge Meme, KMEME）是本分析的中层结构单元——一个由紧密语义链接的多个知识元构成的稳定簇。每个KMEME具有：

- **核心KU**：聚集度最高的知识元
- **边界KU**：与簇内核心KU直接链接、且与其他簇的KU也链接的桥接节点
- **内部一致性**：簇内KU共享同一主题域或逻辑结构
- **跨簇影响力**：通过边界KU对其他KMEME的影响强度

预期KMEME数量：约8-15个，覆盖：
- 修正主义史学KMEME
- 跨媒介统一性KMEME
- 社会改良使命KMEME
- 日本影响KMEME
- 商业转化悖论KMEME
- 跨大西洋传播KMEME
- 讽刺双重功效KMEME
- 形式预先性/英国否定KMEME
- 女性劳动力KMEME
- 技术-审美互动KMEME
- 个体签名/品牌KMEME

## L007 输出文件结构约定

每个输出文件使用统一的编号体系：L001, L002, L003... 作为段落编号，方便跨文件引用。

多语言约定：
- 文件主体为中文
- 关键概念首次出现时附带英文/原文（Latin script）
- 专有名词（人名、书名、机构名、术语）保留原文形式
- 引用原文段落时使用> 块引用符号

## L008 本分析与源"分析报告"的关系

本分析位于"二阶分析"层面：
- **一阶分析**：12份分析报告——对阿斯林原著的直接分析
- **二阶分析**（本分析）：对12份分析报告的二次分析——以跨报告、跨章节的系统视角识别涌现知识

本分析严格以12份分析报告的文本为基础，不引入阿斯林原著以外的外部材料。所有识别的知识模式均以源报告中的具体段落（L编号）为证据锚点。
