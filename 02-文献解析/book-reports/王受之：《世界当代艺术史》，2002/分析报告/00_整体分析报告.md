## 〇、书目信息与证据定位说明

该书为 1960–2000 世界当代艺术（以欧美为主）的史论通览，附大量彩色图版（clean 版保留 `<img>` 图片引用与 `<table>` 图注结构）。文本由台湾《艺术家》杂志连载文章结集修订而来（L45）。clean 版把原书版面合并为 296 个长行，正文多以 `##` 小节标题与内嵌 `# 章节标题` 组织。本报告所有行号证据均以 clean 版为准。

## 一、著作定位与成书脉络

1. **作者**：王受之，1946 年生于广州，设计理论与设计史专家，1988 年起任美国"艺术中心设计学院"（Art Center College of Design, Pasadena）全职终身教授，1998 年任联合国开发总署专家（L10）。
2. **成书缘起**：1999 年为台湾《艺术家》杂志撰写每月专论，一年多集腋成裘；2001 年台湾结集为《世界当代美术发展》（全彩 32 开），后修订成此专著（L45）。
3. **修订内容**：删去中国大陆与俄国当代艺术章节，修订译名（如"普普艺术"改"波普艺术"），注意章节承上启下（L45）。
4. **定位**：为艺术家、艺术专业大学生、艺术爱好者及设计界提供当代艺术第一手参考；补中文著作空白（L45）。

## 二、全书主旨与核心命题

1. **分期命题**：西方现代艺术分两大阶段——"现代主义时期"（约 1870 年代后印象主义至二战结束美国抽象表现主义）与"当代艺术时期"（1960 年代至今）（L45）。
2. **转折命题**：波普艺术带头冲击抽象表现主义，打破雅俗界限，把日常生活与商业文化带入严肃艺术，使艺术从"唯美之术"变为"更个人化、观念化的活动"（L45、L48）。
3. **继承命题**：当代艺术诸运动（新波普、当代抽象、极限主义、观念艺术、新表现主义等）多为现代主义遗产在 1960 年代后环境中的延伸与修正，全书反复使用"延续—修正—反对"的分析框架。
4. **地域命题**：当代艺术中心从巴黎转向纽约（L182），但纽约之外（芝加哥、加州、拉美、日本韩国、非洲加勒比海）亦各有独立面貌（L192、L211）。

## 三、分析框架（人物/主题/结构线索）

- **运动线索**：抽象表现主义式微 → 波普 → 观念艺术/极限主义 → 新波普/新表现主义/新写实主义/后现代主义。
- **地域线索**：英国 → 纽约 → 纽约以外美国 → 拉丁美洲 → 东亚 → 非洲加勒比海 → 身份政治（女权、同性恋）与新型艺术（大地、光线、身体）。
- **人物线索**：每位代表艺术家按"生平—教育—创作—代表作品（附年代/媒介/尺寸）—影响"展开。
- **结构线索**：以章节制并列各运动，各章内部按背景/理论/代表人物/作品/趋势铺陈。

## 六、材料与方法

1. **材料类型**：博物馆/画廊展览目录（近 30 年）、专业著作（鲁西-史密斯《今日艺术》为主要脉络来源）（L45）；大量作品图注（年代、媒介、尺寸、藏地）。
2. **引用方式**：正文中直接嵌入作品说明；图注以 `<table>`/图例形式插入正文。
3. **论证方法**：定义—历史背景—代表人物—作品分析—发展趋势；对比法（美英波普、美欧抽象、欧美超写实、新旧波普）；分期法（三次表现主义高潮等）。
4. **个人经验证据**：与哈林交谈（L54）、看李罗纽约展（L78）、洛杉矶"落日大道"居住（L201）、纽约地铁涂鸦亲见（L185）等，作为一手旁证。

## 七、核心论辩

1. **"新"与"旧"的论辩**：新波普并非全新运动，而是经典波普的延伸（L48）；新表现主义是表现主义第三次高潮（L124）。
2. **客观与主观的论辩**：波普标榜绝对客观，但作者指出其仍具时代痕迹与个人倾向（L48）；后现代主义"绘画性复兴"未必是回归传统，而是反现代主义的手段（L162）。
3. **中心与边缘的论辩**：纽约并非唯一中心；芝加哥、加州、拉美、东亚各有独立价值（L192、L211、L242）。
4. **现代主义遗产的论辩**：当代艺术在"循环使用"经典现代主义中发展（L185）；同时批评当代艺术精神枯竭（L277）。
5. **道德主义回归的论辩**：20 世纪艺术从摆脱道德主义出发，世纪末女权/同性恋艺术又回到道德主义与内容决定论（L293）。

## 八、理论资源与学术谱系

1. **现代主义史谱系**：从后印象主义、表现主义、立体主义、达达、构成主义、风格派到抽象表现主义（L45）。
2. **当代理论**：后现代主义理论家丹尼尔·贝尔、哈贝马斯、李欧塔、詹姆逊、斯潘诺斯等（L133）；哈桑《后现代的转折》的现代/后现代对照表（L133、L162）；斯坦因《现代经典主义》建筑五类型分类（L157）；詹克斯建筑六类型（L157）。
3. **参考书**：H·H·阿森纳《西方现代艺术史》（天津人民美术出版社 1983 中文版）（L45）；爱德华·鲁西-史密斯《今日艺术》（L45）。
4. **法国理论**：女权主义艺术批评借用法国结构主义哲学与德里达解构主义（L283）。

## 九、语言与写作风格总貌

1. 简体中文，口语化、讲课式叙述（如"因此""这样一来""显然""值得注意"高频出现）。
2. 大量"艺术家英文名（中文译名）+ 作品（年代、媒介、尺寸）"实证句式。
3. 擅长用比喻与意象（"万花筒中的图案""黑白地球照片一样""小人'海洋'"）。
4. 常用"按照……的看法/英语称为/翻译为……"做术语辨析，体现翻译者自觉。
5. 含第一人称亲历叙述（L54、L78、L185、L201），偶发议论（L277）。

## 十、成就与限度

**成就**：
- 覆盖 1960–2000 世界当代艺术全景，运动与地域双线并进，中文同类书稀少；
- 作品信息精确详实，兼具学术性与可读性；
- 作者亲历见闻增加文本可信度与独特性；
- 对设计史论丛书的"艺术背景"补充作用显著。

**限度**：
- 以美国为中心，非西方部分篇幅与深度有限（拉美、东亚、非洲均概述性）；
- 部分译名/原文人名存在 OCR 误差与前后不一致（如"黄永砂/黄永石水"、"罗森奎斯特"等），引用需核对；
- 判断带个人倾向（对纽约的褒扬、对当代艺术"精神枯竭"的批评、对女权/同性恋艺术"内容决定论"的质疑）；
- 连载集结导致部分章节结构松散、标题重复（如 L122 内嵌多节标题）。

## 十一、一句话概括

《世界当代艺术史》是王受之撰写的、以"波普之后与美国中心"为主线、运动史与地域史并重的 1960–2000 世界当代艺术通览，用实证作品信息与亲历见闻为中文读者搭建当代艺术基本认知框架。
