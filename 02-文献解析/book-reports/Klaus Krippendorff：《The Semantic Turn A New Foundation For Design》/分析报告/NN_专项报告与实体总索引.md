# 《The Semantic Turn》专项报告与实体总索引

## 第一部分：专项分析报告

### ZX01 全书论证策略专项分析

#### L300 公理化推进结构
全书以"意义公理"（Axiom of Meaning）为逻辑原点，沿四层意义语境逐级推导定理：
- **第一公理**（2.2节）：人类不为事物的物理性质而行动，而是为其意义而行动
- **使用层定理**（3.2节）：人类始终行动以保持其界面的有意义性
- **语言层定理**（4章引言）：所有人工物的命运在语言中被决定
- **生命层定理**（5.4节）：没有任何人工物能在文化中被实现，除非它对那些能推动它穿越其各种定义的人有意义
- **生态层推论**（6.5节）：违背文化生态智慧的设计策略很可能失败

#### L301 区分论证策略
第8章采用"逐一清算"（critique-by-exclusion）模式，针对七个邻近学科分别进行五点/三点式批判——每个批判都遵循"主张陈述→制度背景→认识论问题→实例揭露→替代方案"的结构。

#### L302 谱系建构策略
全书使用三种谱系建构：
1. **思想先驱谱系**（第2章）：从Protagoras到Wittgenstein的九位人本思想先驱
2. **学术运动谱系**（第1章）：产品语义学1984-2001的编年事件链
3. **个人学术谱系**（第9章）：乌尔姆经验到语义转向的传记性追溯

#### L303 环形叙事结构
全书呈现完美的环形结构：
- 开篇："Form follows Function"（导论/第1章——功能主义格言的失效）
- 终篇："\*Interfaces follow recognizable meanings.\*"（第9章——新范式的宣言）
- 主题词"design"在导论中通过词源学"de+signare"获得"赋予意义"的原初含义——全书结束时回到这一原初含义的重新激活

### ZX02 四层意义理论体系对照

#### L310 四层意义的系统性对比

| 维度 | 第3章：使用中的意义 | 第4章：语言中的意义 | 第5章：生命中的意义 | 第6章：生态中的意义 |
|------|---------------------|---------------------|---------------------|---------------------|
| **核心语境** | 个体用户-人工物界面 | 社区中的语言沟通 | 利益相关者网络的时间转换 | 多物种人工物的交互网络 |
| **关键概念** | 界面、中断、可供性 | 范畴、特征、叙事 | 遗传意义、项目 | 合作/竞争、技术合作社 |
| **时间尺度** | 实时交互（秒-分） | 话语循环（日-年） | 生命周期（月-数十年） | 物种演化（年-世纪） |
| **社会单位** | 个体用户 | 语言社区 | 利益相关者网络 | 人工物物种与制度 |
| **核心定理** | 人类始终行动以保持界面的有意义性 | 所有人工物的命运在语言中被决定 | 没有任何人工物能在文化中被实现，除非…… | 违背文化生态智慧的设计策略很可能失败 |
| **设计方法** | 可供性设计、反馈设计 | 特征设计、叙事设计 | 利益相关者参与、项目设计 | 生态影响评估、种群分析 |
| **知识论特征** | 现象学-生态心理学 | 语言学-社会学 | 政治学-管理学 | 生态学-神话学 |

### ZX03 关键概念谱系图

#### L320 从五个思想源头到语义转向的概念流变

1. **维特根斯坦的语言游戏** → Maturana的languaging → 第4章的"语言作为协调过程" → 对话式设计（7.4.5）
2. **Gibson的可供性（affordance）** → 第2章"生态知觉" → 第3章3.4.3的"可供性" → 第3章设计原则3.6.4
3. **Vico的建构论（verum ipsum factum）** → 第2章"意义公理" → 第1章"人工物轨迹" → 第7章"变异性科学"
4. **Heidegger的"上手/在手"** → 第3章"依赖/探索" → 第3章三级使用模型 → 第7章可用性验证
5. **Mead的符号互动论** → 第2章"第二序理解" → 第4章"利益相关者的话语" → 第7章利益相关者研究方法

### ZX04 被批判学科的系统对照

#### L330 语义转向与七个邻近学科的根本差异

| 被批判学科 | 根本分歧点 | 语义转向的方案 |
|-----------|-----------|---------------|
| 符号学（8.1） | 二世界本体论（符号界/指称界） | 非表征性意义——意义在交互中涌现 |
| 认知主义（8.2） | 单一逻辑的心智计算模型 | 对话性——两个或多个"逻辑"的相遇 |
| 工效学（8.3） | 层级制度出身，将人简化为不可靠组件 | 利益相关者自主性，意义的优先性 |
| 美学（8.4） | 普遍主义的客观美理论 | 特征归因——美学是语言-政治实践 |
| 功能主义（8.5） | 功能的从属逻辑——概念层级被误认为实在 | 异层级网络——多元行动者的协商 |
| 营销（8.6） | 仅关注销售点的短暂时刻 | 全生命周期——所有转换点都重要 |
| 文本主义（8.7） | 产品"言说"语言 | 只有人类使用语言——产品提供可供性 |
