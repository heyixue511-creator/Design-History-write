# NN_专项报告与实体总索引

## 第一部分：专项报告

### 专项一：语言、文风与修辞方式

1. **第一人称学术随笔体**：全书以讲座式第一人称展开（"I should like to…"大量出现，如 L40、L1096、L2110），兼具学术论证与个人经验叙述（L1725-1728 Mies 轶事；L1811-1814 家谱探寻）。这种"个人化科学散文"是西蒙风格的标志。
2. **设问-自答结构**：分节常以问题起头并作为推进器。例：L59-60（问题求解是什么）、L79-81（人类如何解 DONALD+GERALD）、L657（直觉是什么）、L1916-1917（无目标设计是否矛盾）。
3. **寓言与思想实验**：蚂蚁（L3-20）、钟表匠 Hora/Tempus（L2367-2403）、点击保险箱（L2484-2507）、黑暗长廊灯光（L1808-1823）、茶园仪式（L746-754）、油画循环（L1933-1935）。寓言承担论证职能（可量化估算），而不仅是修辞。
4. **冷幽默与机智**：长颈鹿式存在论（L1120-1121）；"烤面包的香气让我们看见食物"（L364-365）；Mother Hubbard 空柜（L2785）；"这些山里有很多金子"（L247）；"假如能登月，为何不能……？"（L1523）。
5. **隐喻式术语生成**：为论证方便自造通俗比喻："记忆像百科全书"（L644）、"世界如感/如受"（L2802-2803）、"蓝图 vs 配方"（L2800-2801、L2848）。
6. **审慎的限定语**：反复使用"hedge my bets"（L40-41）、"I have not run the experiment"（L192）、"如果这种观点成立"（L553）、"我无意把开拓性实验夸大成综合理论"（L545），显示科学自我约束。
7. **结构递进文风**：从具体谜题/案例到一般命题再到课程清单/总结，章末常以"预告下一章"收束（L592-594、L2111、L2254），形成全书环环相扣的节奏。

### 专项二：史料使用方式

1. **一手实验数据优先**：认知科学部分以实验室实验为核心证据（Ebbinghaus L220-221、概念获得 L147-189、象棋感知 L385-396、短时记忆 L318-326）。
2. **计算机程序作为"实证对象"**：把程序当作可检验、可模拟的理论载体（EPAM L265、GPS L1224、UNDERSTAND L762、ISAAC L785、BACON L974、AM L962、DENDRAL/MECHEM L997），这是全书最独特的方法论特征——"程序是可检验的实证现象，使设计过程不再躲在判断/经验黑箱后"（L1466-1468）。
3. **历史制度案例**：登月（L1523-1531）、美国宪法（L1533-1548）、马歇尔计划（L1560-1580）、Club of Rome（L1658-1667）作为社会设计论证的锚点。
4. **量级估算**：7 组块/8 秒（L565）、5 万组块（L663）、180 万组块/十年（L704）、钟表匠 4000 倍（L2382-2403）、保险箱 100^10→500（L2486-2489），用可计算的量级支撑论点。
5. **自引与自我语境化**：大量引用自己的著作（Models of Thought、Human Problem Solving、Administrative Behavior、Models of Discovery），把本书定位为既有研究纲领的综合（L46-49、L1103-1108、L1172）。

### 专项三：阐述方法与推演逻辑

1. **假说-检验-限权**：提出经验假说（L27-28）→ 用多类实验检验 → 限定边界（串行性对并行主义 L566-573）。
2. **归谬与还原**：先列祈使逻辑悖论（L1113-1115），再以"可能世界"还原为陈述逻辑（L1153-1156）；对强整体论以"活力论"归谬（L2035-2038）。
3. **类比推演**：演化-规划（L1969-1976）、自然选择-问题求解（L2468-2512）、层级-催化剂（L2447），在跨域间转移论证力量。
4. **分点驳论**：对钟表匠寓言四类反对逐一作答（L2419-2447）；对并行主义三条评论（L566-573）。
5. **两级说明论**：信息加工解释与生理（量子）解释是"两个链接层级的说明"（L590-591）；"原则上还原 + 逐层自主 + 桥接理论"（L2064-2066）。
6. **课程表文体**：以清单/课程表作为结论形式（设计课程 L1448-1463；社会设计课程 L1993-2010），兼具"宣言-指南"性质。
