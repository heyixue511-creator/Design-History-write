# 13_后现代主义与孟菲斯（1970s-1980s）

## 一、章节定位与功能

### L### 1.1 覆盖范围

本章整合原书中以下词条群组：Post-Modernism（后现代主义）、Memphis（孟菲斯）、Ettore Sottsass（埃托雷·索特萨斯，后现代阶段）、Alessandro Mendini（亚历山德罗·门迪尼）、Studio Alchimia（炼金术工作室，后现代前奏）、Michael Graves（迈克尔·格雷夫斯）、Aldo Rossi（阿尔多·罗西）、Robert Venturi（罗伯特·文丘里）、Hans Hollein（汉斯·霍莱因）、Masanori Umeda（梅田正德）、Matteo Thun（马泰奥·图恩）、Michele De Lucchi（米凯莱·德·卢基）、George Sowden（乔治·索登）、Marco Zanini（马可·扎尼尼）、Peter Shire（彼得·夏尔）、Javier Mariscal（哈维尔·马里斯卡尔）、Bořek Šípek（博雷克·西佩克），以及相关概念：Semiotics（符号学应用）、Kitsch（媚俗）。

### L### 1.2 功能定位

在全书中，后现代主义群组承担着"20世纪设计史叙事弧线的反转点"的叙事功能——它标志着从功能主义"统一性"向当代设计"多元性"的不可逆转的转向。孟菲斯（1981-1988年）是这一转向最具标志性的事件：当索特萨斯（时年64岁）带领一群年轻设计师推出第一个孟菲斯系列时，他们以"激进色彩、塑料层压板、不对称形式和历史引用"故意挑衅了"好设计"的一切信条。原书在Post-Modernism词条中明确追溯其谱系："后现代主义的祖先可追溯至1960年代波普和反设计的出现"。

## 二、结构分析

### L### 2.1 后现代设计的双重路径

```
路径A：建筑理论 → 产品设计（以"意义"为武器）
    Venturi《建筑的复杂性与矛盾性》（1966年）
    └→ Venturi为Alessi和Knoll设计的产品
    └→ "少即无聊"（Less is a bore）→ 直接反密斯"少即是多"
    
    Charles Jencks《后现代建筑语言》（1977年）
    └→ 将"后现代主义"标签推广到全球

    Aldo Rossi（意大利理性主义建筑师的"后现代"转向）
    └→ 为Alessi设计的"La Conica"咖啡壶（1984年）

    Michael Graves（美国后现代建筑师）
    └→ 为Alessi设计的"9093"鸟哨水壶（1985年）
    └→ Alessi历史上最畅销的产品之一

路径B：反设计/炼金术 → 孟菲斯（以"感性"为武器）
    Studio Alchimia（1976-1992）
    ├── Mendini的"再装饰化"实验
    └── 1980年"Bau.Haus"展 → 对包豪斯的后现代"重访"
    
    Memphis（1981-1988，米兰）
    ├── 索特萨斯（创始人/精神领袖）
    ├── 核心成员：de Lucchi, Sowden, Thun, Zanini, Umeda, Shire, Mariscal
    └── 1981年9月18日：首展 "孟菲斯：新国际风格"
        → 43件家具/灯具/陶瓷，爆炸性色彩+塑料层压板+不对称+异形
```

### L### 2.2 孟菲斯的"国际风格"构成

孟菲斯是一个刻意设计的"国际化"集体：索特萨斯（意大利）、梅田正德（日本）、夏尔（美国）、马里斯卡尔（西班牙）、西佩克（捷克）、索登（英国）、扎尼尼（意大利）、图恩（奥地利/意大利）——这种国家多元化不是偶然的，而是对"现代主义风格=国际风格"的历史回响的自觉操纵。

## 三、内容分析（核心论题+关键论点案例）

### L### 3.1 核心论题

L### 论题一："意义"对"功能"的取代
后现代主义设计最根本的理论转向是：设计物的首要维度不是其功能（它是用来做什么的），而是其意义（它传达了什么）。罗伯特·文丘里（Robert Venturi）在《建筑的复杂性与矛盾性》（1966年）中提出的关键区分——"鸭子"（建筑本身就是符号）vs."装饰的棚屋"（建筑是功能体，表面承载符号）——被后现代设计师系统性地应用于产品设计。

L### 论题二：历史引用与"双重编码"
Charles Jencks推广的"双重编码"（Double Coding）概念——后现代建筑同时向专业精英和普通公众说话——在设计中体现为：一个产品既有"高雅"的艺术史引用（如希腊柱式、古埃及形式），同时也有"通俗"的感官吸引力（鲜艳色彩、童趣造型）。格雷夫斯为Alessi设计的鸟哨水壶（9093号）是这一策略的完美案例——锥形壶体暗示古典建筑，鸟形哨子在水开时鸣叫，提供了一种人人可理解的触觉与听觉愉悦。

L### 论题三："坏品味"作为方法论
孟菲斯与Studio Alchimia共享了对"坏品味"的正面评估——将廉价的塑料层压板（通常用于1950年代廉价咖啡馆桌面）用于"高品质"家具的表面，使用被认为"庸俗"的色彩组合（粉红+橙+薄荷绿），引用1950年代美国郊区风格的"粗俗"形式。这不是堕落，而是策略：以故意的"坏品味"揭示"好品味/优良设计"标准的任意性和阶级性。

### L### 3.2 关键论点与案例

L### 索特萨斯的"Carlton"书架（1981年）：孟菲斯系列中最具标志性的作品——一个使用廉价塑料层压板制成、彩色几何分割、顶部有一斜向"书挡"的高大书架。它不完全"功能"（斜向的书挡部分不能有效地支撑书籍），也不是完全的"雕塑"（它可以放书）。Carlton在"家具"和"雕塑"之间制造了一种刻意的概念模糊——"它是什么？"这个问题比任何答案都重要。

L### 格雷夫斯的"Alessi 9093"鸟哨水壶（1985年）：Alessi历史上最畅销的厨房用品——锥形不锈钢壶体+塑料鸟形哨子+蓝色塑料把手。它是后现代设计商业化成功的象征——一个后现代"符号"（古典锥形+鸟哨+鲜明色彩）成功地成为了一个大众消费对象。

L### 孟菲斯与"风格"的自我意识：孟菲斯是第一个以如此自觉的方式将自身定位为"风格"的设计运动——它清楚地知道自己在创造一个"风格"，并将这一风格包装为一种媒体事件（1981年首展引发的轰动）。这是从"设计作为解决问题的活动"向"设计作为文化生产的活动"的转向。

## 四、逻辑梳理（论证链条+因果转折）

### L### 4.1 后现代设计的谱系

```
建筑理论（Venturi 1966 / Jencks 1977）
    ↓ 提供"意义""历史引用""双重编码"概念工具
    │
反设计/激进设计（1960s-1970s意大利）
    ↓ 提供"反功能主义"的实践先例和人员网络
    │
Studio Alchimia（1976-）
    ↓ Mendini："再装饰化"概念
    ↓ 1980年"Bau.Haus"展 → 直接面对包豪斯遗产
    │
Memphis（1981-1988）
    ↓ 索特萨斯带领年轻国际化团队
    ↓ 1981年首展全球轰动 → 后现代设计的"品牌化"
    │
Alessi的"Tea & Coffee Piazza"（1979-1983）
    ↓ 邀请11位国际建筑师设计茶/咖啡套装
    ↓ 将后现代建筑理论"压缩"为桌面设计
    │
后现代主义的商业化扩散（1980s）
    ├── Alessi、Swatch → 后现代设计的大众商品化
    ├── Philippe Starck → 后现代设计的"超级明星"模式
    └── 1980年代末 → 后现代主义在严肃设计批评中开始退潮
```

### L### 4.2 关键因果转折

- **索特萨斯离开Studio Alchimia（1981年）→ 建立孟菲斯：** 索特萨斯与Mendini在策略上的分歧——Alchimia以"不可生产的"画廊作品为主，索特萨斯则希望设计"可被工业制造"的产品——导致孟菲斯的诞生。这个分裂反映了"批判vs.生产"在后现代设计中的持续性张力。
- **1981年孟菲斯首展 → 全球媒体轰动 → 后现代"风格"的品牌化：** 展览被全球设计媒体广泛报道，《Domus》《Abitare》等杂志以及主流报刊均予以关注——孟菲斯成为少数被设计圈外的"一般文化公众"所知的设计运动之一。
- **1988年孟菲斯解散 → 后现代主义"运动"阶段的终结：** 索特萨斯在运动达到全球知名度的巅峰时选择解散孟菲斯——这一决定本身是反体制的（不让运动变成"品牌"）。但个别成员（如de Lucchi为Olivetti、Thun为Alessi）继续从事商业成功的后现代设计。

## 五、材料使用方式

### L### 5.1 原书对后现代主义的处理

Post-Modernism词条在原书中以谱系追溯为主——明确将"波普和反设计"列为后现代主义的"祖先"。原书对后现代设计的理论性论述（如文丘里和Jencks的思想）着墨较少——可能因为该书的"设计"导向，而非"建筑理论"导向。

### L### 5.2 孟菲斯词条的结构

Memphis词条（以及相关设计师词条）在原书中以"事件史"为主——1981年首展、核心成员、标志性作品、解散。对孟菲斯与更广泛的后现代文化（文学理论、电影、音乐）的交叉涉及较少。

---

## 六、论辩与阐述方法

### L### 6.1 "运动"叙事的维持

原书将后现代主义维持为一种"运动"叙事（有开始、高峰、结束），将孟菲斯作为其高峰和转折点——这种叙事清晰性有助于读者理解，但也可能简化了后现代主义在1980年代后以更弥漫的方式渗透到主流设计实践中的事实。

### L### 6.2 对后现代主义"商业化"的沉默判断

原书未明确批评后现代主义的"商业化"——但将Alessi的9093水壶描述为"Alessi历史上最畅销的产品之一"本身就暗示了一种判断：后现代设计从激进批判变成了商品。这种判断是隐含的，通过"成功"这一事实性表述本身来完成。

## 九、与前后章关联

### L### 9.1 向前承接

后现代主义从反设计/激进设计（第十二章）吸收了"反功能主义"的实践先例——Mendini和索特萨斯都是从反设计阵营转向后现代设计的核心人物。它也利用了符号学（Semiotics，第十五章）作为理论工具。后现代产品（尤其是Alessi系列）的"建筑师设计日用品"模式部分源自AEG（第三章）和Olivetti（第九章）的"设计师-工业家协作"传统——但将其从"企业功能主义"转向了"文化实验"。

### L### 9.2 向后开启

后现代主义的"超级明星设计师"模式（以Philippe Starck为标志人物）直接开启了1990s-2000s的"设计名人"时代（第十四章）。后现代主义对"意义"的强调为绿色设计（第十四章）的"设计物的道德叙事"提供了方法论先例。孟菲斯的解散（1988年）标志着"运动"模式在设计中的衰落——此后不再有包豪斯式或孟菲斯式的统一运动，取而代之的是个人化和微型化的设计策略网络。
