## 内容摘要

本书以"现代性（1900-1939）"与"后现代性（1940 至今）"两大时段为纲，十章（每章两节）系统考察设计在**消费、技术、身份**三个层面的文化角色：

- **Ch1 消费现代性**：Veblen 炫耀性消费 → 百货/广告/包装制度 → 女性消费者与品味扩张（L141-328）
- **Ch2 技术的影响**：美国制造体系、泰勒制、流水线 → 电木/铝/人造丝等新材料与现代美学（L329-492）
- **Ch3 工业设计师**：莫里斯至包豪斯的艺术-工业调和 → 美国咨询设计师（Loewy、Teague 等）职业化（L493-646）
- **Ch4 现代主义与设计**：功能主义理论谱系 → De Stijl/构成主义/包豪斯 → 国际风格与制度霸权（L647-804）
- **Ch5 设计身份**：世界博览会与民族风格 → 公司识别与极权国家挪用（L805-968）
- **Ch6 消费后现代性**：战后富足社会与"美国化" → 消费文化理论化（Baudrillard、Bourdieu）与遗产产业（L969-1193）
- **Ch7 技术与设计新联盟**：尼龙/乳胶等丰裕材料 → Walkman 以来的数字设计与生活方式（L1194-1394）
- **Ch8 设计师文化**：意/北欧/英/美/日设计师谱系 → 明星设计师与设计思维（L1395-1591）
- **Ch9 后现代主义与设计**：现代设计危机（波普/乌尔姆/反设计）→ 后现代理论与实践（Memphis、Alessi）（L1592-1768）
- **Ch10 重新设计身份**：全球化国家品牌（含中国）→ 设计伦理化与设计重定义（L1769-1946）

## 核心论点与关键概念

- **核心论点**：设计是现代及后现代文化的**中枢性构成要素**——它同时是消费资本主义的工具、社会身份（阶级/性别/国家/个人）的符号资源、技术变迁的物质转译；设计史应"去英雄化"，转向消费与日常（L40-56）。
- **关键概念**：消费文化（L237-328）、炫耀性消费（L141-236）、批量生产（L31-33）、新材料（L39-46）、流线型（L42、L45）、现代主义/功能主义/国际风格（L65-81）、国家身份/公司识别（L805-968）、生活方式（L108-110）、遗产产业（L115-116）、设计师文化（L1395-1591）、设计思维（L181-184）、后现代主义（L1652-1768）、可持续性与社会创新（L118-121、L162-164）。
- **理论谱系**：Veblen → Galbraith → Packard → Baudrillard → Bourdieu → Bauman（消费理论）；Williams → Hoggart → Hebdige → Hall（文化研究）；Lyotard → Jameson → Harvey → Huyssen（后现代理论）；Pevsner → Giedion → Banham（设计史自身）。

## 方法论与材料

- **史料**：以二手研究文献为主体（设计史、文化研究、消费社会学），辅以设计师自传、公司史、展览目录与网络档案（第三版新增，访问时间标注 2012，如 L2675-2682、L2855-2858）。
- **方法**：时期-主题双轨制；理论-案例互证；跨国比较（英美欧日意斯堪的纳维亚）；性别视角贯穿；制度分析（学校、博物馆、协会、公司、博览会）。
- **引用系统**：章末 Notes 编号注释（L2295-2880）+ 每章推荐/延伸阅读导语（L2931-3272）。

## 历史地位与影响

- 英语世界使用最广的设计文化导论之一（1986 首版，本版为 2013 第三版），是把"消费文化"与"身份"议题系统引入设计史教科书的开创性著作。
- 与 1986 年版相比，第三版新增/强化：全球语境（中国、日本）、可持续性、数字技术、设计思维与社会创新——反映了设计史学科 2000 年后的伦理转向。
- 与同书 1986 年版（report-book 已有分析）构成版本对照：本版在"当代端"（T10 全球化-伦理簇）的结构权重显著上升。

## 成就与限度

**成就**：框架自洽（镜像结构）、教学性强（推荐阅读质量高）、理论整合度好（消费理论+文化研究+设计史三线合一）、性别视角贯穿、第三版时效更新到位。

**限度**：欧洲/英语中心（非洲、拉美、印度缺席；中国仅以制造/国家项目出现）；理论密度不均（Ch6.2/Ch9.2 过密 vs Ch2/Ch7 偏技术叙述）；二手依赖为主；"后现代性 1940 起"的时段界定与 Ch6 内文"现代性之梦"存在张力；OCR 文本有少量识别噪声（不影响语义）。

## 一句话概括
