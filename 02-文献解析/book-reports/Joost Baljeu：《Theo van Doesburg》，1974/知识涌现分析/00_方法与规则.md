# 00 方法与规则：知识涌现分析框架

---

## L1 分析对象与来源

### L1.1 分析对象
本知识涌现分析以"F:/Design-history-知识元/report/Joost Baljeu：《Theo van Doesburg》，1974/分析报告/"中的31份章节分析报告为直接加工对象。这些报告是对Joost Baljeu著《Theo van Doesburg》（1974）全书内容的系统化分析，已完成了从原始英文文本到中文结构化分析的第一层转化。

### L1.2 知识元来源层级
知识涌现分析的原材料按抽象层级分为三个来源层：

| 层级 | 来源 | 知识元密度 | 知识元类型 |
|------|------|-----------|-----------|
| **L0 原始层** | Baljeu原书文本（英文，约509KB） | 待挖掘 | 人物、作品、概念、事件、地点、文献——以自然语言形态存在 |
| **L1 分析层** | 31份章节分析报告（中文结构化） | 已提取 | 每份报告的"八、实体清单"中已显式标注六类实体 |
| **L2 聚合层** | NN_专项报告与实体总索引（中文聚合） | 已聚合 | 六类实体的跨章完整索引 + 十二大论辩策略 |

### L1.3 本分析的工作定位
知识涌现分析属于**L3层加工**——在L1分析层和L2聚合层的基础上，执行三项核心操作：
1. **知识元语意标注**：为每一个知识元赋予语意类型标签和属性向量
2. **语义链接构建**：识别知识元之间的各类关联，构建有向有权语义链接网络
3. **涌现计算**：通过网络的拓扑分析和路径计算，发现L1/L2层中未显式陈述的新知识

## L2 知识元（Knowledge Element）定义与分类体系

### L2.1 知识元的操作性定义
**知识元**是构成Baljeu全书知识体系的最小独立意义单元。在本分析中，知识元来自L1分析报告"八、实体清单"中已提取的六类实体，经去重、归一化和语意标注后形成。

### L2.2 知识元六分类体系
继承L1层分析报告的六类实体分类，并在L3层增加语意子类型：

#### L2.2.1 人物知识元（Person-KE）
- **编码前缀**：`P-`
- **定义**：在Van Doesburg生平、De Stijl运动史及相关思想史中出现的真实历史人物
- **语意子类型**：
  - `P-ARTIST`：艺术家/设计师/建筑师（如Mondrian, Oud, Rietveld）
  - `P-THEORIST`：理论家/哲学家（如Hegel, Schoenmaekers, Wölfflin）
  - `P-PATRON`：赞助者/出版者/机构代表（如Rosenberg, Gropius）
  - `P-ALTEREGO`：Van Doesburg的化名身份（Bonset, Camini）
- **属性槽**：姓名_原文, 生卒年, 国籍, 与VanDoesburg关系类型, 首次出场章, 核心关联章

#### L2.2.2 概念知识元（Concept-KE）
- **编码前缀**：`C-`
- **定义**：在全书理论论述中出现的关键艺术/哲学概念、术语和范畴
- **语意子类型**：
  - `C-STYLE`：艺术风格/运动概念（如Neo-plasticism, Elementarism, Dada）
  - `C-PHILOSOPHY`：哲学概念（如counterpart vs opposite, the oppositionless）
  - `C-FORMAL`：形式/技法概念（如diagonal, moto-stereometric, interpenetration）
  - `C-SPATIAL`：空间概念（如fourth dimension, space-time, universal space）
- **属性槽**：术语_原文, 首次提出章, 核心发展章, 来源人物/文献, 演化方向

#### L2.2.3 作品知识元（Work-KE）
- **编码前缀**：`W-`
- **定义**：Van Doesburg及De Stijl相关艺术家的具体绘画、建筑、设计作品
- **语意子类型**：
  - `W-PAINTING`：绘画
  - `W-ARCHITECTURE`：建筑/建筑模型
  - `W-INTERIOR`：室内设计/装饰
  - `W-LITERARY`：文学/诗歌/Dada文本
  - `W-MANIFESTO`：宣言/纲领性文本
- **属性槽**：作品名_原文, 创作年份, 媒介类型, 关联章, 历史命运（存世/已毁/未建）

#### L2.2.4 事件知识元（Event-KE）
- **编码前缀**：`E-`
- **定义**：在Van Doesburg生平与De Stijl运动史中的关键历史事件
- **语意子类型**：
  - `E-BIO`：生平事件
  - `E-INSTITUTIONAL`：制度性事件（创刊、展览、会议）
  - `E-CONFLICT`：冲突/决裂事件
  - `E-INTELLECTUAL`：思想转向/突破事件
- **属性槽**：事件名, 日期, 关联章, 参与人物, 后果类型

#### L2.2.5 地点/机构知识元（Place-KE）
- **编码前缀**：`S-`（Space/Institution）
- **定义**：地理地点、建筑场所、艺术机构、出版物（杂志）
- **语意子类型**：
  - `S-GEO`：地理地点（如Utrecht, Weimar, Paris）
  - `S-INSTITUTION`：机构（如Bauhaus, Rijksmuseum）
  - `S-PUBLICATION`：出版物/杂志（如De Stijl, Mecano, G□）
- **属性槽**：名称_原文, 国家/城市, 在VanDoesburg生涯中的功能

#### L2.2.6 文献知识元（Document-KE）
- **编码前缀**：`D-`
- **定义**：书中引用、讨论或提及的出版物、手稿、宣言文本
- **语意子类型**：
  - `D-PRIMARY`：Van Doesburg本人的著作/文章/手稿
  - `D-SECONDARY`：他人著作/后世研究
  - `D-INFLUENCE`：对Van Doesburg产生影响的著作
- **属性槽**：文献名_原文, 作者, 年份, 关联章, 影响方向（施加影响/接受影响/被讨论）

### L2.3 知识元编码规则
每个知识元获得一个唯一编码，格式为：`{前缀}{三位序号}[-{别名}]`

示例：
- `P-001-Mondrian`：人物知识元001号，Mondrian
- `C-004-Diagonal`：概念知识元004号，diagonal
- `W-023-Aubette`：作品知识元023号，Aubette
- `E-017-Weissenhof`：事件知识元017号，Weissenhofsiedlung

## L5 知识涌现的操作性定义与计算规则

### L5.1 知识涌现的定义
在本框架中，**知识涌现**（Knowledge Emergence）指通过对知识元语义链接网络的计算分析，发现以下四类**在Baljeu原文及L1分析报告中均未被显式陈述的新知识**：

1. **隐性核心枢纽**：网络中连接度极高但在原文中未被明确标识为"核心"的知识元
2. **未申明的因果链**：跨越多个章节、由多条E-E-CAUSES链接构成的因果长链
3. **概念谱系中的断点**：概念演化序列（C-C-EVOLVES_INTO链）中缺失的中间环节
4. **非对称影响结构**：P-P-INFLUENCE链中显著的出度/入度不对称所揭示的权力/影响结构

### L5.2 涌现计算的四类算子

#### L5.2.1 中心性算子（Centrality Operator）
- **度中心性（Degree Centrality）**：DC(v) = deg(v) / (N-1)，其中deg(v)为节点v的度（忽略链接方向），N为网络节点总数
- **介数中心性（Betweenness Centrality）**：BC(v) = sum_{s≠v≠t} σ_st(v) / σ_st，其中σ_st为s到t的最短路径总数，σ_st(v)为经过v的路径数
- **特征向量中心性（Eigenvector Centrality）**：EC(v) ∝ sum_{u∈N(v)} EC(u)，节点的重要性取决于与其相邻节点的重要性
- **涌现判定规则**：BC(v)或EC(v)排名前10%但非`is_core=true`的节点→标记为"隐性核心枢纽"

#### L5.2.2 路径算子（Path Operator）
- **最长因果链发现**：在网络中搜索由E-E-CAUSES链接构成的最长简单路径
- **跨章概念漂移检测**：追踪同一概念C-C-EVOLVES_INTO链上各节点的source_chapters分布，识别概念意义的渐进变化
- **涌现判定规则**：长度≥4的因果链→标记为"深层因果结构"；概念漂移幅度超过阈值的演化→标记为"概念突变"

#### L5.2.3 社团检测算子（Community Detection Operator）
- **模块度最大化**：将网络划分为若干社团，使得社团内部链接密度显著高于社团间
- **桥接节点识别**：连接不同社团的关键节点
- **涌现判定规则**：桥接两个或以上社团但原文未强调其"跨界性"的节点→标记为"隐性桥梁人物/概念"

#### L5.2.4 时序对齐算子（Temporal Alignment Operator）
- **时间轴映射**：将事件知识元和作品知识元按其年份映射到时间轴（1883-1931）
- **前驱-后继关系计算**：在时间轴上识别概念首次出现与其作品体现之间的时间差
- **涌现判定规则**：时间差异常的"概念→作品"实现延迟（如概念提出后多年才有对应作品）→标记为"理论-实践延迟现象"

### L5.3 权重计算复合规则
语义链接的最终权重由以下因素合成：

```
W_final = W_base × (1 + α×F_cross_chapter + β×F_baljeu_emphasis + γ×F_mutual_reinforcement) / (1 + δ×F_isolation)
```

其中：
- `W_base`：链接子类型的权重基数（见L4.2-L4.7）
- `F_cross_chapter`：证据跨章分布因子（= evidence_chapters数量 / 总章节数）
- `F_baljeu_emphasis`：Baljeu强调程度因子（CENTRAL=1.0, SUPPORTING=0.5, MENTIONED=0.2, IMPLIED=0.0）
- `F_mutual_reinforcement`：双向互证因子（若source和target之间存在反向链接则加0.3）
- `F_isolation`：孤立因子（若节点仅有一条链接则加1.0，否则为0）
- `α, β, γ, δ`：调节系数，默认值分别为0.3, 0.5, 0.2, 0.5

## L6 知识元语意分析的操作规程

### L6.1 语意标注三原则
1. **来源可溯原则**：每个知识元的每个属性值，必须能在L1分析报告中找到对应的原文支撑（通过`source_chapters`字段追溯）
2. **分类互斥原则**：每个知识元属于且仅属于一种`ke_type`（六分类），但可以通过语义链接与其他类型知识元建立关联
3. **层级继承原则**：L2聚合层（NN_专项报告）中已确认的实体属性，在L3层直接继承，不做二次判断

### L6.2 语意标注执行顺序
1. **实体抽取与去重**：从31份L1分析报告的"八、实体清单"中提取所有六类实体，以英文/原文名称为主键进行去重
2. **跨章属性合并**：同一实体在多个章节中出现时，合并其各章中的属性信息
3. **语意子类型标注**：根据L2.2中的语意子类型体系，为每个知识元标注子类型
4. **属性槽填充**：逐项填充通用属性和专有属性
5. **核心性初步判定**：根据在NN_专项报告中的出场频率和Baljeu的论述比重，初步标记`is_core`

### L6.3 质量检验规则
- **完整性检验**：NN_专项报告中列出的所有实体必须在L3知识元库中找到对应项
- **一致性检验**：同一知识元在不同章节的source_chapters中不应出现矛盾属性（如生卒年冲突）
- **链接密度检验**：孤立的（度=0）知识元占比应<5%；若超过，需重新审查抽取是否遗漏了链接

## L7 语义链接构建的操作规程

### L7.1 链接提取三来源
1. **显式提取**：从L1分析报告的"九、与前后章关联"和"四、逻辑梳理"中直接提取已陈述的人物关系、概念演化、事件因果
2. **共现提取**：若两个知识元在同一章节的同一小节中被共同讨论，且在NN_专项报告中有明确的交互描述，则建立相应链接
3. **推理提取**：对跨章分布的隐性链接——如概念A在第N章首次提出，在第M章被应用，在第K章被修正——建立C-C-EVOLVES_INTO链

### L7.2 链接构建规则
- **方向性规则**：INFLUENCE类链为单向（source→target）；COLLABORATION类链为双向
- **最小证据规则**：每条链接的`evidence_chapters`必须至少包含一个章节编号
- **权重上限规则**：W_final ∈ [0, 1]，超出此区间的取边界值
- **无自环规则**：source ≠ target（知识元不链接自身）

### L7.3 链接质量分级
| 等级 | 标识 | 条件 |
|------|------|------|
| **S级（确证链接）** | `W_final ≥ 0.8` | Baljeu原文显式陈述 + 多章证据 + 核心论点地位 |
| **A级（强链接）** | `0.6 ≤ W_final < 0.8` | 有明确原文支撑，但非全书核心论点 |
| **B级（中链接）** | `0.4 ≤ W_final < 0.6` | 基于共现或合理推理，原文间接支撑 |
| **C级（弱链接）** | `W_final < 0.4` | 推理链接，需在知识发现报告中标注"待验证" |

## L8 知识发现报告撰写规范

### L8.1 发现类型与呈现格式
知识发现报告（04_知识发现报告.md）应包含以下发现类型：

1. **网络拓扑发现**：基于中心性分析的隐性枢纽节点、桥接节点
2. **因果结构发现**：基于路径分析的深层因果链、事件因果图
3. **概念演化发现**：概念谱系中的突变点、融合点、断裂点
4. **非对称影响发现**：影响结构中的权力不对等、单向影响
5. **时间-空间发现**：基于时序对齐的理论-实践延迟、地理中心转移

每种发现应包含：
- 发现编号（F-{类型}-{序号}）
- 发现陈述（一句话核心判断）
- 支撑证据（引述相关的知识元编码和链接编码）
- 新颖性判定（Baljeu原文是否已陈述 vs 本分析计算得出）
- 学术意义评估（该发现对Van Doesburg研究/De Stijl研究可能带来的新见解）

### L8.2 知识涌现的验证标准
任何"涌现"的新知识必须满足以下三个条件：
1. **非显式性**：在Baljeu原文及L1分析报告的显式陈述中搜索不到相同的命题表述
2. **可计算溯源**：能通过本框架的计算过程（中心性/路径/社团/时序）复现推导路径
3. **可解释性**：能在Van Doesburg/De Stijl的艺术史语境中对发现做出合理的学术解释
