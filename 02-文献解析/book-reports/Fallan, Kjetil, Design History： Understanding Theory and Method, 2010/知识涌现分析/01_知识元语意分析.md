# 01_知识元语意分析：六类实体的全文语义载荷

**基准**：3311 行版（L###）

---

## 〇、总述：五种论证功能

本书的知识元在论证中承担五种功能，先总述再分表：

1. **因果节点**（驱动论证链的源头/枢纽）：艺术史遗产（L119-131）、学科制度化事件（DHS 1977，L81）、SCOT（L441）——它们是"为什么设计史是今天这样"的因。
2. **结构变量**（组织论述框架的范畴）：ism（L686-937）、范式（L827-889）、生产/消费（L180-184）——它们是分析的设计维度。
3. **类型标签**（用于归类对象）：现代主义/后现代主义/流线型/艺术装饰（L716、L876）——主义名充当分类器。
4. **证据载体**（支撑命题的实例）：2CV（L579）、Pruitt-Igoe（L903）、iPod 专利（L37）、挪威产品插图（全书）——个案承担"例证"功能。
5. **参照坐标**（作者立场借以定位的锚点）：Wilde（L99）、Latour（L458-521）、Kuhn（L827）——引证人物为作者判断提供权威坐标。

---

## 一、人物（行动者）

**语义载荷**：人物是"理论资源-立场阵营"的携带者。作者对人物的处理是双重的：既引其言（证据载体），又评其论（参照坐标），且几乎人人获得"肯定+批评"双重待遇。

| 人物 | 做什么/指什么 | 为何存在（论证功能） | 证据 |
|---|---|---|---|
| Bruno Latour | ANT 创始人、非人行动者论者 | 因果节点+参照坐标：为"设计史需网络思维"提供理论源头 | L458-521 |
| Madeleine Akrich | 脚本概念提出者 | 因果节点：脚本工具的唯一来源 | L529-564 |
| Roger Silverstone | 驯化概念提出者 | 因果节点+证据载体："domesticating domestication"的自我指涉 | L595-648 |
| Thomas Kuhn | 范式理论作者 | 结构变量+参照坐标：第三章后半的评估对象 | L827-884 |
| Victor Margolin / Adrian Forty | 论战双方 | 事件性知识元：1990s 学科身份之辩的轴心 | L225-251 |
| Jeffrey Meikle | 美国设计史家 | 证据载体+参照坐标：文化史范例作者兼论战仲裁者 | L243-247、L363-365 |
| John Heskett | 工业设计史奠基者 | 因果节点：工业设计史"按自身条件书写"的先驱 | L176-184、L878 |
| Daniel Miller | 物质文化研究旗手 | 结构变量+参照坐标：消费/使用之辨的对象 | L269-297 |
| 虚构人物（Ford Prefect 等） | 小说角色 | 类型标签：概念的"形象化定义"（脚本/非人行动者） | L454、L525、L583 |

## 二、著作/作品

**语义载荷**：著作是"论点库"——每部被引著作浓缩为一个或几个命题供作者调用、评点或反驳；书评式处理（内容+贡献+局限）使著作成为可拆卸的论证模块。

| 著作 | 语义载荷（代表什么命题） | 证据 |
|---|---|---|
| Pevsner《Pioneers of the Modern Movement》 | 设计史"英雄式/神话式"传统的原点 | L77、L817 |
| Giedion《Mechanization Takes Command》 | 匿名史先声（进步但有局限） | L141-143 |
| Heskett《Industrial Design》（1980） | 工业设计史独立宣言 | L176 |
| Miller《Material Culture and Mass Consumption》（1987） | 物质文化研究对设计史的挑衅与启示 | L271 |
| Latour《Science in Action》（1987） | ANT 方法规则的来源 | L471-483 |
| Kuhn《The Structure of Scientific Revolutions》（1962） | 范式-革命模型的来源 | L827 |
| Jencks《The Language of Post-Modern Architecture》 | 后现代主义"神话书写"的反面教材 | L903-909 |
| 小说群（Underworld、Hitchhiker's、Teori og praksis 等） | 概念的文学意象载体 | L9、L454、L525、L589、L605 |

## 三、概念

**语义载荷**：概念是本书的第一主角——全书本质上是"概念工程"：引入（ANT/脚本/驯化）、重构（ism→文化模式）、移植（范式→设计史）、辨析（现代/现代性/现代主义）。

| 概念 | 做什么/指什么 | 为何存在 | 证据 |
|---|---|---|---|
| ism | 作为文化模式的意识形态范畴 | 结构变量：第三章全部论证的对象 | L686-937 |
| design culture | 设计史的研究对象域升级 | 结构变量：全书落点 | L943-951 |
| seamless web of sociodesign | 设计-社会互构隐喻 | 类型标签：第二章的总框架 | L390-392 |
| ANT / script / domestication | 三个 STS 工具 | 因果节点：第二章的主体内容 | L452-672 |
| paradigm（含三层次） | 科学变革结构 | 结构变量：ism 分析的框架 | L827-889 |
| black box | 稳定化/不可见化机制 | 类型标签：贯通 ANT 与 ism | L473、L821 |
| ideology-practice co-production | 设计文化的运作方式 | 结构变量：ism 定义的落点 | L762 |

## 四、机构

**语义载荷**：机构是"制度化的学科时间线"——学会/期刊/会议构成设计史学科身份的物质载体（L81-91）；企业机构充当产品案例的所有者（插图）；博物馆分裂（L400）象征学科分工。

|---|---|---|
| Design History Society（1977） | 英国学科建制化起点 | L81 |
| Journal of Design History（1988） | 学科话语平台与主题多样性证据 | L83、L201-213 |
| Design Issues / Design Studies | 论战发生地 | L85、L217、L225 |
| Block（1979-1989） | 新艺术史/激进设计史阵地 | L105-115 |

## 六、事件

**语义载荷**：事件是"时间锚点"——学科制度事件（成立/创刊/会议）构成史学史叙事骨架；产品/技术事件（2CV 1948-1990、Pruitt-Igoe 1972）充当论点例证；论战事件（1992-1995）是学科身份博弈的浓缩。

|---|---|---|
| 1977 DHS 成立 | 学科自觉的标志 | L81 |
| 1988 JDH 创刊 | 学科话语制度化 | L83 |
| 1992-1995 Margolin-Forty 论战 | 学科身份之争的高潮 | L225-265 |
| 1972 Pruitt-Igoe 爆破 | 后现代主义"死亡宣告"神话 | L903-907 |
| 2008 Falmouth "Networks of Design" | ANT 进入设计史的里程碑 | L519 |
| 1987/1991 米兰史学会议 | 史学国际化的早期节点 | L91、L172 |
