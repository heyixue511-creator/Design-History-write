# 00_方法与规则

## L001 文档定位与功能

本文件是"知识涌现分析"系列文档的方法论基石，承担五项功能：（1）界定"知识涌现分析"（Knowledge Emergence Analysis）的理论基础与操作范式；（2）定义"知识元"（Knowledge Unit）的提取标准与语义标注规则；（3）规定语义链接网络（Semantic Link Network）的构建方法；（4）解释知识涌现计算的技术原理与操作流程；（5）建立知识发现报告的验证标准。本文件为01至04号文档提供统一的方法论框架和操作规则。

## L002 知识涌现分析的理论基础

### L002-1 核心概念：何为"知识涌现"

"涌现"（emergence）取自复杂系统科学——系统的宏观行为不能从微观组分的行为简单推导，而是由组分间的非线性交互"涌现"而出。将其应用于知识分析：**知识涌现 = 通过对知识元及其语义链接网络的系统化分析，揭示原始文本中未被明确表述、但隐含于知识元间关系结构中的新命题、新模式与新洞见。**

这一概念的操作化需满足三个条件：
1. **知识元可识别性**：可从文本中提取离散的、语义自足的"知识单元"
2. **链接可计算性**：知识元之间的语义关系可被形式化表示和量化
3. **涌现可验证性**：被识别的新知识必须具有"反事实性"——不能直接从原始文本的任何单一句子推导出来，而必须依赖多个知识元间的关系结构

### L002-2 理论谱系

本方法融合了以下四支学术传统：

| 传统 | 来源 | 在本分析中的应用 |
|------|------|------------------|
| 知识工程（Knowledge Engineering） | Feigenbaum (1983); Schreiber et al. (2000) | 知识元的提取、分类与形式化表示 |
| 语义网络（Semantic Networks） | Quillian (1968); Sowa (1984) | 语义链接的类型定义与网络构建 |
| 复杂网络分析（Complex Network Analysis） | Barabási (2002); Watts & Strogatz (1998) | 网络拓扑指标的量化计算 |
| 文本挖掘与NLP | Hearst (1999); Blei et al. (2003) | 语义相似度、主题模型的辅助计算 |

### L002-3 与Manovich"软件研究"方法论的对位

本分析在方法论层面构成与Manovich自身研究策略的"镜像关系"：
- Manovich从**软件界面**逆向追溯文化逻辑 → 本分析从**分析报告文本**逆向追溯知识结构
- Manovich使用**生物学隐喻**（杂交、进化、物种） → 本分析使用**网络科学隐喻**（节点、边、聚类、涌现）
- Manovich揭示**软件的物质性** → 本分析揭示**知识的拓扑性**

## L003 知识元的定义与提取规则

### L003-1 知识元的形式定义

一个 **知识元**（Knowledge Unit, KU）是一个五元组：

```
KU = (ID, Type, Content, Context, Source)
```

其中：
- `ID`：唯一标识符，格式为`KU_XXX`（XXX为三位数字）
- `Type`：知识元类型，取值为下文规定的七种类型之一
- `Content`：知识元的命题化文本（≤100字，以完整断言句表述）
- `Context`：知识元在源文本中出现的位置锚点（章节编号+L###序号）
- `Source`：知识元的来源标记（"原著作"/"分析报告"/"跨文本推断"）

### L003-2 七种知识元类型

| 类型代码 | 类型名称 | 定义 | 判断标准 | 与前期实体的对应 |
|----------|----------|------|----------|------------------|
| KU-C | 概念型（Concept） | 表达一个独立的理论概念、范畴或术语定义 | 可回答"X是什么？" | 对应NN文件之"概念实体" |
| KU-E | 实体型（Entity） | 指涉一个具体人物、软件、机构、事件或论著 | 可回答"X是谁/什么？" | 对应NN文件之六类实体 |
| KU-P | 命题型（Proposition） | 表达一个完整的理论断言或因果判断 | 可判定真/伪/可辩论 | 对应各章核心论题与关键论点 |
| KU-R | 关系型（Relation） | 显式表达两个或多个知识元之间的语义关系 | 至少含两个非关系型KU的引用 | 对应各章"与前后章关联" |
| KU-M | 方法型（Method） | 表达一种分析策略、研究方法或论证技术 | 可回答"如何分析/论证？" | 对应各章"论辩与阐述方法" |
| KU-EV | 证据型（Evidence） | 表达支持某命题的具体案例、数据或材料 | 可回答"理由/证据是什么？" | 对应各章"关键论点与案例"中的案例 |
| KU-H | 历史型（Historical） | 表达一个时间锚定的历史事件或过程陈述 | 含明确的时间标定 | 对应NN文件之"事件实体" |

### L003-3 知识元提取的操作规则

**规则R1（自足性）**：每个KU必须在语义上自足——脱离上下文仍可被理解。若原文中的断言依赖上下文代词或省略成分，需补全后再提取。

**规则R2（原子性）**：每个KU应尽可能只表达一个断言。若原文一段含多个独立断言，应拆分为多个KU，并通过KU-R链接其原始共现关系。

**规则R3（可链性）**：每个KU在提取时必须标注其"可能链接目标"——在提取时刻由分析者预判至少2个可与之建立语义链接的其他KU。

**规则R4（源一致性）**：每个KU的Source字段只能有一个值。跨文本推断的KU标为"跨文本推断"，不能以原始文本的匿名化形式伪装为"源自原著作"。

**规则R5（层级性）**：知识元之间允许层级关系（KU is_a KU, KU part_of KU），但不强制将所有KU归入单一树状层级——允许网状、半结构化分类。

**规则R6（完备性）**：对于全书每一章，需提取的KU总数不少于15个（含7种类型）。对于NN文件中的专项报告，同样适用。

## L004 语义标注规则

### L004-1 语义链接的类型学

知识元之间的语义链接（Semantic Link）分为六种基本类型：

| 链接类型 | 标识符 | 定义 | 示例 |
|----------|--------|------|------|
| 因果链接 | SL-因果 | A导致/促进/驱动B | "数据结构标准化（SL-因果→）杂交化可能" |
| 层级链接 | SL-层级 | A是B的上位/下位概念 | "文化软件（SL-层级→）媒介软件" |
| 类比链接 | SL-类比 | A与B在结构/功能上相似 | "元媒介进化（SL-类比→）生物物种进化" |
| 对立链接 | SL-对立 | A与B在语义上构成对立/张力 | "多媒体（SL-对立→）杂交媒介" |
| 时序链接 | SL-时序 | A在时间上先于B | "Sketchpad 1962（SL-时序→）Photoshop 1989" |
| 证据链接 | SL-证据 | A为B提供证据支持 | "Photoshop滤镜分析（SL-证据→）不存在数字媒介" |

### L004-2 链接强度的三级标度

每条语义链接需标注其强度：

| 强度 | 值 | 判定标准 |
|------|-----|----------|
| 显式 | 1.0 | 源文本中明确使用因果/对比/归属等逻辑词连接 |
| 隐含 | 0.7 | 源文本在相邻段落或同一论证链中暗含此关系，需分析者推理 |
| 推断 | 0.4 | 跨章节、跨文本的关联，源文本未直接建立的连接 |

### L004-3 语义链接的标注格式

每条语义链接记录为一个六元组：

```
SL = (源KU_ID, 目标KU_ID, 链接类型, 强度, 证据文本位置, 标注者置信度)
```

其中"标注者置信度"为0-1之间的数值，表示分析者对该链接存在性的主观确信程度。

## L005 语义链接网络构建规则

### L005-1 网络的形式定义

语义链接网络（Semantic Link Network, SLN）定义为一个有向加权图：

```
SLN = (V, E, W, T)
```

其中：
- `V` = 所有知识元的集合（节点）
- `E` = 所有语义链接的集合（边）
- `W: E → [0,1]` = 链接强度函数
- `T: V → {KU-C, KU-E, KU-P, KU-R, KU-M, KU-EV, KU-H}` = 节点类型函数

### L005-2 网络构建步骤

**步骤1（节点准备）**：从01号报告中提取全部知识元，验证其五元组完整性，生成节点表。

**步骤2（边构建）**：依据04号规则，为每对可链接的知识元标注语义链接类型和强度，生成邻接矩阵。

**步骤3（多模态整合）**：将六种链接类型对应的子网络整合为统一的多层网络——每个链接类型构成一个网络"层"（layer），六层叠加构成完整SLN。

**步骤4（拓扑验证）**：检查网络的连通性——是否所有节点都至少有一条边？是否存在孤岛（isolated nodes）？孤岛节点需重新审查是否需要补充链接或降级为非知识元。

### L005-3 网络拓扑指标

使用以下指标表征SLN的结构特征：

| 指标 | 定义 | 知识学解释 |
|------|------|------------|
| 度中心性 (Degree Centrality) | 节点的直接链接数 | 知识元的"概念影响力"——被引用/链接越多的KU理论重要性越高 |
| 中介中心性 (Betweenness Centrality) | 节点位于多少对节点间最短路径上 | 知识元的"桥梁性"——控制不同知识区域间信息流的枢纽 |
| 聚类系数 (Clustering Coefficient) | 节点的邻居之间互相链接的程度 | 知识元的"学派凝聚性"——高聚类区=紧密耦合的概念簇 |
| 模块度 (Modularity) | 网络自然分割为若干社团的程度 | 知识域的"自然分化"——社团=相对独立的知识子域 |
| 网络直径 (Network Diameter) | 最长最短路径的长度 | 知识域的"语义跨度"——从最远两个KU需要经过多少次概念中转 |

## L006 知识涌现的计算方法

### L006-1 涌现的量化定义

给定一个SLN，一个候选"涌现知识"EP（Emergent Proposition）需满足：

```
涌现度 E(EP) = f(Novelty, NonTriviality, StructuralDependence, Verifiability)
```

四个维度的操作化定义：

**新颖度（Novelty）**：EP是否出现在原始文本的任何句子中？0 = 与原文逐字匹配；1 = 完全无法从原文还原。计算公式：

```
Novelty(EP) = 1 - max_{s∈SourceText} cosine_similarity(embedding(EP), embedding(s))
```

阈值设定为0.65——若EP与源文本中最相似的句子的余弦相似度超过0.65，则不具备足够新颖度。

**非平凡性（NonTriviality）**：EP是否可通过单个已有KU的简单推论得出？0 = 可由1个KU通过一步逻辑演绎得出；1 = 需要3个以上KU的多步推理。

```
NonTriviality(EP) = min(1.0, (|required_KUs| - 1) / 3)
```

**结构依赖性（StructuralDependence）**：EP在多大程度上依赖于SLN的拓扑结构而非仅依赖于节点的语义内容？0 = 仅取决于2个KU的语义内容（=普通语义链接）；1 = 必须通过SLN的全局拓扑特征（如中心性差异、社团结构）才可揭示。

```
StructuralDependence(EP) = 是否调用全局拓扑指标？是=0.8，否=0.2
```

**可验证性（Verifiability）**：EP是否可以回到原文本中找到独立证据支持？0 = 无法验证；1 = 每个构成KU都有明确的文本证据。此维度不同于Novelty——一个命题可以是新颖的但仍可通过回溯原文验证其构成的合理性。

```
Verifiability(EP) = |可验证的构成KU| / |全部构成KU|
```

### L006-2 三类涌现机制

知识涌现可通过三种不同的机制产生：

**机制1：连接涌现（Connection Emergence）**
两个原本在源文本中未连接的知识元，通过SLN中的路径建立间接关联，从而产生新的组合性洞见。典型模式：A→B→C（A与C在原文本中不直接关联，但通过B的桥接产生新意义）。

**机制2：拓扑涌现（Topological Emergence）**
网络的全局拓扑特征（如中心性分布、社团结构、度相关性）揭示出仅看单个节点/边无法看到的宏观模式。典型模式：一个概念簇（社团）的"语义重心"揭示出原文本反复逼近但未曾命名的潜在主题。

**机制3：类比涌现（Analogical Emergence）**
SLN中两个结构相似但内容不同的子图被发现——揭示Manovich在不同领域/章节使用了相同/相似的论证结构。典型模式：子图同构（subgraph isomorphism）检测。

### L006-3 涌现度阈值

一个EP被认定为"有效涌现知识"的阈值设定为：

```
E(EP) ≥ 0.55 即认为该EP构成有效的"涌现知识"
```

此阈值的设计逻辑：要求EP在四个维度上的综合表现良好——单一维度极高不能弥补其他维度的不足。

## L007 知识发现的验证规则

### L007-1 三级验证标准

**L1验证（内部一致性）**：EP是否与SLN中的已有链接逻辑一致？是否存在与之矛盾的已有KU或SL？

验证操作：将EP的所有构成KU和链接标注后，检查SLN中是否存在与EP矛盾的链路。若存在且矛盾无法解释，则EP降级为"待修正"。

**L2验证（源文本回溯）**：EP的每个构成要素是否可以回到原著作和分析报告中找到独立的文本锚点？

验证操作：对每个构成KU标注Source位置，由另一位分析者独立核对每个锚点的原始上下文是否支持该KU的语义。

**L3验证（反事实检验）**：EP是否可能仅由研究者偏见（confirmation bias）驱动——即分析者预先持有某种立场，然后"发现"SLN支持该立场？

验证操作：由独立分析者尝试以相反的预设重新分析同一SLN——如果相反预设也能"发现"同样有说服力的EP，则原EP的可信度降低。

### L007-2 知识发现的权重分类

| 等级 | 标签 | 定义 | 报告中的呈现方式 |
|------|------|------|------------------|
| 一等发现 | 核心涌现 | E≥0.75, 通过L1+L2验证 | 全文详述，含完整推理链 |
| 二等发现 | 显著涌现 | E≥0.60, 通过L1验证 | 简述+核心数据 |
| 三等发现 | 可能涌现 | E≥0.55, 待L2验证 | 以"假设"形式提出，标明验证状态 |

## L009 与前期分析报告的关系

本系列文档（00-04）与前期分析报告（00-07, NN）构成**分析-元分析**的嵌套关系：

| 层次 | 文档 | 作用 | 产出物 |
|------|------|------|--------|
| 第一层 | 原著作（Manovich 2013） | 理论源 | 概念、命题、论证 |
| 第二层 | 分析报告（00-07, NN） | 文本分析 | 结构化解读、实体索引、概念网络 |
| 第三层 | 知识涌现分析（本文档系列） | 元分析 | 知识元语义网络、涌现知识、新发现 |

关键区分：第二层分析报告是对原文的**解读**和**结构化**——回答"Manovich说了什么、怎么说的"。第三层知识涌现分析是对解读的**再解读**——回答"从这些解读中，我们能发现什么原文未曾明言的知识"。这是知识生产层级的递进——从**再现**（representation）到**生成**（generation）。

本分析方法自身也构成一个"元媒介"：它不直接分析原著作，而是以分析报告的内容为"知识元"、"语义链接"和"涌现机制"的操作对象——正如Manovich的"元媒介"以已有媒介为内容。这一方法论的递归性并非巧合：知识涌现分析是对"软件研究"研究方法的软件式应用。
