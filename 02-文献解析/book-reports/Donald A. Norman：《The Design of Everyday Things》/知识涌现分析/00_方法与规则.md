# 00_方法与规则：知识涌现分析方法论

---

## 一、层级定义

本分析采用三层知识组织体系，从微观到宏观逐级涌现：

### 1.1 知识元（Knowledge Element, K）

知识元是知识涌现分析的最小不可分割单元。在本报告中，每一个独立实体（人物、著作、概念、机构、地点、事件）构成一个知识元。知识元是整个知识网络的节点（node），是语义链接的起始端或终止端。

知识元的标识格式：`K###_名称`，例如 `K001_示能性`。

每一个知识元携带以下元数据：
- **名称**（中/英）
- **类别**（六类之一：人物/著作/概念/机构/地点/事件）
- **语义功能**（五种之一，见 §2.2）
- **来源证据**（L### 行号引用）
- **所属层级归属**（被聚类后归属于若干 Topic）

### 1.2 Topic（话题/主题簇）

Topic 是从若干知识元经由语义链接聚集形成的中层知识结构。一个 Topic 包含至少 3 个知识元，这些知识元通过语义链接构成一个强内聚的局部子网络。

Topic 的标识格式：`T###_名称`，例如 `T001_示能性与约束理论`。

Topic 的特征：
- 具有明确的**语义边界**（该 Topic 讨论什么、不讨论什么）
- 其内部知识元之间的链接密度显著高于外部
- 一个知识元可同时归属于多个 Topic（交叉归属反映了知识的跨领域性质）

### 1.3 Theme（主题/知识板块）

Theme 是从若干 Topic 经由跨簇链接（cross-cluster links）聚集形成的宏观知识结构。一个 Theme 包含至少 2 个 Topic，代表该书论证体系中的一个**基本知识板块**。

Theme 的标识格式：`Θ###_名称`，例如 `Θ01_认知与设计的基础理论`。

Theme 的特征：
- 代表全书论证体系的**结构性支柱**
- 其内部的 Topic 之间存在经论证逻辑串联的**跨簇语义链接**
- Theme 之间同样可以存在跨 Theme 链接，构成全书的最高层知识拓扑

### 1.4 涌现命题（Emergent Proposition, P）

涌现命题是从知识元网络的拓扑结构中浮现的、不可还原为任何单一知识元的新知识命题。其"涌现"性质体现为：命题 P 的真实性依赖于多个知识元的联合结构，而无法从任何一个单独知识元中完整推导。

涌现命题的标识格式：`P###_命题陈述`。

## 二、九种语义链接类型

本分析定义九种语义链接类型，覆盖认知、因果、结构、类比和参照等关系维度：

| 符号 | 名称 | 定义 | 读写方向 | 示例 |
|------|------|------|----------|------|
| `→` | 推导链（Derivation） | A 是 B 的理论前提或逻辑前件，B 从 A 导出 | A→B：A 推导出 B | 七阶段行动模型 → 执行鸿沟（L313） |
| `⇒` | 因果链（Causation） | A 是 B 的原因或条件，B 是 A 的结果 | A⇒B：A 导致 B | 审美至上 ⇒ 可用性被忽视（L30） |
| `↔` | 互构链（Co-construction） | A 与 B 互相定义、互相支持、不可分离 | A↔B：A 与 B 互构 | 知识在头脑中 ↔ 知识在世界中（L61, L245） |
| `⊂` | 包含链（Containment） | A 是 B 的子类、子概念或组成部分 | A⊂B：A 是 B 的子集 | 捕获错误 ⊂ Slips（L65） |
| `≻` | 应用链（Application） | A（理论/原则）被应用于 B（实践/案例） | A≻B：A 应用于 B | 示能性 ≻ 门把手设计（L21-L31） |
| `≈` | 类比链（Analogy） | A 与 B 在结构或功能上相似 | A≈B：A 类比于 B | Carelman 咖啡壶 ≈ 现实中的糟糕设计（L171） |
| `:` | 参照链（Reference） | A 引述、引用或以 B 为理论资源 | A:B：A 参照 B | Norman : Gibson（L309） |
| `⇐` | 反馈修正链（Feedback-Revision） | B 的出现提供了反思 A 的经验基础，促使 A 被修正 | A⇐B：A 被 B 反馈修正 | POET 书名 ⇐ 商界误置（L13-L15） |
| `∼` | 张力链（Tension/Contradiction） | A 与 B 之间存在矛盾、对立或未解决的理论张力 | A∼B：A 与 B 矛盾 | 标准化 ∼ 个性化（L269-L275） |

## 三、六项涌现指标

### 3.1 知识元度数 k（Knowledge Element Degree）

k(K) = 知识元 K 的出入度之和（与之直接相连的其他知识元数量）。

- 高 k 值标识**hub 知识元**（网络中连接最广的节点）
- k ≥ 15 为核心 hub；k ≥ 10 为重要枢纽；k ≥ 5 为一般节点；k < 5 为外围节点

### 3.2 中介中心性 b（Betweenness Centrality）

b(K) = 知识元 K 位于网络中任意两个其他节点之间最短路径上的次数比例。

- 高 b 值标识**broker 知识元**（桥接不同知识簇的关键节点）
- 当 b(K) > 0.1 时，K 为一级桥接点；b(K) > 0.05 时为二级桥接点

### 3.3 簇结构（Cluster Structure）

将知识元网络通过社区检测算法（基于模块度最大化）划分为若干知识簇（Topic）。每个 Topic 内部链接密度高于外部。簇边界标识知识的自然分界。

### 3.4 内聚度（Cohesion）

Cohesion(T) = （Topic T 内部实际链接数）/（T 内部可能的最大链接数）

- Cohesion ≥ 0.6：强内聚 Topic
- 0.3 ≤ Cohesion < 0.6：中等内聚 Topic
- Cohesion < 0.3：松散 Topic

### 3.5 涌现强度 S（Emergence Intensity）

S = n(P) × ΣL_cross

其中：
- n(P) = 该层级涌现出的不可还原命题数量
- ΣL_cross = 该层级内所有跨簇语义链接的数量总和

S 值与知识的"创新密度"正相关。高 S 值意味着该层级的知识具有高度的结构化创新，超越了简单的事实累积。

### 3.6 层次化度量 H（Hierarchy Index）

H = （被组织为 Theme 的 Topic 数量）/（总 Topic 数量）×（Theme 数量）

H 度量知识体系的结构层次化程度。H 越高，说明知识组织越具有层次性；H 越低，说明知识越呈现扁平化分布。

## 四、证据规范

### 4.1 证据格式

所有知识元归属和语义链接均需附至少一处 `L###` 证据。证据引用自源文件 `F:/Design-history-知识元/00-book/Donald A. Norman：《The Design of Everyday Things》.md` 的行号。

格式示例：
- 单证据：`L313`
- 多证据：`L17, L39, L313`
- 跨章节证据：`L19（Ch4）, L61（Ch3）, L313（Ch2）`

### 4.2 证据层级

| 层级 | 类型 | 说明 |
|------|------|------|
| L1 | 直接陈述证据 | Norman 在正文中明确陈述的命题关系 |
| L2 | 可推断证据 | 基于多处文本的合理推断，标注 `[推断]` |
| L3 | 结构性证据 | 基于文本整体结构和论证逻辑的定位，标注 `[结构]` |

### 4.3 反例与边界

每一处涌现命题和核心语义链接应尽可能标注其**边界条件**（在何种条件下该命题可能不成立）和**反例**（Norman 自身是否提供了限制该命题的证据）。此规范确保分析的客观性和可证伪性。

反例标注格式：`[边界: 条件描述]` 或 `[反例: L###, 具体内容]`

### 4.4 引用完整性

本分析的所有 L### 行号均来自《The Design of Everyday Things》源文件。当引用"整体分析报告"中的 L 行号时，这些行号对应的原文内容已在各章节分析报告中得到双重验证。

## 五、分析流程

1. **知识元抽取与语义功能标注**（→ FILE 01）：从实体总索引中抽取所有知识元，赋予语义功能分类。
2. **语义链接识别与网络构建**（→ FILE 02）：识别所有知识元对之间的语义链接关系，构建语义链接网络。
3. **簇检测与涌现计算**（→ FILE 03）：将知识元聚类为 Topic，将 Topic 聚类为 Theme，计算各项涌现指标。
4. **知识发现与假设生成**（→ FILE 04）：从网络拓扑中识别结构性发现、隐藏 hub、潜在链接，生成知识假设。

---

## 六、分析限定

本分析基于《The Design of Everyday Things》1988/1990 年版文本及已有的七份分析报告，不涉及 Norman 在此之后的著作（如《Emotional Design》《Living with Complexity》等），也不涉及后人对 DOET 的引用和扩展（除非这些扩展被该七份分析报告明确涵盖）。

分析的任何"发现"限定在 DOET 文本内部的知识结构。跨文本的知识涌现（如 DOET 与 Gibson 原著之间的知识涌现）不属于本分析的范围，但可作为 C 类知识假设（参见 FILE 04）提出。
