# NN 专项报告与实体总索引

## 第一部分：专项报告

### 一、语言专项报告

《神话学》全书以法语写作，兼具学术论文的严密与文学随笔的灵动。语言特征如下：

1. **法语原文文本**：clean 版为法语原文，未作翻译，保留了巴特原文的句法风格——长句、破折号、分号堆叠、插入语与同位语（例：L4 的长句以破折号展开"ce-qui-va-de-soi"）。
2. **术语的中英对照**（详见第四节术语表）：核心术语如 mythe/parole/signifiant/signifié/signe/signification/sens/forme/concept 等，巴特在第二部分给出严格定义（L1776-1820）。
3. **新词（néologisme）的自觉使用**：sinité（L1867）、gouvernementalité（L1974）、bobétisme（L1021）、vaccine（L2204）、ninisme（L2240）、"bouvard et pécuchéité"（L2042）等。巴特在 L1862-1869 论证了新词的必要性。

### 二、文风专项报告

1. **格言式断言**：斩钉截铁的短句收束段落（L2116、L1723、L1991、L2267）。
2. **反讽与讥诮**：针对小资产阶级与官方话语的讽刺（L240-251、L704-732、L1298-1331）。
3. **隐喻化理论**：以"疫苗"（L2204）、"天平"（L2266）、"放血/流失"（L2115）、"被窃的语言"（L1991）、"捉迷藏"（L1836）等意象作为理论工具。
4. **第一人称在场**：全篇以"je"组织论证，承认立场与情感（L2、L4、L1732），拒绝客观主义伪装（L16-17）。

### 三、修辞方式专项报告

1. **对比法（二项对立）**：拳击/摔跤（L32-37）、酒/奶（L602-635）、水/油（L690-698）、凡尔纳/兰波（L658-679）、左翼/右翼神话（L2142-2271）、舞台/城市（L130-138）。
2. **类比/引喻**：汽车=大教堂（L1353）、玩具=吉瓦罗缩头（L474）、环法=荷马史诗（L922）、演员照片=涂油礼（L150）。
3. **反问与反诘**：L247、L396、L1500 等。
4. **排比与叠句**：L135-138（"A la scène…; à la ville…"）、L2204-2263（七种修辞格式的列举）。
5. **归谬法**：L805-810、L918（"埃斯库罗斯作为班图作者并不更假"）。
6. **典故与引用**：古典文学（伊索、莫里哀、拉辛、雨果、福楼拜）、哲学（马克思、萨特、布莱希特）、语言学（索绪尔、Damourette 与 Pichon）。

### 四、史料使用方式专项报告

1. **第一手大众文本**：报刊文章、广告、照片、电影、电视、体育、司法记录等作为分析对象（L2-3、L156、L519、L1353、L1442）。
2. **直接引用**：报刊语汇（L1232-1272 官方辞令；L337-340 Astra 广告语）、电影台词与情节（L652、L546）、法庭陈述（L388-393）。
3. **与学术文献对话**：索绪尔（L1755）、弗洛伊德（L1788）、萨特（L1771）、巴赫拉（L605）、莫斯（L842）、列维-斯特劳斯（L1233）、布莱希特（L555）。
4. **实证档案**：环法车手词表（L1009-1075）、非洲事务词汇表（L1226-1272）以"词典/词条"形式组织材料。
5. **局限性如实说明**：巴特自认材料选择"十分随意"（L3），个案随时代流逝部分过时（见整体报告"限度"节）。

### 五、阐述方法专项报告

1. **符号学还原**：把文本拆解为能指/所指/意指的三元系统（L1754-1820）。
2. **意识形态批判**：把符号学分析接到马克思式阶级分析与去政治化命题（L2106-2140）。
3. **现象学描述**：对感知、身体、物质的描述性分析（L499、L794、L1371）。
4. **人类学/民族志视角**：把大众文化当"异域"材料（L538、L1721）。
5. **自反性**：不断反思分析者自身的位置（L12-17、L2273-2314）。
6. **类型学建构**：三种阅读（L1944-1951）、七种修辞格式（L2204-2263）、三种命名状态（L2069-2071）。

### 六、推演逻辑专项报告

1. **归纳→系统化**：先以 54 篇个案累积现象（第一部分），再在第二部分作理论系统化（L8 自述）。
2. **定义→分层**：先立"神话=言说"的定义（L1723），再逐层添加限定（形式/历史/材料/二级系统）。
3. **二元对立驱动**：对象语言/元语言、意义/形式、左翼/右翼、本质/天平。
4. **否定→重构**：先拆解神话（阅读二），再提出"以神话反神话"（L2035-2037）。
5. **自反性收束**：把分析者纳入分析对象（L2273-2314），以未解两难作结。
