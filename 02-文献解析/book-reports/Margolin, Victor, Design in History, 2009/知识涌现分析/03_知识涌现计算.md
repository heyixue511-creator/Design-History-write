## 一、涌现计算的总流程与参数设定

### 1.1 计算流程

L### 涌现计算流程 L###

```
步骤1: 157个知识元的多维语意空间映射
        ↓
步骤2: 知识元对之间的语意距离矩阵 D(157×157) 计算
        ↓
步骤3: 社区检测(已有C1-C5) → 结构洞识别
        ↓
步骤4: 涌现潜力指数 EPI 计算 → 结构洞排序
        ↓
步骤5: 涌现候选生成 → 三重验证
        ↓
步骤6: 已验证涌现型知识元 (KE-EMG) 输出
```

### 1.2 权重参数设定

| 参数 | 符号 | 默认值 | 用途 |
|------|------|--------|------|
| 语义距离权重 | α | 0.3 | EPI公式中的语意距离贡献系数 |
| 中介中心性权重 | β | 0.4 | EPI公式中的桥接重要性贡献系数 |
| 局部密度权重 | γ | 0.2 | EPI公式中的局部稠密度贡献系数 |
| 冗余惩罚系数 | δ | 0.1 | EPI公式中的冗余信息惩罚系数 |
| 涌现阈值 | θ | 0.65 | EPI ≥ θ 的结构洞进入"高涌现候选"清单 |
| 信度阈值 | τ | 0.50 | 支撑链路平均权重 ≥ τ 的涌现候选通过验证 |

## 二、步骤1-2：多维语意空间映射与距离矩阵

### 2.1 语意空间的六个维度

每个知识元 i 被映射为一个六维语意向量：

```
V(i) = [EPI编码, ARG编码, DIS编码, POL编码, LVL编码, LNK编码]
```

其中每一维的离散取值的距离定义如下：

| 维度 | 距离计算规则 | 最大距离 |
|------|-------------|----------|
| EPI | 规范性↔描述性=1, 诊断性↔纲领性=2, 其他=1 | 3 |
| ARG | 前提↔呼吁=3, 证据↔结论=1, 其他按论证距离评估 | 3 |
| DIS | 设计史↔技术史=1, 设计史↔史学理论=2, 设计史↔科学哲学=3, 其他按学科亲疏 | 3 |
| POL | 批判↔肯定=2, 批判↔建设性=1, 中立↔肯定=1 | 2 |
| LVL | 元理论↔操作=3, 元理论↔方法论=1, 方法论↔专题=1 | 3 |
| LNK | 枢纽↔终端=2, 枢纽↔桥接=1 | 2 |

### 2.2 知识元对的语意距离矩阵

对157个知识元的两两配对，计算其六维语意距离的加权和：

```
D(i,j) = w1×d_EPI(i,j) + w2×d_ARG(i,j) + w3×d_DIS(i,j) + w4×d_POL(i,j) + w5×d_LVL(i,j) + w6×d_LNK(i,j)
```

其中w=[0.20, 0.20, 0.25, 0.10, 0.15, 0.10]——学科领域（DIS）权重最高（0.25），因为它是社区划分的主要驱动力。

|--------|------|
| 平均语意距离 | 1.47（在0-2.73范围内） |

| 距离>2.0（极高差异） | 约11%的知识元对——主要是C1诊断与C5元分析之间的远距离节点 |

## 三、步骤3：结构洞识别

### 3.1 结构洞的操作性定义

在语义链接网络中，**结构洞**定义为两个不同社区之间满足以下条件的位置：

1. 该位置处于两个（或更多）语义社区的边界
2. 该位置当前没有（或极少）语义链接穿过
3. 该位置的"两侧"节点具有较高的语意距离（D>1.5）

## 四、步骤4：涌现潜力指数(EPI)计算

### 4.1 EPI公式应用

对每个结构洞SH-j，计算其涌现潜力指数：

```
EPI(SH-j) =  α × NormDist(SH-j) + β × NormBC(SH-j) + γ × NormDensity(SH-j) - δ × NormRedun(SH-j)
```

其中NormDist、NormBC、NormDensity、NormRedun分别为各指标的归一化值（缩放到[0,1]）。

## 五、步骤5：涌现候选生成

### 5.1 候选生成方法

对每个高涌现候选结构洞，执行以下操作：

1. 提取该结构洞两侧的知识元集合 Left(SH-j) 和 Right(SH-j)
2. 识别在Left和Right之间虽然没有直接语义链接、但存在多条通过中介节点的"潜在路径"的知识元对
3. 对每个"潜在连接"，根据其两侧知识元的语意内容，生成一个"如果我们将Left的X与Right的Y结合起来，可能产生什么新判断？"的假设
4. 将假设形式化为一个候选的KE-EMG
