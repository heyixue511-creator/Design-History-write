# 00 方法与规则
> 本文件定义《Line and Form》（Walter Crane, 1900）知识涌现分析的方法框架，供 01-04 各报告共用。

## 一、层级定义

| 层级 | 定义 | 本报告中对应物 |
|---|---|---|
| 知识元（Knowledge Unit） | 六类实体：人物、著作/作品、概念、机构、地点、事件 | 如"轮廓线 Outline""辐射原则 Radiation""Dürer""帕特农神庙""装饰目的 Ornamental Purpose"等，均附行号证据 |
| Topic（强连通簇） | 语义上强连通、互为依赖的知识元聚类 | 如"线之语言/两途"簇、"控制边界/几何计划"簇、"浮雕三法"簇 |
| Theme（高层语义域） | 若干 Topic 聚合的高层语义域 | 如"线的本体论""装饰的几何学""材料与媒介的适应""图案与图画统一论" |

## 二、9 种语义链接判定标准

| 符号 | 类型 | 判定判据 | 示例（本书） |
|---|---|---|---|
| → | 因果 | A 引起/导致/产生 B，有因果动词或时间先后+因果语义 | 自然有机线（辐射+反复）→ 艺术采纳为装饰形（L742） |
| ⇒ | 条件 | A 是 B 的必要/充分条件；"若 A 则 B" | 若无几何控制网 ⇒ 图案无法和谐重复（L278、L292） |
| ↔ | 对比 | A 与 B 对举、相反、互为镜像 | 图绘目的 ↔ 装饰目的（L257-261） |
| ⊂ | 隶属 | A 是 B 的子类/成员/组成部分 | 轮廓线 ⊂ 线的表现手段；装饰目的 ⊂ 设计目的 |
| ≻ | 时序 | A 早于 B，构成发展/演变序列 | 希腊楣梁 ≻ 罗马圆拱 ≻ 哥特尖拱（L636-652） |
| ≈ | 空间共现 | A 与 B 在同一空间/场景/画面中共现，互为语境 | 帕特农檐壁与雕塑空间共现（L637-641） |
| : | 属性 | A 具有属性 B | 线：语言（L216）；壁纸：21 英寸方幅（L288） |
| ⇐ | 论证支撑 | A 为 B 提供证据/例证/依据 | 贝壳/鸟羽/骨骼 ⇐ 支撑"有机线"命题（L733-748） |
| ∼ | 同域 | A 与 B 属同一主题域，概念相近不必然互依 | 数量 ∼ 对比 ∼ 等价（Ch04 装饰计量域） |

## 三、涌现指标

| 指标 | 定义 | 说明 |
|---|---|---|
| 节点度 k | 知识元在网络中直接相连的边数 | 度越高越可能是枢纽 |
| 桥接值 b | 知识元连接不同 Topic 的边数 | 桥接值高者为跨域中介 |
| 簇识别 | 强连通分量（Topic）检测 | 簇内边数/节点数反映内聚 |
| 内聚度 | 簇内实际边数 / 簇内最大可能边数 | 衡量 Topic 紧密度 |
| 涌现强度 S | 一级涌现 E 与二级涌现 P 的支撑证据密度与去重论元数 | 用行号证据计数与独立论证单元数衡量 |
| 一级涌现 | 知识元直接组合产生的新结构单元 E | 如"两途+控制线+几何计划 ⇒ 装饰语法" |
| 二级涌现 | 一级结构跨 Topic 综合产生的命题 P | 如"图案必是图画 ⇒ 装饰即艺术之基" |

## 四、证据规范

- 全部链接、簇、涌现结构、命题均须附 clean 版行号证据（L###）。
- 不写代码、不做统计程序，涌现计算采用**人工逐条枚举+语义判断**的定性量化（计数以独立论证单元为准）。
- 客观性核对：对强断言列反例与边界（如克莱恩对"无规则"的自认 L300、L602）。
- 报告清单：01 知识元语意分析 → 02 语义链接网络 → 03 知识涌现计算 → 04 知识发现报告。
