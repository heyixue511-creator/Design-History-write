# 00_方法与规则

## 本分析的定位

本分析是在「分析报告」层之上的第二层元分析：第一层以逐章L###编码拆解全书知识元，第二层在此基础上对知识元之间的跨章涌现关系进行计算与发现。「知识涌现」指超出单章分析范围、仅在各章知识元之间发生非线性交互时才显现的结构性知识——包括跨章主题回路、隐性论辩轴、概念家族谱系、方法论交叉感染、实体共现网络等。

### 知识元的定义

**知识元**（Knowledge Unit）定义为L###编码下的一个独立分析单元。全书分析报告中共包含约240个L###编码单元（导论每章9节×22章≈198，加上整体报告9条L###和专项报告）。每个L###对应于以下九类编码之一：

| 节编码 | 知识元类型 | 语义角色 |
|--------|-----------|---------|
| L### X0 | 章节定位与功能 | 标识该章在全书论证结构中的位置与功能 |
| L### X1 | 结构分析 | 描述论证的构成部件与组织形式 |
| L### X2 | 内容分析 | 提炼核心论题与关键论点 |
| L### X3 | 逻辑梳理 | 展示论证链条的推进方式 |
| L### X4 | 材料使用方式 | 记录理论工具与经验材料的配置关系 |
| L### X5 | 论辩与阐述方法 | 归纳修辞策略与论证手法 |
| L### X6 | 语言文风 | 原文摘录与风格特征 |
| L### X7 | 实体清单 | 六类实体（人物/机构/概念/文献/作品/事件）的逐章索引 |
| L### X8 | 前后章关联 | 明确该章在全书知识网络中的邻接关系 |

### 涌现的定义与判定规则

**知识涌现**（Knowledge Emergence）在本分析中定义为满足以下至少一项判据的知识形态：

**判据A：跨章概念耦合**——两个或多个L###中出现的概念/术语，若其语义关系仅当同时阅读至少两个不同章节时方能被辨识，则构成涌现。例如：Buchanan（Ch8）的"技术推理"与Morgantini（Ch3）的"三代技术"之间的深层关联——前者提供了分析技术展示的修辞框架，后者提供了技术本身的本体论分期——这一关联不在任何单章中被明确讨论。

**判据B：隐性论辩轴**——全书各章之间存在未在00_整体分析报告中明确总结的论辩张力。例如：Vitta（Ch1）将设计界定为独立于艺术的文化领域，而Ashwin（Ch17）以艺术符号学方法分析设计绘图——两者之间的方法论矛盾在全书范围内构成"设计是否可被艺术学方法解读"的隐性论辩轴。

**判据C：概念家族谱系**——三个或以上分属不同章节的概念/术语共享一个知识来源或理论传统，但各自衍生出互有差异的使用方式。例如：Buchanan的"ethos"、Kinross的"中性修辞"、Ehses的"修辞格"均源于古典修辞学，但三者在设计语境中的使用构成了一个概念家族。

**判据D：实体共现网络**——两个或以上人物/机构/文献在三个或以上章节中被同时引用，且这种跨章共现揭示了某种不被单章讨论的知识社群或思想谱系。例如：Barthes在Vitta（Ch1）、Selle（Ch5）、Kinross（Ch12）、Lupton（Ch13）、Ashwin（Ch17）、Buckley（Ch20）共六个章节中被引用，其"神话学"在各章中被用于不同的批判目的，构成跨章的理论枢纽。

**判据E：结构性对称/不对称**——全书三编之间或各章之间在结构、方法或论证策略上存在可辨识的对称或不对称模式，这一模式仅在全量数据上可见。例如：第二编10章中有5章使用修辞-符号学方法，形成方法论上的"阐释主导"格局，与第一编的理论多元主义和第三编的历史批判构成不对称分布。

### 分析方法

本分析综合运用以下四种方法：

1. **语义网络分析**：以L###为节点，以L###X8中明示的前后章关联为初始边，通过逐条核验实体清单（L###X7）的跨章共现和L###X2（核心论题）之间的隐含关联进行边扩增，构建全书知识元语义链接网络。

2. **共现矩阵计算**：对六类实体（人物A、机构B、概念C、文献D、作品E、事件F）构建跨章共现矩阵，计算各实体在全书的出现频次、共现强度和中介中心性。

3. **论辩轴提取**：比较各章核心论题（L###X2）之间的逻辑关系（支持/反对/补充/转化/忽略），提取全书层面的多条论辩主轴。

4. **涌现路径追踪**：对于每一个被判定为涌现的知识形态，逆向追溯其组成知识元的来源章节和语义连接路径，形成"涌现证词"。

## 分析流程与规则

### 步骤一：知识元语意分析（对应01号文件）

- 输入：分析报告全部L###编码单元
- 操作：(1) 按知识元类型（X0-X8）进行跨章归类；(2) 识别同类知识元之间的语义关系（同义/反义/上下位/因果/类比）；(3) 标注各知识元的语义边界（该知识元覆盖的论域范围和与其他知识元的交叠区域）
- 输出：知识元语义空间的总览图谱

### 步骤二：语义链接网络构建（对应02号文件）

- 输入：步骤一的语义关系标注结果
- 操作：(1) 将全部L###编码单元映射为网络节点；(2) 按L###X8明示关联创建初始边；(3) 按X7实体共现和X2论题关联创建增补边；(4) 计算网络全局属性（密度、直径、模块度）
- 输出：全书知识元语义链接网络

### 步骤三：知识涌现计算（对应03号文件）

- 输入：步骤二的语义链接网络
- 操作：(1) 运行涌现判据A-E，识别涌现现象；(2) 对每个涌现现象进行路径追踪；(3) 计算涌现强度（涉及的知识元数量、跨编跨章跨度、概念新颖性）
- 输出：涌现现象清单与量化指标

### 步骤四：知识发现报告（对应04号文件）

- 输入：步骤三的涌现清单
- 操作：(1) 对涌现现象进行主题归类；(2) 比较本分析发现与00_整体分析报告中已有论断的差异；(3) 提出仅在涌现分析视角下才可辨识的新知识主张
- 输出：知识发现综合报告

### 质量标准

1. **可追溯性**：每一条涌现发现必须标注其所依赖的源知识元L###编码
2. **可验证性**：每一条涌现发现的推理路径必须清晰可复现
3. **新颖性**：涌现发现必须超出00_整体分析报告已明确陈述的内容
4. **结构性**：涌现发现必须具有全书层面的结构性意义，而非零散注记
