# 02_语义链接网络

## L001 文档定位与功能

本文件是"知识涌现分析"系列的第三份文件，承担构建全书二级知识元（KE2命题）的语义链接网络的功能。核心操作包括：（1）从15份分析报告的L004（逻辑梳理/因果转折）和L009（跨章关联）节段中系统提取实体间的语义关系，构建KE2命题库；（2）按八种关系类型（CAUSE/BEFORE/CONTAIN/OPPOSE/TRANSFORM/INSTANCE/CONDITION/COMPARE）对命题进行分类和加权；（3）计算命题网络中所有实体对之间的语义距离（BSD/CSD/GSD），生成语义距离矩阵；（4）对网络进行社区检测——识别高度密集互连的实体群（语义社区）及其边界；（5）识别网络中的枢纽节点（Hub）和桥梁节点（Bridge）——前者在同社区内高度连接，后者连接不同社区。

本文件为03_知识涌现计算.md提供结构化的命题网络输入——命题库、语义距离矩阵和社区结构将被用作KE3模式识别和CEI计算的基础数据。

## L002 命题提取与分类

### L002a 提取方法

命题（KE2）从分析报告的以下节段中提取：

2. **L009 跨章关联节段**（每章1节，共14节）：从中提取实体在跨章语境中的语义关联——特别是跨章主题的延续、演变和对照关系。
3. **L003 内容分析/核心论题节段**：从"关键论点与案例"段落中提取INSTANCE（例证）和COMPARE（比较）关系。
4. **NN专项报告**：NN01（概念演变轨迹）和NN02（关键人物网络）提供已结构化的跨章实体关系。

每个提取的命题赋予唯一编号KE2-###，标注源章节和源节段。

### L002b 八类关系定义与权重

| 关系类型 | 代码 | 定义 | 网络边权重 | 双向？ |
|----------|------|------|-----------|--------|
| 因果 | CAUSE | A导致/推动/引起/促成B | 1.0 | 否（有向边A→B） |
| 时序 | BEFORE | A在时间上先于B发生 | 0.7 | 否（有向边A→B） |
| 包含 | CONTAIN | A是B的子概念/组成部分 | 0.9 | 否（有向边A→B） |
| 对立 | OPPOSE | A与B矛盾/冲突/构成张力 | 0.8 | 是 |
| 转化 | TRANSFORM | A演变为/被重新定义为B | 0.9 | 否（有向边A→B） |
| 例证 | INSTANCE | B是A的具体实例/案例 | 0.6 | 否（有向边A→B） |
| 条件 | CONDITION | A是B的前提条件/必要环境 | 0.8 | 否（有向边A→B） |
| 比较 | COMPARE | A与B在分析中被并行对比 | 0.5 | 是 |

### L003b 语义距离分布特征

全书210个实体之间的GSD分布呈现明显的双峰模式：

**近距峰**（GSD < 0.3）：约占总实体对的15%。主要包含（a）直接CAUSE/CONTAIN/TRANSFORM关系实体（如"发展"与各子概念）；（b）人物与其创立/推动的政策/概念（如Chamberlain与建设性帝国主义）；（c）事件与直接后果（如一战与贸易条件恶化）。

**远距峰**（GSD > 0.6）：约占总实体对的45%。主要是跨类别的、非直接关联的实体对。这个区域是知识涌现的富矿区——相距较远的实体之间如果存在未被显式表述的语义关联，其被识别时将产生高ED（涌现距离）值（按00_方法与规则-L004d，ED = 1/(1+GSD)，GSD > 0.6时ED < 0.625——中等涌现倾向）。

**中距区**（0.3 < GSD < 0.6）：约占总实体对的40%。此区域的实体对有间接关联但非紧密——它们通常是（a）通过一个中介实体关联的；（b）在同一历史阶段但不同域中出现；（c）被作者在不同章中分别讨论但未直接链接。

### L005c 网络结构特征
