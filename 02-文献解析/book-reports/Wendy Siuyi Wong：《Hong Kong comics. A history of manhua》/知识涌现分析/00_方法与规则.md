# 00 方法与规则（知识涌现分析）

## 一、层级定义

本书为图录式通史，按《分析方法说明书》定义如下层级：

- **知识元（Knowledge Unit）**：六类实体——人物、著作/作品、概念、机构、地点、事件。全书实体索引见 `NN_专项报告与实体总索引.md`。
- **Topic（强连通簇）**：由语义链接紧密互连的知识元集合。本书中 Topic 以"产业—类型—审查"为天然聚合单元。
- **Theme（高层语义域）**：若干 Topic 共享枢纽知识元后形成的宏观域。

## 二、9 种语义链接判定标准

| 类型 | 符号 | 判定标准 | 本书实例 |
|---|---|---|---|
| 因果 | → | A 的发生/存在导致 B 的状态变化（文本有因果词或可推证） | 电视引入→漫画衰落（L202） |
| 条件 | ⇒ | A 是 B 成立的前提/前提条件 | 1949 大陆出版中断⇒香港成为唯一商业化产地（L170） |
| 对比 | ↔ | A 与 B 被文本并置比较，形成差异 | 本地 manhua ↔ 日本 manga（L86） |
| 隶属 | ⊂ | A 属于 B 的类/成员 | 龙虎门 ⊂ 功夫漫画类型（L210, L2606） |
| 时序 | ≻ | A 在时间上先于 B（同一叙事线） | 小流氓(1970) ≻ 龙虎门(1975)（L218, L222） |
| 空间共现 | ≈ | A 与 B 在同一空间/媒介场域出现 | 街头租书摊 ≈ 连环图（L103, L216） |
| 属性 | : | B 是 A 的属性/特征 | 老夫子 : 最长寿漫画角色（L196, L1482） |
| 论证支撑 | ⇐ | B 是 A 论点的证据/支撑 | 1974 社会调查 ⇐ 暴力批评论述（L5034） |
| 同域 | ∼ | A 与 B 属于同一类型/主题域 | 功夫漫画 ∼ 剑侠漫画（L2606） |

## 三、涌现指标

- **节点度 k**：知识元被其他知识元直接引用的链接数（全书提及次数+语义连接数）。
- **桥接值 b**：连接不同 Topic/Theme 的跨域链接数。
- **簇识别**：强连通子图（组内互链密度显著高于组间）。
- **内聚度**：簇内链接数 / 簇内节点数。
- **涌现强度 S**：一级涌现 S1（簇内聚合后的新属性）、二级涌现 S2（簇间综合后的命题强度），按"支撑证据行号数量 + 跨域范围"定级（强/中/弱）。
- **一级/二级涌现**：一级 = 簇内节点组合产生的新单元知识；二级 = 跨簇综合产生的新命题。
