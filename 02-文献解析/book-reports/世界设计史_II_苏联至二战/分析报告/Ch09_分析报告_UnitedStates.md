# Ch09 分析报告：第28章 美国（1917—1941）

## 章节定位与功能（含行号范围）

- **行号范围**：正文 L2575—L2722；章末参考文献 L2723—L2724；文献综述与著作书目 L2725—L3234（下接第29章标题 L3235）。章题行在 clean 版中缺失，以 L1 目录为准；正文以 `## ·简介`（L2575）起锚。
- **功能**：全卷篇幅最大的国家章，讲述两次世界大战之间美国设计的全面转型：消费者文化与广告、大萧条与新政、设计推广（博物馆/百货公司）、欧洲移民设计师、大批量制造的现代设计、工业设计职业化（贝尔·盖迪斯、德雷夫斯、罗维、提革）、交通工具（汽车/火车/飞机）、设计教育、世界博览会、广告杂志书籍、印刷与平面设计、政府项目。确立"咨询设计师"与"流线型"的美国模式，为二战后工业设计职业奠定制度与话语基础。

## 内容分析

- **消费社会与广告**：广告心理学（华生 L2679）、消费不足论（卡尔金斯 L2604）、"消费者工程"（谢尔顿/阿伦斯 L2577）。
- **设计推广制度**：胡佛代表团与 1925 年博览会报告（L2584—L2586）、博物馆年展（L2586）、百货公司展览（L2586）。
- **现代设计第一波**：欧洲移民设计师（维也纳/德国/匈牙利）将手工艺传统与装饰艺术带入美国（L2588—L2592）；美国本土设计师的现代化转向（戴斯凯、罗德 L2592）。
- **工业设计职业化**：贝尔·盖迪斯《地平线》（L2606）、德雷夫斯"清爽风"（L2608）、罗维"从唇膏到轮船"（L2609）、提革的"视觉戏剧"（L2609）；年度换型与"有计划废止"（L2609）。
- **交通工具**：通用汽车造型部与厄尔（L2628）、克莱斯勒"气流"（L2631）、福特林肯和风（L2628）；流线型火车（库勒、德雷夫斯、罗维，L2634—L2638）；DC-3（L2642）。
- **设计教育**：卡耐基/普拉特职业模式（L2649）、克兰布鲁克社区模式（L2650）、芝加哥新包豪斯（莫霍利-纳吉，L2650）、黑山学院（亚伯斯，L2650）。
- **世界博览会**：芝加哥世纪进程展（L2655—L2657）、纽约世博会"未来世界"（贝尔·盖迪斯，L2660—L2677）。
- **平面设计**：字体工业（L2706—L2712）、"平面设计"术语诞生（德威金斯，L2714）、现代主义吸收（兰德/比尔，L2717）、欧洲移民设计师群体（L2717）。
- **社会维度**：女性设计师（科根等，L2619）、黑人发明家与 WPA 艺术中心（L2619—L2620）。

## 逻辑梳理

以"消费经济兴起 → 设计推广制度（博物馆/百货/政府）→ 现代设计第一波（移民+本土）→ 工业设计职业化（四大师）→ 交通工具与产品 → 设计教育 → 世界博览会 → 广告/平面/印刷 → 政府项目"推进；核心叙事是"咨询设计师"职业的诞生与美国消费文化的合流，流线型作为视觉语言的兴衰。

## 论辩与阐述方法

- **职业化叙事**：以四位咨询设计师（贝尔·盖迪斯、德雷夫斯、罗维、提革）为核心案例，展示工业设计的制度确立。
- **批判视角**：对"有计划废止"的环境批评（蔡斯 vs 谢尔顿/阿伦斯，L2577）并列呈现；对性别与种族的不公（L2618—L2620）明确批判。
- **历史平衡**：指出流线型的"非功能"应用（凡·杜伦 L2622）与二战后其影响力的消退。
