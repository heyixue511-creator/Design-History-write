# Ch15 分析报告：第34章 亚洲：印度、缅甸及其他地区（1900—1945）

## 章节定位与功能（含行号范围）

- **行号范围**：正文 L5365—L5422；章末参考书目 L5423—L5424；文献综述与著作书目 L5425—L5648（下接第35章 L5649）。章题行在 clean 版中缺失，以 L1 目录为准；正文以 `## ·简介`（L5365）起锚。
- **功能**：讲述印度（手工业角色、抵制英国货运动/Swadeshi、东方学专家和手工浪漫主义、国外设计师和印度消费者、甘地与印度土布、工业化：英国政策/印度回应、版式印刷广告、电影海报）、缅甸（胡文虎虎标万金油）、其他地区（香港制造文化、关蕙农月份牌）的设计。体现"殖民经济×民族运动（甘地）×现代工业化"的三重结构，与第33章非洲构成殖民议题的双峰。

## 结构分析

1. **简介**（L5365—L5369）：印度工业化的可能/障碍、甘地简单生活主张、香港例外、东南亚市场（月份牌、虎标万金油）。
2. **印度**（L5371—L5415）：
   - 手工业角色（L5373—L5374）：纺织冲击、铁匠/木匠、火车站零售车；
   - 抵制英国货运动（Swadeshi）（L5376—L5380）：孟加拉运动、《黎明》杂志、抵制英国货商店；
   - 东方学专家和手工浪漫主义（L5382—L5384）：哈弗尔、库马拉斯瓦米、阿什比联系；
   - 国外设计师和印度消费者（L5386—L5387）：英籍印度人、王公宫殿（马尼克花园、穆特修斯）、装饰艺术；
   - 甘地与"印度土布"的政治（L5389—L5391）：拉斯金影响、纱车、土布作为民族象征；
   - 工业化：英国政策（L5393—L5394）：柯曾、查特顿、马德拉斯工业部、印度工业委员会；
   - 工业化：印度的回应（L5396—L5397）：国民大会党、中小企业、塔塔钢铁、玻璃工坊；
   - 版式、印刷以及广告（L5399—L5407）：印刷文化、杂志、《现代评论》、广告与月份牌（卡莉香烟、杜兰代）；
   - 印度的电影海报（L5410—L5415）：帕克、佩因特、艺术装饰风格。
3. **缅甸**（L5417—L5418）：胡文虎与虎标万金油。
4. **其他地区**（L5420—L5421）：香港制造文化、关蕙农月份牌与中药包装。
5. **参考书目与文献综述**（L5423—L5648）。

## 内容分析

- **手工业与现代性的张力**：甘地土布 vs 塔塔钢铁（L5389—L5391、L5396—L5397）；哈弗尔/库马拉斯瓦米的手工浪漫主义 vs 查特顿的小型企业论（L5382—L5384、L5394）。
- **Swadeshi 运动**：经济自给与政治独立的结合（L5376—L5380）。
- **殖民设计市场**：王公宫殿的欧洲现代主义（马尼克花园，L5387）；英籍印度人的装饰艺术消费（L5387）。
- **平面与广告**：拉维·瓦尔马传统与月份牌（L5405—L5407）；神话题材与民族主义（卡莉香烟，L5405）；电影海报（L5410—L5415）。
- **区域企业家**：胡文虎虎标万金油作为亚洲第一个区域性品牌（L5417—L5418）；香港关蕙农月份牌王（L5420—L5421）。

## 逻辑梳理

以"殖民经济遗产 → 手工业地位争论 → Swadeshi 与甘地 → 工业化政策（英/印）→ 平面广告与电影海报 → 区域案例（缅甸/香港）"推进；核心张力：甘地的反工业象征主义 vs 塔塔等企业家的工业化愿景。

## 论辩与阐述方法

- **二元对立呈现**：甘地 vs 工业化派、手工艺浪漫主义 vs 经济发展论，双方观点并列。
- **符号学分析**：甘地土布作为民族象征（巴拉拉姆，L5391）。
- **殖民批判**：英国政策对印度工业化的压制（L5393—L5394）。
