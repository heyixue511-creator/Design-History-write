# Ch16 分析报告：第35章 亚洲：中国和暹罗（1900—1939）

## 章节定位与功能（含行号范围）

- **行号范围**：正文 L5649—L5700；章末参考书目 L5701—L5702；文献综述与著作书目 L5703—L5908（下接第36章标题 L5909）。章题行在 clean 版中缺失，以 L1 目录为准；正文以 `## ·简介`（L5649）起锚。
- **功能**：讲述中国（手工艺与早期工业化、艺术教育及 1925 年博览会、摩登上海、国货运动、广告/月份牌、出版业/期刊杂志/五四运动/版式字体/漫画和讽刺期刊/新兴版画运动和宣传画）与暹罗（手工艺与经济、平面设计）的设计。体现"半殖民现代化×民族消费主义（国货运动）×月份牌视觉文化"的主题，是全书关于东亚消费社会最重要的章节。

## 结构分析

   - 出版业（L5673—L5685）：商务印书馆、期刊杂志（《真相画报》《良友画报》《东方杂志》）、五四运动与书籍封面（鲁迅、陶元庆、陈之佛、钱君匋）、版式与字体（宋体/仿宋体/黑体）；

3. **暹罗**（L5693—L5699）：
   - 手工艺与经济（L5695—L5696）：朱拉隆功改革、拉玛六世艺术部、暹罗王国展览会；

4. **参考书目与文献综述**（L5701—L5908）。

## 内容分析

- **半殖民工业化**：通商口岸的工厂与手工艺竞争（L5654）；"三大件"（自行车、缝纫机、手表）作为消费符号（L5655）。
- **美术教育与设计**：蔡元培美育、林风眠/刘海粟学校培养商业美术人才（L5658）。
- **摩登上海**：四大百货公司与装饰艺术（L5661—L5664）；旗袍与现代女性形象（L5664）。
- **国货运动**：民族消费主义与"国货标准"（L5666—L5667）；"购买洋货可耻"（L5667）。
- **月份牌**：从周慕桥线绘到郑曼陀擦笔水彩再到杭穉英工作室（L5669—L5671）；现代女性形象与情色元素（L5670—L5671）。
- **出版与书籍**：商务印书馆、鲁迅书籍封面网络（陶元庆、陈之佛、钱君匋，L5680—L5682）；构成主义影响（钱君匋，L5682）。
- **漫画与木刻**：丰子恺漫画（L5688）；《时代漫画》抗日（L5688）；鲁迅木刻运动与延安宣传画（L5690—L5691）。
- **暹罗**：拉玛六世民族主义与艺术部（L5695—L5696）；西方影响下的平面设计（L5698—L5699）。

## 逻辑梳理

以"清末通商口岸工业化 → 民国美术教育与摩登上海 → 国货运动 → 广告（月份牌）→ 出版/漫画/木刻 → 暹罗对照"推进；核心张力：民族主义（国货、抗日）与现代消费文化（摩登、月份牌）的共生。

- 依赖中国近代经济史、视觉文化研究文献（L5703—L5908 文献综述：费惟恺、罗斯基、格特、李欧梵、梁庄爱伦等）。

## 论辩与阐述方法

- **双重视角**：既呈现上海摩登的国际化，也揭示国货运动的民族主义（L5666—L5671）。
- **媒介分析**：月份牌作为"传统技法×现代消费"的杂交媒介（L5669—L5671）。
- **政治批判**：左翼木刻与国民党的审查/镇压（L5690—L5691）。
