## NN-01 专项报告：关键术语演变谱系

### LNN01-001 报告目的

本专项报告追踪论文中关键术语的**概念史演变**——视觉文化、设计文化、物质文化三个核心学术范畴在 Julier 的论述框架中各自经历了怎样的语义漂移和相互位置变化。

### LNN01-002 Visual Culture（视觉文化）的概念状态演变

| 论述阶段 | 语义状态 | Julier的立场 |
|---------|---------|-------------|
| 导论 | 已建制化的学科（两本期刊/五本导论/三本读本） | 承认建制事实，但质疑方法论有效性 |
| 第二章 | 两种时期化理解（本质主义/解释学）+视觉中心主义 | 在更精致的解释学版本上发掘视觉中心主义残余 |
| 第三章 | 面对当代设计时的"焦虑"与"异化预设" | 诊断焦虑为其认识论不足的症状 |
| 第四章 | 与设计文化共享"范围的开放性" | 承认其在打破等级制上的历史贡献 |
| 第五章 | 作为被超越的对象——其"单一化的观看之道"是设计文化研究的反面 | 结束对视觉文化的批判，将其定位为学科史中已被超越的阶段 |

**演变轨迹**：从"值得尊重的建制化对手"到"被揭示为在深层预设有缺陷"到"作为设计文化研究需要超越的背景"。

### LNN01-003 Design Culture（设计文化）的概念建构过程

| 论述阶段 | 语义来源 | Julier的建构动作 |
|---------|---------|----------------|
| 导论 | "更零星被使用"——出现在学术界、新闻界、设计行业 | 提出建制化的问题 |
| 第四章 | 五种既有用法（过程/语境/组织/能动/弥漫） | 类型学梳理——展示概念的丰富性 |
| 第五章 | Julier自己的四领域模型 | 从"描述既有用法"到"提出分析框架" |

**建构轨迹**：从"散见的术语"到"类型学概念"到"操作性框架"。Julier 从不给出本质主义的单一定义，而是通过展示概念的多元使用和提出分析框架来"间接定义"设计文化。

### LNN01-004 Material Culture（物质文化）的定位

| 论述阶段 | Julier的处理 | 功能 |
|---------|-------------|------|
| 导论 | "物质文化研究的开放性和智识灵活性为设计文化概念提供了养分" | 正面但未展开 |
| 第三章 | "物质文化研究认为通过消费的单一化来逆转异化" | 作为对比参照 |
| 第五章 | 与设计史和设计研究并列为设计文化研究综合的对象 | 终章中的三学科来源之一 |

**定位**：物质文化研究在本文中始终是一个**被提及但未被充分讨论的正面参照**——Julier 承认其价值但以"篇幅限制"为由未展开，这在一定程度上构成了论文的一个未被兑现的承诺。

## NN-02 专项报告：学术谱系图

### LNN02-001 报告目的

本专项报告以**知识谱系图**方式呈现论文涉及的主要学术传统及其相互关系，揭示 Julier 的论证在知识系谱中的位置。

### LNN02-002 视觉文化研究谱系

```
艺术史（Art History）
  └→ 新艺术史（New Art History, 1970s）
      └→ 视觉文化研究（Visual Culture, 1990s建制化）
          ├─ 核心期刊: Journal of Visual Culture (2002)/Visual Culture in Britain (2000)
          ├─ 时期论分支: Mitchell → Mirzoeff（"视觉是现代性的主导形式"）
          ├─ 解释学分支: Bal（"媒介是不纯的"）→ Mitchell 后期（"被不经意提及"）
          ├─ 观看类型学: Martin Jay（笛卡尔式/荷兰经验主义/巴洛克式）
          └─ 当代焦虑派: Foster/Van Winkel/Bryson（"被图像淹没"）
```

### LNN02-003 异化理论谱系（视觉文化的深层预设来源）

```
Marx（异化劳动/客体化, 19世纪）
  └→ Weber（法理型思维/祛魅, 20世纪初）
      └→ Ritzer（麦当劳化, 1996）
          └→ Sennett（公共人的衰落/都市异化, 1976）
              └→ Urry（旅游凝视, 1990）
                  └→ 视觉文化学者的"被淹没"焦虑（2000年代）
```

### LNN02-004 设计文化研究的学术来源

```
设计史（Design History）
  ├─ Margolin（"设计史 vs. 设计研究"之争, 1990s-2002）
  └─ "逆向共识"——从划界到接受复杂交互

设计研究（Design Studies）
  ├─ Pizzocaro（"开放性的感觉"）
  └─ Margolin（"产品环境"概念）

物质文化研究（Material Culture）
  ├─ Carrier（"脱嵌"概念）
  └─ 通过消费的单一化逆转异化

当代文化理论
  └─ Lash（"建筑术"文化论——三维的、环绕的、被栖居的）

意大利设计理论
  └─ "cultura di progetto"（项目文化——从协商到实现的全过程）

管理研究/创意产业研究
  └─ Lash & Urry, Scase & Davis（灵活/网络化的符号产品组织）
```

### LNN02-005 Julier 本人的思想演变

```
Julier 早期（旧版模型）
  └─ Diagram 1: 设计者—生产—消费 围绕 设计物（仍残有视觉文化的单一化痕迹）
      └→ 自我批判（本文）
          └→ Julier 新版（Diagram 2）
              └─ Value / Circulation / Practice 多领域互动（去中心化+关系性）
```

## NN-03 专项报告：论证逻辑全景图

### LNN03-001 报告目的

本专项报告以**结构化推演**方式呈现论文全文的论证逻辑，使读者可一目了然地把握从"提出问题"到"给出方案"的整体推理路径。

### LNN03-002 全文论证推演

```
STEP 0: 背景
  [事实] 三门学科（视觉文化/物质文化/设计文化）在十年间相继兴起
  [判断] 视觉文化已建制化（期刊/教材/课程齐全）

STEP 1: 提出问题
  [问题] 视觉文化的方法是否足以处理当代设计的文化角色？
  [预判] 视觉文化"理论上"应为设计文化提供跳板，但"实际上"其方法有"有限的用处"
  [议程] 三步论证——批判视觉文化→梳理设计文化用法→提出概念模型

STEP 2: 批判视觉文化（章02-03）
  STEP 2a: 认识论诊断（章02）
    [揭示1] 视觉文化时期化理解的两种版本中，即便更精致的解释学版本也隐含视觉中心主义
    [揭示2] 视觉文化的去语境化操作与自身批评的传统艺术史"并无二致"
    [揭示3] 即便 Martin Jay 区分了三种观看方式，仍然局限于"框内"

  STEP 2b: 当代设计反证（章03）
    [正题] Lash: 当代设计是"建筑术的"——三维的、环绕的、被栖居的
    [证据1] Foster/Van Winkel/Bryson 的焦虑——暴露了视觉文化分析工具的不足
    [深层分析] 焦虑根源于 Marx→Weber→Ritzer→Sennett→Urry 的"异化-脱嵌"预设
    [反证1] 虚拟现实的"沉浸"隐喻——主客对立并非必然
    [反证2] 1990年代多平台同时性——同一信息的多重呈现
    [反证3] 设计物的多重再现本身=意义的来源（而非"被淹没"）
    [结论] 视觉文化的分析工具已无法处理当代设计

STEP 3: 走向设计文化（章04）
  [案例] Daniel Koh: 设计=思维方式+环绕我们
  [类型学] 设计文化的五种用法
    ├─ 过程（cultura di progetto）
    ├─ 语境塑造的实践（地理+沟通平台）
    ├─ 组织/态度（管理的+文化资本）
    ├─ 能动性（改良主义的+encultured）
    └─ 弥漫但分化的价值（随机连接+偶遇）
  [与视觉文化对比] 共享"开放性"——但时期化的内容不同
  [量证] 设计市场/学生/就业增长数据

STEP 4: 建构模型（章05）
  [旧模型] Diagram 1（废弃——仍残有视觉文化痕迹）
  [方法参照] Pizzocaro（开放）+Margolin（产品环境）
  [新模型] Diagram 2
    ├─ Value（多元价值+product nodes+designscape）
    ├─ Circulation（上游/下游+全球/地方 fit/disjuncture）
    └─ Practice（集体实践的常规+Bourdieu的场域）
  [应用] 品牌作为贯穿模型的案例
  [结论] 三大特征：关系制图学+关系性思维+生成性模式
  [收束] "知晓的路径→改善这个失控的世界"
```

### LNN03-003 论证中的预设（未明言的前提）

1. **设计具有独特性预设**：Julier 预设了"设计"作为一种实践活动具有视觉文化方法所无法捕捉的独特性（三维空间性、系统流通性、多平台存在性）。如果设计确实可以用视觉文化的方法充分分析，则论文的核心论证将失效。

2. **视觉文化同质性预设**：Julier 对视觉文化的批评建立在"视觉文化学者共享某些核心预设（视觉中心主义、异化论）"的假设之上。如果视觉文化内部的分歧比 Julier 所呈现的更大，这一批评的对象的有效性将受到削弱。

3. **模型优于方法预设**：Julier 预设了"提出一个概念模型"是推动学科发展的有效方式——这一预设本身就来自设计研究（而非视觉文化）的学术传统。

## NN-04 专项报告：跨学科对话映射

### LNN04-001 报告目的

本专项报告**地图化**呈现 Julier 在本文中所建立的跨学科对话关系——哪些学科被纳入了对话，以什么方式，以及哪些重要的缺席值得注意。

### LNN04-002 对话学科清单

| 学科 | 对话方式 | 对话强度 | Juliuer 的立场 |
|------|---------|---------|--------------|
| **视觉文化研究** | 核心批判对象 | ★★★★★ | 超越——其方法已不够用，但其"开放性"值得继承 |
| **物质文化研究** | 正面参照但讨论不足 | ★★☆☆☆ | 承认贡献，但"篇幅限制"——可能是论证中最薄弱的环节 |
| **设计史** | 学术来源与合法性依据 | ★★★★☆ | 出身——其"逆向共识"为模型开放提供合法化 |
| **设计研究** | 方法论来源 | ★★★★☆ | 借 Margolin 和 Pizzocaro 的方法论工具 |
| **社会学/文化理论** | 理论资源 | ★★★★☆ | 借 Lash, Bourdieu, 异化理论谱系等 |
| **管理研究/创意产业研究** | 经验参考 | ★★★☆☆ | 作为"用法三"的语境——但不作为理论权威 |
| **意大利设计理论** | 概念来源 | ★★☆☆☆ | 借 "cultura di progetto" 丰富"用法一" |
| **STS（科学技术研究）** | 案例引用 | ★☆☆☆☆ | 仅作为"用法三"的经验案例出现 |

### LNN04-003 值得注意的缺席

1. **现象学**：Julier 讨论了"具身性参与"（embodied engagement），但未引证任何现象学文献（Merleau-Ponty, Heidegger 等），尽管其论证方向显然是现象学方向的。
2. **认知科学/认知心理学**：关于"观看"的讨论未涉及视觉认知的研究成果。
3. **非西方学术传统**：尽管引用了新加坡案例，但对话的学术文献完全限于西方（欧美）学术界。
4. **生态学/环境研究**：论文提到设计文化的"环境价值"和"生态效益"，但未与生态学文献对话。
5. **数字人文学/新媒体研究**：1990年代新技术的讨论未引用新媒体理论的专门文献。
