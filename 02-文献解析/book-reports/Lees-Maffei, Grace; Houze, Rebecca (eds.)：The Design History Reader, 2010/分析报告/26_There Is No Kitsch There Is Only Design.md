# 26_There Is No Kitsch There Is Only Design.md## 一、章节定位与功能
Gert Selle (1984)。德国设计理论家。本文颠覆了现代主义对'kitsch'(媚俗)的负面评价——如果'好设计'(Good Design)的标准本身就是一种阶级/文化建构，那么'kitsch'不过是被排除在正统叙事之外的另一种设计实践。核心论题：'没有kitsch，只有设计'——所有设计都参与文化意义的生产，没有先验的优劣之分。实体：Selle L89; kitsch; Good Design ideology; cultural relativism in design L89。关联：与Ch21(Hine: Populuxe)呼应——Populuxe正是被'好设计'倡导者斥为kitsch的设计文化。
