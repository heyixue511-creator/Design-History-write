# 03_知识涌现计算

## 一、计算框架总览

### 1.1 计算目标

基于00_方法与规则.md定义的计算框架，对02_语义链接网络.md构建的145节点×480边的语义链接网络进行量化分析，目标为：

（1）识别涌现潜力（EP）最高的知识元节点；
（2）定位结构洞位置——即网络中不同群落之间的"桥接薄弱点"；
（3）量化知识密度在各章的分布，并与实体数量分布进行对比；
（4）识别涌现性知识区域——即满足E1/E2/E3条件的新知识可能"涌现"的位置。

### 1.2 计算指标回顾

| 指标 | 公式/定义 | 范围 |
|------|----------|------|
| D(n) | 节点度 = 入链数 + 出链数 | 1-50 |
| BC(n) | 介数中心性（标准化0-1） | 0-1 |
| CS(n) | 跨章跨度 = 该知识元出现的不同章数 | 1-9 |
| CD(n) | 跨域度 = 该知识元链接到的六类实体类型数 | 1-6 |
| EP(n) | 涌现潜力 = D(n) × CS(n) × CD(n) / 145 | 0-15 |
| SH(n) | 结构洞指数 = 1 - Burt's constraint | 0-1 |
| KC | 知识浓度 = 该章的知识元数量 / 该章总实体数量 | 0-1 |

## 六、涌现阈值分析

### 6.1 涌现阈值的操作性定义

基于00_方法与规则.md的E1/E2/E3条件，定义涌现阈值：

**T1（跨域阈值）**：一个语义链接模式涉及≥3个不同的语义域且非从中任何单一域的逻辑可推导。
**T2（新链接阈值）**：该关系未被任何单个章节报告明确陈述，而是跨章节涌现的。
**T3（结构性阈值）**：该洞察描述了关系模式本身，而非任何个别节点或链接的内容。

当一个语义链接模式同时满足T1+T2或T1+T3或T2+T3时，达到"涌现阈值"。
