# 00_方法与规则

---

## 一、知识涌现分析的定义与目标

### 1.1 什么是知识涌现

知识涌现（knowledge emergence）是指：在对一组已结构化的分析文本进行跨文本、跨范畴的再组织过程中，原本分散的、孤立的"知识元"之间的隐性关联被系统性地捕捉和呈现，从而产生超出单篇分析报告所能达到的新认知。这一过程不创造新的"事实"，而是**揭示既有事实之间未被注意的结构关系**。

在本书的知识涌现分析中，"源文本"是六篇分析报告（00_整体分析报告、01-04各章分析报告、NN_专项报告与实体总索引），"目标"是在这六篇报告的基础上提取出五种分析维度下的涌现性发现。

### 1.2 五份产出文件的功能定位

| 文件 | 功能 | 与源报告的关系 |
|------|------|---------------|
| 00_方法与规则（本文件） | 定义分析框架、术语、编码规则 | 方法论声明 |
| 01_知识元语意分析 | 提取和诠释核心知识元的语意内涵 | 从各章报告中提取并深化 |
| 02_语义链接网络 | 构建知识元之间的多维链接 | 跨越源报告的章节和组织边界 |
| 03_知识涌现计算 | 通过定量指标计算涌现度 | 对源报告中的数据进行数学处理 |
| 04_知识发现报告 | 综合前四份文件，产出最终发现 | 全流程的总结与洞察 |

## 二、知识元的定义与分类体系

### 2.1 知识元的定义

**知识元**（Knowledge Element, KE）是知识涌现分析的最小语义单元。在本分析框架中，一个知识元是满足以下任一条件的实体或关系：

1. **实体类知识元**：一个具有明确指称的人、组织、物、概念、事件或文献（源报告中的六类实体索引）。
2. **关系类知识元**：两个以上的实体之间被论证链条所明确建立的联系（如因果、类比、对比、演变、结构）。

### 2.2 实体知识元的六类编码

延续源报告的分类体系，实体知识元分为六类：

| 编码前缀 | 类别 | 定义 | 示例 |
|----------|------|------|------|
| P_ | 人物/学者 | 历史人物、学者、设计师、艺术家 | P_Dreyfuss, P_Friedan |
| C_ | 机构/公司/品牌 | 企业、博物馆、工会、政府部门 | C_AT&T, C_Maytag |
| T_ | 技术/产品/器物 | 机器、工具、家具、消费品 | T_washing_machine, T_Selectric |
| K_ | 概念/术语 | 理论概念、分析范畴、设计术语 | K_commodity_fetishism, K_pin_money |
| E_ | 历史事件/节点 | 有明确时间定位的社会/技术事件 | E_feminization_clerical, E_AT&T_divestiture |
| B_ | 文献/著作 | 书籍、论文、电影、广告 | B_Feminine_Mystique, B_Understanding_Media |

### 2.3 关系知识元的六类链接

| 编码前缀 | 关系类型 | 定义 | 逻辑符号 |
|----------|----------|------|----------|
| R_causal | 因果关系 | A导致/促使B | A → B |
| R_analogy | 类比关系 | A在结构上与B同构 | A ≈ B |
| R_contrast | 对比关系 | A与B形成结构性对立 | A ↔ B |
| R_evolution | 演变关系 | A在时间中转化为B | A ⟿ B |
| R_struct | 结构关系 | A是B的组成部分 | A ⊂ B |
| R_cite | 引用关系 | A引用/使用B | A ⊃ B |

## 三、语意分析的方法与规则

### 3.1 语意分析的四个层次

知识元的语意分析在四个层面上展开：

| 层次 | 分析对象 | 分析问题 |
|------|----------|----------|
| 层次一：指称层 | 实体的定义与边界 | 这个知识元"是什么"？ |
| 层次二：语境层 | 实体在全书语境中的位置 | 它在全书的论证结构中扮演什么角色？ |
| 层次三：关联层 | 实体与其他实体的语义关系 | 它与哪些其他知识元相关联？通过何种关系？ |
| 层次四：位置层 | 实体在跨章知识空间中的分布 | 它在哪些章节中出现？出现频率和功能有何差异？ |

### 3.2 语意分析的编码规则

1. **所有语意分析均基于源报告的行号引用（L###）**，不引入源文本之外的"新事实"。
2. **一个知识元可以同时拥有多个语意标签**（如"K_commodity_fetishism"同时是"Marxist理论概念"和"全书核心分析方法"）。
3. **语意的命名采用"内涵+外延"的双层结构**：内涵标签定义该知识元的核心意义，外延标签定义其在全书中的使用方式。

## 四、语义链接网络的构建规则

### 4.1 网络的基本构成

语义链接网络是一个**多元关系有向图**，其基本构成为：

- **节点**：实体知识元（六类编码）
- **边**：关系知识元（六类关系编码）
- **边的权重**：关系在源报告中被论证的强度（1-3级）
  - 1级：隐含关系（仅在同一篇章中共现）
  - 2级：显性关系（源报告中有明确链接，但未深度展开）
  - 3级：核心关系（源报告中有专门分析段落论证的关系）

### 4.2 跨章链接的识别规则

跨章链接是知识涌现的首要场域。识别规则为：

1. **同名跨章**：同一实体在多个章节的分析报告中被提及 → 自动建立跨章链接点。
2. **同质跨章**：不同实体在不同的章节中承担相同的结构性功能 → 建立类比链接。
3. **桥接跨章**：一个实体在一个章节中作为"方法的起点"，在另一章节中作为"结论的终点" → 建立因果/演变链接。

### 4.3 网络分析指标

| 指标 | 定义 | 知识涌现含义 |
|------|------|-------------|
| 度中心性（degree centrality） | 节点连接的边数 | 知识的"枢纽度"——连接越多，在全书中地位越核心 |
| 介数中心性（betweenness centrality） | 节点作为最短路径桥梁的次数 | 知识的"桥接度"——连接不同知识子群的能力 |
| 跨章密度（cross-chapter density） | 节点在不同章中出现的分布 | 知识的"渗透度"——是否贯穿全书 |
| 聚类系数（clustering coefficient） | 邻居节点之间相互连接的程度 | 知识的"群落度"——是否形成紧密的知识簇 |

## 五、知识涌现计算的方法与规则

### 5.1 涌现度的定义

**涌现度**（Emergence Score, ES）是一个知识元或一组知识元的"超出各组成部分之和"的信息增量。其计算公式为：

```
ES(K) = α × O(K) + β × N(K) + γ × B(K)
```

其中：
- O(K) = 重叠度（Overlap）：知识元K在不同章节中被不同论证带使用的次数
- N(K) = 新颖度（Novelty）：知识元K在跨章语境中产生的语义扩展量
- B(K) = 桥接度（Bridge）：知识元K作为不同知识簇之间连接器的次数
- α, β, γ = 权重系数（本分析取α=0.3, β=0.4, γ=0.3）

### 5.2 重叠度计算方法

重叠度基于源报告中的"跨章关联"段落的显性引用：
- 每个跨章引用：+1
- 每个"参见/呼应/承接/平行"类型的论证：+0.5
- 每个跨章类比或对比：+0.3

### 5.3 新颖度计算方法

新颖度度量知识元在跨章转移中的**语义增量**：
- 实体从"被提及"变为"被分析"（层次一→层次二）：+1
- 实体从单一语境中的含义扩展到另一语境：+2
- 实体在跨章转移中产生了源报告未明确陈述的新连接：+3

### 5.4 桥接度计算方法

桥接度基于实体在语义链接网络中的位置：
- 连接两个不同类别的实体簇：+1
- 连接两个不同章节的分析域：+2
- 作为"孤岛"簇与中心网络的唯一连接点：+3

## 六、知识发现报告的撰写规则

### 6.1 发现的等级分类

| 等级 | 定义 | 呈现方式 |
|------|------|----------|
| L1-确认性发现 | 验证了源报告中已暗示但未系统陈述的模式 | 数据支撑 + 源报告引用 |
| L2-结构性发现 | 揭示了源报告之间未被注意的结构关系 | 网络图/矩阵 + 分析 |
| L3-涌现性发现 | 产生了超出任何单篇源报告的新认知 | 完整论证 + 跨文件证据链 |

### 6.2 发现的表述格式

每条发现遵循以下格式：
1. **发现编号**（F01, F02, ...）
2. **发现等级**（L1/L2/L3）
3. **发现陈述**（一句话概括）
4. **证据链**（来自不同源报告的L###引用）
5. **论证展开**（2-5段解释）
6. **知识涌现印记**（说明该发现如何"超出"源报告）

### 6.3 引用规则

- 所有论断均需引用至少一处源报告行号（L###）。
- L2和L3级发现必须引用来自**至少两个不同章节**的源报告。
- 跨章引用格式：`[Ch1_L223] + [Ch2_L355]` 表示第一章和第二章的行号。
- 源报告中的口述史、广告文案等"一级材料"需标注引用层级：`[一级: 广告文案] Ch2_L342`。

## 七、分析框架的操作流程

```
第一步：知识元提取
  六篇源报告 → 六类实体清单（已有，NN专项报告） + 关系清单（需识别）
  
第二步：语意分析
  每个知识元的四层语意分析 → 语意标签矩阵
  
第三步：链接网络构建
  实体节点 + 关系边 → 加权有向图 → 网络分析指标
  
第四步：涌现计算
  重叠度 + 新颖度 + 桥接度 → 涌现度ES → 排序
  
第五步：发现报告
  高ES知识元 + 高介数关系 → L1/L2/L3发现 → 综合报告
```
