# 19 第十九章分析报告：Conclusion: Counting Creativity（结论：计算创造力）

## 一、章节定位与功能

本章由Guy Julier和Liz Moor联合撰写，是全书的综合结论。其功能为：

1. **理论总结与概念提炼**：将分散在19章中的分析线索编织为三个核心命题——创造力是"偶然的"(contingent)、"协商的"(negotiated)、"表演的"(performed)(L258)。

2. **三个关键主题的系统阐述**：围绕"创意劳动"(Creative Labour)、"系统化的物质文化"(Material Culture of Systematization)、"设计管理-解耦还是殖民化"(Decoupling or Colonization?)三大主题组织全书内容的回顾。

3. **前瞻性的生态转向**：在结论末尾引入气候变化和Peak Oil的全球挑战——将全书关于"测量"的讨论重新框定为可能具有"新的社会重要性"(L270)的关切。

## 三、内容分析（核心论题+关键论点）

### 3.1 三项核心命题

**命题1：创造力是偶然的(contingent)**(L258)
- "它需要物质和人力资源的特定调整和配置才能存在，因此其品质取决于这些配置和调整"
- 案例支撑：Dorland(Ch6)的设计师被迫依赖"头脑中的图书馆"

**命题2：创造力是协商的(negotiated)**(L258)
- "它涉及行动者之间关于其位置和价值的同意"
- 案例支撑：Springer(Ch7)和Dorland(Ch6)——"创意的声称越来越多地由设计公司的成员在'ideation'阶段而非在'form-giving'阶段提出"
- 案例支撑：Scothron(Ch15)和Törmikoski(Ch17)——长期客户关系使"创意的场所从form-giving转移到更具战略性的输入"

**命题3：创造力是表演的(performed)**(L258)
- "创意工作的一部分增值过程发生在它以特定方式由特定行动者在特定组织中'上演'的方式中"
- "创造力的意义因此经历持续的发展"

### 3.2 关键综合论点

**论点1：公共政策是关键驱动力**(L2763)
- "国家层面的关于设计工作最佳实践的政策和声明是本书核心的各种系统化和测量的主要驱动之一"
- 证据追溯：Moor(Ch1)政策再造政治主体性→Julier(Ch2)城市设计编码化→Hill & Julier(Ch3)中央/地方冲突→Sandle(Ch4)公共艺术评估→Pavitt(Ch5)博物馆身份再造

**论点2：技术/物质系统创造"组织事实"**(L2787-2788)
- Harvest和Oracle Workflow的时间记录系统→Power (2009)的"新组织事实"→促进"对工作室创意工作与组织最终盈利能力之间关系的更密切审查"
- 但这些系统的使用程度取决于"管理者的倾向和能力以及普通员工的配合"(L2787)

**论点3：系统化也是差异化**(L2806-2808)
- "推广材料总是在理想化实践，但它们可能为实际行为的持续内部监控和再造做出贡献"(L2807)
- 在"缺乏与相关学科（如建筑学）相关的规范、基准和专业标准"的设计行业中，"系统化往往采取竞争性系统的增生形式"(L2807-2808)
- →"形式模型和系统在设计领域至少既是推广性的，也是功能性的"(L2808)

**论点4：创意场所正在转变**(L2814-2817)
- "传统上'创意人'在某个机构中的位置和角色正受到那些占据更多战略和规划角色的人的挑战"
- 原因：客户的创造性信心增加 + 数字分析和消费者追踪 + 品牌化的兴起（"项目的'look and feel'已被提前决定"）

### 3.3 生态转向

结论的最后一部分以生态设计结束——"设计应对Peak Oil和气候变化双重全球挑战的角色是明确的"(L2823-2826)。这一转向将全书的"测量"讨论从商业审计重新框定为社会价值——"在这些新语境中，设计的历史性关注'美'可能需要以尚未容易想象的方式与它更近期的关注测量和规范化联系起来"(L2825-2826)。

## 四、逻辑梳理

### 4.1 论证链条

```
开篇: 反对创意/商业的二元对立
  →"我们的关切是溶解文化与经济的二元论"(L2747-2751)
  →"创造力不再抵抗量化"(L2751)

三项核心命题:
  创造力是偶然的→需要特定配置
  创造力是协商的→涉及同意创造的位置和价值
  创造力是表演的→增值过程发生在"上演"中

三大主题回顾:
  A.创意劳动 — 政策作为驱动力 → 每章回顾
  B.系统化的物质文化 — Harvest/Oracle Workflow → 数字分析 → 多重受众审查
  C.管理: 解耦/殖民化? — Power的光谱 → 行为的规范化 → 小/新机构有更大自由

主题深化:
  表演性的双重性 — 玩耍vs.审计的形象管理 → 推广的"反射性"效应
  创意场所的转移 — ideation vs. form-giving → 客户信心 → 品牌化
  设计的权宜性 — Yúdice → 新自由主义的"技术修补"

前瞻:
  波兰1980s ↔ 当代新自由主义 → 设计的价值作为"未来潜力"(value in potentia)
  生态设计 → 碳计算 → "情感耐久性" → 社会创新
  "美与测量的连接"→ 尚未可知的未来
```

### 4.2 关键转折

**转折1——二元论的溶解**：从"创造力抵抗量化"(Lockwood)到"创造力不再抵抗量化"(L2751)——将全书的经验发现总结为对传统二元论的拒绝。

**转折2——推广=反射性资本主义**：将推广材料重新概念化为"反射性资本主义"的组成部分——"一个范围广泛的行动者反思公司的组织和实践，通常旨在构造通用模型以体现当前最佳实践的思想"(L2807)。

**转折3——从审计到可持续性**：结论的生态转向将全书的"测量"论述从商业效率重新定义为环境必要性(L2823-2824)。

## 六、论辩与阐述方法

1. **综合与回顾**：而非引入新论点，结论将之前分散的章节发现编织成三个清晰的主题轴线。
2. **"解耦/殖民化"框架的居中部署**：将Power的框架作为评估全书经验发现的核心理论透镜。
3. **"尽管……但"的结构**：整章充满这种转折结构——"尽管我们想强调设计实践的关系性，但我们不认为这种构想中产生的所有关系都是平等的"(L2758)——在承认复杂性的同时保持批判性立场。
4. **末尾的生态转向**：以"设计与气候变化"的急迫性收尾，给予全书一个方向性的、未来面向的闭合。
