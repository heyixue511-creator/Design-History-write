# 00_方法与规则

## L### 一、分析目标与范围

### L### 1.1 分析目标
本"知识涌现分析"旨在对《The Russian Avant-Garde Book 1910-1934》（2002）全七章分析报告中的知识体系进行系统性重组，通过知识元提取、语义标注、链接网络构建与涌现计算，发现超越单一章节边界的新知识——即原文本中未直接陈述、但从知识元间关系的结构性配置中"涌现"出来的跨章节洞见。

### L### 1.2 分析范围
- **源数据**：分析报告/目录下的00_整体分析报告.md, 01-07章分析报告.md, NN_专项报告与实体总索引.md
- **覆盖知识域**：书籍本体论、解构诗学、原始主义来源学、反古腾堡技术策略、构成主义范式转型、至上主义视觉哲学、非官方出版抵抗实践
- **时间跨度**：1910-1934（含部分前溯至1904年象征主义、后延至1968年Kruchenykh去世）
- **空间跨度**：Moscow, St. Petersburg, Tiflis, Vitebsk, Berlin, Leningrad

## L### 二、知识元的定义与分类体系

### L### 2.1 知识元定义
"知识元"（Knowledge Element, KE）是知识体系中最小的、具有独立语义的、可被链接与操作的认知单元。在本分析中，知识元满足以下条件：
1. **可指称性**：可被唯一命名或编号
2. **语义自足性**：脱离原句后仍保持完整的语义内容
3. **可链接性**：可与其他至少一个知识元建立语义关系
4. **边界明确性**：不与其他知识元重叠

### L### 2.2 知识元分类体系

| 分类代码 | 类别名称 | 定义 | 示例 |
|---------|---------|------|------|
| KE-P | 人物实体 | 参与前卫书籍生产/理论/收藏/研究的个体 | Kruchenykh, Lissitzky, Malevich |
| KE-W | 出版物实体 | 在前卫书籍史中具有节点意义的出版物品 | Worldbackwards, For the Voice, Of Two Squares |
| KE-T | 技术实体 | 用于书籍生产的印刷/复制/装订技术 | 石印手稿, 胶版印刷, 照片蒙太奇 |
| KE-G | 团体/机构实体 | 艺术团体、出版印记、教学/研究机构 | Gileia, UNOVIS, INKhUK, 41° |
| KE-C | 概念/术语实体 | 前卫理论中的核心概念与术语 | zaum, dis-konstruktsiia, organization of materials |
| KE-E | 事件/展览实体 | 具有转折意义的历史事件或展览 | 1917十月革命, 0.10展览, 5x5=25展览 |

### L### 2.3 知识元粒度控制
- 一个章节中多次出现的同一实体，合并为一个知识元，但保留其在不同章节中的语义侧面
- 一个出版物如有多个版本（如Worldbackwards的五藏本），以母体为知识元单位，异体作为属性
- 同一人物在不同时期的不同角色（如Kruchenykh作为"创造者"vs."档案守护者"），视为同一知识元的不同时间切片

## L### 三、知识元的语义属性模型

每个知识元携带以下六维语义属性：

### L### 3.1 六维属性体系

| 维度 | 属性名 | 取值类型 | 说明 |
|------|--------|---------|------|
| A1 | 时间定位 | 起止年份 | 知识元活跃/存在的时间区间 |
| A2 | 空间定位 | 城市列表 | 知识元活动/生产的地理位置 |
| A3 | 章节分布 | 章节点集 | 知识元在哪些章节中被讨论 |
| A4 | 语义密度 | 0-1浮点数 | 知识元在原文本中的信息丰富度（基于出现频次、描述篇幅、引文数量归一化） |
| A5 | 功能角色 | 枚举值 | 创造者/理论家/中介者/守护者/机构/技术/媒介 |
| A6 | 跨章桥接度 | 0-1浮点数 | 知识元连接不同章节的能力（=该知识元关联的其他知识元所属的不同章节数/总章节数） |

### L### 3.2 语义密度计算公式
```
语义密度(KE) = (w1 * 出现频次归一化 + w2 * 描述篇幅归一化 + w3 * 引文数量归一化) / (w1+w2+w3)
其中 w1=0.3, w2=0.4, w3=0.3
```

## L### 四、语义链接的类型与规则

### L### 4.1 链接类型定义

| 链接类型 | 代码 | 定义 | 方向性 | 示例 |
|---------|------|------|--------|------|
| 合作链接 | L-COLLAB | 两个人物/团体共同参与出版物的创作/生产 | 双向 | Kruchenykh —[COLLAB]→ Rozanova |
| 因果链接 | L-CAUSAL | 一个事件/概念/技术导致另一个的产生或转变 | 单向 | 1917革命 —[CAUSAL]→ 书籍功能嬗变 |
| 影响链接 | L-INFLUENCE | 一个人物/团体/概念对另一个的观念或风格产生可追溯的影响 | 单向 | Malevich —[INFLUENCE]→ Lissitzky |
| 转型链接 | L-TRANSFORM | 知识元在时间序列中发生角色/性质的系统性改变 | 单向 | Kruchenykh(创造者) —[TRANSFORM]→ Kruchenykh(档案守护者) |
| 对立链接 | L-OPPOSE | 两个知识元在理念/方法/风格上构成系统性对立 | 双向 | Rodchenko(体系内) —[OPPOSE]— Lissitzky(体系外) |
| 空间迁移链接 | L-MIGRATE | 人物/团体/技术在空间上的迁移轨迹 | 单向 | Moscow —[MIGRATE]→ Tiflis |
| 技术-作品链接 | L-PRODUCE | 某种技术被用于某出版物的生产 | 单向 | 石印 —[PRODUCE]→ A Game in Hell |
| 概念-概念链接 | L-SUBSUME | 一个概念包含或统摄另一个概念 | 单向 | 原始主义 —[SUBSUME]→ lubok传统 |
| 同属链接 | L-BELONG | 人物属于某团体/机构 | 单向 | Kruchenykh —[BELONG]→ Gileia |
| 出版物间链接 | L-REFERENCE | 一出版物直接引用/回应/对峙另一出版物 | 单向 | Universal War —[REFERENCE]→ From Cubism and Futurism to Suprematism |

### L### 4.2 链接建立规则
1. **证据充分性**：每条链接必须有至少一个章节的原文依据
2. **非冗余性**：两个知识元之间同类型链接只建立一条（不跨章节重复）
3. **跨章优先性**：链接所涉知识元若分布在不同章节，该链接被视为"跨章链接"，在涌现计算中获得更高权重
4. **双向链接的对称性检查**：L-COLLAB和L-OPPOSE为双向链接，需验证对称性——若A→B成立，B→A也必须成立

## L### 五、语义链接网络的构建规则

### L### 5.1 网络构建步骤
1. **节点提取**：从分析报告中提取所有满足条件的知识元（目标：≥100个节点）
2. **属性标注**：为每个节点标注六维语义属性
3. **链接枚举**：遍历所有知识元对，根据链接类型定义与原文依据建立语义链接
4. **邻接矩阵生成**：以知识元为行/列，以链接为矩阵元素，生成加权有向邻接矩阵
5. **网络可视化参数**：节点大小=语义密度，边粗细=链接证据强度（1-3级），颜色=链接类型

### L### 5.2 网络度量指标

| 指标 | 公式/定义 | 知识论意义 |
|------|----------|-----------|
| 节点度（Degree） | 与该节点直接相连的链接数 | 衡量该知识元在网络中的"活跃度"——高节点度=知识体系中的"枢纽" |
| 介数中心性（Betweenness） | 经过该节点的最短路径数/所有最短路径数 | 衡量该知识元的"桥接"功能——高介数=知识体系中的"不可绕过的通道" |
| 聚类系数（Clustering Coefficient） | 节点的邻居之间相互链接的比例 | 衡量围绕该知识元是否形成"知识簇"——高聚类=局部知识密集区 |
| 网络密度（Network Density） | 实际链接数/最大可能链接数 | 衡量整个知识体系的结构化程度——高密度=知识高度互联 |
| 模块度（Modularity） | 实际社区内部链接密度与随机期望的差值 | 衡量能否自然分化出"知识社区"——高模块度=知识体系存在清晰的分支结构 |

## L### 六、知识涌现的判定与计算规则

### L### 6.1 "知识涌现"的操作性定义
在本分析框架中，"知识涌现"指以下任何一种情况：
1. **跨章桥接涌现**：两个在源文本中从未在同一章讨论的知识元，通过网络分析被发现存在强语义关联
2. **闭环涌现**：网络中形成了源文本未显式陈述的语义闭环（如A→B→C→A），其环路本身构成新的知识命题
3. **结构对称涌现**：网络中存在对称的结构模式（如两个人物在历史叙事中具有对称的镜像关系，但源文本未做比较）
4. **中心性矛盾涌现**：某一知识元在源文本中被边缘化处理，但在网络分析中呈现出远高于预期的中心性
5. **语义空洞涌现**：网络中某些理论上应存在链接但实际缺失的位置——即"应该被链接但未被链接"的语义空洞，构成新的研究问题

### L### 6.2 涌现评分公式
```
E(KE_i, KE_j) = α * CrossChapter(KE_i, KE_j) + β * PathNovelty(KE_i, KE_j) + γ * StructuralSurprise(KE_i, KE_j) + δ * ClosureContribution
```
其中：
- CrossChapter = 1（若两知识元跨章）否则 0
- PathNovelty = 1 - (最短路径上已被显式陈述的边数/最短路径总边数)
- StructuralSurprise = 节点的实际度与预期度的偏差的归一化值
- ClosureContribution = 该链接参与形成的、未被源文本显式陈述的闭环数/总闭环数
- 权重：α=0.3, β=0.3, γ=0.2, δ=0.2

### L### 6.3 涌现知识的分级
| 级别 | 涌现分数阈值 | 含义 |
|------|-----------|------|
| E1-强涌现 | E ≥ 0.7 | 高度新颖，具有独立的学术发表价值 |
| E2-中涌现 | 0.4 ≤ E < 0.7 | 具有一定新颖性，可为既有研究提供补充视角 |
| E3-弱涌现 | 0.1 ≤ E < 0.4 | 验证既有认知，确认既有研究判断的可靠性 |
| N-非涌现 | E < 0.1 | 原文本已充分陈述，无新增知识 |

## L### 七、L### 层级约定

### L### 7.1 标题层级规则
本分析系列五份文档统一采用以下标题层级：
- `#` 一级标题：文档总标题（每个文档仅一个）
- `## L###` 二级标题：主题板块划分
- `### L###` 三级标题：细分议题/小节
- `#### L###` 四级标题：具体条目（仅在必要时使用）

### L### 7.2 表格规范
- 所有数据表使用Markdown表格语法
- 数值列右对齐
- 文本列左对齐
- 表格上方提供编号与标题

### L### 7.3 术语规范
- 俄语原文术语首次出现时保留拉丁转写，括号内给出中文译名
- 人名采用"拉丁全名（中文译名）"格式，如"Aleksei Kruchenykh（阿列克谢·克鲁乔内赫）"
- 出版物名保留原文斜体格式或书名号包裹
- 团体名保留原文大写形式
- 年份使用阿拉伯数字
