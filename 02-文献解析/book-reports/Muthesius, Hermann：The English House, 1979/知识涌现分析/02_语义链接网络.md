# 02：语义链接网络——网络拓扑与模块分析

## 一、网络总览

### 1.1 网络规模

基于01_知识元语意分析.md中编码的核心知识元（约173个），构建有向语义链接网络SLN-DEH（Semantic Link Network of Das englische Haus）：

| 指标 | 数值 |
|------|------|
| 总节点数 |V| 173 |
| 总边数 |E| 约486条 |
| 网络密度 | 486 / (173×172) ≈ 0.0163 |
| 平均度 | 约5.62 |
| 最大入度 | 8（KU-00-L018：核心命题） |
| 最大出度 | 7（KU-NN-L007："自然"话语的论证功能；KU-NN-L021：三重文本策略） |
| 平均路径长度 | 约3.41（< log₂(173) ≈ 7.43，符合小世界特性） |
| 全局聚类系数 | 约0.38（显著高于同规模随机网络期望值≈0.03） |
| 有向边中双向边比例 | 约12%（表明网络非简单对称） |

### 1.2 网络的小世界特性

SLN-DEH的平均路径长度（3.41）远小于log|V|（7.43），而聚类系数（0.38）远大于随机网络期望值。这确认了网络具有**小世界特性**——知识元之间即使分属不同章节和内容域，也能通过较短的路径相互连接。这一特性是知识涌现的结构性基础。

## 三、全局网络拓扑的关键发现

### 3.1 网络的"双核-桥-环"结构

SLN-DEH的全局拓扑呈现为一种"双核-桥-环"的非对称结构：

**第一核心（肯定性知识核）**：由M1-自然、M2-谱系、M3-壁炉、M4-传动四个模块构成的高度互联核心。这四个模块之间的跨模块边密度（0.11）显著高于它们与其余模块的跨模块边密度（0.06）。核心内部，KU-NN-L007（"自然"话语的论证功能）和KU-NN-L021（三重文本策略）是两个"超级连接器"，各自与三个以上其他模块的关键节点有强链接。

**第二核心（反思性知识核）**：由M5-方法和M6-文本两个模块构成。这一核心聚焦于"如何写"和"如何读"，与第一核心形成方法论上的呼应。M5中的KU-Ch08-L025（自我修正）是连接两个核心的关键桥梁。

**桥模块**：M3-壁炉是网络中最具桥接能力的模块——它同时连接M1-自然（五个层面中的"自然性"含义）、M5-方法（多层面分析法）、M2-谱系（壁炉是Shaw设计中的关键元素）、M4-传动（壁炉的"英式舒适"是跨文化比较的关键参照点）。M3的介数中心性之和在全网最高（1.62）。

**否定环**：M7-局限通过大量跨模块OPP→边形成一个包裹全网的"否定环"。这一结构意味着：网络中的任何肯定性命题（来自M1-M4）都有一条路径通向M7中的对应批评。这种全局OPP结构使SLN-DEH不同于单向论证的树状网络，而更接近于包含内在张力的对话式网络。

**三角3（Shaw-悲剧-局限）**：KU-NN-L010（Shaw枢纽）→ KU-NN-L011（悲剧叙事）→ KU-NN-L012（中心论局限）→ KU-NN-L010。这一三角揭示了"枢纽地位"的建构性——Shaw之所以是枢纽，部分是因为Muthesius选择了这样的叙事策略。
