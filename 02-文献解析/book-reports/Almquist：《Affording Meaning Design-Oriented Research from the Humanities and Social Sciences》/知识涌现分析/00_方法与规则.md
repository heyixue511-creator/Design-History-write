# 00_方法与规则

## 一、本分析的方法定位

本卷为"知识涌现分析"（Knowledge Emergence Analysis），是对源论文《Affording Meaning》已完成的多维度"分析报告"（共六份：整体分析、导论分析、显隐性功能分析、可供性与使用分析、设计生态学与客体间性分析、专项报告与实体总索引）的二次知识加工。其目标不是对原文进行更高层次的概括，而是通过结构化知识建模，揭示原文分析报告之间隐含的关联结构、知识聚簇与涌现主题——即那些在单篇分析报告中不可见，而在跨报告的关联网络中才能浮现的深层知识模式。

本方法基于以下核心假设：（1）知识以离散的"知识元"（knowledge unit）为单位存在；（2）知识元之间的语义链接构成网络；（3）当网络的规模、密度与拓扑结构达到一定阈值时，网络中会涌现出新的知识属性——这些属性不能还原为任一孤立知识元的特征。

## 二、核心概念定义

### 2.1 知识元（Knowledge Unit）

知识元是可被独立标识、命名与定位的知识最小有意义单位。在本分析中的操作化定义为：源分析报告中出现的、具有独立语义功能的实体或命题。

知识元分为以下类型：

| 类型码 | 类型名称 | 定义 | 来自源报告的对应内容 |
|--------|----------|------|----------------------|
| K-C | 概念型知识元 | 具有理论定义或论证功能的抽象概念 | 来自分析报告中的"概念"实体部分 |
| K-P | 人物型知识元 | 在论证中发挥作用的学者/作者/历史人物 | 来自分析报告中的"人物"实体部分 |
| K-W | 著作型知识元 | 被引用或讨论的学术著作/文献 | 来自分析报告中的"著作"实体部分 |
| K-I | 机构型知识元 | 与论述相关的组织/公司/机构 | 来自分析报告中的"机构"实体部分 |
| K-L | 地点型知识元 | 具有论证功能的地理/空间位置 | 来自分析报告中的"地点"实体部分 |
| K-E | 事件型知识元 | 被用作案例或论证锚点的历史/社会事件 | 来自分析报告中的"事件"实体部分 |
| K-T | 论点型知识元 | 原文中明确的论证性命题或判断 | 从分析报告的"核心论题""关键论点"中提炼 |
| K-M | 隐喻型知识元 | 原文中贯穿的隐喻性表达与修辞结构 | 来自专项报告一"跨章隐喻系统分析" |

### 2.2 语义链接（Semantic Link）

语义链接是两个知识元之间有意义的、可被命题化表述的定向关系。链接的类型定义如下：

| 链接类型 | 含义 | 示例 |
|----------|------|------|
| L-DEF | 定义关系：A是B的定义者或来源 | Gibson —DEF→ affordance (Gibson版) |
| L-CRI | 批判关系：A批判或质疑B | Redstrom —CRI→ user-centered design |
| L-DER | 派生/改造关系：A从B派生或改造而来 | Norman的感知可供性 —DER→ Gibson的可供性 |
| L-APP | 应用关系：A将B应用于某个领域 | Nardi & O'Day —APP→ Gibson的生态学 |
| L-SUP | 支撑/佐证关系：A为B提供论证支撑 | Csikszentmihalyi的瓷研究 —SUP→ 脆性作为意义的可供性基础 |
| L-OPP | 对立关系：A与B构成论证上的对立 | 社会科学 —OPP→ 人文学科 |
| L-BRG | 桥接关系：A与B被作者桥接或整合 | Merton的隐性功能 —BRG→ 隐性意义 |
| L-ANA | 类比/隐喻关系：A与B在文中被类比或用同一隐喻表述 | 盲眼厨房广告 —ANA→ 可供性理论被蒙眼化 |
| L-SEQ | 序列/因果：A导致或引出B | Gibson→Norman的概念退化 —SEQ→ 用户概念的还原论 |
| L-COL | 协作/合著：A与B协作 | Almquist —COL— Lupton |

### 2.3 语义链接网络（Semantic Link Network, SLN）

语义链接网络是知识元节点与语义链接边的组合图。形式化定义为：

SLN = (V, E)，其中 V = {K-C, K-P, K-W, K-I, K-L, K-E, K-T, K-M} 类型的知识元集合，E = {L-DEF, L-CRI, L-DER, L-APP, L-SUP, L-OPP, L-BRG, L-ANA, L-SEQ, L-COL} 类型的语义链接集合。

### 2.4 知识涌现（Knowledge Emergence）

知识涌现定义为：在语义链接网络中，通过节点的连接模式与拓扑结构，产生的新的知识属性或主题，它满足以下标准中的至少两项：

1. **不能从任一孤立知识元推导得出**（不可还原性）；
2. **跨越了两个或更多分析报告的边界**（跨边界性）；
3. **在源分析报告中没有被显式表述**（隐式性）；
4. **具有理论或方法论的新颖性**（新颖性）；
5. **对理解原文或其他领域具有启发价值**（可迁移性）。

## 三、分析流程

本卷的分析流程分为四个阶段，对应四份产出文件：

### 第一阶段：知识元语意分析 → 产出 `01_知识元语意分析.md`

操作步骤：
1. 从六份源分析报告中提取所有实体与论点，映射为知识元类型。
2. 为每个知识元赋予唯一编号（KU-XXX）。
3. 为每个知识元定义其"语义力度"（semantic weight）——从1（边缘）到5（核心）的量化评分，基于该知识元在原文中的论证功能、跨章节出现频率、以及与其他知识元的链接密度。
4. 输出完整的知识元目录与分类统计。

### 第二阶段：语义链接网络 → 产出 `02_语义链接网络.md`

操作步骤：
1. 在知识元之间建立语义链接，标注链接类型。
2. 构建完整的有向语义链接网络。
3. 对网络进行子图（cluster）划分：按主题域识别密集链接区域。
4. 计算每个知识元的度中心性（degree centrality）与中介中心性（betweenness centrality）。
5. 识别"桥接节点"（bridge node）——那些连接不同子图的、中介中心性异常高的知识元。

### 第三阶段：知识涌现计算 → 产出 `03_知识涌现计算.md`

操作步骤：
1. 对语义链接网络进行涌现检测——识别通过节点间多重关系的叠加与反馈而产生的新属性。
2. 计算知识聚簇的"涌现潜力"（emergence potential, EP）——定义为子图内链接密度 × 跨子图桥接节点数 ÷ 子图节点数。
3. 识别"涌现主题"（emergent themes）——语义链接网络中高度紧致且跨边界的主题聚簇。
4. 分析知识涌现的动力学——通过链接类型的分布揭示哪些知识操作（桥接、批判、派生）驱动了原文的论证推进。

### 第四阶段：知识发现报告 → 产出 `04_知识发现报告.md`

操作步骤：
1. 综合前三阶段的量化结果与定性分析。
2. 提炼出本论文在跨学科设计研究中的核心知识贡献（knowledge contribution）。
3. 识别隐含的理论模型——那些在原文论证中运作但未被显式命名的理论结构。
4. 提出从知识涌现分析中产生的、可进一步研究的开放问题。

## 四、量化指标与计算规则

### 4.1 语义力度评分标准

| 评分 | 标准 |
|------|------|
| 5 | 跨四章的全文核心概念/人物/论点；在论证结构中发挥枢纽作用；与其他知识元有密集链接 |
| 4 | 跨三章的次级核心概念/人物/论点；在特定章节内主导论证 |
| 3 | 在两章中出现或主持一章的核心论证；链接数中等 |
| 2 | 在单一章中出现，承担特定论证功能但非中心 |
| 1 | 仅在脚注或背景中出现；主要为文献支撑功能 |

### 4.2 度中心性计算公式

度中心性 C_deg(v) = in_degree(v) + out_degree(v)

即节点被链接与链接至其他节点的总数。有向图区分入度与出度。

### 4.3 中介中心性计算公式

中介中心性 C_bet(v) = Σ_{s≠v≠t} [σ_{st}(v) / σ_{st}]

其中 σ_{st} 为节点 s 到 t 的最短路径总数，σ_{st}(v) 为经过 v 的最短路径数。本分析使用归一化版本。

### 4.4 涌现潜力（EP）计算公式

涌现潜力 EP(C) = [E(C) / (n(C)*(n(C)-1)/2)] × [B(C) / n(C)]

其中：
- E(C) = 子图 C 内的实际边数
- n(C) = 子图 C 的节点数
- B(C) = 连接C与其他子图的桥接节点数
- 第一项为子图内网络密度，第二项为每个节点的平均桥接数

### 4.5 涌现判定阈值

- EP ≥ 0.30: 高涌现潜力——该知识聚簇有强涌现特性
- 0.15 ≤ EP < 0.30: 中等涌现潜力——有涌现倾向但未充分实现
- EP < 0.15: 低涌现潜力——离散知识聚簇

## 五、规则约定

### 5.1 编号规则

知识元编号格式：`KU-{类型码}-{三位序号}`，如 KU-C-001、KU-P-015、KU-T-003。

### 5.2 命名规则

知识元名称优先采用源分析报告中的中文规范译名。首次出现时附原文。

### 5.3 源引规则

每项知识元标注其来源的分析报告编号（00–05），如 [源:00,03] 表示该知识元来自整体分析报告和可供性分析报告。

### 5.4 跨语言规则

所有知识元的核心内容以中文呈现，但保留原文关键术语作为参照。语义力度的评估基于原论文的论证结构，而非中文翻译的语义效果。

### 5.5 涌现证据标准

涌现主题的确认需满足：至少来自三个不同的源分析报告、涉及至少两种不同知识元类型、以及构成至少一个由五个以上节点组成的网络子图。

## 六、本方法的方法论定位

本方法的设计原则是"分析—综合双向驱动"：既从源分析报告的定性分析中提取结构化的知识元（分析方向），又通过量化网络指标揭示跨报告的知识模式（综合方向）。这种方法介于传统的内容分析（content analysis）与形式化的知识图谱构建（knowledge graph construction）之间——它承认人文学术论文特有的论证性、修辞性与多义性，不追求完全的数学严格性，但借助网络分析的概念工具系统地呈现文本深层结构。

本方法的合法范围限于：对该论文的六份已完成的深度分析报告的知识建模。不扩张至论文原文的直接分析，也不扩张至论文所引文献或外部文献的独立分析。所有知识元与语义链接均以源分析报告的文本为依据。
