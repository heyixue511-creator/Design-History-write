# 00 方法与规则

## 一、知识涌现分析的总体定位

本分析系列旨在对《Critical Design in Context: History, Theory, and Practices》一书的八份章节分析报告进行二次知识加工，通过知识元提取、语义标注、网络构建与涌现计算四个步骤，发现那些隐含在各章分析中但未在单章层面被明确陈述的跨域关系、结构洞、对立张力与新兴命题。知识涌现分析不重复原报告的内容，而是在原报告的元层次上产生新的知识。

知识涌现分析由五个文档构成：
- **00_方法与规则**（本文档）：定义操作规则、分析单元、标注体系与计算模型
- **01_知识元语意分析**：从八份分析报告中提取知识元并完成语义属性标注
- **02_语义链接网络**：建构知识元之间的多类型语义链接，形成网络拓扑
- **03_知识涌现计算**：通过网络分析与聚类计算，识别涌现性结构
- **04_知识发现报告**：将涌现计算结果转化为可读的知识发现命题

## 二、知识元（Knowledge Unit）的定义与提取规则

### 2.1 知识元的界定

知识元（KU, Knowledge Unit）是知识涌现分析的最小不可再分操作单元。在本分析语境中，一个知识元是原分析报告中承载一个可独立陈述的命题、概念、事实或论证片段的文本块。知识元必须满足以下条件：

1. **原子性**：包含一个且仅一个可独立引证的论断、概念定义、事实陈述或论证环节
2. **可标注性**：可以被赋予至少一个语义类别标签
3. **可链接性**：至少与另一个知识元之间存在可定义的语义关系
4. **来源可溯性**：可回溯至原分析报告中的L###编号或具体段落位置

### 2.2 知识元的提取范围

从以下八份源文档中提取知识元：
- 00_整体分析报告
- 01_第1章分析报告_导论：引介批判性设计
- 02_第2章分析报告_历史
- 03_第3章分析报告_理论、方法与策略
- 04_第4章分析报告_批评、功能与学科
- 05_第5章分析报告_实践
- 06_第6章分析报告_结论：批判性设计实践的学科贡献
- NN_专项报告与实体总索引

每个知识元在提取时标注其来源文档编号（D00-DNN）和具体位置。

### 2.3 知识元的编号体系

知识元采用 KU-XXX 三段编号：
- KU: 固定前缀，表示 Knowledge Unit
- XXX: 三位数字，从001开始，跨全部分析文档连续编号

每个知识元的标注格式为：`KU-XXX | [语义类别] | [来源文档] | [源L编号/段落] | 核心陈述`

## 三、语义属性标注体系

### 3.1 语义类别（Semantic Category）

每个知识元被赋予一个主要语义类别和一个可选的次要语义类别。六类语义类别定义如下：

| 编码 | 类别名称 | 判定标准 | 示例 |
|------|----------|----------|------|
| **C-CON** | 概念定义 | 对某一理论概念的首次或系统性界定 | "post-optimal design是超越技术/符号最优化的设计" |
| **C-ARG** | 论证命题 | 构成论证链条的命题性论断 | "批判性设计与主流设计构成拮抗性互补关系" |
| **C-FACT** | 事实性知识 | 历史事件、人物关系、作品归属等事实陈述 | "Sella Stool由Castiglioni兄弟于1957年设计" |
| **C-METH** | 方法论/策略 | 关于方法、策略、技法的陈述 | "Gaver et al.区分了三种模糊性类型" |
| **C-CRIT** | 批评/质疑 | 对某一立场、概念的批评或质疑 | "以实用功能为唯一标准来判定设计身份是不充分的" |
| **C-REL** | 关系陈述 | 关于两个或多个实体之间关系的陈述 | "第3章的模糊性三分类直接构成第5章分类学的主要区分维度" |

### 3.2 语义维度（Semantic Dimension）

每个知识元在以下四个语义维度上标注其取值：

**（1）抽象层级（Abstraction Level）**
- **L-META**：元理论层次——关于理论、学科、方法论的论述
- **L-TH**：理论层次——具体的理论概念或论证命题
- **L-EMP**：经验层次——关于具体案例、作品、人物的陈述

**（2）时间指向（Temporal Orientation）**
- **T-HIST**：指向历史的陈述（1950s-1990s）
- **T-CONT**：指向当代的陈述（2000s-至今）
- **T-TRANS**：跨时段的比较或连接性陈述
- **T-ATEMP**：无特定时间指向的理论性陈述

**（3）论证角色（Argumentative Role）**
- **R-PREM**：前提性陈述（为后续论证提供基础）
- **R-CLAIM**：主张性陈述（核心论点）
- **R-EVID**：证据性陈述（支撑主张的案例、数据、引用）
- **R-CONC**：结论性陈述（论证的归宿）

**（4）学科域（Disciplinary Domain）**
- **D-DES**：设计学科内部
- **D-ART**：艺术领域
- **D-STS**：科学与技术研究
- **D-PHIL**：哲学/伦理学
- **D-SOC**：社会学/人类学/物质文化研究
- **D-LIT**：文学批评/讽刺理论
- **D-INTER**：跨学科交叉

### 3.3 实体关联标注

每个知识元若涉及原报告L###实体索引中的实体，标注关联的L编号，以便追溯。格式为 `[E: L###, L###, ...]`。

## 四、语义链接的类型与规则

### 4.1 链接类型定义

知识元之间可以建立以下六种语义链接：

| 编码 | 链接类型 | 语义含义 | 方向性 | 示例 |
|------|----------|----------|--------|------|
| **L-SUB** | 上下位关系 | A是B的子类/特例/组成部分 | 有向 A→B | "联想式设计" → "批判性设计实践" |
| **L-CAUS** | 因果关系 | A导致/驱动/催生B | 有向 A→B | "经济低迷" → "设计师转向实验性实践" |
| **L-SUPP** | 支撑关系 | A为B提供理论/证据/论证支撑 | 有向 A→B | "Kroes双重本体论" → "功能是社会建构的" |
| **L-OPP** | 对立/张力关系 | A与B构成对立、矛盾或紧张关系 | 无向 | "肯定性设计" ↔ "批判性设计" |
| **L-ANAL** | 类比/平行关系 | A与B在不同语境中呈现结构相似性 | 无向 | "Superstudio的反乌托邦视觉化" ↔ "Dunne & Raby的United Micro Kingdoms" |
| **L-TRANS** | 转化/演变关系 | A经过修正、扩展或语境转移成为B | 有向 A→B | "Dunne二分法" → "Malpass三分法" |

### 4.2 链接的权重规则

每条链接根据其证据强度赋予权重值（1-3）：

- **权重3（强链接）**：由原报告明确陈述或直接引用原文支持
- **权重2（中链接）**：由原报告的论证逻辑可推断，但未明确文字陈述
- **权重1（弱链接）**：需要跨文档比较才能发现的隐含关联

## 五、知识涌现的计算模型

### 5.1 涌现的定义

在本分析框架中，"知识涌现"指满足以下至少一项条件的认知增益：

1. **跨域桥接**：发现两个或多个此前未在源报告中被关联的学科域/概念域之间的结构性连接
2. **结构洞识别**：识别语义网络中"应该存在但实际缺失"的链接——即论证空白
3. **对立合成**：发现一对对立关系背后隐藏的共同预设或潜在综合
4. **模式递归**：识别在不同层级（概念/方法/论证）上重复出现的同构结构
5. **临界转换**：识别知识元密度超过阈值的区域——高频被引概念、"必经之路"论证节点

### 5.2 计算指标

**(1) 中心度指标**
- **度中心度（Degree Centrality）**：与该知识元直接链接的其他知识元数量
- **介数中心度（Betweenness Centrality）**：该知识元位于其他知识元之间最短路径上的频率
- **特征向量中心度（Eigenvector Centrality）**：该知识元所链接的知识元的重要性加权和

**(2) 聚类指标**
- **模块度（Modularity）**：语义网络中的社区结构质量
- **聚类系数（Clustering Coefficient）**：知识元邻域的连接密度

**(3) 涌现性指标**
- **桥接指数（Bridging Index）**：跨越不同语义类别的链接数与总链接数之比
- **新颖性得分（Novelty Score）**：在01_知识元语意分析中首次被发现（即未在原报告单层被陈述）的关系的加权计数
- **结构洞得分（Structural Hole Score）**：该知识元填充的结构洞数量

### 5.3 涌现计算的四步流程

```
[步骤一] 知识元网络构建
    输入：01_知识元语意分析中的全部KU及标注
    输出：有向加权语义网络 G = (V, E, W)
    V = {KU-001, KU-002, ...}
    E = {L-SUB, L-CAUS, L-SUPP, L-OPP, L-ANAL, L-TRANS}
    W = {1, 2, 3}

[步骤二] 基础网络分析
    计算：度中心度、介数中心度、特征向量中心度
    识别：高中心度节点（Critical Node）、低中心度但对偶节点
    输出：网络拓扑特征描述

[步骤三] 社区发现与聚类
    方法：基于模块度最大化的Louvain社区检测
    识别：知识元的功能聚类（不依赖预设语义类别）
    比较：功能聚类 vs 源文档章节结构，识别"跨章节涌现"的知识元群

[步骤四] 涌现性评估
    计算桥接指数、新颖性得分、结构洞得分
    识别涌现命题：得分超过阈值的知识元/知识元群
    生成知识发现候选清单
```

## 六、L### 输出标注规则

本系列文档延续原分析报告的L###标注体系，所有标注在已使用的L001-L634之后继续编号：

- **00_方法与规则**：L701-L720（方法论规则定义）
- **01_知识元语意分析**：L721-L900（知识元实体标注）
- **02_语义链接网络**：L901-L1050（语义链接标注）
- **03_知识涌现计算**：L1051-L1150（涌现计算结果标注）
- **04_知识发现报告**：L1151-L1250（知识发现命题标注）

L编号的使用规范：
1. 每个L编号标记一个可被独立引用和分析的语义单位
2. L编号可标记：知识元、链接、计算指标、涌现命题、发现论断
3. 跨文档引用时使用格式 `[文档名:L编号]`

## 七、方法论规则（L701-L720）

L701: 知识涌现分析的操作对象是"分析报告"而非"原书文本"——它是对分析的分析（meta-analysis），因此其知识元是从原报告的论证结构中提取的，而非从原书的原始语句中提取。

L702: 知识元的提取遵循"语义闭合原则"——每个知识元必须包含完整的主谓结构或等价的概念界定，断不可只提取一个术语或人名而不附其陈述内容。

L703: 同一原报告中的同一个命题如果在多处被重复陈述，仅提取为一个知识元，并在来源字段中标注所有出现位置。

L704: 语义链接的建立以"最小充分性"为原则——两个知识元之间只建立最直接、最不可化约的链接类型，避免冗余链接（例如若A→B是L-SUPP且B→C是L-SUPP，则不在A与C之间建立直接L-SUPP，除非A→C在语义上独立于A→B→C）。

L705: 知识涌现计算中，"新"的判定标准是：该命题在八份源分析报告中均未以完整形式被陈述。若某命题在单章报告中被隐含但未明述，而在跨章网络分析中被显式化，仍计入新颖性得分。

L706: 涌现分析的最终产出是"知识发现命题"——以命题形式呈现的、可被验证或证伪的跨域洞察，而非对源报告内容的重新描述或摘要。

L707: 当语义网络分析的结果与源报告的显性陈述之间存在不一致时，优先报告该不一致并将其视为潜在的涌现信号（表明源报告的内在论证结构中可能存在未解决的张力）。

L708: 社区检测的结果不以"符合预期"或"不符合预期"为评价标准——无论结果是否与预设的语义类别一致，均予以报告并讨论其知识论含义。

L709: 结构洞的识别不以"应该被填补"为前提假设——某些结构洞可能是知识体系内在边界的有意义表达，其"空缺"本身就是一个知识发现。

L710: 权重赋值（1-3）在分析过程中保持方法论的透明性：每条链接的权重赋值需附简短理由（1-2句）。

L711: 跨文档的知识元提取遵循"源文档完整性原则"——不因知识涌现分析的需要而修改或重新解释源报告中的陈述。若源报告之间存在表述差异，如实记录而不做"调和"。

L712: 涌现命题的表达形式为："命题P：基于[证据1]和[证据2]的聚合分析，发现[跨域连接/结构洞/对立合成/模式递归/临界转换]，其知识论含义为[含义]。"

L713: 知识元网络的可视化描述（在02_语义链接网络中）应包含：网络总节点数、总边数、平均度、直径、模块度、以及关键子图的拓扑特征。

L714: 六类语义链接类型构成完备且互斥的分类体系——任意两个知识元之间至多存在一种语义链接类型。若两个知识元之间似乎同时存在多种链接类型，则选择语义上最主导的类型（主导性判定规则：L-CAUS > L-SUPP > L-TRANS > L-SUB > L-OPP > L-ANAL）。

L715: 知识元的抽象层级标注（L-META/L-TH/L-EMP）采用"最高适用"原则——若一个知识元同时操作在理论和经验层面，标注为较高的抽象层级（L-META > L-TH > L-EMP）。

L716: 涌现性得分的计算采用加权公式：涌现性得分 = 0.4 × 桥接指数 + 0.35 × 新颖性得分 + 0.25 × 结构洞得分。得分超过0.6的知识元或知识元群被标记为"涌现信号"。

L717: 知识发现报告（04）中的每个知识发现命题需附"信度评级"：高（由多条权重3的链接支撑）/ 中（主要基于权重1-2的链接或单一分析路径）/ 低（高度推测性，需要进一步验证）。

L718: 所有语义标注操作（语义类别、语义维度、实体关联）均在01文档中以表格形式呈现，每个知识元一行，确保标注的完整性和可检索性。

L719: 02_语义链接网络的网络数据以两种格式呈现：邻接表（文本描述）和网络统计量（数值描述），不依赖图形工具即可完整传达网络的结构信息。

L720: 本方法论自身也是可被反思的知识对象——如果涌现计算的结果表明方法论规则自身构成了某种偏见（例如特定语义类别的知识元被系统性高权重连接），这一发现应在04_知识发现报告中如实报告。

## 八、分析流程与文档间关系

```
                            ┌─────────────────┐
                            │ 八份源分析报告    │
                            │ (D00-DNN)        │
                            └────────┬────────┘
                                     │ 知识元提取
                                     ▼
                            ┌─────────────────┐
                            │ 01_知识元语意分析 │
                            │ KU-001 ~ KU-NNN  │
                            │ +语义属性标注     │
                            └────────┬────────┘
                                     │ 关系识别
                                     ▼
                            ┌─────────────────┐
                            │ 02_语义链接网络   │
                            │ G = (V, E, W)    │
                            │ +L-SUB/CAUS/...  │
                            └────────┬────────┘
                                     │ 网络分析+涌现计算
                                     ▼
                            ┌─────────────────┐
                            │ 03_知识涌现计算   │
                            │ 中心度/聚类/     │
                            │ 桥接/结构洞/涌现  │
                            └────────┬────────┘
                                     │ 命题化
                                     ▼
                            ┌─────────────────┐
                            │ 04_知识发现报告   │
                            │ 涌现命题+信度评级 │
                            └─────────────────┘
```

以上方法和规则构成知识涌现分析的完整操作规程。后续四个文档（01-04）将严格依循此规则执行。
