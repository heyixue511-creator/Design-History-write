## K010 语意域一：设计的本体论地位

### KU-DEF-001: 设计是人的类本质能力

- **类型**: DEF
- **内容**: 设计是"人类塑造和制造我们的环境——以自然中无先例的方式——以满足我们的需求并赋予生活意义的能力"，与语言并列构成人类定义性特征。
- **来源**: L003(P1)+L012+L017@章1
- **语意场**: [人类学常项]、[与语言对等]、[无自然先例]、[环境塑造]
- **权重**: 0.95（全书最高权重——核心定义，贯穿全部10章）
- **激活条件**: 任何关于"设计是什么"的讨论被启动时，此知识元件作为默认前提加载。
- **关联KU**: KU-PROP-003, KU-DEF-002, KU-CRIT-001

### KU-DEF-002: "design"的四重语法含义

- **类型**: DEF
- **内容**: "Design is to design a design to produce a design"——名词(领域/field)、动词(过程/process)、名词(概念/concept)、名词(成品/product)，四重含义构成词义光谱。
- **来源**: L011(P3)+L016(原文3)+L012@章1
- **语意场**: [语法分析]、[语义歧义]、[概念澄清]、[名词/动词光谱]
- **权重**: 0.78
- **激活条件**: 当"设计"一词的使用出现歧义时，此知识元作为消歧工具调用。
- **关联KU**: KU-DEF-001, KU-META-001

### KU-CRIT-001: 设计被商业媒体贬低为轻浮装饰

- **类型**: CRIT
- **内容**: 现代世界最奇特的特征是设计被广泛转化为平庸和无足轻重之物——被媒体商业包装贬低为"轻浮的、装饰性的、无关紧要的"角色。
- **来源**: L012(论题1)+L016(原文1)@章1
- **语意场**: [文化批评]、[商业泡沫]、[本质/表象]、[严肃/轻浮]
- **权重**: 0.65
- **激活条件**: 作为KU-DEF-001的前置批判语境——先破除再确立。
- **关联KU**: KU-DEF-001, KU-DICH-008(严肃/轻浮)

### KU-PROP-001: 设计从未凝聚为统一专业

- **类型**: PROP
- **内容**: 与法律、医学、建筑不同，设计从未形成拥有准入标准的统一专业，这既是其定义的混乱之源，也是其实践多样性的制度保障。
- **来源**: L013+L084@章1+章9
- **语意场**: [专业化]、[制度缺失]、[多样性/混乱]、[准入标准]
- **权重**: 0.72
- **激活条件**: 当讨论设计的社会组织形式时激活。
- **关联KU**: KU-STRUC-001, KU-PROP-024

## K011 语意域二：历史解释框架

### KU-PROP-002: 设计史是层积过程而非线性更替

- **类型**: PROP
- **内容**: 设计的历史应被描述为层积过程——新发展随时间叠加于既有之物上，形成动态互动而非简单取代。每一层改变既有诸层的角色、意义和功能。
- **来源**: L003(P2)+L012(论题3)+L025+L021(论题1)@章1+章2
- **语意场**: [层积模型]、[非线性史观]、[共存/更替]、[动态互动]

- **关联KU**: KU-PROP-003, KU-PROP-004, KU-DICH-001

### KU-PROP-003: 人性不变，变化的是技术-组织-文化条件

- **类型**: PROP

- **来源**: L021(论题1)+L025(原文1)@章2

- **关联KU**: KU-PROP-002, KU-DEF-001

### KU-PROP-004: 抽象能力是设计进化的关键转折

- **类型**: PROP
- **内容**: 区分"手工具"（直接延伸肢体）与"心工具"（语言、几何概念、书写——使知识可积累、保存和跨代传递）。轮子作为"无自然先例的纯粹文化发明"是所有抽象发明的原型。

### KU-PROP-005: 制作与构想的分离是工业化的标志性断裂

- **类型**: PROP
- **内容**: 手艺时代匠人既是构想者也是制作者；工业革命后功能分化为三——工程师解决技术问题，风格顾问决定外观，制图员执行绘图。这是"设计作为一种独立实践"诞生的结构性条件。
- **来源**: L021(论题3)+L022(转折2)@章2

- **关联KU**: KU-PROP-001, KU-PROP-002

## K012 语意域三：分析框架——效用与意义

### KU-DEF-003: 效用与意义的二分定义

- **类型**: DEF
- **内容**: 效用（utility）指"使用中的适切性品质"，关注效率与操作；意义（significance）指"形式如何在使用方式或所赋角色中获得意义"，关注表达与象征。两者构成分析一切设计形式的双轴。
- **来源**: L003(P3)+L028+L029@章3
- **语意场**: [分析框架]、[效用]、[意义]、[双轴模型]
- **权重**: 0.93（全书第三高权重——核心分析工具）
- **激活条件**: 任何具体设计案例的分析均以此框架为默认工具。
- **关联KU**: KU-DICH-002, KU-CRIT-002, KU-RELA-001

### KU-CRIT-002: "形式追随功能"是窄化的教条

- **类型**: CRIT
- **内容**: Sullivan的原文包括装饰作为设计的"整体元素"，但被后人压缩为"形式追随功能"，在此压缩中"功能"被窄化为纯实用效率。赫斯克特追溯了这一概念的退化过程。
- **来源**: L030(论题1)+L034(原文1)@章3
- **语意场**: [功能主义]、[概念的窄化]、[Sullivan]、[装饰的排除]
- **权重**: 0.70
- **激活条件**: 作为KU-DEF-003的前置批判语境激活。
- **关联KU**: KU-DEF-003, KU-PROP-006

### KU-PROP-006: "形式追随虚构"

- **类型**: PROP
- **内容**: "与自然界不同，人类生活经常被梦想和抱负而非纯粹的实用性所激励和推动。"这是赫斯克特替代"形式追随功能"的逆向命题。
- **来源**: L030(论题1)+L034(原文2)@章3
- **语意场**: [替代命题]、[梦想/抱负]、[虚构]、[反功能主义]
- **权重**: 0.73
- **激活条件**: 当需要补充功能主义的"意义"维度时激活。
- **关联KU**: KU-CRIT-002, KU-DEF-003

### KU-RELA-001: 效用与意义是光谱而非二元对立

- **类型**: RELA
- **内容**: 效用与意义不构成二元对立，而是连续体的两端——纯效用端（手术器械、铁路时刻表）到纯意义端（珠宝、瓷器雕像），大多数设计产品以不同比例混合二者。
- **来源**: L029(P4)+L033(方法2)@章3
- **语意场**: [连续光谱]、[非二元]、[混合比例]、[极端检测]
- **权重**: 0.68
- **激活条件**: 当有人将效用/意义误解为二元对立时纠正。
- **关联KU**: KU-DEF-003, KU-META-002

### KU-PROP-007: 意义不是固定不变的——VW甲壳虫案例

- **类型**: PROP
- **内容**: VW甲壳虫在1930年代是纳粹"力量来自欢乐车"，1950年代在美国成为cult对象乃至迪士尼电影英雄(Herbie)，1997年重新设计后再获cult地位——"设计几乎完全相同，但产品的意义经历了惊人的转变"。
- **来源**: L030(论题3)+L035@章3
- **语意场**: [意义的历时性]、[符号转化]、[同一形式/多重意义]、[VW甲壳虫]
- **权重**: 0.66
- **激活条件**: 讨论意义的时间依赖性时作为典型案例激活。
- **关联KU**: KU-PROP-008, KU-DEF-003

### KU-PROP-008: 文化是设计意义的主要编码系统

- **类型**: PROP
- **内容**: 赫斯克特在精英式"教养文化"与泛式"作为生活方式的文化"之间选择后者，使其分析能够涵括日常设计的广泛领域。Electrolux冰箱、Coca-Cola中文译名、Darkie/Darlie牙膏等案例证明——文化不是可以被管理决策消除的变量。

- **激活条件**: 讨论设计的跨文化维度时激活。
- **关联KU**: KU-PROP-007, KU-CASE-003, KU-CASE-004

## K013 语意域四：设计者-使用者交互

### KU-META-001: 设计意义产生于设计者与使用者的交互界面

- **类型**: META
