# 02 语义链接网络

## 一、网络总览

### L### 网络规模与结构
基于517个去重知识元，构建语义链接网络，共计 **1,823条** 有效链接，对应七种语义关系类型。网络呈现"一个核心枢纽区 + 五个子网带 + 多条跨域桥接"的非均质结构。

### L### 网络基本参数
| 参数 | 数值 |
|:--|:--|
| 节点总数（V） | 517 |
| 边总数（E） | 1,823 |
| 网络密度 | 0.0137 |
| 平均度（average degree） | 7.05 |
| 聚类系数 | 0.38 |
| 直径（diameter） | 8 |
| 平均最短路径长度 | 3.42 |
| 连通组件数 | 1（完全连通） |

*注：网络密度偏低，反映该网络并非全连接——知识元间的语义关系具有选择性；聚类系数0.38表明存在明显的社团结构（community structure），证实六大语意簇的存在。*

### L### 五个子社团（Communities）的结构

#### L### 社团1：哲学批判核心（约110个节点，密度0.042）
节点以K1（哲学家）、K3（诊断性概念）、K4（哲学著作）为主。Merleau-Ponty、Heidegger、Levin、Jay为核心。该社团与触觉簇（社团2）之间通过"具身化体验"节点实现紧密连接（边密度0.031）。

## 四、语义网络的层次结构

### L### 从知识元到命题：涌现的中间层
517个知识元链接为1,823条关系边，这些边又聚合成205个**初级命题**（prime propositions）。一个初级命题是至少三个知识元通过确定关系类型形成的闭合三元组（closed triplet）。例如：

`Merleau-Ponty + 具身化体验 + 触觉连续体` → 命题P87："身体现象学为触觉的感知连续性提供哲学基础"（强度3，出现于5+章）

### L### 从初级命题到复合主题
205个初级命题进一步聚合成28个**复合主题**（compound themes），涵盖全书的全部核心论题。每个复合主题至少包含两个初级命题的交叉。

### L### 从复合主题到涌现知识
28个复合主题通过跨社团的桥接关系，产生**12个涌现知识节点**（emergent knowledge nodes）——这些节点不直接等同于任何单一知识元或命题，而是从网络结构中"涌现"的整体模式。详见03_知识涌现计算.md。

## 五、语义链接网络的非均质特征

### L### 幂律分布的证据
度值分布呈明显的幂律特征——前10%的节点（约52个）集中了58%的总边数。这表明该语义网络具有"无标度"（scale-free）特征：少数"枢纽节点"承载了大部分语义连接功能。

### L### 结构洞分析
网络中存在9个结构洞（structural holes），即两个子社团之间的桥接仅由单个节点承担的位置。最显著的结构洞位于：
1. 社团1（哲学批判）↔ 社团5（声-嗅-味觉）之间，桥接节点：谷崎润一郎
2. 社团2（触觉-身体）↔ 社团4（文学-记忆）之间，桥接节点：巴什拉

结构洞的存在表明某些跨域语义链接在书中是"窄通道"——只有少数几位思想家或作品被用来桥接远距离的知识域。

### L### 弱链接的远距离桥接
全书最长的语义跳数（8跳）为：`Heraclitus（古希腊视觉证词）→ Plato → 视觉特权 → 笛卡尔 → 透视法 → 阿尔伯蒂之窗 → 塞尚的反透视 → Merleau-Ponty → 触觉的视觉 → 阿尔托的感官建筑`
这条8跳路径跨越了2500年的时间跨度和K1-K2-K3-K5四个类别。
