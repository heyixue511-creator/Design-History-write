# 00 方法与规则

## 一、知识涌现分析的基本定位

### L### 什么是知识涌现分析
知识涌现分析（Knowledge Emergence Analysis）是在已有文本分析报告的基础上，识别、提取、链接并计算知识元及其语义关系，以发现超越单个章节/报告层面的"涌现性知识"（emergent knowledge）的系统方法。其核心假设是：知识元之间的语义链接网络所产生的结构性洞见，无法通过逐章阅读获得，必须通过系统性的语义网络计算才能显现。

### L### 本分析的数据基础
本分析基于《The Eyes of the Skin》的27份逐章分析报告（01_序言至27_门把手与握手）以及1份整体分析报告（00）和1份专项报告与实体总索引（NN），共计29份基础文献。

### L### 知识涌现的层次
- **L1 语素层**：独立的实体（人物、作品、概念术语、文献著作、感官模态、时间地点）
- **L2 命题层**：跨实体的论题性关联（如"Merleau-Ponty → 触觉 → 阿尔托"）
- **L3 主题层**：跨章节的论题簇（如"视觉批判-触觉恢复-感官建筑"）
- **L4 涌现层**：跨越L1-L3的结构性洞见，即非明显存在于任何单一报告中的新知识

## 二、知识元分类体系

### L### 知识元六大类别
本分析沿袭分析报告中的实体分类体系，将知识元分为六类：

1. **K1-人物**（Persons）：哲学家、建筑师、艺术家、作家、学者与批评家
2. **K2-建筑作品**（Architectural Works）：具体建筑物、设计项目、空间场所
3. **K3-概念术语**（Concepts & Terms）：核心理论概念、分析术语、修辞标签
4. **K4-文献著作**（Texts & Works）：哲学著作、建筑批评、文学作品、电影等
5. **K5-感官模态**（Sensory Modalities）：七类感官（视/听/触/嗅/味/肌肉运动/骨骼本体）
6. **K6-时间地点**（Temporalities & Localities）：历史时期、地理地点、特定事件

### L### 知识元编码规则
每个知识元赋予唯一编码，格式为：`{类别代码}-{来源章节}-{序号}`
- 类别代码：K1, K2, K3, K4, K5, K6
- 来源章节：两位数章节编号（00-27, NN）
- 序号：三位数流水号（001-999）

示例：`K1-03-001` = 第03章中出现的第一位人物（Heraclitus）

## 三、语义关系类型体系

### L### 七种语义关系
1. **R1-理论来源关系**（theoretical_source_of）：人物→概念、人物→人物（影响关系）
2. **R2-建筑体现关系**（architectural_embodiment）：概念→建筑作品（概念在建筑中的体现）
3. **R3-文献引用关系**（textual_reference）：人物→文献著作、文献著作→文献著作
4. **R4-感官关联关系**（sensory_association）：概念→感官模态、建筑作品→感官模态
5. **R5-论辩支持关系**（argumentative_support）：概念→概念（逻辑链条中的前后支持）
6. **R6-时间地点关联**（spatiotemporal_context）：人物→时间地点、建筑作品→时间地点
7. **R7-批判／反对关系**（critical_opposition）：人物→概念、概念→概念（批判性对立）

### L### 关系强度计算规则
- **强度1（弱）**：单次提及，无详细阐述（如人名列表中的一次出现）
- **强度2（中）**：多次提及，或出现在论辩链条中
- **强度3（强）**：专节或专章讨论，构成论辩核心环节

## 四、知识涌现的计算维度

### L### 四个计算维度
1. **D1-中心度（Centrality）**：知识元在语义网络中的连接数量与质量
2. **D2-桥接度（Bridgeness）**：知识元连接不同知识簇的能力
3. **D3-密度（Density）**：特定知识簇内部的知识元连接密度
4. **D4-涌现度（Emergence Score）**：综合D1-D3的加权得分，标识知识元/命题/主题的涌现价值

### L### 涌现度的计算公式
`E = (C × 0.3 + B × 0.4 + D × 0.2 + N × 0.1)`

其中：
- C = 标准化中心度
- B = 标准化桥接度
- D = 标准化密度
- N = 标准化新颖度（知识元在单章中出现频率的反比）

### L### 涌现知识的判定阈值
- **E ≥ 0.70**：高涌现度——形成独立的知识发现
- **0.40 ≤ E < 0.70**：中涌现度——揭示重要的结构关系
- **E < 0.40**：低涌现度——属于常规的线性阅读发现

## 五、分析流程

### L### 四阶段流程
**阶段一：知识元提取**（对应文件01_知识元语意分析.md）
- 从29份分析报告中提取全部知识元
- 按六大类别归类编码
- 进行语义聚类与深度语意分析

**阶段二：语义链接网络构建**（对应文件02_语义链接网络.md）
- 建立知识元之间的七种语义关系
- 计算关系强度
- 构建全局语义链接网络图谱

**阶段三：知识涌现计算**（对应文件03_知识涌现计算.md）
- 计算四个维度的涌现指标
- 识别涌现性知识节点、命题和主题
- 进行敏感度分析与稳健性检验

**阶段四：知识发现报告**（对应文件04_知识发现报告.md）
- 综合前三阶段成果
- 报告涌现性知识发现
- 提出知识空白与未来研究方向

## 六、方法论约束与局限性

### L### 约束条件
1. **来源依赖性**：知识涌现分析的边界由29份分析报告的知识覆盖范围决定
2. **编码主观性**：知识元分类和关系强度判断包含分析者的解释学判断
3. **语言跨译性**：英文原著→中文分析报告的翻译环节可能影响语义精度
4. **计算模型的简化**：E值的加权分配（0.3/0.4/0.2/0.1）基于经验而非实证验证

### L### 质量控制规则
1. 每个知识元的提取必须可追溯到至少一份源分析报告
2. 每条语义关系必须注明其对应的分析报告章节编号
3. 所有涌现性发现必须经过"反证检验"：确认该发现在任何单一报告中均未明确表述
4. E ≥ 0.70 的发现须提供至少两个独立证据来源佐证
