### L001-3 网络拓扑特征

网络呈现出"核心-边缘"（core-periphery）的拓扑结构。核心层由约40个高度数知识元构成（总度数≥6），主要分布在概念型（KEC）和论点型（KEA）两类。边缘层由约160个知识元构成，主要是事实型（KEF）和评价型（KEE），它们通过大量例证链接（EXM）和层级链接（HIE）连接到核心层。

核心层内部呈现"桥梁-枢纽"双结构：约5个枢纽节点（功能性装饰、现代主义多元性、人性化、归因政治、女性主义修正）具有极高的加权中心性，约10个桥梁节点（信息过载、跨文化惊奇、物品完整性、劳动中的快乐、历史墙、India Report、Powers of Ten等）连接不同领域板块。

## L004 四、关键语义路径

### L004-1 全书核心论证路径

以下是从方法论起点到结论终点的最长连通路径（"论证脊椎"）：

```
KE00-06-KEA（女性主义修正）
  → [CAU] KE00-09-KEA（语境化方法）
    → [EXT] KE02-07-KEM（比较传记法）
      → [EXM] KE00-10-KEA（蕾比查尔斯更早接受前卫现代主义）
        → [CAU] KE03-03-KEA（真正创造性伙伴关系）
          → [CAU] KE06-01-KEA（蕾对家具形式的贡献）
            → [EXT] KE03-01-KEC（归因政治）
              → [EXM] KE03-04-KEA（系统性和结构性的亏欠）
                → [EXT] KE09-01-KEA（伊姆斯遗产是态度和方法）
```

这条路径展示了Kirkham论证的完整逻辑链：女性主义框架 → 语境化方法 → 比较传记 → 发现蕾的前卫性 → 重新评估合作模式 → 识别蕾的形式贡献 → 发展归因政治概念 → 识别制度性缺陷 → 最终评价伊姆斯遗产。

### L004-2 跨域模式路径："人性化"的四重实例化

```
KE00-04-KEC（人性化）
  ├→ [EXM] KE04-01-KEA（建筑：工业预制的温暖转化）
  ├→ [EXM] KE06-02-KEA（家具：躺椅的"一垒手套般温暖"）
  ├→ [EXM] KE07-02-KEA（展览：将历史人物呈现为有血有肉的个体）
  └→ [EXM] KE08-02-KEA（电影：从野餐者开始的宇宙之旅）
```

这四条平行的EXM链接共同构成了"人性化"概念在四个独立领域中的实例化模式——这本身就是一种深层知识涌现：在表层上这四个领域的"人性化"表现完全不同，但在深层结构上它们共享同一个操作逻辑（将抽象的/技术的/非人的转化为具象的/情感的/人的）。

### L004-3 矛盾路径："功能性装饰"的合法性-权力张力

```
KE05-03-KEA（"功能"是修辞策略）——揭示术语的策略性
  → [EXT] KE05-04-KEA（收藏的殖民主义维度）——揭示术语掩盖的权力关系
    → [CMP] KE05-02-KEC（物品完整性）——物品被视为"如其自身"的伦理与物品被从其原始语境中剥离的暴力之间的矛盾
```

这条路径揭示了Kirkham论证中最微妙的张力：她既欣赏伊姆斯"物品完整性"的伦理（尊重物品作为其自身），又批判性地审视"功能性装饰"实践中的殖民主义与东方主义维度。这不是一个可以轻易"解决"的矛盾，而是需要保持在张力中的分析立场。
