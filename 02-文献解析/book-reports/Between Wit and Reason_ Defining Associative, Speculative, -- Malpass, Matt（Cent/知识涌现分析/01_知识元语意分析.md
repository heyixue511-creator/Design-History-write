### 2.2 语义重心分析

通过计算每个语义场中高EP概念的密度，识别 Malpass 论文的"知识重心"：

```
知识重心定位：
┌─────────────────────────────────────────────┐
│                                             │
│   SF7 社会语境 ──── 表层（实践分类）          │
│        ↑                                     │
│   SF5 分类学 ──── 中层（理论框架）            │
│        ↑                                     │
│   SF1 讽刺 + SF2 叙事 + SF6 哲学 ── 深层机制  │
│        ↑                                     │
│   SF4 认知效果 ──── 目标层（反思与批评）       │
│                                             │
└─────────────────────────────────────────────┘
```

**发现一：Malpass 论文的知识结构是一个"四层金字塔"**：
- **底层（SF3 设计方法，21.9%）**：最庞大的概念群，但EP均值最低（2.57）——方法概念多且具体，但跨域链接弱
- **机制层（SF1+SF2+SF6，32.9%）**：中等规模，EP均值中高——讽刺、叙事、哲学概念是论文的核心机制语言
- **框架层（SF5，6.3%）**：最小但EP均值最高（4.25）——分类学概念最少但最"重"，每个都跨越多个语义场
- **目标层（SF4，14.1%）**：EP均值较高（3.67）——效果概念高度跨域，但数量有限

### 2.3 语义场之间的交叉渗透

| 语义场对 | 共享概念 | 交叉密度 |
|----------|----------|----------|
| SF1—SF2 | satire类型决定narrative方式（Horatian→embedded, Juvenalian→extrinsic） | 高 |
| SF1—SF4 | satire的终极目标是critical reflection; wit是satire的工具 | 高 |
| SF1—SF7 | satire类型区分三种实践 | 高 |
| SF2—SF6 | extrinsic narrative 与 defamiliarization/estrangement 配合 | 中 |

| SF1—SF6 | Juvenalian satire 与 estrangement/defamiliarization 共享"陌生化"逻辑 | 中 |

## L### 四、知识元聚类分析

### 4.1 聚类方法

基于S-知识元的维度坐标相似度和语义场归属，进行概念聚类。聚类标准：
1. **同一实践类型**（Associative / Speculative / Critical）
2. **同一语义场**或**相邻语义场**
3. **在分析报告中高频共现**（跨章共现 ≥ 3次）

### 4.2 识别的六个概念聚类

#### 聚类A：Associative Design 核心簇

| 成员 | 语义场 | 聚类特征 |
|------|--------|----------|
| S-C002, S-C006, S-C009, S-C012, S-C017, S-C018, S-C019, S-C053, S-C051, S-EXT01 | SF1+SF2+SF3+SF7 | Horatian讽刺—嵌入叙事—理性对象—家具设计—过时批判 |

**识别特征**：该聚类是六个聚类中**唯一以"理性对象"为核心的簇**。所有成员共享"通过颠覆熟悉来批判"的逻辑。
