# 02 语义链接网络

## 一、网络总览与拓扑特征

### 网络规模
基于`01_知识元语意分析.md`提取的387个知识元和`00_方法与规则.md`定义的七种语义关系类型，构建的语义链接网络具有以下基础参数：

| 参数 | 数值 |
|------|------|
| 总节点数（N） | 387 |
| 总边数（E） | 1,247 |
| 有向边数 | 1,023 (82.0%) |
| 无向边数（RELATES_TO / OPPOSES） | 224 (18.0%) |
| 平均度（average degree） | 6.44 |
| 网络直径（diameter） | 8 |
| 平均路径长度（average path length） | 3.72 |
| 跨章节边数 | 287 (23.0%) |
| 同章节边数 | 960 (77.0%) |

### 网络类型判定
该网络为**无标度（scale-free）小世界网络**。判定依据：
- 度分布呈幂律特征：少数节点拥有极高连接度，多数节点为低度节点
- 平均路径长度3.72显著小于随机网络预期值，体现了"小世界"效应
- 聚类系数（见03章计算）高于同等规模的随机网络

## 六、网络的结构性特征

### 6.1 核心-边缘结构
该网络呈现清晰的"核心-边缘"（core-periphery）结构：
- **核心层**（52个节点，13.4%）：12个枢纽节点加上其直接邻居，承载了58%的总连接权重
- **半边缘层**（116个节点，30.0%）：与核心层有至少一条连接，但度值中等
- **边缘层**（219个节点，56.6%）：仅在单一章节内出现，与其他社区连接稀疏

核心-边缘结构的意义：该书的论证高度依赖少数"超级概念"的组织功能，大量边缘节点为这些核心概念提供例证、文献支撑或具体应用。

### 6.2 小世界特性验证
- 平均聚类系数：0.41
- 等规模随机网络预期聚类系数：0.017
- 小世界指数σ = 0.41 / 0.017 = 24.1 >> 1

强烈的小世界特性表明：该网络虽然规模较大（387个节点），但任意两个知识元之间通常只需4步以内即可建立语义连接——全书的"论证空间"具有高度连通性。

### 6.3 无标度特性
度分布的前20个节点（5.2%）承载了总度数的38.7%——幂律特征明显。这表明该网络的形成不是随机的：作者有意将论证锚定在少数核心概念上，其余概念通过USES、EXEMPLIFIES、BELONGS_TO等关系链接至这些核心。
