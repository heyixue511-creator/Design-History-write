# 00 方法与规则

## 本系列文件的方法论基础

本"知识涌现分析"系列文件是对已完成的19份分析报告进行元层次加工的工作。其基本假设是：当一份文献被拆解为若干份专题分析报告后，这些报告所承载的知识并非简单的加性堆积——报告之间的交叉引用、实体重叠、逻辑呼应和结构性空白，构成了一种**知识涌现**的可能性条件。本系列文件的任务，就是系统地识别、提取和报告这种跨报告的新生知识。

本系列文件由五个功能文件组成：
- **00_方法与规则.md**（本文件）：定义分析框架、核心概念、操作规则和输出规范
- **01_知识元语意分析.md**：对全部知识元进行系统性语意拆解与维度标注
- **02_语义链接网络.md**：构建知识元之间的链接网络，识别网络拓扑特征
- **03_知识涌现计算.md**：对语义网络进行涌现性计算，量化新生知识
- **04_知识发现报告.md**：综合前述分析，产出面向研究者的知识发现陈述

## 核心概念定义

### 知识元（Knowledge Element / 知识元）

知识元是指在一份或多份分析报告中出现的、具有独立可识别语义边界的最小知识单元。一个知识元必须同时满足以下三个条件：

1. **可命名性**：能够以一个确定的名称（专名、术语或短语）指称
2. **可定位性**：能够追溯至至少一份源分析报告中的特定章节
3. **可关联性**：与至少一个其他知识元之间存在可识别的语义关系

在本分析中，知识元按范畴分为以下六类：

| 范畴代码 | 范畴名 | 源报告中的对应实体 |
|----------|--------|-------------------|
| KE-P | 人物知识元 (Person) | L008.1 / LNN.4.1 人物实体 |
| KE-I | 流派知识元 (Ism/Movement) | L008.2 / LNN.4.2 流派实体 |
| KE-W | 作品知识元 (Work) | L008.3 作品实体 |
| KE-B | 概念知识元 (Concept/Term) | L008.4 / LNN.4.3 概念/术语实体 |
| KE-S | 文献知识元 (Source/Text) | L008.5 / LNN.4.4 文献实体 |
| KE-V | 机构知识元 (Institution/Venue) | L008.6 / LNN.4.5 出版/机构实体 |

### 语意维度（Semantic Dimension）

每个知识元均包含一个可量化的多维语意属性集合。本分析采用六维语意标注体系：

| 维度代码 | 维度名 | 说明 |
|----------|--------|------|
| D-ONT | 本体论维度 | 知识元所断言的存在类型（物质的/精神的/形式的/社会的） |
| D-TMP | 时间性维度 | 知识元的时间定位与时间关系（瞬时的/持续的/回溯的/预期的） |
| D-GEO | 地理性维度 | 知识元的空间归属与空间移动（本地的/跨国的/中心的/边缘的） |
| D-AGY | 能动性维度 | 知识元所承载的行动者角色（创造者/定义者/传播者/批判者） |
| D-REL | 关系性维度 | 知识元与其他知识元之间的显性关系类型 |
| D-VAL | 价值性维度 | 知识元在全书系统中的评价梯度（肯定的/讽刺的/中立的/忽视的） |

### 语义链接（Semantic Link）

语义链接是两个知识元之间可被文本证据支持的关系。本分析定义以下链接类型：

| 链接代码 | 链接名 | 说明 | 示例 |
|----------|--------|------|------|
| L-GEN | 谱系继承 (Genealogical) | 一个知识元历史性地派生于另一个 | 立体主义→纯粹主义 |
| L-OPP | 语义对立 (Oppositional) | 两个知识元在核心主张上构成对立 | 达达主义↔新造型主义 |
| L-PAR | 语义平行 (Parallel) | 两个知识元在不同空间/语境中呈现相似特征 | 形而上画派∥至上主义 |
| L-COL | 协作共生 (Collaborative) | 知识元之间以合作/共同出现的方式关联 | 李西茨基+阿尔普(编纂) |
| L-INT | 解释中介 (Interpretive) | 一个知识元被另一个知识元所定义/解释 | 阿波利奈尔→立体主义 |
| L-REF | 交叉引用 (Referential) | 一个知识元在文本层面引用了另一个 | 马列维奇总纲→各ism定义 |
| L-EXT | 外部延伸 (External Extension) | 知识元指向全书对象范围之外的实体 | 1924年原版→1990年重印 |
| L-NUL | 空白/缺失 (Null/absent) | 两个知识元之间可能存在但实际缺失的关系 | 毕加索未被选择为定义者 |

### 知识涌现（Knowledge Emergence）

知识涌现是指：当知识元及其语义链接被构建为一个**网络**之后，从网络的拓扑属性中产生出的、任何单个知识元或单份分析报告都未明确陈述的**新生知识命题**。涌现性知识必须满足以下标准：

1. **不可归约性**：该知识命题无法从任何单一知识元或单一报告中逻辑演绎得出
2. **拓扑依赖性**：该知识命题的产生依赖于网络结构本身，而非节点属性
3. **可验证性**：该知识命题可以被回溯至网络中的具体链接模式作为证据

## 分析方法规则

### 规则一：知识元提取的完整性原则

源分析报告中已经过系统化编码的实体（L008.1至L008.6、LNN.4.1至LNN.4.5）将被**全量**纳入知识元语料库。此外，在各分章分析报告中出现的、未被上述索引覆盖的知识元（如L001-L009各节中出现的论证性概念、修辞策略、逻辑结构等），也将被识别和标注。

### 规则二：跨报告交叉验证原则

任何一个语义链接的建立，必须在**至少两份不同的源分析报告**中找到文本证据支持。单一报告中的孤证不能作为语义链接的充分依据。此规则意在过滤掉偶然性的措辞关联，确保链接网络基于可复现的文本模式。

### 规则三：涌现阈值原则

一个知识命题被认定为"涌现"的，当且仅当：
- 该命题所依赖的网络节点数不少于5个
- 该命题所依赖的链接类型不少于2种
- 该命题无法在任何源分析报告的"结论"、"小结"或"L009 关联"节中找到直接的文字表达

此规则区分"被分析报告明确陈述的知识"与"通过网络结构涌现的新生知识"。

### 规则四：发现陈述的格式化原则

所有知识发现陈述必须遵循以下格式：
> **[发现编号] 发现陈述（一句概括）。** 支撑证据：（1）涉及的知识元列表；（2）依赖的语义链接类型；（3）网络拓扑依据。命题溯源：确认该命题未在任何源报告中以当前形式出现。

### 规则五：计算的可复现性原则

03_知识涌现计算.md 中的所有定量计算，必须给出明确的计算公式、输入数据来源和中间步骤。任何基于阈值或参数的选择必须说明理由。

## 输出规范

### 知识元语意分析输出格式

每个知识元条目包含：
```
### KE-[范畴代码]-[序号] [知识元名称]
- **范畴**：[范畴名]
- **维标**：[六维标注，以分号分隔]
- **源定位**：[源报告编号:章节号]
- **语意简述**：[50-100字的核心语义描述]
```

### 语义链接网络输出格式

```
### 链接子网络：[子网络名称]
- **节点列表**：[涉及的KE编号]
- **链接矩阵**：[N×N矩阵，以链接代码标注]
- **网络拓扑特征**：节点度分布/聚类系数/介数中心性
- **涌现效应**：该子网络的新生知识属性
```

### 知识涌现计算输出格式

```
### 涌现计算项：[计算项名称]
- **计算公式**：[数学表达式]
- **输入数据**：[来源与规模]
- **计算结果**：[数值与单位]
- **解释**：[计算结果的知识含义]
```

### 知识发现报告输出格式

```
### 发现[序号]：[发现标题]
- **陈述**：[知识命题]
- **证据链**：[从网络结构到命题的推导]
- **不可归约性验证**：[证明该命题未在源报告中出现]
- **意义评估**：[该发现对理解全书的知识贡献]
```

## 操作流程

本分析系列的操作顺序如下：

1. **知识元提取**（对应01文件）：扫描全部19份源报告，提取并标注所有知识元，建立知识元语料库
2. **语意维度标注**（对应01文件）：对每个知识元进行六维语意标注
3. **链接提取**（对应02文件）：基于跨报告交叉验证原则，建立知识元之间的语义链接
4. **网络构建**（对应02文件）：将知识元作为节点、语义链接作为边，构建完整的有向加权语义网络
5. **涌现计算**（对应03文件）：计算网络的拓扑特征，识别涌现性结构
6. **发现报告**（对应04文件）：综合前述分析，提取并陈述知识发现
