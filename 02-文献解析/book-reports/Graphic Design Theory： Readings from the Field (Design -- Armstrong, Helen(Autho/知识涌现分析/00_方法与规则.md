# 00_方法与规则

## L### 一、知识涌现分析概述

### L### 定义
知识涌现分析（Knowledge Emergence Analysis）是对一组已完成的文本分析报告进行二次加工的方法论体系。其核心目标是：从分散于各章节分析报告中的实体、概念、关系等"知识元"（Knowledge Element）出发，通过语义计算与网络建模，识别那些"单独阅读任一章节无法感知、唯有跨文本整合才能浮现"的高阶知识模式。

### L### 适用前提
本方法适用于以下条件全部满足的文本集合：
1. 源文本为一部结构完整的著作（书籍、论文集、档案汇编）
2. 已完成逐章/逐篇的精细化分析报告（每章包含实体清单、逻辑梳理、论辩分析等）
3. 分析报告采用统一模板，实体分类标准一致（人物、机构、概念、作品、事件、技术/媒介六类）
4. 源文本内部存在跨章节的主题延续、对话关系或演化脉络

### L### 核心假设
- **知识元独立性假设**：每个知识元具有可独立辨识的语义边界，可被编号、归类、描述
- **关系可编码假设**：知识元之间的关系可被有限关系类型所覆盖（影响、回应、继承、反对、并置等）
- **涌现可计算假设**：通过统计聚类、网络拓扑分析、时间序列追踪等手段，可从知识元集合中涌现出非显而易见的宏观模式
- **主题跨域假设**：最重要的知识发现往往跨越单章边界，存在于多章共享的主题节点、结构性空洞或非对称联结之中

## L### 二、知识元定义与分类体系

### L### 知识元的定义
知识元（Knowledge Element, KE）是知识涌现分析的最小操作单元。一个知识元对应源文本分析报告中提取的一个具有独立语义的实体。每个知识元由以下四元组定义：

```
KE = (ID, Type, Attributes, Source)
  ID：唯一标识符，格式为 {TypePrefix}{3位数字}，如 P01, C05, W12
  Type：实体类型，取自六类实体分类体系
  Attributes：属性集 {名称, 原文名, 核心描述, 时间/时期, 关联章节列表}
  Source：来源章节编号（如 03, 15, NN）
```

### L### 六类实体分类体系

| 类型代码 | 类型名称 | 判别标准 | 示例 |
|---------|---------|---------|------|
| P | 人物实体 | 历史上实存的个人、笔者或理论命名者 | P01=Marinetti, P13=Ellen Lupton |
| O | 机构/组织实体 | 具有制度化边界的集体 | O01=Bauhaus, O05=Pentagram |
| C | 概念/术语实体 | 可被定义的理论概念或专业术语 | C01=水晶杯, C06=设计师即作者 |
| W | 作品/出版物实体 | 被命名的书、论文、设计作品 | W01=《未来主义宣言》, W13=IBM标志 |
| E | 事件/运动实体 | 有时段边界的历史事件或运动 | E01=未来主义, E05=国际风格 |
| T | 技术/媒介实体 | 物质技术或传播媒介 | T03=摄影, T06=Adobe Photoshop |

### L### 知识元颗粒度规则
- **颗粒度一致性**：同一类型知识元的颗粒度应大致相当。例如，人物实体不应混合"Marinetti"（个人）与"未来主义者"（群体）
- **源文本锚定**：每个知识元必须有明确的源章节出处，不可凭空构造
- **跨章重复合并**：同一实体在多个章节出现时，合并为单一知识元，在"关联章节"属性中列出所有出处

## L### 三、关系类型体系

### L### 核心关系类型
知识元之间的关系被编码为以下有限类型集合：

| 关系代码 | 关系名称 | 定义 | 方向性 | 示例 |
|---------|---------|------|--------|------|
| R_INFLUENCE | 影响关系 | A的思想/方法/作品对B产生可辨识的影响 | 有向 | Moholy-Nagy → R_INFLUENCE → Bayer |
| R_RESPOND | 回应关系 | B的文本明确回应/引用/批评A | 有向 | Rock → R_RESPOND → McCoy |
| R_INHERIT | 继承关系 | B在A建立的传统/体系/机构中工作 | 有向 | Weingart → R_INHERIT → Müller-Brockmann |
| R_OPPOSE | 对立关系 | A与B的立场/主张构成直接对立 | 无向 | Warde ↔ R_OPPOSE ↔ Weingart |
| R_BELONG | 归属关系 | A属于/参与B（机构/运动/事件） | 有向 | Bayer → R_BELONG → Bauhaus |
| R_PRODUCE | 产出关系 | A创作/出版/设计了B | 有向 | Marinetti → R_PRODUCE → 《未来主义宣言》 |
| R_USE | 使用关系 | A以B为材料/工具/媒介 | 有向 | Manovich → R_USE → Adobe After Effects |
| R_COOCCUR | 共现关系 | A与B在同一章节/同一文本中被共同讨论 | 无向 | Warde ↔ R_COOCCUR ↔ Tschichold |
| R_EVOLVE | 演化关系 | A概念在时间中演化为B概念 | 有向 | 前卫普遍主义 → R_EVOLVE → 方法论普遍主义 |

### L### 关系强度规则
- **显性关系**（强度=1.0）：源文本明确陈述的关系（如"McCoy提出'设计师即作者'"、"Rock回应McCoy"）
- **推断关系**（强度=0.7）：由编者/分析者基于文本证据推断的关系（如同一思想传统中的先后位置）
- **弱推断关系**（强度=0.4）：基于时代/地理/机构邻近性的假定关系
- **结构性关系**（强度=0.3）：仅通过共同归属（如同时代、同运动）建立的关系

### L### 关系编码规则
1. 每条关系必须可在源文本中找到支撑证据（至少一个章节引用）
2. 优先使用显性关系，推断关系需标注"推断依据"
3. 关系的编码粒度与知识元粒度保持一致
4. 避免关系的冗余传导（如A→B→C已有显性关系，A→C的推断关系仅在有独立证据时添加）

## L### 四、语义网络构建规则

### L### 网络定义
语义链接网络（Semantic Link Network, SLN）是一个加权有向图：

```
SLN = (V, E, W)
  V = {KE₁, KE₂, ..., KEₙ}            // 知识元节点集合
  E = {(KEᵢ, KEⱼ, Rₖ)}               // 有向边，标记关系类型
  W = {w₁, w₂, ..., wₘ}              // 边权重（关系强度）
```

### L### 节点属性
每个节点携带以下元数据：
- `type`：实体类型（P/O/C/W/E/T）
- `period`：所属时期（1900s-1910s / 1920s-1930s / 1940s-1960s / 1970s-1980s / 1990s-2000s）
- `chapter_count`：出现的章节数
- `centrality`：在网络中的中心性指标（计算后填入）

### L### 网络构建步骤
1. **节点抽取**：从全部28篇分析报告的实体清单中提取并去重
2. **关系编码**：遍历全部报告，逐对标注知识元间的关系
3. **网络合并**：将不同来源的关系合并，取最高强度值
4. **权重归一化**：关系强度归一化至 [0, 1] 区间
5. **网络输出**：生成节点表、边表、邻接矩阵三种格式

## L### 五、知识涌现计算方法

### L### 涌现的定义
在本分析框架中，"知识涌现"指满足以下至少两个条件的高阶模式：
1. **不可归约性**：该模式在任一单章分析中不可见，必须跨至少3章才能识别
2. **非显而易见性**：该模式不是源文本表层叙述的直接复述（如目录结构），而是需要计算/统计/建模才能发现的隐藏结构
3. **解释增益**：该模式能够为理解全书的深层逻辑提供增量解释力

### L### 计算方法清单

#### L### (1) 中心性分析（Centrality Analysis）
- **度中心性（Degree Centrality）**：统计每个知识元被关联的次数，识别"枢纽知识元"
- **中介中心性（Betweenness Centrality）**：识别承担"桥梁"角色的知识元——连接否则孤立的子网络
- **特征向量中心性（Eigenvector Centrality）**：加权版中心性，连接枢纽的知识元自身更重要
- **涌现信号**：高中介中心性+低度中心性的节点往往是"隐藏枢纽"——不是最常出现但结构性最关键的节点

#### L### (2) 社区发现（Community Detection）
- 使用Louvain算法或Girvan-Newman算法识别紧密互联的知识元社区
- 将算法生成的社区与源文本的三部分结构对比——不匹配之处即为有趣的"涌现"信号
- **涌现信号**：跨越源文本部分边界的社区（如"宣言文体"社区同时包含Marinetti、Rodchenko、Lasn）

#### L### (3) 时序分析（Temporal Analysis）
- 将知识元按时间轴排列，追踪六类实体的数量/密度随时间的变迁
- 计算每条"主题线"（作者身份、普遍性、社会责任）在各时段的出度/入度比率
- **涌现信号**：出/入度比率的突变点标识着该主题线的"转折时刻"

#### L### (4) 结构洞分析（Structural Hole Analysis）
- 识别网络中本应有连接但实际缺失的"结构洞"（Structural Holes）
- 结构洞的存在可能指示：未完成的思想对话、被忽视的关联、编者的取舍意图
- **涌现信号**：高重要性知识元之间存在结构洞=全书论证中的"沉默的缺口"

#### L### (5) 主题漂移追踪（Topic Drift Tracking）
- 追踪同一概念（如"普遍性"）在不同时期关联的知识元簇的变化
- 概念从A簇逐渐漂移至B簇→该概念的内涵/外延发生了可量化的语义变迁
- **涌现信号**：漂移方向与源文本叙述不一致的概念（如源文本说"从A到B"但计算显示"从A到C再到B"）

#### L### (6) 跨类型耦合分析（Cross-Type Coupling）
- 统计六类实体之间的交叉关联密度
- 识别异常高/低的跨类型耦合对——如"人物-概念"耦合极高但"技术-事件"耦合极低
- **涌现信号**：耦合强度的结构失衡可能揭示全书的知识生产偏向

## L### 七、数据来源与处理约定

### L### 数据来源
本分析基于以下已完成的分析报告：

- `01-26`：24篇核心文献 + 前言 + 导论的逐章分析
- `NN_专项报告与实体总索引.md`：6项专项报告与6类实体总索引

总计28篇分析报告，涵盖：24位人物实体、16个机构实体、22个概念实体、20个作品实体、14个运动实体、16个技术实体。

### L### 实体去重规则
- 同一人物如在各章分析中以不同编号出现（如P13=Ellen Lupton在各章中出现多次），以`NN_专项报告与实体总索引`中的编号为权威编号
- 总索引未收录的实体，以首次出现的章节编号为准
- 名称变体（如"Moholy-Nagy"与"László Moholy-Nagy"）统一为全名

### L### 时期划分
为时序分析需要，将全书时间跨度划分为以下区间：
- **P1_前卫时期**（1900-1919）：未来主义、俄国革命的酝酿期
- **P2_构成-包豪斯时期**（1920-1933）：构成主义、包豪斯全盛期
- **P3_功能主义-移民时期**（1934-1959）：包豪斯关闭后、美国企业现代主义兴起
- **P4_瑞士国际风格时期**（1960-1969）：方法论主义顶峰
- **P5_后现代反叛时期**（1970-1989）：新浪潮、后现代主义
- **P6_数字重构时期**（1990-2008）：数字技术、全球化、后后现代

### L### 工具约定
- 网络计算使用标准图论算法，边权重归一化至[0,1]
- 中心性排名归一化为百分位排名
- 社区检测使用Louvain算法，分辨率参数默认1.0
- 所有计算结果的原始数据以表格形式附于对应章节
