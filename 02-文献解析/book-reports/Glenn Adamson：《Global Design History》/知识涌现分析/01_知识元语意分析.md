## 二、概念元的语意场分析

### 核心概念的四象限语意场

基于NN索引的"概念/术语索引"（共45个核心概念），按照两个维度构建语意场：

- **横轴**：物质性（Material）←→ 社会性（Social）
- **纵轴**：分析性（Analytical，作为研究工具）←→ 对象性（Objectual，作为研究对象）

四个象限的分布：

| 象限 | 位置 | 概念示例 |
|------|------|---------|
| I | 分析性+物质性 | "物品的'物质褶皱'"、"设计的可适应性"、"治具批次生产"、"次要文学" |
| II | 分析性+社会性 | "去中心化逻辑"、"连接与比较"、"好的描述"、"展演性" |
| III | 对象性+物质性 | "第一个全球品牌"、"侘寂（wabi）"、"设计词汇"、"炫耀性贫困" |
| IV | 对象性+社会性 | "手工现代主义"、"世界性地方主义"、"重新东方主义"、"内部他者性" |

### 概念的语义谱系

#### 物质流通语意簇


#### 权力结构语意簇


#### 文化转化语意簇

```

  → 搭配的眼光/toriawase（Ch4: 日本茶道中的组合审美）
```

### 方法论的知识原型冲突

全书存在一种深层的方法论张力，可归纳为两极化：

```
描述 ←————————————————————————————→ 批判
│                                        │
Ch7 (Golec: 次要文学的描述)              Ch8 (Maciuika: 政治经济批判)
Ch12 (Zimmermann: 好的描述/Latour)        Ch14回 (May: 发展经济学批判)
Ch13 (Traganou: 民族志工作者)             Ch12回 (Sum: Foucault+政治经济)
     │                                        │
     └────────── 导论"连接"轴线 ──────────────┘
                    ↕
              导论"比较"轴线
```

这一"描述 vs. 批判"的张力在Ch12/Sum回应对中最为显现——Zimmermann以Latour的"好的描述不需要解释"为其第一人称民族志辩护，Sum则以Foucauldian生物政治学追问开心网在"更广泛的互联网审查背景下"的政治条件。这不是两种方法谁对谁错的问题，而是全球化设计研究的内在认识论张力：**全球设计史的描述性任务（记录差异）与规范性任务（评估权力）之间的不可消解**。

## 五、论证元的逻辑结构

### 全书核心论证链条的提取

从各章分析报告的"逻辑梳理"节提取论证元（A型知识元），识别全书级别的论证结构：

```
A-0（导论）: 设计史长期被欧洲中心/现代主义叙事主导
  → 需要"全球转向"
    → 全球设计史是方法论而非话题
      → 三种分析模型：连接/比较/物品
        → 14章案例研究 + 14篇回应
          → 星丛式知识图景（拒绝大叙事）

A-1（Ch1-3 早期现代）: 全球物质交换早于现代殖民主义
  → 文艺复兴/瓷器/棉布皆内在于全球网络
    ↕（对立）
A-4（Ch4-6 文化实践）: 本地文化实践不是全球化的被动接受
  → 进口替代、城市品牌、身份展演皆构成创造性转化

A-2（Ch7-9 技术政治）: 技术与政治经济对设计的规训
  → 电话/制造联盟/印度工业化——全球化的权力维度
    ↕（补充）
A-3（Ch10-14 当代）: 手工艺/奢侈/SNS/建筑/电商——全球化的当代形态
  → "全球"不再只是一个历史分析范畴，而是一种当代实践条件
```

### 论证元的"未闭合"特征

全书的一个显著特征是大量论证以**未闭合**状态收束：

- Ch1的"裂隙"（Leibsohn）概念开放了"不可共享性"的理论空间，但未给出解决方案。
- Ch12以"也许我很快会跨过这条线"收束，明确拒绝传统结论。
- Ch14的May回应以尖锐批判收束，而正文作者未再答辩——全书在其最尖锐的内部批判处戛然而止。

这种"未闭合"不是论证的缺陷，而是全书"碎片化、局部、临时"方法论立场的**具身化**——它不提供解决方案，而提供问题的精确表述。
