# 第一部分：专项报告

## Z01 全书跨章主题网络深度分析

### 主题1：数字/物质不可分性（Digital–Material Inseparability）

| 章 | 贡献维度 | 关键论点 |
|----|----------|----------|
| Ch1 | 本体论奠基 | 数字物质性是"过程"、"涌现"——不是混合本体论标签 |
| Ch2 | 技术内部论证 | 仿真实践揭示"虚拟化=再物质化"——PDP-10虫子、CRT时序、IO的非Turing性 |
| Ch3 | 知识生产的物质性 | 传感器的"可负担性"不在于低价，在于使技术知识"物质化"为公共可及的形式 |
| Ch4 | 日常实践的再物质化 | 智能家居从乌托邦愿景→日常生活的"mess"——"自动化奴隶"反而获得"自己的生命" |
| Ch5 | 家作为数字-物质氛围 | media presence + atmosphere——数字媒体在on/off/standby状态中参与家的氛围构成 |
| Ch6 | 思辨对象的物质性 | 数字-物质对象作为"白痴"——其歧义性、非功能性、游戏性构成探测可能世界的方法 |
| Ch7 | 代码与身体的物质性对话 | 用户的身体materiality与flow——通过代码与系统对话——成为co-designer |
| Ch8 | 身体作为数字物质性 | 活跃身体不interact with数字化环境，活跃身体**就是**数字物质性的一种形态 |
| Ch9 | 手机与身体的物质审美 | 手机通过指甲/牛仔裤/钱包/背包的物质配置成为"移动美学" |
| Ch10 | 档案的数字-物质记忆 | 视频记录作为"nonhuman storyteller"——将其material singularity带入记忆展演 |
| Ch11 | 基础设施的物质-象征交织 | Wi-Fi网络的物质功能薄弱，但其**象征性**展示"progressive"品格——物质/符号不可分 |

## Z02 方法论谱系专项分析

全书呈现了六种不同的数字物质性研究方法论路径：

### L001 感官视频民族志
- **代表章节**：Ch5 (Pink et al.)
- **核心操作**：video tour → reenactment studies → activity studies 的三阶段循环
- **数据形态**：视频材料 + 参与者反馈 + 理论-民族志对话
- **与设计的关系**：民族志洞察→"How might we"机会陈述→设计概念→理论回审

### L002 嵌入式过程民族志
- **代表章节**：Ch7 (Ferrer, Ardèvol, Parés)
- **核心操作**：五年追踪一个设计项目——从Lab到公共场所的多次实验
- **数据形态**：田野笔记 + 对话抄本 + 视频分析 + 系统日志
- **独特之处**：民族志学者本人是设计者——"内部-外部"双重视角

### L003 多场景产业民族志
- **代表章节**：Ch3 (Lanzeni)
- **核心操作**：追踪传感器的"生命周期"——IoT聚会→Fab Lab→Kickstarter发布会→行业论坛
- **数据形态**：田野观察 + 开发者引语 + 产业文本（Nature文章/Cisco主页）
- **独特之处**：研究对象（传感器开发者）在进行与民族志学者平行的"知识生产"

### L004 未来导向的研究贯穿设计（Research-through-Design）
- **代表章节**：Ch8 (Mueller)
- **核心操作**：设计系统→部署（"in-the-wild"）→观察→反思→工具化
- **数据形态**：设计作品 + 玩家观察 + 反思日志
- **独特之处**：民族志被用来"provoke future interactions"——理解"should be"而非仅"what is"

### L005 思辨方法（Idiotic Methodology）
- **代表章节**：Ch6 (Michael)
- **核心操作**：部署歧义/非功能性/游戏性数字-物质对象→观察用户如何与该对象"共生成"
- **理论武器**：Whitehead的process philosophy + Stengers的cosmopolitics/idiot
- **数据形态**：设计轶事（蓝牙音箱）+ 设计案例（Local Barometer/Home Health Monitor）+ 哲学概念

### L006 长期多点民族志
- **代表章节**：Ch9 (Horst)
- **核心操作**：长期田野关系（1999年至今）——跨越手机型号世代的跟踪
- **数据形态**：生活史叙述 + 物质文化观察 + 照片
- **独特之处**："时间纵深"使得追踪单个审美模式在十年间的连续性成为可能

### L007 社区-政策网络分析
- **代表章节**：Ch11 (McShane et al.)
- **核心操作**：访谈关键行动者 + 政策/产业文本分析 + 空间观察
- **数据形态**：访谈转录 + 议会文件 + 网络使用数据 + 照片
- **独特之处**：研究者明确记录了自身分析框架被田野修正的过程

## Z03 数字物质性的概念谱系

全书贡献了数字物质性的多层次概念体系：

| 层次 | 概念 | 提出者/章节 | 定义要旨 |
|------|------|-------------|----------|
| 本体论 | digital materiality as process/becoming | Ch1 (Pink et al.) | 数字物质性不是状态/品质，而是制造过程和涌现 |
| 技术本体论 | rematerialization | Ch2 (Dourish) | 虚拟化不是在创造脱离物质的"虚拟域"，而是在新物质基础上重新实现 |
| 设计过程论 | affordable material knowledge | Ch3 (Lanzeni) | 传感器使技术知识以可及的价格被"物质化"——知识生产是物质工作 |
| 日常实践论 | atmosphere / presence | Ch5 (Pink et al.) | 数字媒体参与家的"氛围"构成——不是内容/通信工具而是存在方式 |
| 思辨方法论 | idiotic digital–material object | Ch6 (Michael) | 歧义对象通过其"不make sense"来探测社会物质事件的可能性 |
| 交互本体论 | coded object / seasoned object | Ch7 (Ferrer et al.) | 代码塑造物的物质性和在世存在——物通过反复使用"积累经验" |
| 身体现象学 | body as digital materiality | Ch8 (Mueller) | 活跃身体不是"界面"——是数字物质性本身的一种形式 |
| 物质审美论 | mobile aesthetics | Ch9 (Horst) | 手机通过其与身体/衣物的物质配置成为审美世界组成部分 |
| 档案物质论 | nonhuman storyteller / platform for memory | Ch10 (Carlin) | 视频记录作为机器的"叙事者"——数字档案的物质性enable storytelling |
| 基础设施论 | tactical/symbolic digital–materiality | Ch11 (McShane et al.) | Wi-Fi网络的物质功能薄弱，但其象征性展示是"成功"的关键 |
