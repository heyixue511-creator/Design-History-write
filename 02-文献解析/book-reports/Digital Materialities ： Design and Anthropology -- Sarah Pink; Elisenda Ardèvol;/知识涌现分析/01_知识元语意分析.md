### 一、K01 本体论知识元（8个）

#### KU-001 | 数字物质性作为过程/涌现

| 属性 | 标注 |
|------|------|
| **来源章** | Ch1 |
| **源分析报告** | 01 |
| **学科域** | 跨学科（人类学+设计学+HCI） |
| **抽象层级** | L1 元理论 |
| **可链接度** | 5 |
| **新颖度** | 5 |
| **跨域潜力** | 5 |

**语意核心**：数字物质性（digital materiality）不是对某种混合本体论的标签描述，而是对"制造过程及该过程中涌现之物"的命名。它指涉的是 **making and what emerges of entanglements** ——不是"状态"也不是"品质"，而是"过程"与"生成"（process and becoming）。

**语意辨析**：
- 区别于新物质主义（Bennett的vibrant matter）：新物质主义赋予物质以活力，但未充分处理"数字"维度。
- 区别于Parikka的过程物质性（processual materiality）：Parikka聚焦电子废物的物质流动，但未将其与设计实践连接。
- 区别于Dourish的具身互动：Dourish聚焦"身体-计算"的互动，本书将其扩展为"数字-物质-社会"的三元过程。

**跨章演化轨迹**：Ch1提出概念→Ch2以技术内部论证（仿真=再物质化）→Ch5以民族志展示（家作为数字-物质氛围）→Ch8推向极端（身体=数字物质性）。

#### KU-002 | 数字与物质的不可分割性

| 属性 | 标注 |
|------|------|
| **来源章** | Ch1 |
| **源分析报告** | 01 |
| **学科域** | 跨学科 |
| **抽象层级** | L1 元理论 |
| **可链接度** | 5 |
| **新颖度** | 4 |
| **跨域潜力** | 5 |

**语意核心**："the digital and material should not be thought of as two separate things that already independently existed in the world and have now become entangled"（L216）。数字与物质不是两个预先独立存在的实体而后发生纠缠，而是同一过程的不可分割的维度。

**语意辨析**：与Latour的ANT（actor-network theory）的"纠缠"（entanglement）概念有亲缘但也有差异——ANT的"对称性"仍以人与非人为两个分析单元而后对称分析，而数字物质性的不可分割性更进一步：在分析起点上就不应区分。

#### KU-003 | 虚拟化作为再物质化

| 属性 | 标注 |
|------|------|
| **来源章** | Ch2 |
| **源分析报告** | 02 |
| **学科域** | HCI/计算机科学 |
| **抽象层级** | L2 中层理论 |
| **可链接度** | 4 |
| **新颖度** | 5 |
| **跨域潜力** | 4 |

**语意核心**："virtualization is better seen as rematerialization"（L396）。每一次"虚拟化"操作不是在创造一个脱离物质的"虚拟域"，而是在新的物质基础上重新实现数字体验。仿真——作为"双重虚拟"——恰如其分地暴露了这一点。

**论证逻辑的内在结构**：
1. 仿真声称在软件中"复制"旧计算机
2. 但仿真必须复制原机器的硬件缺陷（PDP-10的浮点bug）
3. 必须复制原机器的非数字物理特性（CRT扫描时序）
4. 必须处理原机器的输入输出——而IO在数学上超出Turing可计算性
5. 因此：仿真不是在"去物质化"，而是在执行一种"跨越物质基础的翻译"

#### KU-004 | 计算机程序的欠规范性

| 属性 | 标注 |
|------|------|
| **来源章** | Ch2 |
| **源分析报告** | 02 |
| **学科域** | HCI/计算机科学 |
| **抽象层级** | L2 中层理论 |
| **可链接度** | 3 |
| **新颖度** | 4 |
| **跨域潜力** | 3 |

**语意核心**：程序文本（notation）与实际执行（enaction）之间存在结构性间隙——"the experience that is the result of the program's execution is radically underspecified by that program"（L379）。数字的物质性恰恰存在于这一"间隙"之中——在规范与执行之间、在标注与呈现之间。

**语意关联**：与Ingold的"making as a process of growth"（制造作为生长过程）存在深层类比——程序执行不是"实现预定规范"，而是在特定物质条件中的"生长"。

#### KU-005 | 身体作为数字物质性

| 属性 | 标注 |
|------|------|
| **来源章** | Ch8 |

| **抽象层级** | L1 元理论 |
| **可链接度** | 4 |
| **新颖度** | 5 |
| **跨域潜力** | 5 |

**语意核心**："the active human body...can even be seen as a form of digital materiality"（L1191）。这不是说身体"与"数字系统交互——Kinect/Wii的模式仍保持身体/屏幕的二分——而是说身体本身（在其活跃、运动、流汗、拥抱的物理性中）构成了数字物质性的一种形态。其论证通过Cart-Load-O-Fun（通勤动作=游戏输入）、SweatAtoms（心率数据→3D打印物质产物）、Musical Embrace（社交尴尬→游戏资源）三案例逐层推进。
