# 00 知识涌现分析：方法与规则

## 一、本系列文件的目的

从《The Elements of Typographic Style》（clean 版，6924 行）中，不依赖代码与统计，仅凭逐行语义阅读，完成三层涌现分析：
1. **知识元提取**（01 文件）：将文本离散为可复用的最小知识单元；
2. **语义链接网络**（02 文件）：揭示知识元之间的关系（支持、反对、例证、递进）；
3. **涌现结构计算**（03 文件）：识别高层域、桥接元、内聚度与涌现强度，生成一级/二级涌现命题；
4. **知识发现**（04 文件）：网络整体特征、隐藏枢纽、跨主题综合命题与完整层级图谱。

## 二、分析流程（六步）

1. **逐行通读**：全部 6924 行正文与附录已通读（父进程已清洗，行号以 clean 版为准）。
2. **章节锚定**：确定 11 章 + 5 附录 + 序/后记的起止行号（见 00 整体分析报告第四节）。
3. **知识元切分**：以"可独立成立、可被引用、可被验证"为标准，按主题归类。
4. **链接标注**：对每一知识元标注其来源章节、支持/例证/反例关系、桥接属性。
5. **域归纳**：将知识元归入 5 个高层域（见 03 文件），识别域间桥接元。
6. **涌现综合**：对重复出现、跨域交织的主题进行综合，形成命题。

## 三、客观性规则

1. 所有命题须有行号证据；无证据的推断明确标注为"推断"。
2. 本书存在内部张力（如"规则 vs 反例"），涌现命题必须同时给出文本依据与边界。
3. 不引入文本之外的外部知识作为证据；背景解释仅作辅助。
4. OCR 文本中希腊文、公式等字符识别混乱处，只取语义可读部分（如 L2801–L2803 的字符集规模结论不受影响）。

## 四、关键前置判断（供 01–04 引用）

- **全书元主题**：排印是"赋予语言以耐久可见形态"的技艺（L76），兼具视觉意义与历史意义（L42–L43），其原则基于人体结构与心灵解剖（L67）。
- **全书元方法**：规则条文 + 历史谱系 + 音乐类比 + 伦理批判四法并用。
- **文本的内在结构**：理念（第1章）→参数（2–5章）→选择（6章）→历史（7章）→页面（8章）→技术（9章）→修缮（10章）→谱系（11章）→工具书（附录）。
