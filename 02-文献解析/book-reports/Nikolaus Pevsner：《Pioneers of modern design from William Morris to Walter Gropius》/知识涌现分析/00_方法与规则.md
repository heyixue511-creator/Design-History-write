# 00 方法与规则：知识涌现分析的框架定义

## L1 分析目标

本知识涌现分析以佩夫斯纳《现代设计的先驱者》的七章分析报告、整体分析报告及专项报告为源文本，完成以下四项任务：

1. **知识元语意分析**——将源文本中承载独立知识的最小语义单元（知识元）提取出来，赋以语意标注和分类编码。
2. **语义链接网络构建**——识别知识元之间的语义关系，构建有向有权重的语义链接网络。
3. **知识涌现计算**——基于语义网络的结构特征，运用涌现算子（emergence operator）计算新知识的涌现位置、涌现强度和涌现类型。
4. **知识发现报告**——将涌现计算的结果转译为面向设计史学术研究的知识发现，提供可验证、可讨论的研究假说。

## L2 知识元的定义与分类体系

### L2.1 知识元的操作定义

知识元（Knowledge Unit, KU）是源文本中满足以下三个条件的最小语义单元：

1. **独立性**——该单元携带一个完整的、可独立理解的语义命题。
2. **可链接性**——该单元能够与至少一个其他知识元建立明确的关系连线。
3. **知识承载性**——该单元传递的是"关于某物某事的知识"，而非纯粹的修辞、过渡性或结构性语言。

### L2.2 知识元的七类本体

| 类别编码 | 类别名称 | 定义 | 示例 |
|----------|----------|------|------|
| KU-P | 人物 | 在源文本中被命名的历史人物 | William Morris, Walter Gropius |
| KU-C | 概念/术语 | 在源文本中被定义或使用的专业概念 | Sachlichkeit, 过渡风格 |
| KU-E | 事件 | 具有时空坐标的历史事件 | 1851年万国博览会, 1914年科隆辩论 |
| KU-B | 建筑/作品 | 被分析的具体建筑或设计作品 | 红屋, AEG涡轮机工厂 |
| KU-O | 组织/机构 | 被提及的组织、学派或机构 | 包豪斯, 德意志工业联盟 |
| KU-PB | 出版物 | 书籍、期刊、宣言文本 | 《七盏灯》, The Studio |
| KU-T | 论题/命题 | 源文本中的论证性命题 | "莫里斯与格罗皮乌斯之间的阶段构成一个历史单元" |

### L2.3 知识元的本体属性

每个知识元携带以下本体属性：

- `id`：唯一标识符（格式：`KU-{类别}-{序号}`）
- `name`：知识元的规范名称（中文/原文）
- `time_range`：知识元的时间锚（人物为生卒年，事件为发生年，概念为首次提出年等）
- `geo_tag`：知识元的地理标签（国家/城市）
- `source_chapter`：在源文本中首次出现或主要展开的章节编号
- `salience`：显著性评分（1-5），基于在源文本中的出现频次、篇幅占比和论证权重
- `semantic_vector`：语义向量，即以5个关键语义维度描述该知识元的核心特征

## L3 语义关系的定义与分类

### L3.1 关系类型体系

知识元之间的语义关系分为五类十八型：

**A类：因果-影响关系（4型）**

| 关系型 | 编码 | 正向 | 逆向 | 说明 |
|--------|------|------|------|------|
| 直接影响 | R-A1 | influences | influenced_by | A直接影响了B的思想或实践 |
| 间接影响 | R-A2 | shapes | shaped_by | A通过中介间接影响了B |
| 理论奠基 | R-A3 | grounds | grounded_in | A为B提供了理论基础 |
| 实践继承 | R-A4 | inherits_from | bequeaths_to | B在实践上继承或发展了A |

**B类：时间-序列关系（3型）**

| 关系型 | 编码 | 正向 | 逆向 | 说明 |
|--------|------|------|------|------|
| 先于 | R-B1 | precedes | succeeds | A在时间上先于B |
| 同时 | R-B2 | contemporary_with | — | A与B同时发生或存在 |
| 过渡 | R-B3 | transitions_to | transitions_from | A作为过渡阶段通向B |

**C类：结构-组成关系（4型）**

| 关系型 | 编码 | 正向 | 逆向 | 说明 |
|--------|------|------|------|------|
| 属于 | R-C1 | belongs_to | contains | A是B的组成部分 |
| 产生 | R-C2 | produces | produced_by | A生产了B（人物→作品） |
| 定义 | R-C3 | defines | defined_by | A对B进行了概念定义 |
| 例证 | R-C4 | exemplifies | exemplified_by | A作为B的具体例证 |

**D类：对位-张力关系（4型）**

| 关系型 | 编码 | 正向 | 逆向 | 说明 |
|--------|------|------|------|------|
| 对立 | R-D1 | opposes | opposed_by | A与B在理论上对立 |
| 互补 | R-D2 | complements | complemented_by | A与B相互补充 |
| 综合 | R-D3 | synthesizes | synthesized_by | A综合了B1、B2……的矛盾 |
| 替代 | R-D4 | replaces | replaced_by | A在功能上替代了B |

**E类：类比-映射关系（3型）**

| 关系型 | 编码 | 正向 | 逆向 | 说明 |
|--------|------|------|------|------|
| 类比 | R-E1 | analogous_to | — | A与B在结构或功能上具有类比关系 |
| 跨域映射 | R-E2 | maps_to | mapped_from | A领域的概念映射到B领域 |
| 同构 | R-E3 | isomorphic_to | — | A与B在深层结构上同构 |

### L3.2 关系的权重定义

每条语义关系的权重由三个因子乘积决定：

```
W(R) = S_source × S_target × I(R)
```

其中：
- `S_source`：源知识元的显著性评分（1-5）
- `S_target`：目标知识元的显著性评分（1-5）
- `I(R)`：关系强度系数，按关系类型取值：
  - 直接影响（R-A1）：0.9
  - 理论奠基（R-A3）：0.8
  - 综合（R-D3）：0.8
  - 对立（R-D1）：0.7
  - 实践继承（R-A4）：0.7
  - 过渡（R-B3）：0.6
  - 间接影响（R-A2）：0.5
  - 互补（R-D2）：0.5
  - 产生（R-C2）：0.5
  - 替代（R-D4）：0.5
  - 定义（R-C3）：0.4
  - 例证（R-C4）：0.3
  - 属于（R-C1）：0.3
  - 先于/同时（R-B1/R-B2）：0.2
  - 类比（R-E1）：0.3
  - 跨域映射（R-E2）：0.2
  - 同构（R-E3）：0.3

权重范围为 1-112.5。

## L4 语义链接网络的构建规则

### L4.1 网络定义

语义链接网络（Semantic Link Network, SLN）定义为一个有向加权图：

```
SLN = (V, E, W, T)
```

其中：
- `V`：节点集合，即全部知识元
- `E`：边集合，即全部语义关系
- `W`：边的权重函数
- `T`：边的类型标记函数

### L4.2 节点度与中心性

- **出度（out-degree）**：从该知识元出发的关系数
- **入度（in-degree）**：指向该知识元的关系数
- **介数中心性（Betweenness Centrality）**：节点位于任意两节点最短路径上的次数比例
- **特征向量中心性（Eigenvector Centrality）**：考虑邻居节点重要性的加权中心性

### L4.3 社区检测

采用模块度优化算法（Louvain Method），将语义链接网络划分为若干社区（communities）。每个社区代表一个内部关系密集、外部关系稀疏的知识簇。社区检测的目标是识别源文本中隐含的"知识板块"——这些板块并非源文本明确标注的章节边界，而是语义关系的自然聚类。

### L4.4 网络层级

SLN 构建为三层结构：

- **L1——实体层**：人物、建筑、组织、出版物之间的具体历史关系
- **L2——概念层**：概念、术语、论题之间的逻辑-理论关系
- **L3——跨层映射层**：实体层与概念层之间的定义、例证、影响关系

三层之间通过桥接边（bridge edge）连接，形成完整的语义立方体。

## L5 知识涌现的计算规则

### L5.1 知识涌现的操作定义

知识涌现（Knowledge Emergence）指：当两个或两个以上的知识元通过语义链接网络中的特定路径连接时，产生了一个在原始知识元中**均不单独包含**的新语义内容。该新内容满足以下条件：

1. **新颖性**——该内容在源文本的任何单个知识元中均不直接陈述。
2. **可推导性**——该内容可以通过链接路径信息和链接类型逻辑地推导得出。
3. **非平凡性**——该内容不是已有知识元的简单组合或并集，而是具有质的新意。

### L5.2 涌现算子

定义三种涌现算子：

**算子1：闭合涌现（Closure Emergence）**

条件：存在三角链接结构 A→B, B→C, A→C（类型不限），且三条边的语义协同。
涌现产物：从三元组的语义闭合中产生的新的跨级命题。

计算公式：
```
E_cl(A,B,C) = min(W(A→B), W(B→C), W(A→C)) × f_type(A→B, B→C, A→C)
```
其中 `f_type` 为关系类型协同系数：
- 三条边均为因果-影响类：1.5
- 含时间关系+因果关系的组合：1.2
- 含对位-张力关系的组合：2.0
- 含类比-映射关系的组合：1.8

**算子2：桥接涌现（Bridge Emergence）**

条件：两个不同社区（community）的节点通过桥接边连接，且两社区的语义域不同。
涌现产物：跨域的知识映射或类比。

计算公式：
```
E_br(u,v) = W(u→v) × |C_u - C_v| / d(C_u, C_v)
```
其中 `|C_u - C_v|` 为两社区语义距离，`d(C_u, C_v)` 为两社区间最小路径长度。

**算子3：矛盾涌现（Contradiction Emergence）**

条件：存在 A→B 和 C→B，且 A 与 C 之间存在对立关系（R-D1）。
涌现产物：对被指向节点 B 的二元评价所揭示的深层悖论。

计算公式：
```
E_cnt(A,B,C) = max(W(A→B), W(C→B)) × W(A↔C)
```
其中 `W(A↔C)` 为 A 与 C 之间对立关系的权重。

### L5.3 涌现强度的阈值

- **高强度涌现**（E >= 30）：应被列为"高置信度知识发现"，进入知识发现报告的核心论点。
- **中强度涌现**（15 <= E < 30）：应被列为"中置信度知识发现"，进入知识发现报告的扩展分析。
- **低强度涌现**（E < 15）：列为"待验证假说"，进入知识发现报告的附录。

## L6 分析流程的执行规则

### L6.1 五阶段流程

```
源文本读取 → 知识元提取与语意标注 → 语义链接网络构建 → 涌现计算 → 知识发现报告
```

每一阶段的输出作为下一阶段的输入，形成线性流水线。

### L6.2 质量控制规则

1. **双人原则**（模拟）：每个知识元的提取需基于源文本的明确段落（注明出处），不得凭空产生。
2. **完整性原则**：知识元的覆盖率应不低于源文本主要实体的90%（基于NN_专项报告与实体总索引作为对照基准）。
3. **一致性原则**：同类知识元的语意标注维度应保持一致，确保后续计算的向量可比性。
4. **可溯源性原则**：每条涌现产出的新知识必须附带推导路径和计算过程，供人工审查。

### L6.3 输出格式规则

- 所有文件使用 Markdown 格式
- 所有标题使用 L###（L1/L2/L3/L4）层级制，与源分析报告保持一致
- 知识元编码使用统一格式：`KU-{类别}-{三位序号}`
- 关系编码使用统一格式：`R-{主类}{子类}{序号}`
- 涌现产物编码使用：`EM-{算子}-{序号}`
