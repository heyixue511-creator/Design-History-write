### 1.2 第一板块的跨章整合结构

第一板块的三章形成了一个从"定义"（第1章）到"历史"（第2章）到"过程研究"（第3章）的螺旋上升结构。其SLN呈现以下特征：

**层级1——认识论基础层**：
- KU-ONT-P-001（设计作为技能）和KU-ONT-P-003（问题-方案协同涌现）构成板块的两个根本前提
- 二者之间通过KU-EPI-P-003（认知策略是教育塑造的）建立桥梁：[KU-ONT-P-001 → KU-EPI-P-003 ] ⊣ [分叉 → KU-ONT-P-003]

**层级2——方法论批判层**：
- KU-MET-M-001（RIBA地图批判）和KU-MET-M-002（Markus/Maver模型批判）→ 共同通过KU-MET-C-002（分析通过综合）形成对线性过程的系统性批判

**层级3——实证支持层**：
- KU-MET-E-001（积木实验）、KU-MET-E-002（Eastman协方分析）⊢ KU-ONT-P-003（问题-方案共同涌现）

### 2.2 第二板块的整合结构特征

第二板块的SLN呈现明显的"双流星"结构：两个高中心性节点是KU-ONT-M-004（约束空间格）和KU-ONT-P-002（设计作为规范性活动）。这两个节点通过KU-VAL-P系列（价值论知识元）实现深度耦合。

关键发现：约束模型的形式上虽被定位为"问题模型"（第6章），但其SLN地位更多服务于桥接：它将板块一的认知心理学发现（第1-3章）和板块三的设计策略讨论（第11章）结构性地连接起来。

## L003 第三板块SLN：设计思维（第8-11章）

### 3.1 章内核心链接

```
[认知双核结构]
KU-COG-P-001 (收敛与发散的思维区分)
    ├── ⇔ KU-COG-P-004 (创造力非纯粹发散)  [共同涌现 ⇔]
    │   └── ↝ KU-COG-M-001 (五阶段模型及其批判)
    └──→ KU-COG-M-002 (Laxton的水库学习模型)  [工具应用 ⌣]

KU-COG-P-003 (经验的双刃剑——Einstellung)
    ├──⊣ KU-COG-M-002 (水库模型)  [批判：经验既充实水库又僵化思维]
    ├── ⇔ KU-COG-E-002 (初学者优势)  [支持论证 ⊢]
    └── ∼ KU-MET-M-006 (拼合陷阱)  [相似类比 ∼]
        [注：Einstellung是认知心理学层次的"隐式规则限制"，拼合陷阱是设计实践层次上的同一机制]

KU-COG-E-001 (MacKinnon创造性建筑师人格)
    ├──⊢ KU-VAL-M-001 (设计哲学作为隐性世界观)
    └──⊣ KU-ONT-P-001 (设计作为可学习的技能)
        [注：人格研究揭示了个体差异的存在——技能是可学习的，但人格维度上的差异不可约简为技能训练结果]

KU-VAL-M-001 (设计哲学作为隐性世界观)
    ├── → KU-MET-C-005 (设计策略多样性的根源)  [因果推导 →]
    └── ⇔ KU-ONT-P-004 (不存在唯一正确的过程)  [支持论证 ⊢]

KU-MET-C-004 (Form Generator)
    ├── ↝ KU-ONT-M-001 (约束生成者——设计师作为generator之一)
    ├── ∋ KU-MET-E-002 (Eastman协方分析——"提前承诺"现象)
    └── → KU-MET-C-005 (设计策略多样性)  [用例 ∋]
```

### 3.2 第三板块的跨章整合结构

第三板块建立了全书中认知心理学与设计方法论的最高度整合：

1. **认知层次（第8-9章）**：KU-COG-P-001（收敛/发散）和KU-COG-P-003（Einstellung效应）构成认知科学的双核
2. **价值层次（第10章）**：KU-VAL-M-001（设计哲学）作为从认知到方法的翻译层——将认知偏好转化为设计方法论立场
3. **策略层次（第11章）**：KU-MET-C-004（Form Generator）和KU-MET-C-005（策略多样性根源）作为方法论的应用层

三层之间的链接模式：[认知双核 → (工具应用⌣) → 设计哲学 → (因果推导→) → 设计策略选择]

## L004 第四板块SLN：设计实践语境（第12-14章）

### 4.1 章内核心链接

```
[陷阱网络的层次结构]
KU-MET-C-006 (注意力转移作为核心机制)

    ├── → KU-MET-M-006 (拼合陷阱) [因果推导 →: 注意力误向伪拼合]
    ├── → KU-MET-M-007 (数字陷阱) [因果推导 →: 注意力被数字的修辞力量捕获]
    ├── → KU-MET-M-008 (图符陷阱) [因果推导 →: 注意力局限于单一表征模式]
    └── → KU-MET-M-009 (意象陷阱) [因果推导 →: 注意力被象征意象的自我说服力捕获]

KU-MET-M-010 (Broadbent的四种设计策略)
    ├── ∼ KU-MET-C-005 (策略多样性的原因) [相似类比 ∼]
    └── → KU-MET-C-006 (注意力转移) [工具应用 ⌣]
        [注：四种策略可视作四种基本的注意力分配模式]

[Sociotechnical链接]
KU-SOC-P-001 (行动需求语境的时间压力)
    ├──→ KU-VAL-P-003 (没有犯错的权利)  [支持论证 ⊢]
    └──→ KU-ONT-P-005 (设计的无终点性)  [支持论证 ⊢]

KU-TEC-M-001 (CAD的四种角色)
    ├── ∼ KU-ONT-M-004 (约束空间格) [相似类比 ∼：两者都是分类学结构]
    ├── ↝ KU-MET-C-005 (策略多样性) [修正发展 ↝：CAD的引入增加了策略的一个新维度]
    └── ⌣ KU-MET-C-006 (注意力转移) [工具应用 ⌣：CAD改变注意力的可及范围]

KU-TEC-P-001 (Fitts List)
    ├──⊢ KU-ONT-P-001 (设计作为技能) [支持论证：技能被Fitts List形式化]
    └──⊣ KU-ONT-P-003 (问题-方案共同涌现) [批判限定：机在协同涌现中模仿人脑的能力受限]
```

### 4.2 第四板块的整合结构特征

第四板块的SLN呈现"中心辐合"结构：KU-MET-C-006（注意力转移）作为五个陷阱的共同解释机制，成为板块的认知枢纽。五个陷阱之间的平行结构（每个陷阱都不可约简为其他陷阱，但共享相同的认知机制）表明劳森的陷阱分类是完备且互斥的。

## L005 全书级SLN：跨板块宏观链接

### 5.1 全书四大板块间的关键桥接链接

```
[板块1 ↔ 板块2：从"过程是什么"到"问题是什么"]
KU-ONT-P-003 (问题-方案共同涌现)  ⇔  KU-ONT-P-006 (问题不可全面陈述)
    └── 协同效应：板1的经验发现(协方分析、实验)解释板2的理论主张(问题性质)

KU-MET-C-002 (分析通过综合)  ↝  KU-ONT-M-004 (约束空间格)
    └── 方法论含义：因为分析通过综合，所以需要一个静态约束地图作为
        动态探索的参照——约束模型正是这个地图

[板块2 ↔ 板块3：从"问题的结构"到"思维的匹配"]
KU-ONT-M-004 (约束空间格)  ⌣  KU-MET-C-004 (Form Generator)
    └── 选择哪种约束作为生成器——设计师的认知-价值-方法论的联结行动

KU-VAL-M-001 (设计哲学)  ⌣  KU-ONT-M-004 (约束空间格)
    └── 设计哲学引导注意力倾向于某些约束维度并忽视其他

[板块3 ↔ 板块4：从"如何思考"到"如何避免认知错误"]
KU-COG-P-003 (Einstellung效应)  ∼  KU-MET-M-006 (拼合陷阱)
    └── 同一认知机制（隐式规则限制）在实验室层次和实践层次的表现

KU-COG-P-001 (收敛/发散思维)  ↝  KU-MET-C-006 (注意力转移)
    └── 收敛/发散可以被概念化为注意力转移的两个维度：收敛固定注意，发散移动注意

[板块1 ↔ 板块4：全循环封闭]
KU-MET-E-001 (积木实验)  ⊢  KU-MET-C-001 (问题vs.解决方案聚焦)  →  KU-MET-M-005 (分类陷阱)
    └── 积木实验展示了解决方案聚焦策略——这一策略在分类陷阱中表现为
        过快的"类型锁定"而具有的风险性

[全书性的三个论证闭环]
1. KU-ONT-P-001 (技能) → KU-COG-M-002 (水库模型) → KU-COG-P-003 (Einstellung效应) → KU-ONT-P-001
   [闭环性：技能需要经验(水库)，经验引致僵化(Einstellung)，僵化挑战技能的适应性→需元认知]

2. KU-ONT-P-003 (共同涌现) → KU-ONT-M-004 (约束模型) → KU-MET-C-004 (Form Generator) → KU-ONT-P-003
   [闭环性：涌现性需要约束地图，约束地图有助于生成器选择，生成器再引导下一轮涌现]

3. KU-ONT-P-002 (规范性活动) → KU-VAL-P系列(价值→伦理→犯错的权利) → KU-SOC-P-001 (行动需求语境) → KU-ONT-P-002
   [闭环性：规范性引致伦理要求，伦理要求在行动需求压力下表达，行动需求压力又限制规范性的全面实现]
```

## L006 语义网络的结构模型

### 6.1 四层嵌套的"洋葱模型"

全书知识结构呈现四层嵌套结构：

```
[外环层：语境——设计的社会与技术条件] {SOC, TEC共6个节点}
    └── 围绕：时间压力、行动需求语境、团队动力、CAD角色
[中环层：方法——设计过程的组织与操作] {MET共17个节点}
    └── 围绕：策略选择、陷阱识别、启发式搜索
[内环层：认识——关于设计知识的性质] {EPI, VAL共9个节点}
    └── 围绕：知识的多学科性、价值负载性、伦理审查
[核心层：本体——关于设计是什么的根本命题] {ONT共11个节点}
    └── 围绕：技能性、规范性、协同涌现性、无终点性
```

外层对核心的反馈路径：外环层的技术变迁（CAD）和社会要求（行动需求压力）重塑中环层的方法——通过改变"注意力"的可能分布范围——进而影响核心层对设计本体的重新理解。

### 6.2 跨域桥接的"量子中继"模型

某些知识元的桥梁功能类似于量子通信中的中继站——不生成新信息，但使原本隔离的领域能够"通信"：

**中继站1**：KU-COG-P-003（Einstellung效应）——连接实验室心理学（认知科学）与设计实践（方法论）
**中继站2**：KU-VAL-M-001（设计哲学）——连接认知人格倾向（认知科学）与策略选择（方法论）
**中继站3**：KU-MET-C-006（注意力转移）——连接通用认知机制（认知科学）与具体设计错误（方法论）

这些中继站的知识元在源分析报告的逐章分析中通常作为一个普通概念出现，但在SLN层面，它们的结构性功能远超过其章内讨论的篇幅。

### 6.3 涌现的逻辑前奏——"隐藏的同构"

SLN分析揭示了不直接陈述在源报告中的结构同构关系：

1. **"水库-僵化-创造性"悖论三角形**：
   KU-COG-M-002 (水库：经验促进创造力) ⟂ KU-COG-P-003 (Einstellung：经验僵化思维) ∼ KU-COG-E-002 (初学者优势：无知促进创新)
   这三个知识元之间形成相互限制、无法同时优化的悖论结构——类比于"CAP定理"在计算机科学中的不可行三者兼得。

2. **设计的"不确定性层级"同构**：
   KU-ONT-P-006 (问题不可全面陈述)
   KU-VAL-P-001 (不存在最优解)
   KU-ONT-P-004 (不存在唯一正确的过程)
   KU-ONT-P-005 (过程无终点)
   这四个命题构成一个关于设计的不确定性层级：问题陈述的不确定性 → 解决方案的不可避免多样性 → 过程的不可避免多样性 → 过程终点的不可避免不确定性。
