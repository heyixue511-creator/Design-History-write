# Sources 阶段规则

## 执行
读取根 Claude.md 与同目录 AGENT.md。实际登记或验收时读取 [来源契约](references/source-contract.md)。
sources 对应 `01-基础文献/`，登记与新增 MD 均使用该目录，不另建 sources 数据目录。
以用户现行参考文献清单为主集合；识别版本、译本、卷册和重复记录，保留既有编号。
把现有原文 MD 映射至清单条目；标题相似只产生候选匹配，不能静默合并不同著作。
直接阅读文本起讫、目录、来源标记与疑似 OCR 缺损，辨认其语义影响；不运行程序批量推定来源身份或自动纠错。
登记检查不等于全文语义分析，未读内容明确保留未读状态。
源文件默认保全，不覆盖原文做清洗；如需清洗，另存 `02-文献解析/` 中对应文献的衍生文本并保留变更映射。
PDF 只登记用户提供或实际发现的路径与访问状态。当前仅有 MD 时不杜撰 PDF 页码或核验状态。
找不到权威清单不阻断规则建设；实际全库任务先保留候选登记，再就清单范围提出必要问题。

## 验收
每条已登记 MD 有唯一来源身份、内容版本、实际路径与匹配状态。
清单条目缺 MD、一个 MD 对应多条、译本不明等问题明确可见，未匹配文件不得丢失。
完成登记不代表已经完整阅读或核验原件。可用条目交 processing，不等待全部 PDF 上传。
