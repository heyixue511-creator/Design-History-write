# Sources 阶段

## 1. 目标
建立参考文献清单、原文 MD、版本及原件之间的可靠对应关系，使每份来源可追溯、可核验、可移交。

## 2. 数据位置
- 文献实体数据：`01-基础文献/`
- 来源登记：`01-基础文献/references.md`
- 原文 MD：沿用 `01-基础文献/` 下现有 books、papers 等目录
- 不另建根级 sources 数据目录

执行时同时遵守根 `Claude.md` 与同目录 `AGENT.md`。

## 3. 执行原则
- 以用户现行参考文献清单为主集合，优先保留既有编号。
- 识别版本、译本、卷册和重复记录；标题相似只作为候选匹配，不能静默合并不同著作。
- 把现有原文 MD 映射到对应清单条目，并检查文本起讫、目录、来源标记与明显 OCR 缺损。
- 来源核验不等于全文语义分析；未读内容必须保留未读状态。
- 不使用程序批量推定来源身份或自动纠错。
- 原始 MD 默认保全，不覆盖原文做清洗；如需清洗，衍生文本进入 `02-文献解析/` 并保留与原文的映射。
- PDF 只登记用户提供或实际确认的信息；当前只有 MD 时，不杜撰 PDF 路径、页码或核验状态。
- 找不到权威清单时，可暂存候选登记，但必须显式标明待对齐状态。
- 已有分析报告不能替代原著来源。

## 4. 来源登记字段

| 字段 | 要求 |
| --- | --- |
| ref_id | 稳定文献编号；优先沿用现行清单编号，不按处理批次重排 |
| bibliography_entry | 清单原条目；格式整理采用用户指定的 GB/T 7714—2015，不捏造缺失元数据 |
| bibliography_locator | 清单真实路径、版本及条目定位；未找到则 null 并标明待对齐 |
| work_id / edition_id | 可确认时标识著作与版本；同著作不同译本不自动当独立证据 |
| md_sources | 文件列表；每项记录仓库相对路径、SHA-256、完整性状态及与原著的对应说明 |
| pdf_status | local_unavailable / accessible / unknown；不可访问不代表不存在 |
| pdf_locator | 仅使用实际确认的定位；缺失为 null，不写示例路径 |
| match_status | confirmed / candidate / ambiguous / missing_md |
| issues | 缺损、版本、卷册、重复和待核的具体问题 |

补充规则：
- 原文拆成多个 MD 时，同一 `ref_id` 可关联多个路径，不冒充多篇独立文献。
- 登记文件或 MD 版本变化后，下游记录按来源版本复核。
- 登记所有清单条目，包括缺源条目。
- 清单之外的 MD 单列待对齐，不纳入已确认覆盖率。

## 5. 验收
- 每条已登记 MD 都有明确来源身份、内容版本、实际路径与匹配状态。
- 清单条目缺 MD、一个 MD 对应多条、译本不明等问题必须显式可见。
- 未匹配文件不得丢失。
- 完成来源登记不代表已经完整阅读或核验原件。
- 可用条目可直接移交 `processing`，不必等待全部 PDF 上传。
