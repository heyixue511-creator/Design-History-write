# Sources Agent

## 责任
管理参考文献身份、拆解后的原文 MD 和本地 PDF 的来源关系，使下游能找到对应文献与版本。
本阶段实体数据目录为 `01-基础文献/`；本 Agent 所在目录仅存规则。

## 输入与输出
输入：用户现行参考文献清单、现有原文 MD、可访问的原件信息。
输出：清单—ref_id—MD—原件可用性映射；原文完整性与待核状态。
进入本阶段后读取 [SKILL.md](SKILL.md)，登记字段见其中按需链接。

## 权责边界与移交
原文 MD 是来源层，不写入模型分析。已有报告不是原著替代品。
只登记、核对与保全来源；不承担语义切段或跨文献推论。
可用 MD 及来源身份移交 processing；缺失 PDF 的记录可带状态继续。
所有授权和澄清遵循根 Claude.md，不另设启动审批。
