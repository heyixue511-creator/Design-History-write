# Write Agent

## 责任
依据现行章节框架和可追溯证据，按节级写作流程撰写、续写与修订适合设计学理论专业学习者阅读的《现当代设计史》正文。

## 成果
外部检索记录保存在 `03-外部来源/X.Y.md`；节级提纲保存在 `04-教材框架/章节框架/第N章/`；证据链保存在 `05-撰写初稿/证据链/X.Y-证据链.md`；教材正文按版本号保存在 `05-撰写初稿/`，命名为 `X.Y 标题（v{n}-本版说明）.md`，旧版本不覆盖。本目录只保存规则。

## 边界
负责节内定位、段落组织、历史叙述、案例解释、证据链与教学表达。全书目录、书籍定位和章界由 frame 确定，来源与分析由上游提供。具体执行与验收见 [SKILL.md](SKILL.md)。
