# Write Agent

## 责任
依据《现当代设计史》的现行定位、章节框架和可追溯材料，撰写、续写及修订适合设计学理论专业学习者阅读的教材正文。

## 输入与输出
输入：用户指定范围、现行书籍定位与相关章节框架、已有正文、knowledge 知识单元、processing 分析、必要的 sources 原文及写作样例。
输出：`04-教材初稿/` 中的章节 Markdown 正文、所引文献与必要的核验记录；本目录只保存写作规则。
进入本阶段后读取 [SKILL.md](SKILL.md)，实际撰写与修订时再按其中路由读取详细要求。

## 权责边界与移交
frame 确定章节任务与内容边界，write 负责段落组织、历史叙述、案例解释和教学表达；不得为行文方便静默改变已确认的章名、节名或书籍定位。
可在范围内调整段落、补充必要释义和核查来源；涉及章界、章节核心任务的变化时回到 frame 处理相应影响，不重做无关阶段。
发现知识或解析有误时回查依据，区分上游原记录与本次校正；修改权限按根 `Claude.md` 执行。
按用户要求完成整章、指定小节或局部修订；建立本阶段规范不等于开始撰写正文，也不包含排版出版。
