# 正文与核验要求

本文件用于实际撰写或修订正文，不是逐项填空模板。全书字数遵循共享入口的30万字总量要求，不设章、节配额；节数与段落组织服从现行框架、材料和用户要求。

## 保存与版本

| 内容 | 位置与处理 |
| --- | --- |
| 章节正文 | 默认 `04-教材初稿/<chapter_id>.md`，如 `ch01.md`；已有明确映射的正文文件优先原位修订 |
| 节级写作 | 通常写入对应章节文件；长章需要分文件时沿用清晰的章、节映射，不重复保存同一正文 |
| 引用文献 | 放在章末，或沿用已有全书统一文献表；正文标记与实际条目一一对应 |
| 写作核验记录 | 默认章末单列，与教学正文分开；记录较长或需持续补证时才另建对应章节记录 |

沿用 frame 的 chapter_id，不因写作新编另一套章节编号。保留未涉及的已写内容，以 Git 管理修改，不堆积“最终版”“最终修订版”等副本。
章节正文至少可识别章名、当前写作范围与状态。续写时读取上次结尾及相邻段落，实际未写部分不能标为完成。

## 教学正文

- 章首交代理解本章所需的历史情境和问题，避免把框架工作说明搬入正文。
- 节内按历史材料形成递进、比较、转折或尺度变化；背景说明、概念释义和史料辨析各按实际需要安排。
- 案例从可核的对象、行动或事件进入，展开足以支撑解释的细节；作品名称和设计师名单不能代替分析。
- 将设计思想落实到形式、材料、结构、制作、传播或使用关系；只讨论有依据的环节，不为凑齐维度虚构细节。
- 概念讨论回应本章已经呈现的历史关系，说明概念的适用范围；不把后来的职业名称、价值尺度或理论术语无说明地投射到早期实践。
- 节末或章末归纳已经论证的认识及必要限制，避免重复全文；导论、专题和结语可采用适合自身任务的组织方式。

章首引言、总结、术语栏、思考题或图文栏目是否单列，取决于现行体例与用户要求，不以统一外观制造无必要模块。

## 来源与认识状态

关键断言能追溯到实际使用的来源位置：已有 unit_id、chunk_id 可沿用，否则记录文献路径及章节、页码或 MD 段落定位。MD 行号不得写成原书页码。
区分“解析线索”“转录文本已核读”“原件已核验”等已有状态；读取一份解析报告不能提高其上游证据等级。
正文使用有依据的叙述。只有解析线索且无法回查的重要事实，不写成已经证实的结论；必要时明确限定为某研究的解释，并在核验记录中说明依据层级。
转引指出直接读取的中间文献；存在多个版本、译本或不同年代信息时核对本次引用版本，不能混用其页码。
有依据的综合判断说明由哪些事实关系形成；有争议的因果、传播路线或影响关系保留替代解释与限制，不以含糊限定掩饰根本缺证。
文献表按实际使用的条目列出，沿用现行清单标识及引用方案；尚无统一方案时用可追溯的章内标记，不冒充全书最终编号。缺失书目信息明确待核，不造作者、题名、年份或出版信息。

## 图像与对象观察

需要图示时说明对象、观察重点和来源线索；未见图像时不编造颜色、结构或视觉细节。
图注中的作者、名称、年代、材料与出处按已核信息写入；未取得图像或未核定使用条件时保留用图说明，不标为图片已落实。
正文中依靠图片成立的关键观察，须有可访问图像或明确的可靠文字依据；不能依靠想象填充。

## 交付前复核

直接阅读完成的正文，核对其是否回答本章任务、是否清楚连接事实与解释、是否让学生理解概念与历史过程。
检查关键事实、引语、数字与来源是否匹配，是否误把宣言当作实施、个案当作普遍规律、先后关系当作因果。
检查当前章与相邻框架的边界，以及人物译名、概念、时代范围和重复案例的分工；局部修改只检查实际影响范围。
核验记录只保留实质信息：依据的框架、关键来源定位、尚待核查的具体问题及其影响、长任务的下一续写位置。已有记录足够时不另造审查报告。
