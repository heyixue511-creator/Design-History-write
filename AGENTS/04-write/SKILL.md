# Write 阶段

共同规则见根 [Claude.md](../../Claude.md)。

## 先确定任务与读取范围

- **新写、续写、重写或结构性修改：**读取 `03-教材框架/00_书籍定位.md`、`03-教材框架/全书目录.md` 中的相关内容，以及 `03-教材框架/章节框架/` 中目标章级框架、对应节级框架与直接关联的证据链、核读记录和待核事项。理解中心判断、案例责任、相邻边界与文件状态后再写；续写还须读取已有正文及衔接段落。
- **事实、引文或解释修改：**读取受影响段落、对应框架任务、相关核读记录及原文上下文，检查修改是否影响其他论断。
- **纯语言或引用格式修改：**读取当前正文及直接依赖；若触及事实、判断强度或章节任务，扩大到上述核验范围。不要因改一句措辞重启全库审计。

多份框架与证据文件按章级入口说明分工，不能只读标题、凭会话记忆写作，或把历史快照当作现行框架。第一章1.1的分工见 `03-教材框架/章节框架/ch01.md`。已核修正只适用于其实际覆盖的论断与版本，不能提高整份文件的证据等级。

## 框架、证据与参考写法

| 来源 | 用途 |
| --- | --- |
| `03-教材框架/章节框架/` | 确定本节写什么、案例承担什么任务、写到哪里 |
| `02-文献解析/` | 寻找、比较和挑战证据，发现反例与解释分歧 |
| `01-基础文献/` | 回查准备进入正文的重要事实、引语、数字、关系与学者判断 |
| 外部原始资料与可靠研究 | 按具体问题补证、纠错和跨语言核查；优先档案、博物馆、大学、研究机构、出版社与同行评议研究 |
| `00-参考原则/《现当代设计史》写作参考原则.md` | 按写作难点参考语言、案例解释和历史叙事方法；需要时回读 `00-参考原则/00-写作样例/` 的连续段落 |

要求全库寻找证据时，以每份文献的整体分析报告或等价报告为基础阅读单元，逐份完整阅读并记录“相关／弱相关／无关／反证／可替代证据”及具体理由，不要求先读完每个子文件。高相关项深入核读原文；其他材料一旦用于正文的重要判断，也须回查。复用范围、版本和判断仍适用的已有审计，只补查缺口与受影响条目。

框架规定内容责任，不规定固定段落顺序。可依材料调整叙事节奏、补充释义和修正判断强度；新证据若改变中心判断、章界或案例责任，转入 frame 同步有关框架，不在正文中静默改动。研究材料的多少和外部资料的易得程度不能自行改变章节分工。

## 正文组织

1. 让学生理解时间、地点、行动者与当前问题，再展开必要的历史解释。背景、比较、概念释义和转折各按材料需要安排，不将分析报告或证据表直接拼成正文。
2. 案例围绕本节任务展开，以可核细节说明形式、材料、制作、流通或使用怎样发生联系；只写有依据的环节，不把人物小传、作品名单或名词解释当作案例分析。
3. 保持现行“中国”“观念”等栏目分工；“观念”回应本章材料，避免另加脱离正文的理论。相同案例跨节使用时，按框架分配不同解释任务。
4. 用准确、连贯的学术中文表达，明确指代与判断归属，统一术语、译名和日期；样例只提供可选择的写法，不逐句仿写，也不将OCR错误或翻译腔当作风格。
5. 依赖图像的观察须有可访问图像或明确的可靠文字依据。图注只写已核信息；尚未取得图像时保留用图说明，不虚构视觉细节或声称图片已落实。

## 引用、保存与交付

- 直接引语核对字句、版本与定位，转引标明实际读取的中间文献。文献表按实际使用条目编列，采用 GB/T 7714—2015，与正文标记对应；暂无统一编号时沿用可追溯的章内标记。
- 已有有效正文原位修订。旧初稿已删除，取消自动写入 `04-教材初稿/` 的默认约定，不自动恢复旧稿。后续新写按用户指定位置保存；未指定且要求直接出示时在回复中交付，确需落盘时依当前任务确定并说明路径。
- 章、节身份沿用现行框架；核验说明与教学正文分开，简要记录关键来源、实质缺口和续写位置，已有记录足够时不另造报告。
- 交付前通读正文，核对框架任务、关键事实与出处、案例解释、概念归属及段落衔接；局部修改检查实际影响范围。证据不足时补查、收缩判断或换用有据材料，仍影响核心解释的缺口须明确说明。
- 用户要求整章或整节时交付相应正文，不能以计划、证据清单或示范段落替代；只要求规范或证据框架时不开始正文写作。
