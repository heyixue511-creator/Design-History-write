# Write 阶段

共同规则见根 [Claude.md](../../Claude.md)。

## 先确定任务与读取范围

- **新写、续写、重写或结构性修改：**先读取书籍定位、全书目录和对应章节框架，明确本次问题与范围；随后按下述流程，首先由 perplexity.ai 检索外部原始资料与可靠研究，形成具体写作内容的研究线索，再结合仓库资料核验和组织正文。续写还须读取已有正文及衔接段落；已有检索记录仍适用时复用，并对新增内容和缺口继续检索。
- **事实、引文或解释修改：**读取受影响段落、对应框架任务、相关核读记录及原文上下文，检查修改是否影响其他论断。
- **纯语言或引用格式修改：**读取当前正文及直接依赖；若触及事实、判断强度或章节任务，扩大到上述核验范围。不要因改一句措辞重启全库审计。

多份框架与证据文件按章级入口说明分工，不能只读标题、凭会话记忆写作，或把历史快照当作现行框架。第一章1.1的分工见 `03-教材框架/章节框架/ch01.md`。已核修正只适用于其实际覆盖的论断与版本，不能提高整份文件的证据等级。

## 章节内容研究：先由 perplexity.ai 检索

1. **确定检索任务。** 按本次章、节的问题及历史范围，列出需要解释的变化、人物、作品、机构、技术、材料与争议。`03-教材框架/全书目录.md` 只提供章、节标题与排列，不含内容方向或证据；具体任务读取 `03-教材框架/章节框架/` 中现行文件。框架尚不充分时，围绕目录主题提出研究问题，不凭标题假定已有完整写作方案。
2. **通过 perplexity.ai 搜索具体写作内容。** 优先寻找外部原始资料与可靠研究，按对象使用中文、英文及必要的其他语言。围绕史实、历史条件、代表案例、案例细节、不同解释与反证展开，要求返回可追溯的原始来源链接。优先档案、历史文献、博物馆藏品记录、大学、研究机构、出版社及同行评议研究；不止取得一份概括性回答。
3. **记录来源并核读。** 随检索保存下表信息，打开实际来源核查其内容与上下文。Perplexity 的综合回答和推荐链接属于检索线索，不直接视作已证事实；未打开的来源明确标为未核读。需要引用时回到实际读取的原始页面或文献。
4. **结合仓库资料核验与补充。** 带着外部检索形成的问题、案例和判断，查阅 `02-文献解析/` 中有关报告，并回到 `01-基础文献/` 核读对应原文。比较支持、分歧、反例及版本差异，补足来源定位，不以本地资料数量决定章节篇幅。
5. **形成可写内容后进入正文。** 将有据的内容、案例责任、来源及待核问题纳入现有章节研究记录；若改变中心判断或章界，先同步有关框架，再组织正文。具体段落和叙事节奏由材料决定。

### 检索与来源记录

在对应章节已有的证据链或研究记录中保存；尚无合适记录时，在 `03-教材框架/章节框架/` 下建立必要的章节研究记录，不另建规则层。

| 记录内容 | 要求 |
| --- | --- |
| 章节问题与检索过程 | 章、节范围，交给 perplexity.ai 的问题、检索日期；有可分享的检索结果链接时一并保留 |
| 来源身份 | 题名、作者或机构、出版或发布日期；缺失信息标明待核 |
| 原始来源链接 | 保存实际网页、文献或藏品记录的URL；有DOI或稳定链接时优先保留，不只记录Perplexity结果页 |
| 支持内容与定位 | 说明该来源支持哪个事实、案例细节或判断；附章节、明确页码、页面小标题或必要短引文 |
| 核读状态与问题 | 区分检索线索、已核读网页、已核读全文和待补原件；注明访问日期、访问限制、争议或缺口 |

一条判断使用多个来源时分别保留链接；同源转载不算独立互证。无法访问的来源不补造内容或定位。

此步骤指定使用 perplexity.ai。当前环境无法调用或访问时，说明该步骤尚未完成及具体限制，可使用用户提供的Perplexity检索记录继续核读；不得把其他工具的搜索或模型自行回答标为Perplexity检索结果。

## 各类材料的作用

| 来源 | 用途 |
| --- | --- |
| `03-教材框架/00_书籍定位.md`、`03-教材框架/全书目录.md` | 明确教材定位和目录位置，不代替具体章节内容研究 |
| `03-教材框架/章节框架/` | 确定本节写什么、案例承担什么任务、写到哪里 |
| perplexity.ai检索所得外部原始资料与可靠研究 | 作为具体章节内容研究的首个检索步骤，发现内容、案例、证据与争议，逐项记录原始来源链接 |
| `02-文献解析/` | 对照检索所得内容，寻找、比较和挑战证据，发现反例与解释分歧 |
| `01-基础文献/` | 回查准备进入正文的重要事实、引语、数字、关系与学者判断 |
| `00-参考原则/《现当代设计史》写作参考原则.md` | 按写作难点参考语言、案例解释和历史叙事方法；需要时回读 `00-参考原则/00-写作样例/` 的连续段落 |

要求全库寻找证据时，以每份文献的整体分析报告或等价报告为基础阅读单元，逐份完整阅读并记录“相关／弱相关／无关／反证／可替代证据”及具体理由，不要求先读完每个子文件。高相关项深入核读原文；其他材料一旦用于正文的重要判断，也须回查。复用范围、版本和判断仍适用的已有审计，只补查缺口与受影响条目。

框架规定内容责任，不规定固定段落顺序。可依材料调整叙事节奏、补充释义和修正判断强度；新证据若改变中心判断、章界或案例责任，转入 frame 同步有关框架，不在正文中静默改动。研究材料的多少和外部资料的易得程度不能自行改变章节分工。

## 正文组织

1. 让学生理解时间、地点、行动者与当前问题，再展开必要的历史解释。背景、比较、概念释义和转折各按材料需要安排，不将分析报告或证据表直接拼成正文。
2. 案例围绕本节任务展开，以可核细节说明形式、材料、制作、流通或使用怎样发生联系；只写有依据的环节，不把人物小传、作品名单或名词解释当作案例分析。
3. 保持现行“中国”“观念”等栏目分工；“观念”回应本章材料，避免另加脱离正文的理论。相同案例跨节使用时，按框架分配不同解释任务。
4. 用准确、连贯的学术中文表达，明确指代与判断归属，统一术语、译名和日期；样例只提供可选择的写法，不逐句仿写，也不将OCR错误或翻译腔当作风格。
5. 依赖图像的观察须有可访问图像或明确的可靠文字依据。图注只写已核信息；尚未取得图像时保留用图说明，不虚构视觉细节或声称图片已落实。

## 引用、保存与交付

- 直接引语核对字句、版本与定位，转引标明实际读取的中间文献。文献表按实际使用条目编列，采用 GB/T 7714—2015，与正文标记对应；暂无统一编号时沿用可追溯的章内标记。
- 已有有效正文原位修订。旧初稿已删除，取消自动写入 `04-教材初稿/` 的默认约定，不自动恢复旧稿。后续新写按用户指定位置保存；未指定且要求直接出示时在回复中交付，确需落盘时依当前任务确定并说明路径。
- 章、节身份沿用现行框架；核验说明与教学正文分开，保留Perplexity检索记录、原始来源链接、实质缺口和续写位置，已有记录足够时不另造报告。
- 交付前通读正文，核对框架任务、关键事实与出处、案例解释、概念归属及段落衔接；局部修改检查实际影响范围。证据不足时补查、收缩判断或换用有据材料，仍影响核心解释的缺口须明确说明。
- 用户要求整章或整节时交付相应正文，不能以计划、证据清单或示范段落替代；只要求规范或证据框架时不开始正文写作。
