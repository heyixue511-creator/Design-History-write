# Write 阶段规则

## 进入与读取

遵循根 `Claude.md` 和同目录 `AGENT.md`；先确定本次章、节或修订范围，读取已有正文，避免重复生成。

实际写作时先读取 [正文与核验要求](references/write-contract.md)，再读取 `03-教材框架/00_书籍定位.md`、`03-教材框架/00_全书目录与内容方向表.md`，以及本次具体章节在 `03-教材框架/章节框架/` 中的全部现行相关文件。

### 各章共用写作规范

所有章、节共用本 Skill，不要求为每章或每节新建独立 Skill，也不把独立 Skill 是否存在作为研究、续写或交付的前置条件。
章节差异、材料边界、案例责任和证据要求保存在 `03-教材框架/章节框架/` 的对应文件中，不为满足流程复制一套章节规则。
已存在的1.1专项 Skill 仅用于其原定范围，不推广为逐章建 Skill 的要求。仅在用户明确要求新增专项 Skill 时创建。

### 具体章节框架是强制前置来源

凡进入某一章、某一节或某一专题的证据准备、内容组织、正文撰写、续写或重写，**必须先详细遵守并读取 `03-教材框架/章节框架/` 中与该范围对应的现行文件**。不得只读总目录、章名或节名，也不得凭已有记忆直接写作。

读取至少包括：

- 对应章级框架，例如 `ch01.md`；
- 对应节级、专题级、证据链级文件，例如 `ch01_1.1_*.md`；
- 与当前小节直接关联的证据链、全库文档清单、原文核读记录、A级证据核验或其他现行研究文件；
- 文件中标注的版本状态、优先级、中心判断、历史范围、内容单元、案例责任、相邻小节边界、证据状态、待核问题以及明确保留给后文的内容。

若同一章节同时存在旧版回填、形成史、现行框架与证据深化文件，应根据文件中的状态说明与相互引用确定优先级。旧版只能用于理解形成过程，不能与现行框架并列决定正文。

框架读取不是摘录标题。必须先理解它已经建立的历史判断和内容分工，再进入证据与写作。框架明确规定“本节回答什么”“某案例在本节证明什么”“哪些内容留给相邻小节”的，正文必须遵守。若新增材料确实改变这些判断，应先返回 `AGENTS/03-frame/` 形成有证据的调整理由，不得在 write 阶段静默改变框架。

### 全书字数只设总量，不设分章配额

本项目只规定一项字数要求：**全书文字总量为30万字**。

不设分章字数配额，也不预先分配节级篇幅。任何章、节的长度由其历史任务、证据密度、案例责任和与相邻部分的分工决定，由写作时按实际材料判断。

各章篇幅可以不同，不平均分配，也不将旧配额按比例放大到30万字。旧稿、旧对话及历史文件中的20万字配额表和章、节定额均不再作为写作或验收依据。总量通过全书统筹取舍实现，不为凑数重复材料或扩写缺乏证据的内容。

### 具体章节的来源优先级

写作来源按以下关系执行：

1. **`03-教材框架/章节框架/`：决定写什么、写到哪里。**  
   它确定章节问题、历史边界、内容单元、案例责任、证据缺口和相邻小节分工，是具体正文的直接结构来源。

2. **`02-文献解析/`：寻找、比较和挑战证据。**  
   根据03框架提出的问题查找相关分析报告、反证、替代案例和史学分歧。解析报告负责研究导航，不得越过03框架自行决定章节内容，也不能代替原文。

3. **`01-基础文献/`：核实准备进入正文的本地证据。**  
   对重要事实、引文、页码、数字、因果、人物关系和学者判断回到可访问原文核读。

4. **联网与跨语言外部资料：补充、纠错和检验。**  
   工作区只是研究起点。按具体章节问题继续查一手档案、博物馆、大学、研究机构、出版社、同行评议研究及必要语言资料，并明确证据限制。

5. **`00-参考原则/00-写作样例/`：只提供语言、内容组织与叙事参考。**  
   样例不能决定史实、人物地位、案例篇幅、章节边界或历史因果。

不得颠倒以上关系：不能因为02中某材料很多就扩大正文篇幅；不能因为01中某人物资料丰富就改变03已确定的历史责任；不能因为外部资料易得就挤压章节核心；也不能为了模仿写作样例而重排已经确认的历史结构。

需要判断语言、内容安排、段落推进或历史叙事方式时，可进一步读取 [`sample-guided-writing/SKILL.md`](sample-guided-writing/SKILL.md)，将其作为柔性写作参考，并按当前章节实际需要读取 `00-参考原则/00-写作样例/` 的相关连续段落。样例用于理解叙事和论证方法，不能直接作为设计史事实的依据；待校文本不能作为已核原文引用。

## 框架与正文的关系

`03-教材框架/章节框架/` 是具体章节正文的**直接上游来源**。正文不是重新发明章节结构，而是把已经研究确认的框架、证据责任和历史关系转化为可阅读的教材叙述。

保持现行章节任务、历史范围、栏目安排和全书总量控制；草案按实际状态使用，不能自行标为已确认。

框架中的内容单元、证据链和案例责任用于规定“必须解释什么”和“不得越界到哪里”，**不等于固定段落模板**。实际段落顺序、展开方式和叙事节奏仍由材料本身决定，只要没有改变框架已经确认的历史责任。

将节级任务转化为可阅读叙述，不把框架表格、证据链、主谓宾记录、解析报告或文献摘要直接拼成正文。

同一案例在多节出现时，严格按照03框架为它分配的不同证据面和论证责任使用，避免重复介绍；需要跨期材料时说明其是前史、比较还是后续影响。

写作过程中发现新证据时，先判断它是：
- 补强现有内容单元；
- 修正某一判断的强度；
- 构成反例或替代解释；
- 实际属于相邻小节或其他章节；
- 足以改变当前框架。

前四类按现行框架处理；最后一类返回frame阶段，不在正文中自行改章界。

## 高精度阅读与写作
由模型直接阅读相关原文及必要上下文，判断事实、作者观点、转引、反驳和解释的层次，再组织正文。
禁止程序改写、固定模板填充、关键词拼接或批量模型调用代替阅读、论证与写作；文件保存和版本管理遵循共同规则。
沿用框架和来源的核验状态。解析报告可定位问题，不能把其中的引文、页码、数字和历史因果未经回查就当作原文已证。
拟作为确定事实使用的关键断言应有可核依据；直接引语核对可访问文本的字句与定位，转引明确注明，不声称读过不可访问的 PDF。
局部依据不足时先核查，必要时缩小判断、换用有据案例或保留待补位置，继续完成其他部分；影响章节核心解释的缺口须在交付中明确。

## 教材叙述与案例解释
面向学生建立时间、地点、行动者和问题的基本关系；新概念在承担解释任务前给出必要释义。
围绕具体历史变化组织背景、对象观察、行动过程和解释。社会生产、技术材料、制度市场、生活方式、公众认知与设计观念按材料实际关联展开，不固定为每段必备清单。
案例须说明为何出现在此处、哪些可观察细节支持判断、它能代表到什么范围；用具体对象连接设计观念与制作、流通或使用实践。
区分条件、动机、实施与结果；不从时间先后、形式相似或共同出现直接推导因果和影响。
保持中国视角的全球设计史定位，依据真实联系和差异比较地区经验；“中国”“观念”等栏目按当前章节安排展开，不强制所有章节采用同一模式。

## 语言与论证
用准确、连贯的学术中文解释历史，保留教材可读性；优先明确谁在何种条件下做了什么、发生了什么变化。
让段落承担清楚的叙述或解释任务，通过事实关系完成承接、比较和转折，避免概念堆叠、空泛拔高和每段重复总结。
区分史实、历史行动者的主张、后世研究者解释与教材作者综合判断；有争议时交代分歧所依据的材料或尺度。
借鉴样例的组织与阐述方法，不移植其时代判断、逐句仿写或将局部写法规定为全书公式。
术语、译名和日期保持一致；参考文献沿用项目要求的 GB/T 7714—2015，正文标注与所列条目对应，未核页码不补造。

## 完成判定
交付用户要求范围内的实际正文；写作计划、案例清单、证据表或示范段落不能替代整章写作请求。
按正文逐项检查框架任务、关键事实与出处、案例解释、概念归属、时间范围和段落衔接，不以篇幅或格式检查代替内容复核。
把工作说明、待核问题和来源追踪放入文末写作记录或必要的独立记录，正文保持教学阅读的连贯性。
说明实际完成范围及影响使用的缺口；未核材料仍保持其状态，正文初稿不等于出版定稿。
仅要求建立写作规范时，只建立规则和用户指定的成果目录，不自动生成章节正文。
