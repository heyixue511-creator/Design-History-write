# 写作样例驱动规则

## 适用范围

当任务涉及《现当代设计史》正文的撰写、续写、重写、段落重组、语言润色、叙事调整或“按参考体例写作”时启用本 Skill。

本 Skill 只规范：
- 写作语言；
- 内容进入正文的先后与层级；
- 段落内部论证；
- 段落之间的衔接；
- 案例进入叙事的方式；
- 历史叙事的推进；
- 事实材料向“观念”解释的提升。

本 Skill 不负责：
- 确定全书或章节框架；
- 代替史料核验；
- 从写作样例提取设计史事实；
- 为追求文风而改动已确认的历史边界或章节任务。

必须同时遵循上级 `AGENTS/04-write/SKILL.md`。

## 样例读取顺序

写作前先确认本次允许参考的样例。当前核心样例为：

- `00-参考原则/00-写作样例/艺术与观念_上册_连续正文.md`
- `00-参考原则/00-写作样例/艺术与观念_下册_逐页全文_待校稿.md`

涉及《艺术与观念》写法时，再读取：
- [《艺术与观念》写作机制](references/arts-and-ideas-principles.md)

样例只用于分析写作机制。上册连续正文为OCR整理稿，下册明确为待校稿；其中错字、断句和识别异常不得被学习为语言特征。

不得仅凭目录、译者序或单个章节概括整部样例的写作风格。实际写作前，应按本次正文任务至少读取：
1. 一个同类历史阶段的正文开头；
2. 一个案例展开段；
3. 一个“观念”或总结性段落；
4. 必要时一个跨章节过渡段。

## 总体写作发动机

正文优先采用“历史问题驱动”的解释性叙事，而不是知识点罗列。

基本推进关系为：

历史条件变化
→ 原有生产、生活、审美或设计方式出现问题
→ 新的技术、材料、制度、市场或文化需求形成
→ 设计行动者作出回应
→ 人物、机构、作品或事件成为具体实践
→ 分析可观察的形式、材料、生产、传播或使用方式
→ 多个事实之间形成共同趋势
→ 提炼设计观念或时代认识
→ 指出尚未解决的矛盾
→ 为下一变化建立历史条件。

这一链条是论述逻辑，不是固定段落模板。不得机械要求每段包含全部环节。

## 语言规则

### 1. 关系优先于术语

学理性首先来自因果、条件、比较、转折和限定关系，而不是抽象术语密度。

优先写清：
- 什么发生了变化；
- 为什么发生；
- 谁在什么条件下作出回应；
- 变化如何进入设计实践；
- 这一变化能够说明什么。

谨慎使用“机制、范式、维度、逻辑、本质、赋能、重构”等高抽象词。只有在前文已经提供事实关系时才可使用。

### 2. 句子承担推进任务

避免连续孤立判断：
“工业化发展。城市扩大。材料改变。设计发生变化。”

应建立可追踪关系：
“随着……，……开始……；这一变化又使……，从而……。”

常用衔接应来自真实语义关系，而非形式连接词堆叠：
- 条件：随着、在……条件下、由于；
- 转折：然而、但是、与此不同；
- 延续：与此同时、在这一过程中、这一变化进一步；
- 结果：因此、从而、其结果是；
- 回指：这种变化、这一现象、上述做法、这一新的关系；
- 限定：并不意味着、不能由此推断、在……范围内。

### 3. 旧信息带出新信息

段落和句子尽量形成：
A → A+B → B+C → C+D。

上一句已经建立的对象、问题或判断，应成为下一句继续推进的支点。避免无提示跳入新人物、新作品或新概念。

### 4. 抽象判断晚于事实

除非需要开篇定位，不要先给一个宏大结论再用材料填充。

优先：
具体历史条件
→ 可观察变化
→ 案例
→ 比较
→ 解释
→ 概念归纳。

“观念”应从前文事实中生长出来，不作为预设标签反向筛选材料。

### 5. 保持教材可读性

学术中文应准确、平实、连贯。允许适量形象性表达，但比喻必须承担解释任务，不为文采本身服务。

避免：
- AI式对称排比；
- 每段“这不仅……也……”；
- 频繁“三重、四重、维度、路径”等概括；
- 空泛价值判断；
- 无依据的“标志着”“彻底改变”“必然导致”；
- 过度短句造成讲义化；
- 过度长句造成论文翻译腔。

## 内容安排规则

### 1. 从问题进入，不从名词进入

节或段落应尽量先建立历史处境和需要解释的问题，再引入人物、风格、机构和作品。

不优先写：
“某某主义是……，代表人物有……”

优先写：
“当……发生变化后，原有的……开始无法……。在这一背景下，……成为设计者需要处理的新问题。”

### 2. 背景必须与设计对象建立作用关系

社会、政治、经济、技术背景不能成为独立“背景知识块”。

每写一项背景，应回答：
“它通过什么环节进入了设计？”

例如：
生产制度 → 制造方式 → 设计职能；
城市生活 → 消费场景 → 商品与视觉传播；
材料技术 → 加工可能 → 结构和形式；
制度市场 → 委托/销售/使用关系 → 设计实践。

如果无法建立作用关系，应删减或移出正文。

### 3. 人物是行动者，不是传记条目

人物进入正文时优先说明：
- 他面对什么问题；
- 采取了什么具体行动；
- 与此前做法有何不同；
- 哪些作品或实践能够证明；
- 他的作用能代表到什么范围。

不写与当前论点无关的完整生平。

### 4. 案例是证据，不是插图说明

每个重要案例至少承担一项明确论证任务：
- 显示生产方式变化；
- 显示技术与形式关系；
- 显示设计职能变化；
- 显示生活方式变化；
- 显示市场/传播变化；
- 显示设计观念变化；
- 显示矛盾或反例。

案例段应形成：
为什么在此出现
→ 对象是什么
→ 可观察细节是什么
→ 这些细节支持什么判断
→ 其代表性边界是什么。

### 5. 从对象尺度返回历史尺度

不能连续多段停留在作品介绍。

完成作品、人物或机构分析后，应回升到：
- 这一案例改变了什么关系；
- 它与同阶段其他现象有何共同性；
- 它说明了怎样的历史转向。

形成“宏观 → 中观 → 微观 → 中观/宏观”的往返。

## 段落规则

一个成熟段落通常承担一个主任务，而不是一个名词。

推荐结构：

段首：提出本段需要解释的历史变化或判断；
中部：提供事实、案例、比较或过程；
后部：解释这些材料之间的关系；
段尾：自然带出下一问题，必要时做有限归纳。

段末不要求每次总结。只有需要完成概念提升、历史转向或过渡时才归纳。

禁止：
- 一段一个人名；
- 一段一件作品但没有解释；
- 一段堆多个事实却没有主判断；
- 段尾重复段首同一句话；
- 每段都以“因此/由此可见”强行收束。

## 叙事规则

### 1. 年代是骨架，问题和矛盾才是动力

不能只写“A之后出现B”。

优先解释：
“A内部出现了什么问题，使B成为一种回应？”

历史推进通常由以下关系驱动：
- 旧制度与新生产条件；
- 手工与机器；
- 技术能力与审美规范；
- 生产标准化与个体差异；
- 市场扩张与质量控制；
- 功能与装饰；
- 专业设计与制造分工；
- 大众消费与文化区隔；
- 国际传播与地方经验。

具体使用哪一组，由材料决定，不预设。

### 2. 用“矛盾未解决”连接下一阶段

一个历史阶段的结尾应尽量说明：
- 已经解决了什么；
- 又制造了什么新问题；
- 哪一矛盾被留下；
- 下一阶段为什么会围绕它展开。

不得仅用“进入20世纪以后”“随后出现……”完成历史过渡。

### 3. 建立跨章节回扣

对全书重要的概念应反复回到此前已经建立的含义，再说明新阶段如何重新定义它。

优先维护：
机器/手工、生产/形式、功能/装饰、技术/生活、设计/制造、标准化/个性、市场/社会责任、大众传播/视觉秩序等贯穿性问题。

每次回扣应产生新解释，不重复定义。

## “观念”写作规则

“观念”不是正文之外另加的理论短文，而是对前文材料的二次组织。

写作步骤：
1. 回收前文已经出现的社会、技术、制度、作品和行动者证据；
2. 找到这些证据共同改变的关系；
3. 区分行动者当时明确表达的思想与教材作者后设概括；
4. 提炼有限、可证的设计观念；
5. 说明这一观念如何体现在具体实践；
6. 指出其内在限制或后续矛盾。

不得先确定一个“观念”标签，再强迫所有材料证明它。

## 中国栏目与比较叙事

涉及中国时，不把中国材料处理为西方主线后的附录，也不为追求形式一致强行寻找“一一对应”。

应明确：
- 时间是否同步；
- 生产条件是否相同；
- 概念是否同义；
- 是否存在直接传播或接触；
- 比较是同源、并行、差异还是后来的重新解释。

样例中的西方艺术史发展逻辑不得直接套用于中国设计史。

## 禁止机械模仿

严禁：
- 逐句仿写样例；
- 替换样例中的人物与作品名称形成“同句式文本”；
- 固定套用“社会→艺术→观念”标题结构；
- 因样例频繁使用某种转折词而机械提高其频率；
- 模仿OCR错误、翻译腔或过时表述；
- 把样例作者的历史判断直接移植到设计史；
- 用程序统计词频后机械生成所谓“同风格文本”。

学习对象是结构关系和论述方法，不是表层句式。

## 写作前检查

实际落笔前必须回答：
1. 本节真正解释的历史问题是什么？
2. 前一节已经建立了什么，当前节从哪里接续？
3. 哪些背景与设计实践有直接作用关系？
4. 哪些案例是核心证据，分别证明什么？
5. 哪些概念是材料中出现的，哪些是教材作者的概括？
6. 本节内部最主要的变化或矛盾是什么？
7. 本节最终需要把读者带到哪里？

无法回答的问题优先通过阅读框架与证据解决，不以空泛文字填补。

## 写作后复核

完成后逐段检查：
- 是否存在知识点清单化；
- 是否有背景与设计无关；
- 是否有人物传记化；
- 是否有案例只介绍不解释；
- 是否存在从时间先后直接推出因果；
- 是否出现抽象概念先行、材料随后硬配；
- 段落之间是否出现主题跳跃；
- 是否能看出历史变化如何一步步发生；
- “观念”是否真正回收了正文材料；
- 结尾是否留下了下一历史阶段的问题；
- 是否出现样例句式的机械仿写痕迹。

如存在上述问题，先重组论证关系，再润色语言。
