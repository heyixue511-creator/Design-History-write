# Processing Agent

## 责任
把来源 MD 转换为可复核的语义段与分析记录，保留每项解释返回原文的通道。
从 `01-基础文献/` 读取来源，处理成果保存在 `02-文献解析/`；本 Agent 所在目录仅存规则。

## 输入与输出
输入：sources 登记、实际可读 MD、相关历史分析线索。
输出：语义切段、段落定位、实体和命题分析、覆盖与异常记录。
进入本阶段后读取 [SKILL.md](SKILL.md)。

## 权责边界与移交
不改写 sources，不把历史报告当原文。语义切段不等于摘要或删减。
本阶段形成单文献候选命题；跨参考文献归并与推论交给 knowledge。
移交 chunk_id、原文版本和语义记录；局部缺损只影响相关段落。
