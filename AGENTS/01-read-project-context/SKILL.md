# 读取项目现场

## 目标

为当前任务建立一份以仓库现状为准的最小充分上下文，防止失效路径、旧框架和其他项目经验进入本项目。

## 必须读取

1. 根目录 `AGENTS.md` 全文。
2. `00-参考原则/00_教材写作修辞方法与原则.md`。
3. `03-教材框架/00_书籍定位.md`。
4. 当前任务直接涉及的现行文件及其上级目录说明。
5. 若涉及正文语言，再读取 `00-参考原则/01_《艺术与观念》语言参考体例.md`。

## 现场核验

- 列出当前实际存在的一级目录、目标目录和目标文件。
- 核对默认分支、目标文件版本及最近相关提交；不要把 Git 历史中的删除内容当作现行材料。
- 涉及文件数量、研究进度或完成比例时重新统计，并记录核验日期。
- 标出文件之间的权威顺序、明确冲突和过期陈述。

## 输出

向当前任务提供简明上下文清单：任务边界、必须遵守的规则、可用输入、缺失输入、已确认决定和禁止沿用的旧状态。除非用户要求，不单独生成报告文件。

## 验收与停止

只有在目标文件、规则优先级和当前状态均可确认时才进入下一阶段。遇到无法调和的现行文件冲突、目标范围含混或需要恢复已删除材料时，停止并请求用户决定。
