# 构建全书框架

## 前置门槛

必须具备现行书籍定位、资料库审计、设计史学比较和分期研究。任一输入缺失时，不直接创建章节目录。

## 构建次序

1. 提出能够贯穿全书的真实历史问题，并说明它与书籍定位的关系。
2. 建立全书核心命题和论证主干，明确设计对象、行动者、制度与历史结果如何相互解释。
3. 根据已验证的历史转变确定章界，不预设“编”、章数、平均篇幅或统一节数。
4. 为每章规定独立问题、时期范围、核心判断、关键关系、主要对象类型、地区联系、证据边界及前后章接口。
5. 检查中国材料是否在关系链中改变解释，非欧美材料是否承担论证而非增加数量。
6. 建立跨章线索表，检查概念、人物、制度、媒介和对象再次出现时是否承担新的历史任务。
7. 使用重要反例和无法归类的材料压力测试框架，必要时返回分期阶段。

## 评价标准

框架必须同时满足：总体史而非百科清单；编年与问题相结合；地区间联系可追踪；设计的创造性与权力、劳动、殖民、战争、不平等和环境后果并置；教学顺序可理解；每章对全书命题有不可替代的贡献。

## 输出

先提交结构提案及其证据说明，清楚标记已确认、暂定和待补证内容。重大结构经用户确认后，才将单一现行版本写入 `03-教材框架/01_全书框架.md`；不建立历史方案副本或 `V1/V2` 文件。

## 停止条件

若章界依赖单一原因、地区材料只是并列、关键时期缺少对象与文献、章节之间重复承担同一问题，或用户尚未确认重大取舍，停止定稿并返回相应上游阶段。
