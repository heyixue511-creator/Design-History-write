# Processing 阶段

共同规则见根 [Claude.md](../../Claude.md)。

## 读取与复用

核对来源登记、可读原文及该文献已有分析。成果沿用 `02-文献解析/book-reports/`、`paper-reports/` 中对应目录；已有整体分析、章节分析和专题报告足以承载本次任务时，原位补充，不重建同文献的平行成果。

区分完整分析与定向核读：完整分析按原文结构连续阅读；局部任务只处理相关内容及必要上下文，并说明实际范围。单纯读取既有报告寻找证据，不等于重新完成原著分析。

## 分析方法

1. 先理解文献主旨、章节分工和作者立场，再分析具体论题、关键论点、材料使用及论证转折。
2. 需要细分时，依对象、事件、概念或论证变化划分语义段，保持引文与归属、条件与结论、脚注与正文的联系。无需为每份文献另存一套切段文件。
3. 辨认人物、机构、概念、事件、作品与地点，并说明它们在论证中的作用；同名、别名或译名的归并须有语境依据。
4. 提炼候选命题时，说明谁对什么作出何种判断，区分作者陈述、引用、反驳和假设；复杂命题可以拆分，但保留相互依赖。
5. 对已有报告补核或纠错时回查原文，保留原判断与修正依据的区别；失效定位查找现行来源，不以重写摘要掩盖问题。

## 最少记录

每份分析保留文献身份、实际使用的原文路径与版本、阅读范围、核心分析及待核问题。重要命题提供章节、明确页标或MD行段定位，使读者能返回原文。

已有编号与索引可继续使用，但不强制新建 chunk_id、analysis_id、哈希表或 chunks.md、semantics.md、coverage.md。版本可用版次、文件版本或提交标识说明；原文变化时复核受影响定位。

长任务在原报告或现有进度记录中注明已读范围、未读范围、缺损和下一阅读位置，不复制全文作为进度证明。

## 验收

回读本次形成的重要命题及其原文，检查论证层次、判断归属和解释范围。成果应让后续工作能够找到证据、分辨疑点并继续阅读；交付分析报告或其必要增补，说明实际完成范围，再将有据候选交 knowledge 比较。
