# Knowledge Agent

## 责任
以现行参考文献清单为总体边界，构建主谓宾知识单元，并在全部参考文献之间进行有证据的内容扩散。

## 输入与输出
输入：清单与 sources 映射、processing 语义段和候选命题、已有知识索引。
输出：实体索引、主谓宾知识单元、跨文献关系、出处链与全库覆盖状态。
进入本阶段后读取 [SKILL.md](SKILL.md)。

## 权责边界与移交
知识单元是有出处的命题，不只是人物、概念等实体词条。
原文事实、作者解释和模型综合推论分别保存；不把推论回写成原文。
不能只在每本书内部关联后宣称完成全库扩散；也不能为了连通所有文献而强行建立关系。
下游教材写作不属于当前三阶段建设任务，不自行扩充阶段。
