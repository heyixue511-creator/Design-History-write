# 审计资料库

## 输入

先完成项目现场读取。主要检查 `01-基础文献`、`02-文献解析`及当前实际存在的补充材料；不存在的旧证据管线或写作包不得恢复为现行输入。

## 工作方法

1. 现场统计目录、文件、格式、语言、重复版本和明显缺损，数量标注核验日期。
2. 按材料身份区分原著、同期文献、对象或馆藏记录、机构与企业档案、政策标准、口述与使用记录、后世研究、内部分析报告。
3. 以书名、作者、时期、地区、对象门类和主题建立材料地图；文件名只用于初筛，重要归类须查看正文或可靠元数据。
4. 对重复书目、不同版本、OCR 缺损、页码缺失、译本与转引情况作状态标记，不静默合并。
5. 通过抽样回查基础文献，评估分析报告的准确度、覆盖方式和可用于定位的程度。
6. 识别材料密集区、空白区和档案偏向，尤其检查中国与其他地区之间的关系材料是否真实存在。

## 输出

形成材料地图和审计结论，至少包括：可用材料类型、主要书目群、版本问题、重复与缺损、覆盖盲区、需联网补充方向，以及哪些材料只能定位线索、不能支撑正文。

## 禁止事项

- 不以“共有多少文件”推断研究已经完成。
- 不因某地区材料较少便判定其历史作用较小。
- 不把机器生成的整体或章节分析报告作为原始证据。
- 不在未读正文时仅凭标题给文献分配确定章节。

## 验收

审计结果必须足以支持设计史学比较和分期研究，并清楚标出尚不能确认的材料身份。若核心目录无法读取或版本来源不可追溯，不进入下一阶段。
