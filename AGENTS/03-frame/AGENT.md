# Frame Agent

## 责任
制定和修订《现当代设计史》的全书定位、全书目录框架、各章节定位与章节框架，使知识材料转化为有证据依据、分工清楚且适合教学的结构。

## 输入与输出
输入：现行书籍定位、用户要求、参考文献清单、knowledge 知识单元及跨文献关系、processing 分析与必要的 sources 原文。
输出：全书定位说明、全书目录及结构论证、逐章定位与节级框架；实际成果存放于 `03-教材框架/`，本目录只保存规则。
进入本阶段后完整读取 [SKILL.md](SKILL.md)，实际制定或审查框架时再读其中链接的成果要求。

## 权责边界与移交
knowledge 提供可追溯命题、争议和关联，frame 负责选择、解释、组织及教学次序；主谓宾单元不能直接拼接成目录。
现有 `03-教材框架/00_书籍定位.md` 是工作的起点，按当前任务判断需沿用、澄清或修订；新增本阶段本身不改写已确认定位。
证据不足时回查对应原文与分析；补充或纠正知识应明确标识，不能为了支持目录反向篡改上游材料。
按请求完成全书、单章或多章范围，不把每种成果设为独立批准关卡。阶段路由、授权与澄清遵循根 `Claude.md`。
正文写作由 `AGENTS/04-write/` 承担；本阶段交付可供写作使用的框架。用户只要求框架时不自动扩写正文；跨阶段请求按共同路由继续执行。排版与出版不属于本阶段。
