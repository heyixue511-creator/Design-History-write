# 《现当代设计史》第十四章写作内容框架

章题：第十四章　21世纪设计的转型与挑战。
依据：对话上传的修订版目录，以及第四至十三章已形成的写作体例。本章为内容规划，案例的选择不等于原始史料已逐项核验。各节先列时段、论点与接口，再以七个维度检查案例；设计师身份融入具体项目，不另列职业身份表。不编排详细小结、自然段或字数，不设“待补与待核”栏目。

## 一、全章定位

历史问题：当设计对象从可见的产品与界面扩展到数据、算法、系统与气候问题，设计者对后果的责任如何重新界定，设计史的叙述又如何处理尚未结束的当代。

主体范围：2001年前后至写作当下。本章为全书终章，叙述距今最近，须区分已有历史距离的事件（2000年代、2010年代前期）与仍在变化中的现象（生成式人工智能、平台治理），对后者只记录已发生的事件与已发表的文本，不作趋势预测。

结构：14.1写生产方式；14.2写社交媒体与视觉文化；14.3写数据与算法；14.4写人工智能与生成式设计；14.5写气候危机下的可持续转型；14.6写设计伦理；中国栏写从“中国制造”到“中国设计”（21世纪）；观念栏综合“从产品到系统”。14.3与14.4以“已部署的算法系统”和“生成工具”区分，不重复机器学习原理；14.5与14.6以“物质后果”和“责任与规范”区分。

与前章的关系：第十一章11.7持有可持续设计的兴起（1971—2008），本章14.5只接2000年代后期以来的转型；第十二章持有数字生产工具，本章14.1只写分布式制造与开源硬件等新形态；第十三章持有平台设计，本章14.3写其算法化与治理后果。

七个维度：作品／产品／元素／材料与技术／生产组织与设计媒介／委托与使用／观念与话语。算法、数据集、协议、政策文本与开源项目可以成为对象，不为沿用实体产品体例虚构材料案例。

## 二、各节写作框架

### 14.1 当代设计生产方式的变化

| 项目 | 写作规定 |
|---|---|
| 时段 | 2005年前后至2020年代初。 |
| 论点 | 开源硬件、桌面数字制造与众包、远程协作把设计生产从企业内部流程部分转移到分布式网络，但大规模制造与品牌控制并未因此消失。 |
| 接口 | 快速原型的起点归12.4；全球价值链归11.2；人工智能工具归14.4。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | Arduino（2005）与开源硬件社区；RepRap自复制打印机项目（2005起）与MakerBot（2009）；Thingiverse等模型共享平台；Fab Lab网络（MIT，2001起）。 |
| 产品 | 桌面3D打印机、开源电子模块、众筹平台（Kickstarter 2009）上的硬件产品、按需打印的定制件（助听器、牙科对准器作为已实现量产的医疗案例）。 |
| 元素 | 可下载的设计文件、模块化接口、用户修改与分叉、“开源许可”作为设计的一部分。 |
| 材料与技术 | FDM与SLA的消费化、激光切割、数控铣削、开源固件；区分原型级与生产级。 |
| 生产组织与设计媒介 | 开源社区的分布式协作、众筹作为预售与市场检验、设计工作室与小批量制造的结合；设计者作为社区贡献者、众筹发起人、Fab Lab使用者与企业内部设计师的不同位置在案例中交代。 |
| 委托与使用 | 爱好者与教育机构、小型企业、医疗与航空等专业领域；不把“人人都是制造者”的话语等同于实际分布。 |
| 观念与话语 | 格申菲尔德《Fab》（2005）；安德森《创客》（2012）；开源硬件定义（2011）；记录文本，分析归观念栏。 |

### 14.2 社交媒体与当代视觉文化

| 项目 | 写作规定 |
|---|---|
| 时段 | 2004年前后至2020年代初。 |
| 论点 | 社交平台把图像生产与传播交给大众并以算法排序，视觉文化从设计师主导的发布转为以模板、滤镜、表情包与品牌视觉系统共同构成的持续流动。 |
| 接口 | 平台产品与操作归13.6；算法排序机制归14.3；平面设计的数字化前史归12.2。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | Instagram滤镜与方形图像（2010起）；表情包（meme）作为匿名集体设计；Canva等模板工具（2013）；品牌“扁平化”重设计（谷歌2015、万事达2016等）作为对小屏显示的回应；“企业孟菲斯”插画风格（2010年代后期）作为被批评的统一风格。 |
| 产品 | 滤镜、模板、表情符号（Unicode表情的设计与争议）、短视频格式、品牌动态标识系统。 |
| 元素 | 方形与竖屏构图、扁平与渐变、可变标识、视觉模板的重复、算法可见性对构图的影响。 |
| 材料与技术 | 手机摄像与图像处理、模板引擎、推荐算法作为“可见性条件”一句（机制归14.3）。 |
| 生产组织与设计媒介 | 平台内部设计团队、品牌代理公司、模板工具公司、业余创作者与“影响者”；设计师作为平台雇员、品牌代理、模板提供者与被模板替代者的不同位置在案例中交代。 |
| 委托与使用 | 平台企业、品牌、普通用户同时是生产者与受众。 |
| 观念与话语 | 曼诺维奇《Instagram与当代图像》（2017）；设计界对“企业孟菲斯”与“扁平化”的批评文章；记录文本。 |

### 14.3 数据与算法设计

| 项目 | 写作规定 |
|---|---|
| 时段 | 2000年代后期至2020年代初。 |
| 论点 | 推荐、排序、定价与风险评估算法成为用户所见与所得的实际决定者，设计对象因此包括数据采集、模型行为与其治理规则，而不限于界面。 |
| 接口 | 数据可视化归13.4；生成工具归14.4；伦理规范归14.6；中国平台归中国栏。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 推荐系统（YouTube、Netflix的首页排序）作为设计对象；“暗模式”（dark patterns）目录（布里格努尔，2010起）；A/B测试作为设计决策方法；欧盟GDPR（2018生效）的“隐私设计”条款与Cookie同意界面。 |
| 产品 | 信息流、无限滚动（拉斯金，2006）、通知与“点赞”（2009）、个性化定价与信用评分界面。 |
| 元素 | 排序与可见性、默认选项、摩擦与无摩擦、同意与拒绝的不对称设计。 |
| 材料与技术 | 用户行为数据、机器学习排序模型、实验平台；只写与设计决策直接相关的部分。 |
| 生产组织与设计媒介 | 产品团队中的设计师、数据科学家与增长团队的关系；指标（参与度、留存）作为设计目标；设计师作为团队成员、内部批评者（哈里斯“设计伦理学家”岗位）与外部研究者的位置在案例中交代。 |
| 委托与使用 | 平台企业与广告主、用户、监管机构；参与度指标与用户利益的分离作为核心矛盾。 |
| 观念与话语 | 哈里斯“被劫持的注意力”（2016）；布里格努尔暗模式定义；GDPR第25条文本；记录文本，规范分析归14.6。 |

### 14.4 人工智能与生成式设计

| 项目 | 写作规定 |
|---|---|
| 时段 | 2000年代参数化前史至写作当下。 |
| 论点 | 从参数化与算法生成到机器学习生成，设计工具从执行设计者的规则转为根据数据提出方案，设计者的工作重心向定义约束、选择与判断移动，其长期后果尚未形成历史定论。 |
| 接口 | CAD流程归12.4；算法治理归14.3；职业与伦理归14.6与观念栏。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 扎哈·哈迪德事务所与Grasshopper参数化（2007起）的建筑作品作为前史；欧特克Dreamcatcher项目与空客“仿生隔板”（2016）作为生成式设计的工业案例；DALL·E（2021）、Midjourney与Stable Diffusion（2022）生成图像进入设计流程；Adobe Firefly（2023）集成于专业软件。 |
| 产品 | 参数化插件、拓扑优化软件、文生图工具、AI辅助的排版与配色功能；按“已发布并被使用”限定，不列未实现的演示。 |
| 元素 | 约束与目标的定义、多方案生成与筛选、提示词作为设计媒介、训练数据的风格来源问题。 |
| 材料与技术 | 拓扑优化与有限元、扩散模型、大规模图像数据集（LAION等）；只写与设计实践相关的部分。 |
| 生产组织与设计媒介 | 软件公司的AI功能集成、设计工作室对生成工具的采用与抵制、训练数据中的设计师作品与版权诉讼（2023年起）；设计者作为工具使用者、数据提供者（常为未经同意）与规则定义者三种位置在案例中区分。 |
| 委托与使用 | 软件企业、设计工作室与自由职业者、客户对成本与速度的期待。 |
| 观念与话语 | 欧特克等公司关于“生成式设计”的定义文本；设计师团体关于AI训练数据的声明（2022—23）；记录文本与事件，不作职业前景预测。 |

### 中国：从“中国制造”到“中国设计”（21世纪）

| 项目 | 写作规定 |
|---|---|
| 时段 | 2001年入世至写作当下。 |
| 论点 | 中国设计在入世后经由代工升级、国家政策、企业设计部门与设计教育扩张形成规模，并在消费电子、交通与互联网产品中建立自有品牌，但“中国设计”作为话语与设计实践之间仍需区分。 |
| 接口 | 1978—2001归第十一章中国栏；互联网产品归第十三章中国栏；港台归第十章中国栏。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 2008年北京奥运会视觉系统（会徽“中国印”、体育图标、火炬）；2010年上海世博会中国馆；复兴号动车组（2017）；深圳“设计之都”（2008，联合国教科文组织）。 |
| 产品 | 华为、小米等消费电子产品及其设计团队的建立；大疆无人机（2013年起Phantom系列）；比亚迪与蔚来等新能源汽车的设计；共享单车（2015—17）作为平台产品与城市后果的双重案例。 |
| 元素 | 国家形象设计中的传统符号；消费电子对国际语言的采用与本土化；“国潮”（2018年前后）作为商业与身份策略。 |
| 材料与技术 | 深圳供应链的快速原型与量产能力、新能源与电池、高铁技术引进与再设计。 |
| 生产组织与设计媒介 | 国家“设计产业”政策（“十二五”以来）；企业设计中心（华为、小米、大疆、比亚迪）；高校设计专业的扩张（2000年代设计学成为一级学科2011）；设计者作为企业内部设计师、高校教员、独立工作室主与政策参与者的位置在案例中交代；中国设计师获国际奖项作为传播事件。 |
| 委托与使用 | 国家形象工程、企业与新中产消费者、海外市场。 |
| 观念与话语 | “从中国制造到中国创造”口号（2000年代中期政府文件）；设计学一级学科设立文件；柳冠中等关于“中国设计”与“设计事理学”的论述；记录文本，分析归观念栏。 |

### 观念：从产品到系统——设计对象的扩展

| 项目 | 写作内容 |
|---|---|
| 核心问题 | 当设计对象从可见的物与界面扩展到数据、算法、服务系统与生态后果，“设计”一词是否仍指同一种活动，设计史又如何为尚未结束的当代作结？ |
| 分析材料 | 14.1分布式生产；14.2视觉文化的平台化；14.3算法作为设计对象；14.4生成工具改变设计者位置；14.5系统层面的可持续；14.6伦理形态；中国栏的话语与实践。 |
| 分析任务 | 回顾全书各章观念栏的线索（分化—译介—标准化—科学化—后现代—全球化—职业重组—用户中心），说明“设计对象扩展”是其延续而非断裂；区分系统思维的三种来源（控制论与设计方法运动1960年代、服务设计、生态系统观）；指出扩展带来的责任扩大与设计者权力有限之间的矛盾；说明当代部分只能记录事件与文本，判断留待后续。 |
| 表述限制 | 不以“设计无所不包”作为结论；不预测人工智能对职业的最终影响；不把“中国设计”写成已完成的转型；不以道德判断替代对委托关系的分析。 |
| 接口 | 回指第一章观念栏“设计与工艺的分化”形成全书首尾呼应；向导论的方法论说明开放。 |
