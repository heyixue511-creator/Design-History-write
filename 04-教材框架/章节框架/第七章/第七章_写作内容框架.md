# 《现当代设计史》第七章写作内容框架

章题：第七章　东亚现代设计的形成。
依据：对话上传的修订版目录；体例同第四至六章——每节先列时段、论点、接口，再按七个维度写案例内容；设计师身份随案例交代，不单列；不编排详细小结、自然段、字数，不设“待补与待核”栏目。案例范围为写作规划，不代表每个细节均已完成原始史料核验。

## 一、全章定位

历史问题：东亚各地在殖民体系、国家工业化与城市商业文化并存的条件下，现代设计以怎样的机构、产品和图像形成，传统工艺又如何被重新命名为现代设计的资源。

主体范围：1868年明治维新至1937年中日全面战争爆发；以1900—1937年为重心。殖民地朝鲜、台湾及“满洲”的设计活动纳入7.1，不另设节。战时归第八章，战后日本归9.6。

结构：7.1写区域条件与殖民体系；7.2写日本的工业、建筑与产品；7.3写商业文化与视觉传播（日本为主，东亚其他城市并列）；7.4写民艺运动；中国栏写上海商业美术与月份牌；观念栏综合民艺与“用之美”。本章不把东亚写成西方现代设计的迟到接收者，殖民权力、国家博览会与本地商业资本是形成设计的主动条件。

第二章观念栏已写“图案”译名，第四章中国栏已写图案教育，本章不重述；日本的图案教育只在7.2的生产组织格中以机构名出现。

七个维度为检查工具：作品、产品、元素、材料与技术、生产组织与设计媒介、委托与使用、观念与话语。

## 二、各节写作框架

### 7.1 东亚现代化、殖民体系与现代设计

| 项目 | 内容 |
|---|---|
| 时段 | 1868—1937年 |
| 论点 | 东亚现代设计的形成条件是国家主导的工业化与日本殖民体系的扩张，博览会、铁路和殖民城市规划是设计进入该区域的首批载体。 |
| 接口 | 中国洋务工厂归第二章中国栏；晚清博览会归第三章中国栏；殖民地战时动员归第八章。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 内国劝业博览会（1877起）与1903年大阪第五回博览会的展馆；朝鲜总督府厅舍（1926）、台湾总督府厅舍（1919）作为殖民地官厅建筑；南满洲铁道株式会社的大连城市规划与“亚细亚”号列车（1934）。 |
| 产品 | 博览会出口工艺品（七宝、漆器、陶瓷）；殖民地物产展示品；满铁旅游印刷品与车厢内饰。 |
| 元素 | 殖民官厅的西洋古典样式与“帝冠样式”；博览会出口品中为迎合欧美市场而放大的“日本趣味”；殖民地物产的异域化呈现。 |
| 材料与技术 | 铁路、钢筋混凝土官厅、机器制瓷与出口漆器的量产化。 |
| 生产组织与设计媒介 | 明治政府的殖产兴业政策与工部省；博览会事务局与起立工商会社（1874）作为出口设计的组织者；总督府营缮部门与满铁的设计机构；设计者多为官厅技师与会社雇员，案例中说明其供职方式。 |
| 委托与使用 | 明治政府、殖民地总督府、满铁、欧美博览会买家。 |
| 观念与话语 | 殖产兴业文件、博览会出品规程；总督府关于“同化”的建筑话语只记录出处。 |

### 7.2 日本现代设计的早期发展

| 项目 | 内容 |
|---|---|
| 时段 | 1900—1937年 |
| 论点 | 日本现代设计在工艺改良、西式建筑和新兴产业之间形成，官方工艺指导机构与民间建筑师团体是两条平行线索。 |
| 接口 | 图案教育归第二章观念栏；民艺归7.4；战后归9.6。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 分离派建筑会（1920）成员作品；安托宁·雷蒙德的东京女子大学与自宅（1920年代）；土浦龟城自宅（1935）作为日本现代主义住宅；东京帝室博物馆竞赛（1931）中的“帝冠样式”争议。 |
| 产品 | 商工省工艺指导所（1928，仙台）的家具与金属器试作；布鲁诺·陶特在工艺指导所与群马高崎的竹木制品指导（1933—36）；夏洛特·佩里昂赴日（1940）只作接口提示。 |
| 元素 | 和室尺度与现代平面的结合；工艺指导所产品中的标准化与日本材料；分离派对历史样式的拒绝。 |
| 材料与技术 | 竹、漆、木与金属的工业化加工；钢筋混凝土与木构的并用。 |
| 生产组织与设计媒介 | 商工省工艺指导所的组织与出口导向；分离派建筑会、日本国际建筑会；剑持勇、丰口克平等作为指导所技师的早期工作放入案例，说明官厅技师与建筑师团体两种身份。 |
| 委托与使用 | 商工省与出口贸易商、私人住宅业主、大学。 |
| 观念与话语 | 分离派建筑会宣言（1920）；陶特《日本美的再发现》（1939）与其对桂离宫的论述；工艺指导所出口方针文件。 |

### 7.3 商业文化与现代视觉传播

| 项目 | 内容 |
|---|---|
| 时段 | 1900—1937年 |
| 论点 | 百货公司、铁路、化妆品与出版业是东亚现代平面设计的主要委托方，广告与包装把西方构成语言与本地图像结合为商业视觉。 |
| 接口 | 中国月份牌归中国栏；朝鲜京城、台北的商业广告在本节以并列案例出现；日本战时宣传归8.1。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 三越百货海报（杉浦非水，1914起）；资生堂的广告、包装与字体（1920年代起，福原信三主持的意匠部）；杉浦非水《非水创作图案集》；山名文夫的资生堂插图；朝鲜京城三越与和信百货的广告作为殖民地商业视觉的对照。 |
| 产品 | 化妆品包装、火柴盒与香烟盒图案、百货公司包装纸与宣传册、铁路旅游海报。 |
| 元素 | 新艺术式曲线向构成主义式几何的转变（杉浦非水前后期对照）；资生堂的唐草纹与细线字体；“摩登女郎”图像。 |
| 材料与技术 | 石印与胶印、照相制版、彩色印刷的普及。 |
| 生产组织与设计媒介 | 企业内部意匠部（资生堂）与百货公司宣传部；七人社（1926）等图案家团体；《广告界》等专业杂志；设计者从日本画家、图案教师进入企业意匠部的路径写入案例。 |
| 委托与使用 | 百货公司、化妆品与烟草企业、铁路公司、都市中产消费者。 |
| 观念与话语 | 杉浦非水关于“商业图案”的论述；资生堂意匠部的设计方针；《广告界》的编辑文章。 |

### 7.4 民艺运动：传统文化与现代设计

| 项目 | 内容 |
|---|---|
| 时段 | 1925—1941年 |
| 论点 | 民艺运动以“无名工匠的日用器物”重新评价传统工艺，并把这一评价转化为收藏、展示与新制作，它既是对工业化的批评，也是对殖民地工艺的一种观看。 |
| 接口 | 莫里斯只以“影响”一句出现（2.3持有）；观念综合归本章观念栏；战后民艺的商业化归9.6。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 日本民艺馆（1936，东京驹场）建筑与陈列；滨田庄司、河井宽次郎的陶器；柳宗悦收藏的朝鲜白瓷与木工器物；芹泽銈介的型染。 |
| 产品 | 民艺店“たくみ”（1933）销售的新作器物；地方窑场在民艺指导下的产品改良。 |
| 元素 | 素面、厚釉、手工痕迹与地方性；对“无名性”的强调与署名作家作品之间的矛盾。 |
| 材料与技术 | 地方陶土与釉、型染、木工；传统技法在新市场条件下的延续。 |
| 生产组织与设计媒介 | 《工艺》杂志（1931起）、日本民艺协会（1934）、民艺馆与民艺店；柳宗悦作为收藏者与理论家、滨田与河井作为作家型陶工、地方窑场工匠三种位置在案例中区分。 |
| 委托与使用 | 都市知识阶层与收藏者；地方工匠作为被评价者而非委托方。 |
| 观念与话语 | 柳宗悦《工艺之道》（1928）、《朝鲜与其艺术》（1922）中关于“悲哀之美”的论述；《民艺》命名（1925）的经过；只记录文本及其场合，评价归观念栏。 |

### 中国：上海商业美术与月份牌

| 项目 | 内容 |
|---|---|
| 时段 | 1900—1937年 |
| 论点 | 月份牌与商业美术把石印技术、外商广告需求和本地绘画传统结合为一种大众视觉商品，画家据此成为受雇于广告部门或开设画室的职业人。 |
| 接口 | 染织设计归第五章中国栏；抗战木刻归第八章中国栏；留美建筑师归第六章中国栏。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 周慕桥早期月份牌；郑曼陀擦笔水彩月份牌（1914起）；杭稚英画室为阴丹士林布、美丽牌香烟所作广告；英美烟公司广告部作品。 |
| 产品 | 月份牌年画、香烟与布匹广告、火柴盒与商标、包装与报纸广告。 |
| 元素 | 擦笔水彩的明暗、时装女性与西式室内、商品与节令图像的组合；商标中的中西图像并置。 |
| 材料与技术 | 石印与彩色胶印、擦笔水彩画法、照相制版。 |
| 生产组织与设计媒介 | 英美烟公司、南洋兄弟烟草等企业广告部；杭稚英、金雪尘、李慕白的稚英画室（分工流水作业）；商务印书馆与中华书局的美术部门；画家从年画作坊、画师学徒到企业广告部职员与画室主人的路径放入案例。 |
| 委托与使用 | 外商与民族企业、零售商店、城市与内地消费者（月份牌随商品赠送）。 |
| 观念与话语 | 当时报刊对月份牌的评论、画室的招徕广告、广告部关于“中国风味”的要求；1930年代左翼对月份牌的批评只记出处。 |

### 观念：民艺与“用之美”

| 项目 | 内容 |
|---|---|
| 核心问题 | 当“美”被重新定位在日用器物的使用之中，传统工艺与现代设计之间形成怎样的关系？ |
| 分析材料 | 7.4的柳宗悦文本；7.2工艺指导所与陶特的论述；7.3商业图案的“实用”话语；中国栏中月份牌作为“实用美术”的定位。 |
| 分析任务 | 区分民艺的“用之美”与西方功能主义的“形式追随功能”；指出民艺对朝鲜工艺的评价与殖民地观看的关系；比较民艺对“无名性”的要求与运动中作家署名、都市收藏之间的矛盾。 |
| 表述限制 | 不把民艺写成莫里斯的日本翻版，也不把柳宗悦写成单纯的反殖民者或单纯的殖民共谋者；不以战后“Good Design”与民艺商业化倒推1930年代的意图。 |
| 接口 | 接第二章观念栏的“图案”与第五章观念栏的装饰之争；向9.6战后日本与11.6本土文化与身份开放。 |
