# 《现当代设计史》第九章写作内容框架

章题：第九章　战后现代设计的重构。
依据：对话上传的修订版目录；体例同第四至八章——每节先列时段、论点、接口，再按七个维度写案例内容；设计师身份随案例交代，不单列；不编排详细小结、自然段、字数，不设“待补与待核”栏目。案例范围为写作规划，不代表每个细节均已完成原始史料核验。

## 一、全章定位

历史问题：战后重建、冷战与消费社会如何把战时积累的生产能力、国家机构与设计人员重新组织为各地区的设计体制，“好设计”又如何成为国家、企业与博物馆共同使用的标准。

主体范围：1945—1965年前后；9.1民族独立国家延至1960年代；9.4瑞士国际主义至1960年代末；9.5苏联与东欧至1960年代末。后现代批评归第十章。

结构：9.1写重建与新国家；9.2北美；9.3英国与西欧；9.4瑞士平面；9.5苏联与东欧；9.6日本；9.7拉美；中国栏写工艺美术体系与国家主导的工业设计；观念栏综合“设计的科学化”。各节以体制与产品并重，不写成分国的设计师名人录。

本章七节地区并列，需严格控制同一产品在两节重复：“好设计”展览以9.2持有美国MoMA系列，9.3持有英国“英国能做到”与设计中心，9.6持有日本G标志；不在三处各写一遍定义。

七个维度为检查工具：作品、产品、元素、材料与技术、生产组织与设计媒介、委托与使用、观念与话语。

## 二、各节写作框架

### 9.1 战后重建、民族独立与现代设计

| 项目 | 内容 |
|---|---|
| 时段 | 1945—1965年 |
| 论点 | 重建计划与新独立国家把现代设计作为国家建设的工具，建筑、城市与国家形象设计成为设计师获得国家委托的首要场所。 |
| 接口 | 美国战后住宅归9.2；印度、巴西的后续发展分别归11.5与9.7；马歇尔计划的产品推广只一句。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 昌迪加尔（柯布西耶与印度团队，1951起）；巴西利亚（科斯塔、尼迈耶，1956—60）只在此作国家工程一句，建筑与平面细节归9.7；伦敦“英国节”（1951）会场；柏林国际建筑展Interbau（1957）。 |
| 产品 | 英国节的标识与字体（阿布拉姆·盖姆斯节徽）；战后预制住宅（英国“预制屋”计划、法国普鲁韦的拆装住宅）；新国家的货币、邮票与国徽（印度1947起、加纳1957起）。 |
| 元素 | 现代主义建筑作为新国家象征；国家视觉符号中的传统图案与现代字体的组合。 |
| 材料与技术 | 预制混凝土与钢构件、战时工厂转产的铝与胶合板住宅。 |
| 生产组织与设计媒介 | 国家重建部门、马歇尔计划生产率署的设计推广；新国家的政府印刷与铸币机构；建筑师作为国家聘请的外国顾问（柯布西耶）与本国新建专业机构成员（昌迪加尔印度团队）两种身份在案例中区分。 |
| 委托与使用 | 国家政府与殖民地过渡政府、被安置的居民、国际会议受众。 |
| 观念与话语 | 尼赫鲁关于昌迪加尔“不受过去束缚”的讲话；英国节的“国家的音调”宣传；只记出处。 |

| 项目 | 内容 |
|---|---|

| 论点 | 英国、意大利、德国与北欧以各自的制度把设计纳入重建与出口：英国的国家机构、意大利的企业—建筑师合作、德国的学校—企业系统、北欧的国家推广。 |
| 接口 | 瑞士平面归9.4；意大利激进设计归10.3；5.6北欧战前不重述；8.2实用计划只回指。 |

| 元素 | 英国的“当代风格”；意大利的雕塑性外壳；乌尔姆—博朗的系统化与中性外观；北欧的有机木作与手工—工业结合。 |

| 生产组织与设计媒介 | 英国工业设计委员会（1944）与设计中心标签；意大利奥利维蒂的企业文化部门与建筑师顾问制（尼佐利、索特萨斯）；乌尔姆设计学院（1953—68）与博朗的合作；北欧工艺协会与国家巡展；设计师作为国家机构评审、企业顾问、学院教员与匠作合伙人（韦格纳与约翰内斯·汉森）的身份在案例中交代。 |
| 委托与使用 | 国家机构、出口导向企业、重建中的家庭、北美进口商。 |
| 观念与话语 | 工业设计委员会的“好设计”标签标准；乌尔姆的“设计科学”课程文件（马尔多纳多）；拉姆斯早期论述只作接口；分析归观念栏。 |

| 接口 | 5.3战前基础不重述；信息图标归13.3；企业形象的美国实践归9.2。 |

### 中国：工艺美术体系与国家主导的工业设计

| 项目 | 内容 |
|---|---|
| 时段 | 1949—1978年 |
| 论点 | 新中国把设计纳入国家计划体制：工艺美术以出口创汇与国家礼品为目标形成学院—研究所—工厂体系，工业产品的造型则由工厂与部属研究机构承担，“工业设计”作为独立职业尚未建立。 |
| 接口 | 第四章中国栏的图案教育、第八章中国栏的木刻只回指；1978年后归第十一章中国栏。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 人民大会堂等“十大建筑”（1959）的室内与陈设设计（中央工艺美术学院参与）；国徽（1950，清华与央美两组方案合成）；建国瓷（1953，祝大年等）。 |
| 产品 | 红旗CA72轿车（1958）、解放CA10卡车（1956）、永久与飞鸽自行车、上海牌手表（1955起）、蝴蝶牌缝纫机；出口工艺品（景泰蓝、象牙雕刻、丝绸）。 |
| 元素 | 国家礼仪设计中的民族装饰（宫灯、藻井纹样）；日用工业品对苏联与战前上海产品的沿用；红旗轿车的扇形格栅与宫灯尾灯。 |
| 材料与技术 | 苏联援建的汽车、机床技术；手工艺材料的国家统购；轻工业产品的仿制与改型。 |
| 生产组织与设计媒介 | 中央工艺美术学院（1956）、轻工业部工艺美术研究所、各地工艺美术公司与工厂；一汽、上海手表厂等工厂的产品设计科；庞薰琹、张仃、祝大年等作为学院教员与国家项目负责人的身份随案例交代；设计者在工厂内多为技术人员而非“设计师”。 |
