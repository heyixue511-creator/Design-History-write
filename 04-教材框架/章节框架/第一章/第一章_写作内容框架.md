# 《现当代设计史》第一章写作内容框架

**章题**：第一章　现代设计的起源与发展
**版本**：2026-10-13定稿，经一轮审查修订（章节框架层级，不含小结与段落框架）。每节一组表：表头为时段、重点维度、论点、接口；表体为七个对象维度，各格直接写该维度下的案例内容（含设计者是谁、以什么身份、受雇于谁）。所有案例均已落实对象与出处。
**基准**：对话上传的《现当代设计史_全书目录（修订版）.md》。配套：《全书审查总表》《写作内容框架总表》。

## 一、章的定位

| 项目 | 内容 |
|---|---|
| 历史问题 | 机器与工厂出现后，"决定物品形态"这件事如何从制作者手中分离出来，成为一种独立职能 |
| 时段 | 1760年代—1850年，止于1851年万国博览会（归2.1）；1.5因家具图册起于1754年、1.3因铁桥起于1779年，各节时段略有前后 |
| 地区 | 以英国为主体，法国、美国为对照，中国在栏目中并列；地区只作案例来源 |
| 本章持有的对象 | 工厂制、五类设计者、韦奇伍德的分工、互换零件（至1850）、展示字体与石版术、早期摄影出版、家具图册与陈列室、外销瓷 |
| 只引一句的对象 | 水晶宫与1851年（2.1）、拉斯金与普金（2.2—2.3）、百货公司的成熟形态（2.2）、福特流水线（6.1）、数据可视化（13.4）、"design"的东亚译介（第二章观念栏） |
| 写作规则 | ① 背景段只写到"它改变了什么设计问题"，下一段必须出现可指认的作品或产品；② 每节七个维度全填，★为重点维度，篇幅最大；③ 写每个案例时交代设计者是谁、以什么身份、受雇于谁；④ 每节至少一件可配图实物；⑤ 他章持有的对象只引一句并注"见某节"；⑥ 年份有两说者在正文写区间并注出处 |
| 七个维度 | 作品（可指认的单件设计物）／产品（批量进入市场的物与品类）／元素（形式语言）／材料与技术／生产组织与设计媒介（分工、流程，及图纸、模型、样本簿、图录、木模等传递设计决策的载体）／委托与使用／观念与话语（只填当时人的说法，不填后世评语） |
| 译名 | 柯尼希（Koenig）、韦奇伍德、博尔顿、本特利、弗拉克斯曼、齐本德尔、塔尔博特，全章统一 |

## 二、各节写作框架

### 1.1　工业革命与现代设计的萌发

| 时段 | 重点维度 | 论点 | 接口与去向 |
|---|---|---|---|
| 1760—1830 | 材料与技术；生产组织与设计媒介 | 工厂制使制作被拆成工序，形态决策上移，"谁来设计"成为新问题 | 结尾提出1.2—1.5四个问题；韦奇伍德只以博尔顿合作一句带出；水晶宫、印刷、营销不在本节 |

| 维度 | 案例内容 |
|---|---|
| 作品 | 阿克赖特水力纺纱机（1769年专利）实物。阿克赖特是假发匠出身的企业家，机器由他取得专利并建厂推广，发明权在当时即有争议（1785年专利被撤销）——物品的形态决定者、专利持有者与制作者已不是同一人 |
| 产品 | 机制棉纱；索霍厂的纽扣、带扣等金属"小玩意"，由业主博尔顿定品类、工匠按样复制 |
| 元素 | 机制纱线比手纺纱更均匀、更结实：物品的物理性质先于任何审美判断就已改变，为1.3埋下"新材料无形式传统"一句 |
| ★材料与技术 | 达比焦炭炼铁（1709）；纽克曼抽水机经瓦特改良、与博尔顿合作推向市场；哈格里夫斯珍妮纺纱机（1764）；阿克赖特水力纺纱机；1787年蒸汽机开始为棉纺厂提供动力 |
| ★生产组织与设计媒介 | 导语先写工匠时代：行会师傅—熟练工—学徒，乡村木匠一人兼任木工、细木工、橱柜工、木雕工。克罗姆福德厂（1771）：两班十二小时昼夜运转，操作者为非熟练工。斯密制针工场（1776）：约十八道工序各由一人完成——正文明示这是手工工场而非机器工厂，分工先于机械化。索霍厂（1766）：600余工人分工协作，厂内藏样本簿、石膏模型与模具，工匠复制后把图纸交模具师制模——图纸与模具作为设计媒介已成为工厂环节，但画图者是谁留给1.2。配图：狄德罗《百科全书》图版卷"制针"（1760年代，公有领域） |
| 委托与使用 | 工厂主为匿名市场生产；工人从物品的制作者兼使用者变为机器操作者 |
| 观念与话语 | 斯密《国富论》第一篇第一章论分工（1776）；尤尔《制造业哲学》（1835）颂扬自动工厂。结尾引参照书所列工业化初期的五类分担者——发明家（特里维西克，几乎不识字却造出首台铁路机车）、工程师（布鲁内尔，受正规训练）、技工、建筑师、艺术家——各一句，说明形态决定权散落在这些人手中，尚无"设计者"之名 |

### 1.2　机械化生产与设计职能的分化

| 时段 | 重点维度 | 论点 | 接口与去向 |
|---|---|---|---|
| 1760—1800 | 产品；生产组织与设计媒介 | 工厂把分工制度化为设计岗位，由受雇或自由艺术家供稿 | 营销与图录归1.5；设计者职业化在3.3（贝伦斯）接续 |

| 维度 | 案例内容 |
|---|---|
| 作品 | 弗拉克斯曼《舞蹈时刻》浮雕（约1776—78，洛杉矶郡艺术博物馆藏）。弗拉克斯曼自1775年起为韦奇伍德与本特利供稿，游历意大利后承接浮雕委托；其六位缪斯模型可拆可组，用于挂饰、瓶身与炉面——受雇艺术家的署名作品第一次成为工厂产品的来源 |
| ★产品 | 王后御用陶器（米色陶器，得夏洛特王后赞助后命名）作为"实用器皿"；黑玄武岩炻器与碧玉细炻器系列作为"装饰器皿"，仿希腊花瓶与古代浮雕 |
| 元素 | 新古典浮雕与素色器身的组合规则：白色浮雕在模具中分别制作后黏合于器身，形式来自亚当兄弟引领的新古典风格 |
| 材料与技术 | 黑玄武岩与碧玉细炻器配方为韦奇伍德自行研制；绿釉早期与威尔登合作；模具复制使同一模型反复使用 |
| ★生产组织与设计媒介 | 伊特鲁里亚厂（1769）：沿袭斯塔福德郡分工传统并进一步细化，目标是"制造不会犯错的机器工人"。先雇一批艺术模具师，因其散漫改为雇自由艺术家供稿（亚当兄弟、弗拉克斯曼、斯坦布斯、邓普顿夫人）；图纸交模具师制模，再由成型工复制——"为制造商供稿的艺术家"成为可辨认的岗位。对照法国：家具工（ébénistes）、细木工（menuisiers）、装潢工（ornemanistes）分属不同行会，装潢工把纹样印成样本册出售——手工业内部早有分工，但未形成受雇于工厂的岗位 |
| 委托与使用 | 合伙人本特利（利物浦商人，1768年起合伙）把关新古典趣味，对供稿艺术家有筛选权；赞助与市场的分层留给1.5 |
| 观念与话语 | 韦奇伍德致本特利信（1769年10月9日）："把工人造成不会犯错的机器"；出处：法雷尔编《韦奇伍德书信集》三卷本（1903—06），后由剑桥大学出版社重印 |

### 1.3　新技术、新材料与设计方式的变革

| 时段 | 重点维度 | 论点 | 接口与去向 |
|---|---|---|---|
| 1779—1850 | 元素；材料与技术 | 新材料与互换零件没有现成形式传统，形式决策须另行作出 | 铁与玻璃大跨度建筑止于一句，水晶宫归2.1；互换零件止于1850，流水线归6.1 |

| 维度 | 案例内容 |
|---|---|
| 作品 | 铁桥（1779）；布鲁内尔"大不列颠号"（1843）以铁代木、首用螺旋桨。两者的形式决定者是铁匠与受训工程师；布鲁内尔克里夫顿吊桥塔楼借埃及纪念性建筑，是工程师采用流行样式的特例。里昂迪迪埃·珀蒂公司以提花机织成的《雅卡尔像》（1839）：织工卡基亚以24000张穿孔卡片织出油画般的丝织肖像，纹样信息由"打卡"工序预先编码，织工只负责执行 |
| 产品 | 美式生产体系下的互换零件产品：泰瑞钟表、柯尔特左轮、哈珀斯费里兵工厂的霍尔步枪（1819年列装，1820—40年代生产），形态由机械师与军方规格共同决定 |
| ★元素 | 铸铁构件与铁壳船的形式问题：无传统可循，装饰借自石构与木构。提花织物的形式由穿孔卡片决定，纹样可无限复制且与织工手艺无关——机器生成的纹样 |
| ★材料与技术 | 铸铁、铁壳与螺旋桨；互换零件要求公差与量具：斯普林菲尔德兵工厂的布兰查德仿形车床（1819）按母模一次复制多件枪托，巴克兰制定成套量规，1880年美国人口普查报告记斯普林菲尔德步枪检验用量规达154件；霍尔在哈珀斯费里自建车间与机器以实现零件互换 |
| 生产组织与设计媒介 | 互换零件把工序重新定义为按量规加工：母模与量规取代工匠的手感成为形态标准。博尔顿在基础壶体上搭配不同部件与装饰组成多品种，设计决策在业主的样本簿与模具库中 |
| 委托与使用 | 军队（美国军械部对两座国家兵工厂的互换要求）、铁路与航运公司（布鲁内尔的大西部铁路与船舶） |
| 观念与话语 | 巴贝奇《论机器与制造业的经济》（1832）"论复制"一章论机器复制与精度 |

### 1.4　印刷工业化、摄影与大众视觉传播

| 时段 | 重点维度 | 论点 | 接口与去向 |
|---|---|---|---|
| 1780—1850 | 作品；材料与技术；委托与使用 | 印刷机械化使图像首次批量生产，视觉设计获得独立作品形态与职业雏形 | 商业美术职业化归第二、七章；数据可视化归13.4；摄影作为艺术媒介（照相蒙太奇）归3.4一句 |

| 维度 | 案例内容 |
|---|---|
| ★作品 | 1814年11月29日以柯尼希蒸汽滚筒机首印的《泰晤士报》；1821年伦敦米诺尔剧院天文学演讲传单（多字体中轴堆叠）；普莱费尔柱形图（1786）与饼图（1801）——普莱费尔曾任瓦特的绘图员，是绘图技能转入信息呈现的例子。塔尔博特《自然的铅笔》（1844年6月—1846年4月分六辑出版，24幅照片）：首部商业出版的摄影插图书，照片由其前仆人亨尼曼在雷丁开设的摄影印制所批量制作 |
| 产品 | 报纸、海报、商店传单、商业名片等批量印刷品；沃伦鞋油广告由插画师克鲁克山绘制；比尔德1841年3月在伦敦皇家理工学院楼顶开设英国首家达盖尔法肖像照相馆，肖像成为可购买的批量服务 |
| 元素 | 展示字体谱系：科特罗（卡斯隆学徒）沙模铸二英寸字母（1766），索恩粗黑体（1803），费金斯埃及体（1815），卡斯隆无衬线（1816），托斯卡纳体；海报的中轴堆叠排版——铸字工成为字体设计者 |
| ★材料与技术 | 斯坦霍普铸铁印刷机（1799）；柯尼希蒸汽滚筒机（1814，每小时约1100张，为手动机四倍以上；印刷工只需换纸）；柯珀铅版（1815）与四缸机（1827）；塞尼菲尔德石版术（约1796，发明者为演员兼剧作家）与1820年代末套色石印。摄影：达盖尔法公布（1839年8月）；塔尔博特卡罗法（1840年9月发明、1841年2月获专利）首次实现负—正可复制 |
| 生产组织与设计媒介 | 排字—印刷—发行的工业化分工，排字仍为手工；报馆以《泰晤士报》资助印刷机研发；荷加斯为商店传单刻版，"在图形设计专业出现前，画师和雕刻师成为第一批广告设计师"；1780年张贴广告成为固定职业；雷丁摄影印制所（1844）是首个以批量印制照片为业的机构 |
| ★委托与使用 | 匿名公众首次成为设计对象：报纸读者、剧院观众、商店顾客、照相馆顾客；广告主（专利药、鞋油、服装商） |
| 观念与话语 | 塔尔博特《自然的铅笔》导言论摄影的化学原理与"自然之手"；霍顿以首字母下沉、手指符号引起广告注意的做法（17世纪末—18世纪初）；拉斯金1857年对石版画的偏见（作为后见） |

### 1.5　商品社会、城市生活与现代设计

| 时段 | 重点维度 | 论点 | 接口与去向 |
|---|---|---|---|
| 1750—1850 | 产品；委托与使用 | 分离出来的设计首先服务于市场区分：按品位分层、靠图册与陈列销售 | 百货公司的成熟形态与维多利亚消费归2.2；战后消费归9.2 |

| 维度 | 案例内容 |
|---|---|
| 作品 | 韦奇伍德伦敦陈列室；齐本德尔《绅士与木匠指导》（1754）图版——据吉尔伯特《托马斯·齐本德尔的生平与作品》（1978），齐本德尔经营大型工坊，本人并不负责所有设计，"更偏向经理人而非制造者"。塔利斯《伦敦街景》（1838—40）：逐户绘出摄政街等商业街的店面立面，是1840年前后商店橱窗与招牌的直接图像记录 |
| ★产品 | 韦奇伍德"实用器皿"与"装饰器皿"两条产品线；赫波怀特（1788）、谢拉顿（1793—94）图册推广新古典家具；博尔顿按价位分层的壶、烛台系列（部件组合方法见1.3） |
| 元素 | 家具风格的混杂：新古典、哥特式、中国风并存，"中国风"只是中国元素老套地呈现在英式家具上（中国栏不重复）；店面立面的统一招牌字体与大面积玻璃橱窗（见《伦敦街景》） |
| 材料与技术 | 镀银与仿金铜饰（ormolu）以廉价金属仿贵金属，使同一造型可按价位分层；平板玻璃与煤气灯使橱窗陈列成为可能，1845年英国废除玻璃消费税后大面积橱窗普及 |
| 生产组织与设计媒介 | 陈列室与目录接单、订单在伊特鲁里亚厂装配后寄送，不生产过量库存；大型家具工坊（雇员400人）承接从窗帘到整幢房屋陈设的订单；家具经零售网络与专门商销售；1830年代起城市出现明码标价的综合商店（曼彻斯特肯德尔·米尔恩1836、纽卡斯尔班布里奇1838），为2.2的百货公司作前史 |
| ★委托与使用 | 中产阶级为新消费群，趣味跟风贵族与皇室；王后赞助与中产市场并存；仿制品与廉价竞争者跟随。决定趣味的是企业主本人，供稿者与制作者均不署名 |
| 观念与话语 | 韦奇伍德致本特利信（1779）："时尚远胜于优点"，论贵族趣味对市场的引领，出处同《韦奇伍德书信集》；布莱克《弥尔顿》序诗"黑暗的撒旦磨坊"（约1804—1810）作为对工厂与商品社会的反应 |

### 中国：清代手工业与外销商品网络

| 时段 | 重点维度 | 论点 | 接口与去向 |
|---|---|---|---|
| 1700—1840 | 产品；生产组织与设计媒介 | 形态决策在欧洲订货方，经样稿模型传递，制作在中国工匠——"贸易链上的分离"与英国的工厂分离同期并存 | 洋务运动归第二章中国栏；"中国风"作为欧洲市场元素归1.5；翻转参照书把中国瓷器只写成"中国风"素材与塞佛尔、麦森对手的视角 |

| 维度 | 案例内容 |
|---|---|
| 作品 | 广州加彩纹章瓷单件：欧洲家族把纹章图样寄到中国照样复制，窑工与彩绘工匿名。荷兰东印度公司委托画家普龙克设计的"阳伞仕女"等纹样（1735—40年间订制），是欧洲设计师为中国窑厂出稿的极端例子 |
| ★产品 | 外销瓷品类："广彩""南京"式样在1780—90年代标准化；欧洲器形（杯、壶、烛台、塔扎、咖啡壶、调味瓶）中国无传统，依寄来的木模与图样仿制；荷兰公司集中采购盘、碗、茶具与咖啡具等日用器 |
| 元素 | 欧洲器形与中国纹样的拼合；纹章瓷的私人定制图案；私商订制瓷的图案由中国画工照随订单附来的法国等地版画临摹 |
| 材料与技术 | 景德镇素胎；广州釉上彩——1772年荷兰公司大班记录"全白器是为了在此（广州）加彩"；1720年代珐琅彩技术成熟后，加彩环节可在口岸完成 |
| ★生产组织与设计媒介 | 跨洋订货—景德镇烧素胎—运至广州按西方需求加彩—出口的链条；订单附详细清单，列明器类、型号、配色、数量与预算，并随附图纸、版画或木模——寄往中国的木模与纹章图样是设计媒介，与1.2工厂内的"图纸→模具师"相比，这里的分离发生在贸易链上。规模：每艘荷兰公司商船可装瓷器20万件以上，广州常同时停泊三四艘，瓷器约占整船货值5%—8%，作为压舱底层保护上层茶叶。随着欧洲瓷厂建立，外销瓷在18世纪下半叶衰落 |
| 委托与使用 | 欧洲贵族与商人的私人定制；荷兰、英国东印度公司作为中介，1690—1728年间荷兰公司一度停购、由私商接手，说明时尚变化快于公司采购体制 |
| 观念与话语 | 中国一侧：蓝浦《景德镇陶录》（1815）卷二记"洋器"——"专售外洋者，商多粤东人，贩去与鬼子互市，式多奇巧，岁无定样"，说明器式由外洋需求决定且逐年变换；欧洲一侧：1772年荷兰东印度公司大班记录"全白器是为了在此加彩"，公司订单文本中"按所附模型与图样制作"的指令——订货方的话语即设计指令 |

### 观念："设计"与"工艺"的分化

只写"观念与话语"一维，材料全部取自以上各表已出现的对象。

1. 定义：工业化前"工艺"覆盖构思与制作全过程，没有独立的"设计"活动。
2. 过程：五节证明分离在四个层面同时发生——生产组织（1.1、1.2）、材料与技术（1.3）、传播媒介（1.4）、委托与使用（1.5）；中国栏证明同一分离也可以发生在贸易链上。
3. 结论：本章结束时"设计"由业主、供稿艺术家、工程师、印刷设计者四方分担，是一个被占据的空位而非职业；参照书列出五类设计者却未说明后果，本书补上：设计获得了独立性，同时失去了对制作的直接控制。
4. 史学提醒：三个现场（克罗姆福德、制针工场、索霍）各自在解决生产问题，"萌发"是多方向、未定型的；以工业革命为起点，依据是设计对象从工艺物转向工业商品，而非英国中心的叙述惯性。
5. 接口：第二章的改革者在这个空位上第一次以"设计"自命；"design"的东亚译介归第二章观念栏。
