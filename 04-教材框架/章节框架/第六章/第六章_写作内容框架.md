# 《现当代设计史》第六章写作内容框架

章题：第六章　北美现代设计的发展。
依据：对话上传的修订版目录；体例同第四、五章——每节先列时段、论点、接口，再按七个维度写案例内容；设计师身份随案例交代，不单列；不编排详细小结、自然段、字数，不设“待补与待核”栏目。案例范围为写作规划，不代表每个细节均已完成原始史料核验。

## 一、全章定位

历史问题：在以大批量生产和消费市场为条件的北美，设计怎样成为一种独立职业，欧洲现代主义在传播中被怎样选择和改写，加拿大与墨西哥又形成了哪些不同于美国的路径。

主体范围：1908年T型车投产至1941年美国参战；加拿大、墨西哥两节延至1940年代，以便呈现各自的形成期。战后北美归9.2。

结构：6.1写美国本土的生产与职业条件；6.2、6.3写欧洲经验的进入与教育化；6.4、6.5写北美另两国；中国栏写留美建筑师回国实践；观念栏综合流线型与计划性废止。本章不把北美写成欧洲现代主义的单纯接收地，企业、广告、博览会与市场在形成设计上同样是主动方。

七个维度为检查工具：作品、产品、元素、材料与技术、生产组织与设计媒介、委托与使用、观念与话语。

## 二、各节写作框架

### 6.1 福特流水线、大生产与美国工业设计

| 项目 | 内容 |
|---|---|
| 时段 | 1908—1939年 |
| 论点 | 流水线生产与年度改款之争催生了独立于制造工程的工业设计职业；职业设计师首先服务于销售竞争而非形式理想。 |
| 接口 | 第一章1.2的分工问题回指一句；流线型与计划性废止的理论综合归本章观念栏；战后汽车造型归9.2。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 高地公园工厂移动装配线（1913）与通用汽车艺术与色彩部（1927）作为两个组织案例；分析前者如何消除产品差异、后者如何重新制造差异。 |
| 产品 | T型车与1927年拉塞尔轿车对照；蒂格的柯达相机、德雷夫斯的西电302电话、洛伊的西尔斯冷点冰箱：分别写价格、外壳统一、使用动作与销售额，不全写成“流线化”。 |
| 元素 | 单一色彩与标准件；年度色彩与车身线条；外壳对机构的包覆。流线型只在交通工具与部分家电中出现，不作为美国全部产品的标签。 |
| 材料与技术 | 可互换零件、移动装配线、冲压钢板、电木与珐琅钢板外壳；说明工艺如何允许外观与机构分离。 |
| 生产组织与设计媒介 | 福特工程团队；通用汽车厄尔领导的企业内部造型部门；盖茨、蒂格、德雷夫斯、洛伊、贝尔·格迪斯等从广告插画、舞台美术、橱窗陈列进入产品外形设计并开设独立事务所，案例中交代他们的来历与客户关系；效果图与模型成为与企业沟通的媒介。 |
| 委托与使用 | 大众消费者与分期付款；大萧条中企业以改款刺激购买；百货公司与邮购目录作为销售渠道。 |
| 观念与话语 | 福特《我的生活与工作》（1922）；斯隆关于“每个钱包、每种用途一辆车”的经营方针；盖茨《产品外观》（1932）、蒂格《今日设计》（1940）；只记话语出处，理论比较归观念栏。 |

### 6.2 欧洲现代主义向北美的传播

| 项目 | 内容 |
|---|---|
| 时段 | 1925—1941年 |
| 论点 | 欧洲现代主义进入北美时经过了博物馆、百货公司和建筑委托的筛选，结果既有“国际风格”的命名，也有装饰艺术的商业化改写。 |
| 接口 | 5.5法国装饰艺术只回指；4.3的流散只接人物到达后的工作；中国栏的留美建筑师在此节不写。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 克莱斯勒大厦（1930）与帝国大厦作为装饰艺术建筑；MoMA“现代建筑：国际展览”（1932）作为命名事件；密斯到美国后的伊利诺伊理工学院校园规划（1939起）与格罗皮乌斯的林肯住宅（1938）作为建筑实践。 |
| 产品 | 1925年巴黎博览会展品的美国巡展与百货公司陈列；弗兰克尔的“摩天楼”家具；多伊奇的美国装饰艺术金属器。 |
| 元素 | 退台式轮廓、锯齿与射线纹样、金属表面；对照MoMA展览归纳的体量、规则性、去装饰三原则。 |
| 材料与技术 | 不锈钢、铝、镀铬、人造材料的建筑与家具应用。 |
| 生产组织与设计媒介 | 大都会博物馆与梅西百货的工业艺术展览；MoMA建筑与设计部的建立；移民建筑师进入大学建筑系（格罗皮乌斯哈佛1937、密斯IIT1938）的职位与委托条件写入案例。 |
| 委托与使用 | 企业总部、百货公司顾客、大学校董与私人业主。 |
| 观念与话语 | 希区柯克、约翰逊《国际风格》（1932）；巴尔的展览前言；此处只说明命名的场合与选择，不在此评判其史学后果。 |

### 6.3 美国现代设计教育的发展

| 项目 | 内容 |
|---|---|
| 时段 | 1933—1945年前后 |
| 论点 | 欧洲教学方法在美国被嫁接到企业赞助、职业培训与大学建制上，形成与魏玛—德绍不同的培养目标。 |
| 接口 | 第四章课程只回指；战后教育与设计研究归9.2与第九章观念栏。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 克兰布鲁克艺术学院校园（沙里宁设计）作为教学与作品一体的案例；新包豪斯学生的材料与摄影练习。 |
| 产品 | 1940—41年MoMA“家居有机设计”竞赛中伊姆斯与小沙里宁的胶合板椅：作为学生身份转向职业的产品案例，生产归9.2。 |
| 元素 | 材料练习、摄影、整体设计与手工艺并存；克兰布鲁克的工艺取向与新包豪斯的实验取向对照。 |
| 材料与技术 | 胶合板模压、摄影与光的实验、纺织与金属工艺。 |
| 生产组织与设计媒介 | 克兰布鲁克（1932年建院）与布思家族赞助；莫霍利—纳吉的新包豪斯（1937）—设计学校（1939）—设计学院（1944）及其芝加哥企业赞助人；阿尔伯斯在黑山学院（1933—49）的基础课；教师从流亡者到大学教员的身份变化放在课程案例中交代。 |
| 委托与使用 | 企业赞助人、艺术家庭、退伍军人培训需求。 |
| 观念与话语 | 莫霍利—纳吉《运动中的视觉》（1947）只作接口提示；克兰布鲁克的工艺与设计并举的办学文本；避免把美国教育写成包豪斯复制。 |

### 6.4 加拿大现代设计

| 项目 | 内容 |
|---|---|
| 时段 | 1920年代—1940年代 |
| 论点 | 加拿大现代设计在国家形象建构、公共机构与资源型工业之间形成，并与英国、美国两种影响并存。 |
| 接口 | 战后加拿大归9.2一句；不扩写加拿大建筑史。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 七人画派相关的国家风景图像进入海报与出版；加拿大太平洋铁路的旅游海报与酒店室内。 |
| 产品 | 加拿大国家铁路与太平洋铁路的车厢、标识与印刷品；战时1940年代的实用家具与国家设计机构的前史。 |
| 元素 | 风景、原住民图像的借用及其争议；装饰艺术与现代主义在公共建筑中的并置。 |
| 材料与技术 | 木材与纸浆工业的产品；铁路与酒店装修。 |
| 生产组织与设计媒介 | 铁路公司内部与委托设计部门；设计教育依附于美术学校；设计师多兼画家、插画家与商业美术人员，案例中说明其供职方式。 |
| 委托与使用 | 国家铁路、旅游机构、政府出版物。 |
| 观念与话语 | 铁路与旅游宣传文本；关于“加拿大风格”的当时讨论。 |

### 6.5 墨西哥现代设计

| 项目 | 内容 |
|---|---|
| 时段 | 1920年代—1940年代 |
| 论点 | 革命后的国家文化政策把壁画、版画与建筑纳入现代设计，形成以公共艺术与民族图像为中心的路径。 |
| 接口 | 战后拉美归9.7；美国移民建筑师在墨西哥的活动不在此扩写。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 里韦拉等壁画运动的公共建筑作品；奥戈尔曼为里韦拉与卡罗设计的住宅工作室（1931—32）作为功能主义建筑案例；人民版画工坊（1937起）的宣传招贴。 |
| 产品 | 版画招贴与传单、国家出版物、手工艺品的现代化改制。 |
| 元素 | 民族历史与劳动者图像、平面化版画语言、裸露混凝土与色彩。 |
| 材料与技术 | 壁画工艺、油毡刻与石印、钢筋混凝土。 |
| 生产组织与设计媒介 | 教育部的壁画委托、人民版画工坊的集体创作制度、建筑师在公共教育计划中的职位；艺术家作为国家雇员与集体工坊成员的身份随案例交代。 |
| 委托与使用 | 革命后政府与教育部、工会与群众组织、城市公众。 |
| 观念与话语 | 壁画运动宣言、人民版画工坊章程、奥戈尔曼关于功能主义的论述。 |

### 中国：留美建筑师与现代建筑的早期实践

| 项目 | 内容 |
|---|---|
| 时段 | 1920—1937年 |
| 论点 | 留美建筑师把布扎体系的训练带回中国，在民族形式的官方要求与现代材料、商业任务之间形成折中的实践，并建立了中国人自己的建筑事务所与学科。 |
| 接口 | 第三章中国栏的实业与博览会、第四章中国栏的图案教育不重述；战时归第八章中国栏；战后建筑制度归第九章中国栏。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 吕彦直中山陵（1925—29）与中山纪念堂；杨廷宝、赵深等在南京、上海的公共建筑；董大酉上海市政府大厦（1933）；童寯、陈植、赵深的华盖事务所作品。 |
| 产品 | 以建筑及其配套家具、室内与标识为对象，不虚构工业量产品。 |
| 元素 | 大屋顶与西式体量的结合、装饰艺术式的立面处理、现代平屋顶的尝试；比较不同委托下的形式选择。 |
| 材料与技术 | 钢筋混凝土、钢结构与传统瓦作的结合；施工图与结构计算的引入。 |
| 生产组织与设计媒介 | 宾夕法尼亚大学布扎训练；回国后的基泰工程司、华盖建筑事务所；中国建筑师学会（1927）；中央大学、东北大学建筑系（1927、1928）。留学生从学生到事务所合伙人与系主任的身份变化在具体项目中交代。 |
| 委托与使用 | 国民政府与地方政府、银行与企业、大学。“首都计划”（1929）与“大上海计划”作为官方委托条件。 |
| 观念与话语 | 《首都计划》关于“中国固有之形式”的规定；中国建筑师学会章程；童寯等关于中国建筑现代化的文章。 |

### 观念：流线型与计划性废止

| 项目 | 内容 |
|---|---|
| 核心问题 | 当设计服务于销售周期，形式更新与使用寿命之间形成怎样的关系？ |
| 分析材料 | 6.1的通用年度改款与独立设计师作品；贝尔·格迪斯《地平线》（1932）；谢尔登与阿伦斯《消费者工程》（1932）提出的“计划性废止”；伦敦1932年小册子《通过计划性废止结束萧条》；MoMA 1934年“机器艺术”展对“纯粹”机器形式的提倡作为对照。 |
| 分析任务 | 区分空气动力学依据与风格化流线；区分“功能性废止”“心理性废止”与质量性废止；指出流线型在大萧条中既是销售策略也是对技术进步的公共想象。 |
| 表述限制 | 不把流线型简化为“虚假装饰”，也不把计划性废止写成单一人物的发明；不以战后帕卡德《废物制造者》（1960）的批判倒推1930年代人的意图，该批判归9.2或第十章观念栏。 |
| 接口 | 接第五章观念栏的现代主义与装饰之争；向9.2消费社会与11.7可持续设计开放。 |

## 五、编写依据说明
