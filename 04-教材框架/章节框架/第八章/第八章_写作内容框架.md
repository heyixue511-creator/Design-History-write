# 《现当代设计史》第八章写作内容框架

章题：第八章　第二次世界大战时期的设计。
依据：对话上传的修订版目录；体例同第四至七章——每节先列时段、论点、接口，再按七个维度写案例内容；设计师身份随案例交代，不单列；不编排详细小结、自然段、字数，不设“待补与待核”栏目。案例范围为写作规划，不代表每个细节均已完成原始史料核验。

## 一、全章定位

历史问题：当国家成为最大的委托方，设计怎样被纳入宣传、动员、信息与生产体系，这一经历又给战后设计留下了哪些机构、方法和人员。

主体范围：1931年“九一八”至1945年；欧洲以1933年纳粹执政与1939年开战为节点；美国以1941年参战为节点。不把战争写成设计史的中断，而写成国家委托条件下的集中实验期。

结构：8.1写宣传图像；8.2写国家动员的制度与象征工程（含轴心国与同盟国）；8.3写信息、标识与伪装；8.4写战时生产中的材料替代、标准化与军需产品；中国栏写抗战木刻与视觉传播；观念栏综合设计与国家宣传。各国材料在节内并列而非分国叙述，避免同一国家在四节中重复出现背景。

七个维度为检查工具：作品、产品、元素、材料与技术、生产组织与设计媒介、委托与使用、观念与话语。

## 二、各节写作框架

### 8.1 战争宣传与视觉动员

| 项目 | 内容 |
|---|---|
| 时段 | 1933—1945年 |
| 论点 | 各交战国都把海报、电影和展览作为动员工具，但在图像语言上延续了各自战前的商业与先锋传统，并由国家宣传机构统一发包。 |
| 接口 | 第一次世界大战宣传归3.5一句；日本战前商业图案归7.3；中国木刻归中国栏。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 美国战时新闻局海报（本·沙恩的“This is Nazi brutality”1942、米勒的“We Can Do It!”1943为西屋内部海报、洛克威尔“四大自由”1943）；英国新闻部海报（阿布拉姆·盖姆斯的ATS招募海报1941及其争议）；苏联塔斯之窗（1941起）；德国宣传部海报与《意志的胜利》（1935）；日本《FRONT》杂志（1942起，东方社）与《NIPPON》对外宣传。 |
| 产品 | 海报、传单、宣传画册、外宣杂志、新闻纪录片。 |
| 元素 | 美国的商业插画写实与摄影蒙太奇并存；英国的现代主义构图；苏联的手工模版与讽刺画传统；德国的古典英雄身体；日本《FRONT》对苏联《USSR in Construction》版式的借鉴。 |
| 材料与技术 | 胶印与丝网印刷、模版手绘复制（塔斯之窗）、照相凹版画册、电影。 |
| 生产组织与设计媒介 | 美国战时新闻局图像部（1942—45）及其与广告业的合作、战时广告委员会；英国新闻部与盖姆斯作为“官方战争海报设计师”的军职；苏联塔斯社；德国宣传部；日本内阁情报局与东方社（原弘、木村伊兵卫）。设计师以军职、机关雇员或广告公司承包人三种身份出现，案例中写明。 |
| 委托与使用 | 国家宣传机构、企业内部动员（西屋）、海外受众（《FRONT》《NIPPON》）。 |
| 观念与话语 | 战时新闻局内部关于“写实还是现代”的争论（1943年广告派取代设计派）；盖姆斯“以最少手段取最大意义”；只记话语出处，分析归观念栏。 |

### 8.2 国家动员与设计

| 项目 | 内容 |
|---|---|
| 时段 | 1933—1945年 |
| 论点 | 国家把设计纳入制度：从德国“劳动之美”与大众汽车计划到英国“实用计划”，设计成为分配资源与塑造公民生活方式的工具，而不只是宣传图像。 |
| 接口 | 魏玛时期德国设计归5.1；美国生产动员归8.4；战后福利国家设计归9.3。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 纽伦堡党代会会场（施佩尔）与“光之穹顶”；1937年巴黎博览会德国馆与苏联馆对峙；意大利EUR规划（1937—42）；大众汽车城（沃尔夫斯堡，1938）。 |
| 产品 | KdF-Wagen（保时捷设计，1938，储蓄计划售车但战前未交付）；德国“人民收音机”VE301（1933）；英国实用家具（1942起，拉塞尔主持的设计小组）与实用服装（1941起）；意大利的自给自足材料产品。 |
| 元素 | 新古典纪念性与“人民产品”的朴素外形并存；实用家具的标准件与有限样式；标识（卐、法西斯束棒、实用标志CC41）。 |
| 材料与技术 | 实用家具的硬木限额与胶合板；人民收音机的电木壳；汽车的风冷发动机与钢板冲压。 |
| 生产组织与设计媒介 | 德国劳工阵线下的“劳动之美”办公室（1934起）与“力量来自欢乐”组织；英国贸易委员会实用家具咨询委员会（1942）；意大利法西斯的国家工艺机构；设计者作为国家机关雇员（施佩尔、拉塞尔小组）与国家合同承包人（保时捷）两类身份在案例中区分。 |
| 委托与使用 | 国家与党组织；通过储蓄计划或配给获得产品的公民；实用家具限售给新婚夫妇与被炸家庭。 |
| 观念与话语 | “劳动之美”的工作场所美化话语；英国实用计划的“好设计惠及大众”论述（拉塞尔）；希特勒关于“人民汽车”的讲话只记出处。 |

### 8.3 战时信息设计、标识与伪装

| 项目 | 内容 |
|---|---|
| 时段 | 1939—1945年 |
| 论点 | 战争把设计推向信息传递与视觉欺骗两个极端：一方面要求在最短时间内被识别，另一方面要求不被识别，两者共同催生了战后信息设计与系统标识的方法。 |
| 接口 | 贝克地铁图归5.4；战后图标系统归9.4与13.3；美国军方人机工程归8.4一句。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 诺伊拉特ISOTYPE在英国战时的健康与经济宣传图表（1940年代）；英国航空识别图卡与美国“飞机识别”训练材料；伦敦交通在灯火管制下的标识调整；塞西尔·比顿等的伪装摄影记录。 |
| 产品 | 识别手册、军用地图、配给证与表格、空袭标识、仪表盘与操作面板。 |
| 元素 | 图表的图形单元与数量对应；飞机轮廓的剪影识别；迷彩的破形图案（dazzle在二战中的延续与改变）；夜间可见性与颜色规范。 |
| 材料与技术 | 军用印刷标准、荧光与反光涂料、迷彩涂装与伪装网、照相制图。 |
| 生产组织与设计媒介 | 诺伊拉特夫妇在牛津的ISOTYPE研究所（1942起）；英国伪装发展与训练中心（法纳姆，1940）集中了艺术家、建筑师与舞台设计师；美国陆军工程兵伪装部门。艺术家与设计师以征召军官或承包研究者身份进入，案例中说明。 |
| 委托与使用 | 军方、新闻部与卫生部、民防组织、前线与后方人员。 |
| 观念与话语 | 诺伊拉特“文字分隔，图像联结”；伪装教材中关于“形、影、光、色、动”的原则只记录文本。 |

### 8.4 战时生产与设计

| 项目 | 内容 |
|---|---|
| 时段 | 1939—1945年 |
| 论点 | 军需生产把标准化、材料替代与大规模组装推到极限，并把工业设计师转为军方承包者，其技术经验成为战后产品的直接来源。 |
| 接口 | 6.1的流水线只回指；伊姆斯夹板夹具在6.3已作教育接口，本节写军方合同；战后产品归9.2、9.3。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 伊姆斯夫妇为海军制作的模压胶合板腿夹板（1942）；威利斯MB/福特GPW吉普（1941）；自由轮（1941起）的预制分段焊接；德哈维兰“蚊”式木制飞机（1940）。 |
| 产品 | 吉普、腿夹板、军用口粮包装、Zippo打火机军用型、尼龙降落伞、Jerrycan油桶（德国1937设计，盟军仿制）。 |
| 元素 | 可互换与可修复的结构、裸露功能件、无装饰的军用外观；标准化涂装与编号。 |
| 材料与技术 | 模压胶合板、尼龙与合成橡胶、铝的配给、焊接替代铆接、预制与分段装配。 |
| 生产组织与设计媒介 | 美国战时生产委员会与军方合同；伊姆斯夫妇成立模压胶合板公司承接海军订单；德雷夫斯、洛伊事务所转为军方承包（德雷夫斯的军用设备、洛伊的军车涂装）；英国的“影子工厂”；苏联工厂东迁；设计师从商业客户转向军方客户的身份变化在案例中交代。 |
| 委托与使用 | 军方与政府采购、前线部队、后方工厂工人（女性劳动力进入）。 |
| 观念与话语 | 战时生产委员会的标准化文件；伊姆斯关于“以最少材料获最大强度”的说明；只记录文本。 |

### 中国：抗战时期的木刻与视觉传播

| 项目 | 内容 |
|---|---|
| 时段 | 1931—1945年 |
| 论点 | 木刻因材料易得、可就地印刷而成为抗战时期最有效的视觉传播手段，画家在流动与分区条件下形成了面向农民与士兵的图像语言。 |
| 接口 | 鲁迅倡导木刻（1931起）在本栏作起点一句；月份牌画家的战时转向归第七章中国栏接口；战后版画归第九章中国栏。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 李桦《怒吼吧！中国》（1935）；古元《减租会》（1943）、彦涵《当敌人搜山的时候》（1943）；力群、胡一川的延安木刻；全国木刻界抗敌协会的《抗战木刻》集。 |
| 产品 | 木刻传单、报纸插图、年画式新木刻（延安1940年起的“新年画”）、《新华日报》等报刊版面。 |
| 元素 | 从欧洲表现主义式黑白对比到吸收民间年画的单线与套色；人物从受难者转为劳动者与士兵；文字与图像的配合。 |
| 材料与技术 | 梨木、枣木板与就地取材的木料；油墨不足时的土法印刷；套色木刻与报纸凸版。 |
| 生产组织与设计媒介 | 全国木刻界抗敌协会（1938，武汉）；鲁迅艺术学院美术系（1938，延安）与鲁艺木刻工作团；重庆与桂林的木刻出版；木刻家作为协会成员、鲁艺教员与部队美术干部的身份随案例交代。 |
| 委托与使用 | 国共两方的宣传部门、报刊、根据地农民与前线士兵；国际展览（1944—45年苏、美展出中国木刻）。 |
| 观念与话语 | 鲁迅《新俄画选小引》等木刻论述；1942年延安文艺座谈会讲话中关于“普及与提高”的论述对木刻的影响只记出处；木刻家关于“向民间年画学习”的文章。 |

### 观念：设计与国家宣传

| 项目 | 内容 |
|---|---|
| 核心问题 | 当国家成为设计的唯一或主要委托方，“好设计”的标准由谁决定，设计师的职业自主性以何种方式被保留或让渡？ |
| 分析材料 | 8.1战时新闻局“写实—现代”之争与盖姆斯的军职；8.2“劳动之美”与英国实用计划的对照；8.3伪装机构中艺术家的集中使用；8.4设计师向军方承包的转移；中国栏木刻的“普及”要求。 |
| 分析任务 | 区分极权国家与民主国家在动员设计上的制度差异与手段相似性；指出“宣传”在当时并非贬义词，而是各国通用的政府职能；说明战时建立的机构（美国的广告委员会、英国的工业设计委员会1944、ISOTYPE研究所）如何直接转为战后设计体制。 |
| 表述限制 | 不把德国设计一概写为“纳粹美学”，也不把同盟国宣传写成单纯的真相传播；不以战后的道德判断替代对当时委托关系的分析；不把中国木刻写成单一政治阵营的产物。 |
| 接口 | 接第六章观念栏的商业委托问题；向第九章观念栏“设计的科学化”与9.1民族独立国家的设计开放。 |

## 五、编写依据说明

美国战时新闻局采用美国国家档案馆与国会图书馆海报藏品；英国采用帝国战争博物馆与V&A“实用计划”资料；德国采用德国历史博物馆与大众汽车档案；苏联采用塔斯之窗相关展览图录；日本采用东京都写真美术馆《FRONT》研究与原弘资料；ISOTYPE采用雷丁大学奥托与玛丽·诺伊拉特档案；伊姆斯采用伊姆斯事务所与维特拉设计博物馆资料；中国栏采用中国美术馆、延安鲁艺旧址藏品与李允经等抗战木刻研究。引文与年份须对应原始出处，不以概括性网页替代。
