# 《现当代设计史》第十二章写作内容框架

章题：第十二章　数字技术与设计生产方式的转变。
依据：对话上传的修订版目录；体例同第四至十一章——每节先列时段、论点、接口，再按七个维度写案例内容；设计师身份随案例交代，不单列；不编排详细小结、自然段、字数，不设“待补与待核”栏目。案例范围为写作规划，不代表每个细节均已完成原始史料核验。

## 一、全章定位

历史问题：计算机从研究机构的工具变为设计师桌面上的日常工具，这一变化如何改变了设计的生产流程、技能分工、职业边界与产品形态。

主体范围：1963年Sketchpad至2000年代中期；12.1从交互图形的起源起，12.5延至2000年代的数字产品；网络、界面与交互的使用端归第十三章，人工智能与生成式设计归第十四章。

结构：12.1写工具革命的技术与机构起源；12.2写桌面出版对平面生产的改造；12.3写数字字体与图像；12.4写软件与流程（CAD、CAM、协作）；12.5写数字技术与产品设计（含数字产品本身）；中国栏写汉字激光照排与中文数字字库；观念栏综合工具、技能与职业的重组。本章以“生产方式”为主线，每节都要回答工具改变了谁的工作，而不是罗列软件版本。

本章与第十三章的边界：本章写设计如何被生产（工具、流程、字体、CAD、产品硬件与系统软件的设计），第十三章写数字媒介如何被使用与设计（网页、界面、信息、体验、平台）。Macintosh在12.1写工具与图形界面的生产条件，13.2写其界面作为交互设计对象。

七个维度为检查工具：作品、产品、元素、材料与技术、生产组织与设计媒介、委托与使用、观念与话语。

## 二、各节写作框架

### 12.1 计算机与设计工具革命

| 项目 | 内容 |
|---|---|
| 时段 | 1963—1985年 |
| 论点 | 交互式图形计算机从军事与大学研究中产生，经施乐PARC与苹果转为个人工具，使“直接操作图形”成为设计工作的新基础。 |
| 接口 | 图形界面作为交互设计对象归13.2；桌面出版归12.2；CAD在工程中的起源在此只一句，流程归12.4。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 萨瑟兰Sketchpad（1963，MIT林肯实验室TX-2）；恩格尔巴特“所有演示之母”（1968，鼠标与超文本）；施乐Alto（1973）与Star（1981）；苹果Lisa（1983）与Macintosh（1984）。 |
| 产品 | Macintosh 128K及其MacPaint、MacWrite；鼠标（恩格尔巴特原型—施乐—苹果的Hovey-Kelley设计1980）；早期图形工作站（Sun、SGI）作为12.4接口。 |
| 元素 | 位图屏幕、窗口与图标、所见即所得（WYSIWYG）、桌面隐喻。 |
| 材料与技术 | 光笔与CRT、位图显示、鼠标机械结构、激光打印预示（PARC 1971）。 |
| 生产组织与设计媒介 | ARPA资助的大学实验室、施乐PARC（1970）、苹果与青蛙设计的硬件合作（11.2已写外包，此处写工具属性）；图形界面的设计者（凯、戈德堡、苏珊·凯尔的Mac图标）作为研究员与软件公司雇员的身份在案例中交代。 |
| 委托与使用 | 军方与研究基金、企业办公市场（Star失败）、个人用户（Macintosh）。 |
| 观念与话语 | 布什《诚如所思》（1945）作为前史一句；恩格尔巴特“增强人类智能”（1962）；凯“Dynabook”（1972）；苹果1984年广告；记录文本。 |

### 12.2 桌面出版与数字视觉生产

| 项目 | 内容 |
|---|---|
| 时段 | 1985—1995年 |
| 论点 | PostScript、激光打印与排版软件把排字、制版与设计三个行业的分工压缩到一张桌面上，平面设计师获得了生产控制权，也承担了原属排字工的技能。 |
| 接口 | 10.6已写数字工具相遇前的实验平面，此处承接《埃米格雷》1985年后的数字实践；字体归12.3。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 《埃米格雷》杂志1985年起的Macintosh排版（范德兰斯与利科）；格雷曼《Design Quarterly》133期“Does It Make Sense?”（1986）；卡森《Ray Gun》（1992—95）的“非可读”排版；布罗迪“Fuse”项目（1991起）作为12.3接口。 |
| 产品 | Aldus PageMaker（1985）、苹果LaserWriter（1985）与Adobe PostScript（1984）构成的“桌面出版”三件套；QuarkXPress（1987）；Adobe Illustrator（1987）与Photoshop（1990）。 |
| 元素 | 位图字体的低分辨率美学（埃米格雷早期）、层叠与变形、图层合成图像。 |
| 材料与技术 | PostScript页面描述语言、300dpi激光打印、扫描仪与图像处理、照排机输出。 |
| 生产组织与设计媒介 | Adobe（1982）、Aldus、Quark作为新的“工具制造商”；排字行业的萎缩（美国排字工会的衰落）；设计工作室内部完成排版；设计师作为自我排版者、软件早期采用者与杂志发行人的身份在案例中交代。 |
| 委托与使用 | 杂志与出版、企业内部文印（桌面出版的最大市场）、独立设计师。 |
| 观念与话语 | 范德兰斯与利科关于“工具的本真性”的论述；《埃米格雷》与马西莫·维涅利1991年的“垃圾”论争；记录文本，分析归观念栏。 |

### 12.3 数字字体与数字图像

| 项目 | 内容 |
|---|---|
| 时段 | 1975—2005年 |
| 论点 | 字体从金属与照相制品变为可编辑的数字文件，字体设计从铸字厂的集体工艺变为独立设计师的小型产业，同时数字图像以像素与矢量重新定义了“图”的生产。 |
| 接口 | 中文字库归中国栏；网页字体与屏幕排版归13.1；Helvetica与Univers归9.4。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 克努斯Metafont（1977）作为算法字体先声；利科Emperor、Oakland位图字体（1985）与Mrs Eaves（1996）；弗鲁提格与Linotype的数字化；Verdana与Georgia（卡特，1996，微软屏幕字体）；Bitstream（1981）作为首家数字字体公司。 |
| 产品 | PostScript Type 1字体（1984）、TrueType（1991，苹果与微软）、OpenType（1996起）；Fontographer（1986）作为字体设计工具；Photoshop图层（1994）与矢量图形的普及。 |
| 元素 | 字形轮廓的贝塞尔曲线、hinting与屏幕像素、字体家族的程序化扩展；图像的像素化与无限复制。 |
| 材料与技术 | 轮廓字体格式、屏幕渲染、扫描与数码摄影（1990年代后期）。 |
| 生产组织与设计媒介 | 字体公司转型（Linotype、Monotype的数字化与合并）、独立数字字体厂（Emigre Fonts 1985、FontShop 1989、House Industries）；字体设计师从铸字厂雇员变为独立发行人与授权者；图像生产从暗房到软件。 |
| 委托与使用 | 操作系统厂商（微软、苹果）、出版与广告、普通用户首次成为字体选择者。 |
| 观念与话语 | 卡特关于“为屏幕而非纸张设计字体”的论述；《埃米格雷》对“字体复兴”的立场；记录文本。 |

### 12.4 软件与设计生产流程

| 项目 | 内容 |
|---|---|
| 时段 | 1980—2005年 |
| 论点 | CAD/CAM、三维建模与数字原型把设计、工程与制造的数据连接为一条链，改变了手绘—模型—模具的传统流程，并使复杂曲面与跨国协作成为可能。 |
| 接口 | 11.2的价值链只回指；12.5写由此产生的产品；参数化与生成式设计归14.4。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | 盖里毕尔巴鄂古根海姆（1997）采用CATIA（航空软件）实现曲面，11.3已写建筑意义，此处写流程；波音777（1994）全数字化设计；罗斯·洛夫格罗夫与扎哈·哈迪德事务所的数字曲面作为设计流程案例。 |
| 产品 | AutoCAD（1982）、Alias（1983，工业设计曲面）、Pro/ENGINEER（1987，参数化）、SolidWorks（1995）、Rhino（1998）；3D Systems立体光刻机SLA-1（1987）作为快速原型起点。 |
| 元素 | NURBS曲面、参数化约束、数字渲染替代效果图。 |
| 材料与技术 | 立体光刻、FDM（1989）、数控铣削、CAD数据直接驱动模具。 |
| 生产组织与设计媒介 | 软件公司（Autodesk、PTC、Dassault）；企业内部设计与工程的数据共享；跨国团队的文件传递；设计师从手绘与油泥模型转向建模，模型工匠与制图员岗位的消失；汽车业的数字造型流程（福特、通用1990年代）。 |
| 委托与使用 | 航空与汽车业、建筑事务所、工业设计咨询公司。 |
| 观念与话语 | 盖里关于“计算机让我们回到工匠与建造者的直接关系”的论述；米切尔《比特之城》（1995）一句；记录文本。 |

| 产品 | 半透明塑料外壳（iMac）、点击滚轮（iPod）、单色LCD与按键布局（诺基亚）；Palm Pilot（1996）作为手持设备接口。 |

### 中国：汉字激光照排与中文数字字库

| 项目 | 内容 |
|---|---|
| 时段 | 1974—2005年 |
| 论点 | 汉字进入计算机排版的技术难题由国家项目解决，“告别铅与火”改变了中国出版印刷的生产方式，中文数字字库随后成为连接传统书法、铅活字与屏幕显示的新设计领域。 |
| 接口 | 第十一章中国栏的设计行业重建只回指；汉字在界面与网络中的显示归第十三章中国栏；拼音输入法在此只一句。 |

| 维度 | 写作案例内容 |
|---|---|
| 作品 | “748工程”（1974年立项的汉字信息处理系统工程）；王选主持的华光系统（1979年输出第一张汉字激光照排样张，1985年华光III型投入《经济日报》使用）；方正系统（1988年起）；1987年《经济日报》成为首家告别铅字的报纸。 |
| 产品 | 华光IV型与方正激光照排系统；方正字库（1990年代，以北京新华字模厂字稿为基础的宋体、黑体、仿宋、楷体数字化）；汉仪字库（1993）；GB2312（1980）与GBK（1995）编码标准；Windows 3.2与95中文版的系统字体。 |
| 元素 | 汉字轮廓的参数化压缩（王选的轮廓加参数描述方法）、字库中的书法体数字化（舒同体、启功体等）、点阵与屏幕字形。 |
| 材料与技术 | 高倍率信息压缩、激光照排机、字模厂字稿的扫描与矢量化、输入法与编码。 |
| 生产组织与设计媒介 | 国家计委与电子工业部立项、北京大学计算机研究所、潍坊计算机公司、北京新华字模厂；北大方正（1988）与汉仪的公司化；字模厂老一代字体设计师（铅字时代的字稿绘制者）与计算机研究人员的协作，设计者身份从字模厂工人到字库公司字体设计师的转变在案例中交代。 |
| 委托与使用 | 国家出版印刷系统、报社与出版社、操作系统厂商、普通用户。 |
| 观念与话语 | 王选关于“跳过第二代、第三代直接研制第四代激光照排”的决策论述；“告别铅与火，迎来光与电”口号；记录文本，分析归观念栏。 |

### 观念：工具、技能与设计职业的重组

| 项目 | 内容 |
|---|---|
| 核心问题 | 当工具把多个行业的技能压缩到一个人的桌面，设计职业的边界如何重划，被取消的技能去了哪里，新的依赖（软件公司）又带来了什么？ |
| 分析材料 | 12.1工具的研究机构起源；12.2排字工的消失与设计师的自我排版；12.3字体设计的个体化与格式标准的厂商控制；12.4模型工匠与制图员的消失、软件公司的标准化力量；12.5软硬件协作；中国栏字模厂工人向字库设计师的转变。 |
| 分析任务 | 区分三种重组：技能合并（排版）、技能转移（建模替代手绘）、技能新生（界面）；指出“去技能化”与“再技能化”同时发生；说明软件默认设置与格式标准对形式的隐性影响；比较第一章“构思与制作分离”与本章“制作回到构思者手中”的关系，但指出这一回归以对软件厂商的依赖为代价。 |
| 表述限制 | 不把数字化写成单纯的解放或单纯的去技能化；不以第十四章的AI议题倒推本章；不把“工具决定风格”作为结论，而以案例说明工具与设计者选择的互动。 |
| 接口 | 接第一章观念栏“设计与工艺的分化”、第十一章观念栏；向第十三章观念栏“以用户为中心”与第十四章观念栏“从产品到系统”开放。 |
