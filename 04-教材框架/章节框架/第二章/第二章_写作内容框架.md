## 二、各节写作框架

### 2.1　1851年万国工业博览会与工业产品的趣味之争

| 时段 | 重点维度 | 论点 | 接口与去向 |
|---|---|---|---|
| 1837—1852 | 产品（被批评的展品）；生产组织与设计媒介 | 博览会把工业产品的装饰问题变成公开争论，批评针对的是具体的形式错误 | 水晶宫建筑只写一段；博览会制度的扩散归第三章；南肯辛顿体系建制归第四章一句 |

| 维度 | 案例内容 |
|---|---|
| 作品 | 水晶宫（1851）：帕克斯顿是园丁出身的温室设计者，以预制铸铁与玻璃构件在九个月内建成；欧文·琼斯任室内配色，以红、蓝、黄原色涂饰铁构。科尔以"费利克斯·萨默利"之名设计、明顿制作的茶具（1846）：公务员兼出版人的科尔匿名参加艺术协会竞赛获银奖，是改革者亲自示范"好设计"的作品 |
| ★产品 | 被批评的展品：伯明翰与谢菲尔德的电镀餐具、机制地毯、三维错觉壁纸、过度装饰的铸铁家具；萨默利艺术制品（1847—约1850）邀画家、雕塑家为日用品供稿，产品署设计者名 |
| 元素 | 被批评的形式错误：壁纸与地毯上的三维错觉花卉、把动物形体用作器皿把手、装饰掩盖结构；改革派提出的"平面上只用平面纹样"原则 |
| 材料与技术 | 埃尔金顿电镀（1840年专利）使镀银器大众化；古塔胶与纸浆压制可仿任何雕刻；水晶宫的模数化预制构件与现场装配 |
| ★生产组织与设计媒介 | 政府设计学校（1837，萨默塞特府）作为改革的教育端；科尔与雷德格雷夫主编《设计与制造杂志》（1849—52），每期附织物、壁纸实样并逐件点评，壁纸绿色"过于粗糙"之类评语直接面向制造商；1851年博览会的分类与评审制度；1852年马尔伯勒府"错误原则"陈列室（时称"恐怖屋"）把被批评的商品公开展出 |
| 委托与使用 | 皇家委员会与政府；600万观众作为被教育的公众；制造商作为被批评对象与潜在客户 |
| 观念与话语 | 科尔1846年参赛说明：在廉价所允许的范围内尽可能美观；《设计与制造杂志》社论（1849）；沃纳姆《作为趣味课程的博览会》（1851）；雷德格雷夫《设计补充报告》（1852）论装饰应服从用途 |

### 2.2　维多利亚时期的设计与装饰

| 时段 | 重点维度 | 论点 | 接口与去向 |
|---|---|---|---|
| 1840—1880 | 产品；元素 | 改革者批评的另一面，是中产阶级市场对装饰的真实需求；历史主义折衷是制造业的正常策略 | 消费结构承接1.5，止于1880；百货公司在本节出现；德莱塞只在本节 |

| 维度 | 案例内容 |
|---|---|
| 作品 | 普金为威斯敏斯特宫设计的家具与明顿釉面砖（1840年代）：建筑师普金以哥特复兴为唯一正确风格，1851年"中世纪庭院"为其展品（2.1只提一句）。欧文·琼斯《装饰法则》（1856）：建筑师以一百幅彩色石印图版把各文明纹样编成可供制造商取用的纹样库 |
| ★产品 | 波特斯公司滚筒印花壁纸（1839年起机器印刷，价格降至手工印花的数分之一）；詹宁斯与贝特里奇的伯明翰纸浆家具（1825年专利嵌珠母工艺，1850年代为主要生产商）；明顿釉面砖；电镀餐具；德莱塞1870年代起为多家制造商（明顿、科尔曼、哈金等）设计的金属器与陶瓷，首次以独立设计师名义批量供稿 |
| ★元素 | 历史风格并列：哥特、洛可可、文艺复兴复兴混用于同一室内；自然主义写实纹样与改革派"平面化"原则之争；苯胺染料带来的紫红、品绿等新色 |
| 材料与技术 | 滚筒印花机（1839）；纸浆压制与嵌珠母；珀金苯胺紫（1856）开启合成染料；电镀；机制刨花板家具 |
| 生产组织与设计媒介 | 政府设计学校的课程（戴斯的纹样临摹法）；《装饰法则》作为制造商的纹样来源；德莱塞的独立工作室（1860年代起，雇助手为多家厂商出稿）；怀特利百货（1863，伦敦西区）把各类商品集中陈列 |
| ★委托与使用 | 中产家庭室内：客厅、餐厅的成套陈设；百货公司与分期付款；殖民地与美国出口市场 |
| 观念与话语 | 普金《尖拱建筑或基督教建筑的真实原则》（1841）："建筑物不应有任何非为方便、结构或得体所必需的特征"；琼斯《装饰法则》三十七条命题（1856）："形式之美来自线条的流动"；德莱塞《装饰设计原则》（1873）论装饰应"服从材料与用途"；伊斯特莱克《家居趣味提示》（1868）劝中产读者拒绝过度装饰 |

### 2.3　拉斯金、莫里斯与"工艺美术"运动

| 时段 | 重点维度 | 论点 | 接口与去向 |
|---|---|---|---|
| 1849—1896 | 作品；生产组织与设计媒介 | 对工厂分工的回应是让设计者重新成为制作者 | 直接回应第一章观念栏的"分化"；莫里斯的政治活动只一句；运动的传播归2.4 |

| 维度 | 案例内容 |
|---|---|
| ★作品 | 红屋（1859，韦伯设计，莫里斯自用）；"格子"（1862）、"雏菊"（1864）壁纸；凯姆斯科特出版社《乔叟作品集》（1896，莫里斯设计字体与边饰、伯恩—琼斯插图）。莫里斯本人是诗人兼企业主，亲手学习染色、织造与印书 |
| 产品 | 莫里斯公司的壁纸、印花棉布、刺绣、彩绘玻璃、"萨塞克斯"系列椅（1860年代起，据乡村座椅改良，由外协工坊生产）；凯姆斯科特出版的五十余种书 |
| 元素 | 平面化的自然纹样：枝叶缠绕、无透视、重复单元；中世纪手法的再现；结构外露 |
| 材料与技术 | 植物染料与靛蓝拔染（莫里斯拒用苯胺染料）；手工木版印花；手织挂毯与地毯；手摇印刷机与手工纸（凯姆斯科特） |
| ★生产组织与设计媒介 | 莫里斯—马歇尔—福克纳公司（1861，七名合伙人，艺术家合股）→莫里斯公司（1875，莫里斯独资）；默顿修道院工场（1881，染、织、印、玻璃集中一处）；设计师手绘图样直接进作坊，莫里斯本人在染缸旁工作；梅·莫里斯1885年起主持刺绣部 |
| 委托与使用 | 中上阶层客户与教堂委托（彩绘玻璃）；1880年代起为王室与贵族宅邸装修；莫里斯自责产品只服务于富人 |
| 观念与话语 | 拉斯金《威尼斯之石》"哥特的本质"（1853）："把人分成若干段……只造针头与钉尖"；莫里斯《次要的艺术》（1877年演讲）；《生活之美》（1880）："家中不要有你不知其有用或不觉其美的东西"；莫里斯1883年起的社会主义演讲只引一句"为少数人的艺术我不要" |

### 2.4　"工艺美术"运动的传播与转化

| 时段 | 重点维度 | 论点 | 接口与去向 |
|---|---|---|---|
| 1880—1910 | 生产组织与设计媒介；产品 | 运动离开英国后，"手工"理想被转化为行会、学校与商业企业三种形态 | 日本民艺归7.4；制造联盟成立（1907）归3.2，本节止于穆特修斯《英国住宅》 |

| 维度 | 案例内容 |
|---|---|
| 作品 | 阿什比手工艺行会的银器（1890年代—1900年代，建筑师阿什比设计、行会工匠制作）；沃伊齐壁纸与织物（建筑师为埃塞克斯公司等供稿）；格林兄弟甘布尔住宅（1908，帕萨迪纳）；里默施密德为德累斯顿工坊设计的"机器家具"（1906） |
| ★产品 | 斯蒂克利"工匠"家具（1901年起，纽约伊斯特伍德工厂，机器下料、手工装配，明码标价）；罗伊克罗夫特（1895，东奥罗拉）的书籍与家具；利伯蒂"Cymric"银器（1899年起）：伯明翰哈瑟勒公司机器旋压、冲压后手工修饰，设计者（诺克斯等）一律不署名，以商店品牌出售 |
| 元素 | "诚实结构"：榫卯外露、素面橡木、锻打痕迹保留；凯尔特缠结纹（诺克斯）；平屋顶与宽檐（格林兄弟） |
| 材料与技术 | 熏橡木、手工锻铜；机制银器的旋压与冲压；德国工坊的机器刨切与标准件 |
| ★生产组织与设计媒介 | 百年行会（1882，麦克默多）；手工艺行会（1888，伦敦东区，1902年迁奇平卡姆登，1908年解散）；工艺美术展览协会（1888，首次以"工艺美术"命名）；斯蒂克利工厂与《工匠》杂志（1901—16）；利伯蒂—哈瑟勒合伙（1898）；德累斯顿工坊（1898）与慕尼黑联合工坊（1898）；赫勒劳田园城市（1909） |
| 委托与使用 | 英国中产与教堂；美国中西部中产家庭（《工匠》杂志邮购图纸）；德国改革派中产 |
| 观念与话语 | 阿什比《竞争性工业中的手工艺》（1908）：承认手工艺无法与机器竞争，"现代文明依赖机器"；斯蒂克利《工匠》创刊词（1901）论"简单、诚实的家具"；穆特修斯《英国住宅》（1904—05）向德国介绍英国住宅与工艺美术；里默施密德论"机器家具"是"由机器精神产生的家具"（1906） |

### 2.5　"新艺术"运动：反历史主义与整体设计

| 时段 | 重点维度 | 论点 | 接口与去向 |
|---|---|---|---|
| 1890—1905 | 作品；元素 | 第三种答案是放弃历史风格，以自然形态和整体设计统一建筑、家具与平面 | 只写曲线派；格拉斯哥、维也纳、分离派全归3.1；利伯蒂织物只作零售一句 |

| 维度 | 案例内容 |
|---|---|
| ★作品 | 奥尔塔塔塞尔公馆（1893，布鲁塞尔）：建筑师统一设计楼梯、铁艺、壁画、灯具；吉马尔巴黎地铁入口（1900）：铸铁标准构件可组合成多种亭式；穆夏《吉斯蒙达》海报（1894年底—1895年初）：画家穆夏为女演员伯恩哈特作海报后转为海报设计者；高迪巴特略之家（1904—06） |
| 产品 | 加莱与多姆的玻璃器（南锡）；马若雷勒家具；蒂法尼的"法夫赖尔"玻璃与灯具（纽约）；宾"新艺术之家"出售的家具与织物 |
| ★元素 | 鞭绳线、植物茎叶形态、不对称；整体设计：从建筑到门把手的同一套曲线 |
| 材料与技术 | 铸铁与锻铁（奥尔塔、吉马尔）；多层套色玻璃蚀刻（加莱）；彩色石版海报（穆夏、谢雷） |
| 生产组织与设计媒介 | 宾1895年12月在巴黎开设"新艺术之家"画廊，以经销商身份组织设计师并命名运动；南锡派（1901，加莱任会长）；地铁入口由吉马尔设计、工厂铸造标准件；《潘》《青年》等杂志传播 |
| 委托与使用 | 新兴资产阶级私宅（塔塞尔、索尔维、范·埃特维尔德）；市政（巴黎地铁公司）；剧院与商业海报委托；百货公司与画廊顾客 |
| 观念与话语 | 凡·德·威尔德《清除艺术》（1894）主张取消"大艺术"与"小艺术"之分；宾《美国的艺术文化》（1895）；加莱1900年博览会评审报告论以自然为唯一装饰来源；吉马尔自称"建筑—艺术家" |

| 观念与话语 | 冯桂芬《校邠庐抗议》"采西学议"（1861）："以中国之伦常名教为原本，辅以诸国富强之术"；左宗棠1866年奏设船政："欲防海之害而收其利，非整理水师不可；欲整理水师，非设局监造轮船不可"；徐寿1867年向曾国藩建议四项，首为翻译书籍 |

### 观念：从design到"图案"——设计概念的东亚译介

只写"观念与话语"一维，材料取自以上各表已出现的文本，另加译名史的直接证据。

1. 定义：本章英国的"design"指装饰与形式原则——科尔、琼斯、德莱塞的用法都在"装饰如何正确"的范围内，与制造分离。
2. 过程：该词经日本译为"図案"，1896年东京美术学校设"図案科"，词义落在纹样与图样；再传入中国成为"图案"，偏向平面纹样。与此同时，中国栏里洋务工厂的制图以"绘图""绘事"为名，属于工程系统。
3. 结论：东亚接受"设计"时把它拆成两半——美术系统的"图案"与工程系统的"绘图"，这一分裂在第四章中国栏（图案科归美术学校）中成为建制，并延续到20世纪中叶。
4. 史学提醒：不把"图案"视为误译；它准确对应了本章英国改革者所理解的design（装饰原则），只是未包含第一章已出现的工厂设计岗位与工程师的形态决策。
5. 接口：第四章中国栏接续学校与课程；第三章观念栏接续"标准化与功能主义"。
