# 00_方法与规则

**适用范围**：本目录（知识涌现分析 00-04）针对 Bill Gaver & Heather Martin《Alternatives: Exploring Information Appliances through Conceptual Design Proposals》（源文件 `00-paper_clean\Alternatives：《exploring information appliances through Bill Gaver; Heather Marti_clean.md`，行号 L### 以该 clean 版为准，全文 228 行）执行知识涌现分析。
**方法定位**：纯语义分析（不写代码、不做统计程序处理），全部判定基于逐行阅读原文；行号证据必须与原文实际内容对应。

---

## 一、层级定义

分析按三层递进组织：

1. **知识元（Knowledge Element）**：论文中的六类实体——人物、著作/作品、概念、机构、地点、事件。每个知识元是一个语义节点，承载论文中的具体载荷（"做什么、指什么、为何存在"）。本论文的知识元清单见 `01_知识元语意分析.md`。
2. **Topic（主题簇）**：知识元之间由 9 种语义链接连成强连通簇；簇内链接密度高、跨簇链接稀疏的簇即一个 Topic。本论文识别出 9 个 Topic（见 `03_知识涌现计算.md`）。
3. **Theme（高层语义域）**：若干 Topic 共享的更高层语义域（论文的主旨功能区）。本论文聚合为 4 个 Theme（见 `03_知识涌现计算.md`）。

## 二、9 种语义链接判定标准

链接是有方向的（除对称类型外），方向由语义关系决定。每条链接必须有原文行号证据。

| # | 类型 | 符号 | 判定标准（判据） | 本文实例 |
|---|---|---|---|---|
| 1 | 因果 | → | A 是 B 的原因/使 B 成为可能；原文出现"because / as a way of / to allow / leads to"类表述 | 数字技术迁入日常生活 → 期待其形态功能价值扩展（L21） |
| 2 | 条件 | ⇒ | B 的成立以 A 为前提；原文出现"if / when / only if / depends on"类表述 | 提案有效（唤起讨论）⇒ 具体性与开放性平衡（L162） |
| 3 | 对比 | ↔ | A 与 B 对立/互为反例；原文出现"unlike / on the other hand / instead / contrary to"类表述 | 科幻 ↔ 价值虚构（L64） |
| 4 | 隶属 | ⊂ | A 是 B 的子类/组成部分；原文出现"such as / including / for instance / a kind of"类表述 | Data Lamp ⊂ 印象式显示提案（L70） |
| 5 | 时序 | ≻ | A 在 B 之前发生/是 B 的前提步骤；原文出现"first / then / in order to / subsequently"类表述 | 创作提案（L158）≻ 以提案引发对话（L160） |
| 6 | 空间共现 | ≈ | A 与 B 在同一场域/同一作品中共存；图文并置或同一小节并置 | (De)Tour Guide 与城市空间共现（L52-58） |
| 7 | 属性 | : | A 具有属性 B；B 描述 A 的特征 | 信息家电 : 单一功能、简洁优雅（L23） |
| 8 | 论证支撑 | ⇐ | A 为 B 的论证提供支撑（证据/谱系/例证）；A 支撑 B | Carroll & Kellogg 理论枢纽论 ⇐ 提案作为假设性陈述（L166） |
| 9 | 同域 | ∼ | A 与 B 同属一个讨论域（无上述明确关系但共享议题） | Impressionistic Displays ∼ Diversions（同属替代价值域，L68-99） |

## 三、涌现指标

| 指标 | 定义（语义版） | 计算/判定方式（手工语义判定） |
|---|---|---|
| 节点度 k | 某知识元直接相连的链接数 | 在链接清单（`02_语义链接网络.md`）中统计每个知识元出现的链接条目数 |
| 桥接值 b | 某知识元连接的不同 Topic/Theme 数 | 统计该知识元跨簇链接数；桥接值高 = 连接 ≥2 个 Topic |
| 簇识别 | 强连通簇：簇内任意两节点经有向路径互通 | 按链接方向追踪可达性；实际判定以"簇内双向/循环链接 + 高密度"为近似 |
| 内聚度 C | 簇内实际链接数 / 簇内可能链接数（完全图） | C = E / (N(N-1)/2)，E 为簇内链接数，N 为簇内节点数；手工按链接清单估算 |
| 涌现强度 S | 簇级涌现强度：S = 簇内链接数 × 内聚度（或链接密度 × 节点参与度） | S = E × C（簇内链接数乘以簇内聚度），反映簇的语义耦合紧密度；本文用相对排序而非绝对值 |
| 一级涌现 | E1…En：直接由知识元+链接构成的可辨识结构 | 即各 Topic 簇本身 |
| 二级涌现 | P1…Pn：由多个 Topic/Theme 组合生成的论文级命题 | 跨 Theme 综合出的、原文未单点陈述但被证据支持的整体性命题 |

**客观性约束**：所有 k、b、C、S 值均为"语义计数"，以链接清单为唯一数据源；链接清单每一条都有行号证据；反例与边界（如链接方向存疑、证据缺口）必须在相应报告中注明，不得隐瞒。

## 四、证据规范

1. 每条链接、每个簇、每个命题必须可回溯到 `02_语义链接网络.md` 的链接清单与原文行号。
2. 行号以源文件（无 `_clean.md` 版本）为准。
3. 本论文源文件含 OCR 单字符错乱（如 L35 "máy"）与排版性断行（L84↔L99 段落被插图分隔；L190-192 断行），不影响语义判定；涉及处已按上下文还原。
4. 禁止编造原文未出现的关系；对"点到未论"的潜在链接（`04_知识发现报告.md` C1…Cn）必须标注证据缺口。
