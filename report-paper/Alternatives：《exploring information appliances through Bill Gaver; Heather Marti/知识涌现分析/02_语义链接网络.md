# 02_语义链接网络

## 三、枢纽与中介分析（含反例与边界）

1. **全局桥接枢纽：提案群（b=4）**。workbook 同时连接概念域（测绘对象 A9-A10）、价值域（其内容即六价值，B4 及 C 区全部例证）、方法论域（E1-E20）与机构域（F5）。它几乎不直接出现在任何一条"论点句"之外，却是所有例证的宿主——**提案群是网络的物质中枢，而非语义中枢**；语义中枢是替代价值（k=10）。
2. **语义中枢：替代价值（k=10）**。它是六价值小节的父节点（B8-B13），又是二分批判的对立面（B3），还承接情感通信谱系（B5）。文本中"替代价值"一词仅出现于 L15、L31-33、L60，但网络载荷最高——典型的"低词频、高载荷"枢纽。
3. **双挂载例证：Dawn Chorus（k=5, b=2）**。同一提案同时挂在影响价值（C14）、价值虚构（D8）与驯化批判（C15）之下，还被用于拼贴方法示范（L180）——一个提案承载四种论证功能，是论文"一物多用"论证经济学的极致体现。
4. **隐藏枢纽：情感通信（k=4, b=2）**。文本中仅在 L35 与 L115 两处出现，但它是"价值谱系起点（B5-B6）"与"亲密价值的方法对照（C21）"两个关键链接的必经节点；若删除该节点，B 区与 C 区的亲密子簇将失去与外部的连接。
5. **隐藏桥：意义投射倾向（k=2, b=2）**。L129（Gestalt Camera 机制）与 L154（神秘提案的成立条件）两处支撑着洞察与神秘两个价值域的共同心理机制；文本从未为它设专节，却承担了"六价值统一性"的隐性论证——**它把看似最不相干的两类提案（心理测验相机与祈祷装置）焊在同一机制上**。
6. **反例与边界核对**：
   - L72 "Ishii [see 1]"：文献指涉存疑（[1] 为 Brave & Dahley），故谱系链接 F 区未把 Ishii 单列，仅记"软美学谱系 ⇐ Weiser/Philips"，并在本报告与实体索引中注明。
   - L111 "figure 6" 与 L92-93 图注 6（Dream Communicator）冲突：民主广告的图号引用不可靠，但不影响其语义链接（C18-C19 以文字 L111 为准）。
   - 链接 D5（行业 vs 设计原型判据）方向性：原文以 Fiona Raby 之口陈述，作者采纳之，故方向定为"设计判据 ⇐ Fiona Raby"，无反向证据。
   - E11/E18 的"分析进路"是作者设定的对比项，原文未展开正面论述（L194 "This might have been done by addressing the space more analytically"），属"点到未论"——已在 04 报告 C 系列中标注。

## 四、网络整体特征

1. **规模**：约 45 个活跃知识元，93 条链接（A10 + B15 + C31 + D10 + E20 + F8 = 94 条），链接密度高。
2. **结构形态**："伞形放射 + 双轴"结构——横轴为"概念域（信息家电/设计空间）→ 价值域（六价值）→ 方法域（三要素/占位符）"的主论证链；纵轴为"提案例证"自价值域向下放射的伞骨（C 区 31 条链接）。放射伞骨在底层（意义投射、严肃游戏、外围感知）再次交汇，形成局部回路。
3. **强连通性**：提案群—替代价值—信息家电—设计空间四节点间存在循环路径（A9→A10 逆向、B1→A5 等），构成核心强连通子图；价值域六子簇间靠"替代价值"父节点与"意义投射/严肃游戏"桥弱连通。
4. **谱系依赖**：所有谱系支撑链接（⇐）共 10 条（A8、C7、C12、D3、D6、E7、E14、F6、F7），集中在"定义、价值定性、方法基石"三处，显示论文的论证借力结构——新主张均挂在既有权威上。
5. **客观性说明**：以上 k/b 值为手工语义计数（以链接清单为唯一数据源），微小差异（如印象式显示 k=4 或 5）不影响排序结论；链接方向按原文语义判定，所有歧义处已在第三节注明。
