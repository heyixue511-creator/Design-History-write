# 01_知识元语意分析

**论文**：Cameron Tonkinwise《Is Design Finished? Dematerialisation and Changing Things》（2004）
**证据基准**：源文件 241 行，行号 L### 即源文件行号。
**任务**：六类实体的全文语义载荷（"做什么、指什么、为何存在"），先总述五种论证功能，再按类分表。

---

## 一、总述：知识元的五种论证功能

本文论证以"概念—人物—著作"三型知识元为主，机构/地点/事件多为注释层支撑。五种功能分布如下：

1. **因果节点**（承担"X 导致 Y"链）：`mathémata（现代）`、`完成性 finishedness`、`制造完成之物`、`流量 throughput`、`缩短使用期`。例：`完成性`→`短命`→`流量`→`垃圾`（L113, L127, L137）。
2. **结构变量**（定义论证框架、划分层级）：`物之四范畴`（pragmata/mathémata/chrémata/poioúmena/phusiká，L53, L59, L69）、`PSS 三类服务`（L223）、`四阶段转变`（L99-L107）、`三重障碍`（L167-L169）。
3. **类型标签**（对现象命名归类）：`产品主义`（L95）、`消费者主义=无法维持`（L127）、`可处置耐用品`（L129）、`计划性报废`（L129）、`降档者`（L41）、`河流经济`（L43）。
4. **证据载体**（引文/文献支撑论证）：`海德格尔《物之理》`（L59-L69）、`海德格尔《论 physis》`（L77-L87）、`Shove 书`（L51）、`Moles 两文`（L153-L155）、`Manzini《日常的普罗米修斯》`（L91, L141）、`Rilke/Ersatz`（L109-L111）、`Packard/OECD/Terotechnology`（L227）。
5. **参照坐标**（提供对立面或谱系定位）：`Werkbund→Packard→Terotechnology→EternallyYours`（L149, L227）、`Morelli/Bhamra`（L237）、`设计经典`（L149）、`希腊/前苏格拉底`（L123）、`现代数学（Galileo/Newton/Descartes/Kant）`（L59-L61）。

## 二、概念类（核心语义载荷）

| 知识元 | 做什么/指什么/为何存在 | 论证功能 | 行号 |
|---|---|---|---|
| thingliness（物性） | 全文主题：被设计之物的存在方式，使"长命而少用、可积累可弃"之物成为可能；本文任务即阐明之 | 因果节点/结构变量 | L55 |
| mathémata（数学性） | 物被经验为物的"前理解"；希腊原初是实践性的，现代转为量化/蓝图式 | 因果节点/结构变量 | L59, L61, L69 |
| Entwurf（投影/蓝图） | 跳过事物本身的"物性蓝图"；作者提示宜译 design | 因果节点 | L61, L191 |
| pragmata / chrémata / poioúmena / phusiká | 物之四范畴：打交道之物/常备之手之物/手制成品/自然生成之物 | 结构变量 | L53, L69 |
| kinesis（动性） | 一切存在之本质；床架/衣物/盾/房屋皆"在静止中运动" | 结构变量/因果节点 | L77-L79 |
| entelecheia | "持守于其端"：永远在途却时时完整；与"完成"相对 | 对比轴 | L85, L87, L101, L121, L241 |
| techné / poiesis | 制作/制造；其结果"完成即静止"；制造之存在论 | 因果节点 | L69, L81-L87, L99, L113, L123 |
| physis | 非制造的生成；永远在形成中；与"被维持"相连 | 对比轴 | L77-L87, L95-L97 |
| productivism（产品主义） | 把一切视为被制造、已完成、静止之物的倾向；使物可被剥削为手段 | 类型标签/因果节点 | L95 |
| finishedness（完成性） | 现代（未）制造之物的存在方式；"抛入世界仿佛从此不变"；注定短命 | 因果节点（全链之首） | L87, L113, L129, L159 |
| Gegen-Stand / objectness / standing-reserve | 物之现代在场方式：立于对面→对象→持存储备（座架） | 结构变量（四阶段之三、四） | L105-L107 |
| Ersatz（替代品） | 消费对象之"恒定者"：不是自持而是可替换性（引 Rilke） | 证据载体/因果节点 | L111 |
| consumerism（消费者主义） | 被重释为"根本性的无法维持事物"；对物之老化/时间性的拒绝 | 类型标签/因果节点 | L49, L113, L127 |
| throughput / standing stock | 流量/存量；不可持续之根源在流量 | 结构变量/因果节点 | L43, L135 |
| river economy（河流经济） | Stahel 术语：原料→垃圾的线性流动 | 类型标签 | L43 |
| disposable durables（可处置耐用品） | 悖论现象：如塑料——"完美的技术产品" | 类型标签/因果节点 | L129, L137 |
| planned obsolescence（计划性报废） | 因完成性而"能成为设计策略"（而废物管理不能） | 对比轴/类型标签 | L129, L149, L227 |
| PSS（产品服务系统） | 以最少物质投入交付功能结果；须聚焦面向产品的服务并处理时间性，否则本身成弃物 | 结构变量/因果节点 | L67, L137, L151, L197, L223, L237 |
| product-oriented / use-oriented / result-oriented services | PSS 三类：延长使用期/租赁共享/绩效合同（negawatts） | 结构变量（隶属关系） | L137, L223 |
| dematerialisation / rematerialisation | 去物质化/再物质化；前者是幻觉（Moles 悖论），后者在寿命延长条件下可作为前者策略 | 对比轴/因果节点 | L67, L137, L153 |
| re-thing-ification / re-temporalisation | 处方概念：物之再物化=再时间化 | 类型标签（造词） | L137 |
| sustainment / maintenance | 处方核心：希腊式"积极维持"；Moles"维护心态" | 因果节点/结构变量 | L87, L125, L153 |
| product-plus | 产品+为"物须被积极维持"负责的过程 | 类型标签 | L151, L229 |
| Comprehensive Guarantee | Moles 方案：销售附带维修/赔偿合同；反作用于设计过程 | 证据载体/结构变量 | L155, L233 |
| extended producer responsibility | 生产者责任延伸（当代话语，Moles 先知） | 参照坐标 | L155 |
| object/user binome | 对象/用户二体之微观心理分析单位 | 结构变量 | L155 |
| continuous design / redesigning | Jones 概念；理想设计形态："再设计同一物之物质独特性" | 类型标签/因果节点 | L165, L239 |
| imperfectionism（不完美主义） | 本文对"设计未完成之物"伦理的称呼 | 类型标签 | L167 |
| eidos / morphe | 外观/形式作为完成性之界定边界 | 结构变量（论证支撑） | L159 |
| design classic（设计经典） | 批判对象：无时间产品之陈词滥调 | 参照坐标 | L149 |
| homo faber | 制造者之人；马克思主义外化/异化人类学障碍 | 参照坐标 | L47, L167 |
| actor network theory | Shove 方法论来源：用户与产品之历史共构 | 参照坐标 | L51 |
| unconscious consumption | Shove 之"无意识消费"分析 | 参照坐标 | L51 |
| 塑料（plastic） | 可处置耐用品之具象：被解释为"完美的技术产品" | 证据载体（案例） | L129 |
| downshifters（降档者） | 主动减少物之数量者；其"亚文化"地位反证常态 | 证据载体（案例） | L41 |
