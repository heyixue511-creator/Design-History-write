# 00_方法与规则

## 论文：Laura Forlano《Posthumanism and Design》（2017）——知识涌现分析的方法与规则

## 一、层级定义

| 层级 | 定义 | 本论文实例（简述） |
| --- | --- | --- |
| 知识元（Knowledge Element） | 六类实体：人物、著作/作品、概念、机构、地点、事件；是分析的最小单元，每个知识元携带语义载荷（做什么/指什么/为何存在） | 概念：posthumanism（L108）、ANT（L116）；人物：Braidotti（L128）、Haraway（L188）；事件：伊斯坦布尔双年展（L278）等 |
| Topic（主题簇） | 强连通簇：知识元之间通过语义链接紧密互连的局部集群；簇内链接密度显著高于簇间 | 如"ANT 理论簇"（Latour—非人—缺失的大众—扁平社会）、"批判种族簇"（Weheliye—普遍主体—交叉性—去殖民设计） |
| Theme（高层语义域） | 由若干 Topic 聚合而成的高层语义域，反映论文的整体知识组织 | 如"后人类理论谱系"、"设计范式批判"、"设计实践转向"、"平等与正义" |

**涌现的含义**：由底层知识元及其链接关系中"生长"出来、任何单个知识元不直接承载的整体性质——簇（Topic）、域（Theme）、跨簇命题（P）、隐藏枢纽与潜在链接（C）。

## 二、9 种语义链接判定标准

链接记作 `A --类型--> B`（类型符号置于中间），每条链接必须有行号证据。

| 类型 | 符号 | 判定标准（判据） | 示例（本文） |
| --- | --- | --- | --- |
| 因果 | → | A 是 B 的原因/驱动/促成条件；文本中有 cause/leads to/result in/motivate/thus 类表述 | 环境与技术变革（L22）→ 二元边界消融（L24） |
| 条件 | ⇒ | A 是 B 的前提/必要条件；有 if/requires/necessary for/depends on 类表述 | 理解后人类（L26）⇒ 发展相应设计方法（L26） |
| 对比 | ↔ | A 与 B 对立、相区别或互为反题；有 but/whereas/on the other hand/in contrast 类表述 | HCD（L32）↔ 后人类设计（L324） |
| 隶属 | ⊂ | A 是 B 的子类/成员/组成；有 is a kind of/includes/part of 类表述 | 女性主义新物质主义 ⊂ 后人类理论谱系（L114） |
| 时序 | ≻ | A 先于 B 发生或在论述中先行；有 since/in 1980s/then/currently 类表述 | Hawthorne 研究（1920s，L34）≻ Xerox PARC 民族志（1980s，L46） |
| 空间共现 | ≈ | A 与 B 在同一地点/空间框架中共同出现或相互关联；有 at/in/co-located 类表述 | Whanganui 河 ≈ 毛利部落（L50）；盒中人 ≈ 实验室（L336） |
| 属性 | : | A 具有属性/特征 B；B 是 A 的定性描述；有 is described as/characterized by 类表述 | 后人类主体 : 具身、嵌入、关系性（L180） |
| 论证支撑 | ⇐ | A 被用作 B 的论据/证据/例证；A 支撑 B 的成立 | 松茸民族志（L184）⇐ 女性主义新物质主义方法论主张（L184-186） |
| 同域 | ∼ | A 与 B 属于同一概念域/讨论场域，无明确方向性；共用话题、术语或语境 | 超人类主义 ∼ 奇点（L274）∼《Transcendence》（L274） |

**使用规则**：
1. 每一条链接必须给出具体行号（允许范围，如 L118、L118-124）；
2. 同一对实体可按不同证据建立多条不同类型链接；
3. 无证据支撑的关系不得建链；弱证据关系列入"点到未论"潜在链接（C 系列，见 04 报告）；
4. 方向：因果/条件/隶属/时序/论证支撑有方向；对比/空间共现/同域/属性无方向或弱方向。

## 三、涌现指标

| 指标 | 符号/定义 | 计算口径（语义版） | 阈值/用法 |
| --- | --- | --- | --- |
| 节点度 | k | 与某知识元直接相连的链接数（去重后） | k≥6 为核心枢纽；k=4-5 为次级枢纽 |
| 桥接值 | b | 连接不同 Topic/Theme 的链接数（跨簇链接计数） | b≥3 为桥接元；桥接元是跨主题综合的关键 |
| 簇识别 | 强连通簇 | 簇内任意两点经有向/无向链接可达的子图；按主题区人工核对 | 期望 6-15 个 Topic |
| 内聚度 | c | 簇内链接数 / 簇内节点数（链接密度） | c 高=内聚强 |
| 涌现强度 | S | 簇规模 × 内聚度 × 桥接贡献的综合定性-半定量评分（S=高/中/低 或 1-5 级） | 与命题生成挂钩 |
| 一级涌现 | E1…En | 直接由簇（Topic）整体承载的新知识：簇的主题化概括，非任一知识元单独所有 | 每个 Topic 一条 E |
| 二级涌现 | P1…Pn | 跨簇/跨主题综合命题：由 ≥2 个 Topic 的桥接关系生成 | 每条附生成机制与强度 |

**说明**：因约束"不编写分析代码、不做统计/编程处理"，以上指标以人工语义计数与估算执行，数值为证据驱动的近似值，报告中注明"人工核算"。

## 四、证据规范

1. 所有知识元、链接、簇、命题均标注行号（L### 或 L###-L###）；
2. 行号必须与源文件实际内容对应，不得编造；
3. 簇与命题的判定需引用原文表述作为核验锚点；
4. 客观性核对：对每项涌现结论列出反例或边界（见 02/03 报告的"反例与边界"节）；
5. 若某结论证据不足，明确标注"证据缺口"，转入潜在链接 C 系列。
