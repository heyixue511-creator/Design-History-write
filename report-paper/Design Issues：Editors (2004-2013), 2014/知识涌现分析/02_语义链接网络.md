## 三、枢纽与中介分析

1. **Carnegie Mellon University（k=9，b=5）**：文本最大枢纽。它横跨顾问簇（Ballay、Evenson，L2）与编委会簇（Boyarski、Hanington、Ishizaki、S. Stadelmeier、Swinehart，L5），并因 Buchanan 长期任教（外部知识，文本未明示）与主编簇间接相连。**反例/边界**：文本并未为 CMU 单独作任何论述，其"枢纽地位"完全是条目频次的涌现；且 CMU 条目全部集中于 2004–2011 与 2004–present 两批，2011 年后新入编委无 CMU 成员，提示其"母港"地位或正被稀释——此为文本边界内的谨慎推断。
2. **Richard Buchanan（k=6，b=4）**：人物层面最强中介——唯一同时横跨"主编簇"与"客座编辑簇"者（L1 / pL3、pL14）。**客观性核对**：其桥接值来自文本明示的双角色事实，无误。
3. **2011 任期批次（k=12，b=4）**：时间概念成为隐藏枢纽——它既是编委会扩容批次的共同属性（L5），又与顾问委员会终止年（2004–2011，L2–L3）重合，是"制度模式转换"推断的时间锚点。
4. **Frascara / Grefé（各 k=5，b=3）**：顾问簇与编委会簇之间的活体桥接者——二人是仅有的"从顾问直接转入编委会"的成员（L2 / pL49、pL51；L5 / pL75、pL76），是"顾问委员会并入编委会"假说的直接证据。
5. **中介缺失项（点到未论）**：文本未记录任何"主编—机构"的正式隶属（主编的大学职务未标注），导致 Buchanan/Doordan/Margolin 与 CMU/NDU 等机构的链接只能靠外部知识补足——这是名录体例的证据缺口。

## 四、网络整体特征

1. **星型—链式混合**：以 CMU、Lancaster、AIGA 等机构为星型中心；以执行编辑、书评编辑、编辑助理的任期交接为链式时序。
2. **强分层**：网络沿职务层级（主编→专项→运营→事务→编委/顾问）清晰分层，跨层链接稀少（仅 Buchanan、DiSalvo、Evenson、Sutherland、Triggs、Frascara、Grefé 等少数多角色者）。
3. **时间批次聚类**：实体按 2004 / 2008 / 2009 / 2011 / 2012 / 2013 六个年份批次聚类，时间维度与角色维度正交，形成"角色 × 年份"的网格结构。
4. **弱因果、强隶属**：链接类型以隶属 ⊂（人属机构/人属角色）与属性 :（任期、头衔）为主（约 80%），因果/条件链接几乎缺席（仅顾问终止→编委会扩容一条弱因果推断），反映名录文本"描述态"而非"叙事态"。
5. **地理桥接**：地点实体（England、China、Finland 等）通过机构间接连接人物，构成"人物—机构—地点"三级链，全球网络由此形成。
