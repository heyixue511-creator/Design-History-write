# 设计史教材写作仓库

《现当代设计史》（设计学理论专业）教材写作项目的知识库与工作空间。

## 仓库结构

```
├── 00-参考原则/        → 写作体例与参考范例
├── 01-基础文献/        → 原始文献全文（清洗后）
│   ├── books/          → 517 本著作
│   └── papers/         → 72 篇论文
├── 02-文献解析/        → 书籍与论文的分析报告
│   ├── book-reports/   → 著作逐章分析报告
│   ├── paper-reports/  → 论文分析报告
├── 03-教材框架/        → 当前教材总纲
├── 04-教材初稿/        → 正文初稿目录（当前为空）
├── 05-全文润色/        → 润色稿目录（当前为空）
└── 99-文献补充/        → 写作过程中新发现的补充材料
```

## 工作流程

```
01-基础文献 ──→ 02-文献解析 ──→ 03-教材框架
      ↑                │                │
      └── 原文核验 ←── 章节研究 ──────┘
                       │
                       └──→ 04-教材初稿 ──→ 05-全文润色
                              ↑
                         99-文献补充
```

1. **[01-基础文献](01-基础文献/)** 收集设计史领域著作与论文的清洗后全文（Markdown）
2. **[02-文献解析](02-文献解析/)** 保存书籍和论文的分析报告，用于发现材料、定位论证和识别争议；分析报告不能替代原文核验
3. **[03-教材框架](03-教材框架/)** 当前保存全书总纲；逐章写作前仍须根据相关文献重建该章的命题—材料对应关系
4. **[04-教材初稿](04-教材初稿/)** 用于后续逐章正文初稿；当前没有现行初稿
5. **[05-全文润色](05-全文润色/)** 用于后续统一润色和体例调整；当前为空
6. **[99-文献补充](99-文献补充/)** 写作过程中新发现、需补充分析的文献材料
