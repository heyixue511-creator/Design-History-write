# 设计史教材写作仓库

《现当代设计史》（设计学理论专业）教材写作项目的知识库与工作空间。

## 仓库结构

```
├── 00-参考原则/        → 写作体例与参考范例
├── 01-基础文献/        → 原始文献全文（清洗后）
│   ├── books/          → 517 本著作
│   └── papers/         → 72 篇论文
├── 02-文献解析/        → 文献分析产物与证据流水线
│   ├── book-reports/   → 著作逐章分析报告
│   ├── paper-reports/  → 论文分析报告
│   └── evidence-pipeline/ → 证据流水线（知识模型转换工具链）
├── 03-教材框架/        → 总纲大纲与逐章写作框架
├── 04-教材初稿/        → 各章正文初稿
├── 05-全文润色/        → 润色后终稿
└── 99-文献补充/        → 写作过程中新发现的补充材料
```

## 工作流程

```
01-基础文献 ──→ 02-文献解析 ──→ 03-教材框架 ──→ 04-教材初稿 ──→ 05-全文润色
                   │                │
                   └→ 证据矩阵       │
                     章节映射 ←──── 99-文献补充
```

1. **[01-基础文献](01-基础文献/)** 收集设计史领域著作与论文的清洗后全文（Markdown）
2. **[02-文献解析](02-文献解析/)** 对每份文献进行逐章分析，通过证据流水线生成来源卡、章节映射、核心命题矩阵
3. **[03-教材框架](03-教材框架/)** 确定全书大纲与各章写作框架（先定框架，再写作）
4. **[04-教材初稿](04-教材初稿/)** 按框架逐章撰写正文初稿
5. **[05-全文润色](05-全文润色/)** 对初稿进行统一润色和体例调整
6. **[99-文献补充](99-文献补充/)** 写作过程中新发现、需补充分析的文献材料
