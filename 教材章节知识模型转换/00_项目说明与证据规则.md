# 《现当代设计史》教材知识建模：项目说明与证据规则

## 1. 项目目标

本目录承担“参考文献分析资产 → 教材章节知识模型转换”。它位于既有文献知识库与教材正文之间，回答三个问题：

1. 教材每一章、每一节准备解释什么历史问题；
2. 哪一项教材命题由哪些来源、对象、人物、制度、事件和反例支撑；
3. 每项材料已经核验到什么程度，尚不能支持什么外推。

本阶段不直接生成教材正文。机器生成的相似度排名、知识涌现关系和报告摘要均不得自动升级为教材事实。

## 3. 两轴证据等级

### 3.1 来源类型 P0—P4

| 等级 | 定义 | 使用边界 |
|---|---|---|
| P0 | 实物、档案、政策、专利、课程、企业记录、宣言、目录、软件版本、平台规则等原始材料 | 仍须核身份、版本、语境和保存偏差 |
| P1 | 完整学术专著、论文、展览研究和可靠行业史 | 可承担解释和互校，不替代其引用的P0 |
| P2 | 书评、节录、项目记录和评论 | 只承担有限评论、线索或项目存在证明 |
| P3 | 书介、网页、目录、征稿和编辑名单 | 只用于发现与追索 |
| P4 | 项目分析报告和知识涌现报告 | 只用于检索、语义路由和提出待核关系 |

### 3.2 核验状态 V0—V4

| 等级 | 定义 | 正文权限 |
|---|---|---|
| V4 | 原文、版本、具体页码／位置和上下文均已核验 | 可引用或严格转述 |
| V3 | 已核完整原文内容，但尚未逐字核定引文 | 可可靠转述，不作逐字引文 |
| V2 | 已详细读取分析报告，尚未返回原文 | 用于建模与初稿路由 |
| V1 | 来自知识涌现、自动链接或跨文献推断 | 只能形成研究假设 |
| V0 | 未验证、无法定位或模型推测 | 不进入正文 |

P等级与V等级互不替代。例如，一份P1学术专著在只读过项目报告时仍只能标为V2。

## 4. 映射等级

| 等级 | 含义 |
|---|---|
| A | 可承担该节核心命题的核心文献 |
| B | 可承担关键机制、案例或争议的重要文献 |
| C | 补充对象、地区、概念、方法或反例 |
| D | 待返回原文的导航线索 |
| X | 不匹配、跨学科同词异义或因材料等级不足而排除 |

任何来源都必须获得A—D或X的最终处置，但不得为了“全部匹配”而强行安排章节。

## 5. 最小证据单元

正式原子证据卡至少包含：证据ID、证据命题、来源与版本、来源位置、P等级、V等级、适用章／节、教材功能、可支持命题、不能支持的外推、时间与地理边界、反例／争议和原文复核状态。

追溯链统一为：

> 教材句子 → 教材命题 → 原子证据卡 → 分析报告定位 → 原始文献／对象

## 6. 因果与关系规则

系统必须区分时间先后、共现、形式类比、直接接触、制度传播、行动者因果主张、研究者机制解释、教材作者综合判断和已验证因果。没有技术、组织、政策、市场、劳动、传播或使用等中介证据时，不把关系升级为因果。
